# 前端界面菜单重构 — 2级分组菜单

> **§20260812-01** | 2026-08-12 | 状态：实施中

## 1. 背景与问题

当前 `AppSidebar` 的 12 个菜单项以**扁平列表**呈现，随着平台游戏数量增长（6 款游戏 + 管理功能），存在以下问题：

| 问题 | 影响 |
|------|------|
| 游戏种类无分类 | 传统棋类、卡牌、AI Agent 游戏混排，用户难以快速定位 |
| 无视觉层级 | 所有菜单项同等权重，核心游戏与管理功能没有主次之分 |
| 扫描效率低 | 用户需要从头到尾线性扫描，而非按分类跳转 |

## 2. 设计目标

1. **引入 2 级分组菜单**：一级为分类标题（可折叠），二级为具体菜单项
2. **两大游戏分类**：
   - 🎲 **传统游戏**：中国象棋、国际象棋、中国军棋、斗地主、德州扑克
   - 🐺 **Agent 游戏**：狼人杀 13 人局
3. **保持现有功能**：折叠态兼容、移动端 drawer、用户权限过滤
4. **美观且符合暗色主题**：分组标题使用小字号、分隔线，折叠态只显示图标

## 3. 信息架构

### 3.1 菜单结构

```
🏠 游戏大厅          (首页，end match)
🎲 全部游戏          (全部游戏列表页)
─────────────────
🎲 传统游戏          ▼ (一级分组，可折叠)
  ♟  中国象棋
  ♚  国际象棋
  🚩 中国军棋
  🃏 斗地主
  🎰 德州扑克
─────────────────
🐺 Agent 游戏        ▼ (一级分组，可折叠)
  🐺 狼人杀 13人局
─────────────────
👤 个人中心
👥 用户列表          (登录可见)
🤖 模型管理          (管理员可见)
ℹ️  关于
```

### 3.2 折叠态行为

| 状态 | 一级分组 | 二级菜单项 |
|------|---------|-----------|
| 展开 | 显示图标 + 文字 + 展开/收起箭头 | 正常显示 |
| 折叠（桌面） | 仅显示图标，tooltip 显示分组名 | 仅显示图标 |
| 移动端 drawer | 同展开态 | 同展开态 |

### 3.3 默认展开状态

- 「传统游戏」：**默认展开**
- 「Agent 游戏」：**默认展开**
- 用户可折叠，状态存入 `localStorage`（`lsm.sidebar.groups`）

## 4. 数据结构设计

### 4.1 新的菜单定义

```ts
interface MenuItem {
  to: string;
  labelKey: TKey;
  icon: string;
  end?: boolean;
  minUserType?: number;
}

interface MenuGroup {
  id: string;                    // 唯一标识，用于 localStorage
  labelKey: TKey;                // 分组标题 i18n 键
  icon: string;                  // 分组图标
  items: MenuItem[];             // 分组内菜单项
  defaultOpen?: boolean;         // 默认是否展开，默认 true
  minUserType?: number;          // 分组整体的权限门槛
}
```

## 5. CSS 设计方案

### 5.1 分组标题样式

```css
/* 分组标题 */
.sidebar-group__header {
  display: flex;
  align-items: center;
  gap: 6px;
  padding: 10px 12px 4px;
  font-size: 11px;
  font-weight: 600;
  text-transform: uppercase;
  letter-spacing: 0.5px;
  color: var(--muted);
  cursor: pointer;
  user-select: none;
  border-top: 1px solid var(--border);
  margin-top: 4px;
}
.sidebar-group__header:hover {
  color: var(--text);
}

/* 展开/收起箭头 */
.sidebar-group__arrow {
  margin-left: auto;
  font-size: 10px;
  transition: transform 0.2s ease;
}
.sidebar-group--collapsed .sidebar-group__arrow {
  transform: rotate(-90deg);
}

/* 分组内容区域 */
.sidebar-group__items {
  display: flex;
  flex-direction: column;
  gap: 2px;
  overflow: hidden;
  transition: max-height 0.2s ease;
}
.sidebar-group--collapsed .sidebar-group__items {
  max-height: 0;
}

/* 折叠态隐藏分组标题文字 */
.app-sidebar--collapsed .sidebar-group__header {
  justify-content: center;
  padding: 8px 4px;
  border-top: 1px solid var(--border);
  margin-top: 6px;
}
.app-sidebar--collapsed .sidebar-group__label,
.app-sidebar--collapsed .sidebar-group__arrow {
  display: none;
}
```

### 5.2 缩进区分

二级菜单项通过左侧 padding 增加 8px 缩进，形成视觉层级：

```css
.sidebar-group__items .sidebar-link {
  padding-left: 20px;  /* 原始 12px + 8px 缩进 */
}
```
