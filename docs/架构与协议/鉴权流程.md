# 鉴权流程

## 注册

```
浏览器                        HTTPS :39001                  MariaDB
  │                                │                          │
  │ POST /api/auth/register        │                          │
  │ { account, password,            │                          │
  │   phone?, email? }             │                          │
  ├───────────────────────────────►│                          │
  │                                │ bcrypt 加盐哈希          │
  │                                │ 唯一性检查               │
  │                                ├─────────────────────────►│
  │                                │◄─────────────────────────┤
  │                                │ INSERT t_lsm_game_user   │
  │                                ├─────────────────────────►│
  │                                │◄─────────────────────────┤
  │                                │ 签发 JWT（HS256）        │
  │                                │ INSERT t_lsm_game_session│
  │                                ├─────────────────────────►│
  │                                │◄─────────────────────────┤
  │ { code:0, data:{ token,        │                          │
  │   user_id, expires_at }}       │                          │
  │◄───────────────────────────────┤                          │
  │ localStorage['lsm.token']=…    │                          │
  │ zustand.isAuthenticated=true   │                          │
```

## 登录

流程与注册类似，但服务端使用 `bcrypt.CompareHashAndPassword` 校验已存储的哈希。成功时同步更新 `last_login_at`。

## WebSocket 升级

登录成功后，客户端调用 `wsClient.connect()`：

```
浏览器                        WSS :39002                   Hub
  │                                │                          │
  │ GET /ws?token=<jwt>            │                          │
  │ Upgrade: websocket             │                          │
  ├───────────────────────────────►│                          │
  │                                │ ParseToken(jwt)          │
  │                                │ Upgrade()                │
  │                                │ Client{userID} ────────►│
  │                                │ go WritePump()           │
  │                                │ go ReadPump()            │
  │ { type:"heartbeat",             │                          │
  │   payload:{server_ts} }        │                          │
  │◄───────────────────────────────┤                          │
  │                                │                          │
  │ { type:"ack", seq, payload }    │                          │
  ├───────────────────────────────►│                          │
  │ { type:"ack", seq, payload }    │                          │
  │◄───────────────────────────────┤                          │
```

客户端在 `ClientWeb/src/services/ws.ts` 中以指数退避（500 毫秒 → 8 秒）策略处理重连。每次连接都从 `localStorage` 重新读取 token。

## 刷新

`POST /api/auth/refresh`（需 Bearer 鉴权）签发新的 token。前端暂未自动调用该接口——若 token 被拒绝，会直接重新登录。

## 登出

清空 `localStorage`、重置 zustand 状态、关闭 `wsClient`。**服务端不会主动吊销会话**（token 在过期前一直有效）——吊销机制待真正的会话管理界面出现后再行实现。

## 登录新增的验证码与 Cookie 流程

```
浏览器                          HTTPS :39001
  │                                  │
  │ POST /api/captcha                │
  ├─────────────────────────────────►│  util.CaptchaStore.Issue → uuid + 5字母
  │◄─────────────────────────────────┤  { captcha_id, svg, expires_at }
  │                                  │
  │ POST /api/auth/login             │
  │ { account|phone, password,       │
  │   captcha_id, captcha_answer }   │
  ├─────────────────────────────────►│  util.CaptchaStore.Verify (single-use)
  │                                  │  bcrypt 校验
  │                                  │  util.EncryptCookie(AES-256-GCM, 48h)
  │ Set-Cookie: lsm_auth=…;         │
  │   HttpOnly; Secure;              │
  │   SameSite=Strict;               │
  │   Max-Age=172800                 │
  │ { code:0, data:{ token,…}}       │
  │◄─────────────────────────────────┤
```

Agent 自动化账号（`test_01`..`test_04` 加旧版种子账号 `test19082jauishf8`，共 5 个）跳过 captcha 校验（前后端都识别）。完整白名单与维护规则见 `CLAUDE.md` §18 与 `docs/通用功能/测试账号凭证.md` §6 / §7.2。
