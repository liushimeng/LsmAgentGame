## 2. 设计目标

1. **去重标题**:`💬 房间聊天` 标题元素只渲染一次,作为 chat 面板自带头出现(已经是这样),页面级外层 h3 删除;`Day N` 副信息保留在外层(说明当前天数/阶段)。
2. **整列折叠**:
   - **右列(聊天)** — 折叠按钮放聊天头内,折叠时整个右列变成贴右的窄条(只有 `▶ 💬` 一行),点击展开;展开时按现有 1fr 列宽复原。
   - **左列(房间信息)** — 折叠按钮放房间信息头左(与"👁 房间信息 / 🏠 房间信息" 同行的左侧),折叠时整个左列变成贴左的窄条(只有 `◀ 🏠` 一行),点击展开;展开时按现有 0.6fr 列宽复原。
3. **持久化**:折叠状态写入 `localStorage`,key 分别为 `werewolf.fold.chat` / `werewolf.fold.info`,默认展开。
4. **自适应宽度**:`grid-template-columns` 切换:
   - 全部展开:`minmax(0, 0.6fr) minmax(0, 1.8fr) minmax(0, 1fr)`(现)
   - 仅折叠聊天:`minmax(0, 0.6fr) minmax(0, 2.8fr) minmax(0, 0fr)` (右列宽度 0)
   - 仅折叠信息:`minmax(0, 0fr) minmax(0, 2.4fr) minmax(0, 1fr)` (左列宽度 0)
   - 同时折叠:`minmax(0, 0fr) minmax(0, 3.4fr) minmax(0, 0fr)`
   配合 `transition: grid-template-columns 0.25s ease` 让切换平滑。
5. **13 人局角色排列**:每行能放的 SeatCard 数取决于中栏宽度。当前 `.werewolf-table__grid` 没有显式控制 column count,跟随容器宽度变化。我们利用 width 增大同步放大单行角色数 — 用 CSS 媒体查询仍不够,需要以"折叠后宽度变化"为驱动的自适应:
   - 默认(`1fr` 列宽 ≤ 600px):每行 5 角色(`grid-template-columns: repeat(5, 1fr)`)
   - 折叠后(`1fr` 列宽 800–1100px):每行 7 角色
   - 大屏 2K+:`repeat(auto-fit, minmax(72px, 1fr))` 自由排

### 3.2 `ClientWeb/src/components/werewolf/GameChatPanel.tsx`(狼人杀专用 wrapper)

只增 prop 透传:接受 `folded: boolean; onToggleFold: () => void`,显示在头部(用一个 `<button class="werewolf-chat-fold">▶/◀</button>`)。

但因共享 `xiangqi/GameChatPanel` 是跨游戏共用的,改它会影响 4 款其它游戏。为避免作用域扩散,**改为在狼人杀 wrapper 内自己包装一层折叠栏**:在外层 `WerewolfGameChatPanel` 包裹一个 `<div class="werewolf-chat-wrap">`,把 `<div class="werewolf-chat-wrap__handle">` 放在 wrapper 顶部,折叠时整个 wrapper 隐藏 handle,只留 handle 这一根窄条。

> 抉择:不修改共享 `xiangqi/GameChatPanel`,把折叠按钮与 Day N 副标题画在 wolfchat wrapper 外层。

### 3.3 `ClientWeb/src/components/werewolf/GameInfoPanel.tsx`

- 新增 props: `folded: boolean; onToggleFold: () => void`
- 当 `folded === true` 时整个 `game-info-panel` 内容不渲染,只渲染一个贴左的浮动按钮 `<div class="room-info-fold-handle">▶ 🏠</div>`(在父组件侧控制)
- 块 4(状态)改为左右各占 50% 的 `info-block__row`(已是),但追加 `flex: 1` + `min-width: 0`,确保中等宽度不被压缩
- 块 5(规则+退出)按钮并排时各占 50%(`flex: 1 1 0`),但需要给 `min-width: 0`,避免按钮文案超长时撑爆
- 暂停按钮(房主):追加 `width: 100%`,占满整个信息列宽

## 5. 风险与边界

| 风险 | 处理 |
|---|---|
| 中栏变成超宽后某些桌面 SVG 元素错位(固定 px 宽) | `.werewolf-table__bg { background-size: cover; background-position: center; }` 已在;新增 `.werewolf-table__grid` 用 `auto-fit minmax` 让卡片自然伸缩 |
| localStorage 在隐身模式下不可写 | `try/catch` 包住读写,失败时按默认展开行为 |
| 折叠过渡卡顿 | `transition: grid-template-columns 0.25s ease`(标准 CSS,GPU 加速无 paint) |
| 折叠按钮的 z-index 太低被挡住 | handle 不进入 `game-area` flex 容器,而是外层 `position: relative` 容器内 `position: sticky; top: 0`,层级在 .game-sidebar 内正常显示 |
| 座位网格改用 grid 后,某些子组件依赖父级 flex 失效 | 不删除 `.werewolf-table` 的 `display:flex`;只把 `__grid` 子元素改 grid,卡片自身仍按原 markup 渲染 |
