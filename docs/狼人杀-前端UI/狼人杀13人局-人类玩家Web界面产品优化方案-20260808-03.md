## 3. 目标设计

### 3.1 PropPanel 收起/展开（缺陷 A）

在 `PropPanel` header 旁加「▼/▲ 收起」按钮（默认展开，13 人完整列表约 320px）。

```
┌ 🎴 道具系统                                    [▲ 收起] ┐
│ 档位: 健康 · 销毁率 30%                                │
│ 金币 12680 · 剩余 6 次                                  │
│ ┌───────────────────────────────────────────────┐ │
│ │ 📰 公告轰炸   130  🎯 30%  [使用 → #3]       │ │
│ │ 🎭 剧本迷宫   160  🎯 25%  [使用 → #4]       │ │
│ │ ...                                              │ │
│ └───────────────────────────────────────────────┘ │
│ ▶ 最近 10 次道具使用                                          │
```

**实现**：
- 加 `useState<boolean>(isCollapsed)`，默认 `false`（展开）
- `isCollapsed` 时整个 `<ul>` 折叠为单行「🎴 道具系统（点击展开）」按钮
- localStorage 持久化 `werewolf.prop.collapsed`（与 §23 fold 状态对齐）
- 收起时 `PropUseOverlay` 仍照常显示（事件驱动与 UI 折叠正交）

### 3.2 人类玩家死亡后 UI 状态（缺陷 B/C/D/E/F）

`WerewolfGamePage.tsx` 已计算 `mySeatAlive`，增加一个**统一死亡守卫**应用到所有玩家面板：

```ts
const mySeatAlive = (() => { ... })();
const iAmDead = !spectator && gameState && !mySeatAlive;
```

各组件守卫语义：

| 组件 | 存活 | 死亡 |
|------|------|------|
| `NightActionPanel` | 全部 5 种形态 | 渲染「☠ 你已阵亡·等待白天参与遗言/观战」 |
| `DayControlPanel` | 全部形态 | 同上，且 vote/speak 形态隐藏 seat-grid |
| `PropPanel` | 正常展开 | 余额/档位/最近事件可见，使用按钮全部 disabled + 「☠ 已死亡·本局道具无法使用」徽章 |
| `HunterShootInline` | 触发 | 仅死态触发（已正确），增加 hint「☠ 你的最后一次射击」 |
| `LastWordsPanel` | 不可见（death_lyric 仅死态） | 已正确 |
| `LastWordsStage` | 死亡/存活/观战都可见 | 已正确（§20260808-02） |
| 狼人自杀按钮 | 需存活 + 狼人 + speak 阶段 | 已正确（§mySeatAlive 守卫） |

### 3.3 PropPanel 死态改造（缺陷 B/G）

保留面板可见（不卸载），但加 `is-dead` 修饰类与死亡徽章：

```tsx
<div className={`werewolf-action-panel werewolf-prop-panel ${iAmDead ? 'is-dead' : ''}`}>
  <h4>🎴 道具系统 {iAmDead && <span className="prop-panel__dead-badge">☠ 已死亡</span>}</h4>
  ...
  <button disabled={!verdict.ok || busy || iAmDead} ...>使用</button>
</div>
```

死态时仍展示：金币余额、档位、剩余次数、最近 10 次事件（透明度 0.6）。余额仍可能因结算 ±100 而变化（透明性）。

### 3.4 DayControlPanel 死态改造（缺陷 C/D）

vote / speak / idiot_reveal / hunter_shoot 分支顶部加死态守卫：

```tsx
if (phase === 'vote') {
  if (!alive) return <DeadObserverPanel phase="vote" ... />;
  return <VotePanel ... />;
}
```

新增统一 `<DeadObserverPanel>` 子组件：

```tsx
function DeadObserverPanel({ phaseLabel, deaths }: ...) {
  return (
    <div className="werewolf-action-panel werewolf-action-panel--dead">
      <h4>☠ 你已阵亡 · {phaseLabel}</h4>
      <p>本阶段存活玩家正在 {phaseLabel}，你可以：</p>
      <ul>
        <li>📺 观看聊天面板与其他玩家动作</li>
        <li>💀 等待遗言阶段发表最后的话（如果适用）</li>
        <li>📜 在历史抽屉查看完整对局</li>
      </ul>
    </div>
  );
}
```

speak 阶段死态显示「等待当前 #N 号发言...」+ 翻牌列表（不发自己的言）。

### 3.5 NightActionPanel 死态改造（缺陷 E）

`NightActionPanel` 顶层加 `alive` 守卫，所有 5 种形态前先判断：

```tsx
const iAmDead = gameState.players?.[mySeat]?.alive === false;
if (iAmDead && phase !== 'death_lyric') {
  return (
    <div className="werewolf-action-panel werewolf-action-panel--dead">
      <h4>☠ 你已阵亡 · 夜间静默</h4>
      <p>夜晚阶段由存活玩家行动（狼人/守卫/预言家/女巫）。等待黎明遗言。</p>
    </div>
  );
}
```

### 3.6 HunterShootInline 死态 hint（缺陷 F）

人类玩家死后触发 HunterShootInline 已正确（`hunter_pending && my_role === 'hunter'`），
但需要加一句：

```tsx
<p className="hunter-dead-hint">☠ 你已阵亡 · 死前的最后一击（不可逆）</p>
```

与 §135「死亡 = 身份保密/开枪才翻牌」规则一致。

## 4. 实施清单

### 4.1 PropPanel.tsx 改造（~50 行新增）

1. 新增 `useState<boolean>` 折叠状态 + localStorage 持久化（默认展开）。
2. header 加折叠按钮（`▼ 收起` / `▶ 展开`）。
3. `alive` 守卫：接收新 prop `iAmDead: boolean`；UI 全部按钮 disabled 时叠加理由。
4. 加 `is-dead` CSS 类与死亡徽章渲染。

### 4.2 WerewolfGamePage.tsx 改造（~30 行新增）

1. 计算 `iAmDead = !spectator && gameState && !mySeatAlive`。
2. 给 `PropPanel` 传 `iAmDead` prop。
3. 给 `NightActionPanel` 传 `iAmDead` prop。
4. `HunterShootInline` 加 dead-hint。
5. 守卫显示位置：把死态面板渲染在正常面板**之上**（死亡是更高优先级状态）。

### 4.3 NightActionPanel.tsx 改造（~15 行新增）

1. 接受 `iAmDead` prop 或内部 `players[mySeat]?.alive` 自检（推荐自检，更解耦）。
2. 顶层守卫：死态 → 返回「☠ 你已阵亡 · 夜间静默」面板，跳过 5 种形态。
3. `death_lyric` 阶段死态允许进入（不渲染该守卫）—— 让 LastWordsPanel 接管。

### 4.4 DayControlPanel.tsx 改造（~80 行新增）

1. vote / speak / idiot_reveal / hunter_shoot 各分支加死态守卫。
2. 抽 `<DeadObserverPanel>` 子组件复用。
3. vote 死态：显示「等待存活玩家投票」+ 当前实时票数（只读）。
4. speak 死态：显示「等待当前 #N 号发言...」+ 已发言列表。
5. idiot_reveal 死态：显示「等待 #N 决定是否翻牌」。
6. hunter_shoot 死态：保留现有面板（这是死亡触发的合法操作），加 hint。

### 4.5 CSS（`werewolf-panels.css` + `werewolf-modal.css`）

样式全部沿用既有色相库，**禁新创色值**（§26.4）。
