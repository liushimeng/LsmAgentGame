## 5. 备注

## 6. Agent CAPTCHA 旁路

登录页强制要求图形验证码（`POST /api/captcha` → `POST /api/auth/login`），唯一的自动旁路账户是：

| 字段 | 值 |
| --- | --- |
| account | `test19082jauishf8`（大小写敏感） |

调用 `/api/auth/login` 时该账号可以省略 `captcha_id` / `captcha_answer`，其余账号必须先求解验证码再登录（错误码 10301/10302/10303）。

前端识别该账号后会**自动隐藏验证码 UI 字段**，方便 Agent 自动化脚本调用。

### 7.5 Agent 自动化脚本消费方式

```javascript
// Node.js / 浏览器自动化测试场景
import accounts from './test_account.json' assert { type: 'json' };
for (const { account, password } of accounts.accounts) {
  await fetch('https://127.0.0.1:39001/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ account, password }),
  });
}
```

> ⚠️ `test_04` 的密码含分号 `;`，在 shell / curl 单引号外层或 `JSON.stringify`
> 嵌入时不会出问题，但若嵌入到 `eval "$(echo ...)"` 等命令替换里必须先做转义。
