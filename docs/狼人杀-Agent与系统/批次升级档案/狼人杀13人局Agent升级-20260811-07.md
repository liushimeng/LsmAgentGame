## U1 — 死后幽灵语音 `GhostVoice`（§6.5 / DeepSeek §四.2 + M3 §3 S1）

### 1.1 问题
当前死亡玩家从 `killPlayer` 触发的瞬间直接进入"观战者/出局"态：
- 人类死亡仅显示 `ActivityEventKindPlayerDied` 一行 "💀 N号 死亡(cause)"，**没有任何
  "最后想法"** —— LLM 玩家持续推理的最后一段内心独白（`HeartThought`）完全被埋没；
- 死亡信息流对玩家侧只有"你死了"——丢失了 LLM 死亡瞬间最有戏剧性的"遗言前 1 秒
  在想什么"的窗口；
- 这是 §119 协议层隔离最有价值但当前未利用的信号：
  `HeartThought` 只对 spectator 可见，**从未有过"对所有存活玩家公开推送幽灵语音"的
  渠道**。

### 1.2 设计 — 幽灵语音三要素
死亡瞬间一次性推送一条 **结构化 Activity 事件**：
1. **触发**：在 `EmitPlayerDied` 末尾追加 `EmitGhostVoiceLocked(r, seat)`；
2. **LLM 路径**：若死者是 Bot，从其 `Agent.HeartThought` 截取 ≤80 字 + 服务端做
   4 项 redact（去除 `internal_thought` / 工具名 / `speak_with_thought` / `id` /
   `name` / `tool_use_id` 类泄漏 — §135）；
3. **人类路径**：若死者是人类玩家，**不**自动生成幽灵语音（保留死亡时的内心独白
   沉默感），仅推送 `👻 N号 进入幽灵模式` 的提示事件；
4. **可见性**：`ActivityEventKindGhostVoice`（新增常量）走既有活动流广播，**不进
   chat_message 表 / chat_history 队列**（§119），前端 `GameChatPanel` 自动可见；
5. **限制**：每人只有 1 次（死亡瞬间一次性，不可重复触发）；不可包含身份信息
   （§135 `RolePubliclyRevealed` 仍走原单点判定，幽灵语音内容**不能**绕过）。

### 1.3 服务端改动 — `ghost_voice.go` 新文件
**新增文件**：`ServerGo/game/werewolf/ghost_voice.go`（≤180 行）

```go
// §20260811-07 U1 — 死后幽灵语音。
// 在 EmitPlayerDied 末尾追加调用(持锁态,§92a)。
//
// 关键约束(由 §119/§135/§123 联合约束):
//   - 活动事件走 chatQueue.IsActivity=true 路径,不进 chat_message 表;
//   - 文本 redact 任何可能泄漏身份/工具调用细节的子串;
//   - 人类死亡不自动生成幽灵语音(无 HeartThought 来源);
//   - Bot 的幽灵语音 1 人仅 1 次(死亡瞬间)。
func (m *WerewolfManager) EmitGhostVoiceLocked(r *WerewolfRoom, seat int) {
    if r == nil || r.State == nil || seat < 0 || seat >= MaxPlayers {
        return
    }
    // 已经推过(理论上不可能,EmitPlayerDied 仅在 Alive 切换时触发,但兜底)
    if r.ghostVoiceEmitted[seat] {
        return
    }
    if r.ghostVoiceEmitted == nil {
        r.ghostVoiceEmitted = make(map[int]bool, MaxPlayers)
    }
    r.ghostVoiceEmitted[seat] = true

    // 取 Bot 死者的 HeartThought;人类死者留空,仅推送 "进入幽灵模式"。
    raw := ""
    if seat >= 0 && seat < len(r.botContexts) && r.botContexts[seat] != nil {
        raw = r.botContexts[seat].HeartThought
    }
    text := redactGhostVoice(raw, seat, r) // §135 + §119
    // 推送活动事件(走既有活动流,前端 GameChatPanel 自动可见)
    icon := "👻"
    label := "幽灵语音"
    if raw == "" {
        text = strconv.Itoa(seat+1) + "号 进入幽灵模式"
        label = "幽灵模式"
    }
    fullText := icon + " " + strconv.Itoa(seat+1) + "号 " + label + ": " + text
    m.emitActivity(r, ActivityEventKindGhostVoice, fullText,
        r.State.Phase.String(), r.State.DayNumber,
        "info", icon, seat, -1, false)
}

// redactGhostVoice 把可能泄漏身份/工具调用细节的子串移除。
// §119 + §135:身份公开判定走 RolePubliclyRevealed 单点;此处仅做防御性 redact。
func redactGhostVoice(raw string, seat int, r *WerewolfRoom) string {
    if raw == "" {
        return ""
    }
    // 截断 80 字
    if utf8.RuneCountInString(raw) > 80 {
        runes := []rune(raw)
        raw = string(runes[:80]) + "…"
    }
    // 移除工具名/internal 关键词
    banned := []string{"internal_thought", "speak_with_thought", "heart_thought",
        "tool_use", "tool_result", "id=", "name="}
    for _, b := range banned {
        raw = strings.ReplaceAll(raw, b, "·")
    }
    // §135:若座位身份未公开,移除任何"我是 X"句式 — 改为 [身份隐去]
    if !r.RolePubliclyRevealed(seat) {
        re := regexp.MustCompile(`我是[\s\S]{0,6}(?:预言家|女巫|猎人|守卫|白痴|村民|狼王|普通狼)`)
        raw = re.ReplaceAllString(raw, "[身份隐去]")
    }
    return strings.TrimSpace(raw)
}
```

## U2 — 自动高光集锦战报生成 `BattleReport`（§8.4 / DouBao §四.4 + Mimo §4.2）

### 2.1 问题
当前法官整局总结只有 5 段固定格式（§125）：
- 【阵营胜负】【关键翻盘点】【角色操作时间线】【MVP 玩家】【狼人悍跳记录】

**缺**：
- 没有"戏剧化高光时刻"的精炼抓取（精准查杀 / 极限跳身份 / 猎人一枪定乾坤 / 狼人完美
  悍跳 / 票数差 ≤1 的投票轮 / 女巫救人 / 守卫守对 / 狼人自爆）；
- 没有"LLM 长上下文文学创作能力"的展示机会；
- SettlementModal 仅展示法官总结的纯文本 + 几个 sub-tab,没有"高光卡片"概念。

### 2.2 设计 — 高光集锦 3 类事件 + SettlementModal 高光卡片
#### 数据采集（passive）
- **新增事件**：`ActivityEventKindBattleReportTrigger`（仅服务端内部触发，无前端广播）；
- **触发点**（在 `engine.go` 关键节点末尾追加）：
  | 触发点 | 触发条件 | 高光模板 |
  |---|---|---|
  | `endWitchPhase` 末尾 | 守卫守对（同守同救反向）/ 女巫救人成功 | `guardian_shield` / `witch_save` |
  | `TallyVotes` 末尾 | 票数差 ≤1 触发"险胜票" | `close_vote` |
  | `HunterShoot` 末尾 | 猎人带走狼 | `hunter_kill_wolf` |
  | `WolfSuicide` 末尾 | 狼自爆 | `wolf_suicide` |
  | `EndWitchPhase` 末尾 | 毒杀命中狼 | `witch_poison_wolf` |

#### 生成（async, post-game）
- **触发时机**：与 `PersistSummary` 同源（§125 链路），由 `judge_summary_bridge.go`
  的 `PersistSummaryLocked` 末尾追加 `triggerBattleReportAsyncLocked(r, sections)`；
- **路径**：复用 `AgentJudge` 同 modelKey 调一次 LLM（§125 总结管线），输入追加
  `HighlightsJSON` 字段（含触发的高光模板 + 关联聊天片段 ≤200 字 + 关联 BotTranscript
  `LastDecisionSummary` + 关联活动事件）；
- **输出**：`SummarySections.Highlights []HighlightMoment`（最多 5 条），格式：
  ```go
  type HighlightMoment struct {
      Kind       string `json:"kind"`        // guardian_shield/witch_save/close_vote/...
      Seat       int    `json:"seat"`        // 主角座位
      Round      int    `json:"round"`       // 第几轮
      Quote      string `json:"quote"`       // ≤100 字 LLM 文学化描述
      SourceData string `json:"source_data"` // ≤200 字原始素材(供前端 hover 显示)
  }
  ```
- **失败兜底**：`FallbackHighlight` 把 `HighlightsJSON` 原样输出，不阻塞游戏流（§118）；
- **持久化**：与法官总结同路径 — `chatQueue.Append(IsActivity=true)` + `r.highlights`
  内存字段 + `View.Highlights []HighlightMoment` 透传前端。

#### 渲染（SettlementModal 高光卡片）
- **新增组件**：`ClientWeb/src/components/werewolf/BattleReportHighlights.tsx`
  （≤150 行）；
- **数据来源**：`gs.battle_report_highlights[]`（`ClientGameState` 新增字段）；
- **UI**：3 张大卡片（顶部）+ 滚动展开剩余 2 张（折叠），每张卡片显示 icon / 标题 /
  LLM 文学化 quote / 「📋 原始素材」折叠面板。

### 2.3 服务端改动 — `battle_report.go` + 集成
**新增文件**：`ServerGo/game/werewolf/battle_report.go`（≤350 行）

```go
// §20260811-07 U2 — 自动高光集锦战报生成。
// 复用法官 §125 总结管线 + Activity 流触发器 + SettlementModal 渲染。
//
// 数据流:
//   engine 关键节点 → appendBattleReportTriggerLocked(r, kind, payload)
//   PersistSummary 末尾 → triggerBattleReportAsyncLocked(r, sections)
//   goroutine → JudgeLLM.Call → HighlightsJSON 解析
//   FallbackHighlight 兜底 → chatQueue.Append + r.highlights + View.Highlights

const (
    HighlightGuardianShield  = "guardian_shield"  // 守卫守对
    HighlightWitchSave       = "witch_save"       // 女巫救人
    HighlightWitchPoisonWolf = "witch_poison_wolf" // 毒杀命中狼
    HighlightCloseVote       = "close_vote"       // 险胜票
    HighlightHunterKillWolf  = "hunter_kill_wolf" // 猎人带走狼
    HighlightWolfSuicide     = "wolf_suicide"     // 狼自爆
)

// appendBattleReportTriggerLocked 由 engine 关键节点末尾调用。
// 不广播 Activity,仅写入 r.battleReportTriggers(§92a 持锁)。
func (r *WerewolfRoom) appendBattleReportTriggerLocked(kind string, seat, round int, sourceData string) {
    if r.battleReportTriggers == nil {
        r.battleReportTriggers = make([]BattleReportTrigger, 0, 16)
    }
    // FIFO 上限 16,防失控。
    if len(r.battleReportTriggers) >= 16 {
        r.battleReportTriggers = r.battleReportTriggers[1:]
    }
    r.battleReportTriggers = append(r.battleReportTriggers, BattleReportTrigger{
        Kind: kind, Seat: seat, Round: round, SourceData: sourceData,
        RecordedAt: time.Now().UnixMilli(),
    })
}

// triggerBattleReportAsyncLocked 在 PersistSummary 末尾异步触发 LLM 生成。
// §118 异步:不阻塞游戏流/冷却期;§197 长预算。
func (r *WerewolfRoom) triggerBattleReportAsyncLocked(modelKey string, sections wwjudge.SummarySections) {
    go func() {
        ctx := buildLongBudgetCtx(r)  // §197 parentCtx + extendedTimeout
        highlights := generateHighlightsLLM(ctx, modelKey, sections, r.battleReportTriggersSnapshot())
        if len(highlights) == 0 {
            highlights = fallbackHighlights(r.battleReportTriggersSnapshot())
        }
        // 写回内存 + chatQueue(§119 协议层隔离,IsActivity=true)
        r.appendHighlightsLocked(modelKey, highlights)
    }()
}
```
