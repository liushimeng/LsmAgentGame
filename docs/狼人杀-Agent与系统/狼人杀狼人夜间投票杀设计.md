## 一、背景与动机

### 1.1 现状（缺陷）

当前 `night_wolves` 阶段的狼刀实现是 **"谁先行动谁决定"** 的伪协商:

| 现状 | 代码位置 | 问题 |
|------|---------|------|
| 仅一个 `TurnActingSeat = firstLivingWolf` | `engine.go:514` | 只有第一只狼被 wake,其余狼永远没机会行动 |
| `NightWolfKill` 提交后**立即推进**到 `night_seer` | `engine.go:656` | 无协商窗口 |
| `WolfKillTarget` 单值覆盖 | `engine.go:652` | 无投票计数、无弃权、无平票处理 |
| `BuildWolfPeerView` 未接入广播 | `view.go:656`(仅测试引用) | 前端看不到队友、看不到投票进度 |
| `wolf_kill` 工具描述是"选择目标" | `tools.go:208` | Agent 不知道投票语义 |

**结论**: 13 人局 4 狼,夜间刀人没有任何投票/协商机制,与"4 狼协商刀人"的产品描述严重不符。

### 1.2 设计目标

1. **多狼投票**: 所有存活狼人在 `night_wolves` 阶段均有 `MyTurn=true`,各自提交 `wolf_kill{target}` 作为投票。
2. **超时 = 弃权**: 阶段截止(watchdog deadline)时未投票的狼人视为弃权(`target=-1`)。
3. **全弃权 → 随机**: 所有狼人均弃权(含超时) → 从合法目标(存活非狼人)中随机选择。
4. **平票 → 随机**: 最高票并列 → 从并列目标中随机选择。
5. **UI 明确指示**: 狼人玩家看到"X/Y 已投票"进度、每个队友投了谁(或弃权)、最终结果。
6. **Agent 知情**: `wolf_kill` 工具描述改为投票语义,`GameContext` 携带投票快照,prompt 注入投票流程说明。

## 二、核心机制设计

### 2.1 投票流程时序

```
startNight()
  ├─ WolfVotes[all] = NoSeat (重置)
  ├─ PhaseNightWolves + deadline(60s)
  └─ TurnActingSeat = firstLivingWolf (watchdog 兜底用)
       │
       ▼
  所有存活狼人 MyTurn=true → 同时被 wake
       │
       ▼ (每个狼人独立提交 wolf_kill)
  NightWolfKill(actor, target):
       ├─ 校验 actor 是存活狼人
       ├─ WolfVotes[actor] = target (记录投票, target=-1 = 弃权)
       ├─ 若全部存活狼人已投票 → tallyWolfVotes() → 进入 night_seer
       └─ 否则 → wake 剩余未投票狼人
       │
       ▼ (deadline 到期, 仍有狼未投票)
  phaseWatchdogTick → PhaseNightWolves → tallyWolfVotes()
       │              (未投票者视为弃权)
       ▼
  tallyWolfVotes():
       ├─ 统计每个 target 得票数(不含 -1)
       ├─ 全弃权 → randomTarget()
       ├─ 最高票唯一 → 该目标
       ├─ 最高票并列 → randomAmong(tied)
       └─ 设 WolfKillTarget → endWolfPhase() → night_seer
```

### 2.2 计票规则 `tallyWolfVotes()`

```
输入: WolfVotes[MaxPlayers]Seat (仅狼人座位有效)
输出: Seat (最终击杀目标)

1. 遍历所有存活狼人,统计:
   - votes[target]++  (target >= 0)
   - abstainCount++    (target == NoSeat)
2. 若 votes 为空(全弃权):
   - WolfKillTarget = randomAliveNonWolf()
   - 标记 reason = "random_all_abstain"
3. 否则:
   - maxVotes = max(votes)
   - tied = 所有得票 == maxVotes 的 target
   - 若 tied 长度 == 1: WolfKillTarget = tied[0]
   - 否则: WolfKillTarget = tied[random()]; reason = "random_tie_break"
4. 记录 WolfVoteTally = {counts, tied, reason} 供 UI 展示
```

### 2.3 随机选择约束

- **随机源**: 使用房间级 `r.Rand`(`math/rand/v2`),在 `WerewolfRoom` 创建时以 `time.Now().UnixNano()` 种子初始化(已有 `r.Rand` 字段则复用)。
- **合法目标池**: `aliveSeats` 中排除 `RoleWerewolf` 的座位。
- **全弃权随机**: 从合法目标池均匀随机选 1 个。
- **平票随机**: 从 `tied` 列表均匀随机选 1 个。
- **不做的事**: 不引入加权随机、不偏向神职/平民、不记忆历史刀型。

### 2.4 阶段时钟

| 计时器 | 默认值 | 说明 |
|--------|--------|------|
| `night_wolves` deadline | **60s** | 投票窗口(从 240s 缩短,投票不需要那么久) |
| Phase Watchdog 警告 | 60s | 不变 |
| Phase Watchdog 强制跳过 | 90s | 不变(但 deadline 优先) |

> 配置项 `werewolf.phase_deadline_sec.night_wolves` 默认 60。

### 4.2 `NightWolfKill()` 改造

```go
// NightWolfKill 狼人投票选择当晚击杀目标。
// 2026-07-17 改造: 从"单狼决定"改为"多狼投票"。
// target=NoSeat 表示弃权。全部存活狼人投票完毕后自动计票。
func (gs *GameState) NightWolfKill(actor Seat, target Seat) *errcode.Error {
    if gs.Phase != PhaseNightWolves {
        return errcode.CodeMsg(errcode.ErrNotYourTurn, "not night_wolves phase")
    }
    if !gs.AliveSeat(actor) || gs.Roles[actor] != RoleWerewolf {
        return errcode.Code(errcode.ErrPermissionDenied)
    }
    // 校验 target: NoSeat(弃权) 或 合法目标(存活非狼人)
    if target != NoSeat {
        if target < 0 || target >= MaxPlayers {
            return errcode.Code(errcode.ErrValidationFailed)
        }
        if !gs.AliveSeat(target) {
            return errcode.CodeMsg(errcode.ErrValidationFailed, "target dead")
        }
        if gs.Roles[target] == RoleWerewolf {
            return errcode.CodeMsg(errcode.ErrValidationFailed, "wolves cannot kill each other")
        }
    }
    // 记录投票(重复投票覆盖)
    if gs.WolfVotes[actor] == NoSeat {
        gs.WolfVotesCast++
    }
    gs.WolfVotes[actor] = target

    // 全部存活狼人已投票 → 立即计票
    if gs.allWolvesVoted() {
        gs.tallyWolfVotes()
        gs.endWolfPhase()
    }
    return nil
}

// allWolvesVoted 返回是否所有存活狼人均已投票(含弃权)。
func (gs *GameState) allWolvesVoted() bool {
    cast := 0
    total := 0
    for i := 0; i < MaxPlayers; i++ {
        if gs.AliveSeat(Seat(i)) && gs.Roles[i] == RoleWerewolf {
            total++
            if gs.WolfVotes[i] != NoSeat || gs.wolfAbstained(Seat(i)) {
                cast++
            }
        }
    }
    return total > 0 && cast >= total
}

// wolfAbstained 返回该狼人是否已明确弃权(提交过 target=-1)。
func (gs *GameState) wolfAbstained(s Seat) bool {
    return gs.WolfVotes[s] == NoSeat && gs.voteExplicitlyCast(s)
}
```

> **注意**: 弃权判定需要区分"未投票"和"已投弃权"。引入 `WolfVoteCast [MaxPlayers]bool` 标记是否已提交过投票(含弃权)。

### 4.4 `tallyWolfVotes()` 实现

```go
// tallyWolfVotes 统计狼人投票,决定最终击杀目标。
// 调用方需持有 r.mu。前置条件: Phase == PhaseNightWolves。
func (gs *GameState) tallyWolfVotes() {
    counts := map[int]int{}
    abstain := 0
    for i := 0; i < MaxPlayers; i++ {
        if !gs.AliveSeat(Seat(i)) || gs.Roles[i] != RoleWerewolf {
            continue
        }
        target := gs.WolfVotes[i]
        if target == NoSeat {
            abstain++
            continue
        }
        counts[int(target)]++
    }

    tally := &WolfVoteTally{Counts: counts}

    if len(counts) == 0 {
        // 全弃权 → 随机
        tally.Tied = nil
        tally.Reason = "random_all_abstain"
        tally.Final = gs.randomAliveNonWolf()
    } else {
        // 找最高票
        maxV := 0
        for _, v := range counts {
            if v > maxV {
                maxV = v
            }
        }
        tied := []int{}
        for t, v := range counts {
            if v == maxV {
                tied = append(tied, t)
            }
        }
        tally.Tied = tied
        if len(tied) == 1 {
            tally.Reason = "majority"
            tally.Final = tied[0]
        } else {
            tally.Reason = "random_tie_break"
            tally.Final = tied[gs.randInt(len(tied))]
        }
    }

    gs.WolfKillTarget = Seat(tally.Final)
    gs.WolfVoteTally = tally
}

// randomAliveNonWolf 从存活非狼人玩家中随机选一个。
func (gs *GameState) randomAliveNonWolf() int {
    candidates := []int{}
    for i := 0; i < MaxPlayers; i++ {
        if gs.AliveSeat(Seat(i)) && gs.Roles[i] != RoleWerewolf {
            candidates = append(candidates, i)
        }
    }
    if len(candidates) == 0 {
        return int(NoSeat)
    }
    return candidates[gs.randInt(len(candidates))]
}

// randInt 返回 [0,n) 的随机整数。调用方保证 n > 0。
// 注: 房间级随机源在 WerewolfRoom 上,GameState 不持有随机状态;
// 这里提供包级 helper,实际随机由 manager 层注入或包级 rand。
func (gs *GameState) randInt(n int) int {
    return rand.Intn(n)
}
```

> **随机源决策**: `GameState` 是纯状态结构,不应持有 `math/rand` 状态。使用包级 `rand.Intn`(全局源,锁保护)即可——投票随机不需要密码学安全,全局源足够。

### 4.5 `endWolfPhase()` 新增

```go
// endWolfPhase 关闭狼人投票阶段,进入预言家阶段。
// 替代原 NightWolfKill 末尾直接 setPhaseAndDeadline 的逻辑。
func (gs *GameState) endWolfPhase() {
    setPhaseAndDeadline(gs, PhaseNightSeer)
    gs.TurnActingSeat = firstLivingSeer(gs)
    if gs.TurnActingSeat == NoSeat {
        gs.endSeerPhase()
    }
}
```

> 原 `NightWolfKill` 末尾的 `setPhaseAndDeadline` + `endSeerPhase` 逻辑抽取为 `endWolfPhase()`,供 `tallyWolfVotes` 后统一调用。

## 五、Manager 层实现 (`room.go`)

### 5.1 `Action_WolfKill` 改造

```go
func (m *WerewolfManager) Action_WolfKill(roomID, userID string, target Seat) (*WerewolfRoom, *errcode.Error) {
    r := m.getRoom(roomID)
    if r == nil {
        return nil, errcode.Code(errcode.ErrRoomNotFound)
    }
    r.mu.Lock()
    defer r.mu.Unlock()
    if r.State == nil || r.State.Phase != PhaseNightWolves {
        return nil, errcode.Code(errcode.ErrGameNotStarted)
    }
    seat, ok := r.SeatOf(userID)
    if !ok {
        return nil, errcode.Code(errcode.ErrRoomNotIn)
    }
    if r.State.Roles[seat] != RoleWerewolf {
        return nil, errcode.Code(errcode.ErrPermissionDenied)
    }
    if e := r.State.NightWolfKill(seat, target); e != nil {
        return nil, e
    }
    // 投票后不再立即 EmitWolfKill(结果未决),改为广播投票快照
    m.broadcastWolfVoteStateLocked(r)
    // 若已计票(WolfKillTarget != NoSeat 且 Phase 已推进),广播最终结果
    if r.State.Phase != PhaseNightWolves {
        m.EmitWolfKill(r, int(r.State.WolfKillTarget))
    }
    m.wakeActingAgentsLocked(r, "wolf_vote")
    return r, nil
}
```

### 5.2 `broadcastWolfVoteStateLocked` 新增

```go
// broadcastWolfVoteStateLocked 向所有存活狼人推送 WolfPeerView(投票快照)。
// 调用方持有 r.mu。
func (m *WerewolfManager) broadcastWolfVoteStateLocked(r *WerewolfRoom) {
    if r.State == nil || r.State.Phase != PhaseNightWolves {
        return
    }
    view := BuildWolfPeerView(r.State)
    if view == nil {
        return
    }
    for i := 0; i < MaxPlayers; i++ {
        if !r.State.AliveSeat(Seat(i)) || r.State.Roles[i] != RoleWerewolf {
            continue
        }
        userID := r.Seats[i]
        if userID == "" {
            continue
        }
        m.hub.BroadcastTo(userID, Envelope{
            Type:    "game.wolf_vote_view",
            Payload: mustMarshal(view),
        })
    }
}
```

> **广播方式**: 新增 `game.wolf_vote_view` 帧,仅狼人玩家收到。该帧是 `WolfPeerView` 的 JSON。前端 `useWerewolf` hook 处理该帧并更新 store。

## 六、视图层实现 (`view.go`)

### 6.1 `BuildWolfPeerView` 改造

```go
// BuildWolfPeerView 返回狼人夜间投票视图。
// 2026-07-17 扩展: 携带投票快照 + 计票结果。
func BuildWolfPeerView(gs *GameState) *WolfPeerView {
    if gs == nil || gs.Phase != PhaseNightWolves {
        return nil
    }
    out := &WolfPeerView{
        KillTarget: -1,
        Votes:      map[int]int{},
        Abstain:    []int{},
    }
    for i, r := range gs.Roles {
        if r == RoleWerewolf && gs.AliveSeat(Seat(i)) {
            out.WolfSeats = append(out.WolfSeats, i)
            out.TotalWolves++
            if gs.WolfVoteCast[i] {
                if gs.WolfVotes[i] == NoSeat {
                    out.Abstain = append(out.Abstain, i)
                } else {
                    out.Votes[i] = int(gs.WolfVotes[i])
                }
            }
        }
    }
    out.VotesCast = out.TotalWolves - len(out.Abstain)
    // 未投票(且未弃权)的狼人不计入 VotesCast
    for i := range gs.WolfVoteCast {
        if gs.Roles[i] == RoleWerewolf && gs.AliveSeat(Seat(i)) && !gs.WolfVoteCast[i] {
            out.VotesCast-- // 修正: 上面多算了
        }
    }
    // 实际: VotesCast = 已提交投票(含弃权)的狼人数
    out.VotesCast = 0
    for i := range gs.WolfVoteCast {
        if gs.Roles[i] == RoleWerewolf && gs.AliveSeat(Seat(i)) && gs.WolfVoteCast[i] {
            out.VotesCast++
        }
    }

    if gs.WolfKillTarget != NoSeat {
        out.KillTarget = int(gs.WolfKillTarget)
        out.Voting = false
        out.Tally = gs.WolfVoteTally
    } else {
        out.Voting = true
    }
    return out
}
```
