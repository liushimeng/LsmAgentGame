# 狼人杀 13 人标准竞技局 · 观战者互动产品设计

> 实施日期:2026-07-08
> 关联规则:[`docs/狼人杀13人标准局规则.md`](狼人杀13人标准局规则.md) §13
> 关联技术:[`docs/狼人杀观众唤醒设计.md`](狼人杀观众唤醒设计.md)

本文档面向**产品 / UX / 前端**视角,描述 13 人标准竞技局人类观众在房间里发言、与 13 个 AI Agent(混合房间)互动的完整 UX 流程。

---

## 1. 用户故事

### 1.1 主线故事(观众视角)

> **作为**一名注册用户 **,我希望**进入一个全 AI 狼人杀 7 人局做观众 **,以便**观察 AI 之间的博弈,**并且**在合适时机插话/吐槽/提建议,**让** 7 个 Agent 能感知到我的存在并选择性回应。

### 1.2 副线故事(Agent 视角)

> **作为**一个 7 人局 AI Agent **,我必须**在人类观众发言后"思考",**可以选择**公开插话(interject)/ 私聊回应(whisper)/ 留审计记录(idle_think)/ **不允许**完全忽略。

### 1.3 验收标准

| 编号 | 验收点 |
|---|---|
| AC-1 | 观众成功 spectate 加入房间,前端不报错 |
| AC-2 | 观众在 `<GameChatPanel>` 输入框可见、可打字、可发送 |
| AC-3 | 观众发言后,`GameChatPanel` 立即出现该条消息,带 `👁 观战` 徽章 + `HH:mm` 时间 |
| AC-4 | ≤15s 内,`AgentThoughtPanel` 对应 bot 出现新"思考"或发言 |
| AC-5 | Agent 选择回话时,玩家 UI 看到 `💬 插话` 标签 + `HH:mm` 时间 |
| AC-6 | Agent 选择沉默时,`AgentThoughtPanel.RecentMessages` 出现 `[idle]` 行 |
| AC-7 | 夜晚阶段观众发言不触发 wake(可由日志观察) |
| AC-8 | 30 秒静默后,LLM prompt 末尾出现 `⚠️` 提示(可由 BotTranscript 间接观察) |

## 2. UX 流程图

### 2.1 观众加入房间

```
[首页 / 大厅]
   │  click "全 AI 房间 · 7 人局"
   ▼
[房间列表 / 7-AI 房间]
   │  click "观战"
   ▼
[POST /api/rooms/:id/spectate]
   │  服务端插入 t_lsm_game_player (role='spectator')
   │  Hub.SpectateRoom()
   ▼
[WS game.spectate 帧]
   │  room.subscribe, chat.subscribe (scope=room)
   ▼
[前端 /werewolf/spectate/:roomId]
   │  useSpectatorMode() === true
   │  GameChatPanel placeholder: "👁 观战中…"
   │  AgentThoughtPanel 实时刷新 bot 思考
   ▼
[渲染就绪]
```

### 2.2 观众发言

```
[观众在 GameChatPanel 输入框打字]
   │  text ≤ 1024 字符
   │  click "发送" or 按 Enter
   ▼
[WS chat.send { scope: "room", room_id, text }]
   │  ChatService.Send() — 不做角色拦截
   │  持久化 t_lsm_game_chat_message
   │  BroadcastRoomIncludingSpectators
   │  ↓
   │  → players (game.state)
   │  → spectators (game.state)
   │  → onRoomMessage hook → WerewolfManager.RecordRoomMessage
   │     → appendRoomMessage (isSpectator=true)
   │     → 15s 节流检测 (SpectatorWakeLimiter.Allow())
   │     → maybeSpectatorWake(r) 触发
   │        → 对所有存活 bot 推 AgentEvent{Kind:"spectator_speech"}
   ▼
[前端立即收到 chat.message]
   │  GameChatPanel 追加一行:👁 观战-昵称 · HH:mm · 消息内容
   ▼
[≤15s 后 Agent 决策]
   │  7 bot 中存活者依次被 wake
   │  每个 bot 调 LLM(BuildTools 暴露 interject / whisper / idle_think)
   │  LLM 决策 → 调用工具 或 选 idle_think
   ▼
[前端 AgentThoughtPanel 实时刷新]
   │  RecentMessages 追加新行
   │  LastTool / LastThinking 更新
```

### 2.3 Agent 反应(玩家 UI 视角)

```
[玩家 GameChatPanel 持续监听 chat.message]
   │  若 from_role==="bot" && is_interject===true:
   │     → 渲染 "💬 插话" 标签
   │  若 from_role==="bot" && is_interject===false:
   │     → 渲染 "🗨️ 发言"
   │  若 from_role==="player":
   │     → 渲染 "👤 玩家"
   ▼
[玩家看到 Agent 回应]
```

### 2.4 强制思考的"沉默"路径

```
[Agent 被 wake(收到 spectator_speech 事件)]
   │  调 LLM
   ▼
[LLM 决策]
   │  case A: 调 interject(回话)
   │  case B: 调 whisper(私聊)
   │  case C: 调 idle_think(reason)(沉默+留审计)
   │  case D: end_turn(未调任何工具)
   ▼
[run.go 检测 evt.Kind=="spectator_speech" && case D]
   │  自动构造 [idle_thinking] 摘要行
   │  追加到 BotTranscript.RecentMessages
   │  "zero token cost" 审计完成
   ▼
[前端 AgentThoughtPanel 刷新]
   │  显示 "[14:23:05] 观众 张三 发言,我已思考但保持沉默"
```

## 3. Agent 反应策略表(按阶段)

下表详述 7 个 bot 在不同阶段 + 不同观众意图下应采取的策略。**这是给 LLM 的行为指引**(`BuildSystemPrompt` 注入)。

| 阶段 | 观众意图示例 | bot 推荐策略 | 工具 |
|---|---|---|---|
| `pre_wolves` | "5号 看起来像预言家" | 公开试探:发短问句"5号,你说呢?" | `interject` |
| `pre_wolves` | "我赌 1号 是狼" | 公开感谢/追问"为什么?" | `interject` |
| `night_wolves` | (任意) | **沉默**(夜间信息保密) | (不调 LLM,wake 被黑名单) |
| `night_seer` | (任意) | **沉默** | (同上) |
| `night_witch` | (任意) | **沉默** | (同上) |
| `dawn` | (任意) | **沉默**(死亡未公开) | (同上) |
| `sheriff` | "我支持 3号 当警长" | 公开回应"收到" | `interject` |
| `speak`(非发言者) | "1号 你有什么证据?" | 公开回应"我的分析是..." | `interject` |
| `speak`(当前发言者) | 任意 | 主发言 + 可顺便回应观众 | `speak`(主) |
| `vote` | "1号 是狼,投 1号" | 公开表态 | `interject` |
| `hunter_shoot` | (任意) | **沉默** | (wake 被黑名单) |
| `gameover` | 任意 | **沉默** | (游戏已结束) |

> **沉默不等于不思考** — 即便 wake 被阶段黑名单拒绝,bot 仍会在**下一次 phase wake** 时通过 `BuildUserPrompt` 看到该消息并决策(延迟 60-180s)。

## 4. 时间戳格式约定

### 4.1 前端显示(不变)

| 角色 | 格式 | 示例 |
|---|---|---|
| 玩家发言 | `HH:mm` | `14:23` |
| 观战者发言 | `HH:mm` + `👁 观战` | `👁 观战 · 14:23` |
| bot 发言 | `HH:mm` + `🗨️` | `🗨️ · 14:23` |
| bot 插话 | `HH:mm` + `💬 插话` | `💬 插话 · 14:23` |

### 4.2 后端 prompt(2026-07-08 新增)

**给 LLM 看的** RecentSpeeches / WhisperInbox 渲染时统一加 `HH:MM:SS` 前缀:

```
最近发言:
- [14:23:05] 观战-张三: 5号 是不是预言家
- [14:23:18] 1号(张三): 我觉得 2号 像狼
- [14:23:30] 2号(美团 LongCat-2.0 · bot-2): 同意楼上
- [14:23:45] 💬 插话-3号(豆包 2.0 · bot-3): 等等,1号 还没表态

发给你的私聊:
- [14:23:50] 观战-张三 → 你: 1号 是不是预言家
- [14:24:01] 2号(美团 LongCat-2.0 · bot-2) → 你: 我们是队友
```

### 4.3 BotTranscript 审计行(2026-07-08 新增)

LLM 调 `idle_think` 或在 spectator_speech 后 `end_turn` 时,`RecentMessages` 追加:

```
[14:23:05] 观众 张三 发言,我已思考但保持沉默
[14:23:18] 观众 张三 发言,我选择插话(理由: 他说得对,我附和)
[14:23:30] 观众 张三 私聊我,我选择 whisper 回复
```

## 5. 前端 AgentThoughtPanel 增强

### 5.1 顶部 summary 行(2026-07-08 新增)

在 `<AgentThoughtPanel>` 顶部加 3 个统计指标(per-room 总和):

```
👁 观众消息 12 条  |  ✅ 已思考 7 次  |  💤 已 idle 3 次
```

数据源:`bot_contexts[].recent_messages` 解析:
- `[HH:MM:SS] 观战-...` 出现次数 → 观众消息计数
- `LastThinking` 字段非空次数 → 已思考次数
- `[idle]` / `[idle_thinking]` 出现次数 → idle 次数

### 5.2 单 bot 卡片(不变)

保留现有 4 个 section(最近思考 / 最近工具 / 消息摘要 / 工具调用),但消息摘要区增加:
- 观众消息高亮(`👁` 前缀行加背景色 `#fff7e6` 浅黄)
- 私聊消息前置 `[私聊]` 标签

## 6. 错误与边界 UX

### 6.1 观众发言失败场景

| 场景 | 错误码 | UX 处理 |
|---|---|---|
| 房间不存在 | `ErrRoomNotFound` | `<GameChatPanel>` 顶部红条 "房间不存在" |
| 房间已结束 | `ErrRoomFinished` | "对局已结束,发言无法送出" |
| 文本超 1024 字符 | `ErrChatTextTooLong` | 输入框下方红字 "消息过长(>1024 字符)" |
| 文本为空 | `ErrChatEmpty` | 静默忽略(前端已 `trim`) |
| WS 断线 | `chat.error` | "连接中断,正在重连..." + 输入框 disable |

### 6.2 观众→ 私聊失败场景

| 场景 | 错误码 | UX 处理 |
|---|---|---|
| 收件人不存在 | `ErrUserNotFound` | "对方已离开" |
| 收件人是观战者 | (允许) | 正常发送,仅发送者自己看见自己的私聊记录 |

## 7. 性能与体验指标

| 指标 | 目标 | 实测方法 |
|---|---|---|
| 观众发言 → 首个 bot wake | ≤ 15s | 日志: `spectator_wake` → 首个 `push_event` 时间差 |
| 观众发言 → Agent 决策完成 | ≤ 30s | 日志: 首个 bot 调 LLM 完成时间 |
| 30 分钟内 token 增量 | < 5x baseline | 计数 `LLMCallLimiter.Allow()` 通过数 |
| 前端聊天面板更新延迟 | < 500ms | WS 帧收到 → React render 时间 |
| 玩家 UI 不卡顿 | 60fps | 100 条 chat 滚动时,DevTools Performance 录制 |

## 9. 测试用例(产品验收)

### TC-1 观众加入全 AI 房间

**前置**:test_01 创建全 AI 房间,7 个 bot。
**步骤**:
1. test_03 访问 `/werewolf/spectate/<roomID>`
2. 等待 2s,确认 `<GameChatPanel>` 输入框可见
3. 在输入框输入 "测试发言",点击发送
4. 观察 `<GameChatPanel>` 出现新行:`👁 观战-... · 14:23 · 测试发言`
5. 观察 `<AgentThoughtPanel>` 7 bot 中至少 1 个有 `[idle]` 或发言记录

**预期**:全部通过。

### TC-2 多次发言节流

**步骤**:
1. 同 TC-1 房间
2. test_03 在 30s 内连续发送 5 条消息
3. 检查服务端日志: `spectator_wake` 触发次数 ≤ 2(15s 间隔)

**预期**:通过。

### TC-3 夜晚阶段不触发 wake

**步骤**:
1. 全 AI 房间进入 `night_wolves` 阶段(等待 2min 缓冲期结束)
2. test_03 发送消息 "5号 是不是预言家"
3. 观察服务端日志: 30s 内无 `spectator_wake` 触发
4. 等待到 `speak` 阶段,Agent 醒来时 prompt 中包含该消息(可由 BotTranscript 验证)

**预期**:通过。

### TC-4 Agent "必须思考"机制

**步骤**:
1. 全 AI 房间 `speak` 阶段
2. test_03 发送消息,内容不直接 @ 任何 bot
3. 观察 7 bot 中至少 5 个的 BotTranscript.RecentMessages 有 `[idle]` / `[idle_thinking]` 或 `interject` / `whisper` 调用记录

**预期**:7 个 bot 全部产生某种反应(无完全无响应)。
