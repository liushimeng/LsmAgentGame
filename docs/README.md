## 文档命名约定

- `XXXX设计.md` / `XXXX方案.md` —— 长期有效的设计/方案文档（推荐）
- `XXXX规则.md` / `XXXX协议.md` —— 游戏规则与协议
- `XXXX-YYYYMMDD-NN.md` —— 批次升级 / 方案设计文件（仅用于时间戳编号，强约束下保留）
- 顶级文档（指 `docs/` 根目录）仅保留本 `README.md`，**所有可索引内容应放在子目录**。
