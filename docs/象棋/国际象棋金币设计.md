# 国际象棋（Chess）游戏币策划方案

> 版本：v1.0 | 作者：game-designer | 日期：2026-07-02
> 适用范围：国际象棋（chess），2 人 1v1，平均对局 15–40 分钟，无随机性
> 产品基线：封闭资金池、无充值/提现、纯内部休闲

---

## 1. 概述

### 1.1 产品定位
国际象棋是国际主流棋牌（FIDE 体系），平台海外用户占比高。在国际棋牌社区中，"带注对局（staked games）"是常见社交玩法。本方案为国际象棋引入**封闭资金池**的游戏币系统，定位为：

- **休闲竞技**：用封闭金币体验"带注对局"的刺激感，不涉及真实货币
- **段位成长**：Elo 评级与金币资产挂钩，提供长期目标
- **合规安全**：收入仅来自系统发放（注册/登录/胜场/任务），无玩家间转账、无 RMT

### 1.2 设计原则
| 原则 | 说明 |
|------|------|
| **零和偏负** | 每局赢家所得 ≤ 系统总发放，系统通过对局手续费/少量回收保持通缩 |
| **低门槛** | 新用户注册即能开最低底注房间，避免"无房可玩" |
| **段位分层** | 底注分档类似扑克盲注，高底注隐含高 Elo 门槛，但不硬性限制 |
| **海外友好** | Elo 积分沿用国际象棋传统公式（K 因子 10/20/40），与金币奖励挂钩但非绑死 |

### 1.3 平均节奏参考
- 单局时长：15–40 分钟（快棋 5–10 分钟在此方案外）
- 每日可完成带注局数：约 3–8 局
- 单局金币波动：±(ante × 2)（赢家净得 ante，输家失去 ante）

## 2. 金币获取途径

### 2.1 注册奖励
| 项目 | 数值 |
|------|------|
| 新用户首次注册 | **+1000 coin** |
| 一次性，不复发 | —— |

> 复用现有 `Register` 流程，在 `t_lsm_game_user` 新增 `coin` 字段默认 1000。

### 2.2 每日登录奖励
| 项目 | 规则 |
|------|------|
| 金额 | **+2000 coin/天** |
| 时区 | **UTC+8 自然日**（00:00 重置） |
| 补领 | **不补领**，过期作废 |
| 防重发 | 唯一表 `t_lsm_game_daily_reward(user_id, reward_date)` UK |
| 触发 | 当日首次登录成功时发放 |

> 建议首次登录弹窗提示"今日签到 +2000 金币"，增强获得感。

### 2.3 胜场奖励（Rake-free 方案）
国际象棋**无随机性**，胜负完全取决于实力。采用"底注本金对赌"为主、系统奖励为辅：

| 取得方式 | 公式 | 说明 |
|----------|------|------|
| 赢家本金 | +`ante`（来自对手输局扣减） | 双簿记流水 type=`match_win` |
| 系统胜场奖励 | +`floor(ante × 0.1)` | 系统额外发放，上限 100 coin/局 |
| 输局扣减 | −`ante` | 双簿记流水 type=`match_lose` |
| 和局 | 退还本金 ante，无额外奖励 | 流水 type=`match_draw_refund` |

**举例**（ante=100 房间）：
- 赢家净收益：+100（本金） + 10（系统奖励） = **+110**
- 输家净损失：**−100**

### 2.4 连胜奖励（Streak Bonus）
| 连胜场次 | 额外奖励系数 |
|----------|-------------|
| 2 连胜 | 无额外（保持基础） |
| 3 连胜 | 系统奖励 ×1.5 |
| 5 连胜 | 系统奖励 ×2.0 |
| ≥7 连胜 | 系统奖励 ×2.5（封顶） |
| 中断 | 输/和即清零 |

> 连胜奖励**只加系统奖励部分**，不影响对手本金，避免零和失衡。

### 2.5 邀请好友奖励
利用现有 `referral_count` 与 `referrer_user_id` 字段：

| 触发 | 金额 |
|------|------|
| 被邀请人完成注册 | 邀请人 **+300 coin** |
| 被邀请人累计登录 7 天 | 邀请人 **+500 coin** |
| 被邀请人完成 10 场带注对局 | 邀请人 **+700 coin** |
| 单人累计被邀请奖励上限 | **5000 coin/月** |

> 循环邀请风控：同 IP / 同设备多账号邀请不计奖励（§6）。

### 2.6 任务/成就/活动（中长期）
| 类型 | 示例 | 奖励范围 |
|------|------|---------|
| 日常任务 | "参与 1 场带注对局" | 50 coin |
| 周任务 | "本周胜 5 场" | 300 coin |
| 成就里程碑 | "累计胜 100 场" | 2000 coin（一次性） |
| 节日活动 | "国庆双倍奖励日" | 底注奖励 ×2 |
| 段位晋升 | "Elo 突破 1500" | 1000 coin（一次性） |

> MVP 阶段**不实现任务系统**，但数据模型预留 `task_id` 等字段。

## 3. 金币消耗途径

### 3.1 创建带注房间（Ante）
| 消耗项 | 规则 |
|--------|------|
| 创建 ante 房间时冻结 ante×2（双方底注） | 托管在房间，结算后分配 |
| 房间未开局（仅 1 人）超过 5 分钟 | 解冻返还 |
| 玩家在开局前离开 | 冻结金解冻 |

### 3.2 投降 / 输局扣减
- 投降 = 主动认输（resign），按正常输局结算
- 断线超过 15 秒（现有规则）= 自动判负，扣减 ante
- 超时判负 = 扣减 ante

> 不存在"投降少扣"的情形，保持一致性。

### 3.3 商城（简要提及，不展开）
| 品类 | 价格范围 |
|------|---------|
| 头像框 | 500–3000 coin |
| 棋盘皮肤 | 1000–5000 coin |
| 棋子皮肤 | 1500–8000 coin |
| 特效 | 200–2000 coin |

> MVP 阶段商城**不实现**，仅规划商品 ID 体系。

## 4. 房间带注规则

### 4.1 Ante 档位（创建房间时选择）
| 档位 | 单场赢家净收益 | 建议受众 | 隐含 Elo 建议 |
|------|---------------|----------|---------------|
| **50** | +55（含系统奖励 5） | 新手 / 保守玩家 | ≤1200 |
| **100** | +110 | 日常玩家 | 1200–1600 |
| **500** | +550 | 进阶玩家 | 1600–2000 |
| **1000** | +1100 | 高手 / 冒险型 | ≥2000 |

> MVP 仅开放 50 / 100 两档；500 / 1000 在 Elo ≥ 1600 后解锁（软门槛，非硬性）。

### 4.2 赢家通吃
- 国际象棋采用**赢家通吃（winner-takes-all）**模式
- 赢家获得：自己本金 ante（返还） + 对手 ante + 系统奖励 floor(ante×0.1)
- 输家损失：ante
- 系统净支出：floor(ante×0.1)（通胀源，需控制上限）

### 4.3 和局处理
| 情形 | 处理 |
|------|------|
| 协议和棋（双方同意） | 退还本金 ante，无奖励，流水 type=`match_draw_refund` |
|系统判定和棋（三次重复/50步规则） | 退还本金 ante |
| 和局时不扣手续费 | —— |
| 双方均超过 20 分钟的长和局 | 仍退还本金 |

> 和局无通胀（系统不发奖励），对通缩有益。

### 4.4 破产保护
| 情形 | 兜底 |
|------|------|
| 余额 < 最低底注（50） | 无法创建/加入任何带注房间，提示"余额不足，请通过每日登录补充" |
| 连续 3 局输光 | 触发"救济金"任务：免费获得 500 coin 救济（每自然日限 1 次） |
| 破产用户仍可参与休闲房间（ante=0） | 休闲房间不消耗/不产出金币 |

> 救济金记录流水 type=`relief_bonus`，计入当日收入上限（§6.4）。

## 5. 风控与防作弊

### 5.1 刷分检测
| 检测维度 | 规则 |
|----------|------|
| 同 IP 多账号 | 同日同 IP ≥ 3 账号参与带注对局 → 标记审计 |
| 同设备多账号 | 前端生成 device_id 指纹，同设备 ≥ 2 账号带注对局 → 审计 |
| 固定对手对局 | 同一对用户 24h 内对局 ≥ 5 场 → 冻结双方金币流水待审 |
| 异常赠送 | A 总输给 B 且双方 Elo 差距 >200 → 自动标记 |

### 5.2 异常胜率监控
| 指标 | 阈值 | 动作 |
|------|------|------|
| 单日胜率 >90% 且局数 ≥5 | 触发 | 审计标记 |
| 7 日胜率 >80% 且局数 ≥20 | 触发 | 临时限制 ante ≤100 |
| Elo 短期暴涨（7 日 +300） | 触发 | 强制降 K 因子至 10 |

### 5.3 流水审计要求
- 所有金币变动**必须**双簿记（credit/debit 各一条）
- 流水表包含：`user_id, amount, balance_after, type, ref_id(房间/任务), created_at`
- 每日生成审计报告：总发放 vs 总消耗，偏差 >5% 触发告警
- 审计日志保留 ≥180 天

### 5.4 日收入上限（防溢出）
- 单个用户单日系统发放总额（注册/登录/救济/连胜/邀请）**≤10000 coin**
- 超出部分次日不补发
- 仅**对局赢取对手本金**不计入上限（本金是玩家间零和转移）

## 6. 数值平衡建议

### 6.1 通胀/通缩控制
| 源 | 金额（每日估计/用户） | 方向 |
|----|----------------------|------|
| 每日登录 | +2000 | 通胀 |
| 救济金 | +500（触发时） | 通胀 |
| 对局系统奖励 | 约 +0.1×ante/局 | 通胀 |
| 商城消费 | −1000~−5000（中长期） | 通缩 |
| 和局退还 | 0（纯本金退款） | 中性 |
| 房间未开局解冻 | 0（纯本金退款） | 中性 |

**目标**：日均通胀 ≤ 10%（通过商城、活动任务等回收手段渐进调整）。MVP 阶段商城未上线时，靠**每日发放上限**与**系统奖励上限 100/局**抑制通胀。

### 6.2 盲注分层（段位体系）
| 段位名 | Elo 范围 | 建议底注 | 描述 |
|--------|----------|---------|------|
| Bronze | <1200 | 50 | 入门 |
| Silver | 1200–1599 | 100 | 日常 |
| Gold | 1600–1999 | 500 | 进阶 |
| Master | ≥2000 | 1000 | 高手 |

> Elo 计算沿用标准公式（K=40 for 新用户前 30 局, K=20 for 1200–2000, K=10 for ≥2000）。**Elo 解锁底注是软门槛**（可进入高底注房间，但系统会有提示）。

### 6.3 经济增长预期（单用户 30 天）
| 活跃类型 | 日均局数 | 胜率 | 30 天净收益估算 |
|----------|---------|------|----------------|
| 休闲型（负面） | 3 | 30% | −900 + 发放 60000 = 净 +59100 |
| 普通型 | 5 | 50% | ±0 + 发放 60000 = 净 +60000 |
| 高手型 | 8 | 70% | +16800 + 发放 60000 = 净 +76800 |

> 以上含每日登录 2000。可见**主要金币来源是每日登录而非对局**，符合"休闲"定位。

## 7. UI/UX 建议

### 7.1 大厅余额显示
- 顶部导航栏右侧：💰图标 + **coin 数量**（千分位分隔）
- 点击展开：昨日收入 / 余额变化折线（近 7 天）

### 7.2 创建房间时的底注选择器
- 滑动选择：50 / 100 / 500 / 1000（未解锁档位灰色）
- 显示该档位的"赢家净收益"、"建议 Elo"
- 余额 < ante 时禁止选择（红框提示）

### 7.3 对局中的金币变化
- 右上角常驻显示：本局 ante 金额（双方扣减时用红色动画）
- 胜/负结算时弹出 +/−动画（幅度匹配金额）
- 连胜角标（3/5/7 连胜），附带当前倍率

### 7.4 结算面板
- 显示项：对手名字、结果（胜/负/和）、本局底注、系统奖励、连胜加成、Elo 变化
- 条目示例：`+100（本金） +10（系统）×2.0（5 连胜） = +120`；`Elo +12 → 1560`

### 7.5 余额不足提示
- 弹窗文案："您的金币余额不足，可通过每日登录 +2000、完成任务、邀请好友获取金币"
- 按钮：[去登录] [邀请好友] [返回休闲模式]

## 8. 与其他游戏的差异化

| 维度 | 中国象棋 | 国际象棋 | 中国军棋 | 斗地主 | 德州扑克 |
|------|---------|---------|---------|-------|---------|
| 平均时长 | 20–45 min | 15–40 min | 25–60 min | 5–15 min | 10–30 min |
| 玩家数 | 2 | 2 | 2 | 3 | 2–6 |
| 随机性 | 无 | 无 | 高（暗棋） | 高 | 高 |
| 建议底注 | 50/100/500 | 50/100/500/1000 | 100/200/500 | 200/500/1000 | 500/1000/5000 |
| 系统奖励 | 5% | 10% | 15%（暗棋高风险） | 20% | 25% |
| Elo 段位 | 可选 | **强制挂钩** | 无 | 无 | 可选 |
| 核心差异 | 国际化弱 | **国际化强+Elo成熟** | 暗牌复杂 | 牌运主导 | 押注决策 |

**差异说明**：
1. **底注上限更高**（1000 vs 中国象棋 500）因为国际象棋平均海外 Elo 玩家资产认知更高，且对局不含纯运气
2. **段位强制挂钩**：国际象棋天然 Elo 成熟，直接用段位驱动底注分层，中国象棋侧重文化沉淀不做强制
3. **系统奖励更低（10%）vs 斗地主（20%）/德州（25%）**：棋类对局无随机性，高手稳赢，故系统奖励低以抑制通胀

## 9. 国际化考量

### 9.1 Elo 与金币挂钩
- Elo 作为**软门槛**解锁高底注房间（§4.1），不硬性限制
- 段位图标本地化：Bronze/Silver/Gold/Master（三语言词条）
- Elo 历史图表支持分享（生成图片分享链接）

### 9.2 海外用户习惯
- 国际象棋用户熟悉 FIDE Elo → 直接显示 Elo，不额外发明段位名（Bronze/Silver 仅作 UI 皮肤）
- 金币单位支持多语言：coin / コイン / 金币
- 时间格式：ISO + 本地时区显示（基于 `t_lsm_game_user.language`）

### 9.3 合规
- 明确在 UI 标注"金币为虚拟道具，不可兑换真实货币"
- 用户协议（Terms of Service）增加游戏币条款（防 RMT）
- 禁止账号交易（现有 `user_type` 可增加 `banned` 状态封禁）

### 9.4 多语言词条（新增）
| Key | zh-CN | en | ja |
|-----|-------|----|-----|
| `coin_unit` | 金币 | Coin | コイン |
| `ante_select` | 选择底注 | Select Ante | アンテ選択 |
| `coin_insufficient` | 余额不足 | Insufficient Balance | 残高不足 |
| `streak_bonus` | 连胜奖励 | Streak Bonus | 連勝ボーナス |
| `elo_rating` | Elo 等级分 | Elo Rating | Elo レーティング |
