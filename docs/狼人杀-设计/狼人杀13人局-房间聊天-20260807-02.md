# 狼人杀 13 人局 · 房间聊天 — 优化与重构方案

> 文档版本:2026-08-07 v2.0
> 设计对象:`ClientWeb/src/pages/WerewolfGamePage.tsx` 右侧「房间聊天」栏
> 问题反馈:Web 界面中嵌套显示了 2 个「房间聊天」标题 + 2 个折叠按钮

---

## 1. 问题诊断(根因分析)

### 1.1 当前渲染结构(2026-08-07 现状)

```
<div class="game-chat-column">                    ← WerewolfGamePage.tsx:708
  ├─ [展开态] <div class="werewolf-chat-wrap">   ← :726
  │   ├─ <div class="werewolf-chat-wrap__header">← :727 ← 【外层 header】
  │   │   ├─ <span class="werewolf-chat-wrap__title">
  │   │   │     💬 {t('werewolf.chatTitle')}    ← "房间聊天" 标题 #1
  │   │   │     · Day {gameState.day ?? 1}
  │   │   └─ <button class="werewolf-chat-wrap__fold-btn">▶</button>  ← 折叠按钮 #1
  │   └─ <WerewolfGameChatPanel />                ← 包装自 xiangqi/GameChatPanel
  │       └─ <div class="game-chat">
  │           ├─ <header class="game-chat__header"> ← 【内层 header】
  │           │   ├─ <div class="game-chat__title">
  │           │   │     [●] {t('chat.gameTitle')}    ← "房间聊天" 标题 #2
  │           │   └─ <button class="game-chat__toggle">▼</button> ← 折叠按钮 #2
  │           └─ <div class="game-chat__list"> ... </div>
  └─ [折叠态] <button class="room-chat-fold-handle">💬 ◀</button>
</div>
```

**两层独立切换、独立持久化,任何一层都"看上去像合法聊天标题"**:
- **外层**:localStorage 键 `werewolf.fold.chat` + state `chatFolded`
- **内层**:组件内部 React state `collapsed`(无持久化,刷新即重置)

### 1.2 用户视角

- 看到 2 个 "房间聊天" 文字 → "为什么重复?"
- 看到 2 个不同方向的箭头(`▶` / `▼`)→ "点哪个?折叠区域是哪个?"
- 内层折叠按钮的状态还会和外层状态机"打架"(外层折叠时内层仍可独立折叠/展开)

### 1.3 对比参照(为什么其他游戏没事)

`xiangqi/GameChatPanel` 同时被 5 款游戏复用(xiangqi / chess / doudizhu / texas / werewolf),其中 4 款游戏都是**裸调**:

```tsx
// XiangqiGamePage / DoudizhuGamePage / TexasHoldemGamePage / JunqiGamePage
<GameChatPanel roomId={roomId} />
```

只有 `WerewolfGamePage` 在 2026-08-06 §23 优化中**额外包裹了一层** `werewolf-chat-wrap__header`,初衷是为了让右侧栏的折叠按钮"在狼人杀页面里也能控制列收起"——但**折叠列的功能完全可以只用一个按钮表达,标题只需要一份**。

## 2. 设计目标

| # | 目标 | 衡量 |
|---|------|------|
| 1 | 房间聊天只显示 **1 个** "房间聊天" 标题 | DOM 中 `chatTitle` / `gameTitle` 文本节点唯一 |
| 2 | 房间聊天只显示 **1 个** 折叠按钮(共 2 套折叠 UI:列级 / 面板级) | 详见 §3 |
| 3 | 折叠状态持久化逻辑保持稳定(localStorage `werewolf.fold.chat`) | 与左栏「房间信息」对称 |
| 4 | DayN 副信息(游戏日数指示)不丢失 | 保留在 title 旁 |
| 5 | 与左侧「房间信息」布局对称 | 右侧栏与左侧栏共享同一套折叠模式 |
| 6 | 不破坏其他 4 款游戏(它们无此问题) | 不动 `xiangqi/GameChatPanel` 公共契约 |
| 7 | 美学:整体感、间距、圆角、对齐打磨 | 与现有狼人杀 v2 主题一致(暗色 + 金色点缀) |

## 3. 折叠 UI 重新分层(关键设计)

### 3.1 两层折叠的职责厘清

| 层级 | 触发位置 | 折叠效果 | 持久化 |
|------|---------|---------|--------|
| **列级 (column)** | 右侧整列折叠成 36px 窄条手柄 `💬 ◀` | 中栏扩展,棋盘区更大 | localStorage `werewolf.fold.chat` |
| **面板级 (panel)** | 内层 header 上的 ▼/▲ 按钮 | 仅隐藏聊天列表与输入框,保留 header(占位小) | React state `collapsed`(刷新即重置,与左栏无关) |

> **用户需求**:删除的是"嵌套产生的 2 个标题 + 2 个列级/外层折叠按钮"。
> 面板级折叠按钮(▼/▲)保留,因为它是**聊天面板自身的内部行为**(其他 4 款游戏都有,与左栏无关)。

### 3.2 改造后的 DOM 结构(单层标题 + 双层折叠)

```
<div class="game-chat-column">                  ← WerewolfGamePage.tsx (列容器)
  ├─ [折叠态] <button class="room-chat-fold-handle">💬 ◀</button>  ← 列级折叠(唯一外层按钮)
  └─ [展开态] <div class="werewolf-chat-wrap">
      └─ <GameChatPanel>
          ├─ <header class="game-chat__header"> ← 唯一标题"房间聊天"在这里
          │   ├─ <div class="game-chat__title"> [●] 房间聊天 · Day N
          │   └─ <button class="game-chat__toggle">▼</button>  ← 面板级折叠(▼/▲)
          └─ <div class="game-chat__list"> ... </div>
```

### 3.3 标题文案对齐

| 当前 | 改造后 |
|------|--------|
| 外层 `werewolf.chatTitle` + 内层 `chat.gameTitle` 两个键 | **统一使用一个**:沿用内层 `chat.gameTitle`(已被五款游戏共用,i18n 三语已完整) |
| Day N 渲染位置:外层 title 旁边 | **迁移至内层**:在 `game-chat__title` 旁追加 `<span class="game-chat__day">· Day N</span>`(新增) |
| 内层 title 仅含 "● 房间聊天"(无 Day 信息) | 含 "● 房间聊天 · Day N" |

## 4. UI 美学方案

### 4.1 当前内层 header 的不足

```tsx
// xiangqi/GameChatPanel.tsx:280-295
<div className="game-chat__title">
  <span className={'game-chat__dot' + (connected ? ' game-chat__dot--on' : '')} />
  <span>{t('chat.gameTitle')}</span>     ← 单纯文本,无图标无副信息
</div>
```

视觉问题:
- 缺少图标感(其他面板都用 emoji)
- 缺少 Day N 副信息(以前依赖外层)
- 圆角/间距与左栏 `room-info-panel__header` 不对称

### 4.2 美学方案:`game-chat__header` 升级

```
┌─────────────────────────────────────────────────────────────┐
│ 💬 房间聊天 · Day 2                            [▼] 收起聊天  │ ← 30-32px 高
└─────────────────────────────────────────────────────────────┘
   ↑         ↑                              ↑
   主图标    主标题 + 副信息(· Day N)        折叠按钮(右对齐)
```

#### 4.2.1 视觉规范(与左栏 `room-info-panel__header` 对称)

| 属性 | 取值 | 说明 |
|------|------|------|
| 高度 | `36px`(与左栏一致) | CSS 变量 `var(--ww-header-h)` |
| 背景 | `rgba(35, 32, 27, 0.6)` 半透明暗棕 | 与左栏 header 一致 |
| 边框 | `1px solid rgba(193, 154, 86, 0.25)` 金色 25% 透明 | 与左栏一致 |
| 圆角 | `var(--ww-radius) var(--ww-radius) 0 0` 顶部圆角,底部齐平接面板 | 复用设计 token |
| Padding | `6px var(--ww-pad)`(10px/8px 自适应) | 与左栏 header 一致 |
| 标题字号 | `13px` | 与左栏一致 |
| 标题字重 | `600` | 与左栏一致 |
| 标题颜色 | `var(--accent)` 金色 | 复用设计 token |
| 副信息(Day N) | `11px` `rgba(216, 200, 165, 0.65)` 等宽字体 | 与左栏 sub 一致 |
| 折叠按钮 | `12px` 文本 + `padding: 3px 6px` + hover 高亮 | 复用现有 `.game-chat__toggle` |

#### 4.2.2 新增图标策略

`chat.gameTitle` 当前为纯文本「房间聊天」,改为前置 emoji `💬` 与左栏「🏠 房间信息」对称(观战者模式显示「👁 房间信息」——已对齐,无需新增键)。

**i18n 复用方案**:**不新增键**,在 `xiangqi/GameChatPanel.tsx` 的渲染层硬编码 emoji 前缀,与左栏的 `▶ {spectator ? '👁 房间信息' : '🏠 房间信息'}` 写法保持一致 — emoji 不是 i18n 的范围。

#### 4.2.3 交互细节

| 元素 | 行为 |
|------|------|
| 列级折叠按钮 `💬 ◀` | 鼠标悬停 → 背景色 `rgba(193,154,86,0.2)` 高亮;文字竖排 `writing-mode: vertical-rl` |
| 面板级折叠 `▼` / `▲` | 鼠标悬停 → 背景色变化(已实现);点击 → 折叠/展开聊天列表与输入框 |
| 连接状态指示点 `[●]` | 已存在,绿色=已连接,灰色=未连接;**保留**(与其他 4 款游戏共用) |

## 9. 设计原则小结

> **「我方在底部」 + 「列级折叠 + 面板级折叠双层」** 是本项目的核心 UI 范式。
> 改造不是"砍掉一个标题",而是**对齐左栏**:
> - 左栏「🏠 房间信息」= **单** 标题 + **单** 列级折叠按钮(GameInfoPanel 内部无 header)
> - 右栏「💬 房间聊天」= **单** 标题 + **单** 列级折叠按钮 + **单** 面板级折叠(GameChatPanel 自带 header)
>
> 修复后两栏达到**完美对称**:一侧 header + 列级折叠,另一侧也是 header + 列级折叠,只是右侧额外有面板级的 ▼/▲(这是 5 款游戏共用的公共组件内禀行为)。
