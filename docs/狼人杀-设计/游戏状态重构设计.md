# 狼人杀13人局 · 游戏状态栏重构 — 20260807-01

> **目标**：把当前散落在 3 处（主标题、状态条、法官横幅）的游戏信息压缩到一个可折叠的统一栏位，释放首屏垂直空间，且**不丢失任何信息字段**。

---

## 1. 现状盘点（重构前）

页面顶部从下到上依次堆叠了 4 块独立组件，全部使用纵向空间：

| 层级 | 组件 | 关键内容 | 文件 / 行号 | 高度 |
|------|------|---------|------------|------|
| ① 主标题 | `werewolf-main-header` | `🐺 狼人杀 13 人标准竞技局` + `👁 观战中 · 房间 xxx · 警长竞选` + `📜 历史` 按钮 + `⏱ 已运行 10:22` | `WerewolfGamePage.tsx:458-494` | ~64px（带 padding+flex gap）|
| ② 法官横幅 | `judge-action-bar` | `🎙 MeiTuan-model · ⚙️ announce · 警长竞选开始！…` 跑马灯 + 待宣告/已禁用/总结徽章 | `WerewolfGamePage.tsx:496` | ~44px（sticky 顶部 `top:0`）|
| ③ 状态条 | `werewolf-main-header__status` (`WerewolfStatusBar`) | `⏱ 剩余 419s` + `🧠 4 名 Agent 响应中 · 4 调用` + `📊 调用 95 · 成功 95 · 失败 0` + `🔤 Token: …` + `⚖️ 法官: …` | `WerewolfGamePage.tsx:498` | ~48-72px（两行）|
| ④ 阶段时钟 | `phase-clock` | `🌅 黎明 · ⏱ 419s` | `WerewolfGamePage.tsx:608` | 重复在③ |

**问题**：

1. **总占用 ~160-180px 顶部空间**，且都不折叠（除 `info-fold` 是另一回事）。
2. **信息分散**：玩家在主标题看到「房间号」，在状态条看到「剩余时间」，在板内又看到 `phase-clock` 重复的剩余时间。
3. **法官横幅独立**：占用一行却只在 13 人局启用，与状态条信息分家。
4. **没有折叠**：用户想专心看牌桌时，无法收起这些信息。

---

## 2. 重构目标

| # | 目标 | 度量 |
|---|------|------|
| G1 | 顶部统一到**单个**「游戏状态栏」，所有信息**不丢** | 4 块 → 1 块 |
| G2 | **可折叠**，默认展开，折叠后只露 28px 高度 | 折叠态 < 32px |
| G3 | 默认展开高度 ≤ **60px**（紧凑模式）| 之前 ~180px → 现在 ≤ 60px |
| G4 | 关键数字（阶段倒计时 / Agent 数 / 调用数 / Token）一眼可见 | 主栏一屏内 |
| G5 | 法官横幅信息并入主栏，不再是独立 sticky 行 | 删除 `JudgeActionBar` 顶部条 |
| G6 | **不删除**任何已存在的字段（i18n / 字段 / 统计），仅整合布局 | `git grep` 验证 |

## 3. 新设计 — 「游戏状态栏 · GameStatusHeader」

**位置**：替代原 `werewolf-main-header` + `JudgeActionBar` + `WerewolfStatusBar` 三块，粘性顶部。

**两段式结构**：

```
┌─────────────────────────────────────────────────────────────────────┐
│ 🐺 狼人杀 13 人 · 👁 观战中 · 房间 xxx · 🌅 警长竞选       [▲]       │  ← 始终可见标题行 28px
│ ⏱10:22 ⏱剩余419s 🧠4响应中 📊95/0 🔤5.5M ⚖️3 ⚙️announce 📜 ⚙️      │  ← 主信息行
└─────────────────────────────────────────────────────────────────────┘
```

折叠后：

```
┌─────────────────────────────────────────────────────────────────────┐
│ 🐺 13人 · 👁 · 警长竞选 · ⏱10:22 · ⏱剩419s · 🧠4 · 📜    [▼]       │  ← 紧凑单行 28px
└─────────────────────────────────────────────────────────────────────┘
```

## 4. 实施步骤

### 步骤 1 — 新建组件 `GameStatusHeader.tsx`

**路径**：`ClientWeb/src/components/werewolf/GameStatusHeader.tsx`

**Props**：

```ts
interface GameStatusHeaderProps {
  gameState: WerewolfGameState;
  isHumanInRoom: boolean;
  spectator: boolean;
  roomId: string;
  nowMs: number;
  onOpenHistory: () => void;
  /** 折叠状态；不传则组件自管 */
  collapsed?: boolean;
  onCollapsedChange?: (v: boolean) => void;
}
```

**内部数据流**（沿用现有逻辑）：

- 阶段倒计时：`phase_extra.phase_deadline_at` → `Date.parse() - nowMs`
- Agent 响应聚合：`bot_contexts[].llm_call_phase`（沿用 §127 聚合函数）
- API/Token 统计：`agent_stats`（沿用 §统计增强）
- 法官上下文：`judge_context` + `judge_enabled`
- 终局判定：`status === 'over'`
- 房间 ID：`gameState.room_id ?? roomId`

### 步骤 2 — 替换 `WerewolfGamePage.tsx` 三处

```diff
- <header className="werewolf-main-header"> … </header>
- {gameState && <JudgeActionBar gameState={gameState} />}
- {gameState && <WerewolfStatusBar ... />}
+ <GameStatusHeader
+   gameState={gameState}
+   isHumanInRoom={!spectator}
+   spectator={spectator}
+   roomId={roomId}
+   nowMs={Date.now()}
+   onOpenHistory={() => setHistoryOpen(true)}
+ />
```

### 步骤 6 — 折叠状态持久化

```ts
const STORAGE_KEY = 'werewolf.gameStatusHeader.collapsed';
const [collapsed, setCollapsed] = useState<boolean>(
  () => localStorage.getItem(STORAGE_KEY) === '1'
);
useEffect(() => {
  localStorage.setItem(STORAGE_KEY, collapsed ? '1' : '0');
}, [collapsed]);
```

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 法官跑马灯不再持续可见 | §130 设计期望法官宣告高亮可见 | 主信息行 `⚙️announce` chip + tooltip 显示最近宣告首句 + 2s pulse |
