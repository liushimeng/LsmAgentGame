# 辩论比赛 — 工具与记忆系统设计

> 本文档描述辩论比赛的**工具定义**、**Memory 系统**、**记忆压缩（Compact）**、**Context 管理**。
> 复用狼人杀 Agent 的设计模式，适配辩论场景。

## 1. 工具系统概述

### 1.1 工具分类

| 工具类型 | 使用者 | 说明 |
|----------|--------|------|
| **发言工具** | 辩方 Agent | speech / free_debate_speak |
| **质询工具** | 三辩 Agent | cross_exam_question / cross_exam_answer |
| **评审工具** | 裁判 Agent | submit_score / announce |
| **通用工具** | 所有 Agent | idle_silent |

### 1.2 工具过滤规则

工具按 **阶段（Phase）+ 辩位（Role）** 过滤，LLM 只能看到当前可用的工具：

| 阶段 | 一辩 | 二辩 | 三辩 | 四辩 | 裁判 |
|------|------|------|------|------|------|
| OpeningArgument | speech | idle | idle | idle | announce |
| Rebuttal | idle | speech | idle | idle | announce |
| CrossExamination | idle | cross_exam_answer | cross_exam_question | idle | announce |
| CrossExamSummary | speech | speech | idle | idle | announce |
| FreeDebate | free_debate_speak | free_debate_speak | free_debate_speak | free_debate_speak | announce |
| ClosingArgument | idle | idle | idle | speech | announce |
| Judging | idle | idle | idle | idle | submit_score, announce |

> **说明**：`idle` = idle_silent 工具；`speech` = 正式发言工具；裁判在评审阶段获得 submit_score。

## 4. Memory 系统设计

### 4.1 Memory 结构

### 4.2 初始 Memory（身份注入）

```go
// NewDebaterMemory 创建辩方 Agent 的初始记忆
func NewDebaterMemory(role, stance, topic string, teamID, seat int) *Memory {
    m := &Memory{maxPromptBytes: DefaultMaxPromptBytes}

    // 身份消息（第一句话，固定前缀）
    identity := llm.Message{
        Role: "user",
        Content: []llm.ContentBlock{{
            Type: "text",
            Text: buildDebaterIdentity(role, stance, topic, teamID, seat),
        }},
    }
    m.messages = append(m.messages, identity)
    return m
}

func buildDebaterIdentity(role, stance, topic string, teamID, seat int) string {
    roleName := map[string]string{
        "first": "一辩", "second": "二辩", "third": "三辩", "fourth": "四辩",
    }[role]
    stanceName := map[string]string{
        "pro": "正方", "con": "反方", "neutral": "中立",
    }[stance]

    return fmt.Sprintf(
        "你是辩论比赛的%d号辩手（%s），代表%s（%s）。\n辩题：「%s」\n你的立场：%s\n你的职责：%s",
        seat+1, roleName, stanceName, stance, topic, getRoleDuty(role),
    )
}
```

## 5. 记忆压缩系统（Compact）

### 5.1 触发条件

| 条件 | 阈值 | 说明 |
|------|------|------|
| 消息数 | > 50 条 | 防止上下文过长 |
| 字节数 | > 300KB | 防止超出模型限制 |
| 阶段切换 | 每阶段结束 | 阶段结束时自动压缩 |
| 手动触发 | Agent 判断 | Agent 可主动触发 |

### 5.2 压缩策略：8 段结构化摘要

```
## S1. 辩题与立场
  - 辩题文本 + 类型
  - 我方立场 + 辩位

## S2. 我方核心论点与论据
  - 已提出的论点列表
  - 关键论据摘要

## S3. 对方核心论点与论据
  - 对方已提出的论点列表
  - 关键论据摘要

## S4. 关键交锋点
  - 双方争议焦点
  - 攻防结果

## S5. 我方发言摘要
  - 按阶段归档的核心发言要点

## S6. 对方发言摘要
  - 按阶段归档的核心发言要点

## S7. 当前局势
  - 当前阶段 + 剩余时间
  - 待完成任务

## S8. 上次压缩以来的新增
  - 新增的发言要点
  - 新增的交锋点
```

### 5.4 压缩校验

```go
// IsValidCompactSummary 校验压缩摘要的合法性
func IsValidCompactSummary(summary string, myStance string, myRole string) bool {
    // 1. 长度校验
    if len(summary) > 2000 {
        return false
    }

    // 2. 结构校验：必须包含 8 段
    for i := 1; i <= 8; i++ {
        section := fmt.Sprintf("## S%d.", i)
        if !strings.Contains(summary, section) {
            return false
        }
    }

    // 3. 立场校验：不得包含对方内部策略
    forbiddenKeywords := []string{"对方策略", "对方计划", "对方内部"}
    for _, kw := range forbiddenKeywords {
        if strings.Contains(summary, kw) {
            return false
        }
    }

    return true
}
```

## 7. Context 管理

### 7.1 Context 构建时机

| 时机 | 说明 |
|------|------|
| 阶段切换 | 每次阶段切换时重建 Context |
| 轮到我发言 | 收到发言请求时更新 Context |
| 压缩后 | 压缩完成后更新 Context |

### 7.2 Context 大小控制

| 策略 | 说明 |
|------|------|
| 发言截断 | 单条发言最多取前 100 字 |
| 历史窗口 | 最近 20 条发言完整保留 |
| 论点去重 | 重复论点只保留最新版本 |
| 压缩摘要 | 超限时使用压缩摘要替代全文 |

### 7.3 多队 Context 差异

| 模式 | Context 差异 |
|------|-------------|
| 双队 | 仅包含正方 + 反方发言 |
| 三队 | 包含三方发言，立场标注 |
| 四队 | 包含四方发言，BP 制分组 |
| 五队 | 包含五方发言，多角度标注 |

## 8. 工具派发器（DispatchTool）

```go
// DispatchDebaterTool 把辩方 LLM 返回的 tool_use 转换为引擎操作
func DispatchDebaterTool(toolName string, input map[string]any, agent *Agent, engine *DebateEngine) (string, error) {
    switch toolName {
    case "speech":
        content, _ := input["content"].(string)
        thought, _ := input["internal_thought"].(string)
        refs, _ := input["references"].([]string)
        return engine.SubmitSpeech(agent.TeamID, agent.Seat, content, thought, refs)

    case "cross_exam_question":
        targetTeam, _ := input["target_team"].(float64)
        targetSeat, _ := input["target_seat"].(float64)
        question, _ := input["question"].(string)
        return engine.SubmitCrossExamQuestion(agent.TeamID, agent.Seat, int(targetTeam), int(targetSeat), question)

    case "cross_exam_answer":
        questionID, _ := input["question_id"].(string)
        answer, _ := input["answer"].(string)
        return engine.SubmitCrossExamAnswer(agent.Seat, questionID, answer)

    case "free_debate_speak":
        content, _ := input["content"].(string)
        return engine.SubmitFreeDebateSpeech(agent.TeamID, agent.Seat, content)

    case "finish_speak":
        reason, _ := input["reason"].(string)
        return engine.FinishSpeak(agent.TeamID, reason)

    case "idle_silent":
        reason, _ := input["reason"].(string)
        return engine.IdleSilent(agent.Seat, reason)

    default:
        return "", fmt.Errorf("unknown tool: %s", toolName)
    }
}
```
