# 辩论比赛 — 界面与交互设计

> 本文档描述辩论比赛的**前端界面设计**、**交互流程**、**可视化方案**、**组件结构**。
> 参考狼人杀的前端架构模式（store + hook + 组件化）。

## 4. 交互设计

### 4.1 观众交互

| 交互 | 说明 |
|------|------|
| 进入观战 | 点击房间列表的「观战」按钮 |
| 发送聊天 | 在聊天室输入框输入 + 发送 |
| 点赞发言 | 点击发言旁的 👍 按钮 |
| 提问裁判 | 在裁判面板点击「提问」按钮 |
| 查看 Agent 思考 | 点击发言旁的 💭 图标 |
| 展开/收起面板 | 点击各面板的标题栏 |
| 退出观战 | 点击「离开」按钮 |

### 4.2 房主交互

| 交互 | 说明 |
|------|------|
| 开始比赛 | 点击「开始比赛」按钮 |
| 暂停/继续 | 点击「暂停」/「继续」按钮（可选） |
| 跳过阶段 | 点击「跳过当前阶段」（可选） |
| 解散房间 | 点击「解散房间」按钮 |
| 查看配置 | 点击房间信息图标 |

### 4.3 阶段切换动画

| 阶段切换 | 动画效果 |
|----------|----------|
| 立论 → 驳论 | 淡入淡出 + 阶段名称横幅 |
| 驳论 → 质询 | 左右滑动 + 质询图标 |
| 质询 → 自由辩 | 计时器放大 + 紧张音效 |
| 自由辩 → 总结 | 渐暗 + 聚光灯效果 |
| 总结 → 评审 | 等待动画 + 评审倒计时 |
| 评审 → 结果 | 揭晓动画 + 胜方高亮 |

## 6. 状态管理（zustand store）

### 6.1 Store 结构

```typescript
interface DebateStore {
  // 房间信息
  rooms: RoomInfo[];
  currentRoom: RoomInfo | null;

  // 辩论状态
  gameState: DebateGameState | null;
  phase: string;
  timeRemaining: number;

  // 队伍信息
  teams: TeamInfo[];
  currentSpeaker: SpeakerInfo | null;

  // 发言
  speeches: Speech[];
  currentSpeech: Speech | null;

  // 裁判
  judges: JudgeInfo[];
  scores: TeamScore[];
  result: DebateResult | null;

  // Agent 思考
  agentThoughts: Record<string, string>;

  // UI 状态
  expandedPanels: Record<string, boolean>;
  spectatorCount: number;

  // Actions
  setRooms: (rooms: RoomInfo[]) => void;
  setGameState: (state: DebateGameState) => void;
  addSpeech: (speech: Speech) => void;
  updatePhase: (phase: string, timeRemaining: number) => void;
  updateScore: (judgeId: number, score: TeamScore) => void;
  setResult: (result: DebateResult) => void;
  togglePanel: (panelId: string) => void;
  reset: () => void;
}
```

### 6.2 WS 消息处理

```typescript
// useDebate hook 处理 WS 消息
switch (frame.type) {
  case 'debate.state':
    store.setGameState(frame.data);
    break;
  case 'debate.phase':
    store.updatePhase(frame.data.phase, frame.data.time_remaining);
    break;
  case 'debate.speech':
    store.addSpeech(frame.data);
    break;
  case 'debate.judge_vote':
    store.updateScore(frame.data.judge_id, frame.data.score);
    break;
  case 'debate.game_over':
    store.setResult(frame.data.result);
    break;
  case 'debate.agent_thought':
    store.addAgentThought(frame.data.seat, frame.data.thought);
    break;
}
```
