### 关键设计决策

1. **纯 Agent 驱动**:狼人杀是"人类 + Agent 混合",辩论比赛是"100% Agent 参赛,人类仅房主 / 观战者"。
2. **公平分配**:蛇形洗牌确保正反方模型能力均衡,裁判使用与辩方不同的模型。
3. **完整 Bot 循环**(§20260831-02 升级):每轮 ≤5 次 tool_use,失败自纠错重试,终态工具即停,LLM 失败回退 fallback 模板发言。
4. **避免循环引用**:`agent/debaterun` 独立包解决 `debate → agent/debateplayer → debate` 的循环依赖。
5. **发言必须完成 > 名义时长**(§20260831-02):发言阶段等待预算与阶段 deadline 解耦;deadline 仅约束准备期倒计时/自由辩循环/评审收集。
6. **game/debate 不 import ws**:所有实时推送经 `DebateManager` 钩子外抛,由 main.go 接到 `ws.DebateService`(与狼人杀 Manager→GameService 同构)。

### 设计01：标准四对四团体辩论赛流程

第一，开篇立论：正反方一辩依次发言（各 3 分钟），明确辩题定义、划定范围、抛出核心论点。

第二，驳论与质询：二辩驳论（各 2 分钟）+ 交叉质询（三辩交替提问）。

第三，自由辩论：双方累计时长均等（各 4 分钟），交替起立辩论。

第四，总结陈词：四辩收尾（各 3-4 分钟），梳理攻防、升华观点。

### 设计02：华语赛制骨干

1. 开篇立论（一辩）→ 2. 驳论/质询（二/三辩）→ 3. 质询小结 → 4. 自由辩论 → 5. 总结陈词（四辩）

评审：评委评议 → 点评 → 宣布结果。

### 设计03：两大源流

- 奥瑞冈制：申论—质询交替，注重逻辑严谨
- 新加坡制：四人制，重视观赏性和语言美感
- 当代融合：立论→攻防→自由辩论→总结

### AI 辩论适配说明

本项目的 AI 辩论比赛基于上述赛制，由 Agent 全自动执行：
- 辩方 Agent 扮演一至四辩，按阶段自动发言
- 裁判 Agent（3 个）独立评审打分
- 人类玩家仅观战 + 聊天互动
- 详细设计见上述 7 篇专题文档
