## 一、归档原因

`玩家职业设计/` 目录自 v4.0 重构（2026-08-07 §20260807-03 同源重构）后存在 **两套并存** 的目录体系：

| 体系 | 命名规则 | 文件数 | 命名风格 |
|---|---|---|---|
| **v3.x 旧数字目录**（本次归档） | `01-农林牧渔/`、`02-化工与新材料/` 等 | **69,457 张** | 文件名以职业名命名（如 `植保工.md`），带 L1/L2 三层子目录 |
| **v4.0 新字母目录**（保留） | `A-农林牧渔/`、`B-采矿与冶金/` 等 | **5,660 张**（v4.0 + 后续增补）| 文件名以真实姓名命名（如 `傅琳.md`）|

v4.0 重构时已把旧档案映射关系沉淀到 `_框架/06-档案清单/映射表-第01批.md` 到 `映射表-第10批.md`，**信息没有丢失**。但旧数字目录的物理文件未删除，导致：

- 与新字母目录并存，文件系统混乱
- `git grep` 时新旧两套同时命中，搜索噪音严重
- 路径选择歧义：维护者不知道应该改哪一份
- 双套文件占用 git 仓库体积（65,066 张旧卡 × 几 KB = 数百 MB）

本次归档把旧目录物理移动到 `99_归档与待整理/v3.x旧版扁平目录归档/`，让 `玩家职业设计/` 仅保留新字母目录 + 框架。
