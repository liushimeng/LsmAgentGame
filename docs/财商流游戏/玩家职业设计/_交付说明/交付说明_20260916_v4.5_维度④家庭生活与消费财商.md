## 1. 背景与设计意图

财商流游戏的关键变量之一是**家庭结构**——单亲/丧偶/丁克/隔代/跨国等家庭形态对应完全不同的财务压力、支出结构、风险偏好、保险需求。本维度填补行业维度（A–Z）中「无处安放」但真实财富流动举足轻重的人群：

- 单亲妈妈（离异/未婚）—— 单一收入来源 + 子女教育金 + 房贷压力
- 隔代抚养祖辈 —— 已退休 + 带孙辈 + 养老金 + 子女转账
- 丁克与不婚 —— 高储蓄 + 退休规划 + FIRE 目标
- 残障/重病回归 —— 福利补贴 + 就业歧视 + 医疗支出
- 长照家庭 —— 在岗 + 照料失能老人/自闭症/阿尔茨海默症
- 跨国婚姻 —— 跨境转移 + 外汇资产 + 文化冲突
- 多代同堂 —— 四世/三代同住 + 家族互助 + 夹心层压力

这些人群在真实世界财富流动中举足轻重，却是行业树里的「暗物质」。

## 8. 已知限制

1. **留守儿童组**（DIM4-0203/0204）为未成年人（age 6–16），`income_monthly` 语义 = 其支配的月度现金流入（家庭转移 + 助学金），符合 v4.5 `income_semantics: 月度可支配现金流入` 定义。
2. **同 L3 组内职业轮换**：`gen_from_pool` 在 occupations 列表中随机选择，当配额 > 职业数时会出现同一职业多张卡，但收入/年龄/地区/化名均随机扰动，整体多样性可接受。
3. **Go 加载器集成测试**（§10 第 9 项）待 backend P0 修复后补做（本 Agent 不修改 `ServerGo/`）。
