# 财商流游戏 · 职业画像框架与索引

## 1. 设计原则：人物画像不是数据表

### 1.1 为什么单独写一份人物画像

《规则与经济系统》§10 给出了 12 个职业的**财务起跑线**（月薪 4,500–40,000 等），但同一个外卖骑手可以是：

- **小王**：农村出来的 21 岁男孩，父亲工伤在家，母亲务农，每月寄回家 1,500 元，自己节衣缩食，梦想开一家小餐馆；
- **老李**：42 岁二线城市本地人，离异独自带娃，房贷还有 18 年，骑手是中年过渡，下岗后再就业，梦想是给孩子攒出大学学费；
- **阿莲**：28 岁女骑手，单身，独生子女，父母体制内退休有房有养老金，骑车只是因为「自由、不用看老板脸色」，梦想是攒够 50 万去开个奶茶店。

同样是月薪 5,000，**他们的支出结构、负债、家庭压力、人生目标、对机会的判断方式完全不同**。如果游戏只下发"外卖骑手 P01"，所有玩家拿着相同数据开局，就丢失了人生的多样性——而这恰恰是财商教育最重要的一个维度：**金钱决策从来不是数学题，是身份、家庭、性格、价值观的综合题**。

本作的设计选择是：**财务数据来自职业卡（统一规则），人物画像来自玩家卡（差异化故事）**。开局时玩家从职业卡池抽一张（决定财务起点）+ 从玩家卡池抽一张（决定个人故事），两张卡共同决定一个"人"。

### 1.2 五条画像设计原则

| # | 原则 | 说明 |
|---|------|------|
| **P1** | **财务数据与人格独立** | 同一职业不同人格可以玩出完全不同的人生路径，避免"职业 = 命运" |
| **P2** | **覆盖中国阶层光谱** | 12 个画像覆盖农村到一线城市新中产，覆盖体制内/外、体力/脑力、本地/外地 |
| **P3** | **决策倾向真实可识别** | 每个画像对应 1–2 种行为金融偏差（参见《行为金融与投资心理机制设计》），便于 Agent 教练针对性干预 |
| **P4** | **人生目标可量化** | 每个画像有清晰的"梦想成本"（买房、子女教育、创业、自我实现），便于终局评估 |
| **P5** | **避免脸谱化** | 不让低收入职业 = 悲惨命运 / 高收入职业 = 幸福人生，每个画像都有其张力与可能 |

### 1.3 与其他文档的边界

| 文档 | 关注点 | 共同点 |
|------|--------|--------|
| 《规则与经济系统》§10 | 财务起跑线（月薪、储蓄、精力/人脉/认知初始值） | 职业编号 P01–P12 |
| 《总体设计》§10.2 | Agent AI 玩家性格原型（5 种） | 性格分类的简化版 |
| **本文档** | **个人画像、家族背景、决策倾向、人生目标** | **人物的可玩性** |

- **P 系列（P01–P18）**：早期核心卡池 + 扩展卡池，详细档案格式，覆盖 12 个基础职业的差异化人格
- **N 系列（N01–N60）**：扩展卡池，按职业群分类，覆盖新业态、健康照护、金融服务、数字经济、社会服务、高危职业、高端专业、文化艺术、中老年再就业等
- 新增人物继续使用 N61+ 编号，禁止复用已有编号和姓名

## 5. 去重与维护规则

1. 同一职业允许存在多人，但必须在年龄、健康、家庭、住房、负债、行为偏差或城市层级中至少三项显著不同。
2. 新增人物前检索 `git grep "姓名或ID"`；禁止重复使用 P/N 编号和虚构姓名。
3. 一份档案不要同时复制完整财务表和行为定义；行为机制引用专项文档，财务参数引用规则文档。
4. 收入与资产区间变动时，更新 `99-研究来源与数据锚点.md` 的口径和日期，不要直接篡改历史人物卡。
5. 所有档案人物均为教学虚构；不得写入可识别真实个人的身份证号、住址、电话、精确病历或账号。
