# 财商流游戏 · 创意设计、医疗零售与民生服务职业档案（N91–N100）

> 本档案为 N01–N90 之后的扩展，聚焦既有卡池尚未充分覆盖的 **6 大缺口**：
> 1. **自由创意职业**（独立商业插画师）—— 与 N09 游戏美术（公司雇佣）形成"自由接单 vs 全职雇佣"差异化，AI 冲击下 K 型分化的典型；
> 2. **医疗零售终端**（社区药店执业药师+店长）—— 与 N11 规培医生 / N82 私立口腔医师形成"医院 vs 零售终端"差异化，药品零加成与集采政策下的零售转型；
> 3. **国际贸易物流**（跨境物流货代业务员）—— 与 N34 跨境电商卖家形成"货主 vs 货代"差异化，运价周期与客户流失的双重风险；
> 4. **学前教育管理**（民办普惠幼儿园执行园长）—— 与 N43 乡村特岗教师形成"乡村公办 vs 城市民办管理岗"差异化，出生率下降与普惠政策的双重挤压；
> 5. **制造业设计**（工业设计师/产品结构设计师）—— 与 P07 平面设计师形成"产品硬设计 vs 视觉软设计"差异化，制造业升级与原型打样成本；
> 6. **传统批发与民生服务**（海鲜批发行个体户 / MCN 探店达人 / 建筑注册安全工程师 / 跨境 DTC 独立站卖家 / 社区养老驿站站长）—— 覆盖传统农贸批发、本地生活新媒体、建筑安全合规、跨境品牌出海、银发经济终端等高增长或刚需职业群。

  使中低端商稿报价下降 50%–70%，90% 的插画师认为"画得好就能赚钱"是行业最大谎言
