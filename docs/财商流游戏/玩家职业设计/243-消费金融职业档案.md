# 财商流游戏 · 消费金融职业档案（N2811–N2820）

> 本档案补充 N2811–N2820 号非重复人物卡，聚焦既有卡池尚未充分覆盖的 **10 类职业缺口**：
> 1. **消费金融风控模型工程师**（N2811）—— 消费信贷评分模型开发与迭代
> 2. **消费金融产品经理**（N2812）—— 消费贷产品设计与上线运营
> 3. **消费金融催收合规主管**（N2813）—— 催收团队管理与合规催收
> 4. **消费金融数据分析师**（N2814）—— 消费贷业务数据看板与归因分析
> 5. **消费金融信贷审批员**（N2815）—— 个人消费贷申请人工审批
> 6. **消费金融用户运营**（N2816）—— 消费贷用户生命周期运营与促活

> 计价为 2026 年人民币静态开局值；收入/支出为月口径，储蓄/负债为即时存量。
> 健康 A=稳定，B=可控慢病或劳损，C=重大风险。所有姓名为虚构，财务数据用于教学，不构成理财建议。
