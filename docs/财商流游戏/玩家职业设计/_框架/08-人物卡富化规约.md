# 财商流游戏 · 人物卡富化规约（richness: skeleton → rich）

> 本规约定义「黄金样本」批次的富化作业标准。
> 对象：经机械映射生成的 `richness: skeleton` 人物卡。
> 目标：在**不违背任何既有 `explicit` 字段**的前提下，补齐叙事性内容。
>
> **v1.1（2026-09-14）增量**：富化卡在 v1.1 新增的 6 个全息画像字段上**继续深化**（不替换）；
> 既有的 v1.0 字段保持原样。详见 §3.4「v1.1 富化补充」。

---

## 1. 什么可以改，什么不能改

### ✅ 允许修改

| 位置 | 动作 |
|---|---|
| frontmatter `richness` | `skeleton` → `rich` |
| frontmatter `psych.personality` 等**已登记字段** | 填入内容（见 §3） |
| frontmatter `emotion_satisfaction` | 若已存在则填；不存在则不新增 |
| frontmatter **v1.1 字段**（`personality` / `behavior_traits` / `risk_preference` / `birth_family` / `life_story` / `opening_hook`） | 可**深化但不得推翻**既有 `assigned` 值（见 §3.4） |
| `## 6. 情感与人格` 正文 | 把 `- **人格特征**：【待富化】` 一行替换为 §3.1 的 5 行（保留同节既有 bullet） |
| `## 8. 开局钩子` 正文 | 替换为**一个具体开局事件**（含原为原档碎片串的情形） |
| `## 7. 人生目标与机会` | 在既有目标之后、`梦想成本估算` 之前**追加** 1–2 条具体目标 |
| 新增 `_rich` 元数据块 | 见 §4 |

### ❌ 严禁修改

1. **任何 `explicit` 字段** —— `name` `age` `gender` `income_monthly`
   `health_conditions` `occupation` `marital` `children_count` `city`
   `housing_detail` `stress_sources` `_legacy_ids` `_raw` 等。
2. **`id`、文件名、所在目录** —— 富化只改文件内容，**不移动、不重命名**。
3. **正文 9 个小节的标题与顺序**。
4. **与既有数据矛盾的表述** —— 见 §2 一致性硬约束。
5. **v1.1 6 字段的 `assigned` 初始值**（富化只能深化，不能改写回其他标签）。

## 2. 一致性硬约束（违反即整卡作废）

富化内容必须与以下字段**逐项自洽**：

**优先级**：当 `_raw` 原档行与 frontmatter 的 `explicit` 字段**互相矛盾**时
（原档本身有冲突，非本次解析所致），一律**以 frontmatter 字段为准**，
并**回避提及**冲突细节，不得为了满足「与 `_raw` 无矛盾」而写出与字段冲突的内容。

| 约束 | 说明 |
|---|---|
| 城市 | 提到的地名必须与 `housing_city` 同级或更小（不得写人物在北京而 `housing_city` 是成都） |
| 年龄 | 出生年份、工作年限、子女年龄、父母年龄必须与 `age` / `birth_year` 自洽 |
| 收入 | 提到的金额量级必须与 `income_monthly` 同档；**不得**声称远高于或远低于该收入的生活方式 |
| 健康 | 不得声称患有与 `health_conditions` 冲突的疾病；可补充同向的亚健康描述 |
| 家庭 | 提及的家人数量必须与 `children_count` / `elders_dependent` / `marital` 一致 |
| 职业 | 不得改行；不得声称拥有 `certs` 之外的执业资格 |
| 负债 | 不得虚构房贷以外的大额负债（`mortgage_left` / `debts` 已载明） |
| 教育 | 不得声称高于 `education` 的学历 |

> **判据**：读者拿本卡与 `## 9. 数据溯源` 的 `_raw` 原档行对照，**不应发现任何矛盾**。

## 3. 富化内容规格

### 3.0 与既有 bullet 的关系（已按实况明确）

`## 6. 情感与人格` 小节在机械映射后**已含**两行既有 bullet：
`- **情感状况**：…` 与 `- **行为金融偏差**：…`。

> **只替换 `- **人格特征**：【待富化】` 这一行**为下面的多行内容；
> **保留**既有两行 bullet 原样不动（它们属既有正文，非占位符）。

### 3.1 `## 6. 情感与人格`（必填）

将 `- **人格特征**：【待富化】` 替换为以下 **5 行 bullet**：

```
- **人格特征**：大五人格 O:<0-100> C:<0-100> E:<0-100> A:<0-100> N:<0-100>
  —— <一句话概括，20–40 字>
- **风险偏好**：<保守 / 中低 / 中性 / 中高 / 激进>（<依据：与该人物收入结构、健康档、家庭负担的关系>）
- **时间偏好**：<现期偏向 / 中性 / 远期偏向>（<依据>）
- **金钱脚本**：<一句话 —— 这个人与钱的关系是什么>
- **情感张力**：<一到两句，与 `emotion_status`、`household_type` 自洽>
```

大五人格五个分值必须**互补自洽**：高 C（尽责）与低收入月光并存时要给出解释；
高 N（神经质）应与 `stress_level: 高` 或 `stress_sources` 条数多相呼应。

### 3.2 `## 8. 开局钩子`（必填）

**一个**具体场景，150–350 字，格式：

```
**「<场景首句，引号包住，含时间与地点>」**
<3–5 句展开：触发事件 → 该人物的两难 → 一个必须在本回合内做出的财务决定>
```

要求：
- 必须包含**一个数字**（金额、期限或比例），且该数字与该人物财务快照自洽；
- 必须点名**一个行为金融偏差**并让它驱动判断，取值优先级：
  1. `biases` 非空 → 严格取其中一项；
  2. `biases` 为空但 `stress_sources` 含偏差词 → 取该词；
  3. 两者皆无 → 从 §5 词典中选一个与该人物处境（收入结构 / 负债 / 健康档 / 家庭负担）
     强相关的偏差，并在 `_rich.basis` 中列入 `biases` 与 `stress_sources` 作为依据。
  > **注意**：`biases` 字段本身**始终不得修改**（即使为空）。
- 必须是《财商流游戏》可落地的**回合内事件**（不是人生总结）。
- 若 `## 8` **已无占位符**（机械映射填入了原档碎片串，如 `件量下滑；三通压价；儿子`），
  仍按本节规格**整体替换**为合格钩子 —— 碎片信息须融入叙事，不得丢弃（原文另有 §9 `_raw` 兜底）。

### 3.3 `## 7. 人生目标与机会`（追加）

**插入锚点**：在该节**最后一条既有 bullet 之后、`- **梦想成本估算**` 之前**追加 1–2 条目标。
若该节渲染为 `- 未采集`，则**替换**该行。若既有条目是 `- **开局**：…` 形态，同样在其后追加。

追加格式：

```
- **<期限>**：<具体目标>（约 <金额> 元，<资金来源设想>）
```

### 4.1 v1.1 富化深化（2026-09-14 增补）

富化卡在 v1.1 字段上的深化**不替换**原有 `assigned` 值，而是：

- **深化而非推翻**：可在原 `assigned` 标签**之上**补充更精准的描述，
  但**保留**原标签至少 1 项作为「锚点」（避免破坏 75,115 张卡的画像分布）。
- **`opening_hook` 必填**：v1.1 推导的一句话钩子是骨架，**富化时必须按 §3.2 替换为完整 150-350 字场景**，
  覆盖原 30-50 字的合成钩子。
- **`life_story` 时间线补充**：v1.1 已生成 3-6 条主时间线，富化可在**每条 event 后追加细节**（如「入职 XX 公司，担任 XX 岗位」），不增不减年龄。
- **`personality` / `behavior_traits` / `risk_preference` / `birth_family`**：富化时**不得删改 `assigned` 值**，
  仅在 `_rich` 块的 `basis` 字段里补充 1-2 条支撑数据来源。

### 3.4 v1.1 富化补充（2026-09-14 增补）

**目的**：富化卡与骨架卡的 v1.1 6 字段保持**派生连续性**——
骨架卡先由 `enrich_holistic_v44.py` 确定性推导（`_sources.assigned`），
富化时再补叙事性内容（`_sources.assigned` 升级为 `_rich.basis` 显式支撑）。

**深化操作矩阵**：

| 字段 | 骨架（assigned） | 富化（rich） | 关系 |
|---|---|---|---|
| `personality` | 2-4 词列表 | 保留全部 + 可追加同向描述 | 不删改，可叠加 |
| `behavior_traits` | 2-4 词列表 | 保留全部 + 可追加同向描述 | 不删改，可叠加 |
| `risk_preference` | conservative / balanced / aggressive | 保留原值 | **不修改** |
| `birth_family` | 6 档之一 | 保留原值 | **不修改** |
| `life_story` | 3-6 条时间线 | 在每条 event 后追加细节 | 不增不减年龄 |
| `opening_hook` | 30-50 字一句话 | **必替换**为 150-350 字场景（按 §3.2 规格） | 整段覆盖 |

> **关键约束**：富化时 `risk_preference` 与 `birth_family` 是**派生定值**，富化 Agent **不得改写**；
> 这是为了保持与骨架卡画像分布的一致性（让 Agent 教练对 18 位 P 玩家与 75K 普通玩家用同一套画像分布查询）。
> 详细推导决策树见 `05-画像与阶层框架.md` §11。
> 完整 v1.1 字段定义见 `01-人物卡字段字典.md` §8。
> 65 字段全息维度映射与定位声明见 `11-人生全息画像规约.md`（v1.1 新建）。

## 6. 诚实性要求

富化内容是**生成的叙事**，不是调研事实。因此：

- `_rich.basis` 必须列明所依据的真实字段；
- 正文中不得出现「据调研」「数据显示」等**伪引用**；
- 数字可以合理构建，但必须**与既有数据同档**，不得凭空放大或缩小人生处境。
- **已知解析残值**：若某卡 `savings_stock` 为个位/十位数（原档「储蓄 N 万」曾被截断），
  或 `health_conditions` 含 `芳 · 31` 之类人名碎片，一律**不要引用该值**，
  改用 `income_monthly` / `monthly_expense` / `mortgage_left` 等可靠字段入钩子。
