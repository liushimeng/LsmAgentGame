## 二、关键变更说明

1. **数字编号 → 字母编号**：v3.x 用 01-19 数字前缀按行业编号，v4.0 用 A-Z 字母前缀（GB/T 4754 国民经济行业分类习惯）。
2. **目录合并**：部分 v3.x L1 下细分了多个目录（数字编号相同），v4.0 一对一映射到不同字母目录。
   - 例：`02-化工与新材料/` + `02-能源与电力/` + `02-采矿与冶金/` + `02-金属制品与通用机械/` 拆分到 `G/` + `K/` + `B/` + `H/`。
3. **文件命名风格**：v3.x 文件名以「职业名」命名（如 `植保工.md`），v4.0 文件名以「真实姓名」命名（如 `傅琳.md`）。
4. **目录层级**：v3.x 是 L1 → L2（数字前缀）三层扁平；v4.0 是 L1 字母 → L2 数字 → L3 中文 的五层结构。
