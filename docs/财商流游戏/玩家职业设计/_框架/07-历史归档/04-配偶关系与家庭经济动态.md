# 财商流游戏 · 配偶关系与家庭经济动态

## 3. 配偶画像库（5 类）

> 配偶的**财务数据**见《规则与经济系统》§10.3，本节仅给出配偶的**画像**。
> 当玩家抽到"结婚事件"时，从配偶库随机抽 1 张；离婚后配偶所有资源移除（包括人脉、子女归属权视双方议定）。

### 3.1 全职太太/主夫

- **典型人物**：王晓燕，女，32 岁，大专，婚前做过 3 年会计
- **性格**：善于持家、关注细节、社交圈较小
- **画像钩子**：丈夫加班时独自做晚饭，关注小红书育儿
- **婚姻动力学**：玩家需要为家庭提供稳定收入，否则离婚事件触发概率 +30%

### 3.2 普通职员

- **典型人物**：李铭，男，34 岁，本科，物业公司主管
- **性格**：稳定、本分、缺乏理财意识
- **画像钩子**：每月工资全数上交，自己零花钱 1,500
- **婚姻动力学**：能贡献稳定主动收入，但不会主动提出投资建议

### 3.3 专业人士

- **典型人物**：张静，女，33 岁，硕士，二甲医院主治医师
- **性格**：独立、有主见、职业繁忙
- **画像钩子**：经常值夜班，回家后直接休息
- **婚姻动力学**：双高收入家庭，但时间稀缺；理财决策容易"快速拍板"

### 3.4 创业者

- **典型人物**：陈飞，男，35 岁，本科，二线城市小型互联网公司创始人
- **性格**：激进、感性、抗压能力强
- **画像钩子**：经常出差，朋友圈全是行业大会
- **婚姻动力学**：收入波动大，可能某月 0 收入，也可能某月 5 万；离婚事件触发概率 +15%

### 3.5 自由职业

- **典型人物**：Lina，女，31 岁，本科，独立设计师
- **性格**：自由、灵活、不喜约束
- **画像钩子**：工作时间不固定，喜欢下午茶
- **婚姻动力学**：中等收入 + 中等时间自由，但社保公积金需要自己缴纳（影响公积金贷款额度）
