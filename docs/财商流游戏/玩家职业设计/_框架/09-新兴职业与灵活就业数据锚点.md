1. **WebSearch × 43** — 每象限 8–12 个查询，覆盖宏观规模、收入分位、社保参与、政策文件、典型案例。

## 2. 灵活就业（5 类）

### 2.1 外卖骑手

**就业形态**：即时配送平台（美团 / 饿了么）专送 + 众包双轨。2024 年美团 745 万骑手、饿了么 400 万骑手（注册口径，含兼职）。**众包骑手**工作时间自由、按单结算，被平台认定为「独立个体工商户 / 兼职人员」；**专送骑手**有固定站点 / 排班，受平台劳动管理更强。

**月收入分位**（2025 年最新调研汇总）：

| 城市级别 | 专送骑手月收入 | 众包骑手月收入 | 备注 |
|---|---:|---:|---|
| 一线（北上广深） | 10,100 – 12,500 元 | 6,000 – 9,000 元 | 高频骑手 |
| 三四线城市 | 6,900 – 7,800 元 | 4,500 – 6,500 元 | |
| 全国平均（美团调研） | 约 7,500 元 | 约 6,500 元 | 同比 2024 +10% |

**收入分位**（美团研究院 2023–2024）：
- 11.5% 骑手月入 > 10,000 元
- 35.7% 骑手月入 5,000 – 8,000 元
- 30.5% 骑手月入 3,000 – 5,000 元
- 中位数 ≈ 6,000 – 7,500 元（含一线加班奖励）

**社保参与率**（2025 调研）：全国众包骑手社保覆盖率不足 **15%**。美团约 11%、饿了么约 15%。新就业形态职业伤害保障试点（2024.07 启动）已惠及 500 万人，美团骑手新增参保近 100 万人，累计赔付 > 4.9 亿元。

**年龄 / 性别 / 地区**：男 88% / 女 12%；20–40 岁占 80%；主要分布在「CN-E-华东」（长三角外卖密度最高）、CN-S-华南（珠三角）、CN-N-华北（北京/天津）。

**典型压力源**：
1. 交通安全 / 事故风险（电动车上楼、超速、雨天路滑）
2. 算法派单压力 / 差评罚款
3. 跨省跨市流动性，社保转移接续困难
4. 收入波动大，「以罚代管」现象
5. 工作时间模糊（10–14 小时常态）

**数据来源**：
- 国家邮政局《2024 年度快递员收入报告》
- 美团研究院《2024 年度骑手就业报告》
- 人社部新就业形态职业伤害保障试点报告
- https://www.gov.cn/zhuanti/2026nztj/2026qglh/yw/202603/content_7061640.htm
- https://www.mohrss.gov.cn/

### 2.2 网约车司机

**就业形态**：聚合平台（滴滴 / 高德 / 曹操 / T3 / 如祺）+ 双证合规（车辆运输证 + 驾驶员从业资格证）。91% 司机驾驶新能源车（充电成本低）；88% 司机多平台接单；72% 因「找不到其他工作」入行。

**月收入分位**（2025 调研）：

| 收入区间 | 占比 |
|---|---:|
| < 3,000 元 | **44.62%** |
| 3,001 – 5,000 元 | **38.06%** |
| 5,001 – 8,000 元 | 13.29% |
| 8,001 – 12,000 元 | 3.47% |
| > 12,000 元 | 0.56% |
| **中位数 ≈ 3,000 元** | |

> **注**：网约车**中位数显著低于外卖骑手**——主要原因是 49% 司机日均工作 > 10 小时，但单量单价双降 + 平台抽成 20%+ 拉低实际到手。

**从业年限**：64% 司机从业 > 2 年；从 1 年 = 30% 司机曾考虑转行。

**年龄 / 性别 / 地区**：男 92% / 女 8%；35–55 岁占 70%；CN-E-华东（江浙沪）> CN-S-华南（广深）> CN-N-华北。

**典型压力源**：
1. 单量下滑 + 平台抽成（聚合平台最高抽成 25%）
2. 油电切换 / 车辆合规成本
3. 疲劳驾驶（日均 > 10 小时占 49%）
4. 违章 / 投诉罚款
5. 无五险一金，仅平台商业意外险

**数据来源**：
- 中国劳动和社会保障科学研究院《新就业形态劳动者权益保障报告》
- 交通运输部网约车合规化通报
- 地方人大政协提案答复（2025）

### 2.3 快递员

**就业形态**：加盟制快递（通达系）+ 直营（顺丰 / 京东）+ 众包（达达 / 美团跑腿 / 闪送）。2024 年全国快递业务量 1,500 亿件+，从业人员约 500 万。

**月收入分位**（2025 国家邮政局数据）：

| 模式 | 月收入区间 | 旺季峰值 |
|---|---:|---|
| 加盟制专送 | 5,000 – 8,000 元 | 8,000 – 12,000 元 |
| 直营（顺丰/京东） | 6,000 – 9,000 元 | 12,000 – 15,000 元 |
| 众包 / 同城 | 3,000 – 12,000 元 | 15,000 – 20,000 元 |

**社保参与率**：直营模式较高（顺丰 70% / 京东 60%），加盟制 < 30%，众包 < 15%。

**年龄 / 性别 / 地区**：男 90% / 女 10%；30–50 岁占 75%；CN-E-华东占比最高（义乌/广州/上海三大枢纽）。

**典型压力源**：
1. 末端派送时效罚款（618 / 双 11 高峰期日均 600+ 单）
2. 客户投诉 / 暴力分拣
3. 加盟商欠薪
4. 跨区域跨省派送社保转移

**数据来源**：
- 国家邮政局《2024 年度快递员收入报告》（2025-01）
- https://www.51job.com/report（2025 中国蓝领就业市场报告）

### 2.4 直播带货 / 达人

**就业形态**：全职主播（MCN 签约）+ 兼职主播 + 品牌自播 + 达人探店/测评。2024 年人社部将「网络主播」正式纳入职业分类大典（19 个新职业之一）。

**月收入分位**（2025 调研）：

| 类型 | 月收入 | 备注 |
|---|---:|---|
| 头部主播（李佳琦 / 薇娅级别） | 100 万 + | < 10 人 |
| 中腰部（10w – 100w 粉） | 1.5 万 – 5 万 | |
| 小主播（1w – 10w 粉） | 6,000 – 15,000 元 | 底薪 + 佣金 |
| 新人 / 助理 | 4,000 – 8,000 元 | |
| 行业平均 | **约 8,000 元** | |

> **关键结构性变化（2025）**：行业从「流量驱动」转向「产品驱动」，中腰部主播 ROI 最高，头部主播收入透明化（税务监管加强），新人入场难度上升。

**佣金模式**：销售额 10% – 30%；部分垂类（美妆/食品/家居）可更高。

**年龄 / 性别 / 地区**：女 70% / 男 30%（美妆/服饰类更高）；20–35 岁占 80%；CN-E-华东（杭州/上海MCN 集聚）+ CN-S-华南（广州/深圳）。

**典型压力源**：
1. 流量焦虑 / 数据波动
2. 平台规则频繁调整
3. 选品 / 供应链风险
4. 直播时长长（4–8 小时常态）
5. 售后 / 退货纠纷

**数据来源**：
- 人社部 2024 年新职业目录公告（2024-07-31）
- 智联招聘《2025 新就业形态报告》
- 艾瑞咨询《2025 中国直播电商行业研究报告》

### 2.5 众包跑腿（同城速递）

**就业形态**：UU 跑腿 / 达达快送 / 闪送 / 美团跑腿 / 饿了么跑腿。**单价高 + 时效要求高 + 高单价激励**，对骑手工作强度要求高。

**月收入分位**（2025 实测）：

| 平台 | 单价 | 月收入 | 备注 |
|---|---:|---:|---|
| 闪送 | 50+ 元/单 | 8,000 – 12,000 元 | 高强度 |
| 达达快送 | 8 – 12 元/单 | 6,000 – 12,000 元 | 商超/生鲜 |
| 美团众包 | 6 – 10 元/单 | 6,000+ 元 | 订单量最大 |
| UU 跑腿 | 多元（代买/代排队） | 5,000+ 元 | |

**UU 跑腿官方分级**（来自 uupt.com/driver.htm）：

| 等级 | 日均时长 | 月入参考 |
|---|---|---:|
| 入门跑男 | 3–5 小时 | 4,000+ 元 |
| 精英跑男 | 6–8 小时 | 6,000+ 元 |
| 资深跑男 | 10–12 小时 | 10,000+ 元 |

**成本扣除**：实际收入减 15%–20%（电动车维护 / 换电日均 70 元、商业保险 3 元/天、通讯费、餐食、罚款）。

**年龄 / 性别 / 地区**：男 85% / 女 15%；22–40 岁占 75%；CN-E-华东 + CN-N-华北（北京/上海/杭州）。

**典型压力源**：
1. 时效压力（闪送 1 小时 / 达达 30 分钟）
2. 单价波动
3. 远距离单 + 加急单高风险
5. 平台扣罚（差评、超时）

**数据来源**：
- UU 跑腿官网（https://www.uupt.com/driver.htm）
- 哪都达 / 43626 网 / 淘宝好物网 2025 实测
- https://m.fsnews.com.cn/yxwd/202509/553273.html

## 3. AIGC / AI 新职业（5 类）

### 3.1 提示词工程师（Prompt Engineer）

**就业形态**：独立岗位（初级 / 中级 / 高级）+ 复合岗位（AI 产品经理 + Prompt 能力、AI 应用架构师 + Prompt）。**2024 上半年峰值 → 2025 年下半年回落**是本职业最大特征。

**月收入分位**（2025 BOSS 直聘 / 拉勾 / 猎聘数据汇总）：

| 级别 | 月薪 | 年薪 | 备注 |
|---|---:|---:|---|
| 初级（0–6 个月） | 8K – 15K | 10–18 万 | 基础文案 + 对话设计 |
| 中级（1–3 年） | 15K – 30K | 18–36 万 | 需行业背景知识 |
| 高级（资深） | 25K – 40K | 30–48 万 | 垂直领域专家 |
| 复合型人才 | 40K – 60K+ | 48–72 万+ | AI 产品经理 + 应用 |
| AI 应用架构师 | 40K – 100K | 48–120 万 | 技术架构 + 业务理解 |

**主要城市薪资分布**：

| 城市 | 岗位数 | 平均月薪 |
|---|---:|---:|
| 北京 | 2,800+ | 25K – 50K |
| 上海 | 2,400+ | 23K – 45K |
| 深圳 | 2,100+ | 22K – 43K |
| 杭州 | 1,600+ | 20K – 40K |
| 成都 | 900+ | 15K – 30K |

**关键趋势（2025–2026）**：
- 纯「提示词工程师」岗位需求**下降约 73%**，平均薪资**下降约 45%**
- 「从年薪百万到回归理性」只用了 18 个月
- 企业更倾向把 Prompt 作为通用技能，要求与编程 + 行业知识结合
- 「AI 应用开发工程师」岗位缺口超 120 万，月增 15%

**年龄 / 性别 / 地区**：男 75% / 女 25%；24–35 岁占 80%；CN-E-华东 + CN-N-华北（北京/上海/杭州）。

**典型压力源**：
1. 模型迭代快，技能保鲜期短（6–12 个月）
2. 「会调 prompt」贬值，向「会做 AI Agent」+「会做 RAG」迁移压力大
3. 头部企业 JD 高门槛（985 + 顶会论文 + 工程能力）
4. 远程办公易失业，无稳定团队归属

**数据来源**：
- BOSS 直聘《2025 春季人才吸引力报告》
- 拉勾网《2025 大模型人才报告》
- 猎聘《2025 AI 岗位人才洞察》
- https://blog.csdn.net/datian1234/article/details/156150793

### 3.2 AIGC 内容创作者

**就业形态**：AI 漫剧 / AI 短视频 / AI 绘画接单 / AI 头像 / AI 修复老照片 / 数字人 / 虚拟主播代运营。**两极分化严重**——头部月入 10 万+，多数 < 10 元/月。

**收入分位**（2025 调研）：

| 类型 | 月收入 | 备注 |
|---|---:|---|
| 头部 AI 漫剧 | 10 万 – 100 万 | 全国月入 > 20 万的创作者 < 100 人 |
| 垂类 AI 绘画接单 | 1.5 万 – 2 万 | 广州 / 小红书头部 |
| 普通 AI 漫剧 | < 10 元/月 | 80% 作品播放量 < 百万 |
| 个人 AI 制图兼职 | + 6,000 元 | 副业形式 |

**变现路径**：

| 方向 | 收入水平 |
|---|---|
| AI 绘画定制 | 单张 19.9 – 1,200 元（熟手 300 – 2,000+） |
| AI 短视频 / 探店 | 单条 500 – 2,000 元（10 店/月即可过万） |
| AI 视频平台分成 | 万次播放 50 – 200 元 |
| AI 文案代写 | 单篇 50 – 1,000 元 |
| 知识付费（AI 教程） | 9.9 – 998 元/份 |
| 数字人代运营 | 1,500 – 5,000+/账号/月 |

**年龄 / 性别 / 地区**：男 55% / 女 45%；20–35 岁占 85%；CN-E-华东 + CN-S-华南。

**典型压力源**：
1. 版权红线（商用必须「原创声明」，规避真人肖像）
2. 平台资源向优质原创集中
3. 产能瓶颈（个人 AI 漫剧日均仅 ~2 分钟内容）
4. AI 漫剧 2025 规模 168 亿（2026 预计 > 240 亿），但头部效应极强

**数据来源**：

### 3.3 AI 产品经理

**就业形态**：大模型应用产品经理 / AIGC 产品经理 / Agent 方向产品经理 / 多模态产品经理。相较传统产品经理**溢价 30%–50%**。

**月收入分位**（2025 招聘数据）：

| 级别 | 月薪 | 备注 |
|---|---:|---|
| 应届 / 初级 | 15K – 25K | |
| 中级（2–4 年） | 25K – 50K | 一线城市头部企业可达 60K+ |
| 高级 / 资深 | 50K – 80K | |
