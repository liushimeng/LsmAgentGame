## 1. 定位声明

### 1.1 一句话定位

> **完全模拟真实世界财富流动，覆盖个人、群体、社会三层的真实决策、思想、感知、执行**。

### 1.2 三层含义

| 层级 | 含义 | 在 65 字段中的映射 |
|---|---|---|
| **个人** | 玩家个体的财务决策与心理过程 | identity / health / career / income / finance / protection / family / housing / psych / goals / transport / 6 个 v1.1 新字段 |
| **群体** | 家庭、家族、同事、社会网络的影响 | family / housing / goals.opportunities / birth_family（v1.1 新）/ 配偶/父母/子女联动字段 |
| **社会** | 行业、地域、阶层、政策的影响 | industry_l1-l3 / housing_city / birth_province / generation / education 分布 / risk_preference（v1.1 新） |

### 1.3 v1.1 的边界

- **个人层强化**：6 个新字段聚焦**人格 / 行为 / 风险 / 出身 / 人生经历 / 开局**6 维，覆盖用户需求 #3 清单。
- **群体层强化**：`birth_family` 显式承载「出身家庭」信号；`life_story` 时间线承载「家族代际」事件。
- **社会层强化**：`risk_preference` 与 `personality` 联合表达社会阶层（保守中产 / 激进精英），
  `opening_hook` 锚定宏观社会事件（如行业政策、家庭政策变动）。

### 1.4 与既有 18 位 P 卡的关系

P01-P18 是「黄金样本」，每张都是 v1.1 6 字段的**显式标注案例**。
其余 75,097 张 N 卡由 `enrich_holistic_v44.py` **确定性推导**（v1.1 `assigned` 标注）。
Agent 教练在游戏中按 P 卡画像反推对手 AI，逻辑统一。

## 3. v1.1 六字段的确定性推导规则

> 全部规则在 `scripts/财商流游戏知识库/enrich_holistic_v44.py` 中实现并可复现。
> 同份 frontmatter 输入多次推导结果完全一致；不调用 LLM。

### 3.1 `personality` —— 人格特征（13 词，2-4 个标签）

**词库**：谨慎稳健 / 外向社交 / 尽责坚韧 / 开放求新 / 情绪稳定 / 风险偏好高 / 风险偏好低 /
细腻敏感 / 果决有力 / 顺从协作 / 独立自主 / 理想主义 / 务实主义

**推导信号 + 决策树**：

| 维度 | 信号 | 标签 |
|---|---|---|
| 风险偏好 | `biases` 含 `风险厌恶` | 风险偏好低 |
| 风险偏好 | `biases` 含 `风险寻求` | 风险偏好高 |
| 行业大类 | `industry_l1 ∈ {S, T, P}` | 开放求新 |
| 行业大类 | `industry_l1 ∈ {M, O, R}` | 外向社交 |
| 行业大类 | `industry_l1 ∈ {A, B, E}` | 尽责坚韧 |
| 行业大类 | `industry_l1 ∈ {L, H, J}` | 果决有力 |
| 压力等级 | `stress_level = 高` | 细腻敏感 |
| 压力等级 | `stress_level ∈ {中, 低}` | 情绪稳定 |
| 就业形态 | `employment ∈ {个体经营, 自由职业}` | 独立自主 |
| 就业形态 | `employment ∈ {平台就业, 灵活就业, 退休返聘}` | 务实主义 |
| 就业形态 | `career_stage ∈ {资深, 管理}` | 果决有力 / 理想主义 |
| 就业形态 | 其他 | 顺从协作 |

**组装**：按 [风险 → 行业 → 压力 → 就业] 取 4 个，去重 + 截断到 2-4 个。

### 3.2 `behavior_traits` —— 行为特征（10 词，2-4 个标签）

**词库**：记账习惯 / 冲动消费 / 货比三家 / 长线规划 / 风险管理 / 保守储蓄 / 积极投资 /
月光族 / 精打细算 / 冲动决策

**推导信号 + 决策树**：

| 储蓄水平 | `savings_rate > 0.5` | 保守储蓄 |
| 储蓄水平 | `savings_rate > 0.2` | 记账习惯 |
| 储蓄水平 | `savings_rate > 0.05` | 精打细算 |
| 储蓄水平 | `savings_rate ≤ 0.05` | 月光族 |
| 决策风格 | `biases ∈ {过度自信, 即时满足}` | 冲动决策 |
| 决策风格 | `len(goals_short) ≥ 3` | 长线规划 |
| 决策风格 | `biases ∈ {损失厌恶, 保守}` | 货比三家 |
| 风险行为 | `industry_l1 = Q` + 风险寻求 | 积极投资 |
| 风险行为 | `insurance/funds` 非空 | 风险管理 |
| 风险行为 | `biases 含 风险厌恶` | 保守储蓄 |

### 3.3 `risk_preference` —— 风险偏好（3 档 enum）

**推导信号 + 决策树**：

```
[1] 强信号优先：
    biases 含「风险厌恶」                    → conservative
    biases 含「风险寻求」 + ist=低            → aggressive
[2] 结构性判断：
    ist=低 + 有房贷                          → conservative
    无房产 + sr > 0.3                       → balanced
    有房产 + ist ∈ {高, 中} + sr > 0.2       → balanced
    biases 含「风险寻求」                    → aggressive
    ist=高 + 无房贷 + sr < 0.15              → aggressive
[3] 默认                                  → balanced
```

### 3.4 `birth_family` —— 出生家庭背景（6 档）

**推导信号 + 决策树**：

```
[1] 教育 = 博士        → 一线白领（如城市是一线）/ 知识家庭
[2] 教育 = 硕士        → 一线白领（如城市是一线）/ 知识家庭
[3] 教育 ∈ {本科, MBA, EMBA} → 一线白领（如城市是一线）/ 城市中产
[4] 教育 = 大专        → 城市中产（如城市是一线）/ 城镇个体户
[5] 教育 = 中专        → 县城工薪（含县/乡关键词）/ 城镇个体户
[6] 教育 = 高中        → 县城工薪
[7] 教育 ∈ {初中, 缺失} → 农村务农（非一线）/ 县城工薪（一线）
```

**城市启发词**：县/乡/镇/村/屯（命中即视作「县城/乡镇」）。

### 3.5 `life_story` —— 人生经历时间线（3-6 条）

**推导信号 + 决策树**：

```
[1] 出生         age=0     必出
[2] 求学         edu_start_age  按学历查表（博士 22-29 / 硕士 22-26 / 本科 18-22 ...）
[3] 毕业入职     edu_end_age   按学历查表
[4] 结婚         marital 已婚/再婚：m_age = max(22, age - max(children_ages) - 2)
[5] 生育         children_ages 非空 + 已婚：first_child_age = age - max(children_ages)
[6] 购房         housing_tenure ∈ {自有, 自建}：buy_age = max(25, age - 10)
[7] 当前阶段     age       必出
```

**排序 + 去重**：按 age 升序，去重相同 age；上限 6 条。

### 3.6 `opening_hook` —— 开局钩子（30-50 字）

**推导信号 + 模板**：

```
{城市}，{他/她}面对{第一个 stress_source[:8]}，
目标「{第一个 goal.text[:14]}」；
{personality[0]}的{他/她}需在本回合做出取舍
```

**清理**：去除连续 `，`/`；`，按 30-50 字截断（不足补「，财务抉择就在眼前」；过长截断至 47 字 + `…`）。

## 4. 确定性推导 vs LLM 富化的分工

| 工作面 | 确定性推导（enrich_holistic_v44.py） | LLM 富化（patch_cards.py / SubAgent） |
|---|---|---|
| **6 新字段填充** | ✅ 全库 75,115 张 100% 推导 | ❌ 不再重复推导 |
| **既有字段修正** | ❌ 不动 | ✅ 富化时允许补缺/修正（如 `health_conditions` 的人名碎片） |
| **v1.1 字段深化** | ❌ 仅给初始值 | ✅ 必填（尤其 `opening_hook` 必须从 30-50 字升级到 150-350 字场景） |
| **正文 §6/§7/§8 富化** | ❌ skeleton 卡只填「标签列表」 | ✅ rich 卡按 §3.1-§3.3 规格填写 5 行 / 完整场景 |
| **跨字段一致性校验** | ✅ 严格（同一信号产生一致标签） | ✅ 加倍（`biases` 含某偏差时必须触发对应事件） |

### 4.1 边界硬约束

1. **`risk_preference` 与 `birth_family` 是定值**：富化时**不得改写**，仅可补充支撑依据到 `_rich.basis`。
2. **`personality` / `behavior_traits` 至少保留 1 个 assigned 标签**：富化时不得全删替换。
3. **`opening_hook` 必替换**：富化时从骨架的 30-50 字升级为完整 150-350 字场景（按 `08-富化规约.md` §3.2）。
4. **`life_story` 事件数稳定**：富化可在每条 event 后追加细节，但**不得增删年龄节点**。

### 4.2 验收路径

- 全库 75,115 张卡由 `enrich_holistic_v44.py` 一次性推导（v1.1 `assigned` 100% 填充）；
- 富化卡（`richness: rich`）由 SubAgent 在富化时按 §3 深化（不重做 assigned 推导）；
- `work/enrich_v44_report.json` 记录全库闸门与抽样结果；
- 任意时刻运行 `work/verify_enrich_v44.py` 与 `work/verify_rich_body.py` 校验一致性。
