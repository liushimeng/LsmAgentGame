## 2. 派生规则

直接由 `age` 派生：

```python
if 18 <= age <= 24: stage = 'S1'
elif 25 <= age <= 34: stage = 'S2'
elif 35 <= age <= 44: stage = 'S3'
elif 45 <= age <= 54: stage = 'S4'
elif 55 <= age <= 64: stage = 'S5'
elif age >= 65: stage = 'S6'
```

辅助字段：
- `career_stage` 应与 S 阶段大致对齐；不一致时取 `age` 为准。
- `goals_short` 中 horizon 字段用于校验目标分布（短/中/长期）。

## 3. 各阶段典型画像

### S1 探索期（18–24）

- 职业：应届生、实习生、初级技工、学徒
- 收入：低（3000–6000）
- 资产：极少 / 负资产（助学贷款）
- 财商痛点：起步资金、社保、信用建立
- 目标：找到方向、第一笔储蓄、职业资格
- 心魔偏差：即时满足、过度自信
- 占比：约 12%

### S2 建仓期（25–34）

- 职业：初级 → 骨干技术人员 / 基层管理者
- 收入：中低（6000–15000）
- 资产：起步 / 第一套房 / 公积金
- 财商痛点：首套房、应急金、保险配置、婚姻支出
- 目标：买房、结婚、事业起步、第一笔投资
- 心魔偏差：即时满足（消费主义）、损失厌恶
- 占比：约 25%

### S3 高峰期（35–44）

- 职业：骨干 / 资深 / 中层管理
- 收入：中-高（12000–35000）
- 资产：房贷 + 金融资产 + 教育金压力
- 财商痛点：房贷优化、教育金、税务、养老起步
- 目标：事业高峰、子女教育、父母医疗
- 心魔偏差：禀赋效应、沉没成本、确认偏误
- 占比：约 28%

### S4 转型期（45–54）

- 职业：资深 / 高管 / 转型期
- 收入：高但波动（15000–50000+）
- 资产：房产 + 金融资产（成熟）
- 财商痛点：职业转型 / 中年危机 / 子女教育金兑现
- 目标：转型 / 创业 / 海外配置 / FIRE 准备
- 心魔偏差：风险厌恶（年龄相关）、现状偏见
- 占比：约 18%

### S5 退场期（55–64）

- 职业：高管 / 半退休 / 退休返聘
- 收入：高但下降
- 资产：成熟，准备传承
- 财商痛点：退休规划、医疗、保险、传承
- 目标：还清房贷、完成养老金第三支柱、退休筹备
- 心魔偏差：风险厌恶、禀赋效应
- 占比：约 11%

### S6 安养期（65+）

- 职业：退休 / 退休返聘
- 收入：养老金 / 退休金 / 子女供养
- 资产：已配置，进入消耗期
- 财商痛点：医疗支出、反欺诈、遗产规划
- 目标：健康养老、资产传承、避免诈骗
- 心魔偏差：风险厌恶、即时满足（医疗/保健品）
- 占比：约 6%
