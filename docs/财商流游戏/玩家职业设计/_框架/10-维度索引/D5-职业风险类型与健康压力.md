## 1. 职业风险类型（六类）

| 编号 | 类型 | 特征职业 | 健康影响 |
|---|---|---|---|
| **R1 体力型** | 久站负重 / 高温 / 重体力 | 建筑工人、外卖骑手、快递员、护理员、农民 | 腰椎 / 关节 / 应激损伤 |
| **R2 应酬型** | 高频饮酒 / 餐饮 / 销售 | 销售经理、公关、媒体、广告、个体户 | 应酬肝 / 慢性胃病 / 心理压力 |
| **R3 久坐型** | 长时间电脑 / 颈椎 | 程序员、设计师、会计、客服 | 颈椎 / 视疲劳 / 久坐 |
| **R4 心理型** | 高压力 / 高情绪劳动 | 教师、医生、社工、客服、管理者 | 焦虑 / 失眠 / 情感透支 |
| **R5 数字替代高危型** | AI / 自动化替代风险 | 基础客服、初级文案、流水线工人、收银员 | 失业压力 / 转型焦虑 |
| **R6 监管型** | 政策变化 / 监管风险 | 教培、房地产、互联网平台、金融 | 政策风险 / 行业动荡 |

## 2. 派生规则

| 来源字段 | 派生逻辑 |
|---|---|
| `occupation` | 关键词匹配（如「外卖骑手」→ R1） |
| `work_intensity.risk` | 高 → 优先归 R1–R4 中对应类型 |
| `health_risks[]` | 「久站负重」→ R1 / 「应酬饮酒」→ R2 / 「长时间用眼」→ R3 等 |
| `health_grade` | C 重大风险 → 任何类型都可能 |

**优先级**：`health_risks` > `work_intensity.risk` > `occupation` 关键词匹配。

## 3. 各类型典型画像

### R1 体力型

- 典型职业：外卖骑手、快递员、矿工、装配工、建筑工人、护理员、农民
- 行业域：N 交通运输、L 建筑、A 农林牧渔、Y 居民生活服务、H 通用机械
- 健康风险：腰椎、关节、肌肉劳损、心血管（重体力）
- 健康档分布：A 30% / B 50% / C 20%
- 心理压力：中（体力累而非心累）
- 失业风险：中（体力活需求稳定，但收入增长空间小）
- 数字替代风险：低（需要真实在场）
- 占比：约 22%

### R2 应酬型

- 典型职业：销售经理、公关、客户经理、广告 AE、媒体记者、个体工商户
- 行业域：M 批发零售、V 文化传媒、F 医药（医药代表）、Q 金融
- 健康风险：应酬肝、慢性胃病、痛风、心理压力
- 健康档分布：A 25% / B 50% / C 25%
- 心理压力：高
- 失业风险：中（业绩压力）
- 数字替代风险：中
- 占比：约 15%

### R3 久坐型

- 典型职业：程序员、设计师、会计、客服、行政、数据录入
- 行业域：P 信息、R 专业服务、Q 金融、G 化工（研发）
- 健康风险：颈椎病、视疲劳、腰椎、肥胖、抑郁
- 健康档分布：A 40% / B 50% / C 10%
- 心理压力：中-高
- 失业风险：中（行业波动）
- 数字替代风险：高（AI 工具冲击）
- 占比：约 28%

### R4 心理型

- 典型职业：教师、医生、社工、护士、客服、管理者、警察、法官
- 行业域：T 教育、U 医疗、X 社会组织、W 公共管理
- 健康风险：焦虑、失眠、情感透支、抑郁、慢病
- 健康档分布：A 20% / B 50% / C 30%（最高）
- 心理压力：极高
- 失业风险：低（在编稳定）
- 数字替代风险：低
- 占比：约 15%

### R5 数字替代高危型

- 典型职业：基础客服、初级文案、流水线工人、收银员、翻译、初级程序员、卡车司机
- 行业域：所有行业都有，集中在 M 批发零售、P 信息、N 交通运输
- 健康风险：失业焦虑、转型压力
- 健康档分布：A 50% / B 40% / C 10%
- 心理压力：高（不安全感）
- 失业风险：极高（5 年内显著）
- 数字替代风险：极高
- 占比：约 12%

### R6 监管型

- 典型职业：教培、房地产中介、互联网平台、金融业务、外贸、加密行业
- 行业域：T 教育（教培）、L 建筑/房地产、P 信息（互联网）、Q 金融
- 健康风险：政策焦虑、行业动荡
- 健康档分布：A 30% / B 55% / C 15%
- 心理压力：高（不确定性）
- 失业风险：中-高（行业波动）
- 数字替代风险：低（监管而非技术替代）
- 占比：约 8%
