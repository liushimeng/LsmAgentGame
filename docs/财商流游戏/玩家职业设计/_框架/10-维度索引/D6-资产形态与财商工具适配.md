## 1. 资产形态定义（五类）

| 编号 | 类型 | 特征 | 占比目标 |
|---|---|---|---:|

| **A2 房产型** | 主要资产为 1 套自住房（可能含贷款） | 工薪典型 | 35% |

## 2. 派生规则

| 来源字段 | 派生逻辑 |
|---|---|
| `housing_tenure` | 自有/自建 → 含房产 |
| `assets[]` | 房产 / 现金存款 / 金融资产 / 经营资产 → 分类 |
| `net_worth` | < 0 → A1，0–100 万 → A2/A3，100–500 万 → A3/A5，≥500 万 → A5 |

**优先级**：资产分类 → 净值 → 房产状态。

## 3. 各类型典型画像

### A1 无产型（15%）

- 特征：无房产 / 净负债 / 仅现金 < 5 万
- 主导行业：N 交通（灵活就业）、Y 居民生活服务、X 社会组织、A 农林牧渔
- 主导年龄：18–28
- 财商工具适配：应急金（最重要）、信用管理、社保连续性
- 财商痛点：起步资金、抗风险能力低
- 典型场景：刚毕业 / 失业 / 灵活就业初期

### A2 房产型（35%）

- 特征：1 套自住房（可能含贷款）
- 主导行业：所有行业
- 主导年龄：30–45
- 财商工具适配：房贷优化、公积金、保险
- 财商痛点：房贷压力、教育金、保险不足
- 典型场景：典型工薪家庭

### A3 金融资产型（25%）

- 特征：金融资产（基金 / 股票 / 存款）占大头
- 主导行业：F 医药、Q 金融、P 信息、R 专业服务
- 主导年龄：28–45
- 财商工具适配：基金定投、股票、债券、税务规划
- 财商痛点：投资风险、税务、配置平衡
- 典型场景：城市新中产、FIRE 倾向

### A4 经营资产型（15%）

- 特征：商铺 / 企业股权 / 农场 / 个体户经营资产
- 主导行业：M 批发零售、A 农林牧渔、O 住宿与餐饮、C 食品饮料
- 主导年龄：35–55
- 财商工具适配：经营贷、企业税务、合伙机制
- 财商痛点：经营风险、现金流、税务
- 典型场景：个体户、小微企业主

### A5 多资产组合型（10%）

- 特征：房产 + 金融资产 + 经营资产综合
- 主导行业：所有行业，Q 金融、R 专业服务、P 信息密度高
- 主导年龄：40–60
- 财商工具适配：综合规划、信托、传承
- 财商痛点：资产隔离、传承、税务、跨境
- 典型场景：高净值、FIRE 实现者
