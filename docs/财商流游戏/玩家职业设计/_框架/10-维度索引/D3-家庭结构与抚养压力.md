## 3. 各家庭类型典型画像

### F1 三孩家庭（8%）

- 主导行业：L 建筑/房地产、M 批发零售、A 农林牧渔（三孩政策下乡村比例较高）
- 主导年龄：35–44
- 月支出压力：极高（教育 + 抚养 + 老人赡养）
- 财商痛点：教育金储备（3 个子女）、房贷、夫妻一方可能放弃工作
- 收入阶层：L2–L3 为主，L4 困难
- 心魔偏差：损失厌恶、即时满足（教育投入权衡）
- 典型卡示例：`.../45-54/N900xxxx-...`

### F2 二孩家庭（25%）

- 主导行业：所有行业均衡分布
- 主导年龄：30–44
- 月支出压力：高
- 财商痛点：教育金（双份）、房贷、夫妻工作-家庭平衡
- 收入阶层：L2–L3 为主
- 典型卡：城市中产典型

### F3 一孩家庭（28%）

- 主导行业：所有行业，城市高学历占比高
- 主导年龄：28–40
- 月支出压力：中-高
- 财商痛点：教育投入「鸡娃」、房产升级、父母医疗
- 收入阶层：L2–L3
- 心魔偏差：确认偏误（教育投资）、损失厌恶
- 典型卡：新中产典型

### F4 新婚/丁克家庭（12%）

- 主导行业：F 医药、U 医疗、T 教育、P 信息（高知双职工）
- 主导年龄：25–34
- 月支出压力：低-中
- 财商痛点：早期资产积累、FIRE 可能性
- 收入阶层：L2（新中产占比高）
- 心魔偏差：即时满足（精致穷）
- 典型卡：高学历双职工

### F5 单亲家庭（8%）

- 主导行业：所有行业，Y 居民生活服务、X 社会组织比例偏高
- 主导年龄：30–45
- 月支出压力：极高（单收入）
- 财商痛点：应急金、保险、子女教育
- 收入阶层：L3–L4
- 心魔偏差：风险厌恶（保守）、心理压力
- 典型卡：城市单亲妈妈 / 农村单亲爸爸

### F6 单人家庭（19%）

- 主导行业：P 信息、F 医药、V 文化（年轻人密集）
- 主导年龄：22–35 集中，45+ 渐少
- 月支出压力：低-中
- 财商痛点：储蓄、社保连续性、孤独成本
- 收入阶层：L3–L4 偏高（年轻人低收入多）
- 心魔偏差：即时满足、月光
- 典型卡：应届生、独居青年
