# D2 · 收入阶层与资产画像（v4.3 维度索引）

> 本文件是 v4.3 第二维度切片——D2 收入阶层。
> 数据源：现有 73,598+ 张人物卡的 `income_monthly` / `household_monthly` / `net_worth` 字段派生。

---

## 1. 收入阶层定义（五档）

| 阶层 | 月收入家庭（家庭月入） | 净资产 | 占比目标（社会真实分布） |
|---|---|---|---:|
| **L1 高净值阶层** | ≥ 5 万元 | ≥ 500 万元 | 3% |
| **L2 新中产阶层** | 2.5 万–5 万 | 100 万–500 万 | 12% |
| **L3 工薪阶层** | 8000–2.5 万 | 20 万–100 万 | 45% |
| **L4 灵活就业阶层** | 4000–8000 | 0–20 万 | 25% |
| **L5 低收入/失业阶层** | < 4000 | < 0（净负债） | 15% |

> 划分依据：参考 2025 统计局公报 + 北大 CFPS + 人社部最低工资标准。卡池目标分布对应中国社会真实结构。

---

## 2. 派生规则

| 来源字段 | 取值 | 映射 |
|---|---|---|
| `income_monthly` | 单人月入 | L1 ≥ 35k / L2 18k–35k / L3 6k–18k / L4 3k–6k / L5 < 3k |
| `household_monthly` | 家庭月入 | L1 ≥ 50k / L2 25k–50k / L3 8k–25k / L4 4k–8k / L5 < 4k |
| `net_worth` | 净资产 | L1 ≥ 500 万 / L2 100–500 万 / L3 20–100 万 / L4 0–20 万 / L5 < 0 |

**优先级**：`household_monthly` > `net_worth` > `income_monthly`（家庭月入最能反映"可支配资源"）。

## 3. 各阶层典型画像

### L1 高净值阶层（3%）

- 职业：企业主、合伙人、高管、明星医生、知名律师、基金经理、AI 创业者
- 收入结构：年薪制 / 合伙分红 / 投资收益
- 资产形态：房产（≥2 套）+ 金融资产 + 经营资产
- 财商痛点：税务规划、财富传承、资产隔离、跨境配置
- 压力源：事业风险、政策风险、家庭关系
- 典型卡示例：`R-专业服务/R01-法律与合规/R0101-执业律师/.../N900xxxx-...`

### L2 新中产阶层（12%）

- 职业：技术骨干、中层管理、医生、主治医师、资深工程师、骨干教师
- 收入结构：固定薪资 + 年终奖 / 项目奖金
- 资产形态：1 套房贷 + 金融资产（基金 / 股票）
- 财商痛点：房贷优化、子女教育金、税务优化
- 压力源：房贷、子女教育、父母赡养
- 典型卡示例：`P-信息与通信技术/P07-软件工程/P0701-高级软件工程师/.../N901xxxx-...`

### L3 工薪阶层（45%）

- 职业：基层公务员、普通白领、技术工人、销售、普通教师、护士
- 收入结构：固定薪资
- 资产形态：1 套房贷 / 公积金 / 少量存款
- 财商痛点：储蓄率、应急金、保险配置
- 压力源：房贷、子女教育、父母医疗
- 典型卡示例：`M-批发零售与商贸流通/M01-零售门店/M0101-门店店长/.../N901xxxx-...`

### L4 灵活就业阶层（25%）

- 职业：外卖骑手、网约车司机、快递员、直播带货、自由设计师、个体工商户
- 收入结构：提成+底薪 / 项目制 / 季节波动
- 资产形态：少存款 / 电动车 / 无房产 / 合租
- 财商痛点：社保连续性、收入波动、应急金
- 压力源：收入不稳定、伤病风险、无晋升通道
- 典型卡示例：`N-交通运输与物流仓储/N01-快递与末端配送/N0137-快递小哥/.../N901xxxx-...`

### L5 低收入/失业阶层（15%）

- 职业：失业者、待业青年、残疾人就业、传统行业低收入者
- 收入结构：低保 / 临时工 / 救济金
- 资产形态：负资产 / 借款
- 财商痛点：负债管理、应急金、基本保障
- 压力源：生存压力、家庭矛盾、心理压力
- 典型卡示例：`X-社会组织与公益慈善/X01-社会工作/X0101-社区社工/.../N901xxxx-...`

## 5. 游戏场景下的用法

| 场景 | 切片方式 |
|---|---|
| 单人模式：选择 30–40 岁医生 | D4 × L2 × L3 = U 医疗 × 高新中产 × 主治 |
| 多人模式：6 人开局 | 各抽 L1 / L2 / L3 不同阶层，行业尽量分散 |
| 教学：演示房贷压力 | L3（工薪）+ L（建筑/房地产）+ 35–44 |
| 教学：演示投资风险 | L2（新中产）+ Q（金融）+ 35–44 |
| 真实社会模拟 | 按 §4 矩阵权重分布，让对局接近真实社会结构 |
