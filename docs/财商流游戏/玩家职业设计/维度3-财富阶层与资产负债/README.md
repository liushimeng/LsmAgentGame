## 1. 维度定位

财富阶层维度是财商模拟的**核心变量**。行业维度（DIM1）回答「这人做什么工作」，
而财富阶层维度回答「这人有多少钱、欠多少钱、靠什么赚钱」。

真实世界的财富流动同样由**非行业身份**驱动：
- 企业主的财富来自经营分红而非工资
- 收租者的收入与职业无关
- 拆迁户的资产是一次性暴富而非积累
- 失信者的困境与行业身份完全解耦

本维度按**净资产 / 月现金流 / 负债率 / 资产形态**拉开真实差距，
覆盖中国 2025-2026 财富分布的全部象限。

## 4. Schema v1.1 字段继承

维度卡继承 v4.4 全部 65 字段 + v4.5 新增维度字段族：

- `dimension: DIM3`
- `dimension_name: 财富阶层与资产负债`
- `dim_l2 / dim_l2_name`：所属 L2 细分
- `dim_l3 / dim_l3_name`：所属 L3 人群族
- `dim_tag`：人群标签
- `income_semantics`：统一 = "月度可支配现金流入"
- `income_composition`：收入构成（按阶层差异化工资/经营/财产性收入占比）
- `housing_province / migration_status / l4_basis: residence`：地理一致性
- `schema_version: '1.1'`
- `_gen_v45`：溯源章（生成时间/脚本/方法）

## 5. 路径形态

五段式 + 叶段（与 v4.4 行业树完全一致）：

```
维度3-财富阶层与资产负债/<L2>-<细分名>/<L3>-<人群族名>/<L4现居地区档>/<L5年龄段>/<编号>-<姓名>.md
```

**L4 地区档** = 现居省（`l4_basis: residence`），与籍贯解耦，
使「跨省流动人口」这一真实财富现象在路径上可见。

**L5 年龄段** = `16-24 / 25-34 / 35-44 / 45-54 / 55-64 / 65+ / XX-未知`

**示例**：
```
维度3-财富阶层与资产负债/DIM3-04-底层低收入阶层/DIM3-0401-城乡普通工薪阶层/CN-E-华东/25-34/N9025123-王建国.md
维度3-财富阶层与资产负债/DIM3-01-顶层财富阶层/DIM3-0101-大型企业主阶层/CN-S-华南/45-54/N9025001-陈砚青.md
```

## 7. 与既有 75k 库的兼容

1. **零冲突**：所有 DIM3 卡 `id` 在 `N9025000–N9026399` 区间内递增，
   与既有 `N0000001–N9019999` 零重叠；化名取自预分配块 `names_dim3.txt`。
2. **Loader 即插即用**：维度目录**无 `_` 前缀**，文档池索引阶段全量 walk 收录。
3. **字段双轨**：维度卡 `schema_version: '1.1'`（与既有 75k 卡的 `1.0` 并存，后端 loader 容错）。
4. **industry_l1 占位**：无行业归属人群置 `NA / NA00 / NA0000`（`occ_industry_num: '20'`）。
