# 财商流游戏 · 新生代 Z 世代与新业态职业档案（N31–N40）

> 本档案为 P01–P18 与 N01–N30 之后的补充，聚焦 2026 年中国新就业形态中**容易被忽略、但占比极大**的人群：
> **Z 世代学生兼职 / 应届毕业生 / 蓝领技工 / 跨境电商 / 宠物经济 / 知识付费 / 银发网红 / 闪送员 / AI 训练师 / 县乡个体户**。
> 这 10 个画像填补了现有档案的两处空白：
> 1. **没有"在校生/刚毕业/慢就业"的人生阶段**（学生贷款、毕业即失业、慢就业）；
> 2. **没有"县乡/下沉市场/银发再就业"的具体样本**（农村电商、乡镇教师、老年主播）。
>
> 计价为 2026 年人民币静态开局值；收入/支出为月口径，储蓄/负债为即时存量。健康 A=稳定，B=可控慢病或劳损，C=重大风险。
> 所有姓名为虚构，财务数据用于教学，不构成理财建议。

## 3. 财富与机制映射

1. **Z 世代人生阶段**（N31/N32）：学生贷款 + 应届身份 + 试用期 = "低收入高成本"陷阱；
   教育溢价与就业期望差是核心心理账户来源。
2. **中年技工焦虑**（N33/N38）：手艺折旧 + 自动化替代 = "沉没成本陷阱"；
   转型窗口在 35–40 岁，不行动就被时代推走。
3. **新业态高波动**（N34/N35/N36/N40）：经营贷 + 库存 + 平台依赖 = "现金流像过山车"；
   平台政策一变就是灭顶之灾。
4. **银发再就业**（N37）：被动收入极少，必须主动劳动；
   健康折旧是隐形炸弹，要为医疗留储备。
5. **新职业转型压力**（N39）：AI 既是工具也是替代品，"RLHF 训练师"这种职业本身可能被 AI 取代。
6. **县乡个体户**（N40）：熟人经济 + 路径依赖 + 子女接班 = "传承 vs 转型"决策点。
