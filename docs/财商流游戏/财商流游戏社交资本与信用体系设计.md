## 1. 问题诊断：社会关系层的缺失

### 1.1 已被姊妹文档解决的问题

《交易拍卖与企业经营设计》已经解决了交易的**机制层**缺陷：

| 原缺陷 | 解决方案 | 位置 |
|-------|---------|------|
| 交易窗口过窄（只在 S1） | 季度交易窗口 T1–T4 制度 | 该文档第 2 章 |
| 定价无机制（「双方议价」沦为随口报价） | 四种拍卖机制 + 标准提案格式 + 双层股票定价 | 该文档第 4、5、6 章 |
| 机会缺乏排他性争夺 | 拍卖触发规则、企业并购密封暗标 | 该文档第 4 章 |

**本文档不重复这些内容。**

### 1.2 仍然缺失的一层：社会关系

即使有了完善的拍卖与议价机制，以下问题**仍未被任何文档覆盖**：

| # | 缺失项 | 为什么重要 | 真实世界对应 |
|---|-------|-----------|-------------|
| 1 | **没有信用记忆** | 玩家逾期、违约、毁约不留痕迹，下次借钱成本一样。失信零成本 | 央行征信、信用评级决定融资成本 |
| 2 | **担保没有真实后果** | 「担保」若只是签个字，就丢掉了中国民间金融最大的坑 | 连带保证责任、代偿与追偿 |
| 3 | **信息完全对称** | 所有玩家看到的资产信息一样，「认知」这一维资源沦为纯数值门槛 | 看不懂条款就会签下坑自己的合同 |
| 4 | **人脉无变现路径** | 人脉（N）只是某些卡的门槛，攒了没用 | 关系带来信息、机会与更好的交易条件 |
| 5 | **Agent 是报价器而非对手** | NPC 按周期价机械报价，不感知玩家处境 | 真实对手会读你的急迫程度并压价 |
| 6 | **博弈无保护垫** | 一旦引入竞争，新手会被老手收割到劝退 | 教育产品必须保护初学者 |
| 7 | **胜负只看钱** | 靠毁约、压榨盟友赚到钱的人获得最高评价 | 信誉本身是一种资产 |

### 1.3 本文档的核心命题

> **财富的获得方式，和财富的数量同样重要。**
>
> 一个通过守信、协作、专业判断积累财富的玩家，
> 与一个通过毁约、趁人之危、赌运气积累同等财富的玩家，
> **不应该得到相同的评价。**

这既是财商教育的伦理要求（见《真实世界经济与财商理论底座》板块 9），
也是让「人脉」「认知」两维资源真正有意义的设计前提。

## 2. 设计目标与四条底线原则

### 2.1 设计目标

| 目标 | 说明 |
|------|------|
| **G1 让每一次交易都有博弈** | 玩家间的每次交互都应是「双方都有得有失」的谈判，而非单方面施惠 |
| **G2 让机会具有排他性** | 稀缺机会必须能被引发争夺，且争夺机制公平、可预期 |
| **G3 让人脉真正值钱** | 人脉（N）不能只是「某些卡的门槛」，要能直接兑换为信息与机会 |
| **G4 让集体行为影响宏观** | 全体玩家加杠杆 → 资产泡沫 → 破裂，形成系统级反馈 |
| **G5 保护新手与落后者** | 博弈强度上升后必须有防霸凌机制，否则新手一局劝退 |

### 2.2 四条底线原则（不可违背）

| 原则 | 内容 | 违反的后果 |
|------|------|-----------|
| **P1 禁止直接剥夺** | 任何玩家不得通过规则直接夺取他人资产。损失必须来自他人自己的决策失误或风险事件 | 引发真实冲突，且与「财商教育」目标背离 |
| **P2 信息可以私有，规则必须公开** | 玩家可以持有私有信息，但所有机制规则（概率、公式、上限）必须对所有人透明可查 | 不透明规则会让玩家认为被作弊 |
| **P3 承诺必须可执行** | 玩家间的一切约定（合伙、借贷、联盟）必须写入系统合约，由银行家自动执行，不允许口头约定 | 口头约定必然产生纠纷 |
| **P4 劣势方必须有出路** | 任何博弈机制都必须为劣势方保留至少一条理性应对路径，不允许「无解局面」 | 无解局面 = 劝退 |

## 3. 交互强度分级模型

为了适配不同玩家群体（家庭局 / 教学局 / 硬核局），多人交互强度分为三档，**开局前由房主选择**：

| 档位 | 名称 | 启用的机制 | 适用人群 | 单局时长影响 |
|------|------|-----------|---------|-------------|
| **L1** | 温和协作 | 议价交易、合伙买房、玩家间借贷、人脉求助 | 家庭、亲子、青少年教学 | +10% |
| **L2** | 竞争博弈（**默认**） | L1 + 拍卖系统、机会争夺、二手市场挂单、信息交易 | 常规成人局、企业团建 | +25% |
| **L3** | 完全市场 | L2 + 做空/对赌、联盟背叛机制、集体杠杆泡沫、恶意收购 | 硬核玩家、财商进阶训练 | +50% |

> **设计说明**：L1 保留财商教育的安全感；L2 是完整体验；L3 引入真实市场的残酷面，
> 但必须在开局提示中明确标注「本模式包含联盟背叛与对赌机制，可能影响人际关系」。

### 4.1 本文档补充的三条交易规则

以下三条是《交易拍卖与企业经营设计》未定义、但对真实感至关重要的补充：

#### 4.1.1 应急交易窗口（打破季度窗口限制）

原设计的交易集中在季度窗口。但真实世界的资金危机不等季度：

| 阶段 | 是否允许交易 | 说明 |
|------|------------|------|
| 季度交易窗口 T1–T4 | ✅ 正常交易 | 主窗口，见《交易拍卖与企业经营设计》第 2 章 |
| 任意阶段 | ⚠️ **仅允许应急交易** | 仅限「为避免破产而变卖资产」或「紧急借款」，需银行家审核 |
| 回合结算阶段 | ❌ 禁止 | 结算期冻结 |

**应急交易的代价**（防止滥用，且贴近真实）：

| 应急动作 | 代价 | 真实世界对应 |
|---------|------|-------------|
| 应急变卖资产 | 成交价上限 = 评估价 × 70% | 急售的流动性折价 |
| 应急借款 | 利率 = 常规上限 × 1.5 | 紧急融资的风险溢价 |
| 应急动作次数 | 每 5 回合最多 2 次 | 防止把应急当常规 |

> **教育意图**：**越急需要钱，拿到的价格越差。** 这是「现金流管理」重要性的最直观体验——
> 留有现金缓冲的玩家永远不必进入应急窗口。依据见《真实世界经济与财商理论底座》板块 4（流动性溢价）。

#### 4.1.2 非现金筹码库

《交易拍卖与企业经营设计》的标准提案格式为「资产 + 现金 + 附加条款」。
本文档补充**四类非现金筹码**，让谈判维度更接近真实商业：

| 筹码 | 说明 | 结算方式 | 真实世界对应 |
|------|------|---------|-------------|
| **未来现金流分成** | 让渡某资产未来 N 期现金流的 X% | 银行家自动按期划转 | 收益权转让、REITs 份额 |
| **人脉背书** | 为对方下一次借贷提供担保 | 转为担保合约（见 6.3） | 信用担保、连带保证 |
| **认知输出** | 为对方解读一张复杂资产卡（消耗自身 1 点精力，使对方本次视为 K+3） | 一次性生效 | 专业顾问服务 |
| **时间承诺** | 承诺未来 N 回合内优先与对方交易 | 写入合约，违约扣人脉 | 优先认购权、排他期 |

> **教育意图**：让玩家体会「交易不等于付钱」。缺现金时，**能力、信誉、关系同样是可交换的资本**。

#### 4.1.3 Agent 对手的急迫度感知

**原设计问题**：NPC 买家按周期价 90%–110% 机械报价，玩家无法与之博弈。

**改进**：Agent 报价引入**对手急迫度感知**——真实交易对手会读你的处境。

| 玩家状态信号 | Agent 报价调整 | 说明 |
|-------------|--------------|------|
| 现金充裕、无近期还款 | 105%–110% | 你不急，Agent 难压价 |
| 现金紧张、本月有还款压力 | 80%–90% | 你急，Agent 压价 |
| 刚经历失业 / 重疾事件 | 75%–85% | 趁人之危是真实市场行为 |
| 人脉 N ≥ 7 | 额外 +5% | 关系带来更好的条件 |
| 信用等级 AAA | 额外 +3% | 信誉溢价 |
| 市场繁荣期 / 衰退期 | ×1.05 / ×0.9 | 流动性周期 |

> **关键教学设计**：当 Agent 因玩家困境而压价时，系统**必须**弹出教学提示：
>
> > 「银行家注意到你本月现金流紧张，因此压低了报价。这就是现实中的『流动性折价』——
> > 越急需要用钱，卖出资产的价格越差。真正的护城河是**平时留出的现金缓冲**。」
>
> 这把「被占便宜」的挫败感转化为教学时刻。这是本作与「纯竞技桌游」的根本区别：
> **每一次吃亏都必须配一次解释。**

## 5. 合伙、联盟与股权结构

> 与《交易拍卖与企业经营设计》第 10 章（资本运作与并购）互补：
> 该文档定义**并购的估值与流程**，本节定义**合伙关系的治理与背叛风险**。

### 5.1 三种合作形态

| 形态 | 结构 | 期限 | 退出机制 | 道德风险 |
|------|------|------|---------|---------|
| **单次合伙** | 就单一资产按出资比例共享现金流与卖出收益 | 至资产卖出 | 一方买断另一方份额 | 低 |
| **长期联盟** | 多资产持续合作，可约定优先交易权 | 玩家约定（默认 10 回合） | 提前 2 回合通知，或付违约金 | 中 |
| **GP/LP 结构**（L3） | 一方出钱（LP）、一方出力（GP，消耗精力经营），利润按约定分配 | 至项目结束 | 按合约 | **高**（GP 可能懈怠） |

### 5.2 合伙合约的必填字段

系统**强制**要求合伙合约包含以下字段，缺一不可成立：

| 字段 | 说明 | 默认值 |
|------|------|-------|
| 标的资产 | 具体哪一笔 | — |
| 出资比例 | 各方出资金额与比例 | — |
| 现金流分配比例 | **可与出资比例不同**（体现「出力」的价值） | = 出资比例 |
| 决策权归属 | 谁决定何时卖出 | 出资多者 |
| 精力承担 | 谁承担该资产的精力消耗 | 均摊 |
| 退出条款 | 一方退出时的 buyout 公式 | 当前估值 × 出资比例 × 0.9 |
| 违约条款 | 未按约出资/未付精力的后果 | 强制退出，损失出资的 20% |

> **教育意图**：这是真实《合伙协议》的极简版。让玩家意识到
> 「口头说好」与「写清退出条款」是两回事——**这是中国合伙创业最高频的翻车点**。
> 现实中大量合伙纠纷不是因为项目失败，而是因为**没约定失败时怎么分**。

### 5.3 GP/LP 结构的委托代理问题（L3 专属）

| 角色 | 付出 | 收益 | 道德风险 |
|------|------|------|---------|
| **LP（出资方）** | 现金 | 约定比例利润 | 无直接付出，但可能被 GP 坑 |
| **GP（经营方）** | 精力（每回合 1 点） | 约定比例利润 + 管理费 | **可能懈怠**：不投精力，坐享分成 |

**懈怠判定与处置**：GP 某回合未投入约定精力 → 该回合项目收益 **-30%**，LP 可选择：

| LP 应对 | 后果 |
|--------|------|
| 警告（限首次） | GP 人脉 -1 |
| 更换 GP | LP 支付违约金，项目暂停 1 回合 |
| 强制清算 | 项目按 70% 估值变现，双方按比例分配 |

> **真实世界对应**：这正是私募股权基金的核心治理问题（GP 的忠实义务与勤勉义务），
> 也是「投资人 vs 创始人」矛盾的本质。

### 5.4 联盟背叛机制（L3 专属，带强制警示）

L3 模式允许背叛：联盟成员可撕毁优先交易权，把本应给盟友的机会卖给出价更高的第三方。

| 背叛后果 | 数值 |
|---------|------|
| 人脉（N） | **-3** |
| 信用等级 | 下调一级（影响后续所有借贷利率） |
| 全局广播 | 所有玩家获知该背叛行为 |
| Agent 市场惩罚 | 后续 5 回合内，Agent 对该玩家报价下调 10% |

> ⚠️ **启用警告（强制弹窗）**：
> 「本模式允许联盟背叛，可能导致真实的人际关系紧张。建议仅在熟人或纯竞技场景下启用。」
>
> **设计立场**：背叛机制的教育价值在于「让玩家亲历失信的长期成本」——
> 背叛的短期收益必须**小于**长期的信用损失，否则游戏就在教人失信。
> 数值校准原则：**背叛的净期望收益必须为负。**

### 5.6 双层谈判模型（v2.58 增补）

> **来源**：Diplomacy（自由密谈+口头承诺不可执行）+ Chinatown（当场交割、无背叛）。
> **完整设计规格**：见《财商流游戏设计优化与机制增补_v2.58.md》§4.1。

| 层级 | 适用场景 | 承诺是否可执行 | 交割方式 | 来源 |
|------|---------|--------------|---------|------|
| **现货交易层**（T2 交易窗口内） | 即时买卖资产、借贷 | 必须当场交割，不可挂账 | 一手交钱一手交货 | Chinatown |
| **长期合伙层**（跨回合协议） | 合伙创业、长期联盟、口头约定 | 系统只记录事件日志，不强制执行 | 到期自动清算，违约靠社交制裁 | Diplomacy |

**规则细节**：
- **现货层**：严格执行"谈成即交割"，不允许"下回合再给你"——消灭现货交易中的背叛空间（适合低龄/新手局）。
- **长期层**：玩家可在密谈中承诺"下季度我分你 20% 利润"，系统不写入合约；若违约，其他玩家可在下一次谈判中引用此违约记录。
- **社交制裁量化**：连续 2 次不履行口头约定的玩家，下一季度其他玩家对其交易自动获得 +10% 议价权。

### 5.7 轮值税务官机制（v2.58 增补）

> **来源**：Sheriff of Nottingham（2014）——警长轮值、监管者本身是玩家、贿赂博弈。
> **完整设计规格**：见《财商流游戏设计优化与机制增补_v2.58.md》§4.2。

**规则**：
1. 每季度交易窗口期间，随机指定 1 名玩家担任"轮值税务官"（当季银行家角色）；
2. 税务官权力：有权抽查任意 1 名玩家的本季度报税记录；
3. 查出未申报收入：补税 + 罚款（未申报税额 × 2），罚款归税务官；
4. 查清白（如实申报）：税务官自付调查费 2,000 元（赔偿被冤枉者的时间成本）；
5. 贿赂博弈：被抽查的玩家可在抽查前向税务官行贿，但贿赂承诺不强制执行——税务官可以收了贿还开袋。

**教学点**：监管者不是中立 NPC，而是有自己利益的玩家；合规激励相容——乱查清白者要自掏腰包。

### 5.8 隐藏老赖（信用评级不公开）（v2.58 增补）

> **来源**：The Resistance/Avalon（隐藏身份）+ Shadows Over Camelot（叛徒机制）。
> **完整设计规格**：见《财商流游戏设计优化与机制增补_v2.58.md》§4.3。

**信用评级半公开化**（修改原 §6 信用系统）：
- 原规则：所有玩家信用评级公开可见；
- v2.58 修改：信用评级仅自己可见 + Agent 可见；
- 其他玩家只能通过"人脉检定"（消耗人脉点）查询对方的"信用区间"（如"中等"而非具体分数）。

**隐藏老赖变体**（6 人以上局可选）：
- 每局随机指定 1 名玩家为"隐藏老赖"（仅自己知道）；
- 隐藏老赖在合伙创业事件中拥有"秘密抽走合伙公司季度净利润 10%"的能力；
- 其他玩家可公开指控：
  - 指控正确（确实是老赖）：老赖全部资产罚没，指控者获得罚没资产的 30%；
  - 指控错误（被指者不是老赖）：指控者信用分 −10 分 + 赔偿被冤枉者 5,000 元；
- 终局结算：老赖若全程未被识破，抽走的资金归他所有；若被识破，全部罚没。

### 5.9 临时项目制合伙（v2.58 增补）

> **来源**：Cosmic Encounter——联盟按"单次遭遇"缔结，无长期承诺。
> **完整设计规格**：见《财商流游戏设计优化与机制增补_v2.58.md》§4.4。

**规则**：
1. **默认合伙期限**：3 个游戏回合（1 个游戏季度）；
   - 合伙目的：共同投资某个具体项目（如合伙买一套房、合伙开一家店）；
   - 项目清算后自动散伙，下次再谈新的合伙；
2. **出资与分红**：按出资比例分配现金流与退出收益；合伙人必须真金白银出资（押筹码），避免"嘴上合伙人"；
3. **退出机制**：3 回合到期自动清算散伙；提前退出需其他合伙人同意，或按当前净值的 80% 强制赎回（惩罚性折价）；
4. **长期合伙（可选）**：若玩家想建立长期合伙（如共同经营一家企业），需额外签署"长期合伙协议"：期限 12 回合（1 年），中途退出需支付违约金 = 初始出资 × 30%。

**设计意图**：从"签了合伙人卡就是终身绑定"改为"项目制合作"，更接近真实世界的项目制合伙，也避免"离婚式散伙"的痛苦。

## 6. 玩家间借贷与信用系统

### 6.1 利率上限的真实世界依据

**现状**：规则写「建议不超过 24% 年化，否则视为高利贷事件」。

**修订建议**：改为**锚定 LPR 的动态上限**，更贴近真实法律环境。

| 项目 | 建议值 | 说明 |
|------|-------|------|
| 基准 | 1 年期 LPR（游戏内宏观变量，见《宏观经济与政策模拟类游戏资料》第 12 章） | 初始建议 3.45% |
| 司法保护上限 | LPR × 4 | 约 13.8%。**超出部分法律不予保护** |
| 游戏内「高利贷」判定线 | LPR × 4 | 超出即触发「非法借贷」事件 |
| 高利贷事件后果 | 借出方：收益不受保护，可能被赖账；借入方：可申请债务重组 | — |

> ⚠️ **可信度说明**：`LPR × 4` 这一司法保护上限规则来自中国最高法对民间借贷利率司法保护上限的规定（2020 年修订），
> 属**权威二手**来源，**建议正式定稿前核验现行司法解释**。游戏内数值为设计建议值。

### 6.2 信用等级系统

每个玩家拥有**信用等级**，随行为动态变化，直接影响借贷成本：

| 等级 | 触发条件 | 借款利率系数 | NPC 银行贷款额度 |
|------|---------|-------------|-----------------|
| **AAA** | 无逾期、净资产高、人脉 ≥ 7 | × 0.8 | × 1.5 |
| **AA** | 无逾期记录 | × 1.0 | × 1.2 |
| **A**（初始） | — | × 1.0 | × 1.0 |
| **B** | 曾逾期 1 次 | × 1.5 | × 0.7 |
| **C** | 曾逾期 2 次 / 违约 1 次 | × 2.0，需抵押 | × 0.4 |
| **D** | 破产过 / 恶意违约 | 只能向玩家借，利率 × 3.0 | 不可贷款 |

> **教育意图**：信用是有价格的。一次逾期，未来所有资金成本上升——
> 这是真实世界征信系统（央行征信、芝麻信用）的核心逻辑。

### 6.3 担保与连带责任

| 机制 | 规则 | 教育意图 |
|------|------|---------|
| **担保** | 玩家 C 可为 A 的借款提供担保，提升 A 的信用等级 | 担保的价值 |
| **连带责任** | A 违约时，C 必须代偿全部本息 | **担保不是签字，是真金白银的责任**——这是中国民间担保纠纷的重灾区 |
| **追偿** | C 代偿后获得对 A 的债权，可继续追讨 | 代位求偿权 |

**系统设计要点**：必须由 Agent 银行家在担保成立时**明确播报连带责任的含义**，
并要求玩家二次确认。真实世界中大量担保纠纷源于「不知道担保意味着什么」。

### 6.4 逾期与债务重组

```
借款到期无力偿还
   ↓
┌──────────────────────────────────────────┐
│ 方案 A：展期（利率上浮 50%，信用 -1 级）      │
│ 方案 B：以资抵债（资产按 70% 估值转让给债主） │
│ 方案 C：债务重组（减免 30% 本金，信用降至 D） │
│ 方案 D：破产清算（见《规则与经济系统》第 12 章）│
└──────────────────────────────────────────┘
```

> 四个方案对应真实世界的：贷款展期、抵债资产、债务和解、个人破产。

## 7. 玩家间资产市场（二手流通层）

### 7.1 挂单市场

引入简化的**限价挂单**机制，让资产随时可交易：

| 要素 | 规则 |
|------|------|
| 挂单 | 玩家可随时挂出「卖单」：资产 + 要价 + 有效期（1–5 回合） |
| 买单 | 玩家可挂「买单」：资产类型 + 出价 |
| 成交 | 买卖价格匹配即自动成交，由银行家结算 |
| 买卖价差 | 系统对每类资产设定**买卖价差**（bid-ask spread），体现流动性成本 |
| 撤单 | 可撤单，但撤单后 1 回合内不可重新挂同资产 |

### 7.2 买卖价差表（建议值）

| 资产类型 | 买卖价差 | 流动性 | 说明 |
|---------|---------|-------|------|
| 现金 | 0% | 极高 | 无价差 |
| 股票（流通） | 2% | 高 | 交易日随时成交 |
| 债券 / 理财 | 3% | 高 | — |
| 贵金属 | 5% | 中 | — |
| 房产 | 8%–12% | **低** | 交易周期长、税费高、中介费 |
| 企业股权 | 15%–25% | **极低** | 难找到买家，且信息不对称严重 |
| 收藏品 / 另类 | 20%–30% | 极低 | 极度依赖找到特定买家 |

> **教育意图**：这是本文档最重要的教学点之一。
> **流动性是资产的一种隐性成本**——房产看起来涨了 20%，但买卖一次要吃掉 10% 的价差 + 税费。
> 新手最容易犯的错误就是只看「涨幅」，不看「能不能变现、变现要花多少」。
> 依据见《真实世界经济与财商理论底座》板块 4（流动性溢价）。

### 7.3 流动性折价的极端情形

| 情形 | 价差变化 | 说明 |
|------|---------|------|
| 市场繁荣期 | 价差 × 0.7 | 牛市流动性好，好卖 |
| 市场衰退期 | 价差 × 1.8 | 熊市无人接盘 |
| 玩家破产清算 | 额外 -30% 折价 | 强制变现 |
| 稀有资产无人问津 | 挂单超 5 回合未成交，自动降价 10% | 真实世界的降价促销 |

## 8. 信息不对称层

### 8.1 信息分层

| 层级 | 内容 | 获取方式 | 真实世界对应 |
|------|------|---------|-------------|
| **公开信息** | 市场周期状态、宏观变量、资产参考价、公开事件 | 全体可见 | 公开市场数据、财报 |
| **半公开信息** | 其他玩家的净资产区间（不精确）、信用等级 | 消耗人脉查询 | 圈子内的信息 |
| **私有信息** | 自己抽到的机会卡内容、自己的精确三表、内幕消息卡 | 仅自己可见 | 私有信息 |
| **受限信息** | 复杂机会卡的完整条款 | **认知（K）达标才能看清** | 专业能力决定信息解读力 |

### 8.2 认知（K）作为信息解读能力

这是让「认知」这一维资源真正有意义的关键设计：

| 认知等级 | 能看到的信息 |
|---------|------------|
| K 0–2 | 机会卡只显示「预期收益」字样，**不显示风险与隐藏成本** |
| K 3–5 | 显示基础条款，但隐藏条款（如「2 年后需追加投入」）不显示 |
| K 6–8 | 显示完整条款，包括隐藏成本与最坏情形 |
| K 9–10 | 额外显示「银行家点评」：该机会的真实期望值估算 |

> **教育意图**：直击真实世界的核心事实——
> **看不懂合同，就会签下坑自己的条款。** 财商的一部分是「读懂条款的能力」，而不仅是「敢不敢投」。
> 这与《真实世界底座》板块 6「行为金融学」中的「过度自信」偏差形成对照。

### 8.3 信息交易

玩家可将私有信息**出售**给他人：

| 交易对象 | 规则 | 限制 |
|---------|------|------|
| 机会卡内容 | 可出售「我手上有一张 X 类机会卡」（不出售卡片本身） | 售价由双方议定 |
| 内幕消息卡 | 可出售，但**买方使用后被查获将触发处罚** | 见 9.4 |

### 8.4 内幕交易的伦理红线（重要）

**明确禁止将「内幕交易」设计为可靠盈利路径。**

| 设计约束 | 说明 |
|---------|------|
| 内幕消息有概率被查获 | 使用后 30% 概率触发「监管调查」事件 |
| 查获后果严重 | 罚款 = 收益 × 2，信用降至 D，精力 -2 |
| **期望值必须为负** | 系统需确保内幕交易的数学期望 < 0 |
| 教学提示 | 触发时 Agent 播报：「内幕交易在真实市场是违法行为，不仅面临罚款，还可能承担刑事责任。」 |

> **这是财商教育的伦理底线**：不能让游戏暗示「违法能赚钱」。
> 与《真实世界底座》板块 9（财商教育的学术争议与伦理边界）一致。

## 9. 人脉资源的真实变现路径

**现状问题**：人脉（N）目前主要是「某些卡的门槛」，变现路径模糊。

**改革方案**：人脉明确成为可兑换的**资源货币**。

| 人脉值 | 可兑换的能力 | 精力/金钱代价 |
|-------|------------|-------------|
| N ≥ 3 | 查询其他玩家的净资产区间 | 免费，每回合 1 次 |
| N ≥ 5 | 「引荐」：从 Agent 处获得额外的机会卡抽取机会 | 消耗 1 点精力 |
| N ≥ 6 | 发起「合伙邀约」时被接受的概率提升 | — |
| N ≥ 7 | 拍卖中查看他人资金上限；Agent 报价 +5% | — |
| N ≥ 8 | 「人脉担保」：为他人担保时不降低自身信用 | — |
| N = 10 | 「圈子核心」：每回合额外获得 1 条半公开信息 | — |

**人脉的消耗**（防止只升不降）：

| 行为 | 人脉变化 |
|------|---------|
| 主动毁约 | -3 |
| 被 Agent 判定为恶意抬价 | -2 |
| 拒绝他人合理的合伙邀约 3 次以上 | -1 |
| 长期无社交动作（5 回合无玩家间交互） | -1（自然衰减） |
| 成功帮助他人（担保代偿、让渡机会） | +2 |

> **教育意图**：人脉是资产，也需要维护；**信用是慢积累、快消耗的**。

## 10. 博弈的边界：哪些负向互动被禁止

为保护教育目标与游戏体验，以下机制**明确不引入**：

| 禁止机制 | 原因 |
|---------|------|
| 直接窃取他人资产 | 违反 P1，且无教育价值 |
| 强制他人破产的操作 | 无解局面，违反 P4 |
| 恶意散布虚假信息 | 破坏信息层的可信度，且难判定 |
| 针对特定玩家的「仇恨卡」 | 引发真实人际冲突 |
| 可以直接减少他人精力的攻击 | 与人设（健康管理）混淆，且体验极差 |
| 内幕交易作为盈利策略 | 伦理红线，见 9.4 |

**允许**的负向互动（有教育价值且公平）：

| 允许机制 | 教育价值 |
|---------|---------|
| 竞拍抬价 | 竞争性定价 |
| 抢先买断稀缺机会 | 机会的排他性 |
| 急售时压价 | 流动性折价 |
| 联盟背叛（L3） | 契约精神与信用风险 |
| 恶意收购（L3） | 控制权市场 |

## 11. 系统级联动：集体行为反作用于宏观

> 借鉴《宏观经济与政策模拟类游戏资料》第 12 章「市场周期与宏观联动系统升级建议」。

### 11.1 核心设计：集体杠杆 → 泡沫 → 破裂

当前市场周期由骰子驱动，玩家行为不影响宏观。引入**集体行为反作用**：

| 集体指标 | 计算方式 | 对宏观的影响 |
|---------|---------|-------------|
| **市场杠杆率** | 全体玩家总负债 / 总净资产 | > 60% 触发「信贷过热」状态 |
| **资产换手率** | 本回合成交资产数 / 总持有资产数 | > 30% 触发「投机过热」 |
| **现金占比** | 全体现金 / 总资产 | < 10% 触发「流动性紧张」 |

### 11.2 状态机（简化版，线下可手算）

```
         ┌──────────────────────────────────────┐
         ↓                                      │
   【复苏】──杠杆率>60%──→【过热】──系统事件──→【破裂】
      ↑                                          │
      └────────────────【衰退】←────────────────┘
                （持续 3–5 回合后自然回复苏）
```

| 状态 | 资产价格 | 利率 | 失业风险 | 玩家体感 |
|------|---------|------|---------|---------|
| 复苏 | 缓慢上涨 | 低 | 低 | 舒服，适合投资 |
| 过热 | 快速上涨 | 上升 | 低 | 赚钱容易，容易加杠杆 |
| 破裂 | 暴跌 20%–40% | 高 | 高 | 杠杆者爆仓 |
| 衰退 | 阴跌 | 下降 | 高 | 现金为王 |

### 11.3 关键教学时刻

当「破裂」由**全体玩家的集体加杠杆**触发时，系统应明确播报：

> 「本次市场破裂的直接原因是：全场玩家平均杠杆率达到 72%，资产价格被信贷推高至脱离基本面。
> 最先加杠杆的玩家获得了最高收益，最后加杠杆的玩家承担了最大损失。
> 这就是真实世界中每一轮泡沫的共同结构。」

> **教育价值**：把「市场周期是运气」转化为「市场周期是集体行为的结果」——
> 这是财商教育中最难传递、也最重要的一课。
> 理论依据：《真实世界经济与财商理论底座》板块 5（经济周期）、板块 6（羊群效应）。

## 12. 保护垫：反霸凌与落后补偿

博弈强度上升后，必须有保护机制，否则新手一局劝退。

### 12.1 新手保护价

| 条件 | 保护内容 |
|------|---------|
| 玩家净资产 < 全场中位数 × 50% | 参与拍卖时，成交价上限 = 出价 × 0.9（10% 折扣） |
| 同上 | 被 Agent 压价的幅度减半 |
| 玩家连续 3 回合净现金流为负 | 触发「财务辅导」：Agent 教练主动给出一次免费分析 |

### 12.2 落后者补偿机制

| 机制 | 说明 | 争议与取舍 |
|------|------|-----------|
| **落后补偿卡** | 净资产排名末位的玩家，每 10 回合可获得一张「逆风卡」（小额无息贷款额度 / 额外机会抽取） | 会削弱「努力有回报」的公平感，建议仅在 L1/L2 启用 |
| **追赶窗口** | 每次市场「破裂」后，资产价格处于低位，现金充裕者获得买入窗口 | **推荐**：无人为干预，纯粹由周期自然产生追赶机会 |
| **知识补偿** | 落后玩家可获得更多 Agent 教练对话次数 | **推荐**：不破坏经济平衡，且强化教育目标 |

> **设计取舍说明**：本作倾向使用**追赶窗口**与**知识补偿**，而非直接的财富转移。
> 理由：财商教育的核心是「决策质量」，直接发钱会掩盖决策失误，反而削弱教学效果。

### 12.3 反霸凌硬规则

| 规则 | 说明 |
|------|------|
| 禁止联合抵制 | 3 名及以上玩家约定不与某玩家交易 → 触发「垄断」事件，参与者人脉 -2 |
| 禁止恶意低价倾销扰乱 | 以低于估值 50% 的价格连续抛售 3 次 → 触发「异常交易」审查 |
| 破产保护期 | 破产重生的玩家，3 回合内不受他人追债（对应真实世界的破产保护） |

## 13. 社交维度如何计入胜负

### 13.1 现状

《规则与经济系统》第 14 章为**三维评分**：财务自由度 50%、净资产、以及第三个维度。

### 13.2 修订建议：加入第四个维度「社会资本」

| 维度 | 权重（建议） | 说明 |
|------|------------|------|
| 财务自由度（FI Index） | 40% | 核心 |
| 净资产与资产质量 | 25% | 结果 |
| 人生平衡（健康/家庭/认知） | 20% | 幸福感 |
| **社会资本** | **15%** | 新增 |

**社会资本评分构成**：

| 项目 | 分值 |
|------|------|
| 最终信用等级 | 0–40（AAA=40，D=0） |
| 人脉值 | 0–30（N × 3） |
| 履约率 | 0–30（履约次数 / 总约定次数 × 30） |

> **教育意图**：**财富不是唯一指标，信誉也是资产。**
> 一个靠毁约和压榨盟友赚到钱的人，不应获得最高评价。
> 这与《真实世界底座》板块 9.4（伦理边界）的立场一致。

## 14. 线上化实现要点

### 14.1 交易消息流（WebSocket）

| 消息类型 | 方向 | 说明 |
|---------|------|------|
| `TRADE_OFFER` | C → S | 发起报价 |
| `TRADE_BROADCAST` | S → C | 广播公开报价（C3 约束） |
| `TRADE_ACCEPT` / `TRADE_REJECT` | C → S | 接受/拒绝 |
| `TRADE_SETTLED` | S → C | 银行家结算完成，附带三表更新 |
| `AUCTION_START` / `AUCTION_BID` / `AUCTION_END` | 双向 | 拍卖流程 |
| `CONTRACT_CREATED` / `CONTRACT_BREACHED` | S → C | 合约成立/违约 |
| `CREDIT_LEVEL_CHANGED` | S → C | 信用等级变化（含原因） |

### 14.2 异步与超时

| 场景 | 处理 |
|------|------|
| 玩家离线 | 由 Agent 按该玩家的**历史行为画像**代打（Agent 行为画像见《交易拍卖与企业经营设计》第 12 章），但**不代做投机决策** |
| 报价超时 | 默认拒绝，并回复「对方未在时限内回应」 |
| 拍卖轮次超时 | 视为放弃本轮出价 |

### 14.3 反串通

| 风险 | 措施 |
|------|------|
| 私下串通（线下同房间） | 所有报价公开广播（C3）；系统标记「高频交易对」，异常时提示房主 |
| 恶意抬价 | 抬价后放弃达 2 次，禁止本局参与拍卖 |
| 小号输送利益 | 同一 IP / 同一设备的账号间交易需房主确认 |

### 14.4 审计日志

所有玩家间交易必须记录完整日志（时间、双方、标的、价格、信用影响），
终局复盘时可回放——**既是防纠纷手段，也是教学素材**。
