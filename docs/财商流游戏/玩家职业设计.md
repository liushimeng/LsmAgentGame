> **版本**：v2.0（2026-09-10）

## 1. 快速使用

1. 需要人物背景与财务起跑线：先读本索引，再进入对应分类档案。
2. 需要规则数值：以 [`财商流游戏规则与经济系统.md`](../财商流游戏规则与经济系统.md) §10 为唯一事实来源。
3. 需要行为偏差定义：以 [`财商流游戏行为金融与投资心理机制设计.md`](../财商流游戏行为金融与投资心理机制设计.md) 为准。
4. 需要真实世界数据校准：以 [`财商流游戏真实世界经济与财商理论底座.md`](../财商流游戏真实世界经济与财商理论底座.md) 和 [`99-研究来源与数据锚点.md`](玩家职业设计/99-研究来源与数据锚点.md) 为准。

## 3. 人物卡统一字段

| 字段 | 说明 |
|---|---|
| `id` | P 系列为早期档案；N 系列为本轮新增，编号不回收、不复用 |
| `identity` | 虚构姓名、年龄、性别、城市、户籍、教育、健康等级 |
| `household` | 婚姻、子女、赡养、照护责任、异地关系 |
| `career` | 职业、用工形态、收入结构、技能、职业冲击 |
| `money` | 月收入、月支出、现金流、储蓄、负债、住房与金融资产 |
| `risk` | 保障缺口、身体情况、健康折旧、职业集中度 |
| `behavior` | 行为金融偏差、金钱脚本、谈判与合作倾向 |
| `goal` | 短期目标、终局目标、梦想成本 |
| `event` | 开局钩子、阶段事件、教练干预点 |

## 4. 去重与维护规则

1. 同一职业允许存在多人，但必须在年龄、健康、家庭、住房、负债、行为偏差或城市层级中至少三项显著不同。
2. 新增人物前检索 `git grep "姓名或ID"`；禁止重复使用 P/N 编号和虚构姓名。
3. 一份档案不要同时复制完整财务表和行为定义；行为机制引用专项文档，财务参数引用规则文档。
4. 收入与资产区间变动时，更新 `99-研究来源与数据锚点.md` 的口径和日期，不要直接篡改历史人物卡。
5. 所有档案人物均为教学虚构；不得写入可识别真实个人的身份证号、住址、电话、精确病历或账号。
