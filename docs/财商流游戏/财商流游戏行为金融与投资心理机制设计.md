## 1. 偏差体验机制总表

下表将 11 类偏差逐一映射为可执行的游戏机制。「载体」列标明该偏差是通过新卡牌、既有卡牌改造还是系统级规则实现；「复盘揭示」列为 Agent 教练在局后复盘时的核心话术方向（完整话术见第 5 章）。

**玩家画像对接（v1.2 新增）**：上表「复盘揭示」列未直接列出典型玩家，因为每种偏差在不同画像下的表现形式不同。本节与《玩家职业设计》§4.1 的"行为金融偏差 × 玩家画像交叉表"形成映射——Agent 教练在开局后 3–5 回合内识别玩家主要决策原型（保守/激进/焦虑/理性/从众），再针对性触发对应偏差。例如：
- **焦虑型玩家**（P01 王小军、P02 李秀兰）→ 优先触发损失厌恶（XM-01/02）与心理账户（XM-05/06）；
- **从众型玩家**（P03 张建国、P04 陈志远）→ 优先触发羊群效应（XM-11/12）与赌徒谬误（XM-19/20）；
- **理性型玩家**（P06 林若曦、P11 刘芳、P12 吴祖德）→ 优先触发过度自信（XM-07/08）与稀缺心态引发的双曲贴现（XM-15/16）；
- **激进型玩家**（P08 赵明轩、P09 钱昊）→ 优先触发过度自信（XM-07/08）与羊群效应（XM-11/12）；
- **保守型玩家**（P05 周小慧、P07 沈文涛、P10 孙明哲）→ 优先触发锚定效应（XM-03/04）与保守偏差（独立于心魔卡的系统级机制）。

| # | 偏差类型 | 机制名称 | 触发条件 | 玩家可感知的代价/收益 | 对应圈层 | 载体 | 复盘揭示方向 |
|---|---------|---------|---------|---------------------|---------|------|-------------|
| 1 | 损失厌恶 (Loss Aversion) | 「割肉之痛」 | 持仓浮亏 ≥20% 时收到加仓摊薄提示 | 若选择加仓：后续若继续下跌，亏损按 1.5× 放大；若拒绝：无额外惩罚 | 全圈层 | 心魔卡 XM-01/02 + 系统弹窗 | "你加仓是因为相信价值，还是因为不愿承认错误？" |

| 3 | 心理账户 (Mental Accounting) | 「钱的标签」 | 获得意外收入（拆迁/中奖/遗产）时资金被标记来源标签 | 标记为"意外之财"的资金在下回合 Doodad 消费概率 +30%，且单笔消费上限放宽 50% | 全圈层 | 系统级资金标签 + 心魔卡 XM-05/06 | "你把这笔钱当'白捡的'花掉了，但它和你辛苦赚的工资是同一块钱" |
| 4 | 处置效应 (Disposition Effect) | 「赢跑输扛」 | 同时持有盈利和亏损资产时触发交易界面提示 | 若只卖盈利不卖亏损：下月亏损资产额外 -3% 净值衰减；若两者同比例处理：认知 +1 奖励 | 积累圈/自由圈 | 心魔卡 XM-07/08 + 交易系统改造 | "你卖了赚钱的、留着亏钱的——感觉舒服了，钱包不舒服" |
| 5 | 过度自信 (Overconfidence) | 「连赢膨胀」 | 连续 3 次投资盈利后自动触发 | 下 2 次投资的负面事件概率 +15%；若此时追加仓位 > 净资产 30%，额外精力 -2 | 全圈层 | 心魔卡 XM-09/10 + 系统追踪 | "连赢让你觉得自己是股神，但样本量太小不足以证明能力" |
| 6 | 羊群效应 (Herding) | 「跟风漩涡」 | 同一回合 ≥3 名玩家（含 AI）买入同类资产 | 跟风买入者若该资产下季度下跌，亏损额外 +10%；逆势操作者若获利，认知 +1 | 全圈层 | 系统级广播 + 心魔卡 XM-11/12 | "所有人都在买，所以你也买了——但'所有人'不等于'对的'" |
| 7 | 确认偏误 (Confirmation Bias) | 「信息茧房」 | 玩家连续 3 回合只看某类资产的利好信息（由 Agent 记录） | Agent 教练在复盘时强制展示 2 条被忽略的反面证据；若玩家曾主动查看反面信息则豁免 | 全圈层 | Agent 复盘系统 + 心魔卡 XM-13/14 | "你收集了很多看多的理由，但你有没有认真看过一条看空的？" |
| 8 | 沉没成本谬误 (Sunk Cost Fallacy) | 「不舍得扔」 | 企业/副业连续亏损 ≥6 个月且累计投入 ≥5 万 | 弹出"已投入 X 万，是否继续追加？"；若追加且再亏 3 月，总投入 × 0.3 计入"沉没学费"（不可回收） | 积累圈/自由圈 | 心魔卡 XM-15/16 + 系统弹窗 | "你已经花的钱回不来了，问题是：如果今天从零开始，你还会投吗？" |
| 9 | 框架效应 (Framing Effect) | 「说法陷阱」 | 同一投资事件以两种表述呈现给不同玩家 | 选"70% 盈利"框架的玩家比选"30% 亏损"框架的多 25% 接受率（统计用）；两版实际期望值相同 | 全圈层 | 心魔卡 XM-17/18（成对出现） | "同一个机会换了个说法你就改了主意——决定你的是内容还是措辞？" |
| 10 | 赌徒谬误 (Gambler's Fallacy) | 「骰子记忆」 | 玩家连续 3 次掷出 ≤2 点后做出加注/追投决策 | 下次投资掷骰结果不受前次影响（独立事件），但若玩家因"该出了"而加注，加注部分亏损概率不变但金额 ×1.5 | 生存圈/积累圈 | 心魔卡 XM-19/20 + 系统提示 | "骰子没有记忆，连输三次不代表第四次一定赢" |
| 11 | 双曲贴现 (Hyperbolic Discounting) | 「今朝有酒」 | 面临"即时小额 vs 延迟大额"选择时 | 选即时者：当期现金 +Y，但 12 个月后少得 Z（Z > Y）；选延迟者反之。选择记录用于复盘 | 全圈层 | 心魔卡 XM-21/22 + Doodad 联动 | "你选了今天的 5000 块，放弃了明年的 8000 块——这笔账算过吗？" |

## 2. 新增「心魔卡」卡牌组完整规格

### 2.1 命名与定位

- **卡牌类别名**：心魔卡（Bias Card）
- **命名理由**：现有卡牌体系中"Doodad 卡"用英文音译表示冲动消费，"认知卡"表示正面提升。"心魔"一词在中国语境中直觉传达"内心的陷阱"，与"认知"形成正反对照，且不与任何现有卡牌类别重名。
- **卡背颜色**：暗红色（#8B0000），区别于现有粉色 Doodad 卡和紫色认知卡。
- **卡面布局**：顶部偏差类型图标 + 中部中国生活场景插画 + 下部效果数值区 + 底部复盘二维码（线上版点击跳转 Agent 解说）。

### 2.2 卡牌组总量与分布

| 项目 | 数值 |
|------|------|
| 总张数 | **30 张** |
| 生存圈专属 | 8 张（XM-01 ~ XM-08 中适用生存圈的子集） |
| 积累圈专属 | 12 张 |
| 自由圈专属 | 4 张 |
| 全圈层通用 | 6 张 |
| 抽取时机 | 停留在「心魔格」（新增格子类型）或特定事件卡附带触发 |
| 触发格 | 生存圈 S09→改为心魔格（原休息格保留功能，增加"也可抽心魔卡"选项）；积累圈 A11/A26 增加心魔卡抽取选项；自由圈 F09/F17 新增心魔格 |

> **注**：不新增独立格子编号，而是在现有休息格/学习格上叠加"可选择抽心魔卡"的功能，避免修改棋盘总格数。详见附录 B。

### 2.3 心魔卡完整字段规格

每张心魔卡包含以下字段：

```
编号：XM-XX
卡名：中文名称
偏差类型：11 类之一（中英文对照）
适用圈层：生存圈 / 积累圈 / 自由圈 / 全圈层
触发条件：何时生效
即时效果：具体数值
持续回合数：0 = 即时结算；N = 持续 N 个游戏月
解除条件：如何提前终止
认知检定：是否需要认知检定及阈值
认知奖惩：触发/识破时的认知点变动
复盘揭示文案：Agent 教练使用的苏格拉底式提问模板
```

### 2.4 全部 30 张心魔卡详细规格

#### 损失厌恶类（3 张）

**XM-01：割肉之痛·股票篇**
```
编号：XM-01
卡名：割肉之痛·股票篇
偏差类型：损失厌恶 (Loss Aversion)
适用圈层：全圈层
触发条件：持有股票浮亏 ≥20% 时，在 S5 自由投资阶段自动弹出
即时效果：弹出选择框——
  A「加仓摊低成本」：以当前价买入等额股份，若后续 3 个月内股价继续下跌，
    新增部分亏损 ×1.5 倍计算（模拟越补越深）；
  B「止损离场」：立即卖出，承受已实现亏损，但免除后续放大惩罚。
  若玩家认知 ≥5，选择框旁显示提示："损失厌恶系数 λ≈2.25（Kahneman, 1979）"。
持续回合数：3（仅选 A 时生效）
解除条件：选 B 即时解除；选 A 后 3 个月到期自动解除
认知检定：阈值 5；通过则在选项旁显示偏差提示（不阻止选择）
认知奖惩：选 A 且最终亏损扩大 → 认知 -1；选 B 止损 → 认知 +1
复盘揭示文案："你在第{turn}回合以{buy_price}元买入{asset_name}，
  第{trigger_turn}回合浮亏{loss_pct}%时选择了{choice}。
  如果这不是你的钱而是帮朋友管的，你还会这样选吗？
  这就是损失厌恶——同等金额的亏损带来的痛苦是盈利的 2.25 倍。"
```

**XM-02：割肉之痛·房产篇**
```
编号：XM-02
卡名：割肉之痛·房产篇
偏差类型：损失厌恶 (Loss Aversion)
适用圈层：积累圈 / 自由圈
触发条件：持有房产估值低于买入价 ≥15% 且持有 ≥12 个月
即时效果：Agent 询问"是否降价出售？"——
  若拒绝出售：每月额外支付持有成本 = 房产市值 × 0.3%（物业费+机会成本），
    持续至出售或周期切换；
  若出售：按当前市价成交，实现亏损但不受额外惩罚。
持续回合数：直至出售或周期切换
解除条件：出售房产或市场周期切换
认知检定：阈值 6
认知奖惩：拒绝出售且后续房价继续跌 → 认知 -1；果断止损 → 认知 +1
复盘揭示文案："你的房子买入价{buy_price}万，现在值{current_price}万，
  你选择不卖已经{hold_months}个月了。
  每个月多付的持有成本累计{holding_cost}元——
  这些钱本来可以用来做什么？"
```

**XM-03：加仓幻觉**
```
编号：XM-03
卡名：加仓幻觉
偏差类型：损失厌恶 (Loss Aversion)
适用圈层：生存圈 / 积累圈
触发条件：同一资产连续加仓 ≥2 次且仍处浮亏状态
即时效果：第三次加仓时，所需资金 = 正常金额 × 1.3（模拟情绪驱动的过量投入）；
  若认知 ≥4，弹出警告"你正在用更多钱证明自己没错"。
持续回合数：0（即时结算）
解除条件：卖出该资产
认知检定：阈值 4
认知奖惩：无视警告继续加仓 → 认知 -1；取消加仓 → 认知 +1
复盘揭示文案："你对{asset_name}加了{add_count}次仓，均价从{avg1}降到{avg2}，
  但总市值仍在缩水。'摊低成本'听起来理性，
  但如果这只股票从未涨过，你会在第几次加仓时停下来？"
```

#### 锚定效应类（3 张）

**XM-04：买入价执念**
```
编号：XM-04
卡名：买入价执念
偏差类型：锚定效应 (Anchoring)
适用圈层：全圈层
触发条件：持有资产当前价 < 买入价 × 0.85 时尝试卖出
即时效果：系统弹出"当前价远低于你的买入价{anchor_price}元，确定要卖吗？"
  若认知 < 5：强制延迟 1 回合才能确认卖出（模拟犹豫）；
  若认知 ≥ 5：立即执行，但在交易记录中标记"克服锚定"。
持续回合数：1（仅认知 < 5 时）
解除条件：完成卖出或等待 1 回合
认知检定：阈值 5
认知奖惩：克服锚定成功卖出 → 认知 +1；延迟后仍卖出 → 无奖惩
复盘揭示文案："你的买入价是{anchor_price}元，当前价{current_price}元。
  你犹豫了{delay_turns}回合才卖出。
  Tversky & Kahneman (1974) 发现人们过度依赖初始信息做判断——
  你的买入价对市场毫无意义，它只是你的心理锚点。"
```

**XM-05：历史最高价幻觉**
```
编号：XM-05
```

## 3. 系统级机制（非卡牌）

以下机制贯穿全局，不由单张卡牌承载，而是嵌入游戏底层规则。

### 3.1 锚定效应系统

**设计目标**：让玩家在游戏过程中持续感知"锚"的存在与被锚定的过程。

**实现规则**：

1. **买入价锚**：所有资产的交易界面始终高亮显示"你的买入价"（绿色=盈利，红色=亏损），旁边显示当前市场价。这是最基础的锚——玩家每次打开交易面板都会看到它。
2. **历史最高价锚**：每种资产的价格走势图上标注历史最高价（金色虚线）。当当前价低于峰值 30% 以上时，虚线变为醒目橙色，视觉上制造"好便宜"的错觉。
3. **参考成交价锚**：多人局中，当其他玩家成交同类资产时，系统在聊天区广播"玩家 X 以 Y 元买入了 Z"。这条信息成为新的社会锚点。
4. **锚定强度计量**：Agent 后台记录每位玩家的"锚定指数"= Σ(|决策价 - 当前公允价| / |买入价 - 当前公允价|)。指数越高说明决策越受买入价影响。该指数在复盘时可视化展示。

**与认知资源的联动**：认知 ≥5 时，交易界面的买入价显示从"高亮"降级为"小字灰色"，减弱视觉锚定效果。

### 3.2 心理账户系统

**设计目标**：在不改变金钱可替代性的前提下，通过 UI 标签让玩家体验自己如何区别对待不同来源的钱。

**实现规则**：

1. **资金来源标签**：每笔收入入账时自动打标——「工资」「投资收益」「副业」「意外之财」「礼金」「退款」六类。标签仅用于 UI 展示和行为追踪，**不影响实际购买力**（钱仍然是钱）。
2. **消费倾向放大**：当玩家使用「意外之财」标签的资金进行消费时，Doodad 卡的消费上限 ×1.5、确认弹窗延迟缩短 50%（降低消费摩擦）。这是对心理账户行为的**规则级放大**，让玩家更容易观察到自己的非理性。
3. **账户合并按钮**：玩家可在 S1 阶段主动点击"合并账户"，将所有标签资金归并为"统一资金池"。合并后，上述消费放大效果立即消失。这个按钮本身就是教育工具——它的存在提醒玩家"钱是可替代的"。
4. **月度账单分类展示**：每月结算时，现金流量表按资金来源标签分组展示支出明细。让玩家直观看到"意外之财"是否比"工资"花得更快。

**与既有系统的兼容**：不修改 §2.2 金钱的定义，仅在 UI 层增加标签维度。三表联动不受影响（标签不参与勾稽校验）。

### 3.3 双曲贴现系统

**设计目标**：将"即时满足 vs 延迟满足"量化为贯穿全局的选择张力，与 Doodad 卡深度联动。

**实现规则**：

1. **Doodad 卡的延迟替代选项**：每张 Doodad 卡触发时，除了"必须支付"外，新增"延期支付"选项——本月免付，但 3 个月后支付金额 ×1.3（模拟信用卡分期利息）。这本身就是双曲贴现的测试：选即时支付是"痛但清醒"，选延期是"爽但贵"。
2. **储蓄激励曲线**：每月未消费的结余资金，若连续 3 个月保持正储蓄，第 4 个月起获得"储蓄纪律奖励"= 月结余 × 2%（模拟延迟满足的正反馈）。中断则重置计数器。
3. **年度延迟满足评分**：年度结算时计算"延迟满足指数"= 全年选择延迟支付的次数 / (选择延迟 + 选择即时的总次数)。指数 ≥0.6 时，年终认知 +1；指数 ≤0.3 时，复盘重点讨论。

**与既有 Doodad 卡的联动**：现有 25 张 Doodad 卡无需修改卡面，仅在触发逻辑中增加"延期支付"分支。

### 3.4 羊群效应系统

**设计目标**：在多人局中制造真实的社交压力，让玩家体验"明知不该跟风但还是跟了"的过程。

**实现规则**：

1. **实时持仓可见性**：每回合结束时，系统广播每位玩家的"本回合操作摘要"（买入/卖出/持有，不含具体金额）。这让所有人都能看到"大家在做什么"，制造信息瀑布。
2. **AI 玩家的带节奏行为**：AI Agent 玩家被编程为在以下场景中高概率跟风：
   - 繁荣期：80% 概率跟随多数玩家买入同类资产；
   - 萧条期：70% 概率跟随多数玩家抛售；
   - 复苏期：50% 概率独立决策（模拟聪明钱先行）。
   这让真人玩家在多数回合都面临"AI 都在买/卖，我跟不跟"的压力。
3. **逆势奖励**：当 ≥3 人同向操作时，逆势操作者若最终获利，获得认知 +2（而非通常的 +1）。这是对独立思考的强激励。
4. **羊群指数**：Agent 记录每位玩家的"羊群指数"= 跟随多数操作的次数 / 总决策次数。复盘时展示并与全场平均对比。

### 3.5 确认偏误系统

**设计目标**：在复盘中强制呈现玩家忽略的反面证据，打破"我只看到我想要的"循环。

**实现规则**：

1. **信息浏览追踪**：Agent 记录玩家在游戏中查看每条市场信息的类别（利好/利空/中性）和目标资产。
2. **反面证据注入**：当玩家对某资产的利好信息浏览量 ≥3 条且利空信息浏览量 = 0 时，Agent 在下一回合 S1 阶段强制推送 1 条利空分析（不可关闭，必须阅读 5 秒后才能继续）。
3. **复盘时的"盲区报告"**：每局结束后，Agent 生成"信息盲区报告"——列出玩家关注度最高的 3 个资产，以及每个资产上被忽略的最重要的 2 条反面信息。
4. **主动探索奖励**：若玩家在一局中主动查看了 ≥5 条利空信息（针对自己持有的资产），年终认知 +1。鼓励"主动找茬"的习惯。

### 3.6 EV 显式化系统（v2.58 增补）

> **来源**：《概率数学与随机性教育类桌游资料》§8 建议1——所有投资格在决策前显示完整期望值表。
> **完整设计规格**：见《财商流游戏设计优化与机制增补_v2.58.md》§5.1。

**规则**：所有投资格在玩家决策前，UI 强制显示完整期望值表：

| 显示项 | 内容 | 示例 |
|--------|------|------|
| 成功情景 | 成功概率 + 成功收益 | 60% 概率 +20% |
| 失败情景 | 失败概率 + 失败亏损 | 30% 概率 −10% |
| 极端情景 | 尾部风险概率 + 最大亏损 | 10% 概率 −100% |
| 期望值 EV | 加权计算结果 | EV = −500 元 |
| 隐含手续费 | 买卖价差 + 印花税 + 滑点 | 0.5% |
| 系统提示 | EV 正负提醒 | ⚠️ 该投资 EV 为负，你确定要投吗？ |

**设计原则**：
- 禁止"暗骰"——玩家在掷骰子前就知道完整概率分布；
- EV 计算公式公开透明：EV = Σ P(结果) × 损益；
- 手续费/滑点/点差必须显式列出，让玩家一眼看出真实 EV。

### 3.7 1000 局蒙特卡洛复盘（v2.58 增补）

> **来源**：《概率数学与随机性教育类桌游资料》§8 建议5——大数定律教学。
> **完整设计规格**：见《财商流游戏设计优化与机制增补_v2.58.md》§5.4。

**规则**：游戏终局结算后，自动进入"蒙特卡洛复盘"模块：
1. Agent 将本局玩家的投资策略（各类资产配置比例、买卖时点）投入 1000 次蒙特卡洛模拟；
2. 显示收益分布柱状图：X 轴为终局净值区间，Y 轴为模拟次数；
3. 标注本局实际净值所在分位数（前 10%？中位数？后 10%？）；
4. Agent 教练点评：单局结果受运气影响大，长期策略 EV 才是关键。

**教学点**：
- 大数定律：重复试验次数 →∞ 时频率趋近概率；
- 单局结果受运气影响大，不要把几轮的运气当成规律；
- 这是"短样本偏差"的直接教学——本局只玩了 30–50 轮，恰好是"短样本"。

## 4. 认知资源与偏差防御的联动

### 4.1 认知检定规则

认知点是抵抗心魔卡效果的唯一资源。检定规则如下：

| 项目 | 规则 |
|------|------|
| 检定方式 | 阈值判定（非掷骰）：玩家当前认知点 ≥ 卡牌标注的认知阈值即为"通过" |
| 通过效果 | 心魔卡仍然触发，但效果减弱 50%（如亏损放大从 ×1.5 降为 ×1.25）；同时在 UI 上显示偏差名称与一句话学术解释 |
| 未通过效果 | 心魔卡全额生效，且不显示偏差名称（玩家不知道自己踩了什么坑，直到复盘） |
| 检定适用范围 | 所有心魔卡中标注了"认知检定"字段的卡；未标注的卡不受认知影响 |
| 认知点消耗 | 检定本身不消耗认知点；但"主动反思"会消耗（见 §4.3） |

**设计理由**：采用阈值判定而非掷骰，因为认知是长期积累的资源，不应被随机性稀释。高认知 = 稳定抵抗，低认知 = 稳定脆弱，这符合"财商教育是确定性投资"的理念。

### 4.2 认知不足时的偏差加重规则

当玩家认知点 < 心魔卡阈值时，除全额生效外，部分卡牌有额外加重效果：

| 心魔卡编号 | 认知阈值 | 未通过时的额外加重 |
|-----------|---------|------------------|
| XM-01 | 5 | 加仓后亏损放大从 ×1.5 提升至 ×2.0 |
| XM-04 | 5 | 卖出延迟从 1 回合增至 2 回合 |
| XM-07 | 4 | Doodad 消费上限从 ×1.5 提升至 ×2.0 |
| XM-12 | 6 | 负面概率加成从 +15% 提升至 +25% |
| XM-15 | 5 | 跟风亏损加成从 +10% 提升至 +20% |
| XM-19 | 5 | 沉没学费比例从 30% 提升至 50% |
| XM-29 | 5 | 所有选项的负面结果概率 +15% |

### 4.3 主动反思机制

玩家可在 S1 自由动作阶段消耗认知点来解除已生效的心魔卡效果：

| 操作 | 消耗 | 效果 |
|------|------|------|
| 反思·轻度 | 认知 -1 | 解除 1 张当前生效的心魔卡的剩余效果（不追溯已结算部分） |
| 反思·深度 | 认知 -2 | 解除所有当前生效的心魔卡 + 本回合免疫新心魔卡触发 |
| 反思·复盘预习 | 认知 -1 | 在下一回合的心魔卡触发时，无论认知是否达标，均视为"通过" |

**限制**：每回合最多执行 1 次反思操作；认知 ≤1 时不可执行反思（防止认知归零导致恶性循环）。

### 4.4 教育闭环设计

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  踩坑     │ →  │  察觉     │ →  │  付代价   │ →  │  复盘揭示 │ →  │  下局改进 │
│ (心魔卡   │    │ (认知检定 │    │ (量化损失 │    │ (Agent   │    │ (认知提升 │
│  触发)    │    │  通过/    │    │  认知惩罚 │    │  苏格拉底 │    │  行为改变 │
│          │    │  未通过)  │    │  系统加重) │    │  式提问)  │    │  偏差免疫) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
      ↑                                                              │
      └──────────────────────────────────────────────────────────────┘
                              多局学习曲线
```

**多局学习曲线的量化体现**：

1. **跨局认知继承**：每局结束时，玩家获得的认知点中有 30% 可带入下一局（模拟"经验留存"）。例如本局获得 5 点认知，下局开局额外 +1.5 点（向下取整为 1 点）。
2. **偏差免疫进度条**：每类偏差有一个隐藏的"免疫进度"（0–100%）。每次在复盘中被揭示该类偏差 +10%，每次在局内成功抵抗（认知检定通过）+15%，每次踩坑且未抵抗 -5%。免疫进度 ≥80% 时，该类偏差的心魔卡触发概率 -50%。
3. **新手保护期**：前 3 局游戏中，心魔卡触发概率 -30%，给玩家适应基本规则的时间。第 4 局起恢复正常概率。
4. **学习曲线可视化**：Agent 在多局复盘报告中展示"偏差踩坑趋势图"——横轴为局数，纵轴为各类偏差的触发次数。理想的学习曲线应是下降趋势。

## 5. Agent 教练复盘话术库

> **对应关系确认（v1.1）**：本节 5.1–5.11 共 11 个话术模板，与 §0 学术谱系中的 11 类偏差**一一对应**（5.1=损失厌恶…5.11=双曲贴现），无遗漏、无错位。每个话术均引用了对应偏差的原始研究出处，确保复盘时学术事实准确。

以下为每类偏差的参数化复盘提示词模板。`{变量}` 由 Agent 在运行时替换为玩家本局真实数据。

### 5.1 损失厌恶

```
你在第{trigger_turn}回合面对{asset_name}浮亏{loss_pct}%时，选择了{choice}。
让我问你一个问题：如果这笔投资不是你买的，而是你朋友买的、你来帮他做决定，
你还会选{choice}吗？

Kahneman 和 Tversky 在 1979 年的前景理论中发现，同等金额的损失带来的痛苦
大约是收益带来快乐的 2.25 倍。这叫"损失厌恶"。

你本局因为不愿止损，累计多亏了{extra_loss}元。
下一局试试这个规则：买入前就写好止损线，到了就执行，不给情绪留空间。
```

### 5.2 锚定效应

```
你买入{asset_name}的价格是{buy_price}元，当前价{current_price}元。
你等了{wait_turns}回合才卖出/至今未卖。

我想请你思考：如果你今天手里没有这只股票，以当前价格{current_price}元，
你会买入吗？如果答案是"不会"，那你持有它的唯一理由就是买入价——
而这个价格对市场来说毫无意义。

Tversky & Kahneman (1974) 把这叫做"锚定效应"：我们的判断被初始信息钉住了。
下一局试试：每次做卖出决策时，遮住买入价，只看当前基本面。
```

### 5.3 心理账户

```
你收到了{windfall_amount}元的{windfall_source}，
在接下来的{n}个月里，你从中花了{spent_amount}元在消费上，
占这笔收入的{spent_pct}%。

相比之下，你的工资收入中用于消费的比例是{salary_consumption_pct}%。
为什么同样是钱，花起来的速度差了{diff_pct}个百分点？

Richard Thaler 在 1985 年提出"心理账户"概念：
人们把钱分成不同的心理抽屉，违背了"钱是可替代的"这一基本经济学原理。
下一局试试：收到意外收入后，先把它转入投资账户冷静 1 个月再决定怎么花。
```

### 5.4 处置效应

```
本局你卖出了{sold_win}项盈利资产（平均盈利{avg_win_pct}%），
保留了{held_lose}项亏损资产（平均亏损{avg_lose_pct}%）。

如果我告诉你，你卖出的那些盈利资产后来平均又涨了{subsequent_gain}%，
而你保留的亏损资产平均又跌了{subsequent_drop}%——
你觉得你的"止盈止损策略"是在管理风险，还是在管理情绪？

Shefrin & Statman (1985) 把这叫做"处置效应"。
Odean (1998) 用真实交易数据证实：散户平均实现 15% 盈利但仅实现 10% 亏损。
下一局试试：每月做一次"假设清零"练习——如果所有持仓都变成现金，
你会以同样的比例重新买入吗？不会的那些，就该卖了。
```

### 5.5 过度自信

```
你在连赢{win_streak}次后，第{next_turn}回合投入了{invest_amount}元，
占当时净资产的{pct}%。这笔投资的结果是{outcome}。

Barber & Odean (2000) 研究了 66,000 个美国家庭的交易记录，发现：
交易最频繁的 20% 投资者，年化收益比市场低 6.5 个百分点。
他们不是因为笨才频繁交易，而是因为太自信。

你本局的交易频率是{trade_freq}次/年，高于/低于全场平均{avg_freq}次。
下一局试试：给自己设一个"冷却期"——每次连赢后，强制等 1 回合再做新投资决策。
```

### 5.6 羊群效应

```
第{turn}回合有{n}人买入{asset_type}，你也跟了。
之后它{outcome}，你的亏损/收益是{result}元。

我注意到你在全场的"羊群指数"是{herd_index}%，
意味着你{herd_pct}%的投资决策与多数人同向。

2015 年 A 股牛市顶峰，新增开户数创历史纪录，上证指数冲上 5178 点。
三个月后跌到 2850 点。"所有人都在买"从来不是买入理由。
下一局试试：当看到多数人同向操作时，先问自己"如果他们错了呢？"
然后再做决定。给自己 30 秒的"反羊群暂停"。
```

### 5.7 确认偏误

```
你对{asset_name}查看了{positive_count}条利好信息和{negative_count}条利空信息。
你的信息摄入比是{ratio}:1（利好:利空）。

确认偏误不是"看不到"反面证据，而是"看到了但不当回事"。
以下是你本局忽略的两条关键利空信息：
1. {counter_evidence_1}
2. {counter_evidence_2}

如果这两条信息在你买入前就摆在面前，你还会做同样的决定吗？
下一局试试：每次做重大投资决策前，主动搜索"为什么不应该买{asset_name}"，
给反面证据至少 30 秒的认真思考时间。
```

### 5.8 沉没成本谬误

```
你的{project_name}已经投入了{total_invested}元、持续了{months}个月，
其中{loss_months}个月在亏损。你又追加了{additional}元。

我问你一个思想实验：如果今天你手里没有这个项目，
有人拿着同样的商业计划书来找你投{additional}元，你会投吗？
如果答案是"不会"，那你追加的唯一理由就是"已经花了那么多"——
但已经花的钱回不来了。

下一局试试：每季度对所有亏损项目做一次"从零评估"，
只看未来预期回报，不看历史投入。
```

### 5.9 框架效应

```
本局你和另一位玩家面对同一个投资机会，
你看到的描述是"{frame_a}"，他看到的是"{frame_b}"。
这两个描述的数学期望完全相同：{expected_value}元。

但你们做出了{same_or_different}的决定。
如果不同——是什么改变了你的判断？是内容，还是措辞？

Tversky & Kahneman (1981) 的"亚洲疾病问题"实验证明了框架效应：
同一方案用"救活 200 人"vs"死亡 400 人"表述，选择偏好完全反转。
下一局试试：遇到重要决策时，试着用自己的话重新描述一遍，
看看换个说法后你的感受是否改变。
```

### 5.10 赌徒谬误

```
你在连掷{low_streak}次低点后，加注了{bet_amount}元，
因为你感觉"该出大点了"。

但骰子没有记忆。每一次掷骰都是独立事件，
之前的结果不会影响下一次的概率分布。
你加注的部分并没有更高的胜率，只是承担了更大的风险敞口。

蒙特卡洛赌场里最常见的亏钱方式就是赌徒谬误。
下一局试试：当你觉得"该出了"的时候，恰恰是最不应该加注的时候。
把加注的金额改成正常仓位的 50%，而不是 150%。
```

### 5.11 双曲贴现

```
本局你面对{n}次"即时小额 vs 延迟大额"的选择，
其中{instant_count}次选了即时、{delay_count}次选了延迟。
你的"延迟满足指数"是{delay_index}。

你选即时 5,000 元而非 12 个月后 8,000 元的那次，
隐含年化折现率是 47%——而银行理财只有 3%。
这意味着你的大脑把"现在"的价值放大了 15 倍以上。

双曲贴现是人类进化的产物——在远古时代，"明天的食物"确实不如"今天的食物"可靠。
但在现代金融世界里，这个本能会让你永远存不下钱。
下一局试试：给自己设一个"72 小时冷静期"——
任何超过月收入 10% 的消费决策，等 3 天再执行。
```

### 6.3 企业团建场景适配

- **时长**：建议 90 分钟（含 45 分钟完整局 + 30 分钟复盘 + 15 分钟团队讨论）。
- **心魔卡配置**：使用完整版 30 张，但移除 XM-29（P2P 暴雷）以避免与参与者真实投资经历产生不适联想。
- **复盘侧重**：Agent 教练侧重"团队协作中的羊群效应"和"职场决策中的沉没成本"两个维度，与日常工作场景挂钩。
- **禁忌**：不得将游戏中的偏差表现与参与者的真实财务状况关联；不得使用参与者的真实薪资/资产数据作为游戏参数。

### 6.4 伦理边界

> 呼应《底座》板块 9.4/9.5 的伦理约束。

1. **不得制造焦虑**：心魔卡的文案语气必须是"温和的教育者"而非"恐吓的推销员"。禁止使用"你会破产""你将一无所有"等恐吓性语言。所有负面效果都有明确的上限和解除条件。
2. **不得暗示具体投资建议**：Agent 教练的复盘话术只讨论"决策过程"和"心理偏差"，绝不评价具体资产的好坏。"你因为损失厌恶而没有止损"≠"你应该卖掉那只股票"。
3. **不得诱导真实投资行为**：游戏内所有资产均为虚构，复盘时必须声明"本游戏中的资产与市场无任何对应关系，游戏内表现不构成任何投资建议"。
4. **心理健康安全阀**：若玩家在游戏中表现出强烈情绪反应（如愤怒、沮丧到影响正常交流），Agent 教练应暂停复盘，转为安抚模式："这只是游戏，目的是学习而非评判。你的感受是正常的，很多人在面对亏损时都会有类似反应。"
5. **未成年人保护**：青少年版不得使用任何与真实金融产品同名的资产名称；不得出现"炒股""炒房"等词汇；心魔卡插画不得使用真实品牌标识。
