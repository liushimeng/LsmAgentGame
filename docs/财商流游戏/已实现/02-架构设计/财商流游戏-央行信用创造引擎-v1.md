# 财商流游戏 — 央行信用创造引擎 v1

> **定位**：P1 阶段「重要功能 1 项」——央行-商业银行信用创造与货币传导引擎。
> 在 P0 硬编码 LPR/通胀因子的基础上，引入**内生货币传导链**：央行货币政策 → 商业银行
> 信用创造（部分准备金 → 货币乘数）→ M2 增长 → 通胀传导 → 利率传导 → 信贷约束 → 影响每个 Agent。
>
> 数值出处：《规则》§x ｜《后端架构》§x ｜「P1 新定」= 本简报新增。
> 所有金额单位：人民币元（CNY）；对外 JSON 金额字段一律 `*_cny`。
> 设计日期：2026-09-16 ｜ 状态：设计稿（待 backend-dev 实现）

## 1. 定位与分层

### 1.1 引擎层新增文件

```
game/wealth/central_bank.go    央行-商业银行信用创造引擎(纯引擎,无锁无 IO)
game/wealth/central_bank_test.go  确定性单测(seed 注入)
```

- **纯引擎层**（`game/wealth/` 包内，与 `market.go` / `settlement.go` 平级）：
  所有状态变更经显式入参（含 `*rand.Rand`）驱动 → 可确定性单测。
- **房间层不改动**：`room.go` 仍持有 `World`，tick 时序不变，仅 `World` 新增 `CB` 字段。
- **不新增包**：复用 `game/wealth` 现有包，复用 `World.Pay` / `Ledger` / `EntityBank` 等原语。

### 1.2 与现有文件的耦合关系

| 文件 | 耦合点 | 改动方向 |
|------|--------|---------|
| `market.go` | `PhaseTable.LPR` / `PhaseTable.CPI` | 保留为「基础值」参考；实际 LPR/CPI 由 `CentralBank` 内生计算 |
| `engine.go` | `InflationFactor` = 1.05^年数 | 改为内生：`(1 + max(CPI, 0.02))^年数` |
| `settlement.go` | 步骤5 生活支出用通胀因子；步骤6 贷款月供 | 通胀因子改内生；浮动利率贷款月供按当月 LPR 重算 |
| `actions.go` | `actTakeLoan` 直接放款 | 新增信贷约束校验（额度/利率/门槛） |
| `view.go` | `BuildClientState` 下发 | 新增 `central_bank` 子结构（M0/M1/M2/PolicyRate/LPR/CPI/CreditTightness） |
| `events.go` | 事件播报 | 新增 `game.event type:"policy"`（降息/加息/降准/公开市场操作） |

### 1.3 向前兼容

- `CentralBankState` 所有新字段有**合理默认值**（`NewCentralBank()` 构造），老测试不挂。
- `World.CB` 为 nil 时，`MarketState.Params()` 回退到 P0 硬编码 PhaseTable（兼容路径）。
- 通胀因子保底 2%（`max(CPI, 0.02)`），避免通缩时生活支出为 0 的退化。

## 2. 数值表

### 2.1 央行初始参数（P1 新定）

| 参数 | 符号 | 初始值 | 说明 | 出处 |
|------|------|--------|------|------|
| 政策利率（1Y 基准） | `PolicyRate` | 3.0% | 类似 MLF/逆回购利率，锚定 2024 降息后区间 | P1 新定 |
| 准备金率 | `ReserveRatio` r | 10% | 法定+超额平均，中国实际 7–12% | P1 新定 |
| 货币乘数上限 | `1/r` | 10 | 理论最大值 | P1 新定 |
| 再贴现率 | `RediscountRate` | PolicyRate + 0.5% | 银行向央行借款成本 | P1 新定 |
| 央行国债持有 | `GovBondsHeld` | 200,000 | 公开市场操作吞吐基础货币 | P1 新定 |
| 央行再贴现贷款 | `LoansToBanks` | 350,000 | 央行对商业银行贷款 | P1 新定 |
| 基础货币 | `MB` | 550,000 | = M0(50万) + R(5万)，央行负债 | P1 新定 |
| 初始 M0 | `M0` | 500,000 | 玩家初始现金总和（10 座 × 平均 5 万） | P1 新定 |
| 初始 M2 | `M2` | 500,000 | = M0（无定期存款，无贷款派生） | P1 新定 |
| 初始货币乘数 | `m` | 0.909 | = M2 / MB = 50万 / 55万 | P1 新定 |

> ⚠️ 初始乘数 0.909 远低于上限 10，反映「经济复苏初期信贷未扩张」的真实状态。
> 随着玩家贷款 → 存款派生 → M2 增长 → 乘数上升 → 接近上限时触发信贷约束。

### 2.2 利率传导系数（P1 新定）

| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 期限溢价（1Y→5Y） | `TermPremium` | 0.5% | LPR(5Y) = PolicyRate + TermPremium |
| 信贷紧缩加点上限 | `CreditSpreadMax` | 2.0% | 信贷约束极值时 LPR 上浮 |
| 房贷加点 | `MortgageSpread` | +0.5% | mortgage = LPR(5Y) + 0.5% |
| 经营贷加点 | `BusinessSpread` | +2.0% | business = LPR(1Y) + 2.0% |
| 消费贷固定利率 | `ConsumerRate` | 10% | 不变（P0 已定） |
| 信用贷月息 | `CreditMonthly` | 0.8%/1.2%/1.8% | 不变（P0 已定） |

### 2.3 通胀传导系数（P1 新定）

| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 目标通胀 | `TargetCPI` | 2.0% | 中国 CPI 长期目标 |
| 通胀传导系数 | `k_cpi` | 0.5 | CPI = TargetCPI + k_cpi × (M2增速 − GDP增速) |
| CPI 下限 | `CPI_min` | 0% | 通缩下限 |
| CPI 上限 | `CPI_max` | 5% | 极端通胀上限（2008 年 5.9% 历史极值） |
| GDP 增速基线 | `GDPGrowth` | 见下表 | 内生于市场阶段 |

| 阶段 | GDP 增速基线 | 基础 PolicyRate | 基础 CPI |
|------|-------------|----------------|---------|
| recovery | +5% | 3.0% | 2.0% |
| boom | +7% | 3.5% | 3.5% |
| recession | +2% | 4.0% | 2.0% |
| depression | −2% | 2.5% | 0.0% |

> 基础值保留《规则》§7.1/§7.4 的阶段差异；实际值由央行逆周期调节内生调整。

### 2.4 信贷约束阈值（P1 新定）

| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 目标乘数利用率 | `TargetUtil` | 85% | M2/MB 达到 1/r 的 85% 时开始收紧 |
| 信贷约束系数 | `CreditTightness` | [0,1] | 0=宽松，1=完全惜贷 |
| 额度收紧系数 | `LoanQuotaFactor` | [0.5,1] | 贷款额度乘数 |
| 利率上浮系数 | `CreditSpread` | [0,2%] | LPR 上浮 |
| 门槛提高 | `CreditScoreBonus` | +50 | 信用分门槛提高 |

## 3. 状态结构

### 3.1 CentralBankState（央行状态）

```go
// CentralBankState 央行-商业银行体系月度状态(纯引擎,无锁)。
// 所有金额单位 CNY;利率为小数(0.03 = 3%)。
type CentralBankState struct {
    // ── 货币三层次(每月汇总自玩家状态) ──
    M0 float64 // 流通中现金 = Σ玩家 Cash
    M1 float64 // = M0 + 活期存款(游戏简化:活期=现金,故 M1=M0)
    M2 float64 // = M1 + 定期存款(玩家 SavingsDeposit)

    // ── 货币政策工具 ──
    PolicyRate     float64 // 央行基准利率(1Y,类似 MLF)
    ReserveRatio   float64 // 准备金率 r
    RediscountRate float64 // 再贴现率 = PolicyRate + 0.5%

    // ── 货币乘数 ──
    MoneyMultiplier    float64 // 实际乘数 = M2 / MB
    MultiplierCeiling  float64 // 上限 = 1 / ReserveRatio
    BaseMoney          float64 // 基础货币 MB = M0 + Reserves

    // ── 信贷约束 ──
    CreditTightness float64 // [0,1],越高越紧
    LoanQuotaFactor float64 // [0.5,1],贷款额度乘数
    CreditSpread    float64 // [0,2%],LPR 上浮

    // ── 央行资产负债表 ──
    GovBondsHeld  float64 // 资产:持有国债
    LoansToBanks  float64 // 资产:对商业银行再贴现贷款
    Reserves      float64 // 负债:商业银行准备金 = r × M1
    CurrencyIssued float64 // 负债:流通中现金 = M0

    // ── 通胀与产出 ──
    CPI           float64 // 内生 CPI(替代 PhaseTable 硬编码)
    RealGDPGrowth float64 // 实际 GDP 增速(内生于市场阶段)
    M2GrowthYoY   float64 // M2 同比增速

    // ── 历史(每月快照,用于 view 展示与复盘) ──
    History []CBMonthlySnapshot
}

// CBMonthlySnapshot 单月央行快照(view 展示用)。
type CBMonthlySnapshot struct {
    Month            int
    M0, M1, M2       float64
    MB               float64
    MoneyMultiplier  float64
    PolicyRate       float64
    LPR              float64
    CPI              float64
    CreditTightness  float64
}
```

### 3.2 CommercialBankState（商业银行体系状态）

```go
// CommercialBankState 商业银行体系汇总(纯引擎)。
// 游戏简化:不逐家跟踪,只跟踪全体系汇总。
type CommercialBankState struct {
    DemandDeposits   float64 // 活期存款 = M1
    TimeDeposits     float64 // 定期存款 = M2 - M1
    TotalDeposits    float64 // = DemandDeposits + TimeDeposits
    Reserves         float64 // = r × TotalDeposits
    ExcessReserves   float64 // 超额准备金 = 可贷资金
    LoansOutstanding float64 // 贷款余额 = Σ玩家 Loan.Balance
    BondHoldings     float64 // 银行持有国债(公开市场操作卖出)
}
```

### 3.3 Player 新增字段（P1 新定）

```go
type Player struct {
    // ... P0 已有字段 ...
    SavingsDeposit int64  // 定期存款(M2 但非 M1),利率 1.5%/年,提前支取损失全部利息
    // 活期存款 = Cash(P0 已有,可动用),利率 0.2%/年
}
```

> ⚠️ `Cash` 语义不变(可动用现金),新增 `SavingsDeposit` 表示定期存款。
> 定期存款不可直接消费/投资,需先「提前支取」(损失利息)或「到期支取」。

## 4. 月推进逻辑

### 4.1 与 §14 时序的衔接

在现有 `SettleMonth()` 的 ① 之前插入央行月度决策,在 ③ 之后更新货币统计:

```
t=0    Start(): NewWorld() 内 NewCentralBank() 初始化央行
每月   phase=acting:
         · (不变)重置 ActionBudget / SpokenThisMonth / Submitted
         · (不变)广播 game.state + 唤醒 Agent
窗口结束:
         phase=settling → 停止接收动作
         ① central_bank.go 央行月度决策(新增):
              a. 更新基础货币 MB(含上月公开市场操作/再贴现效果)
              b. 汇总 M0/M1/M2(遍历玩家 Cash + SavingsDeposit)
              c. 计算实际货币乘数 m = M2 / MB
              d. 计算 M2 同比增速
              e. 内生 CPI = clamp(TargetCPI + k_cpi × (M2Growth − GDPGrowth), 0, 5%)
              f. 央行逆周期调节:调整 PolicyRate(通胀↑→加息,产出缺口↓→降息)
              g. 内生 LPR = PolicyRate + TermPremium + CreditSpread
              h. 更新信贷约束:CreditTightness = f(M2/MB 与上限的距离)
              i. 公开市场操作:根据通胀/产出缺口决定买/卖国债(±5万)
              j. 记录 CBMonthlySnapshot
         ② events.go 月度事件(失业判定)
         ③ settlement.go 逐座位月结 7 步(通胀因子改内生,浮动利率重算)
         ④ market.go 月漂移 + 阶段到期重掷(LPR/CPI 不再读 PhaseTable)
         ⑤ 月份 +1;年调整 / 钟声事件
         ⑥ 广播 game.month(含 central_bank 快照) → game.state(新月)
```

### 4.2 与 MarketState.MonthStep / CycleStep 的关系

- `MarketState.MonthStep()`:不变(股票/黄金/房价漂移)。
- `MarketState.CycleStep()`:不变(阶段重掷)。
- **LPR/CPI 不再从 `PhaseTable` 读取**,改为 `World.CB.LPR` / `World.CB.CPI`。
- `PhaseTable` 保留为「基础值」参考(用于 GDP 增速基线、基础 PolicyRate),但实际值由央行内生。

## 5. 传导链

### 5.1 完整传导路径

```
玩家贷款(actTakeLoan)
  │
  ▼ 银行放贷:玩家 Cash += loanAmount(M0 增加)
  │         银行资产端:贷款 +loanAmount
  │         银行负债端:存款 +loanAmount(贷款变存款)
  │
  ▼ M2 增加:M2 = M0 + SavingsDeposit
  │         实际乘数 m = M2 / MB 上升
  │
  ▼ M2 同比增速上升:M2Growth = (M2_t − M2_{t-12}) / M2_{t-12}
  │
  ▼ 内生 CPI 上升:CPI = TargetCPI + k_cpi × (M2Growth − GDPGrowth)
  │         (MV=PY 简化:货币增速 − 产出增速 = 通胀)
  │
  ▼ 央行观察到通胀上升 → 加息:PolicyRate += ΔRate
  │         (逆周期调节:通胀 > TargetCPI + 0.5% → 加息)
  │
  ▼ 内生 LPR 上升:LPR = PolicyRate + TermPremium + CreditSpread
  │
  ▼ 贷款成本上升:
  │   mortgage = LPR(5Y) + 0.5% → 月供增加
  │   business = LPR(1Y) + 2.0% → 月息增加
  │
  ▼ 信贷约束收紧(若 m 接近上限):
  │   CreditTightness = (m / (1/r) − TargetUtil) / (1 − TargetUtil)
  │   LoanQuotaFactor = 1 − CreditTightness × 0.5
  │   CreditSpread = CreditTightness × 2%
  │
  ▼ 玩家行为变化:
      · 新贷款额度收紧(× LoanQuotaFactor)
      · 新贷款利率上浮(+ CreditSpread)
      · 信用分门槛提高(+50)
      · 月供增加 → 现金流压力 → 减少消费/提前还款
```

### 5.2 关键公式汇总

| 步骤 | 公式 | 说明 |
|------|------|------|
| 基础货币 | `MB = M0 + Reserves` | 央行负债 |
| 准备金 | `Reserves = r × M1` | 银行持有 |
| 货币乘数 | `m = M2 / MB` | 实际乘数 |
| 乘数上限 | `m_max = 1 / r` | 理论上限 |
| M2 同比 | `M2Growth = (M2_t − M2_{t-12}) / M2_{t-12}` | 12 月同比 |
| 内生 CPI | `CPI = clamp(TargetCPI + k_cpi × (M2Growth − GDPGrowth), 0, 5%)` | MV=PY 简化 |
| 内生 LPR | `LPR = PolicyRate + TermPremium + CreditSpread` | 期限结构 |
| 信贷约束 | `CreditTightness = clamp((m/m_max − TargetUtil) / (1 − TargetUtil), 0, 1)` | 线性插值 |
| 额度收紧 | `LoanQuotaFactor = 1 − CreditTightness × 0.5` | 最低 0.5 |
| 利率上浮 | `CreditSpread = CreditTightness × 2%` | 最高 2% |
| 通胀因子 | `InflationFactor = (1 + max(CPI, 0.02))^年数` | 内生替代 1.05^年数 |

## 8. Ledger 实体与记账

### 8.1 新增实体

| 实体 | 含义 | 允许方向 |
|------|------|---------|
| `central_bank` | 央行 | 公开市场操作 / 再贴现 / 准备金 |
| `commercial_bank` | 商业银行体系 | 存款 / 贷款 / 准备金 |

### 8.2 记账场景

| 场景 | From → To | Category | 说明 |
|------|-----------|----------|------|
| 公开市场操作(买国债) | `central_bank → commercial_bank` | `omo` | 投放基础货币 |
| 公开市场操作(卖国债) | `commercial_bank → central_bank` | `omo` | 回收基础货币 |
| 再贴现 | `central_bank → commercial_bank` | `rediscount` | 银行向央行借款 |
| 准备金缴存 | `commercial_bank → central_bank` | `reserve` | 准备金存入央行 |
| 贷款放款 | `commercial_bank → seat:<n>` | `loan` | 复用 P0 `EntityBank` |
| 贷款还本 | `seat:<n> → commercial_bank` | `repay` | 复用 P0 `EntityBank` |
| 贷款利息 | `seat:<n> → commercial_bank` | `interest` | 复用 P0 `EntityBank` |

> ⚠️ 贷款相关记账复用 P0 `EntityBank`(不新增 `commercial_bank` 实体用于贷款),
> 仅公开市场操作/再贴现/准备金使用 `central_bank` / `commercial_bank`。

### 8.3 央行资产负债表(守恒)

```
资产 = 负债
GovBondsHeld + LoansToBanks = Reserves + CurrencyIssued
```

## 9. 守恒不变量与验收断言

### 9.1 货币守恒

| 不变量 | 公式 | 验收 |
|--------|------|------|
| 货币乘数上限 | `M2 ≤ MB × (1/r)` | 每月断言 |
| 央行资产负债表平衡 | `GovBondsHeld + LoansToBanks = Reserves + CurrencyIssued` | 每月断言 |
| 基础货币 | `MB = M0 + Reserves` | 每月断言 |
| M1 定义 | `M1 = M0`(游戏简化) | 每月断言 |
| M2 定义 | `M2 = M1 + SavingsDeposit` | 每月断言 |

### 9.2 新增验收断言(central_bank_test.go)

| 断言 | 条件 |
|------|------|
| CPI 有界 | `0 ≤ CPI ≤ 0.05` |
| 信贷约束有界 | `0 ≤ CreditTightness ≤ 1` |
| 额度乘数有界 | `0.5 ≤ LoanQuotaFactor ≤ 1` |
| 利率上浮有界 | `0 ≤ CreditSpread ≤ 0.02` |
| 准备金率有界 | `0.05 ≤ r ≤ 0.20` |
| LPR 非负 | `LPR ≥ 0` |

## 10. 确定性测试与边界条件

### 10.1 seed 注入复现性

- `NewWorld(seed, cards)` → `NewCentralBank()` 不消费 rng(初始值固定)。
- 央行月度决策中的随机性(如公开市场操作幅度抖动)经 `World.Rand` 驱动。
- 同 seed 同操作序列 → 逐月逐字段一致(`central_bank_test.go` 断言全量快照 hash)。

### 10.2 边界条件测试

| 场景 | 输入 | 预期 |
|------|------|------|
| 准备金率下限 | `r = 5%` | 乘数上限 = 20,信贷极宽松 |
| 准备金率上限 | `r = 20%` | 乘数上限 = 5,信贷较紧 |
| 信贷约束极值 | `m/m_max = 100%` | `CreditTightness = 1`,贷款冻结 |
| 通缩情形 | `M2Growth < GDPGrowth` | `CPI = 0`,通胀因子保底 2% |
| 货币乘数用尽 | `M2 = MB × (1/r)` | 无法新增贷款,`apply_loan_with_credit` 返回 `approved=false` |
| 极端通胀 | `M2Growth = 20%` | `CPI = 5%`(上限),央行大幅加息 |
| 玩家全部破产 | `alivePlayers() = 0` | M2 归零,央行状态冻结 |
