## 2. 类型与状态

- `types/wealth.ts`：`export interface WealthGameState {…}`（协议 §3 全字段）、`WealthPlayer`、
  `WealthMyState`、`WealthAsset`、`WealthLoan`、`WealthLedgerEntry`、`WealthEvent`、
  `WealthMonthSummary`、`WealthScore`、`WealthAction`（ discriminated union by `type`）。
  字段名 / 可空性与协议**逐字一致**，禁止 camelCase 转写偏差。
- `store/wealth.store.ts`（zustand，仿 `doudizhu.store.ts`）：
  `state: WealthGameState | null`、`applyFrame(type, payload)`（switch：`game.state` 全量替换、
  `game.month` 追加 ticker、`game.event` 追加事件流（截断 100）、`game.over` 置 scores）、
  `ui: { panelTab, selectedDistrict, actionModal }`。
- `hooks/useWealth.ts`：WS 连接由 `AppLayout` 唯一持有（§16 约束），本 hook 只订阅
  `game.*` 帧 + 提供 `sendAction(action)`（封装 `game.wealth_action{room_id, action}`）；
  断线恢复：进入 `/wealth/:roomId` → `game.join` → `game.state`（`useSessionRestore` 增加
  `/wealth/:roomId` 路由解析）；观战：`useSpectatorMode()`（已有，复用）。
- 错误展示（§7.1）：弹窗内动作用内联 `formError`；面板级 / 帧错误 `reportGlobalError(e)`。

## 3. 2.5D 城市场景规范

`WealthCityMap.tsx`（@react-three/fiber + @react-three/drei，与狼人杀 3D 座位同一技术栈）：

| 项 | 规范 |
|----|------|
| Canvas | `<Canvas shadows dpr={[1,2]}>`；挂于左主区，flex 自适应 |
| 相机 | 透视 `position={[14,12,14]} fov={45}`，lookAt 原点（等距视角） |
| OrbitControls | `enablePan`（右键/双指）、`enableZoom`、`enableRotate`；`maxPolarAngle={1.2}`、`minDistance={8}`、`maxDistance={40}`；`target={[0,0,0]}` |
| 地面 | 40×40 `planeGeometry` 旋转 -90°，深色底（`#141a24`）+ 网格辅助线（`gridHelper` 40×40，低对比） |
| 城区 | 8 × `DistrictBlock`：位置 = 协议 `districts` 表 (x,z)（§4 城区定义）；**底板** 8×8 `planeGeometry` 贴 `districts/<id>.png` 纹理（缺失降级纯色）；**楼群** 4–6 栋 `boxGeometry`，确定性伪随机（`seedrandom(districtId)`，**不用 Math.random**——重渲染布局稳定），高度映射 `price_index`（0.8–1.6 指数 → 1–5 单位，繁荣期楼变高、萧条期变矮 = 可视化周期） |
| 道路 | 深色薄 `planeGeometry`（y=0.02）连接各城区中心到 finance(0,0)，宽 0.8 |
| 灯光 | `ambientLight intensity={0.7}` + `directionalLight castShadow position={[10,16,8]}` |
| Token | `AgentToken`：圆柱（r=0.35 h=0.7，职业色）+ drei `Billboard` 头像 sprite（512 PNG）+ `Html` 名牌（`distanceFactor={12}`：座位号 + 昵称 + 职业图标）；**移动**：`useFrame` 中 `position.lerp(target, 0.06)` 到目标区中心（迁区平滑动画，约 1s） |
| hover | `DistrictBlock` 悬停 → 浮层信息卡（区名 / 当前房价 / 月租 / beta / 在区玩家数），离开消失 |
| 选中 | 小地图或面板点击城区 → 地图 `OrbitControls.target` 平滑聚焦该区 |

职业色（Token 圆柱与名牌底色，对比度 ≥4.5:1 于深色地图）：
`P01 #f59e0b / P03 #94a3b8 / P05 #34d399 / P07 #60a5fa / P08 #fb7185 / P09 #a78bfa /
P10 #f87171 / P11 #fbbf24 / P15 #fdba74 / P16 #e879f9`（P0 新定；头像缺失时同一色画圆环兜底）。

## 4. 小地图

`WealthMinimap.tsx`：主地图左上角**绝对定位**（120×120px，`pointer-events:auto`）：

- 技术：Canvas2D（**不开第二个 r3f Canvas**，性能考虑）。
- 绘制：40×40 世界 → 120px 坐标（scale 3）；8 城区色块（§3 主色，透明度 0.35）+ 区名首字；
  agent 点（职业色 4px 圆）；当前相机视野框（由主 Canvas `onFrame` 回传 target/distance 推算白框）。
- 交互：点击城区 → 触发主地图聚焦；`requestAnimationFrame` 与主 Canvas 同频重绘 agent 点位。

## 8. 样式与对比度

- `styles/wealth.css`：**`globals.css` 的 `@import` 链末尾追加**（§2.1 硬约束 4：只追加不改序），
  注释块注明日期与「追加在末尾」原因（仿 `debate.css` 追加样例）。
- 命名空间：全部选择器前缀 `.wealth-`（`.wealth-panel` / `.wealth-action-btn` / `.wealth-ticker` …），
  杜绝与既有样式互染；CSS 变量挂 `.wealth-root` 作用域（`--wealth-accent: #c9a227` 等）。
- 对比度（§26 硬阈值）：正文 ≥4.5:1；徽章 ≥5.0:1；周期徽章四色配白字全部 ≥5:1
  （recovery `#15803d` / boom `#b45309` / recession `#b91c1c` / depression `#374151`）；
  FI 仪表 selected 档 ≥6.0:1。**禁止**红底红字 / `color:inherit`+半透明底 / `opacity:0.4` 表
  disabled（§26.2 五反模式一票否决）。
- 状态徽章三件套（§26.3）：`income-band-*`、`cycle-*`、`ending-*` 的 JSX 拼接与 CSS 规则
  **同提交**完成；写完 JSX 立即 `grep -rn "income-band-" src/styles/` 验证非零命中。
- 触控：`--wealth-touch-target: 44px`；`prefers-reduced-motion` 下关闭 token lerp 与数字滚动
  （`@media` 兜底）。

## 9. 降级策略

| 缺失 | 降级 | 构建影响 |
|------|------|---------|
| 职业头像 PNG | 职业色圆环 + 职业 emoji（`AgentToken` 内 `onError` 切换） | 无 |
| 城区纹理 PNG | `DistrictDefs` 主色纯色底板 | 无 |
| banner PNG | CSS 渐变（accent 金 → 深蓝） | 无 |
| 3D 不可用（极端低端机） | 不做 P0（r3f 与狼人杀同一栈，平台已验证） | — |

美术生成脚本 `python-generate-image-tool/generate_wealth_assets.py`（Volcengine Ark，绿幕抠像）
**skip-if-exists 可续跑**；前端构建**不依赖**生成成功（Vite `import.meta.url` 引用 + 运行时
`onError` 兜底），CI 无图也能 `npm run build` 通过。
