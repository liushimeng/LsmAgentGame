## 1. 游戏形态与节奏

### 1.1 形态

**实时月度节拍模拟**。不是回合制轮流行动，而是全房间共享一条时间轴：

```
月份 N 开始（广播 game.state, phase="acting"）
  ├─ 人类：在动作窗口内随时提交动作（`game.wealth_action`，可多个，限类目次数）
  ├─ Agent：LLM 决策 → ≤3 个动作工具 + ≤1 次 speak → submit_month 提前完成
  ▼ 窗口结束（默认 8000ms）或全部座位已 submit
月结（服务端，phase="settling"，< 500ms）
  ├─ 工资(+配偶+副业) → 被动收入 → 固定支出 → 税+社保 → 生活支出 → 债务
  ├─ 市场波动（股票/房产/黄金/债券利率月漂移）、人生事件、失业判定
  ▼ 广播 game.month（全座位月度汇总）+ game.state（新月份快照）
月份 N+1 开始 …直至 60 岁强制终局 → 广播 game.over
```

- 时间轴：开局年龄 = 职业卡 `start_age`（精选手卡恒 25 岁）；每 12 个月 = 1 年（年度调整）；每 5 年（60 个月）= 钟声（人生事件 + 市场周期重掷）；60 岁强制终局。
- 单局时长：25→60 岁 = 35 年 = 420 月 × 8s ≈ **56 分钟**（月结与开局开销另计，实测约 60–70 分钟）。

> ⚠️ 混合年龄说明：文档池职业卡 `age` clamp 20–55，各座位开局年龄可以不同。P0 为可实现性取
> **统一主时钟**：房间基准年龄 = 各座位 `start_age` 的中位数（精选手卡池恒 25）；`game.state.age`
> 为主时钟年龄；`players[].age` 保留个人年龄仅作展示；终局判定以主时钟 ≥ 60 触发。

### 1.2 五维资源（《规则》§2）

现金 C（可短暂透支为负，连续 3 月 < 0 触发破产）｜ 年龄 T（20–60）｜ 精力 E（0–10，可透支到 -3）｜ 人脉 N（0–10）｜ 认知 K（0–10）。

### 1.3 核心公式（《规则》§3.2 / §4.4）

`FI Index = 月被动收入 ÷ 月总支出`（支出为 0 时记 2.0 封顶）。三表（损益 / 资产负债 / 现金流）
由 Ledger 流水推导，前端 `FinancialPanel` 实时展示。

## 3. 房间创建

### 3.1 创建弹窗（`WealthCreateRoomModal.tsx`）

```jsonc
POST /api/games/wealth/rooms
{
  "name": "周日财商局",              // 可选，缺省自动生成
  "agent_seats": [                    // 可选；复用狼人杀 CreateRoomWithAgents 流程
    { "seat": 1, "model_key": "DeepSeek" },
    { "seat": 2, "model_key": "GLM" }
  ],
  "wealth": {                         // 可选段；DisallowUnknownFields 严格校验
    "month_ms": 8000,                 // 1 游戏月时长 ms，3000–30000，缺省 8000
    "pool": "curated",               // "curated" | "docs"，缺省 curated
    "seed": 0                         // 可选随机种子（测试确定性复现）
  }
}
```

- `agent_seats` 携带 >1 座位时，§14.2 model_key 去重随机化自动生效（7+ bot 尽量不同模型）。
- `pool:"docs"` 时从 `cfg.Wealth.ProfessionDocsPath`（json：`profession_docs_path`，默认
  `./docs/财商流游戏/玩家职业设计`）随机抽卡；不可用时自动回退精选手卡并在 `game.event` 提示。
- 创建者默认占 0 号座；纯 Agent 房（创建者不占座）允许，创建者降级为观战者（与狼人杀 / 德扑一致）。

### 3.2 开局触发（P0 新定）

1. **满员自动开局**：满 MinSeats(10) 即自动开局（2020-09-16 §12 座扩容，阈值从 MaxSeats 下调到 MinSeats，让 10–11 bot 全 Agent 房注册完 bot 后即可开局）；房间仍可容纳到 MaxSeats(12)；
2. **房主提前开始**：已占座 ≥ 3 时，房主发送 `game.wealth_start{room_id}` 立即开局；
3. 未达 3 座时提前开始被拒（错误码 35003）。

## 4. 加入 / 观战 / 退出

| 动作 | 途径 | 行为 |
|------|------|------|
| 加入 | 大厅「进入房间」或 `POST /api/rooms/:id/join` + WS `game.join{room_id,game_kind:"wealth"}` | 分配空座；进行中的对局允许中途加入（P0 新定：新座位从当月下月开始参与结算，年龄按主时钟） |
| 观战 | 大厅「👁 观战」或 `POST /api/rooms/:id/spectate` + WS `game.spectate` | `my_seat=-1`、`my=null`；可见 `players[]` 与 `bot_contexts`，不可发动作帧 |
| 退出座位 | WS `game.leave`（进行中 = 玩家「离席托管」）| P0 新定：进行中离席的人类座位转为 **bot 接管**（若有可用 provider，无则座位冻结）；终局前重新进入可夺回 |
| 退出观战 | `game.unspectate` / `POST /api/rooms/:id/leave_spectate` | 常规 |
| 结束后离场 | 终局 `game.over` 后房间停留 60s 展示报告，随后自动解散（广播 `game.removed`） | P0 新定 |

## 5. 开局与座位

1. 开局时服务端按座位顺序发职业卡（curated 池内去重随机；docs 池随机抽 N 张）。
2. 每座位初始状态：初始储蓄入现金（Ledger：`world → seat:n`）、精力 / 人脉 / 认知 / 信用分取卡面值、
   `district = home_district =` 职业卡工作区。
3. 广播 `game.started` + 首个 `game.state`（month=1，phase="acting"）。
4. 开局聊天：Agent 通过 `chatSvc.SendFromBot` 发送职业卡 `opening_hook` 开场白（30–50 字）。

## 7. 人类玩家操作

### 7.1 动作条 = Agent 工具集按钮化

按钮逐项映射 `game.wealth_action{room_id, action:{type,…}}`（参数与校验见协议文档 §4 动作语义表）：

| 按钮 | action.type | 弹窗参数 |
|------|-------------|---------|
| 💵 买资产 | `buy_asset` | 资产（stock_index/bond/gold）+ 金额 |
| 📈 卖资产 | `sell_asset` | 资产 + 份额（房产整售 1 套） |
| 🏠 买房 | `buy_house` | 城区 + 首付比例（0.3–1.0） |
| 🏦 贷款 | `take_loan` | 种类（consumer/credit/business）+ 金额 |
| 💳 还款 | `repay_loan` | loan_id + 金额（提前还 ≥1 万） |
| 🛵 副业 | `start_side_business` / `stop_side_business` | 副业种类（delivery/content/tutoring/freelance） |
| 📚 学习 | `study` | 无参（2000 元 / 精力-1 / 认知+1） |
| 🤝 社交 | `socialize` | 无参（1000 元 / 人脉+1） |
| 😴 休息 | `rest` | 无参（精力+2） |
| ⚡ 加班 | `work_overtime` | 无参（精力-2 / 当月工资×0.3 奖金） |
| 🚚 迁区 | `move_district` | 目标城区（搬家费 3000 元 / 精力-1，P0 新定） |
| 🛍 消费 | `consume` | 金额 + 备注 |
| ❤ 捐赠 | `donate` | 金额（每万 1 社会贡献分，人脉+1 累计 3 次） |
| ✅ 结束本月 | `submit_month` | 无参；标记本人完成，等待月末统一结算 |

### 7.2 错误展示（CLAUDE.md §7.1 硬约束）

弹窗内动作失败 → **弹窗内联红色错误条**（`formError` state），弹窗不关闭；
面板级操作失败 → `reportGlobalError` 全局 toast。绝不允许吞进 console。

### 7.3 人类与 Agent 公平性

人类与 Agent 走**同一套引擎 action 语义**（协议文档 §4 表格是唯一语义来源）；
人类无 `check_state` / `speak` 按钮（数据面板即 check_state；发言走聊天面板）。

## 8. 月度节拍与事件呈现

### 8.1 月结帧呈现

每月结算后前端依次收到：

1. `game.month`：全座位汇总 `{seat, cash_delta, net_worth, fi_index, note}` + 市场变动 + 本月事件 →
   `MonthTicker` 横滚插入、`FinancialPanel` 数字滚动动画、地图楼群高度随房价指数微调。
2. `game.state`：新月份全量快照 → 全面板刷新（zustand 单向数据流）。

### 8.2 事件呈现规则

| 事件 | 呈现 |
|------|------|
| 动作 / 迁移（`type:"action"/"move"`） | 事件流一行 + 地图 token 移动 |
| 月结（`type:"settle"`） | 仅本人明细入 LedgerPanel；汇总入 MonthTicker |
| 市场周期切换（`type:"market"`） | 顶部周期徽章变色 + 全屏 toast「📉 衰退期来临：LPR 5.8%」 |
| 人生事件（`type:"life"`） | 事件流 + 当事座位 token 闪烁（结婚 💒 / 生育 🍼 / 住院 🏥 / 失业 📉） |
| 聊天（`type:"chat"`） | 聊天面板（复用 `GameChatPanel` 5 游戏共用版 + werewolf 式薄适配器） |
| 错误（`type:"error"`） | 事件流红色行 |

### 8.3 暂停

P0 新定：房主可 `game.wealth_pause{room_id, pause:true|false}`（沿用狼人杀 pause 语义：
暂停 tick 计时与 Agent 唤醒；月结完成后才生效）。断线恢复靠 `game.state` 快照重放。

## 9. 破产 / 出局 / 终局与结局展示

### 9.1 破产流程（玩家可见）

现金连续 3 月 < 0 → 全屏公告「⚖️ X 号位触发破产清算」→ 流动资产按市价、房产按 70% 强制变现 →
消费贷本金减 50% 分 36 期免息、信用分清零、停 3 月（token 灰色 + ⛔ 状态图标）→
重组后月现金流仍负 → 出局（token 移出地图，players[].alive=false）。

### 9.2 终局评分与 6 结局

主时钟 60 岁 → 全房停止 → `game.over{scores:[…], report}`。`GameOverModal` 展示：

```
┌─────────────────── 人生结算 · 3 号位 ───────────────────┐
│  总分 78 / 100        🏆 富足安稳 · 中产典范             │
│  ──────────────────────────────────────────────────── │
│  财务自由度 50%  ▓▓▓▓▓▓▓▓░░ 72 分   FI Index 1.12      │
│  人生满意度   30%  ▓▓▓▓▓▓░░░░░ 68 分   已婚·1孩·精力5    │
│  社会贡献     20%  ▓▓▓░░░░░░░░ 45 分   累计捐赠 4.5 万   │
│  ──────────────────────────────────────────────────── │
│  📈 净资产曲线（25→60 岁）  📜 关键决策时间线            │
│  [查看完整 Ledger]  [留在房间讨论]  [返回大厅]           │
└────────────────────────────────────────────────────────┘
```

结局映射（总分 → 结局）：≥85 财务自由·人生赢家 ｜ 70–84 富足安稳 ｜ 50–69 平淡度日 ｜
30–49 债务缠身 ｜ <30 破产出局 ｜ 特殊：FI ≥ 1.5 且人生满意度 < 40 → 孤独富翁（《规则》§14.3）。

4. 住房公积金（§9.2.1，可选开局开关 P1 再议）。

7. Agent 银行家 / 教练 / 解说 / NPC 投资人（AgentClassName 仅登记 `LsmAgentGame-Wealth-Player`，§130 教训：不登记未接线类别）。
8. 跨局记忆持久化（`MEMORY.md` 迭代）与蒙特卡洛复盘。
9. 三层圈层切换玩法（评分展示中的圈层语义 P1 接入）。
