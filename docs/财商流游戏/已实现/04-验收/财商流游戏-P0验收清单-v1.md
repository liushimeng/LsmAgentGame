## 3. 经济不变量

（`ledger_test.go` / `settlement_test.go` 实现为断言；任何月结改动必须保持全绿）

| # | 不变量 | 断言 |
|---|--------|------|
| I1 | **座位现金守恒**：对每个 seat n、每个月，`期末现金 − 期初现金 = Σ(to=seat:n) − Σ(from=seat:n)` | 逐月逐座位 |
| I2 | **world 注入唯一性**：`from=world` 的 Ledger 条目仅存在于开局初始储蓄（金额 = 卡面 Savings） | 全局计数 = 座位数 |
| I3 | **无凭空造币**：所有 `to=seat` 条目的 from ∈ {bank, market, gov, world}；`gov` 只收不付（养老金缴存 gov→seat 为 `pension` 类白名单） | 实体方向白名单 |
| I4 | **资产负债恒等式**：`净资产 = 现金 + Σ资产市值 − Σ贷款余额`（逐月快照重算一致） | 《规则》§3.4 |
| I5 | **月结顺序**：损益明细数组的 category 顺序 = §9.2 七步（快照比对） | 固定顺序 |
| I6 | **FI 公式**：`FI = 被动收入/月总支出`（支出 0 → 2.0）；与 `game.month.summaries[].fi_index` 一致 | 复算 |
| I7 | **税费率**：股票卖出税费 = 佣金 0.025%（min 5 元）；房产 5%+2%（满五唯一免）；黄金 0.5% | 逐笔 |
| I8 | **月供公式**：等额本息 `P·r·(1+r)^n / ((1+r)^n −1)` 与引擎输出误差 < 0.01 元 | 30 年/3 年/5 年三档 |
| I9 | **seed 确定性**：同 seed + 同动作序列 → 逐月全量状态 hash 一致（engine_test） | 跨平台跑两次 |
| I10 | **评分权重和**：`total = fi×0.5 + life×0.3 + social×0.2`；结局映射区间无重叠无缝隙 | 终局断言 |

## 4. 前端验收要点

1. **对比度**（§26）：暗色主题正文 ≥4.5:1；周期徽章四色白字 ≥5:1；FI selected 档 ≥6:1；
   用开发工具抽查 `.wealth-*` 关键类。
2. **状态徽章三件套**：`income-band-*` / `cycle-*` / `ending-*` JSX 与 CSS 同提交——
   `grep -rn "income-band-" ClientWeb/src/styles/` 非零命中。
3. **禁用态**：`phase!=acting` / 预算耗尽 / 停赛 → 灰底 + `cursor:not-allowed`，禁止 `opacity:0.4`。
4. **错误展示**：每个 catch 要么 `setErr` 内联、要么 `reportGlobalError`（§7.1 自检清单）。
5. **性能**：8 token + 48 楼栋场景 ≥50fps（中端核显）；小地图 Canvas2D 无第二 r3f Canvas。
6. **触控**：动作按钮 ≥44px；`prefers-reduced-motion` 关闭 lerp/滚动动画。

## 5. Agent 验收要点

1. **不调真实 LLM 的单测**：fake llmCaller（仿 `run_circuit_short_circuit_test.go`）覆盖：
   工具循环 ≤3 轮、超时强制 submit、350xx 错误回喂重试、speak 限流。
2. **协议 wire 合规**（§14.1）：text 块仅 `{type,text}`；tool_use 四键齐全；user/assistant 交替
   （`SanitizeMessagesForAnthropic`）；system 为 SystemBlock 数组。
3. **流式超时**：ChatStreamAccumulate 字节刷新（§197）——用慢速 fake SSE 验证不误杀。
4. **User-Agent**：出站 UA 前缀 = `LsmAgentGame-Wealth-Player/`（抓包或 Provider 单测断言）。
5. **公平性**：同 ModelKey 的两个 bot 同 seed 下决策输入一致；Transcript 可审计。

## 6. 已知边界与不修复项

| # | 边界 | 说明 | 处理 |
|---|------|------|------|
| B1 | 文档池卡年龄差异 | 混龄卡仅展示个人 age；终局按主时钟 60 触发 | 设计取舍（后端架构 §1.1 ⚠️） |
| B2 | 债券不做市值重估 | 周期影响落地为新购利率联动，持仓锁定 | P1 再议浮亏记账 |
| B3 | 配偶/副业收入不二次计税 | 按税后净额入账 | P0 简化（后端架构 §8.2） |
| B4 | 股票无分红、无印花税 | 简报锁定 0 税 + 0.025% 佣金 | 与《规则》§6.1 差异已 ⚠️ 标注 |
| B5 | LLM 决策不进确定性测试 | fake Provider 覆盖；真实 LLM 仅 e2e 手测 | 平台惯例 |
| B6 | 极端低端机 3D 降级未做 | r3f 与狼人杀同栈，平台已验证 | P1 观察 |
| B7 | 人类中途加入从下月参与 | 当月不补结 | P0 新定（产品设计 §4） |
| B8 | pause 仅月结边界生效 | tick 中途暂停可能导致该月略长 | 可接受（≤1.5×month_ms watchdog 兜底） |
| B9 | P0 房间不持久化 | 重启服务丢对局（与德扑/狼人杀 in-memory 一致） | 平台现状 |
| B10 | 捐赠无上限刷社会分 | 上限 10 分已封顶；金额本身不设限 | 教学语义（钱真花出去） |
