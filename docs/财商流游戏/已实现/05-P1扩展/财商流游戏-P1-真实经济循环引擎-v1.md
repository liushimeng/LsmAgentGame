# 财商流游戏 · P1 扩展：真实经济循环引擎（消费品市场 + 内生 CPI + 劳动力市场 + 社会结构）

> **版本**：v1 ｜ **日期**：2026-09-16 ｜ **game_kind**: `wealth`
> 本文件是 P1 第二期的**实现契约**——打通「家庭消费 → 企业营收 → 劳动需求 → 工资 →
> 收入 → 消费」的财富循环流，使 CPI 与失业率**内生化**。
> 上游设计来源：《财商流游戏总体设计》§6（圈层）、《财商流游戏规则与经济系统》§7；
> P1 前序：央行信用创造引擎 / 明斯基与 LPR 引擎（同目录）。
> 实现以本文件为唯一事实来源；与 P0/P1 前序契约冲突时以本文件为准。

## 1. 设计目标

P0/P1 前序中，CPI 是央行 MV=PY 理论值（`central_bank.go:168-180`），失业是周期阶段
的外生概率（`events.go:32-39`），玩家的生活支出流向 `world` 黑洞——**消费与生产
两端互不认识**。本次新增三个纯引擎模块，让「你花的每一分钱」都变成「别人的营收
与工资」：

| 引擎 | 新文件 | 核心教育价值 |
|------|--------|------------|
| **消费品市场 + 内生 CPI** | `goods.go` | 统计局八大类消费篮子：需求过热/供给冲击 → 分品类涨价 → 加权 CPI（真实物价统计原理）|
| **劳动力市场** | `labor.go` | 消费 → 企业营收 → 劳动需求 → 失业率 → 个体裁员概率 → Phillips 工资（凯恩斯循环流）|
| **社会结构统计** | `labor.go` | 净资产基尼 / 收入五等份 / 生存-积累-自由圈分布（《总体设计》§6 落地）|

**循环链路**（每月闭合一次）：

```
玩家月结消费(步骤5, 按恩格尔曲线拆 8 类) ──Pay──▶ firms(企业部门)
                                                    │ ×FirmScale 2.5(投资/政府/外需)
                                                    ▼
                                        Revenue → CapacityWage(×0.52 劳动份额)
                                                    │ ÷ WageBill
                                                    ▼
                              TargetEmployment → Unemployment → LayoffWave
                                                    │                    │
                              Phillips 年度工资 ◀──┘          个体裁员概率 ×(U/5%)
                                                    │
                              GoodsMarket.DemandIdx(8 类需求) → 分品类价格 → CPI
                                                    │
                              央行 MonthlyDecision CPI 混合(50% 篮子实测)
```

配套的**消费档位系统**（节俭/标准/精致/奢侈）与 Agent 经济感知工具见 §7；
社会调研系统见同目录《财商流游戏-P1-社会调研系统-v1.md》（引用本文档 §3/§7）。

## 2. 消费品市场与内生 CPI（新文件 `goods.go`）

### 2.1 统计局八大类消费篮子（权重照真实 CPI 口径，P1 新定）

| id | 中文 | weight | 弹性/特例 |
|----|------|--------|-----------|
| `food` | 食品烟酒 | 0.30 | 猪周期扰动 seed |
| `clothing` | 衣着 | 0.06 | — |
| `housing` | 居住 | 0.20 | 价格向 Market 区租金指数联动 |
| `household` | 生活用品及服务 | 0.06 | — |
| `transport` | 交通通信 | 0.13 | 油价扰动 seed |
| `education` | 教育文化娱乐 | 0.11 | 繁荣期需求旺（供给系数随周期 +1.0）|

### 2.2 数据结构（契约，字段名/JSON tag 不可改）

```go

type GoodsItem struct {

    SupplyIdx map[string]float64    // 产能指数 base=100

// NewGoodsMarket 构造初始市场(8 类 PriceIdx/SupplyIdx=100,权重 §2.1)。

func (g *GoodsMarket) CPIYoYReady() bool
```

### 2.3 月度价格更新（World 方法，调用方持锁，随机经 `w.Rand`）

```go
// GoodsMonthStep 月度消费品价格更新(P1 新定)。
// 调用时机:SettleMonth ④ 市场漂移之后(新插入点 ④.5,§5.2)——housing 联动
// 需要本月最新 DistrictIdx。所有随机性经 w.Rand 驱动(确定性单测)。
func (w *World) GoodsMonthStep()
```

逐类算法（伪码，常量在 `goods.go` 顶部）：

```
for g in 8 类:
    DemandIdx_g = 上月该类实际消费额(Σ玩家 ConsumptionByGoods[g]) ÷ 基准需求_g
        基准需求_g = goodsBaselineDemandCNY × weight_g   // 常量 102000(12 人×均值月支出 8500)
    phaseBeta = {recovery:+0.4, boom:+1.0, recession:−0.6, depression:−1.2}
    SupplyIdx_g(t+1) = 100 + phaseBeta×12 + N(0,2)        // 产能随周期扩张/收缩
    food:    15% 概率猪周期 seed → SupplyIdx ×(1 ± 0.04)   // ±4%
    transport: 15% 概率油价 seed → SupplyIdx ×(1 ± 0.04)
    priceRatio = clamp((DemandIdx_g / SupplyIdx_g)^0.4, 0.96, 1.05)
    moneyEffect = clamp((CB.M2GrowthYoY − CB.RealGDPGrowth)×0.05, −0.005, +0.01)  // CB nil → 0
    PriceIdx_g(t+1) = PriceIdx_g(t) × priceRatio × (1 + moneyEffect)
    MomChange_g = PriceIdx_g(t+1)/PriceIdx_g(t) − 1

housing 特例(替代上式 priceRatio):
    MomChange_housing = 0.3 × mean_d(ΔIdx_d ÷ Idx_d)      // 八区房价指数环比均值
    PriceIdx_housing(t+1) = PriceIdx_housing(t) × (1 + MomChange_housing) × (1 + moneyEffect)

CPIMom = Σ weight_g × MomChange_g
history = append(history, CPIMom); 若 len>420 截断
CPIYoY = Π(1 + history[i], 最近 12 月) − 1   // 不足 12 月:值保留但 CPIYoYReady()=false
```

> ⚠️ housing 联动理由：真实 CPI「居住类」以房租为主要口径；游戏内 Market 的
> `DistrictIdx`（`market.go:102-118` HousePrice/HouseRent 同源）已是唯一房价信号，
> 八大类若另起炉灶会出现两套居住价格——故居住类 CPI 直接锚定房价指数环比，
> 系数 0.3（租金涨幅通常低于房价涨幅）。

### 2.4 央行联动（`central_bank.go` MonthlyDecision 修改）

现状：`MonthlyDecision`（`central_bank.go:222-326`）步骤 e 调 `ComputeCPI()`

```go

cb.ComputeCPI() // 理论分量(写入 cb.CPI)
if w.Goods != nil && w.EconomyEnabled && w.Goods.CPIYoYReady() {
    blended := 0.5*cb.CPI + 0.5*w.Goods.CPIYoY

```

50/50 混合的理由见 §12.2。`InflationFactorCB`（`engine.go:322-337`）无需改动——
它读 `w.CB.CPI`，混合后自动传导到生活支出。

### 3.4 恩格尔曲线分配（`goods.go` 纯函数，P1 新定）


份额公式（伪码；income 为月收入，CNY）：

```
foodShare       = clamp(0.30 − 0.002×((income−8000)/100), 0.15, 0.45)
housingShare    = 0.22 + 0.03×(家庭人数−1)                    // 上限 0.40
educationShare  = 0.08 + 0.04×Children                        // 上限 0.25
healthcareShare = 0.05 + 0.003×max(0, age−35)                 // 上限 0.15
其余 4 类(clothing/household/transport/misc)默认权重 0.06/0.06/0.13/0.05:
    if Σ(上述4类) > 0.90: 四类等比缩放至 0.90(家庭极值保护)
    remaining = 1 − Σ(上述4类)   // ≥0.10 由缩放保证

金额 = total × 份额;round 到元。
```

| 家庭项 | 金额 | 篮子拆分 |

| 配偶 | 2000 | food 0.45 / housing 0.35 / misc 0.20 |
| 每孩 | 5000 | education 0.55 / food 0.30 / clothing 0.15 |
| 每位老人 | 1000 | healthcare 0.60 / food 0.30 / misc 0.10 |

## 4. 劳动力市场（新文件 `labor.go`）

### 4.1 数据结构（契约）

```go
// FirmSector 企业部门月度状态(挂 World.Labor;引擎纯状态,无锁)。
type FirmSector struct {
    RevenueCNY    int64   // 上月企业营收 = Σ当月 to-firms 流水 × FirmScale(2.5)
    WageBillCNY   int64   // 上月全城工资总额(在职玩家 SalaryBase 之和)
    AvgWageCNY    int64   // 滚动平均工资 = WageBill ÷ 在职人数
    Unemployment  float64 // 内生失业率 0-1(clamp [0.02,0.35])
    Employment    float64 // 就业率 = 1 − Unemployment
    WageGrowthYoY float64 // Phillips 年化工资增长(小数,AnnualAdjust 时更新)
    LayoffWave    int     // 裁员潮强度 0-3(0 平静/1 观察/2 裁员潮/3 已触发个体放大)
}

// 常量(goods/labor 标定,P1 新定,理由 §12.1):
const FirmScale        = 2.5  // 居民消费 → GDP 的倍数(投资+政府+外需)
const LaborShare       = 0.52 // 劳动报酬份额(国民收入口径)
const UnemployFloor    = 0.02 // 失业率下限
const UnemployCeil     = 0.35 // 失业率上限
const UnemployNatural  = 0.05 // 自然失业率(个体概率基准)

// NewFirmSector 构造初始状态(Unemployment=0.05 自然率)。
func NewFirmSector() *FirmSector

// SocietyStats 社会结构统计(§5,月度计算后缓存于 World.Society)。
type SocietyStats struct {
    Gini      float64    // 存活玩家净资产基尼系数 [0,1]
    Quintiles [5]float64 // 可支配收入五等份各组收入占比(低→高,和=1)
    Circles   [3]int     // 圈层人数:{生存圈, 积累圈, 自由圈}
}

// ComputeSociety 月度社会结构统计(纯函数,§5)。
func ComputeSociety(w *World) *SocietyStats
```

### 4.2 月度更新（`SettleMonth` 新插入点 ②.0）

```go
// LaborMonthStep 劳动力市场月度更新(P1 新定)。
// 调用时机:SettleMonth ② MonthlyEvents 之前(events.go 失业概率消费最新 Unemployment)。
// 随机性:无(本步确定性;个体裁员掷骰仍在 MonthlyEvents 经 w.Rand)。
func (w *World) LaborMonthStep()
```

算法（伪码）：

```
conFirms = Σ Ledger 当月(w.Month)To=EntityFirms 条目金额   // 本月企业内需
          // 辅助函数 sumFirmsInflow(month int) int64(扫描 Entries,O(条目数))
Revenue = conFirms × FirmScale(2.5)                          // 含投资/政府/外需
WageBill = Σ alive 且 UnemployedMonths==0 玩家 SalaryBase     // 失业者不计
AvgWage = WageBill ÷ max(1, 在职人数)
CapacityWage = Revenue × LaborShare(0.52)
TargetEmployment = clamp(CapacityWage ÷ max(1, WageBill), 0.60, 1.0)
Unemployment = clamp(Unemployment + 0.25×((1−TargetEmployment) − Unemployment),
                     0.02, 0.35)                              // α=0.25 平滑
Employment = 1 − Unemployment
LayoffWave = switch { Unemployment > 0.12 → 2; Unemployment > 0.08 → 1; default → 0 }
```

> 负反馈自稳：失业人数上升 → WageBill 下降 → TargetEmployment 回升 → 失业率减速——
> 与真实劳动市场的均值回复一致，防 12 人小样本发散。

### 4.3 个体失业概率改造（`events.go:22-49` MonthlyEvents）

现状：`base` 按周期阶段 0.15/0.25/0.05（`events.go:32-39`），再乘认知折扣。

P1 改造（`economy_enabled=true` 时）：

```
p = base(周期) × clamp(Unemployment ÷ 0.05, 0.5, 2.5)
    // 内生失业率=自然率 5% 时 p=base(与 P0 等价);
    // 危机 U=12.5% → ×2.5(衰退期 37.5%/月);过热 U=2% → ×0.4→clamp 0.5。
失业时长 = 2 + w.Rand.Intn(5)        // U(2,6) 月,不变
RehireSalaryRatio(裁员时点抽样,分段):
    U > 0.10 → 0.7 + 0.2×rand   // 0.7–0.9(就业市场冷,降薪再就业)
    U < 0.04 → 1.0 + 0.2×rand   // 1.0–1.2(用工紧俏,跳槽涨薪)
    其他     → 0.8 + 0.4×rand   // 0.8–1.2(P0 原区间)
```

`economy_enabled=false` → 完整回退 P0（base 直乘、ratio 恒 0.8–1.2）。

### 4.4 工资 Phillips 曲线（`settlement.go:530-556` AnnualAdjust）

现状：`p.BrassSalaryGrowth()`（`player.go:324-335`）返回 +3%/+1%/0%/−1%（Brass 档改写）。

P1 改造（`economy_enabled=true` 时，`AnnualAdjust` 内替换增长率来源）：

```go
// phillipsBase 年化基础工资增长 = 3% + 0.5×(5% − U×100)%(P1 新定)。
// U=5% → 3%(与 P0 基线一致);U=10% → 0.5%;U=2% → 4.5%。
func (w *World) phillipsBase() float64 {
    return 0.03 + 0.5*(0.05-w.Labor.Unemployment)
}

// 年增长 g = phillipsBase + Brass 档相对偏移:
//   BrassSalaryDelta: tier1 −2% / tier2 −3% / tier3 −4% / 无信用贷 0
//   (偏移 = BrassSalaryGrowth − 0.03,保持「Brass 压低增长」语义叠加在 Phillips 基线之上)
g := w.phillipsBase() + p.BrassSalaryGrowth() - 0.03
```

**名义工资粘性**（v2.60 N10-2，机制即文档）：工资只在年度调整（AnnualAdjust 不变），
CPI 每月变——高通胀期实际工资自动缩水（`InflationFactorCB` 抬升生活支出而工资不动），
无需额外代码，本节写明供验收观察。

## 12. 设计取舍

1. **FirmScale=2.5 与劳动份额 0.52 的标定**（12 人小样本校准）：精选 14 卡
   Expense/Salary ∈ [0.62, 0.78]、均值 ≈0.69（`profession/curated.go`）。
   单人基线 TargetEmployment = 2.5×0.52×0.69 ≈ 0.90；成家后（配偶+2000、每孩+5000）
   典型已婚 1 孩顶到 1.0 上限；12 人混合构成（开局部分已婚 + 钟声逐步成家）加权
   ≈0.94–0.96 → 平滑失业率 **4–6%**（自然率带）。全员节俭（×0.6）→ 0.54–0.78 →
   clamp 后失业率升至 20%+，呈现真实「节约悖论」；clamp [0.60,1.0]×[0.02,0.35]
   封死极端值。真实世界劳动份额 ≈52%（国民收入统计），FirmScale 2.5 近似
   「居民消费 ≈ GDP×40%」的倒数为消费乘数口径——两个参数都有现实锚点，
   联合取值由 12 人样本反推微调。
2. **CPI 混合权重 50/50**：纯篮子实测在前 12 月（CPIYoY 未就绪）与消费剧烈波动月
   噪声过大（12 人样本无大数定律）；纯 MV-PY 又回到「货币决定一切」的外生感。
   各取一半：货币供给决定中长期趋势，篮子捕捉短期结构性涨价（猪周期/油价 seed）。
3. **`firms` 只收不付**：企业营收回流玩家需要「分红/雇佣」二级模型（P2 企业投资），
   P1 先闭合「消费→劳动需求」因果链；bank 代发工资保持既有实体语义不动。
4. **精力奖励方向**（奢侈 +2）：品质生活提升精气神——档位权衡是「现金 vs 精力」，
   节俭档省钱但耗神（−1），与 rest/study 动作形成资源替代关系。
5. **强制降档阈值 2×月生活支出**：低于该线意味着一次失业即击穿应急垫；
   自动降档模拟流动性约束（真实世界「没钱只能省」），Agent 无法装死。
6. **Brass 偏移制**：Phillips 基线 + (Brass 增速 − 3%)，保证自然失业率下与 P0
   数值完全一致（回归零差异），Brass 语义（信用贷压增长）原样保留。
7. **家庭支出篮子拆分比例**（§3.4 表）：配偶偏食品/居住、孩偏教育、老人偏医疗——
   按中国家庭消费调查的常识口径取整，教学显著优先统计精度。

| # | 契约原文 | 代码实现 | 修正理由 |
|---|---------|---------|---------|
| 1 | §4.2 `conFirms = Σ Ledger 当月(w.Month) To=EntityFirms` | 扫描**上一完整结算月 `w.Month−1`** | ②.0 时点当月生活支出尚未入账（步骤③才记账），字面实现会让消费大头永远进不了营收，违反 §12.1 自身标定 |
