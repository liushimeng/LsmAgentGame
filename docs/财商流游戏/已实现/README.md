## 2. P0 一句话摘要

**实时月度节拍的人生财商沙盘**：12 座位（10–12 可玩，2026-09-16 §12 座扩容；支持全 Agent / 混合 / 全人类），
1 游戏月 = 1 tick（默认 8000ms）。每月 ACTING（人类按钮 / Agent LLM 决策）→ 月结
（工资 / 税 / 贷款 / 被动收入 / 市场波动）→ 广播 `game.state` + `game.month` → 下月。
开局 25 岁（精选手卡），60 岁强制终局，按 FI Index + 人生满意度 + 社会贡献三维度评分，
映射 6 种结局。世界地图 = 一座城市的 8 个城区（2.5D 渲染），每一笔资金变动写入
**财富流水账（Ledger）**双式记录，三表由 Ledger 推导。

## 3. P0–P3 阶段路线图

### P0（本档案，v1）

**范围**：月度 tick 引擎 + 五维资源 + 三表 + Ledger + 市场周期（四阶段 / 月漂移 / seed 注入）
+ P0 七类资产（stock_index / bond / gold / house / shop / side_business / pension）
+ 8 城区 + 贷款（房贷 / 消费贷 / Brass 三档信用贷 / 经营贷）+ 税务社保 + 人生事件
（结婚 / 生育 / 健康 / 失业）+ 破产与终局 + WealthPlayer Agent（17 工具）+ 精选 10 职业卡
+ 文档池懒加载 + 2.5D 前端全套 + 观战。

**明确砍掉（写入 P1+）**：玩家间交易 / 拍卖、保险、REITs、企业股权 / 并购、公积金、
年终奖单独计税（§9.6）、蒙特卡洛复盘（§6.9.3）、心魔卡（30 张）、Agent 银行家 / 教练 / 解说、
跨局记忆持久化（MEMORY.md 迭代）。

### P1（资产与事件扩展）

- 资产：REITs 基金（§6.1.3）、保险五险种（§6.7，`insurer` Ledger 实体已预留）、企业投资（§6.3 成长期 / 风险事件 / 退出）。
- 事件：离婚（§11.2.3）、父母赡养（§11.2.7）、拆迁 / 限购 / 房产税（§11.2.8）、集体事件（§11.3）、Doodad 意外支出。
- 职业晋升线（§10.5 薪资天花板 / 跳槽成本）、年终奖单独计税（§9.6）、专项附加扣除（§9.2，认知 ≥ 6）。
- 圈层语义（生存 / 积累 / 自由圈，《总体设计》§6）接入评分展示。
- 心魔卡系统（《行为金融与投资心理机制设计》）。

### P2（Agent 生态 · 全量卡池 · 复盘）

- Agent 银行家（结算播报）、Agent 教练（中场提问 / "我现在该做什么"）、Agent NPC 投资人 / 交易对手。
- 玩家间交易 / 四种拍卖（《交易拍卖与企业经营设计》）。
- 全量 75,115 张人物卡直连（按 D2–D7 六维切片索引抽卡）。
- 蒙特卡洛复盘 + 结构化人生财务报告（§14.4 完整版）。
- 跨局 Agent 记忆持久化（`LsmAgentGame-Wealth-MemoryIter`，按 §24 规则登记）。

### P3（十万级 Agent 规模化）

- 多房间并行调度（房间级 LLM 并发信号量，复用狼人杀 `RoomLLMConcurrency` 经验）。
- 月结批处理流水线化（LLM 决策预算控制：短上下文 / 决策缓存 / 档位化模型路由）。
- 卡池分片索引服务化（内存预算硬上限 + LRU 解析缓存，见职业卡加载器文档 §5）。
- 观赛大规模分发（`game.month` 汇总帧降频 / 差量推送）。
