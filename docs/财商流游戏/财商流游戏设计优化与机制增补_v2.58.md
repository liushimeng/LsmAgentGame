## 2. 交易系统升级：四种拍卖方式 + 赢家诅咒 + 同时暗标

> **来源**：《拍卖议价股票商业经营桌游机制对比与借鉴矩阵》表一（Modern Art 五种拍卖并存设计）+ 表四建议 B-6（Ra 有限竞价预算）+ C-22（双阵营限时谈判）。
> **补充引用**：《交易拍卖与企业经营设计》§4 已有四种拍卖机制规格，本节为 **v2.58 增补版**，补全赢家诅咒数值参数与同时暗标规则。

### 2.1 四种拍卖方式完整规则对照表

| 拍卖方式 | 来源游戏 | 流程 | 出价可见性 | 适用资产 | 时长预算 | 财商教学点 |
|---------|---------|------|-----------|---------|---------|-----------|
| **公开喊价（英式）** | Modern Art / Medici / Amun-Re | 从起拍价开始，玩家轮流递增喊价；无人加价时落槌成交 | 完全公开 | 稀缺机会卡、热门企业股权 | 90 秒 | 趋势跟踪、价格动量 |
| **密封投标（第一价格）** | Modern Art / For Sale / Stockpile | 所有买家同时提交密封出价；最高价者以自己出价金额得 | 出价保密，揭晓时公开 | 房产整售、大额股权交易 | 60 秒 | 估值能力、信息不对称 |
| **荷兰式（减价拍卖）** | 现代金融拍卖借鉴 | 从高价开始逐档递减；第一个喊"我要"的玩家以当前价得 | 价格公开递减，买家动作保密 | 大宗资产快速变现、清算资产 | 30 秒 | 机会成本、决策速度 |
| **一口价（定价销售）** | Modern Art（定价拍卖变体） | 卖方直接设定固定价；第一个接受者得 | 价格公开 | 标准化金融产品、挂牌房产 | 即时成交 | 流动性溢价、快速定价 |

**起拍价与底价规则**：
- 起拍价 = 资产公允价值 × 0.8（预留 20% 竞价空间）；
- 心理底价由卖方挂牌时填写（仅 Agent 可见）；
- 成交价低于心理底价时 Agent 自动不成交（卖方未"被胁迫"出售）。

### 2.2 密封投标详细规则（v2.58 新增补全）

```
T2 阶段·密封投标子模式：
  1. 卖方在 T1 挂牌时选择"密封投标"模式；
  2. T2 开始后 60 秒内，所有感兴趣的玩家在系统中提交：
     - 出价金额（必须 ≥ 起拍价）
     - 付款方式（现金 / 分期 / 资产置换）
  3. 60 秒到，Agent 同时揭晓所有出价：
     - 最高价者以其出价得资产；
     - 若最高价有两人相同：两人均不得，该资产流拍（借鉴 Las Vegas tie-cancels-out）；
  4. 流拍资产回到卖方手中，下一季度窗口重新挂牌。
```

**设计意图**（来源：For Sale 两阶段封闭循环 + Diplomacy 同时暗令）：
- 密封投标避免"谁先出价谁被拿捏"的跟价效应；
- 同时揭晓杜绝后动者看先动者出价再调整的漏洞；
- 同分作废规则模拟"拥挤交易"——两个买家同时看上同一资产时，双方都拿不到。

### 2.3 荷兰式拍卖详细规则（v2.58 新增补全）

```
T2 阶段·荷兰式子模式：
  1. 卖方选择"荷兰式快速变现"模式（适用于急需现金的场景）；
  2. Agent 从起拍价（公允价值×1.2）开始，每 5 秒自动递减一档；
  3. 递减档位：
     - 第 1–3 档：每档 −5%（快速试探市场热度）；
     - 第 4–8 档：每档 −3%（接近公允价值区间）；
     - 第 9 档起：每档 −1%（底价附近缓慢下降）；
  4. 任意玩家点击"我要"即以当前价成交；
  5. 价格降至心理底价仍无人响应：流拍，资产退回。
```

**设计意图**：荷兰式拍卖教"机会成本"——你犹豫 5 秒，价格降了，但你也可能等到更低价；第一个出手的人拿到的是"时间溢价"。

### 2.4 一口价交易规则（v2.58 新增补全）

```
T2 阶段·一口价子模式：
  1. 卖方挂牌时直接设定"一口价"（必须 ≥ 心理底价）；
  2. 该价格立即展示在交易大厅；
  3. 第一个点击"购买"的玩家即以一口价成交；
  4. 成交前其他玩家仍可发起议价挑战：
     - 玩家 B 可在一口价基础上 +5% 直接"截胡"购买；
     - 卖方选择：按原一口价给先到者，或接受更高价给 B；
     - 这模拟真实市场中的"加价截胡"现象。
```

### 2.5 同时暗标：借贷/入股的密封谈判格式（v2.58 新增）

> **来源**：Diplomacy 同时暗令 + 同时揭示机制（外交资料 §2.2）。

**适用场景**：玩家间借贷、合伙入股的利率/分红条件谈判。

```
同时暗标流程（借贷场景示例）：
  1. 借款方在系统中提交：借款金额、期望利率上限、期限；
  2. 贷款方在系统中提交：可贷金额、期望利率下限、期限；
  3. 双方同时提交，Agent 比对：
     - 若借款方利率上限 ≥ 贷款方利率下限：按中间价成交；
     - 若借款方利率上限 < 贷款方利率下限：不成交；
  4. 成交后系统自动写入合约，不可撤销。
```

**设计意图**：避免"谁先报价谁被拿捏"的议价困境——双方同时亮底牌，消除信息不对称中的先后手劣势。

### 2.6 赢家诅咒机制（v2.58 新增）

> **来源**：拍卖议价矩阵表三（赢家诅咒是拍卖理论经典现象）；Modern Art 排名博弈中的"出价过高"风险。

**触发条件**：拍卖成交价 > 资产公允价值 × 1.15（即超付 ≥15%）。

**效果**：

| 超付比例 | 触发效果 | 心魔卡 | 教学提示 |
|---------|---------|--------|---------|
| 15%–25% | 下期该资产收益 × 0.85 | XM-32（轻度） | "你赢了拍卖，但可能输了钱" |
| 25%–40% | 下期该资产收益 × 0.70 + 认知 −1 | XM-32（中度） | "你出的价比别人都高——为什么？" |
| >40% | 下期该资产收益 × 0.50 + 认知 −2 + 精力 −1 | XM-32（重度） | "赢家诅咒：在拍卖中赢的人，往往是最乐观、出价最高的人" |

**公允价值如何计算**：
- 房产：同区域同户型最近 3 次成交均价 × 0.95（流动性折价）；
- 股票：当前市场周期价格系数 × 每股净资产；
- 企业：年利润 × 行业平均市盈率（积累圈 5–8×，自由圈 8–12×）。

**Agent 提示**：拍卖前，Agent 向所有参与者显示"公允价值区间"（±10%），但不显示精确值——玩家需自己判断自己的出价是否合理。

## 3. 企业经营升级：FCM 六步现金流 + 并购红利 + 三权分离

> **来源**：《拍卖议价股票商业经营桌游机制对比与借鉴矩阵》建议 B-11（FCM 零运气经营日）+ B-12（刚性工资陷阱）+ C-17（Lords of Vegas 三权分离）+ C-19（Acquire 并购红利 10×/5×）。

### 3.1 FCM 六步现金流循环（v2.58 新增）

> **来源**：Food Chain Magnate（FCM）六步经营日——招聘→营销→晚餐→收入→工资→里程碑。
> **落点**：《交易拍卖与企业经营设计》§7 企业经营系统的"阶段三·成长期"每回合结算流程。

**六步循环**（每游戏月执行一次，Agent 自动结算，玩家只在关键节点做战略选择）：

```
┌─────────────────────────────────────────────────────┐
│  FCM 六步经营日（每回合一次）                         │
├─────────────────────────────────────────────────────┤
│  Step 1: 招聘（Recruit）                             │
│    - 玩家决定：本月是否招聘新员工？                    │
│    - 招聘成本：月薪 × 1.5（招聘费）                    │
│    - 员工到位后：产能 +X，但下月起每月发工资           │
│                                                     │
│  Step 2: 营销（Marketing）                           │
│    - 玩家决定：本月营销预算投多少？                    │
│    - 营销效果：下月客流 × (1 + 营销预算/月营收×0.3)    │
│    - 注：营销效果滞后一个月（FCM 核心设计）            │
│                                                     │
│  Step 3: 晚餐/产能（Dinner/Production）              │
│    - Agent 自动结算：本月能服务多少客户？              │
│    - 产能 = 员工数 × 单员工月产能                     │
│    - 若营销带来的需求 > 产能：流失客户（口碑下降）      │
│                                                     │
│  Step 4: 收入（Revenue）                              │
│    - Agent 自动结算：本月实际收入                      │
│    - 收入 = 成交客户数 × 客单价                       │
│    - 客单价由品牌等级决定（见 §3.1 品牌等级表）         │
│                                                     │
│  Step 5: 工资（Wages）                                │
│    - 刚性支出：所有员工工资 = 员工数 × 月薪           │
│    - ⚠️ 工资与本月营收无关——这就是"刚性成本陷阱"      │
│    - 若本月收入 < 工资总额：现金流为负，需从资金池补    │
│                                                     │
│  Step 6: 里程碑（Milestone）                          │
│    - Agent 检查：是否达到本月里程碑条件？               │
│    - 里程碑奖励：品牌等级提升 / 成本下降 / 新能力解锁   │
│    - 8 张里程碑卡（借鉴 FCM 原版 8 张里程碑）          │
└─────────────────────────────────────────────────────┘
```

**品牌等级表**：

| 品牌等级 | 客单价倍数 | 客流系数 | 解锁条件 |
|---------|-----------|---------|---------|
| L1 初创 | 1.0× | 0.8× | 开局默认 |
| L2 小有名气 | 1.2× | 1.0× | 累计营收 ≥ 50,000 元 |
| L3 区域知名 | 1.5× | 1.3× | 累计营收 ≥ 200,000 元 + 营销累计 ≥ 30,000 元 |
| L4 行业龙头 | 2.0× | 1.6× | 累计营收 ≥ 500,000 元 + 品牌里程碑 ≥ 4 张 |

**刚性工资陷阱教学点**（FCM 核心教学）：
- 低营收日才是最危险日——工资照发，但收入不够；
- 玩家必须在"招人扩张"和"保持现金安全垫"之间做取舍；
- Agent 在玩家招第 3 个员工时提示："你确定要招这么多人吗？如果下个月客流下降，工资会吃掉你的现金。"

### 3.2 并购红利 10×/5× 倍数（v2.58 新增）

> **来源**：Acquire（Sid Sackson, 1962）——酒店连锁并购时最大股东拿 10× 年利润、第二大拿 5×。

**适用场景**：自由圈企业被收购/IPO 退出时。

**分红规则**：

```
企业被收购时，收购方支付对价 = 企业估值（年利润 × 市盈率）
对价按以下优先级分配：

  第一顺位：最大股东（持股比例最高者）
    - 先拿走 10 × 年利润（一次性现金）
    - 若 10×年利润 > 对价：最大股东拿全部对价，其余股东 0

  第二顺位：第二大股东
    - 拿走 5 × 年利润（一次性现金）
    - 若剩余对价 < 5×年利润：拿剩余全部

  第三顺位：其余股东
    - 按持股比例分剩余对价

  第四顺位：优先股/债权方
    - 最后分配（若有剩余）
```

**数值示例**：
- 企业年利润 100,000 元，估值 800,000 元（8×PE）；
- 最大股东持股 40%：先拿 10×100,000 = 1,000,000 元；
- 但对价只有 800,000 元——最大股东拿全部 800,000，其余股东 0。
- **教学点**：这就是 Acquire 的"创始人套现"机制——早期大股东在并购中拿走大部分，小股东可能血本无归。条款比估值更重要。

### 3.3 股权稀释与三权分离（v2.58 新增）

> **来源**：Lords of Vegas（Selinker/Ernest, 2004）——地权≠控制权≠收益权，三权可分离。

**三种权利定义**：

| 权利 | 代号 | 含义 | 来源 |
|------|------|------|------|
| **收益权**（地权） | R | 按比例分利润/分红/清算款 | Lords of Vegas 地权 |
| **控制权**（Boss 权） | C | 决定企业经营决策（招人/营销/定价/并购） | Lords of Vegas 控制权 |
| **表决权**（骰面权） | V | 重大事项投票权（增资/清算/换 CEO） | Lords of Vegas 骰面权 |

**三权分离规则**：

1. **默认绑定**：初始创业时，创始人的 R/C/V 三权绑定（持股比例 = 收益权 = 控制权 = 表决权）。
2. **可分离交易**：融资扩张时，创始人可选择：
   - 只出让收益权 R（发优先股），保留控制权 C；
   - 出让控制权 C（聘请职业经理人），保留收益权 R；
   - 表决权 V 可按"一股一票"或"AB 股结构"分离（创始人持 B 类股，1 股 = 10 票）。
3. **股权稀释**：
   - 每轮融资 = 新股东入股，老股东收益权 R 被稀释；
   - 若创始人持股 <51%：可能失去控制权 C（被股东会罢免 CEO）；
   - 表决权 V 的稀释速度与 R 同步，除非使用 AB 股结构。

**教学点**：让玩家亲身体会"出钱多 ≠ 说了算"——这是真实商业世界中最容易被新手忽略的治理细节。

## 4. 社交系统升级：双层谈判 + 轮值税务官 + 隐藏老赖 + 临时合伙

> **来源**：《外交谈判与信任背叛类桌游资料》§2 Diplomacy + §3 Cosmic Encounter + §4 Shadows Over Camelot + §5 Sheriff of Nottingham + §6 The Resistance/Avalon。

### 4.1 双层谈判模型（v2.58 新增）

> **来源**：Diplomacy（自由密谈 + 口头承诺不可执行）+ Chinatown（当场交割、无背叛）。

**双层结构**：

| 层级 | 适用场景 | 承诺是否可执行 | 交割方式 | 来源 |
|------|---------|--------------|---------|------|
| **现货交易层**（T2 交易窗口内） | 即时买卖资产、借贷 | 必须当场交割，不可挂账 | 一手交钱一手交货 | Chinatown |
| **长期合伙层**（跨回合协议） | 合伙创业、长期联盟、口头约定 | 系统只记录事件日志，不强制执行 | 到期自动清算，违约靠社交制裁 | Diplomacy |

**规则细节**：
- **现货层**：严格执行"谈成即交割"，不允许"下回合再给你"——这消灭了现货交易中的背叛空间（适合低龄/新手局）。
- **长期层**：玩家可在密谈中承诺"下季度我分你 20% 利润"，系统不写入合约；若违约，其他玩家可在下一次谈判中引用此违约记录，降低信任评级（借鉴 Diplomacy 的群体自发制裁）。
- **社交制裁量化**：连续 2 次不履行口头约定的玩家，下一季度其他玩家对其交易自动获得 +10% 议价权（即社交惩罚由系统结算）。

### 4.2 轮值税务官机制（v2.58 新增）

> **来源**：Sheriff of Nottingham（2014）——警长轮值、监管者本身是玩家、贿赂博弈。

**规则**：

```
每季度交易窗口（T1–T3）期间：
  1. 随机指定 1 名玩家担任"轮值税务官"（当季银行家角色）；
  2. 税务官权力：
     - 有权抽查任意 1 名玩家的本季度报税记录；
     - 查出未申报收入：补税 + 罚款（未申报税额 × 2），罚款归税务官；
     - 查清白（如实申报）：税务官自付调查费 2,000 元（赔偿被冤枉者的时间成本）；
  3. 贿赂博弈：
     - 被抽查的玩家可在抽查前向税务官行贿（现金/承诺）；
     - 税务官可接受贿赂并放弃抽查；
     - 但贿赂承诺不强制执行——税务官可以收了贿还开袋（借鉴 Nottingham 的"贿赂可空头"）；
  4. 诚实者保护：
     - 如实申报却被抽查的玩家，获税务官支付的调查费赔偿；
     - 这防止税务官滥用权力乱查。
```

**教学点**：
- 监管者不是中立 NPC，而是有自己利益的玩家；
- 合规激励相容——乱查清白者要自掏腰包，这是制度性制衡；
- 灰色收入是"高收益高风险"的二元结构，不是温和扣钱。

### 4.3 隐藏老赖（信用评级不公开）（v2.58 新增）

> **来源**：The Resistance/Avalon（隐藏身份）+ Shadows Over Camelot（叛徒机制）。

**规则**：

```
1. 信用评级半公开化（修改原 §6 信用系统）：
   - 原规则：所有玩家信用评级公开可见；
   - v2.58 修改：信用评级仅自己可见 + Agent 可见；
   - 其他玩家只能通过"人脉检定"（消耗人脉点）查询对方的"信用区间"（如"中等"而非具体分数）。

2. 隐藏老赖变体（6 人以上局可选）：
   - 每局随机指定 1 名玩家为"隐藏老赖"（仅自己知道）；
   - 隐藏老赖在合伙创业事件中拥有"秘密抽走合伙公司季度净利润 10%"的能力；
   - 他必须维持正常分红假象（抽走的钱不体现在公开报表上）；
   - 其他玩家可公开指控：
     - 指控正确（确实是老赖）：老赖全部资产罚没，指控者获得罚没资产的 30%；
     - 指控错误（被指者不是老赖）：指控者信用分 −10 分 + 赔偿被冤枉者 5,000 元；
   - 终局结算：老赖若全程未被识破，抽走的资金归他所有；若被识破，全部罚没。
```

**设计原则**（借鉴 Avalon）：
- 任务失败不暴露具体是谁——只知道"项目黄了"，让玩家自己复盘归因；
- 错误指控有成本——防止"看谁不顺眼就投谁"的暴政；
- 3 人以下小局不启用此变体，避免内鬼伤害过大。

### 4.4 临时项目制合伙（v2.58 新增）

> **来源**：Cosmic Encounter——联盟按"单次遭遇"缔结，无长期承诺。

**规则**：

```
1. 默认合伙期限：3 个游戏回合（1 个游戏季度）；
   - 合伙目的：共同投资某个具体项目（如合伙买一套房、合伙开一家店）；
   - 项目清算后自动散伙，下次再谈新的合伙；

2. 出资与分红：
   - 按出资比例分配现金流与退出收益；
   - 合伙人必须真金白银出资（押筹码），避免"嘴上合伙人"；

3. 退出机制：
   - 3 回合到期自动清算散伙；
   - 提前退出：需其他合伙人同意，或按当前净值的 80% 强制赎回（惩罚性折价）；
   - 借鉴 Cosmic Encounter：背叛无长期记忆——上一回合临阵脱逃的人，下一回合别人可能还需要他。

4. 长期合伙（可选）：
   - 若玩家想建立长期合伙（如共同经营一家企业），需额外签署"长期合伙协议"：
     - 期限 12 回合（1 年）；
     - 中途退出需支付违约金 = 初始出资 × 30%；
     - 这模拟真实世界的"创业合伙人"绑定。
```

**设计意图**：从"签了合伙人卡就是终身绑定"改为"项目制合作"，更接近真实世界的项目制合伙，也避免"离婚式散伙"的痛苦。

## 5. 行为金融升级：EV 显式化 + 继续vs收手 + Martingale + 蒙特卡洛 + 热手检测

> **来源**：《概率数学与随机性教育类桌游资料》§2 Risk + §3 Can't Stop + §5 赌场数学 + §6 大数定律教学 + §8 七条建议。

### 5.1 EV 显式化（v2.58 新增）

> **来源**：概率数学资料 §8 建议1——所有投资格在决策前显示完整 EV 表。

**规则**：

```
所有投资格在玩家决策前，UI 强制显示完整期望值表：

┌─────────────────────────────────────────┐
│  投资机会：XX 股票                       │
│  投入金额：50,000 元                     │
│                                         │
│  成功情景（60% 概率）：                   │
│    收益 +20% → 10,000 元                │
│                                         │
│  失败情景（30% 概率）：                   │
│    收益 −10% → −5,000 元                 │
│                                         │
│  极端情景（10% 概率）：                   │
│    收益 −100%（退市）→ −50,000 元        │
│                                         │
│  ─────────────────────────────          │
│  期望值 EV = 0.6×10,000                  │
│           + 0.3×(−5,000)                │
│           + 0.1×(−50,000)                │
│         = 6,000 − 1,500 − 5,000          │
│         = −500 元                        │
│  隐含手续费：0.5%（买卖价差 + 印花税）    │
│                                         │
│  ⚠️ 该投资 EV 为负，你确定要投吗？        │
└─────────────────────────────────────────┘
```

**设计原则**：
- 禁止"暗骰"——玩家在掷骰子前就知道完整概率分布；
- EV 计算公式公开透明：EV = Σ P(结果) × 损益；
- 手续费/滑点/点差必须显式列出，让玩家一眼看出真实 EV。

### 5.2 继续 vs 收手双选机制（v2.58 新增）

> **来源**：Can't Stop（Sid Sackson, 1980）——Push-Your-Luck 经典实验。

**规则**：

```
所有持仓类投资（股票、房产、企业股权）在每季度开始时：
  1. Agent 显示当前持仓浮盈/浮亏；
  2. 玩家必须二选一：
     A「止盈卖出」：按当前市价卖出，落袋为安；
     B「继续持有」：再持一季度，显示下季度 EV 表；
  3. 若选 B，下季度结束后再次触发此选择（循环）；
  4. 若持仓浮亏 ≥20%，增加选项 C「止损卖出」：
     - 与"止盈卖出"的区别是：止损卖出触发心魔卡 XM-01（割肉之痛）的认知检定；
     - 止盈卖出不触发心魔卡。
```

**Can't Stop 式边际决策**：
- 把"持有"从默认动作变成需要决策的动作；
- 显示"再持一季度"的 EV 差，让玩家自己算边际收益；
- 已赚的钱不是沉没成本，而是继续下注时可能损失的筹码。

### 5.3 Martingale 心魔卡（v2.58 新增 XM-31）

> **来源**：赌场数学教具——Martingale 倍投策略数学必败原理。

```
编号：XM-31
卡名：Martingale 倍投诱惑
偏差类型：赌徒谬误 + 追损 + 过度自信
适用圈层：自由圈（仅成人局）
触发条件：投资连续亏损 ≥3 次，且当前持仓浮亏 ≥15%
即时效果：系统弹出选项：
  A「收手止损」：接受当前亏损，结束本轮投资；
  B「Martingale 倍投」：加倍投入，赌下一把回本。
  选 B 的规则：
    - 新投入 = 原投入 × 2；
    - 若下一把赢：总收益 = 原投入 × 1（覆盖亏损 + 净赚 1 单位）；
    - 若下一把输：总亏损 = 原投入 × 3（亏损翻倍）；
    - 系统强制展示教学提示：
      "Martingale 不改变游戏的负期望值，
       它只是把'偶尔小赢 + 一次大输'
       替换成'经常小赢 + 一次毁灭性大输'。
       连输 10 把的概率 = (0.5135)^10 ≈ 0.12%，
       但玩 1000 把必然遇到——
       遇到时赌注已经翻倍到 2^10 = 1024 倍。"
持续回合数：即时结算
解除条件：即时结算
认知检定：阈值 6
认知奖惩：选 A → +1；选 B 且亏损 → −2
复盘揭示文案："你选择了倍投，结果是{outcome}。
  Martingale 的数学真相：
  它不改变长期收益率，只是让方差变得极端。
  真实赌场有投注上限——玩到第 9 把就触顶，
  无法继续翻倍。你的本金是有限的，
  即使无桌限，连输 20 把需要本金 100 万倍基础单位。"
```

### 5.4 1000 局蒙特卡洛复盘（v2.58 新增系统机制）

> **来源**：概率数学资料 §8 建议5——大数定律教学。

**规则**：

```
游戏终局结算后，自动进入"蒙特卡洛复盘"模块：
  1. Agent 将本局玩家的投资策略（各类资产配置比例、买卖时点）
     投入 1000 次蒙特卡洛模拟；
  2. 显示收益分布柱状图：
     - X 轴：终局净值区间；
     - Y 轴：模拟次数；
     - 标注：本局实际净值所在分位数（前 10%？中位数？后 10%？）；
  3. Agent 教练点评：
     "本局你的策略在 1000 次模拟中中位数收益是 X%，
      你本局实际收益 Y% 偏离中位数 Z%。
      偏离的主要来源是运气（骰子/事件）而非策略——
      单局结果受运气影响大，长期策略 EV 才是关键。"
```

**教学点**：
- 大数定律：重复试验次数 →∞ 时频率趋近概率；
- 单局结果受运气影响大，不要把几轮的运气当成规律；
- 这是"短样本偏差"的直接教学——本局只玩了 30–50 轮，恰好是"短样本"。

### 5.5 热手检测心魔卡（v2.58 新增 XM-33）

> **来源**：Gilovich/Vallone/Tversky 1985 热手效应研究；概率数学资料 §8 建议6。

```
编号：XM-33
卡名：热手效应错觉
偏差类型：热手效应 + 过度自信
适用圈层：全圈层
触发条件：玩家连续 3 次投资盈利
即时效果：下一次投资决策时，系统弹窗提示：
  "你已经连续赢了 3 次，
   是不是觉得自己手气特别好？
   ⚠️ 独立事件无记忆——
   本次胜率与过去 3 次盈利无关。"
  若玩家此时追加仓位 > 净资产 30%：
    下次投资负面事件概率 +15%（模拟"飘了"后的失误率上升）；
  结算后展示教学卡：
    "Gilovich 1985 年研究 NBA 投篮发现：
     连续投中后下一球命中率提高是错觉——
     真实命中率与过去 5 球是否命中无关。
     但球员和球迷普遍相信'手热'。
     投资市场同理：过去 3 次盈利
     不代表第 4 次更可能盈利。"
持续回合数：1（仅下一次投资）
解除条件：下次投资结算后自动解除
认知检定：阈值 5
认知奖惩：追加仓位且亏损 → −1；理性控制仓位 → +1
复盘揭示文案："你连续赢了 3 次后{action}，
  结果是{outcome}。
  这就是热手效应——把随机连胜误当技能。
  过去的表现不代表未来。"
```

## 6. 职业系统升级：薪资天花板 + P/M 双通道 + 跳槽成本 + 年度绩效

> **来源**：《职场晋升与薪资谈判博弈及2024-2026财商教育趋势资料》§2 Game of Life + §4 Peter Principle Game + §5 Sysifus Corp + §13 八条建议。

### 6.1 薪资天花板 + Peter Principle（v2.58 新增 §10.5）

> **来源**：Game of Life 薪资上限机制 + Peter Principle Game（1973）。

**规则**：

```
1. 每个职业卡新增"薪资上限"字段：
   - 月薪从入职起每年 +3%（原规则 §1.3）；
   - 到达薪资上限后，再走"升职"格不涨薪；
   - 薪资上限 = 入职月薪 × 3.0（即涨薪 3 倍后到顶）；

2. 职业天花板状态：
   - 到达上限后进入"职业天花板"状态；
   - 此时若继续冲管理岗晋升：
     - 每升一级"无能值" +1；
     - 无能值 = 决策失误率加成（每次职业相关掷骰，失误概率 +无能值×5%）；
     - 当无能值 ≥5：触发"彼得原理事件"——被降级或换岗；
   - 留在专家岗（P 线）：薪资不再涨，但无 Peter Principle 风险。
```

**各职业薪资上限参考**（估算，基于 2025 居民收支锚点）：

| 职业 | 入职月薪 | 薪资上限（×3.0） | 达到上限所需年数（每年+3%） |
|------|---------|----------------|--------------------------|
| P01 外卖骑手 | 5,000 | 15,000 | 约 37 年（基本达不到） |
| P05 小学教师 | 9,000 | 27,000 | 约 37 年 |
| P09 初级程序员 | 15,000 | 45,000 | 约 37 年 |
| P10 医生 | 25,000 | 75,000 | 约 37 年 |
| P12 高级专家 | 40,000 | 120,000 | 约 37 年 |

> **注**：×3.0 倍率为估算值，实际游戏中需根据职业类型调整——技术岗 ×3.5、体制内 ×2.5、销售岗 ×4.0（底薪低但提成空间大）。

### 6.2 P/M 双通道晋升（v2.58 新增 §10.7）

> **来源**：Up the Corporation（学历/工龄双通道）+ Peter Principle Game。

**规则**：

```
1. 30 岁节点（第 10 个钟声前），玩家必须选择晋升通道：
   - P 线（专业/专家序列）：
     * 薪资增长平稳，无 Peter Principle 风险；
     * 但终局财富排名上限低（无股权/分红权）；
     * 适合保守型、焦虑型玩家画像；
   - M 线（管理序列）：
     * 薪资增长快，有股权/分红权；
     * 但 Peter Principle 风险累积（无能值随晋升级次上升）；
     * 适合激进型、理性型玩家画像；

2. 通道一旦选定不可切换（模拟真实职场的"转管理难、转专业更难"）；

3. M 线股权机制：
   - 每升一级 M，获得公司股权激励（年利润 ×0.5% 的分红权）；
   - 升到 M5（总监级）：累计分红权 ≥2.5%；
   - 这模拟真实职场中管理岗的"金手铐"。
```

### 6.3 跳槽成本模型（v2.58 新增 §10.8）

> **来源**：Sysifus Corp 公共项目路径设计 + 职场资料 §13 建议3。

**规则**：

```
主动跳槽（玩家主动选择换职业）：
  1. 前司工龄清零：
     - 失去前司累积的年度调薪加成；
     - 失去前司未行权的股权/分红权；

  2. 新司试用期（前 2 个游戏季度）：
     - 薪资 −20%（试用期打折）；
     - 不可申请升职；
     - 不可参与公司重大决策投票；

  3. 新司溢价（第 3 季度起）：
     - 薪资 +30%（跳槽溢价）；
     - 行业扩张期：溢价 +50%（人才稀缺）；
     - 行业收缩期：溢价仅 +10%，且有 20% 概率跳到更差的公司（薪资反而 −10%）；

  4. 签约奖金（一次性）：
     - 新公司支付 1–3 个月工资作为签约奖金；
     - 入职即发，若 12 个月内离职需退还 50%。
```

**教学点**：跳槽不是"涨薪的捷径"——有试用期成本、工龄损失、行业周期风险。

### 6.4 年度绩效评估（v2.58 新增 §10.6）

> **来源**：Sysifus Corp 年度绩效评估机制。

**规则**：

```
每 12 个游戏回合（1 个游戏年）进行一次年度绩效评估：
  1. 评估内容：
     - NPC 老板打分（基于过去一年的工作表现：是否按时完成任务、是否触发职业危机事件等）；
     - 其他玩家社交投票（在"众生相"教学局中，其他玩家可作为"同事"投票）；

  2. 评估结果三档：
     - 优秀（≥80 分）：下年度薪资 +20% + 绩效奖金（2 个月工资）；
     - 合格（60–79 分）：薪资持平；
     - 不合格（<60 分）：
       * 薪资 −10%；
       * 或被解雇（进入失业状态，需重新找工作）；
       * 连续 2 年不合格：强制进入"职业转型"事件。

  3. 办公室政治卡（可选变体）：
     - 借鉴 Sysifus Corp 的 25 张办公室政治卡：
       * 抢功：把别人的项目成果算到自己头上；
       * 甩锅：项目失败后把责任推给同事；
       * 越级汇报：绕过直属领导找大老板；
     - 这些卡可影响绩效评估结果，但被识破会降低信用评级。
```

## 7. 新增投资品：碳交易配额（ESG 扩展包）

> **来源**：《职场晋升与薪资谈判博弈及2024-2026财商教育趋势资料》§12 ESG/绿色金融类教育游戏 + 建议5。
> **参考产品**：Electric Factory（2025 Sustainability Expo）、CO₂ Permits Online Game、Daybreak（2023）。

### 7.1 设计定位

碳交易配额是**可选扩展包**，默认不启用；适合"进阶局"或"ESG 主题局"。

### 7.2 规则规格

```
新增投资品：碳排放配额（CEA, Carbon Emission Allowance）

1. 配额分配（每年初）：
   - 高污染行业职业（传统制造、燃油车投资、火电）：
     * 每年免费获得 100 吨碳配额；
     * 实际排放量若 >100 吨：超出部分需购买配额；
   - 绿能/ESG 投资品（光伏、风电、植树造林）：
     * 每年产生 50–200 吨碳信用（可售）；
     * 投资绿电项目：每吨碳信用产生成本 30 元；
     * 出售碳信用：市场价 50–100 元/吨；

2. 碳价波动：
   - 政策驱动：每年政策收紧（"双碳目标"推进），碳价年均 +10%–20%；
   - 市场驱动：
     * 高碳玩家多 → 碳价上涨（供不应求）；
     * 绿能玩家多 → 碳价下跌（供过于求）；
   - 开局碳价：60 元/吨（估算，参考全国碳市场 2025 年均价）；

3. 交易规则：
   - 碳配额可在季度交易窗口买卖；
   - 最小交易单位：10 吨；
   - 无交易手续费（政策鼓励）；

4. 违约惩罚：
   - 年底未结清排放（排放量 > 配额持有量）：
     * 每吨罚款 200 元（远高于市场价）；
     * 信用评级 −2 级。
```

### 7.3 教学点

- **外部成本内部化**：污染不是"免费"的——你多排的碳，必须花钱买；
- **政策驱动价格**：碳价不取决于市场供需，而取决于政策收紧节奏——这是"政策市"的直接教学；
- **ESG 投资不是道德选择，而是财务选择**：投资绿能不仅有社会价值，还能产生可出售的碳信用现金流。

## 8. AI 教练层设计

> **来源**：《职场晋升与薪资谈判博弈及2024-2026财商教育趋势资料》§10 AI + 财商教育结合（FinQuest AI / Kidonomic / Finelo）+ 建议4。

### 8.1 AI 教练定位

AI 教练是**线上版可选模块**，线下版由真人教练替代。

**核心原则**（伦理红线）：
- AI 不提供具体投资建议（持牌要求）；
- AI 的话术必须"引导用户自己决策"而非"替用户决策"；
- 青少年版符合 COPPA / 中国未成年人个人信息保护规定。

### 8.2 功能规格

```
AI 理财教练（可关闭）：

1. 投资决策后追问（苏格拉底式）：
   - 每次投资决策后，AI 教练弹出追问：
     "你这次决策的 EV 是多少？"
     "你为什么觉得这支股票会涨？"
     "如果跌了 20% 你会怎么办？"
   - AI 不直接给建议，而是引导玩家自己复盘；

2. 行为数据分析：
   - AI 分析玩家的消费/投资模式：
     * 是否频繁追涨杀跌？
     * 是否有冲动消费倾向？
     * 是否过度集中投资某类资产？
   - 在冲动消费前弹窗提醒："你这是在冲动消费吗？"

3. 自适应学习路径：
   - 根据玩家在模拟盘中的错误推送针对性课程：
     * 频繁追涨 → 推送"均值回归"课程；
     * 过度保守 → 推送"复利与长期主义"课程；
     * 集中投资 → 推送"资产配置"课程；

4. 青少年版 vs 成人版：
   - 青少年版（12–15 岁）：
     * 语气更温和；
     * 降低骰子随机性；
     * 提高 EV 教学显式度；
   - 成人版：
     * 可加入"灵魂拷问"式复盘；
     * 保留真实市场的高方差；
     * 让玩家体验"短样本下策略无效"的挫败感。
```

### 8.3 线下教练模式参考

> **来源**：财富流教练认证体系（¥6980/14天/5板块）。

**线下版教练角色**：
- 认证教练负责主持游戏、引导复盘、解答规则疑问；
- 教练培训体系参考财富流：14 天培训 + 5 大板块（规则精通/复盘引导/行为观察/伦理规范/课程设计）；
- 教练不是裁判，而是"苏格拉底式提问者"——不替玩家做决定，而是引导玩家自己发现问题。
