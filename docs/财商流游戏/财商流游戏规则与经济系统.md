## 1. 回合结构

### 1.1 回合阶段顺序

每位玩家的一个回合严格按以下 7 个阶段执行，不可跳阶段：

| 阶段 | 名称 | 玩家可做的事 | 结算内容 |
|------|------|-------------|---------|
| **S1** | 自由动作（回合前） | ①偿还贷款本金；②向银行申请新贷款；③与其他玩家交易（买卖资产/借贷/合伙）；④买卖在市场上挂牌的资产 | 即时结算现金与报表变动 |
| **S2** | 掷骰前进 | 掷 1 颗六面骰（自由圈为 2 颗），按点数在当前圈层顺时针移动 | 无 |
| **S3** | 落脚格事件 | 按落点格子类型执行（详见《棋盘与道具设计》第 2–4 章） | 事件效果即时结算 |
| **S4** | 月结（若经过/停留结算日格） | 领取月工资 + 所有被动收入；扣除所有月支出 + 税 + 社保 + 利息 | 现金流量表月结，三表更新 |
| **S5** | 自由投资动作 | ①用闲钱买债券/理财；②购买保险；③提升认知（学习）；④联系人脉（社交） | 即时结算 |
| **S6** | 报表更新 | 所有本回合发生的交易/事件更新到三表；Agent 自动校验勾稽关系 | 三表勾稽校验 |
| **S7** | 目标检查 | 检查：①FI Index 是否达到圈层切换条件；②精力是否触发健康事件；③年龄是否触发钟声 | 状态变更 |

### 1.2 回合时间推进

- 1 个回合 = 1 个游戏月。
- 每绕当前圈层一整圈（经过 1 次结算日格）= 1 个游戏年。
- 每经过 12 个回合（12 个月）= 1 个游戏年，触发**年度结算**（见 1.3）。
- 每经过 5 个游戏年（60 个回合）= **钟声**，全场年龄 +5 岁，触发第 11 章人生事件与市场周期重掷。

### 1.3 年度结算（每 12 回合一次）

除月结外，每 12 个回合额外执行年度结算：

| 项目 | 规则 | 对应真实概念 |
|------|------|-------------|
| **通胀调整** | 所有生活支出 +5%（因 CPI 每年约 2%–3%，游戏中加速为 5% 以在 40 年内体现效果） | 通货膨胀 |
| **工资增长** | 主动收入每年 +3%（模拟行业平均涨薪） | 工资增长 |
| **投资品价格** | 按当前市场周期阶段调整（见第 7 章） | 资产价格波动 |
| **养老金缴存** | 工资的 8% 自动划入养老金账户（资产表增加） | 中国社保养老金 |
| **年度税结算** | 全年总收入按累进税率汇算，多退少补（见第 9 章） | 个税年度汇算 |

### 1.4 玩家顺序与等待

- 开局掷骰决定先手，顺时针轮流。
- 玩家在 S1/S5 阶段的交易必须在 30 秒内完成（线上版 60 秒），超时则跳过交易直接进入 S2。
- 其他玩家在非自己回合时可自由观察、讨论，但不能替玩家做决定。

## 2. 五维资源系统

### 2.1 总览

| 资源 | 代号 | 初始值（因职业而异） | 上限 | 下限 | 恢复机制 |
|------|------|---------------------|------|------|---------|
| 金钱（现金） | C | 5,000–200,000 | 无 | 0（现金为负即欠款） | 月结发薪、出售资产 |
| 时间（年龄） | T | 20 岁 | 60 岁 | 不可逆增长 | 无（时间只增不减） |
| 精力 | E | 5–9 点 | 10 点 | -3（≤ -3 触发健康危机） | 休息、好事件 |
| 人脉 | N | 1–7 点 | 10 点 | 0 | 社交事件、合作投资 |
| 认知 | K | 1–8 点 | 10 点 | 0 | 学习、培训、经验积累 |

### 2.2 金钱

- **现金**：手头可立即动用的人民币。
- **资产**：现金 + 股票市值 + 房产估值 + 企业估值 + 养老金 + 贵金属 + 债券。
- **负债**：房贷 + 车贷 + 消费贷 + 信用卡 + 经营贷。
- **净值 = 资产 - 负债**。
- 详细科目见第 3 章三表联动。

### 2.3 时间（年龄轴）

- 开局 20 岁。每 60 回合（5 年）钟声一响，年龄 +5。
- **年龄对游戏的影响**：
  - 20–30 岁：生存圈，可创业窗口开放，精力上限 +1（年轻体壮）。
  - 30–45 岁：积累圈，收入高峰期，但家庭支出上升。
  - 45–60 岁：自由圈冲刺期，可申请退休（见第 11 章）。
  - 60 岁：游戏强制终局，无论当前状态。
- **对应真实世界概念**：人力资本随年龄变化、职业生命周期。

### 2.4 精力

- **范围**：-3 到 10 点。
- **消耗场景**：

| 动作 | 精力消耗 |
|------|---------|
| 购买股票（每只） | 1 点 |
| 投资副业 | 3 点（维持期每月 -1） |
| 投资企业 | 4 点（成长期前 12 月每月 -1） |
| 购买房产 | 2 点 |
| 结婚 | 2 点 |
| 生子 | 3 点 |
| 离婚 | 4 点 |
| 失业后找工作 | 2 点 |
| 生病/住院 | 3 点 |
| 学习提升认知 | 1 点 |

- **恢复机制**：
  - 每回合开始时，若精力 < 上限，自动恢复 1 点。
  - 停留"休息格"：自愿选择，付 0.5 个月支出，精力恢复至满。
  - 好事件（升职、结婚纪念日、孩子考上好学校）：+1 到 +3 点。
  - 每年生日（钟声时）：若该年未生大病，+2 点。
- **精力为负的后果**：
  - 精力 -1 到 -2：下回合无法进行任何"消耗精力"的动作（只能收租、领工资）。
  - 精力 -3：触发"健康危机"事件，强制住院停 2 回合，医疗支出 5,000–30,000 元（因病种而定），若无力支付则加速破产流程。
- **对应真实世界概念**：健康是底层资产，体力是行动的前提。

### 2.5 人脉

- **范围**：0 到 10 点。
- **获取方式**：
  - 结婚：+2 点（配偶的社会关系）。
  - 合作投资（与其他玩家或 Agent 合伙）：+1 点/次。
  - 停留"社交格"：付 1,000 元宴请，+1 点。
  - 升职：+1 点。
  - 慈善捐赠：+1 点/次（累计 3 次后不再加）。
- **消耗/使用方式**：
  - 找工作（失业后）：人脉 ≥ 5 时，掷骰成功率 +20%（从 50% 提升到 70%）。
  - 交易议价：人脉 ≥ 7 时，玩家间交易可要求 5%–10% 的折扣或溢价。
  - 获得机会卡：人脉 ≥ 5 时，在"机会格"可多选 1 张卡。
  - 企业融资：人脉 ≥ 7 时，可获得 Agent 投资人的青睐（见第 6.3 节）。
- **对应真实世界概念**：社会资本、弱关系与强关系、人脉变现。

### 2.6 认知

- **范围**：0 到 10 点。
- **获取方式**：
  - 停留"学习格"：付学费 2,000 元，+1 点认知（同时精力 -1）。
  - 每年钟声时，若过去 12 回合内做过至少 3 次投资决策，+1 点认知（经验积累）。
  - 抽到"认知卡"：直接 +1 点。
  - 读完一本书（购买"书籍卡"500 元）：+1 点。
- **作用**：
  - **降低投资风险**：认知每高 1 点，所有投资品的负面事件触发概率 -5%（上限 -30%）。
  - **解锁高级机会**：认知 ≥ 3 解锁中型房产；认知 ≥ 5 解锁企业投资；认知 ≥ 7 解锁自由圈大额项目。
  - **税务优化**：认知 ≥ 6 时，每年税结算可申请"专项附加扣除"，个税 -10%。
  - **识破骗局**：认知 ≥ 4 时，"诈骗卡"触发概率 -50%。
- **对应真实世界概念**：财商教育、经验曲线、认知税。

### 2.7 五维资源互动矩阵

| | 金钱 | 时间 | 精力 | 人脉 | 认知 |
|---|---|---|---|---|---|
| **金钱** | — | 用钱买时间（雇人） | 花钱买休息/医疗 | 花钱社交 | 花钱上学 |
| **时间** | 时间换工资 | — | 休息恢复精力 | 社交花时间 | 学习花时间 |
| **精力** | 精力换收入（副业） | 精力耗尽老得快 | — | 社交耗精力 | 学习耗精力 |
| **人脉** | 人脉变现（中介费） | 人脉需要维护 | 社交耗精力 | — | 人脉带来学习机会 |
| **认知** | 认知提高投资收益 | 认知随时间增长 | 学习耗精力 | 人脉交流提升认知 | — |

## 3. 三表联动财务系统

### 3.1 三张表总览

| 报表 | 周期 | 核心公式 | 更新时机 |
|------|------|---------|---------|
| 损益表（月） | 月结 | 月利润 = 收入 - 支出 | 每次月结 |
| 资产负债表 | 实时 | 资产 = 负债 + 净值 | 每次交易 |
| 现金流量表（月） | 月结 | 期末现金 = 期初现金 + 经营净流 + 投资净流 + 筹资净流 | 每次月结 |

### 3.2 损益表科目设计

#### 3.2.1 收入科目

| 大类 | 子科目 | 说明 |
|------|--------|------|
| **主动收入** | 工资（税前） | 职业卡初始值，每年 +3% |
| | 副业收入 | 副业卡产生，需持续精力 |
| | 配偶工资 | 结婚后加入，离婚后移除 |
| **被动收入** | 租金收入 | 出租房产月租 - 月供 - 维修 |
| | 股票分红 | 持有分红股，按季度发放 |
| | 债券利息 | 持有债券，每月计息 |
| | 企业分红 | 投资企业，按季度分红 |
| | 养老金（60 岁后） | 退休后每月领取 |
| **资本利得** | 卖出价差 | 房产/股票/贵金属卖出时一次性确认 |

| 大类 | 子科目 | 说明 |

| | 配偶生活 | 已婚时 +2,000 元/月 |
| | 子女抚养 | 每个孩子 3,000 元/月（0–18 岁） |
| | 教育支出 | 每个孩子另加 1,000–5,000 元/月（学区/补习班） |
| **债务支出** | 车贷月供 | 车贷 × 月供系数 |
| | 消费贷月供 | 消费贷 × 月供系数 |
| | 信用卡还款 | 每月最低还款 = 余额 × 10% |
| | 经营贷利息 | 经营贷余额 × 月利率 |
| **保障支出** | 保险费 | 年缴保费 / 12 |
| | 医疗自付 | 生病时扣除医保后自付部分 |
| **其他支出** | Doodad 类意外支出 | 事件卡触发，不可预测 |

### 3.4 勾稽关系（会计恒等式）

```
1. 资产负债表恒等式：
   总资产 = 总负债 + 净值（净资产）

2. 损益表 → 资产负债表：
   期末净值 = 期初净值 + 本期净利润 - 分红（生活消费从利润中扣除）

3. 现金流量表 → 资产负债表：
   期末现金 = 期初现金 + 经营活动净现金流 + 投资活动净现金流 + 筹资活动净现金流

4. 损益表 → 现金流量表：
   经营活动净现金流 ≈ 月利润 + 非现金支出（折旧） ± 营运资本变动
   （游戏中简化为：经营净现金流 = 月利润，因为无应收账款概念）
```

### 3.5 月结流程（S4 阶段详细步骤）

每次经过"结算日"格，按以下顺序结算：

```
步骤1：发放主动收入
  → 银行家发放本月工资（税后？不，先全额发放，税在步骤4扣除）
  → 发放配偶工资（若已婚）
  → 发放副业收入（若有）

步骤2：发放被动收入
  → 收取所有出租房产的租金（现金流入）
  → 收取股票分红（按季度发放，仅 3/6/9/12 月）
  → 收取债券利息（每月）
  → 收取企业分红（按季度）
  → 收取养老金（仅 60 岁后）

步骤3：扣除固定支出
  → 扣除房贷月供
  → 扣除车贷月供
  → 扣除房租（若未买房）
  → 扣除保险费（月均）
  → 扣除物业费

步骤4：扣除税与社保
  → 计算本月个税（见第 9 章）
  → 扣除社保（工资的 10.5%）

步骤5：扣除可变支出
  → 扣除生活支出（本人+配偶+子女）
  → 扣除教育支出
  → 扣除医疗自付（若生病）
  → 扣除 Doodad 意外支出

步骤6：扣除债务利息/还款
  → 偿还信用卡最低还款额（若有余额）
  → 偿还消费贷月供
  → 支付经营贷利息

步骤7：计算月现金流
  → 月现金流 = 总收入 - 总支出
  → 现金增加/减少 = 月现金流
  → 更新现金流量表

步骤8：更新资产负债表
  → 现金科目变动
  → 房贷/车贷/消费贷余额减少（月供中的本金部分）
  → 净值 = 资产 - 负债
```

## 4. 收入系统

### 4.1 主动收入

| 类型 | 来源 | 计算方式 | 稳定性 |
|------|------|---------|--------|
| 工资 | 职业卡 | 初始值 × (1 + 3%)^(年龄-20) | 高（除非失业） |
| 副业收入 | 副业卡 | 卡面固定金额，每月发放 | 中（需精力维持） |
| 配偶工资 | 结婚卡 | 配偶职业卡工资 | 高（除非离婚/失业） |
| 自由职业 | 认知 ≥ 4 解锁 | 按单结算，金额波动大 | 低（多劳多得） |

### 4.2 被动收入

| 类型 | 来源 | 计算方式 | 稳定性 |
|------|------|---------|--------|
| 租金净收入 | 出租房产 | 月租 - 月供 - 物业费 - 维修（每 12 月发生 1 次维修 = 月租 × 2） | 中（有空置风险） |
| 股票分红 | 持有分红股 | 持股数 × 每股季度分红 ÷ 3（折月） | 中（公司可能不分红） |
| 债券利息 | 持有债券 | 债券面值 × 年化利率 ÷ 12 | 极高（固定） |
| 企业分红 | 投资企业 | 企业季度净利润 × 持股比例 ÷ 3 | 低（企业可能亏损） |
| REITs 分红 | 持有 REITs | 持有份额 × 每份额季度分红 ÷ 3 | 中 |
| 养老金 | 60 岁后 | 累计养老金账户 × 4% ÷ 12（月） | 极高 |

### 4.3 资本利得

- 房产卖出：卖出价 - 买入价 - 交易税费（增值税 5% + 中介费 2%）。
- 股票卖出：卖出价 - 买入价 - 印花税 0.1% + 佣金 0.025%。
- 贵金属卖出：卖出价 - 买入价 - 交易费 0.5%。
- 企业股权转让：卖出价 - 投入成本 - 企业所得税（25% × 利润部分）。
- **资本利得税**：见第 9.3 节。

### 4.4 被动收入合计与 FI Index

```
月被动收入 = 租金净收入 + 股票分红（月）+ 债券利息（月）
           + 企业分红（月）+ REITs 分红（月）+ 养老金（60岁后）

FI Index = 月被动收入 ÷ 月总支出

- FI Index < 0.5：生存状态
- 0.5 ≤ FI Index < 1：积累状态
- FI Index ≥ 1：财务自由（可申请进入自由圈）
```

#### 6.2.3 月供计算公式

```
月供（等额本息）= 贷款本金 × [月利率 × (1+月利率)^还款月数] ÷ [(1+月利率)^还款月数 - 1]

示例：贷款 200 万，年利率 4.2%（月利率 0.35%），30 年（360 月）
月供 = 2,000,000 × [0.0035 × (1.0035)^360] ÷ [(1.0035)^360 - 1]
     ≈ 2,000,000 × 0.004902 ≈ 9,804 元/月
```

游戏中为简化计算，提供**月供速查表**（见《棋盘与道具设计》附录）。

- 房产持有满 5 年且为唯一住房：免征增值税。
- 对应真实世界：**二手房交易税费**。

#### 6.3.2 企业成长与风险

- **成长期**：前 N 个月每月消耗精力，现金流可能为负（烧钱期）。
- **成熟期**：精力消耗归零，现金流稳定为正。
- **风险事件**：每 12 个月掷骰一次，1/6 概率触发"经营危机"（现金流 -50% 持续 6 个月）。
- **退出机制**：
  - 被收购：Agent 投资人报价（估值 = 年净利润 × 5–10 倍）。
  - IPO：自由圈机会卡，估值 = 投入 × 10–50 倍（高风险）。
  - 清算：净资产变现，通常低于投入。

### 6.9 投资决策行为金融增强（v2.58 增补·可选模块）

> **来源**：《概率数学与随机性教育类桌游资料》§8 建议1/2/5——EV 显式化、继续vs收手双选、1000局蒙特卡洛复盘。

> **启用方式**：默认开启；新手局可在设置中关闭"继续vs收手双选"以降低复杂度。

#### 6.9.1 EV 显式化规则

所有投资格在玩家决策前，UI 强制显示完整期望值表：

| 显示项 | 内容 | 示例 |
|--------|------|------|
| 成功情景 | 成功概率 + 成功收益 | 60% 概率 +20% |
| 失败情景 | 失败概率 + 失败亏损 | 30% 概率 −10% |
| 极端情景 | 尾部风险概率 + 最大亏损 | 10% 概率 −100% |
| 期望值 EV | 加权计算结果 | EV = −500 元 |
| 隐含手续费 | 买卖价差 + 印花税 + 滑点 | 0.5% |
| 系统提示 | EV 正负提醒 | ⚠️ 该投资 EV 为负，你确定要投吗？ |

**设计原则**：禁止"暗骰"——玩家在掷骰子前就知道完整概率分布。EV 计算公式公开透明：EV = Σ P(结果) × 损益。

#### 6.9.2 继续 vs 收手双选机制

> **来源**：Can't Stop（Sid Sackson, 1980）Push-Your-Luck 经典实验。

所有持仓类投资（股票、房产、企业股权）在每季度开始时，玩家必须二选一：

| 选项 | 效果 | 触发心魔卡 |
|------|------|-----------|
| A「止盈卖出」 | 按当前市价卖出，落袋为安 | 不触发 |
| B「继续持有」 | 再持一季度，显示下季度 EV 表 | 视情况触发 |
| C「止损卖出」（浮亏≥20%时出现） | 按当前市价卖出，接受亏损 | 触发 XM-01（割肉之痛）认知检定 |

**设计意图**：把"持有"从默认动作变成需要决策的动作。已赚的钱不是沉没成本，而是继续下注时可能损失的筹码。

#### 6.9.3 1000 局蒙特卡洛复盘

> **来源**：概率数学资料 §8 建议5——大数定律教学。

游戏终局结算后，自动进入"蒙特卡洛复盘"模块：
- Agent 将本局玩家的投资策略投入 1000 次蒙特卡洛模拟；
- 显示收益分布柱状图，标注本局实际净值所在分位数；
- Agent 教练点评：单局结果受运气影响大，长期策略 EV 才是关键。

## 7. 市场周期系统

### 7.1 四阶段定义

> **参数校准说明（v1.1）**：原 v1.0 衰退期利率取 7.0%、繁荣期通胀取 5%，均显著超出中国真实宏观区间——2019 年 LPR 机制改革以来，5 年期以上 LPR 历史最高值仅 4.85%（2019-08），1 年期历史最高 4.25%；中国 CPI 仅 2008 年出现过 5.9% 的极端值。为使游戏「真实模拟中国经济」，本节利率锚定 LPR、通胀锚定 CPI，整体区间已下调。依据见《真实世界经济与财商理论底座》板块 5.6 与附录 A 第 12/13 条。

| 阶段 | 持续时间 | 经济特征 | 股票价格系数 | 房产价格系数 | 利率水平（1Y LPR 口径） | 就业状况 |
|------|---------|---------|-------------|-------------|---------|---------|
| **复苏期** | 2–3 年 | 经济回暖，政策宽松 | 1.10（+10%） | 1.05（+5%） | 3.5% | 就业率 90% |
| **繁荣期** | 2–4 年 | 乐观高涨，泡沫化，温和加息 | 1.25（+25%） | 1.15（+15%） | 4.5% | 就业率 95% |
| **衰退期** | 1–2 年 | 需求萎缩，信贷收紧 | 0.80（-20%） | 0.95（-5%） | 5.8% | 就业率 80% |
| **萧条期** | 1–3 年 | 恐慌出清，降息救市 | 0.65（-35%） | 0.85（-15%） | 2.8% | 就业率 65% |

- **利率口径**：表中为 1 年期 LPR。5 年期以上 LPR（房贷基准）= 表中数值 + 0.5%；实际房贷利率 = 5Y LPR + 加点（首套 −0.2% ~ +0.3%，二套 +0.3% ~ +0.8%）。
- **衰退期 5.8% 的含义**：这不是 LPR 本身升到 5.8%（历史上从未发生），而是模拟「信贷收紧期综合融资成本」——真实世界中 LPR 未变但银行上浮加点、审批收紧、经营贷抽贷，企业与个人的**实际获得利率**会显著上行。游戏用单一数值合并这一效应，Agent 教练在解释时应说明这一点。
- **教育价值**：玩家会看到「名义利率不高但融资变难」的真实体验，比单纯把利率拉到 7% 更贴近中国实际。

### 7.2 周期触发与切换

- 开局默认进入**复苏期**（20 岁时经济刚从低谷恢复）。
- 每 5 年（一次钟声）掷**市场周期骰**决定下一阶段：
  - 当前为复苏期 → 50% 概率进入繁荣期，30% 仍在复苏期，20% 直接进入衰退期。
  - 当前为繁荣期 → 20% 仍在繁荣期，60% 进入衰退期，20% 进入萧条期。
  - 当前为衰退期 → 40% 仍在衰退期，40% 进入萧条期，20% 回到复苏期。
  - 当前为萧条期 → 70% 进入复苏期，30% 仍在萧条期。
- **周期不可预测**，但玩家可通过"政策卡"事件提前预判。

### 7.3 周期对各类资产的影响表

| 资产类别 | 复苏期 | 繁荣期 | 衰退期 | 萧条期 |
|---------|--------|--------|--------|--------|
| 股票（成长型） | +15% | +30% | -25% | -40% |
| 股票（价值/银行） | +8% | +10% | -10% | -15% |
| 一线城市房产 | +5% | +15% | -5% | -15% |
| 二三线房产 | +3% | +8% | -10% | -25% |
| 商业地产 | +5% | +12% | -10% | -20% |
| 黄金 | -5% | -10% | +10% | +25% |
| 债券 | 持平 | -5% | +5% | +10% |
| 企业估值（PE） | +10% | +30% | -20% | -35% |

### 7.4 利率与通胀联动

```
贷款利率 = 基准 LPR + 风险溢价

基准 LPR 随周期（1Y 口径，与 §7.1 一致）：
  复苏期：3.5%
  繁荣期：4.5%
  衰退期：5.8%
  萧条期：2.8%

通胀率（CPI 口径）：
  复苏期：2%
  繁荣期：3.5%
  衰退期：2%
  萧条期：0%（通缩）

生活支出每年按 (通胀率 + 3%) 增长（基础工资增长 + 通胀）。
```

**通胀参数说明**：中国 CPI 长期中枢约 2%，历史极值为 2008 年 5.9%。原 v1.0 繁荣期取 5% 过于极端，已下调至 3.5%；萧条期 0%（通缩）符合 2023–2024 年 CPI 接近 0 的真实现状。「生活支出年增 = 通胀 + 3%」中的 3% 是**有意的游戏加速系数**，用于让 40 年人生在 120 分钟内产生可感知的购买力侵蚀，属于设计上刻意的压缩，不追求与真实 CPI 完全一致（见《底座》附录 A 第 14 条）。

### 7.4.1 利率传导链（Agent 教练讲解用）

玩家看到利率变化时往往不理解其影响路径。Agent 教练应在周期切换时展示传导链：

```
央行政策利率（MLF/逆回购）↓
  → LPR ↓
    → 房贷利率 ↓ → 购房需求 ↑ → 房价 ↑（短期）
    → 企业融资成本 ↓ → 企业利润 ↑ → 股价 ↑
    → 存款利率 ↓ → 储户转向理财/基金 → 资本市场资金流入 ↑
    → 存量债券价格 ↑（收益率与价格反向）
```

反向同理。这是 §6.5 债券「利率下行时存量债券升值」与 §6.1 股票周期表现背后的统一机制。

### 7.4.2 美林时钟提示卡（可选教育机制）

> 依据见《真实世界经济与财商理论底座》板块 5.7。

每次周期切换时，Agent 教练可展示一张「资产配置象限提示卡」：

| 象限 | 经济增长 | 通胀 | 历史最优资产 | 历史最差资产 | 对应游戏阶段 |
|------|---------|------|------------|------------|------------|
| 复苏 | ↑ | ↓ | 股票 | 大宗商品 | 复苏期 |
| 过热 | ↑ | ↑ | 大宗商品 | 债券 | 繁荣期 |
| 滞胀 | ↓ | ↑ | 现金 | 股票 | 衰退期（高通胀变体） |
| 衰退 | ↓ | ↓ | 债券 | 大宗商品 | 萧条期 |

**三条硬约束**（防止把游戏变成荐股工具）：
1. 提示卡**仅供参考，不强制执行**，且必须在卡面上注明「历史规律，非必然重演」。
2. 美林时钟基于美国数据，中国因政策干预较强、周期不完全市场化，轮动规律性弱于美国——这一局限必须写入 Agent 教练的解说词，不能让玩家以为照表操作必赢。
3. 玩家**逆提示操作并获利**时，给予额外认知点奖励（+1），鼓励独立思考而非机械跟随。

### 7.5 就业与失业风险

- **就业率**影响失业格触发概率：
  - 就业率 95%（繁荣）：踩中失业格后 80% 概率立即找到新工作。
  - 就业率 65%（萧条）：踩中失业格后只有 30% 概率找到新工作。
- 失业期间工资归零，但仍需支付所有固定支出（房贷/生活/保险）。

## 8. 杠杆与债务系统

### 8.1 贷款类型总览

| 贷款类型 | 利率（年化） | 期限 | 用途限制 | 月供方式 |
|---------|------------|------|---------|---------|
| 自住房贷 | LPR（3.5%–7%） | 30 年 | 仅限自住房 | 等额本息 |
| 商业房贷 | LPR + 1% | 10 年 | 商铺/写字楼 | 等额本息 |
| 经营贷 | LPR + 2% | 5 年 | 仅限企业经营 | 先息后本 |
| 车贷 | 5%–8% | 5 年 | 仅限购车 | 等额本息 |
| 消费贷 | 8%–15% | 3 年 | 无限制 | 等额本息 |
| 信用卡分期 | 18%（年化） | 随借随还 | 无限制 | 最低还款 10% |

### 8.2 贷款额度规则

| 贷款类型 | 额度上限 | 条件 |
|---------|---------|------|
| 房贷 | 房产总价 × 70%（首套）/ 40%（二套） | 信用评分 ≥ 600 |
| 车贷 | 车价 × 80% | 月现金流 ≥ 月供 × 2 |
| 消费贷 | 月现金流 × 12 | 无逾期记录 |
| 经营贷 | 企业估值 × 50% | 企业成立 ≥ 12 月 |
| 信用卡 | 月收入 × 3 | 初始额度 10,000–50,000 |

### 8.3 月供计算（等额本息速算）

```
月供 = 本金 × 月利率 × (1+月利率)^n / [(1+月利率)^n - 1]

简化速算系数（每 100 万贷款）：
  30 年，4.2%：月供 ≈ 4,900 元/100万
  20 年，4.2%：月供 ≈ 6,160 元/100万
  10 年，5.0%：月供 ≈ 10,600 元/100万
  5 年，8.0%：月供 ≈ 2,030 元/10万
```

### 8.4 还款规则

- **正常还款**：每月月结时自动从现金中扣除月供。
- **提前还款**：S1 阶段可自愿提前还本金，每次至少还 1 万。提前还款后月供重新计算或期限缩短（玩家选择）。
- **逾期**：若现金不足以支付月供，触发逾期：
  - 第 1 次逾期：罚息 = 月供 × 5%，信用 -50。
  - 第 2 次逾期：罚息 = 月供 × 10%，信用 -100，银行催款。
  - 第 3 次逾期：抵押物被查封，进入破产流程。
- **信用卡循环利息**：若未全额还款，未还部分按 18% 年化计息。

### 8.5 破产清算流程

1. **触发**：连续 3 个月月现金流为负且现金不足以支付，或现金 + 可立即变现资产 < 月支出 × 3。
2. **第一步：变卖流动资产**：按当前市场价格卖出所有股票、基金、贵金属、债券。
3. **第二步：变卖固定资产**：
   - 房产按市场价 70% 强制出售（急售折扣）。
   - 车辆按买入价 50% 强制出售。
   - 企业按净资产 50% 强制出售。
4. **第三步：债务重组**：
   - 信用卡/消费贷：本金减免 50%，剩余分 36 期免息偿还。
   - 车贷：车辆被收回，贷款清零。
   - 房贷：若房产被拍卖，贷款随房产转移；若仍有余额，转为长期分期。
5. **第四步：状态**：
   - 信用清零，5 年内（游戏中 5 年钟声）无法新增大额贷款。
   - 精力 -5。
   - 停赛 3 回合（找工作/重整）。
6. **第五步**：若重组后月现金流仍为负，正式**出局**（见第 12 章）。

### 8.6 贷款降收入等级与信用评分（v1.2 新增）

> **借鉴来源**：Brass: Birmingham/Lancashire 的核心机制——玩家可借 £10/£20/£30 三档贷款，每借一档收入等级降 1 级（代表杠杆对经营现金流的侵蚀）；Container 的贷款利息与违约扣押设计。这两款游戏证明了「杠杆不是免费的——它直接压低你的收入能力」。

#### 8.6.1 信用评分梯度

| 信用评分 | 等级 | 贷款利率上浮 | 可贷额度 | 现实对应 |
|---------|------|------------|---------|---------|
| 700–850 | A（优秀） | 基准 −0.5% | 收入 × 24 | 征信优质客户 |
| 600–699 | B（良好） | 基准 | 收入 × 18 | 征信良好客户 |
| 500–599 | C（一般） | 基准 +1.0% | 收入 × 12 | 征信一般 |
| 400–499 | D（较差） | 基准 +2.5% | 收入 × 6 | 征信瑕疵 |
| < 400 | E（违约） | 不可贷款 | 0 | 征信黑名单 |

- 初始信用评分按职业：P01–P04 = 550（C），P05–P09 = 650（B），P10–P12 = 700（A）。
- 每次逾期：−50；每次按时还贷 ≥ 12 月：+20（上限 850）；破产：清零。

#### 8.6.2 贷款降收入等级机制（借鉴 Brass）

玩家在 S1 阶段可主动申请「信用贷款」（无抵押），每借一笔即降低收入等级：

| 贷款档 | 金额 | 月利息 | 收入等级影响 | 现实对应 |
|--------|------|--------|------------|---------|
| 一档贷款 | 50,000 元 | 月息 0.8% | 下一年工资增长从 +3% 降为 +1%（降 1 级） | 小额消费贷 |
| 二档贷款 | 100,000 元 | 月息 1.2% | 工资增长降为 0%（降 2 级），且副业月收入 −20% | 中型经营贷 |
| 三档贷款 | 200,000 元 | 月息 1.8% | 工资增长 −1%（降 3 级），副业收入 −40%，企业月现金流 −15% | 高杠杆周转 |

- **设计意图**：Brass 的「贷款降收入等级」比单纯加利息更直观——玩家不仅付利息，还主动压低了自己未来的赚钱能力。这训练的是「杠杆的隐性成本」：借得越多，赚钱越难。
- **还款恢复**：还清某档贷款后，收入等级恢复（按档回升）。
- **与 Container 的联动**：连续 3 期未还信用贷款 → 触发违约扣押（自动变卖一项流动资产，按评估价 70% 归银行），信用评分直接降至 D。

## 9. 税务系统

### 9.1 个人所得税（工资薪金）

采用中国现行 7 级超额累进税率：

| 级数 | 月应纳税所得额（税前工资 - 5,000 起征点 - 社保公积金） | 税率 | 速算扣除数 |
|------|---------------------------------------------------|------|-----------|
| 1 | 不超过 3,000 元 | 3% | 0 |
| 2 | 3,000–12,000 元 | 10% | 210 |
| 3 | 12,000–25,000 元 | 20% | 1,410 |
| 4 | 25,000–35,000 元 | 25% | 2,660 |
| 5 | 35,000–55,000 元 | 30% | 4,410 |
| 6 | 55,000–80,000 元 | 35% | 7,160 |
| 7 | 超过 80,000 元 | 45% | 15,160 |

**月个税计算公式**：
```
应纳税所得额 = 税前月工资 - 5,000（起征点）- 社保（工资×10.5%）
月个税 = 应纳税所得额 × 适用税率 - 速算扣除数
```

**示例**：月薪 20,000 元
- 社保扣除：20,000 × 10.5% = 2,100
- 应纳税所得额：20,000 - 5,000 - 2,100 = 12,900
- 适用税率 20%（第三级）
- 月个税 = 12,900 × 20% - 1,410 = 1,170 元
- 税后到手 = 20,000 - 2,100 - 1,170 = 16,730 元

### 9.2 专项附加扣除（认知 ≥ 6 解锁）

> **参数依据**：国发〔2023〕13 号《国务院关于提高个人所得税有关专项附加扣除标准的通知》+ 国家税务总局公告 2023 年第 14 号，自 2023-01-01 起执行（「一老一小」三项扣除标准提高）。详细来源见《真实世界经济与财商理论底座》板块 2.2。

| 项目 | 每月扣除额 | 条件 | 游戏内备注 |
|------|-----------|------|-----------|
| 3 岁以下婴幼儿照护 | 2,000/孩 | 有 3 岁以下子女 | 夫妻可选一方 100% 或各 50%；年度内不可变更 |
| 子女教育 | 2,000/孩 | 子女满 3 岁至全日制学历教育结束 | 同上分摊规则；覆盖幼儿园至博士 |
| 赡养老人 | 3,000 | 父母任一方 ≥ 60 岁 | 独生子女全额 3,000；非独生与兄弟姐妹分摊，每人 ≤ 1,500 |
| 住房贷款利息 | 1,000 | 首套住房贷款，期限 ≥ 20 年 | 与住房租金**不可同时享受** |
| 住房租金 | 1,500 / 1,100 / 800 | 在主要工作城市无自有住房 | 直辖市/省会/计划单列市 1,500；市辖区户籍人口 > 100 万 1,100；其他 800 |
| 继续教育 | 400（学历）/ 3,600（取证当年） | 正在提升认知或考取职业资格 | 学历（学位）继续教育最长 48 个月 |
| 大病医疗 | 年度汇算时扣除 | 年度内个人负担累计超 15,000 | 限额 80,000；**汇算清缴时扣除，不在月结中体现** |

- 认知 ≥ 6 时，Agent 自动帮玩家申报专项附加扣除，降低个税。
- 认知 < 6 时，玩家需主动选择是否申报（漏报多缴税）。
- **游戏内教学点**：专项附加扣除是"合法节税"的最直接手段，对应现实中"应扣尽扣"。玩家漏报即为认知不足的代价，量化为每月多缴税额。
- 大病医疗因是年度汇算扣除，游戏在 §1.3 年度结算时一次性返还，不进入月结。

### 9.2.1 住房公积金（可选机制）

> 公积金是中国特有的「强制储蓄 + 税优 + 低息贷款」三位一体工具，现行规则未纳入，建议作为**可选开局选项**引入。参数依据见《真实世界经济与财商理论底座》板块 2.6.1。

| 项目 | 规则 | 游戏简化 |
|------|------|---------|
| 缴存比例 | 单位 5%–12% + 个人 5%–12%，由单位选定 | 玩家入职时三选一：5% / 8% / 12% |
| 缴存基数 | 上限为当地社平工资 3 倍，下限为当地最低工资 | 简化为按本人工资全额缴存 |
| 税优 | 缴存部分免征个税，账户利息免税，提取免税 | 缴存额在个税计算**前**扣除 |
| 用途 | 购房贷款（利率约 2.85%，低于商贷）、租房提取 | 购房时可用公积金贷款，利率 = 当期 LPR − 0.7% |
| 额度 | 各地不同，一线城市通常 60 万–120 万（个人/夫妻） | 上限 = 累计缴存额 × 15，封顶 120 万 |

**设计权衡**：高缴存比例减少当期可支配现金但增加长期免税资产与低息贷款额度——这是一个真实的「延迟满足」决策，与 §2.4 精力、§2.6 认知的长期投资逻辑同构。为避免加重新手负担，**默认关闭，仅在开局设置中提供开关**。

### 9.6 年终奖单独计税（年度结算时触发）

> **政策依据**：财政部 税务总局公告 2023 年第 30 号，全年一次性奖金单独计税优惠政策延续至 **2027-12-31**。游戏中体现这一中国特色税务规划点。

| 项目 | 规则 |
|------|------|
| 触发时机 | 年度结算（每 12 回合）时，玩家若持有年终奖（≥ 2 个月工资） |
| 计税方式 | 年终奖 ÷ 12 查找适用税率（同 §9.1 七级税率表），应纳税额 = 年终奖 × 适用税率 − 速算扣除数 |
| 计税选择 | 玩家可选：①单独计税（默认，税低）；②并入综合所得（收入高时可能更划算） |
| 游戏简化 | 认知 ≥ 6 时 Agent 自动选择更优方案；认知 < 6 时默认单独计税（可能多缴） |
| 教育价值 | 让玩家理解「年终奖两种计税方式」的差异——这是真实中国职场最常接触的税务优化点 |

**示例**：年终奖 36,000 元，÷12 = 3,000，适用税率 3%，速算扣除数 0 → 应纳税 = 36,000 × 3% = 1,080 元。若并入综合所得可能适用 10% 税率，税负更高。

### 10.2 职业设计说明


- **低收入组（P01–P04）**：月薪 4,500–6,000，总支出 2,800–3,800。FI 门槛低（只需 2,800–3,800 被动收入即可自由），但初始现金少，买不起大资产。
- **中收入组（P05–P09）**：月薪 9,000–15,000，总支出 6,000–10,000。平衡型，有一定储蓄可投资。
- **高收入组（P10–P12）**：月薪 25,000–40,000，总支出 18,000–25,000。FI 门槛高，需要 18,000–25,000 被动收入才能自由，但初始现金多，可直接买大资产。

**设计自洽性验证**：
- 外卖骑手：月现金流 1,800，初始储蓄 8,000。要买一套 40 万的二线房产（首付 12 万），需要攒 5 年（20→25 岁）。
- 医生：月现金流 7,000，初始储蓄 10 万。可立即买一套 100 万房产（首付 30 万），月供约 4,800，但租金净收入约 2,000，FI 提升有限。
- 关键教学点：**低收入低支出反而更容易财务自由**（FI 门槛低），这是富爸爸游戏验证过的核心教学点，本作保留并强化。

**参数校准说明（v1.2）**：本表 12 个职业的月薪区间（4,500–40,000）与初始储蓄（5,000–300,000）已锚定央行 2019 年城镇居民家庭资产负债调查数据——户均总资产均值 317.9 万元、中位数 163.0 万元、住房占总资产 59.1%（实物资产合计 79.6%）、住房拥有率 96%。游戏中一线城市房产 300–1000 万的总价区间对应北京/上海/深圳的真实房产中位水平；P12 高级专家初始储蓄 30 万 ≈ 城镇家庭净资产中位数（163 万）的「金融资产子集」合理比例。详见《真实世界底座》板块 3（注意口径：此为城镇居民家庭，非全国居民）。

## 11. 人生事件系统

### 11.1 事件触发方式

| 事件类型 | 触发方式 | 举例 |
|---------|---------|------|
| 格子事件 | 停留在特定格子 | 结婚格、生子格、失业格 |
| 卡牌事件 | 抽到事件卡 | 疾病、拆迁、政策变化 |
| 年龄事件 | 钟声时自动触发 | 30 岁成家、50 岁父母退休 |
| 周期事件 | 市场周期切换时 | 繁荣期裁员减少、萧条期裁员增加 |
| 集体事件 | 全体玩家同时触发 | 金融危机、疫情、政策改革 |

### 11.2 主要人生事件规则

#### 11.2.1 结婚

- **触发**：停留在"结婚格"或抽到结婚事件卡。
- **效果**：
  - 从配偶卡堆随机抽 1 张配偶卡，加入财务报表。
  - 精力 -2，人脉 +2（配偶的社交圈）。
  - 结婚支出：婚礼一次性 30,000–100,000 元（随机）。
  - 其他玩家可随份子（自愿，每人 1,000–10,000 元）。

#### 11.2.2 生子

- **触发**：停留"生子格"或已婚玩家抽到怀孕卡。
- **效果**：
  - 子女数 +1，月支出增加 3,000（抚养）+ 1,000–5,000（教育，随机）。
  - 精力 -3。
  - 认知 +1（为人父母的成长）。
  - 孩子数量无上限，但每多一个孩子总支出线性上升。

#### 11.2.3 离婚

- **触发**：抽到离婚事件卡，或玩家主动选择离婚（S1 阶段）。
- **效果**：
  - 配偶的工资、支出、精力全部移除。
  - 财产分割：现金与净值的 50% 判给配偶（若有过错方判定，比例可调整）。
  - 子女抚养权：随机判给一方，另一方支付抚养费 2,000/月。
  - 精力 -4，人脉 -2。

#### 11.2.4 失业

- **触发**：停留在"失业格"或抽到裁员卡。
- **效果**：
  - 工资收入归零，持续 1–3 个游戏月。
  - 仍需支付所有固定支出（房贷/生活/保险）。
  - 人脉 ≥ 5：掷骰成功率 70%（失业第 2 回合即可找新工作）。
  - 人脉 < 5：掷骰成功率 50%。
  - 找到新工作后，工资为原工资的 80%–120%（随机）。

#### 11.2.5 疾病/医疗

- **触发**：抽到疾病卡或精力 ≤ -1 时概率触发。
- **轻症**：医疗支出 1,000–5,000 元，停 1 回合。
- **中症**：医疗支出 10,000–30,000 元，停 2 回合，精力 -2。
- **重疾**：医疗支出 50,000–200,000 元，停 3 回合，精力 -5。
  - 若有重疾险：保险赔付 30–50 万，自付部分降至 10%。
  - 若有百万医疗险：住院费报销 90%。
- **大病返贫**：未买保险且现金 < 医疗费用 50% 时，触发"因病致贫"，强制变卖资产。

#### 11.2.6 退休

- **触发**：年龄 ≥ 60 岁时自动触发，或 FI Index ≥ 2 时玩家可自愿提前退休。
- **效果**：
  - 主动收入归零（不再领工资）。
  - 开始领取养老金（社保 + 商业养老金）。
  - 支出减少 30%（退休后生活成本降低）。
  - 精力恢复至满（不再为工作消耗精力）。
  - 但游戏仍继续到 60 岁终局结算。

#### 11.2.7 父母赡养

- **触发**：年龄 ≥ 35 岁后，每 5 年掷骰决定父母健康状态。
- **健康**：无需赡养支出。
- **一般**：每月赡养 1,000 元。
- **重病**：一次性支出 50,000–100,000 元，后续每月 2,000 元。
- **去世**：继承遗产（随机 0–500,000 元），触发遗产税（见下）。

#### 11.2.8 拆迁/政策变化

- **拆迁**：持有自住房时抽到"拆迁"卡，获得补偿款 = 房产市值 × 1.2–1.5。
- **限购政策**：政策卡宣布某城市限购，新购房产首付从 30% 升至 60%。
- **利率调整**：央行加息/降息，所有浮动利率房贷月供变化。
- **房产税试点**：自由圈触发，持有第二套以上房产每年缴纳 0.5% 房产税。

### 11.3 集体事件（每 10 年触发）

| 事件 | 效果 | 对应真实概念 |
|------|------|-------------|
| 金融危机（萧条期触发） | 所有股票 -30%，房产 -10%，失业率上升 | 2008 金融危机 |
| 疫情冲击 | 所有玩家停 1 回合，副业收入归零 12 月 | 新冠疫情 |
| 牛市到来（繁荣期触发） | 所有股票 +20%，但估值泡沫化 | 2015 牛市 |
| 房地产税试点 | 持有 2 套以上房产每年交 0.5% 市值 | 房地产税改革 |
| 政策红利 | 小微企业税收减免，创业玩家税负 -50% | 减税降费 |

## 12. 破产与出局规则

### 12.1 破产触发条件

满足以下任一条件即触发破产清算：
1. 连续 3 个月月现金流为负，且现金 < 月支出 × 2。
2. 现金 + 可立即变现资产（股票/贵金属）< 本月应付款项。
3. 抵押物被银行查封（第 3 次逾期）。

### 12.2 破产清算流程

详见第 8.5 节。清算后：
- 若月现金流回正 → **重整成功**，继续游戏，停 3 回合。
- 若月现金流仍为负 → **正式出局**。

### 12.3 正式出局

- 玩家退出游戏，棋子从棋盘移除。
- 所有资产按市场价 50% 清算，债务一笔勾销。
- 终局结算时该玩家结局为"**破产出局**"。
- 出局玩家可转为观察者，或由 Agent 接管继续游戏（线上版）。

### 12.4 健康危机出局

- 精力 ≤ -3 时触发"健康危机"。
- 强制住院停 3 回合，医疗支出 30,000 元。
- 若住院期间仍无法恢复（精力持续为负），触发"提前退场"。
- 终局结算时结局为"**精力透支 · 提前退场**"。

### 13.1 可交易资产

| 资产类型 | 交易方式 | 定价方式 |
|---------|---------|---------|
| 房产 | 整售/合伙份额 | 双方议价，参考市场价 |
| 股票 | 整手转让 | 双方议价（场外交易） |
| 企业股权 | 股权转让 | 双方议价（参考估值） |

### 13.2 交易规则

1. **只能在 S1（回合前自由动作）阶段交易**。【已废止，见《交易拍卖与企业经营设计》§2 季度交易窗口 T1–T4】

3. 玩家间借款无固定利率，可约定任何利率（但建议不超过 24% 年化，否则视为高利贷事件）。

### 13.3 Agent 作为交易对手

- **NPC 雇主**：失业时提供新工作，工资 8,000–20,000 随机。
- **NPC 房东**：租房市场，房租 2,000–8,000 随机。
- **NPC 投资人**：自由圈中可报价收购企业，估值 = 年利润 × 5–10 倍。
- **NPC 买家**：房产/股票市场买盘，按当前周期价格的 90%–110% 报价。

## 14. 胜负判定与结局分类

### 14.1 终局时间

**60 岁钟声响起时，立即进入终局结算。** 无论玩家当前在哪个圈层、什么状态。

### 14.2 三维评分

终局时，Agent 计算每位玩家的三维评分：

#### 14.2.1 财务自由度（50%）

```
FI Score = min(FI Index, 2.0) / 2.0 × 100  （满分 100）
         + 净资产加分（净资产 > 100 万加 10 分，> 500 万加 20 分）
```

- FI Index ≥ 2.0：100 分
- FI Index 1.5–2.0：80 分
- FI Index 1.0–1.5：60 分
- FI Index 0.5–1.0：30 分
- FI Index < 0.5：0 分

#### 14.2.2 人生满意度（30%）

| 项目 | 分值 |
|------|------|
| 精力剩余（0–10） | × 3 分 = 0–30 |
| 已婚且和睦 | +10 |
| 子女数 1–2 个 | +10 |
| 人脉 ≥ 7 | +10 |
| 实现梦想（停留在梦想格并支付） | +20 |
| 无重大疾病记录 | +10 |
| 慈善捐赠 > 10 万 | +10 |
| 总和上限 100 | |

#### 14.2.3 社会贡献（20%）

| 项目 | 分值 |
|------|------|
| 慈善捐赠总额 | 每 1 万 = 1 分（上限 10） |
| 培养/帮助其他玩家 | 每人 5 分（上限 10） |
| 无税务处罚记录 | +10 |
| 无逾期/破产记录 | +10 |
| 合规经营（无诈骗事件） | +10 |
| 总和上限 100 | |

### 14.3 总分与结局

```
总分 = 财务自由度 × 50% + 人生满意度 × 30% + 社会贡献 × 20%
```

| 总分 | 结局 | 说明 |
|------|------|------|
| ≥ 85 | **财务自由 · 人生赢家** | 财富与人生双丰收 |
| 70–84 | **富足安稳 · 中产典范** | 财务稳健，人生平衡 |
| 50–69 | **平淡度日 · 普通一生** | 中等水平，靠社保养老 |
| 30–49 | **债务缠身 · 挣扎求生** | 入不敷出，压力巨大 |
| < 30 | **破产出局 / 提前退场** | 游戏失败结局 |
| 特殊：FI Index ≥ 1.5 但人生满意度 < 40 | **财务自由 · 孤独富翁** | 有钱但人生不完整 |

### 14.4 复盘报告

终局后 Agent 自动生成每位玩家的"人生财务报告"，包含：
1. 20–60 岁净资产变化曲线（折线图）。
2. FI Index 变化曲线。
3. 关键决策树（买了什么、卖了什么、借了多少）。
4. 与同职业平均水平的对比。
5. 三个最值得反思的决策点（Agent 标注）。

## 附录 A：关键公式速查

```
1. 月现金流 = 总收入 - 总支出
2. FI Index = 月被动收入 / 月总支出
3. 净值 = 总资产 - 总负债
4. ROI（房产）= 年租金净收入 / 首付
5. 月供（等额本息）= P × r × (1+r)^n / [(1+r)^n - 1]
   P=本金, r=月利率, n=还款月数
6. 月个税 = (月薪 - 5000 - 社保) × 税率 - 速算扣除数
7. 养老金月领取 = 个人账户余额 × 4% / 12
8. 房产卖出净额 = 卖出价 - 未还贷款 - 交易税费
```
