## 1. Acquire（收购）——连锁并购机制的巅峰

### 1.1 游戏概述

- **设计师**：Sid Sackson（美国桌游设计先驱）
- **首版**：1964 年，3M 出版；后 Avalon Hill、Hasbro 多次再版
- **玩家人数**：2–6 人 | **时长**：60–90 分钟
- **BGG 评分**：≈ 7.3
- **地位**：公认的"并购机制教科书"，影响后续所有连锁并购类游戏

### 1.2 完整规则

#### 1.2.1 棋盘与组件

- 12×18 的棋盘（编号 A1–L18）
- 连锁卡 7 种颜色（ Tower、Continental、Festival、Imperial、American、Worldwide、Sackson）
- 股票卡：每种连锁约 25 张

#### 1.2.2 回合流程

1. **放置板块**：从手中选择一个板块放到棋盘上
   - 若相邻无任何连锁 → 创建新连锁
   - 若相邻仅一个连锁 → 加入该连锁
   - 若相邻多个不同连锁 → **触发并购**
2. **并购结算**（核心机制）：
   - 两个相邻连锁合并为一个
   - 较大连锁为"存续连锁"，较小连锁为"被收购连锁"
   - **奖励金**：被收购连锁的前两名股东获得现金奖励
     - 大股东（Majority）= 2 × 被收购连锁股价
     - 二股东（Minority）= 1 × 被收购连锁股价
   - 被收购连锁的股票持有者可选择：
     - 兑换为存续连锁股票（2:1）
     - 出售给银行（按被收购连锁当前股价）
     - 保留（但股票价值变为 0 直到被并购的连锁再次独立）
3. **购买股票**：每回合最多购买 3 张股票
   - 价格由当前连锁规模决定（查价格表）
   - 可用现金购买，股价从银行支付

#### 1.2.3 结束条件

- 某连锁达到阈值大小（通常 41+）
- 所有连锁均"不可收购"（大小 ≥ 11 且彼此隔离）
- 终局结算：所有连锁奖励金 + 股票价值，现金最多者获胜

### 1.3 市场机制分析

| 维度 | 游戏映射 |
|------|---------|
| **价格发现** | 股票价格完全由连锁规模查表决定，无玩家定价 |
| **并购溢价** | 被收购连锁股东获得奖励 = 并购溢价 |
| **股权稀释** | 新股发行导致每股价值下降 |
| **内幕信息** | 手牌私有，可预测并购时机 |
| **代理问题** | 大股东与二股东利益不完全一致 |
| **投机与价值投资** | 股票既可获得奖励金又可长期持有 |

### 1.4 对财商流游戏的启示

- **并购时机**：何时触发并购是游戏的核心策略
- **股权结构**：大股东 vs 二股东的博弈
- **连锁网络效应**：规模越大价值越高，但越大越难增长

## 2. 18xx 系列——股票市场模拟的终极形态

### 2.1 系列概述

- **起源**：1829（Francis Tresham，1974 年设计 1829，1981 年首次出版 1830）
- **设计师群体**：All Aboard Games 出版多部 18xx 作品
- **玩家人数**：3–6 人 | **时长**：3–6 小时（重度）
- **复杂度**：BGG Weight ≈ 4.0/5
- **核心主题**：铁路建设与股票市场的互动

### 2.2 双市场并行机制

#### 2.2.1 私有公司市场（Private Phase）

- 游戏开始时通过拍卖出售私有公司
- 私有公司赋予玩家特殊能力（如铺设铁路补贴、获取特定路段）
- 私有公司最终会被公有化或关闭

#### 2.2.2 股票市场（Stock Round）

- 玩家轮流行事，可选择：
  - 买入股票（从公司金库或par处）
  - 卖出股票（给"市场"，价格下降）
  - 持有
- **股价变动规则**：
  - 卖出 → 股价下降 1 格
  - 分红后 → 股价变动取决于分红水平
  - 不分红 → 股价下降 1 格
- **持股限制**：个人持股上限 60%（防止完全控制）

#### 2.2.3 运营轮次（Operating Round）

- 每家公司按顺序运营：
  - 铺设铁轨（消耗地形成本）
  - 放置车站
  - 运营列车（产生收入）
  - 决定分红（分红/留存）
- **分红决策** = 公司CEO（最大股东）的核心策略

### 2.3 核心经济机制

| 机制 | 描述 |
|------|------|
| **公司金库** | 公司的现金独立于玩家现金 |
| **市值计算** | 市值 = 股价 × 发行股数 |
| **股权稀释** | 新发行股票导致每股价值下降 |
| **空壳公司** | 破产后股票价值归零，但公司实体可能继续 |
| **并购** | 大公司可收购小公司（用股票/现金） |
| **CEO 更替** | 最大股东成为 CEO，可被挑战 |

### 2.4 关键策略维度

- **价值投资 vs 投机**：买入低估公司等待分红 vs 短线操作股价波动
- **CEO 控制**：通过持股控制公司决策
- **股权稀释策略**：迫使对手持股被稀释
- **清算价值**：破产后公司资产的市场价值

### 2.5 对财商流游戏的启示

- **双层市场**：股票市场 + 运营市场的互动
- **CEO 与股东代理问题**：大股东决策影响小股东利益
- **分红政策的影响**：高分红 vs 再投资的权衡
- **市场操纵**：买卖时机影响股价

## 3. Stockpile（股票盲拍）——信息不对称的现代演绎

### 3.1 游戏概述

- **设计师**：Danlets Games
- **首版**：2015 年；**第二版**：2024 年
- **玩家人数**：2–5 人 | **时长**：45–60 分钟
- **BGG 评分**：≈ 7.2

### 3.2 核心机制

#### 3.2.1 信息不对称系统

- **公开信息板**：每家公司有公开信息（已知利好/利空）
- **内幕信息卡**：玩家私有，显示某公司的真实价值
- **盲拍**：每轮出现"信息包"，玩家盲拍获得

#### 3.2.2 股票买卖

- 6 家公司各有独立股价
- 股价随买卖行为波动（需求↑ → 价格↑）
- 每回合限买/限卖

#### 3.2.3 终局结算

- 翻开所有公司的真实价值
- 玩家持有的股票按真实价值兑现
- 现金 + 股票真实价值 = 总财富

### 3.3 信息经济学映射

| 真实概念 | 游戏映射 |
|---------|---------|
| 内幕交易 | 内幕信息卡 |
| 公开信息披露 | 公开信息板 |
| 分析师报告 | 信息包的混合信号 |
| 市场有效性 | 价格反映信息的程度 |
| 信息套利 | 利用信息优势获利 |

## 4. 现代市场微观结构理论在桌游中的应用

### 4.1 买卖价差（Bid-Ask Spread）

> **定义**：同一时刻买方最高出价与卖方最低要价的差额。

**桌游映射**：
- **Chinatown**：买卖双方分别报价，成交价介于之间
- **Container**：工厂出售价 ≠ 商店采购价

**设计应用**：
- 财商流游戏可设置"买卖价差"机制——买入价 = 市价 × 1.1，卖出价 = 市价 × 0.9
- 这模拟了真实交易中的摩擦成本

### 4.2 限价订单簿（Limit Order Book）

> **定义**：记录所有未成交的买卖限价订单。

**桌游实现**：
- 使用订单簿板记录所有玩家的挂单
- 当买卖价格匹配时自动成交
- 增加了市场深度和流动性的考量

### 4.3 大宗交易（Block Trade）vs 零散交易（Odd Lot）

> **定义**：大额交易（影响市场价格）vs 小额交易（不影响价格）。

**桌游映射**：
- **Acquire**：大宗卖出影响股价
- **18xx**：大宗买入改变 CEO 控制权

### 4.4 熔断机制（Circuit Breaker）

> **定义**：价格剧烈波动时暂停交易，让市场冷静。

**桌游实现**：
- 当股价单回合涨跌幅超过阈值时触发"熔断"
- 暂停交易一回合，期间只能挂单不能成交
- 模拟真实市场的稳定机制

### 4.5 做市商（Market Maker）

> **定义**：提供双边报价，为市场提供流动性。

**桌游设计**：
- 一名玩家担任"做市商"角色
- 做市商持续提供买卖报价
- 其他玩家与做市商交易
- 做市商通过价差盈利

## 5. 中国A股市场特征的模拟可能性

### 5.1 A股特有机制

| 机制 | 描述 | 桌游映射 |
|------|------|---------|
| **涨跌停板** | 单日涨跌幅限制 ±10%（ST ±5%） | 股价变动设置上下限 |
| **T+1 交易** | 买入后次日才能卖出 | 买入的股票锁定一回合 |
| **打新** | IPO 申购 | 新股抽签/拍卖机制 |
| **融资融券** | 借券做空/借钱买入 | 信用交易模块 |
| **北向资金** | 外资流入 | 外部资本事件 |
| **国家队** | 政府救市 | 政府干预事件 |

### 5.2 模拟设计建议

- **涨跌停机制**：每家公司每回合股价变动不超过 ±10%
- **T+1 限制**：买入的股票需持有一回合才能卖出
- **打新事件**：随机出现新股，玩家申购（中签率与持股相关）
- **外资事件**：北向资金流入/流出影响特定板块
- **政策事件**：监管政策变化影响市场整体

## 6. 财商流游戏股票市场机制的升级建议

### 6.1 既有机制回顾

根据《财商流游戏规则与经济系统》：
- 股票投资品：价格随市场周期波动
- 买卖：自由定价/市场定价
- 分红：按持股分配

### 6.2 可引入的新机制

| 机制 | 来源游戏 | 适配方式 |
|------|---------|---------|
| 并购奖励 | Acquire | 公司合并时原股东获得奖励 |
| 内幕信息 | Stockpile | 玩家可花费资源获取内幕 |
| 双向报价 | 真实市场 | 同时挂买/卖单 |
| 熔断机制 | 真实市场 | 价格波动过大时暂停交易 |
| 信用交易 | CASHFLOW 202 | 融资融券模块 |
| 涨跌停板 | A股 | 股价日涨跌幅限制 |

### 6.3 财商教育价值

- **市场微观结构理解**：买卖价差、订单簿、流动性
- **交易摩擦**：手续费、税费、T+1 成本
- **信息价值**：内幕信息与公开信息的区分
- **风险管理**：熔断机制、涨跌停的意义
