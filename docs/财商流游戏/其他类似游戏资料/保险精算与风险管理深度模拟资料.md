## 1. 生命表与寿险精算

### 1.1 生命表（Life Table）

| 符号 | 含义 |
|------|------|
| lₓ | x 岁存活人数 |

| pₓ | x 岁存活率 |

### 1.2 寿险产品精算模型

#### 1.2.1 定期寿险（Term Life）

> **定义**：保险期间内死亡赔付，期满生存不赔付。

**精算公式**：
```
纯保费 = 保额 × Σ [v^(t+1) × t|qₓ] / Σ [v^t × t|qₓ]
v = 1 / (1 + i)  # 贴现因子
t|qₓ = x 岁的人在 t 年内死亡的概率
```

#### 1.2.2 终身寿险（Whole Life）

> **定义**：保障至死亡，必赔。

**精算公式**：
```
纯保费 = 保额 × Aₓ / äₓ
Aₓ = 终身寿险精算现值
äₓ = 终身年金精算现值
```

#### 1.2.3 两全保险（Endowment）

> **定义**：期间内死亡赔付，期满生存也给付。

**特点**：储蓄性强，保费较高

### 1.3 年金产品精算

#### 1.3.1 年金类型

| 类型 | 描述 |
|------|------|
| **即期年金** | 立即开始给付 |
| **延期年金** | 若干年后开始给付 |
| **终身年金** | 给付至身故 |
| **定期年金** | 给付固定年数 |

#### 1.3.2 年金定价

```
年金现值 = 年给付额 × äₓ
äₓ = Σ [v^t × tₚₓ]  # 终身年金精算现值
```

## 2. 非寿险（财产险/责任险）精算

### 2.1 损失分布

#### 2.1.1 损失频率分布

| 分布 | 适用场景 |
|------|---------|
| **泊松分布** | 索赔次数 |
| **负二项分布** | 异质性风险 |

#### 2.1.2 损失强度分布

| 分布 | 适用场景 |
|------|---------|
| **对数正态分布** | 医疗/车损 |
| **帕累托分布** | 巨灾/大额索赔 |
| **伽马分布** | 一般财产险 |

### 2.2 费率厘定方法

#### 2.2.1 纯保费法

```
纯保费 = 期望损失频率 × 期望损失强度
毛保费 = 纯保费 / (1 - 费用率 - 利润率)
```

#### 2.2.2 损失率法

```
费率调整 = 实际损失率 / 目标损失率 - 1
```

### 2.3 准备金评估

#### 2.3.1 未到期责任准备金

> **定义**：保费中属于未来责任的部分。

**计算方法**：
- 1/24 法（按月平均）
- 1/365 法（按日精确）
- 风险分布法

#### 2.3.2 未决赔款准备金

> **定义**：已发生但未赔付的赔款。

**计算方法**：
- 链梯法（Chain Ladder）
- Bornhuetter-Ferguson 法
- 案均赔款法

## 3. 风险管理框架

### 3.1 风险四步法

```
┌──────────────────────────────────────────┐
│           风险管理流程                     │
├──────────────────────────────────────────┤
│  1. 风险识别（Risk Identification）       │
│  2. 风险评估（Risk Assessment）           │
│  3. 风险应对（Risk Response）             │
│  4. 风险监控（Risk Monitoring）           │
└──────────────────────────────────────────┘
```

### 3.2 风险识别工具

| 工具 | 描述 | 桌游映射 |
|------|------|---------|
| **风险清单** | 列出所有可能风险 | 风险事件卡库 |
| **风险热力图** | 评估风险概率×影响 | 风险矩阵板 |
| **情景分析** | 模拟不同情景 | 剧本模式 |
| **压力测试** | 极端情景测试 | 极端事件卡 |

### 3.3 风险评估方法

#### 3.3.1 定性评估

| 等级 | 概率 | 影响 |
|------|------|------|
| 极低 | <5% | 可忽略 |
| 低 | 5–20% | 轻微 |
| 中 | 20–50% | 中等 |
| 高 | 50–80% | 严重 |
| 极高 | >80% | 灾难性 |

#### 3.3.2 定量评估

| 指标 | 描述 |
|------|------|
| **VaR（风险价值）** | 在给定置信水平下的最大可能损失 |
| **TVaR（尾部风险价值）** | 超过 VaR 的平均损失 |
| **标准差** | 损失波动性 |
| **夏普比率** | 风险调整后收益 |

### 3.4 风险应对策略

| 策略 | 描述 | 桌游映射 |
|------|------|---------|
| **规避（Avoid）** | 不从事该活动 | 不购买高风险投资品 |
| **转移（Transfer）** | 将风险转移给第三方 | 购买保险合约 |
| **缓解（Mitigate）** | 降低概率或影响 | 分散投资 |
| **接受（Accept）** | 自留风险 | 自保/应急储备 |

## 4. 各类保险产品精算要点

### 4.1 医疗保险

#### 4.1.1 定价因素

| 因素 | 影响 |
|------|------|
| 年龄 | 年龄越大保费越高 |
| 性别 | 女性某些年龄段费用更高 |
| 既往症 | 增加风险 |
| 免赔额 | 免赔额高则保费低 |
| 保障范围 | 范围广则保费高 |

#### 4.1.2 损失分布

- 医疗费用通常服从对数正态分布
- 存在"长尾"——少数人产生大部分费用
- 医疗通胀率通常高于 CPI

### 4.2 车险

#### 4.2.1 定价因素

| 因素 | 影响 |
|------|------|
| 车型 | 豪车保费高 |
| 车龄 | 新车保费高 |
| 驾驶员年龄 | 年轻驾驶员风险高 |
| 驾驶记录 | 有事故则保费上浮 |
| 地区 | 城市风险高于农村 |

#### 4.2.2 NCD（无赔款优惠）系统

| 等级 | 连续无赔款年数 | 折扣率 |
|------|-------------|--------|
| 0 | 0 年 | 0% |
| 1 | 1 年 | 10% |
| 2 | 2 年 | 20% |
| 3 | 3 年 | 30% |
| 4+ | 4 年+ | 40% |

### 4.3 财产保险

#### 4.3.1 定价因素

| 因素 | 影响 |
|------|------|
| 建筑类型 | 木结构 > 砖混 > 钢筋混凝土 |
| 地理位置 | 洪水/地震带保费高 |
| 保障金额 | 保额高则保费高 |
| 免赔额 | 高免赔降低保费 |
| 防灾措施 | 有措施可降费 |

#### 4.3.2 巨灾风险

- 巨灾事件（地震/台风/洪水）损失巨大
- 需要再保险分散风险
- 巨灾债券（Cat Bond）转移风险

## 5. 社会保障精算

### 5.1 养老保险精算平衡

#### 5.1.1 收支模型

```
年度收入 = 参保人数 × 缴费基数 × 缴费率 + 投资收益
年度支出 = 退休人数 × 养老金水平 + 管理费用
当期结余 = 年度收入 - 年度支出
累计结余 = 上年结余 × (1 + 投资收益率) + 当期结余
```

#### 5.1.2 中国养老保险现状（2024）

| 指标 | 数据 |
|------|------|
| 参保人数 | ≈ 10.7 亿 |
| 抚养比 | ≈ 2.6:1（缴费者/退休者） |
| 平均替代率 | ≈ 43% |
| 缴费率 | 企业 16% + 个人 8% |
| 累计结余 | ≈ 12 万亿元 |

### 5.2 医疗保险精算

#### 5.2.1 收支模型

```
年度收入 = 参保人数 × 人均缴费
年度支出 = 门诊费用 + 住院费用 + 大病费用
当期结余 = 年度收入 - 年度支出
```

#### 5.2.2 控费机制

| 机制 | 描述 |
|------|------|
| DRG/DIP 支付 | 按病种/病组付费 |
| 总额预算 | 年度总额控制 |
| 药品集采 | 集中采购降价 |
| 医保谈判 | 创新药降价准入 |

## 6. 对「财商流游戏」保险机制的启示

### 6.1 当前机制回顾

根据《财商流游戏规则与经济系统》：
- 风险事件卡：随机触发
- 保险：可选购买，降低损失

### 6.2 可引入的精算机制

| 机制 | 描述 | 适配方式 |
|------|------|---------|
| **差异化费率** | 不同玩家费率不同 | 基于风险评估 |
| **免赔额选项** | 高免赔低保费 | 保险产品设计 |
| **NCD 系统** | 无理赔优惠 | 连续安全奖励 |
| **再保险** | 保险公司的保险 | 系统性风险分散 |
| **准备金评估** | 保险公司财务稳健 | 保险机构模拟 |
| **巨灾债券** | 风险证券化 | 高级投资品 |
