| 大富翁 | 无拍卖（固定价购地） | 完全公开 | 掷骰 | 低 |

**机制光谱结论：**
- **拍卖密度最高**：Modern Art（五机制并存）、Ra、High Society——适合做财商流"拍卖行"子模块。
- **谈判密度最高**：Container、Panic on Wall Street、Chinatown——适合做财商流"交易大厅"子模块。
- **零运气纯策略**：FCM、1830、Concordia——适合作为 Agent 接管经营的沙盒（无随机因素，LLM 可稳定复现最优策略）。

## 表二：经济模型对比表

| 游戏 | 货币形态 | 价格形成机制 | 杠杆/信贷 | 破产机制 | 终局估值 |
|------|---------|------------|----------|---------|---------|
| Modern Art | 现金硬币（100 起始） | 玩家竞价 + 画家排名（30/20/10 累计） | 无 | 无（现金可负？否） | 现金总额 |
| Ra | 太阳币（12/时代，花掉不返） | Once Around 竞价 | 无 | 无 | 声望分 |
| For Sale | 封闭现金池（$14k–$18k） | 密封一价 | 无 | 无 | 支票总额 |
| Medici | 佛罗林 | 英式竞价 + 商品轨道排名（10/5） | 无 | 无 | 佛罗林总额 |
| Amun-Re | 黄金（61 张卡） | 英式省份竞价 | 无 | 无 | 金字塔+黄金 |
| Keyflower | **工人即货币**（8 枚起） | 同色工人押注 | 无 | 无 | VP 折算 |
| Century | 香料立方体（105 个） | 市场卡摊牌价 | 无 | 无 | 合约 VP + 余物折算 |
| High Society | 手牌金额（不可撤回） | 累进加价 | 无 | **终局现金最少者出局** | 声望分 |
| Stockpile | 现金（$20k 起） | 多轨密封竞价 + 内幕预测 | $0 可拿堆 | 个股破产清零 | 现金+持仓 |
| 1830 | 现金 | par 价 IPO（$67–$100）+ 分红政策 | 董事长 2× 控股；1817 可发债做空 | 玩家破产即终局 | 现金+股票市值 |
| Brass | 英镑 | 向银行固定成本建 | 贷款 £10/£20/£30 **永久降收入** | 无强制 | 现金 £10=1VP |
| Lords of Vegas | 美元 | 无市场（固定成本） | Reorg 政变 = Σ骰点×$1 | 无个人破产 | 分数轨 break |
| Acquire | 现金 | 连锁规模 → 股价表 | 无 | 连锁 ≥11 安全 | 现金+股票+红利 |
| Container | 美元 | **玩家间议价 + 供需** | 无 | 无 | 现金 |
| Panic on Wall St. | $120k 起 | 限时谈判定价 | 口头赊账（无约束） | 连锁传染破产 | 现金 |
| FCM | 现金（$0 起始） | **玩家自定菜单价** | **无贷款（裸奔）** | 现金归零淘汰 | 现金 |
| Terraforming Mars | M€ | 标准项目固定价 + 资源抵扣 | 无 | 无 | TR + VP |
| Concordia | Sestertii 金币 | 市场卡摊牌 + 供需轨道 | 无 | 无 | 乘法 VP |
| Capitalism Lab | 货币 | 完全市场供需 | 银行贷款/债券/增发/回购 | 真实三表破产 | 总资产/市值 |
| Chinatown | 现金 | **玩家自由议价** | 无 | 无 | 街区组合分 |
| Hotel Tycoon | 元 | 固定地价 | 抵押地契半价 | 个人破产清算 | 现金+资产 |
| 大富翁 | 纸币 | 固定价 + 随机涨跌 | 银行贷款 | 破产淘汰 | 资产 |

**经济模型光谱结论：**
- **价格由玩家竞价发现**：Modern Art、Ra、For Sale、Medici、Amun-Re、Keyflower、Stockpile、1830——"定价即博弈"。
- **价格由玩家直接自定**：FCM（菜单价）、Container（议价）、Chinatown（议价）——"定价即经营"。
- **价格由系统公式决定**：Acquire（规模→股价表）、Brass（成本固定）、Terraforming Mars（标准项目价）——"定价即查表"。
- **财商流建议**：三种定价机制分层使用——新手圈用"查表价"（降低决策负担），积累圈用"竞价发现"（教估值），自由圈用"自定议价"（教经营）。

## 表四：对财商流游戏的可落地借鉴建议清单（24 条）

> 每条建议标注：**来源机制 → 财商流落点 → 预期教学目标**。按"圈层"分组。

### A. 生存圈（入门层，60 分钟内）

| # | 借鉴建议 | 来源 | 落点 | 教学目标 |
|---|---------|------|------|---------|
| 1 | **双阶段买卖循环**：先用有限现金竞拍资产，再按手牌排序出售 | For Sale | 生存圈"副业低买高卖"小回合 | 买入价≠卖出价 |
| 2 | **封闭现金池**：阶段一现金全部流出游戏，强制"花完即结束" | For Sale | 副业初始预算硬约束 | 预算纪律 |
| 3 | **低阶资源终局清零**：姜黄不计分，高阶香料保值 | Century | 终局财富只计"硬资产/技能"，不计现金 | 避免囤现金躺赢 |
| 4 | **星级升级租金**：酒店设施等级越高，随机客流天数的单位收入越高 | Hotel Tycoon | 副业"固定成本×随机客流"收入公式 | 固定资产提升单位产出 |
| 5 | **事件卡市场情绪**：牛/熊卡随机切换整体景气 | 大富翁、Pit | 市场情绪指数 | 系统性情绪不可控 |

### B. 积累圈（策略层，2–3 小时）

| # | 借鉴建议 | 来源 | 落点 | 教学目标 |
|---|---------|------|------|---------|
| 6 | **有限竞价预算**：每回合 N 个竞价点数，花掉不返，余点折声望 | Ra | 机会卡竞拍池 | 跨期权衡 |
| 7 | **排名价值跨期累计**：行业景气连续上榜累加，掉线归零 | Modern Art | 行业指数：连续 3 季盈利者估值乘数累加 | 趋势跟踪 |
| 8 | **前两名分肥结构**：每条赛道第 1 名 10 分、第 2 名 5 分、第 3 名 0 分 | Medici | 行业赛道奖励：龙头/次龙头/跟随者 | 卡位博弈 |
| 9 | **献祭-公共收获循环**：多缴税者下一期获公共基建优先使用权 | Amun-Re | 纳税模块：多缴社保/税者获贷款优惠 | 税收与公共品 |
| 10 | **工人即货币**：同一资源可用于竞价（投资）或激活产能（生产） | Keyflower | "精力/人脉点数"双向用途 | 投资 vs 即时产出 |
| 11 | **零运气经营日六步**：招聘→营销→晚餐→收入→工资→里程碑 | FCM | 企业副业每回合六步结算 | 全成本核算 |
| 12 | **刚性工资陷阱**：工资与营收无关，低营收日才是最危险日 | FCM | 企业固定成本提示 | 现金流安全垫 |
| 13 | **标准项目+资源抵扣**：固定价行动，握有上游资源者成本自动下降 | Terraforming Mars | 企业投资品标准价+人脉折扣 | 供应链议价权 |
| 14 | **双功能投资卡**：每张技能卡既是当回合行动，又是终局乘数 | Concordia | 技能/证书卡池 | 沉没投资的双重回报 |
| 15 | **永久收入贷款**：借钱一次性到账，但永久性降低每轮基础收入 | Brass | 银行贷款：高杠杆=长期收入扣减 | 杠杆的长期成本 |
| 16 | **分红政策操纵估值**：企业是否分红直接影响下一期估值乘数 | 18xx | 企业分红决策→股价 | 分红与估值 |

### C. 自由圈（资本层，3 小时+）

| # | 借鉴建议 | 来源 | 落点 | 教学目标 |
|---|---------|------|------|---------|
| 17 | **三权分离**：出钱者（地权）≠ 经营者（控制权/Boss）≠ 分红者（按骰面） | Lords of Vegas | 合伙股权：投资人/经营者/分润权分开 | 公司治理 |
| 18 | **政变成本与对方实力挂钩**：夺权成本=对方影响力总和×系数，结果随机 | Lords of Vegas Reorg | 代理权之争事件 | 控制权争夺的不确定性 |
| 19 | **并购红利 10×/5×**：最大股东拿 10× 年利润一次性现金，第二大拿 5× | Acquire | 企业出售环节 | 创始人套现 vs 员工变现 |
| 20 | **清算优先权埋雷卡**：估值高但退出时后拿钱 | Stockpile 交易费卡 | 融资条款副卡池 | 条款比估值重要 |
| 21 | **不对称内幕信息**：每个玩家/Agent 只提前知道一组行业行情 | Stockpile | 创业事件卡：董事内幕 vs 公众信息 | 信息优势的博弈 |
| 22 | **双阵营限时谈判**：企业方 vs 投资方 2 分钟沙漏定价 | Panic on Wall Street | 融资轮限时 term sheet 竞价 | 时间压力下的估值 |
| 23 | **连锁传染破产链**：投资者违约→企业收不到钱→付不起管理费→贱卖公司 | Panic on Wall Street | 金融危机事件：违约传染 | 系统性风险 |
| 24 | **流动性枯竭终局**：全押资产者（现金最少）直接失去评优资格 | High Society | 困难模式终局规则 | 现金流为王 |

---

## 组合方案：财商流三大圈层的机制选型

```
生存圈（60 分钟，入门）
  核心：For Sale 双阶段 + Century 库存清零 + 大富翁事件卡
  目标：教会"低买高卖 + 现金不是财富"

积累圈（2–3 小时，策略）
  核心：Ra 有限预算拍卖 + FCM 六步经营日 + Brass 永久贷款 + Modern Art 行业动量
  目标：教会"现金流 + 杠杆 + 趋势"三角平衡

自由圈（3 小时+，资本）
  核心：18xx 分红操纵 + Lords of Vegas 三权分离 + Acquire 并购红利 + Stockpile 内幕
  目标：教会"控制权 + 条款 + 信息"的高阶博弈
```

## 风险与反模式清单

| 反模式 | 出处教训 | 财商流规避 |
|--------|---------|-----------|
| 无限资金拍卖 | 无预算约束的拍卖无教育意义 | 所有拍卖硬约束 ≤ 当前流动资产 30% |
| 纯随机骰子主导 | Hotel Tycoon 依赖建造骰，教学价值低 | 骰子只用于"客流天数"等二阶变量，不决定核心决策 |
| 换皮大富翁 | 苏联 Manager 证明换皮无意义 | 企业模块必须有独立的经营决策空间 |
| 四小时心算地狱 | FCM 原版心算量劝退 | Agent 自动结算，玩家只做 ≤2 分钟战略决策 |
| 黑箱财务 | Capitalism Lab 完整三表不适合桌游 | 仪表盘只亮红黄绿灯，配人话解释 |
| 赢家通吃无惩罚 | 纯累计计分鼓励垄断 | 引入 High Society 式"现金最少者出局"作为困难模式 |
