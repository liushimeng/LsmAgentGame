## 6. 2024–2025 金融热点与财商教育素材

### 6.1 热点话题

| 热点 | 财商教育切入点 |
|------|--------------|
| 房地产调整 | 资产泡沫、杠杆风险、分散投资 |
| A 股波动 | 市场情绪、长期投资、止损纪律 |
| 提前还贷潮 | 机会成本、流动性管理 |
| AI 投资 | 技术冲击、技能升级、职业规划 |
| 个人养老金 | 退休规划、税收优惠、长期复利 |
| 数字人民币 | 货币演进、支付安全、隐私保护 |
| 加密货币波动 | 投机风险、监管合规、技术认知 |

### 6.2 游戏设计素材

| 热点 | 可设计的游戏事件/机制 |
|------|---------------------|
| 房地产调整 | "房价下跌"事件卡，影响房产价值 |
| A 股波动 | "市场恐慌"事件，股价大幅波动 |
| AI 冲击 | 部分职业卡被"AI替代"，收入变化 |
| 个人养老金 | 新增"养老金账户"投资品 |
| 数字诈骗 | "诈骗事件"卡，考验风险防范 |
