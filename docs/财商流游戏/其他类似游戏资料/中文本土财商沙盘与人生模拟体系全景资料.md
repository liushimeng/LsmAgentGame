## 1. 觉商流沙盘 / "觉商"概念考证

### 1.1 背景与出品方

**考证结论**："觉商流沙盘"**并非一个独立于财富流的沙盘产品**。经多源检索，"觉商"是财富流/富而喜悦体系中提出的"六商"之一（财商、情商、玩商、逆商、觉商、健商），而非独立品牌或产品线。

- "觉商"在财富流官方语境中指"觉察能力"——即对自身思维模式、决策盲区的反思认知能力。财富流官方宣传物料将训练目标归纳为"六商"：财商、情商、逆商、玩商、觉商、健商（来源：财富流官网 caifuliu.com；抖音财富流教练讲解视频，2026-08-19，https://www.iesdouyin.com/share/video/7675552221442136811 ）。
- 部分财富流教练在个人推广中使用"觉商流"作为活动标签，但这只是对财富流推演中"觉察"环节的强调性称呼，不是独立产品。
- 富而喜悦品牌旗下沙盘工具以财富流沙盘、时空流沙盘、明日之星沙盘为主（财富流官网产品介绍，http://www2.caifuliu.com/about.php?id=164 ，2026-08-18 访问）。其中并无"觉商流沙盘"独立产品。

⚠️ **风险提示**：若有第三方以"觉商流沙盘"名义独立招生收费，可能是未经授权的衍生或混淆行为，需警惕。

### 1.2 "觉商"在财富流体系中的具体含义

在财富流的"六商"框架中，"觉商"被定义为：
- **对自身思维模式的元认知能力**：能否在决策过程中意识到自己的惯性思维、情绪驱动和认知偏差。
- **复盘反思的结构化能力**：财富流推演结束后的复盘环节被视为"觉商训练"的核心场景——教练引导玩家回顾每个关键决策点，追问"你当时为什么这样选""如果重来你会怎么做"。
- **从沙盘中"照见自己"的能力**：官方宣传语"推演即觉察"即指此意。

值得注意的是，"觉商"并非心理学或教育学中的标准术语，而是财富流品牌的自创概念。其内涵与心理学中的"元认知"(metacognition)、正念(mindfulness)有部分重叠，但缺乏学术定义与测量工具。

### 1.3 检索过程与结论

本次调研使用了以下关键词组合进行多轮检索（2026-09-10 复核）：
- "觉商流沙盘 规则""觉商流沙盘 玩法""觉商流沙盘 介绍"
- "觉商流 与 财富流 区别""觉商流 独立产品"
- "觉商流 培训""觉商流 认证"

复核检索结果（2026-09-10）：财富流官网（http://www2.caifuliu.com/about.php?id=164 ）及多个教练推广物料（活动行 https://huodongxing.com/event/9797396033912 ；抖音 https://www.iesdouyin.com/share/video/7675552221442136811 ）均把"觉商"列为财富流"六商"训练目标之一，未发现任何独立的"觉商流沙盘"商标、产品包装、规则文档或出品机构。所有搜索结果均指向财富流/富而喜悦体系的官方内容或教练个人推广文章，未发现任何独立的商标注册、产品包装、规则文档或出品机构。部分教练在小红书/微信公众号中以"觉商流推演"为标题发布活动招募，但内容实质仍是财富流沙盘推演，仅强调了"觉察"环节。

**结论**："觉商流沙盘"作为独立产品体系不存在。这一考证结果本身具有价值——说明在中文本土沙盘市场中，"觉商"尚未形成独立的产品品类，仍依附于财富流品牌。

### 1.4 对「财商流游戏」的可借鉴点与风险提示

- **可借鉴**："觉商"概念本身有价值——在游戏中嵌入"复盘觉察"机制（如 Agent 教练引导玩家反思决策盲区），可作为 AI 教练的核心差异化功能。具体实现建议：
  - Agent 在每轮结束后自动生成"决策回溯报告"，标注玩家的关键转折点；
  - 提供"如果重来"模拟功能，让玩家体验不同选择的后果差异；
  - 用数据可视化呈现玩家的决策模式（如风险偏好曲线、资源分配饼图），替代主观感悟式复盘。
- **风险提示**：命名上应避免使用"觉商流"以免与财富流体系产生混淆或侵权争议。建议使用"决策反思""策略复盘"等中性表述。

## 2. 幸福流沙盘 / 幸福力沙盘

### 2.1 背景与出品方

**考证结论**："幸福流沙盘"和"幸福力沙盘"均非独立的知名沙盘品牌，而是财富流体系的衍生应用场景或课程包装名称。

- **"幸福力儿童财商启蒙营"**：多个财富流教练/机构推出的亲子课程品牌，以"财富流沙盘"为核心教具，融合儿童教育心理学，面向 8 岁以上儿童。课程内容包含沙盘推演 + 名人故事 + 买卖实战演练。（来源：微信公众号"幸福力儿童财商启蒙营"2025-06-19）
- **"幸福流"** 一词在搜索结果中未出现任何独立产品、注册商标或出品机构。所有含"幸福流/幸福力+沙盘"的内容均指向财富流沙盘的儿童/亲子版本或教练个人课程品牌。
- **官方/机构使用佐证（2026-09-10 复核）**：财富流沙盘已被妇联、银行等机构用作亲子财商教具。例：辽宁兴隆台区妇联 2026-03-12 联合广发银行开展"财爸富妈"财富流沙盘活动（兴隆台区政府网 https://www.xlt.gov.cn/2026_03/13_17/content-555154.html ）；活动行平台上大量"亲子财富流沙盘""青少年财商训练营"报名页（如 https://huodongxing.com/event/9797396033912 ）。这些均以"财富流沙盘"为教具，无独立"幸福流"产品实体。

⚠️ 公开资料不足，未查证到独立于财富流的"幸福流沙盘"产品实体。

### 2.2 "幸福力儿童财商启蒙营"的课程结构

从已查证的公众号文章（2025-06-19）可提取以下课程设计信息：
- **适用年龄**：8 岁及以上。
- **课程形式**：沙盘推演 + 名人故事启发 + 买卖实战演练。
- **教育理念**：以儿童教育心理学为基础，融合财富流沙盘理念。
- **设计意图**：解决"成长于物质匮乏年代、财商思维受限的父母不知如何与孩子谈论金钱"的痛点。

另有微信公众号（2026-07-05）记录了"4 期青少年/亲子财富流沙盘"进阶课程设计：
- **第一期**：体验与熟悉沙盘逻辑；
- **第二期**：深度复盘首次推演问题，优化决策逻辑；
- **第三期**：借鉴优秀玩家策略，学会协作与抓核心机会；
- **第四期**：综合运用，形成个人财商思维框架。

这种"体验→复盘→借鉴→综合"的四阶递进设计，体现了财富流教练在亲子场景下的课程化包装能力。

### 2.3–2.9 各节

核心教具仍为财富流沙盘，规则参见 `财富流沙盘完整资料.md`。亲子版本的主要调整包括：
- 简化财务报表（减少资产负债表的复杂度）；
- 增加趣味叙事元素（名人故事、角色扮演）；
- 缩短单场时长（适配儿童注意力）；
- 增加家长参与环节（亲子共同决策）。

### 2.10 商业模式与生态

- **亲子课程定价**：⚠️ 未查到统一标准价，各地教练自行定价。从公众号文章推断，单次体验课约 100–300 元/人，系列课（4 期进阶）约 800–2000 元。
- **目标客群**：8 岁以上儿童及其家长，主打"亲子共学""财商启蒙"。
- **本质是财富流教练的二次变现路径**：用同一套沙盘教具切入亲子市场。教练通过成人场积累口碑后，开设亲子场扩大收入来源。
- **季节性特征明显**：暑假是亲子财商课程的高峰期，多个机构在 6-7 月集中推出暑期班。
- **与学校教育的互补关系**：中国大陆公立学校的财商教育几乎空白，亲子财商课程填补了这一空缺，但也意味着缺乏课程标准与质量监管。

### 2.11 对「财商流游戏」的可借鉴点与风险提示

- **可借鉴**：亲子/青少年场景是真实需求。财商流游戏可设计专门的"青少年模式"（简化规则、缩短时长、增加趣味叙事），对接学校财商课与暑期营地场景。
- **风险提示**：儿童财商课程市场鱼龙混杂，部分机构将身心灵话术包装为"幸福力"，缺乏可量化的教学成果评估。本作应坚持可验证的教育目标。

## 3. 财富罗盘 / 金钱罗盘

### 3.1 背景与出品方

本条目涉及两个不同产品，需分别考证：

#### 3.1a 金钱罗盘（北京奥特乐坤）

- **出品方**：北京奥特乐坤沙盘模拟训练中心。
- **性质**：投资与财务沙盘，小组竞技型培训教具。
- **Slogan**："金钱罗盘 财富指南针；盛世财商 人生即投资"。
- **渊源**：百度百科词条明确描述其"结合了欧美、日本等理财游戏的精华，并赋予鲜明的中国特色"，属于清崎现金流游戏的中国化改编版本之一。
- **创立时间**：⚠️ 百度百科词条创建于 2022-10-21，但实际产品可能更早；具体创立年份未查证。

#### 3.1b 富中富·财富罗盘（Wealth Share / 财富海洋·人生罗盘）

- **出品方（2026-09-10 复核已查证）**：实践家教育集团，由林伟贤（董事长，华文 Money&You 创办人）与郭腾尹（副董事长）联合开发。两位老师是风靡全球 40 多国、累计讲授约 38 年的美国课程 Money&You 国际级讲师。产品 2021 年问世，英文品牌名 Wealth Share / 富中之富人生罗盘。（来源：互动吧活动页 https://party.hudongba.com/party/gtso5.html ；Doers ASEAN 官网 https://doersasean.com/wealth-share-boardgame/ ；搜狐 https://m.sohu.com/a/478561509_520056/ ，2021-07-20）
- **设计理念**：以"富中之富 / 贫中之富 / 贫中之贫 / 富中之贫"四象限人生模型为核心，融合 Money&You 课程精髓、DISC 性格特质、富勒博士财富思维；盘面含"全方位人生财富表（损益表）"，判断玩家处于穷人/一般人/富人循环。
- **渊源澄清**：罗伯特·清崎本人亦是 Money&You 讲师，故财富罗盘与现金流游戏同源于 Money&You 体系，而非"融合财富流和智达富"。此前版本"融合财富流和智达富"的判断应予修正。
- **业内评价**：一位资深沙盘教练评价"逻辑有 bug，不好玩"（来源：微信公众号测评 2024-11-12）。⚠️ 仅为一方说法。

#### 3.1c 亲子沙盘"财富罗盘"

- 另有微信公众号文章（2026-08-11）以"亲子沙盘「财富罗盘」"为名推广亲子财商教具，定位为"沉浸式亲子财商教具"，覆盖"五商"。⚠️ 该产品与上述两款是否同源未查证。

### 3.2 完整游戏/课程流程

**金钱罗盘（奥特乐坤）**：
- 分为穷人圈（24 格）和富人圈（36 格）。
- 穷人圈格子类型：银行结算日、特殊机会（健康/公益、婚姻/生育、失业/生病）、市场风云、额外支出、小机会/大机遇。
- 富人圈格子类型：现金流量日、大额支出（移民、出版专集、演唱会、孩子留学）、特殊机会（慈善、商学院、幸运轮盘、原始股）、陷阱（官司、税务审计、股东纠纷、离婚）、梦想、投资机会。
- 核心目标：非工资收入 > 总支出，实现财务自由。

**金钱罗盘已查证的具体规则（2026-09-10 复核，来源：管理资源网"金钱罗盘"王长震老师课程页 https://m.qg68.cn/neixun/detail/201077.html ）**：
1. 手里现金达到 10 万元可抽"大机遇"卡；
2. 停留或经过银行结算日，可向银行领取当季现金流；
3. 忘记领取季度现金流或移动碰到别人棋子，罚款 1,000 元；
4. 健康/公益日缴纳工资收入的 1/5，可再掷一次骰子；
5. 停在结婚/生育日第一次，缴纳工资收入的 1/5 作为结婚（生育）费用。

**富中富·财富罗盘**：核心机制为购买/积累资产使被动收入 > 总支出、精力不为负、无贷款，即从"平流层"进入"顺流层"（来源：管理资源网 https://m.qg68.cn/neixun/detail/214481.html ；与财富流的"顺流层"术语高度相似，⚠️ 需注意二者术语混用）。完整四圈数值规则仍未公开。

### 3.3 详细规则

**金钱罗盘**：核心机制与清崎现金流高度相似（财务报表 + 投资卡牌 + 市场卡 + 额外支出），增加了中国式人生事件（婚姻/生育/移民/出版专集等）。具体数值规则 ⚠️ 未查证。

**富中富**：⚠️ 公开资料不足。

### 3.4–3.8 道具/棋盘/棋牌/经济/角色系统

⚠️ 以上两个产品的详细卡牌数量、棋子样式、职业卡数据等均未能从公开资料中查证。金钱罗盘的格子类型分布已在上文列出。

### 3.9 财商理念与教育目标

- **金钱罗盘**：偏传统财商教育，聚焦投资决策与财务自由，与清崎体系一脉相承，增加了中国化人生事件。

### 3.10 商业模式与生态

- **金钱罗盘**：主要面向企业培训与团建场景，由培训机构采购使用。⚠️ 具体价格未查证。

### 3.11 对「财商流游戏」的可借鉴点与风险提示

- **可借鉴**：金钱罗盘的"中国化人生事件"设计思路（移民、出版专集、孩子留学等）值得参考——这些是清崎原版没有、但对中国用户有共鸣的场景。

## 4. 金钱关系沙盘 / 财富关系沙盘

### 4.1 背景与出品方

**考证结论**："金钱关系沙盘"和"财富关系沙盘"**不是标准化的桌游产品**，而是心理咨询/家庭系统排列领域的体验式工作坊形式。

- 这类活动通常由心理咨询师或家庭系统排列导师带领，使用心理沙盘（箱庭疗法）+ OH 卡 + 象征物，探索个体与金钱的潜意识关系。
- 理论基础：精神分析客体关系理论、海灵格家庭系统排列、原生家庭金钱观代际传递理论。
- 典型活动形式：参与者在沙盘中自由摆放代表"我与金钱关系"的象征物 → 用 OH 卡解读潜意识剧本 → 导师引导觉察与疗愈。（来源：微信公众号"沙盘与OH卡对话财富"2026-04-09；互动吧《我与金钱的关系——系统排列探索》工作坊，标价 199–600 元，https://www.hudongba.com/party/36a95.html ，2026-07 ；壹心理 OH 卡金钱信念课程 http://m.xinli001.com/lesson/playView?id=1002&play_id=19164 ）

⚠️ 这不是一个有统一规则、卡牌、棋盘的标准化产品，而是一种心理咨询方法论的应用场景。

### 4.2–4.8 各节

不适用。无标准化游戏规则、棋盘、卡牌或经济系统。每次工作坊由导师根据参与者情况即兴设计。

### 4.9 财商理念与教育目标

- 核心理念："人与金钱的关系本质上是早年与养育者关系的投射与内化"。
- 目标不是教授理财技能，而是疗愈金钱创伤、打破限制性信念、重建与金钱的健康心理关系。
- 与清崎/九哥体系的根本区别：后者关注"如何赚钱/管钱"，此方向关注"为什么我在金钱上痛苦"。

### 4.10 商业模式与生态

- 以心理咨询工作坊形式收费，单次约 300–800 元/人，系列课程可达数千元。
- 从业者多为持证心理咨询师或家排导师，非财商教练。
- ⚠️ 该领域缺乏行业标准和监管，从业者水平参差不齐。

### 4.11 对「财商流游戏」的可借鉴点与风险提示

- **可借鉴**：金钱心理维度可在游戏中适度体现（如 Agent 教练在复盘时引导玩家觉察"你为什么不敢投资""你对亏损的情绪反应来自哪里"），但应保持轻量，不应喧宾夺主。
- **风险提示**：过度心理化会偏离财商教育主线。本作是开源 MIT 项目，不应提供心理咨询服务，也不应由 AI 扮演心理治疗师角色。

## 5. 亲子财商沙盘 / 青少年财商桌游 / 儿童财商教具

### 5.1 背景与出品方

这是一个分散的市场，没有单一主导品牌。主要参与者包括：

| 类型 | 代表 | 出品方 | 特点 |
|------|------|--------|------|
| 银行活动 | "小小银行家" | 平安银行、兴业银行、上海银行、宁波银行、广西北部湾银行等多家银行 | 免费公益活动，参观银行+点钞体验+财商小讲堂 |

| 证券投教 | "陶朱见喜"儿童财商桌游 | 国联证券投资者教育基地 | 融合历史文化+古代金融科普+防非反诈 |

| 本土桌游 | 《奇乐小鸡》《大宋百商图》等 | 多家国内桌游厂商 | 农场经营/古代商业主题，融入成本利润概念 |

### 5.2 完整游戏/课程流程

以"小小银行家"为例（最具代表性）：
1. 银行工作人员讲解货币起源、人民币防伪知识。
2. 参观银行全功能厅堂，认识 ATM、智能柜员机等设备。
3. 模拟"小小柜员"体验存取款全流程。
4. 趣味点钞环节（使用练功券）。
5. 财商小讲堂：零花钱规划、理性消费、储蓄意识。
6. 防诈骗知识普及。

以"汇童筑梦·财智小镇"为例：
1. 分队闯关，在模拟微型社会中赚取"第一桶金"。
2. 精打细算规划日常花销。
3. 制定长远存钱目标。
4. 财商嘉年华游园会。

### 5.3–5.8 规则/道具/棋盘/经济/角色系统

各产品差异极大，无统一标准。共同特点是：
- 规则大幅简化，适合 6-12 岁认知水平。
- 强调"想要 vs 需要""劳动换取报酬""储蓄实现目标"三个基础概念。
- 不涉及复杂的投资、杠杆、财务报表。

### 5.9 财商理念与教育目标

- 核心理念：财商启蒙 ≠ 教赚钱，而是建立健康的金钱观。
- 教育目标分层：幼儿（认识货币）→ 小学低年级（储蓄与消费选择）→ 小学高年级（简单投资概念、风险意识）。
- 银行/保险机构的活动带有明显的客户获取与品牌形象目的。

### 5.10 商业模式与生态

- **银行/保险/券商**：免费公益性质，费用纳入消保/投教预算，本质是客户关系维护与品牌建设。
- **公益组织**：基金会资助，面向欠发达地区儿童，不以盈利为目的。
- **财富流教练**：商业化运营，单次体验 100–300 元，系列课 800–2000 元。
- **桌游产品**：零售价格 50–300 元不等。

### 5.11 对「财商流游戏」的可借鉴点与风险提示

- **可借鉴**：①"小小银行家"模式的实景体验感极强，AI Agent 可通过叙事模拟弥补线上体验的不足；②分龄设计思路值得采纳；③银行/保险机构的 B 端合作模式可参考（作为学校/企业场景的切入渠道）。
- **风险提示**：金融机构的财商活动本质是获客，内容往往浅尝辄止。本作应保持教育中立性，不为任何金融产品背书。

## 6. 银行/保险/券商机构财商体验活动与教具

### 6.1 背景与出品方

本节与第 5 节有重叠，此处聚焦**成人向**的机构财商活动：

- **招商银行**：定期举办客户财商沙龙，使用定制版现金流游戏或财富流沙盘。⚠️ 具体教具型号与供应商未查证。

### 6.2–6.9 各节

机构财商活动通常不自研教具，而是采购第三方沙盘（财富流/现金流为主）或由培训师定制。活动内容以 2-3 小时沙龙为主，包含沙盘推演 + 讲师点评 + 产品推介（⚠️ 最后一步是隐性商业目的）。

- 隐性商业目的：客户粘性提升、理财产品推介、代理人增员。
- 财富流教练是机构活动的主要供给方，形成"教练→机构→客户"三方生态。

### 6.11 对「财商流游戏」的可借鉴点与风险提示

- **可借鉴**：B 端机构是重要的分发渠道。开源版财商流游戏可作为机构活动的免费替代方案，降低其采购成本。
- **风险提示**：机构活动的财商教育往往服务于销售目标，内容深度有限。本作应保持教育独立性，在设计上防止被用作理财产品推销工具。

## 7. 企业团建类财商沙盘 / 经营管理沙盘（ERP 沙盘模拟）

### 7.1 背景与出品方

**这是中国大陆覆盖面最广的经营沙盘体系**，与个人财商沙盘是完全不同的赛道。

- **起源**：20 世纪西方军事沙盘推演 → 英美商学院改良为企业培训 → 2009 年首次引入中国高校 MBA 教学。
- **两大供应商**：用友（"用友杯"全国沙盘大赛）和金蝶（手工沙盘+电子沙盘），是中国 ERP 沙盘市场的绝对双寡头。
- **赛事体系**：
  - "用友杯"全国大学生沙盘大赛：已连续举办十余届，影响力巨大。
  - "全国高等院校数智化企业经营沙盘大赛"：中国高等教育学会主办，2023 年列入《全国普通高校大学生竞赛分析报告》竞赛目录（赛项序号 74）。
  - "全国企业竞争模拟大赛"：中国管理现代化研究会主办，设企业决策、企业运营、供应链决策、数智沙盘四个赛道。
- **参赛规模**：2025 年全国企业竞争模拟大赛数智沙盘赛道有 354 所高校 1619 支队伍报名复赛，供应链决策赛道 306 所 1294 支。（来源：bisai.ibizsim.cn）

### 7.2 完整游戏/课程流程

1. **组队**：每队 4-6 人，分别担任 CEO、CFO、营销总监、生产总监、采购总监。
2. **接手企业**：从已运营 3 年的虚拟制造企业接手，初始资产约 1 亿元（总资产 107M，含现金 44M、厂房 40M、生产线 9M 等）。
3. **连续经营**：模拟 4-8 个会计年度（练习赛 4 年，正式比赛 6-8 年）。
4. **年度循环**：年初（投放广告、选订单、申请长贷、付税）→ 季度运营（采购、生产、研发、短贷）→ 年末关账（编制损益表和资产负债表）。
5. **评分**：总分 = 最终权益 ×（1 + 综合发展潜力系数/100）- 罚分。

### 7.3 详细规则

- **市场开拓**：本地 → 区域（1M/1 年）→ 国内（2M/2 年）→ 亚洲（3M/3 年）→ 国际（4M/4 年）。
- **产品研发**：P1（初始）→ P2 → P3 → P4，研发投入递增。
- **生产线**：手工线、半自动、全自动、柔性线，投资与产能递增。
- **融资**：长期贷款（年利率 10%）、短期贷款（年利率 5%）、贴现。
- **税务**：企业所得税 25%。
- **罚则**：报表不平扣 2-5 分/次，超时扣罚按分钟计，违规操作扣 2-3M/次。

### 7.4 道具/卡牌系统

- **物理沙盘**：6 张沙盘盘面代表 6 个竞争企业，盘面按职能划分营销与规划中心、生产中心、物流中心、财务中心。
- **标识物**：原材料、在制品、成品、现金等用不同颜色筹码/卡片表示。
- **报表**：损益表 + 资产负债表，每年手工填写并提交审核。
- **电子沙盘**：用友/金蝶软件系统，自动计算与评分。

### 7.5 棋盘/沙盘设计

不同于个人财商沙盘的"人生棋盘"，ERP 沙盘是企业运营面板：
- 6 张并列的企业盘面，每张代表一个模拟公司。
- 盘面按职能部门分区，放置对应标识物。
- 无"行进路线"概念，而是"年度经营循环"。

### 7.6 棋牌设计

- 无传统意义上的棋子/卡牌。
- 使用彩色筹码/卡片代表资金、物料、产品。
- 订单卡、市场预测表等纸质材料。

### 7.7 经济系统

模拟了完整的制造业企业经济环境：
- 供应链管理（采购→生产→销售）
- 资本结构（股权+债权融资）
- 市场竞争（广告投放→订单争夺）
- 税收制度（25% 企业所得税）
- 折旧与投资回报
- 国际贸易（多市场开拓）

### 7.8 角色/职业系统

固定 5 个管理角色：CEO、CFO、营销总监、生产总监、采购总监。部分赛事增设人力总监。

### 7.9 财商理念与教育目标

- 核心理念：企业资源计划（ERP）管理思想，强调系统化、全局化经营思维。
- 教育目标：理解企业运营全流程、培养团队协作与战略决策能力、掌握财务报表分析。
- 与个人财商沙盘的**根本区别**：ERP 沙盘关注"如何经营企业"，个人财商沙盘关注"如何管理个人财富"。前者是管理学教育工具，后者是个人成长工具。

### 7.10 商业模式与生态

- **高校教学**：纳入经管类专业必修/选修课程，教材由清华大学出版社等出版（如《ERP沙盘模拟企业经营教程》）。
- **竞赛体系**：校级选拔 → 省赛 → 全国总决赛，获奖可加分/保研。
- **企业培训**：2 天内训课程报价约 2-5 万元/场（含讲师+教具），头部讲师返聘率超 70%。
- **软件平台**：用友新道、金蝶 BizSand 等电子沙盘系统，高校采购价 ⚠️ 未查证。
- **师资认证**：IPA 国际注册认证沙盘讲师、AACTP 授权翻转教练等。

### 7.11 ERP 沙盘在中国高校的覆盖规模

ERP 沙盘模拟是中国大陆覆盖面最广的经营类沙盘体系，其渗透率远超任何个人财商沙盘：

- **赛事层级**：校级选拔赛 → 省级复赛 → 全国总决赛，形成完整的三级竞赛体系。
- **参赛规模**：仅 2025 年全国企业竞争模拟大赛就有 688 所高校 9091 支队伍报名，其中数智沙盘赛道 354 所 1619 支、供应链决策赛道 306 所 1294 支。加上用友杯等其他赛事，全年参与高校预计超过 1000 所。
- **课程嵌入**：大量高校经管类专业将 ERP 沙盘设为必修或选修课，配套教材由清华大学出版社等主流出版社出版。国家高等教育智慧教育平台上也有相关慕课（如内蒙古财经大学"创业者沙盘模拟企业经营"）。
- **职业院校**：全国职业院校技能大赛（中职组）设有企业经营沙盘模拟赛项，比赛时长约 490 分钟，模拟 5 个会计年度。
- **师资生态**：IPA 国际注册认证沙盘讲师、AACTP 授权翻转教练等认证体系已形成稳定的师资供给。头部讲师如焦小亮等累计培训场次 400+、学员 20000+、返聘率超 70%。

### 7.12 ERP 沙盘的典型运营规则详解

以下规则综合自用友/金蝶多个版本的公开资料，代表主流赛制：

**初始状态（第 0 年末）**：
- 总资产 107M：现金 44M、应收款 0M、在制品 8M、成品 6M、原料 0M、土地建筑 40M、机器设备 9M、在建工程 0M。
- 负债与权益：长期负债 40M（3 年期 20M + 4 年期 20M）、短期负债 0M、应交税 1M、股东资本 50M、利润留存 14M、年度净利 2M、所有者权益 66M。
- 生产基础：仅生产 P1 产品，拥有大厂房 1 座（40M）、生产线 4 条（3 条手工线 + 1 条半自动线）。

**市场开拓规则**：
| 市场 | 开拓费用 | 开拓周期 | 备注 |
|------|---------|---------|------|
| 本地 | 0 | 0 | 初始即有 |
| 区域 | 1M | 1 年 | — |
| 国内 | 2M | 2 年 | 每年投入 1M |
| 亚洲 | 3M | 3 年 | 每年投入 1M |
| 国际 | 4M | 4 年 | 每年投入 1M |

**生产线类型**：
| 类型 | 投资额 | 安装周期 | 产能 | 转产灵活性 |
|------|-------|---------|------|-----------|
| 手工线 | 0（已有） | 0 | 低 | 高 |
| 半自动 | 2M | 1Q | 中 | 中 |
| 全自动 | 4M | 2Q | 高 | 低 |
| 柔性线 | 6M | 3Q | 高 | 高 |

**融资规则**：
- 长期贷款：年利率 10%，最长 4 年，每年初可申请。
- 短期贷款：年利率 5%，期限 1 年，每季度初可申请。
- 贴现：应收账款可提前变现，扣除贴现息。

**评分公式**：
```
总分 = 最终权益 × (1 + 综合发展潜力系数 / 100) - 罚分
```
综合发展潜力系数由以下指标累加：自动线 +8 分/条、柔性线 +10 分/条、国际市场开拓 +10 分、ISO14000 认证 +10 分、P4 产品研发 +10 分等。

### 7.13 对「财商流游戏」的可借鉴点与风险提示

- **可借鉴**：
  - ① ERP 沙盘的"角色分工+团队协作"模式可直接用于财商流游戏的多人模式设计；
  - ② 高校竞赛体系是极佳的分发渠道——若财商流游戏能进入高校财商课或创业课程，将获得巨大的用户基数；
  - ③ 年度经营循环的结构化设计思路可用于游戏中的"市场周期"机制；
  - ④ 初始状态的精确数值设定（资产 107M、权益 66M 等）体现了专业级沙盘的设计严谨度，财商流游戏的职业卡数据应达到同等精度；
  - ⑤ 罚则体系（报表不平扣分、超时扣分）可作为 AI 裁判的规则参考。
- **风险提示**：
  - ERP 沙盘过于侧重企业经营，与个人财商教育的目标有本质差异。不应将两者混为一谈。
  - ERP 沙盘的复杂度较高（4-8 年经营周期、多职能协同），不适合直接移植到个人财商场景。应提取其结构化思维，而非照搬规则。
  - 用友/金蝶的知识产权需注意规避——财商流游戏不应使用其专有的盘面设计、软件界面或商标。

## 财商流游戏的市场定位与差异化建议

基于以上生态全景调研，对「财商流游戏」提出以下差异化定位建议：

### ① 坚持可量化的理性财商教育，避开身心灵化陷阱

当前中文本土沙盘市场的显著趋势是**身心灵化**：财富流已走向"六商"融合，智达富更是将财商完全包裹在"能量""觉醒"话语中。这固然满足了部分人群的心理需求，但也带来了三个问题：
- 教育成果不可量化、不可验证；
- 容易滑向伪科学与迷信；
- 为类传销式营销提供了话语掩护。

**财商流游戏的定位应是"理性财商教育的开源基础设施"**：
- 所有游戏机制对应可解释的经济学/金融学原理；
- 复盘引导基于数据分析而非直觉感悟；
- 明确声明"本游戏不构成投资建议，不承诺任何收益"。

### ② Agent 驱动带来的结构性优势

现有沙盘体系的共同瓶颈是**对带盘人/教练的高度依赖**：
- 财富流需要认证教练，培训费数千至上万元；
- ERP 沙盘需要专业讲师，内训费 2-5 万/场；
- 现金流俱乐部需要有经验的带盘人。

AI Agent 教练可以：
- **消除教练供给瓶颈**：不需要培养带盘人，任何人都可以单人开局；
- **实现个性化复盘**：Agent 可根据每位玩家的决策数据生成定制化分析报告；
- **保证教育质量一致性**：不会因教练水平参差导致体验落差；
- **支持多语言/多方言**：天然适配国际化与方言场景。

### ③ 教育场景切入路径

- **高校财商课**：ERP 沙盘已证明高校是经管类沙盘的巨大市场。财商流游戏可定位为"个人财商版 ERP 沙盘"，填补高校财商通识课的教具空白。MIT 开源协议对高校友好。
- **企业团建**：作为 ERP 沙盘的轻量化补充（半天 vs 两天），聚焦个人财务健康而非企业经营。
- **社区/公益**：开源+免费特性使其适合社区财商普及、乡村财商教育等公益场景。
- **亲子场景**：设计专门的"青少年模式"，与"小小银行家"等活动互补。

### ④ 开源 MIT 模式与商业化沙盘的竞争关系

- **不是替代，而是互补**：商业沙盘卖的是"体验+社交+教练服务"，开源沙盘提供的是"可定制的底层工具"。
- **差异化价值**：商业沙盘受限于教练产能和场地，开源沙盘可实现无限并发、随时随地、零边际成本。
- **生态位**：做财商教育的"Linux"——不追求开箱即用的完美体验，而是提供可被任何人修改、适配、二次开发的底层引擎。

### ⑤ 合规与伦理边界

- **不构成投资建议**：在游戏启动页、复盘报告、Agent 对话中反复声明。
- **不承诺收益**：禁止任何"玩了就能赚钱""提升财商=增加收入"的承诺性表述。
- **不发展下线**：绝不设计任何形式的推荐奖励、层级分销机制。本次调研发现，中国大陆市场中以"俱乐部""共建""合伙人"为名的多层级分销模式频繁出现在财商/身心灵领域，且多起已被司法认定为传销或非法集资。开源项目应彻底远离此类模式。
- **数据隐私**：玩家的财务模拟数据不得用于任何商业用途。
- **心理健康免责**：Agent 教练不提供心理咨询服务，发现玩家情绪异常时应建议寻求专业帮助。
- **知识产权尊重**：不使用"财富流""现金流""CASHFLOW""富爸爸"等已有品牌的商标或近似名称。游戏规则设计可借鉴思路但不应复制具体卡牌内容或数值。
- **文化敏感性**：涉及中国传统文化元素（如节气、五行）时，应以文化符号而非神秘主义的方式使用，避免"能量""频率""觉醒"等伪科学表述。

### ⑥ 竞品生态位总结

基于本次全景调研，中文本土财商沙盘市场可分为四个象限：

| | 高财商纯度 | 低财商纯度（高身心灵比重） |
|---|---|---|
| **个人向** | 现金流原版、金钱罗盘 | 财富流、智达富、金钱关系沙盘 |
| **组织向** | ERP沙盘、企业竞争模拟 | 企业团建版财富流、沙漠掘金 |

**财商流游戏的定位**：左上角（高财商纯度 + 个人向），但通过 AI Agent 同时覆盖右下角的部分需求（如个性化复盘中的轻度心理觉察）。这是一个目前几乎空白的生态位——现有的高财商纯度产品（现金流原版）缺乏中国化和本地化，而中国化产品（财富流）又过度身心灵化。

### 调研方法论说明

本次调研采用以下方法：
1. **中文搜索引擎检索**：以 WebSearch 工具为主，使用多组关键词组合覆盖各体系。
2. **来源交叉验证**：对关键事实（如创立时间、出品方、规则数据）要求至少两个独立来源佐证；仅有一个来源的标注为"一方说法"。
3. **营销话术过滤**：对公众号文章中的宣传性表述（如"全球40国""体验用户触达百万"等）保持审慎，不作为事实引用，除非有第三方数据支撑。
4. **企业信息核实**：对出品公司使用启信宝等企业信息平台核实注册信息、股东结构与经营风险。
5. **负面信息平衡**：对争议性内容（如类传销模式、身心灵化批评）同时呈现正反两方信息，注明信息来源性质。
6. **缺失即结论**：对于检索后仍无法查证的信息，如实记录"未查证"并说明检索过程，将信息缺失本身视为市场生态的特征之一（公开资料稀薄 = 市场成熟度低）。
