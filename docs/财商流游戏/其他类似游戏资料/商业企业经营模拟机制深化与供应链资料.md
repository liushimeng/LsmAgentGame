## 1. 企业全生命周期模拟

### 1.1 Adizes 企业生命周期理论

#### 1.1.1 阶段模型

| 阶段 | 特征 | 桌游映射 |
|------|------|---------|
| **孕育期（Courtship）** | 创意验证、资源承诺 | 创业卡/创意验证阶段 |
| **婴儿期（Infancy）** | 现金流紧张、生存压力 | 创业初期资金紧张 |
| **学步期（Go-Go）** | 快速增长、机会主义 | 快速扩张但管理混乱 |
| **青春期（Adolescence）** | 规范化、权力交接 | 引入职业经理人 |
| **盛年期（Prime）** | 平衡灵活与稳定 | 最优规模与利润 |
| **稳定期（Stability）** | 保守、创新下降 | 利润稳定但增长放缓 |
| **贵族期（Aristocracy）** | 形式主义、避免风险 | 官僚化、决策缓慢 |
| **官僚早期（Salems）** | 内部斗争、忽视客户 | 组织政治取代市场 |
| **官僚期（Bureaucracy）** | 依赖外部维持 | 需要重组或退出 |
| **死亡（Death）** | 无法生存 | 破产清算 |

#### 1.1.2 桌游设计应用

**企业生命周期事件卡**：
- 婴儿期：频繁现金流危机事件
- 学步期：过度扩张风险事件
- 青春期：管理变革事件
- 盛年期：品牌溢价能力
- 贵族期：创新瓶颈事件

### 1.2 企业生命周期在桌游中的实现

#### 1.2.1 Brass: Lancashire/Birmingham 的产业演进

- **运河时代（Canal Era）**：基础建设、资源开发
- **铁路时代（Rail Stage）**：规模扩张、全国市场
- **时代切换**：旧产业强制淘汰，模拟技术迭代

**映射**：
- 运河期 = 婴儿期→学步期
- 铁路期 = 青春期→盛年期
- 时代切换 = 技术颠覆/产业周期

#### 1.2.2 Food Chain Magnate 的企业成长

- 单店经营 → 区域连锁 → 全国帝国
- 从"夫妻店"到"上市公司"的模拟

## 2. 供应链管理机制

### 2.1 供应链牛鞭效应（Bullwhip Effect）

#### 2.1.1 定义

> **定义**：需求信息从终端客户向上游传递时波动逐级放大的现象。

**桌游映射**：
- 终端需求小幅波动 → 零售商订单中等波动 → 批发商订单大幅波动 → 生产商剧烈波动

#### 2.1.2 实现机制

| 角色 | 信息流 | 决策 |
|------|-------|------|
| 终端客户 | 需求卡片（随机） | 无 |
| 零售商 | 观察客户需求 | 向上游下单 |
| 批发商 | 观察零售商订单 | 向生产商下单 |
| 生产商 | 观察批发商订单 | 生产计划 |

**设计应用**：
- 财商流游戏中"供应链"投资品可设置牛鞭效应——终端需求波动被上游放大
- 玩家需要预测需求并管理库存，避免过度生产或库存不足

### 2.2 Container（集装箱）的供应链议价

#### 2.2.1 供应链角色

| 角色 | 功能 | 议价力来源 |
|------|------|-----------|
| **工厂（Factory）** | 生产集装箱 | 产能、技术 |
| **船运公司（Shipping）** | 运输集装箱 | 航线、运价 |
| **仓库（Warehouse）** | 存储集装箱 | 仓储能力 |
| **商店（Shop）** | 销售集装箱 | 渠道、客户 |

#### 2.2.2 双边议价机制

- 上下游之间一对一议价
- 无替代对手时议价力弱
- 有替代对手时议价力强

**映射**：波特五力模型中的"买方议价力"与"卖方议价力"

### 2.3 精益生产与库存管理

#### 2.3.1 JIT（Just-in-Time）机制

> **定义**：只在需要时生产所需数量，追求零库存。

**桌游实现**：
- 持有库存每回合产生仓储成本
- 缺货导致销售机会损失
- 玩家需平衡库存成本与缺货风险

#### 2.3.2 经济订货量（EOQ）模型

```
EOQ = √(2DS/H)
D = 年需求量
S = 每次订货固定成本
H = 单位年持有成本
```

**桌游映射**：
- 大量订货 → 单位成本低但持有成本高
- 频繁订货 → 单位成本高但持有成本低
- 最优订货量平衡两者

## 3. 人力资源管理机制

### 3.1 Food Chain Magnate 的员工培训链

#### 3.1.1 员工层级

| 级别 | 职位 | 能力 | 薪资 |
|------|------|------|------|
| 1 | 跑腿伙计（Runner） | 基础执行 | 低 |
| 2 | 服务员（Waiter） | 服务客户 | 低-中 |
| 3 | 厨师（Cook） | 制作菜品 | 中 |
| 4 | 经理（Manager） | 增加服务容量 | 中-高 |
| 5 | 培训讲师（Trainer） | 培训其他员工 | 高 |
| 6 | 总经理助理（Asst. Mgr.） | 管理协调 | 高 |
| 7 | CEO | 全局决策 | 最高 |

#### 3.1.2 培训前置条件

- 要雇佣高级员工，必须先有低级员工在岗
- 例如：雇佣厨师需要先有服务员
- 这模拟了现实中的"技能阶梯"与"职业发展路径"

**桌游映射**：
- 财商流游戏中"人力资源管理"可引入技能阶梯
- 高级职位需要从低级晋升，不能直接空降

### 3.2 人力资本投资回报

#### 3.2.1 投资回报周期

| 投资类型 | 回报周期 | 风险 |
|---------|---------|------|
| 招聘基础员工 | 立即 | 低 |
| 培训高级员工 | 2-3回合 | 中 |
| 雇佣CEO | 4-5回合 | 高 |

#### 3.2.2 员工流失风险

- 高级员工可能被"猎头"（对手挖角）
- 培训投入沉没
- 需要"竞业禁止"或"留任奖金"机制

### 3.3 组织行为学概念

#### 3.3.1 管理幅度（Span of Control）

> **定义**：一个管理者直接管辖的下属数量上限。

**桌游映射**：
- 经理可管辖 3 名员工
- 超过上限需要增加管理层级
- 增加管理成本

#### 3.3.2 决策质量与决策速度

- 民主决策：质量高但速度慢
- 独裁决策：速度快但质量依赖个人能力
- 游戏中可让玩家选择决策方式

## 4. 生产与成本管理

### 4.1 成本分类

#### 4.1.1 固定成本 vs 变动成本

| 成本类型 | 特征 | 桌游映射 |
|---------|------|---------|
| **固定成本** | 与产量无关 | 租金、设备折旧 |
| **变动成本** | 随产量变化 | 原材料、直接人工 |
| **半变动成本** | 部分固定+部分变动 | 水电费（基础费+用量费） |

#### 4.1.2 边际成本与平均成本

- **边际成本**：每多生产一单位的成本
- **平均成本**：总成本 / 总产量
- 当边际成本 < 平均成本时，平均成本下降（规模经济）
- 当边际成本 > 平均成本时，平均成本上升（规模不经济）

### 4.2 盈亏平衡分析

#### 4.2.1 盈亏平衡点（BEP）

```
BEP = 固定成本 / (单价 - 单位变动成本)
```

**桌游映射**：
- 玩家需计算"卖多少才能回本"
- 低于 BEP = 亏损
- 高于 BEP = 盈利

#### 4.2.2 安全边际

```
安全边际 = (实际销量 - BEP) / 实际销量
```

**意义**：衡量企业对抗需求波动的缓冲能力

### 4.3 质量管理

#### 4.3.1 质量成本

| 成本类型 | 描述 |
|---------|------|
| 预防成本 | 预防缺陷的投入 |
| 鉴定成本 | 检验产品质量的成本 |
| 内部失败成本 | 生产中发现缺陷的损失 |
| 外部失败成本 | 售后质量问题的损失 |

#### 4.3.2 质量与成本的权衡

- 高质量 → 高成本 → 高售价
- 低质量 → 低成本 → 低售价
- 最优质量水平 = 边际质量收益 = 边际质量成本

## 5. 研发与知识产权

### 5.1 研发投入机制

#### 5.1.1 研发类型

| 类型 | 投入 | 回报 | 风险 |
|------|------|------|------|
| 基础研究 | 高 | 不确定 | 高 |
| 应用研究 | 中 | 较确定 | 中 |
| 产品开发 | 低 | 确定 | 低 |

#### 5.1.2 研发回报

- 成功：获得新产品/新技术，竞争优势
- 失败：投入沉没
- 研发具有"期权价值"——当前投入可能在未来产生回报

### 5.2 知识产权机制

#### 5.2.1 专利

- 研发成功可获得"专利卡"
- 专利有效期有限（如 5 回合）
- 其他玩家使用需支付许可费

#### 5.2.2 技术溢出

- 其他玩家可"逆向工程"绕过专利
- 但需投入额外研发成本

## 6. 市场营销与定价

### 6.1 4P 营销组合

| 要素 | 描述 | 桌游映射 |
|------|------|---------|
| **Product（产品）** | 产品差异化 | 产品卡质量等级 |
| **Price（价格）** | 定价策略 | 玩家自定售价 |
| **Place（渠道）** | 销售渠道 | 直销/分销/电商 |
| **Promotion（推广）** | 广告宣传 | 营销费用投入 |

### 6.2 定价策略

#### 6.2.1 成本加成定价

```
售价 = 成本 × (1 + 加成率)
```

#### 6.2.2 竞争定价

- 参考竞争对手定价
- 价格战：低价抢客但利润薄

#### 6.2.3 价值定价

- 基于客户感知价值定价
- 差异化产品可定高价

### 6.3 Food Chain Magnate 的营销系统

- 营销手段：广告牌、广播、报纸
- 营销在特定住宅区产生"需求"
- 多家餐厅营销同一区域 = 竞争同一客户群
- 距离 + 价格决定客户流向
