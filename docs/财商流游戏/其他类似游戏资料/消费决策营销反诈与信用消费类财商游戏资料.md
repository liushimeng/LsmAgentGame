## 板块 0 · 为什么这四个维度必须单独成篇

真实世界普通家庭的「钱袋子漏洞」来源分布，按危害频次排序，**消费侧远高于投资侧**：

1. **冲动消费与营销话术**：中国消费者协会 2024 年度投诉分析报告显示，**广告与营销类投诉**连续多年位居前列，「先涨后降」「直播限时限量」「凑单满减」是消费者感知最强烈的三大价格误导（公开资料，具体位次待核验）。普通人每月被「话术」多花的钱，往往超过全年投资收益。
2. **信用消费利率幻觉**：信用卡分期「月手续费 0.6%」名义年化 7.2%，**真实 IRR 约 13%**——这正是监管要求明示「实际年化利率」的核心原因。大量消费者把「手续费率」误作「利率」，是家庭过度负债的重要认知根源。
3. **电信网络诈骗**：公安部 2024 年公布，**刷单返利类诈骗占发案总量近三分之一**、**虚假网络投资理财类占损失总额近三分之一**；十大高发类型合计占比达 **88.4%**（2023 版为近 80%）。受害者平均年龄 **37 岁**，18–40 岁占 **62.1%**。反诈不是「老年人的事」，是青壮年群体最大财产风险之一。
4. **套路贷 / 校园贷 / 砍头息**：虽经 2017–2020 年专项整治，但变形产品（「培训贷」「美容贷」「租机贷」）仍活跃；《民法典》第 670 条虽禁止砍头息，但消费者在签约时极少逐条核验。

桌游/教具侧，既有资料几乎空白——没有一款现有文档把「消费陷阱做成事件卡」「信用消费做成真实 IRR 换算」「反诈做成信息甄别 mini-game」。本文件即为填补这一结构性缺口而作。

## 板块 1 · 反诈主题桌游与沉浸式教具（中国公安 / 银行 / 高校出品）

> **共同特征**：反诈主题游戏几乎全部由**公安机关主导**（联合银行、高校、社区、游戏厂商），而非商业桌游公司自发设计。这是区别于其他财商游戏的重要生态特征——它们的核心 KPI 是「辖区发案率下降」而非「销量」。

### 1.1 反诈大富翁（Anti-Fraud Monopoly，各地公安局，2023–2026）

| 项 | 内容 |
|----|------|
| 出品方 | 多地主警公安联合社区/银行独立开发；典型如 **江苏淮安公安**（清江浦分局反诈扑克牌、反诈套圈）、**江苏警方微博**发布多款变体 |
| 形态 | 把 Monopoly（大富翁）棋盘按**高发诈骗类型**分格，替代「街道 / 铁路」；玩家途经格子触发对应诈骗案例事件卡 |
| 核心机制 | **事件卡驱动**：每格对应一种诈骗手法（刷单/杀猪盘/冒充公检法/虚假投资等），翻事件卡后玩家决策——识破则免损、被骗则扣现金 / 扣押「资金格」若干回合 |
| 差异点 | 区别于 Pay Day 的「财务规划」导向，反诈大富翁是**纯风险识别训练**——不教储蓄，只教「这是骗局」 |
| 局限 | 多数为线下活动一次性产品，**无统一公开发行版**，规则碎片化、未商业化；机制偏简单（识破/被骗二选一），缺少「半信半疑」「延迟决策」等真实心理状态 |

> **借鉴落点**：《财商流游戏》「反诈 mini-game」（见板块 5）可借鉴其「按诈骗类型分格」的**分类框架**（公安部十大高发类型），但把「二选一识破」升级为「信息甄别 mini-game」（多信号、多干扰项、有时间压力），并把「被骗扣钱」改为「被骗触发信用评分下降 + 资金冻结 + 影响后续贷款利率」——把反诈结果**接入本作信用系统**而非一次性惩罚。

### 1.2 反诈飞行棋（Anti-Fraud Flying Chess，南京鼓楼警方 / 民生银行 / 大兴安岭公安 / 山东大学，2025–2026）

| 项 | 内容 |
|----|------|
| 代表案例 | **南京鼓楼警方**（2025.12，进校园）棋高一招；**民生银行**（2025.11，山东省，联合人民银行山东省分行/公安厅/教育厅）设计「反诈投壶、沙包投准、反诈飞行棋」等 10 余个互动游戏；**大兴安岭公安局十八站分局**（2026.6）地面绘棋盘进校园；**山东大学**（2025）青年反诈在行动 |
| 形态 | 把传统飞行棋棋盘格替换为**反诈知识问答 / 诈骗识别题**；答对前进、答错后退或触发「被骗事件」 |
| 核心机制 | **体感 + 问答**：部分版本把棋盘画在地面，学生身体当棋子（大兴安岭「地面绘棋盘」），强化记忆锚点 |
| 规模 | 民生银行山东版本联合监管、公安、教育、网安四方；南京鼓楼版本被多家媒体报道为「棋高一招」 |
| 局限 | 纯问答型，**缺少决策分支**——对消费侧「半信半疑 / 从众 / 锚定」等心理状态覆盖不足 |

> **借鉴落点**：其「体感锚点」思路可转化为《财商流游戏》的**线下实体扩展包**（如线下桌游版 / 亲子版），但在核心线上版应升级为「情境判断 + 多选项 + 即时反馈 + 心魔卡触发」（见板块 5）。

### 1.3 反诈剧本杀《收网》（Shou Wang，2025，烟台公安 × 烟台大学 × 大众网）

| 项 | 内容 |
|----|------|
| 全称 | 《收网》——山东省首个警校媒三方联创反诈剧本杀 |
| 发布时间 | **2025 年 11 月**，烟台大学发布 |
| 出品方 | **烟台市公安局莱山分局**（案例+专业指导）+ **烟台大学**（场景+智力支持）+ **大众网**（传播推广） |
| 面向群体 | **大学生**，**免费开放** |
| 剧情设计 | 改编自莱山分局侦破的**多起真实诈骗案件**；**6 位玩家**扮演普通人，命运相互交织 |
| 融入骗局类型 | 「高薪兼职」先交押金、**AI 换脸诈骗**、网恋诱导转账、高回报投资、**刷单诈骗** |
| 游戏类型 | 欢乐机制阵营沉浸式剧本；玩家**每一个决策与选择都会影响「财产安全」** |
| 设计理念 | 从「单向灌输」转向「双向互动」；从「要我防诈」到「我要防诈」；让玩家在「受骗」中完成**免疫接种**，将反诈意识熔铸为本能 |
| 效果数据 | 上线一周体验及预约学生近 **10000 名**；现场问卷 **90%+** 参与者认为显著提升反诈警觉性 |
| 学生反馈 | 「在游戏中流下的冷汗，会成为现实生活中最坚硬的铠甲」（大二学生）；「意想不到的骗局确实会让我以后在生活中提高警惕」（剧本杀老玩家） |
| 推广计划 | 计划推广至其他高校和居民社区 |

> **借鉴落点**：《收网》证明了「**在安全环境中体验被骗**」（sandbox 受骗）的教育有效性——这正是《财商流游戏》「反诈 mini-game」应采用的**核心教学法**：让 Agent 玩家与 bot 在 mini-game 中「真实」经历一次受骗（触发资金损失、信用降级），但后果可控、可复盘。其「6 人阵营沉浸」形态也适合本作的**在线房间模式**（6 人一桌反诈挑战）。

### 1.7 国际反诈 / 信用消费教育游戏补遗（英文，可机制借鉴）

| 游戏 | 出品方 | 形态 | 核心机制 | 借鉴点 |
|------|-------|------|---------|-------|
| **Con 'Em If You Can** | FINRA 投资者教育基金会 + McGill 大学金融数据科学实验室 | 数字游戏（Web / App） | **扮演骗子**：玩家选择骗局类型（投资骗局 / 爱情骗局 / 疫情骗局等）与目标受害者，学习诈骗者如何选择话术、制造紧迫感、利用信任；每关后复盘「为何受害者会上当」 | **反向学习法**——从施骗方视角理解诈骗心理，比「受害者视角识破」记忆更深。可借鉴为《财商流游戏》「反诈 mini-game」的**反派模式**（bot 扮演骗子，玩家扮演受害者，或反之） |

## 板块 2 · 营销识破类教具与广告素养课堂游戏

### 2.1 广告素养 / 媒介素养课堂游戏（全球，1990s–至今）

| 项 | 内容 |
|----|------|
| 代表产品 | **Center for Media Literacy (CML)** 五核心概念框架；**Namle (National Association for Media Literacy Education)** 课堂游戏；中国内地多省**《媒介素养》**中小学选修课配套游戏 |
| 核心教学目标 | 识别广告五大手法：**从众(bandwagon)、光环转移(glittering generality)、平民化(plain folks)、堆卡(card stacking)、代言(testimonial)** |
| 典型课堂游戏 | 「广告解剖」——给一份真实广告，学生圈出使用的说服手法；「真假新闻辨析」——混排 10 条信息，学生判断真伪并说明理由 |
| 局限 | 偏**批判性思维识读**，不涉及「消费决策 + 钱包影响」——识破广告后，**花不花钱、怎么花钱**仍是空白 |

> **借鉴落点**：广告素养的「识别说服手法」清单可直接转化为《财商流游戏》的**「营销话术卡」**（见板块 5），每张话术卡标注手法类型 + 心理偏差锚定（框架效应 / 从众 / 锚定），玩家使用时对手可「识破」检定。

### 2.2 「双十一比价」课堂实验（中国中小学 / 消费者组织，2018–至今）

| 项 | 内容 |
|----|------|
| 做法 | 教师让学生在双十一前 1 个月记录某商品日常价，双十一当天再记录「促销价」，对比是否真便宜；中国消费者协会历年发布**「双十一」价格监测报告**揭示「先涨后降」 |
| 教学点 | **价格锚定**：原价标签是人为锚点；**时间压力**：限时制造冲动；**凑单满减**：诱导超额消费 |
| 效果 | 消费者协会历年监测均发现相当比例商品存在「先涨后降」（具体比例按年度待核验）；学生实验后对促销的**盲信度显著下降**（训练知识待核验） |

> **借鉴落点**：可直接设计为《财商流游戏》的**「比价 mini-game」**——给出同一商品的 3 个「优惠方案」（满减 / 直降 / 返券），玩家选择最划算选项，系统按**真实折后单价**判定胜负（训练「表面折扣 vs 实际单价」识别）。

### 2.3 直播带货话术实验（学术研究 + 课堂，2021–2025）

| 项 | 内容 |
|----|------|
| 代表研究 | 中国知网多篇论文：「电商直播情境下主播营销话术与消费者冲动购买行为——基于心理契约调节的中介作用」（2025）；「基于语言经济学的直播带货话语分析——以李佳琦直播带货话语为例」（2021） |
| 话术分类 | **理性诉求**（成分/功效/性价比）+ **情感诉求**（陪伴/认同/稀缺）；**催单话术**（限时/限量/从众：「还剩最后 3 件」「XX 人已下单」） |
| 行为经济学映射 | 限时限量 → **稀缺效应 + 损失厌恶**；从众数字 → **羊群效应**；「家人/宝宝称呼」→ **心理契约**；憋单（延迟上架）→ **预期后悔** |

## 板块 3 · 信用消费真实机制（IRR 换算 / 校园贷 / 套路贷 / 法律底线）

> **设计底稿**：以下机制是把「信用消费」做进桌游时**必须正确建模**的金融事实，数值口径以中国现行法规与通行产品规则为准，供《规则与经济系统》§5 / §8 直接引用。

### 3.1 信用卡分期真实利率（IRR 换算）

**核心事实**：信用卡分期标注的「月手续费率」**不是**真实年化利率。

| 表面利率 | 名义年化（单利） | **实际年化（IRR）** | 说明 |
|---------|----------------|-------------------|------|
| 月手续费 0.5% | 6% | **≈ 11%** | 1 万元分 12 期，总手续费 600 元，平均资金占用 ≈ 5,417 元 |
| 月手续费 0.6% | 7.2% | **≈ 13%** | 1.2 万元分 12 期，月还 1,072 元，总手续费 864 元，平均占用 ≈ 6,500 元 |
| 月手续费 0.75% | 9% | **≈ 16%** | 常见「优惠费率」档 |
| 日息万五（0.05%） | 18.25% | **≈ 18%–19%** | 花呗/借呗常见档位 |
| 花呗万四（0.04%）每天 | 14.6% | **≈ 14.6%** | 等额本息下接近名义 |

**IRR 计算原理**：手续费按**全额本金**收取，而非按**剩余未还本金**——这是真实利率远高于名义利率的根本原因。每月还款后本金递减，但手续费始终按初始本金计算，导致**平均资金占用仅约本金的一半**。

**监管要求**：**中国人民银行 2021 年第 3 号公告**明确要求，所有贷款产品均须以明显方式展示**实际年化利率（APR/IRR）**，不得仅展示日利率、月利率或手续费率。

#### 3.1.1 手工 IRR 计算示例（供规则书附录直接使用）

以「借款 12,000 元，分 12 期，月手续费 0.6%」为例：

| 期数 | 期初剩余本金 | 月手续费（按全额 12,000 计） | 月还本金 | 月还款总额 |
|------|-----------|--------------------------|---------|----------|
| 1 | 12,000 | 72 | 1,000 | 1,072 |
| 2 | 11,000 | 72 | 1,000 | 1,072 |
| 3 | 10,000 | 72 | 1,000 | 1,072 |
| … | … | 72 | 1,000 | 1,072 |
| 12 | 1,000 | 72 | 1,000 | 1,072 |

- 总还款 = 1,072 × 12 = **12,864 元**
- 总手续费 = 72 × 12 = **864 元**
- 名义年化 = 0.6% × 12 = **7.2%**（看似很低）

**但玩家的真实资金占用**：第 1 个月占用 12,000，第 2 个月 11,000……第 12 个月 1,000。平均占用 ≈ (12,000+1,000)/2 = **6,500 元**。

- 简化实际利率 ≈ 864 ÷ 6,500 ≈ **13.3%**
- 精确 IRR（现金流折现）：-12,000 + Σ(1,072/(1+r)^t) = 0，解得月利率 r ≈ **1.089%**，年化 (1+1.089%)^12 - 1 ≈ **13.87%**

> **结论**：月手续费 0.6% 的**真实年化约 13%–14%**，是名义 7.2% 的**近两倍**。这正是监管要求明示 IRR、消费者必须理解的财商核心课。

**IRR 近似速算法（供游戏内快速估算）**：
- 近似公式：实际年化 ≈ 月手续费率 × 期数 × 2 / (期数 + 1) × 12 / 期数 = 月手续费率 × **24 / (期数+1)**
- 12 期：乘数 = 24/13 ≈ **1.85** → 0.6% × 12 × 1.85 ≈ **13.3%** ✓
- 6 期：乘数 = 24/7 ≈ **3.43** → 0.6% × 6 × 3.43 ≈ **12.3%**
- 3 期：乘数 = 24/4 = **6** → 0.6% × 3 × 6 ≈ **10.8%**（期数越短，名义与实际差距越小）
- 36 期：乘数 = 24/37 ≈ **0.65** → 0.6% × 36 × 0.65 ≈ **14.0%**（期数越长，乘数趋近于名义，但绝对利息总额更大）

> **借鉴落点**：《财商流游戏》「信用消费」规则应**强制显示 IRR**：玩家选择分期时，UI 同时展示「月手续费 X 元」与「**实际年化 IRR ≈ Y%**」，并在规则书附录中直接引用上表。设计「认知检定」——玩家若能正确估算 IRR 即可获「财商 +1」奖励，错误则接受「利率幻觉 debuff」（下回合所有利率显示延迟 1 回合）。

### 3.2 校园贷 / 套路贷 / 砍头息（真实案例与法律底线）

| 概念 | 定义 | 真实世界典型手法 | 法律底线 |
|------|------|----------------|---------|
| **砍头息** | 放款时预先扣除利息，按**名义本金**计息 | 借 10,000 元，先扣 2,000 元「手续费」，实收 8,000 元，借条写 10,000 元 | 《民法典》第 670 条：利息不得预先扣除；预先扣除的，按**实际借款数额**返还并计算利息 |
| **套路贷** | 以非法占有为目的，**虚增借贷金额、恶意制造违约、肆意认定违约、毁匿还款证据**的违法犯罪活动 | 故意制造银行流水痕迹 + 口头约定虚高金额 + 软暴力催收（电话骚扰、威胁家人） | 2019 年两高一部《关于办理「套路贷」刑事案件若干问题的意见》：以诈骗罪定罪；组织化团伙可认定黑社会性质组织 |
| **校园贷** | 面向在校大学生的**高息 / 超短期**网络借贷，常与套路贷交织 | 「培训贷」「美容贷」「租机贷」等变形；利用学生「不敢告诉家长」心理逼其「以贷养贷」 | 2017 年原银监会等《关于进一步加强校园贷规范管理工作的通知》：**禁止网贷机构向大学生发放贷款**；银行须经监管部门批准方可入校园 |
| **司法保护利率上限** | 超过部分法院不予保护 | — | 2020 年最高法司法解释：**约 4 倍 LPR**（当前 1 年期 LPR 约 3.45%，4 倍 ≈ **13.8%**）；超过部分不受司法保护 |

> **借鉴落点**：可设计《财商流游戏》的**「黑贷事件卡」**——玩家遭遇紧急资金需求时，可选择「正规银行贷款（利率 4%–8%，审批 1–2 回合）」或「黑贷（即时到账，但触发砍头息 / 套路贷判定：若认知检定失败，实际利率按 IRR 折算后可能超过 13.8% 司法保护线，且后续触发催收事件——信用评分骤降、精力 -N、社交关系受损）」。这正是「信用消费」教育的核心张力。

### 3.3 征信修复骗局（国家发改委专项治理）

| 项 | 内容 |
|----|------|
| 骗局手法 | 声称「花钱可删除征信不良记录」，收费后失联或提供虚假「征信异议」材料 |
| 官方定性 | **中国人民银行征信中心**多次声明：**「征信修复」均为骗局**，征信记录无法由第三方删除；仅信息主体对错误/遗漏信息可向征信机构**免费提出异议** |
| 治理行动 | **国家发改委**牵头「征信修复」乱象专项治理（2022 年「百日行动」），将「征信修复」类机构纳入失信名单；**信用中国**网站公示违规机构 |
| 消费者易骗点 | 对征信系统运作机制无知；急于消除不良记录（如房贷被拒）；轻信「内部关系」话术 |

> **借鉴落点**：可设计**「征信修复骗局事件卡」**——玩家信用评分下降时，收到「花钱修复征信」诱惑；若接受，损失现金且**信用评分不恢复**（甚至因「试图造假」再扣分）；若拒绝并走正规异议流程（消耗 1–2 回合 + 精力），可恢复真实错误记录。

## 板块 4 · 行为经济学消费侧机制（心理账户 / 支付疼痛 / 订阅制陷阱）

### 4.1 心理账户（Mental Accounting，Thaler 1985 / 1999）

| 项 | 内容 |
|----|------|
| 核心概念 | 人们会在心理上把钱分入不同「账户」（生活费 / 享乐 / 意外之财），**不同账户的消费倾向不同**——「意外之财」账户的消费倾向远高于「工资」账户 |
| 经典实验 | Thaler：意外获得 30 美元奖金 vs. 工资增加 30 美元，前者被用于享乐消费的概率显著更高 |
| 中国化表现 | 年终奖「花起来不心疼」、拆迁款「来得快去得快」、红包「电子红包比现金更易花掉」 |
| 游戏化映射 | 本作心魔卡 **XM-05/06（心理账户）** 已建模：获得意外收入时资金被标记来源标签，「意外之财」在下回合 Doodad 消费概率 +30%、单笔消费上限放宽 50% |

> **借鉴落点**：心理账户已在本作心魔卡中建模（见《行为金融与投资心理机制设计》§1 总表），本文件**不重复**其机制，仅补充**消费侧新场景**：
> - **「工资 vs. 年终奖」双账户**：月结时工资入「常规账户」（消费倾向正常），年终奖入「意外账户」（消费倾向 +30%），玩家可主动「转账」但需消耗 1 精力（自我控制成本）。
> - **「电子红包 / 直播打赏」**：社交收入入「社交账户」，打赏/红包支出从此账户扣，账户余额归零前玩家**感知不到损失**——模拟「电子钱包无痛消费」。

### 4.2 支付疼痛（Pain of Paying，Prelec & Loewenstein 1998）

| 项 | 内容 |
|----|------|
| 核心概念 | 消费时存在「支付疼痛」——**支付方式越透明、越物理，疼痛越强，消费越克制**；越抽象、越延迟，疼痛越弱，消费越冲动 |
| 支付方式疼痛梯度（强→弱） | **现金** > 借记卡 > 信用卡 > 扫码支付（微信/支付宝）> 花呗/白条（先享后付）> 自动续费（无感扣款） |
| 中国研究 | 多篇中文论文（中国知网）研究「心理账户视角下数字支付对我国家庭消费的影响机制」；媒体报道「扫码支付是无痛陷阱」「诺贝尔经济学奖得主理查德·塞勒的心理账户理论早就说过，现金支付时的痛感会让人理性消费，而扫码支付剥脱了这种痛感」 |
| 游戏化映射 | 本作可引入**「支付方式」维度**：同一笔消费，选现金支付则**精力 -1（痛感成本）但消费金额可打折（商家偏好现金）**；选扫码/花呗则**无即时痛感但按 IRR 计息** |

> **借鉴落点**：在「消费陷阱事件卡」中引入**支付方式选择**——玩家购买大件时，选「现金/借记」需即时付全款（可能触发流动性危机），选「花呗分期」则当期现金流平滑但**按真实 IRR 多付利息**。这正是「信用消费教育」的核心张力。

### 4.3 订阅制陷阱与自动续费

| 项 | 内容 |
|----|------|
| 核心概念 | 订阅制利用**支付疼痛递减**（首月痛感强，后续自动扣款痛感趋零）+ **现状偏差**（不主动取消就默认续订）+ **沉没成本**（「已经用了 3 个月，取消可惜」） |
| 真实世界数据 | 公开资料显示大量用户存在「僵尸订阅」——连续扣款数月的服务早已停用（具体比例待核验） |
| 法律规制 | **《消费者权益保护法实施条例》2024 年 7 月 1 日施行**：经营者须在自动续费前以**「显著方式」**提醒消费者；不得默认勾选或强制开通自动续费（法条原文待核验，指向条例相关条款） |
| 游戏化映射 | 本作可设计**「订阅卡」**——玩家购买订阅服务（如「健身会员」「流媒体」「知识付费」），每回合自动扣小额费用；**取消需主动操作 + 消耗 1 精力**（模拟「取消摩擦」）；若连续 3 回合未使用仍不取消，触发「僵尸订阅」事件——累计扣款 × 1.5 倍返还惩罚 |

> **借鉴落点**：「订阅卡 + 取消摩擦 + 僵尸订阅事件」可直接作为**消费陷阱事件卡**的子类型，与心魔卡 XM-15/16（沉没成本）联动——「已经付了 3 个月，取消可惜」正是沉没成本谬误的典型话术。

### 4.4 锚定效应与凑单满减（Anchoring / Threshold Discount）

| 项 | 内容 |
|----|------|
| 核心概念 | **锚定效应**（Tversky & Kahneman 1974）：人们把最先接收到的数字作为「锚」做后续判断。**原价标签**就是最经典的锚——「原价 999，现价 199」让玩家以 999 为锚，觉得 199 超值，**忽略商品真实价值可能只有 150** |
| 凑单满减机制 | 「满 300 减 50」——玩家购物车 260 元，为了「省 50」凑到 300，**多花 40 却觉得自己省了 50**（净亏 10 元）。CSDN 行为经济学分析指出「框架效应使决策偏差率超 60%」 |
| 真实世界数据 | 中国消费者协会历年「双十一」价格监测均发现相当比例商品存在「先涨后降」（具体比例按年度待核验）；「划线价」与「实际成交价」差距是监管重点 |
| 法律规制 | 《价格法》第 14 条第 4 项：**「利用虚假的或者使人误解的价格手段，诱骗消费者或者其他经营者与其进行交易」**构成价格欺诈；2022 年《明码标价和禁止价格欺诈规定》进一步细化「原价」定义（指**促销前 7 日内**在本交易场所成交的有交易票据的**最低成交价**） |
| 游戏化映射 | 本作「市场」阶段引入**价格锚定**：商品卡同时显示「划线价（灰色删除）」与「实际单价」；玩家购买时若以划线价为锚做决策，触发锚定效应 XM-03/04 检定；**凑单满减**作为「促销事件」出现，玩家需判断「凑单后的真实单价 vs. 不凑单的真实单价」 |

> **借鉴落点**：在「比价 mini-game」中，给出同一商品 3 个 SKU（单件 50 / 3 件 120 / 5 件 175），玩家选「最划算」——正确答案是 5 件装（单价 35），但多数玩家会选 3 件装（单价 40，因为「3 件比 1 件便宜很多」的锚定错觉）。这正是训练「**按真实单价决策而非按折扣幅度决策**」的核心场景。

### 4.5 冲动消费的心理结构（Impulse Buying）

| 项 | 内容 |
|----|------|
| 核心概念 | 冲动消费 = **「想要」压倒「需要」**的瞬间决策，由三个要素驱动：**情感唤起（兴奋/焦虑）+ 感知稀缺（限时/限量）+ 自我控制资源耗尽（决策疲劳）** |
| 中国研究 | 中国知网「电商直播情境下主播营销话术与消费者冲动购买行为」（2025）基于**有调节的中介模型**，从理性诉求/情感诉求出发，发现**关系型心理契约**（主播「家人」称呼）显著增强冲动购买 |
| 游戏化映射 | 本作可引入**「自我控制资源条」**（与「精力」维度联动）：每回合做 N 次消费决策后，自我控制资源下降，后续消费决策的**认知检定难度 +1**——模拟「决策疲劳」；「限时促销」事件在玩家自我控制资源低时触发，成功率更高 |

> **借鉴落点**：「自我控制资源条」是连接「消费决策」与本作「精力」维度的桥梁——玩家在一天内（多回合）连续消费后，越到后面越容易冲动，这正是真实消费场景的写照。

| **「限时促销」** | 进入消费圈 / 市场繁荣期 | 给出 3 个「优惠方案」（满减/直降/返券），玩家 30 秒内选择；按真实折后单价判定是否「划算」 | 框架效应 XM-17/18 + 羊群 XM-11/12 |
| **「直播带货」** | 市场繁荣期 / 社交 ≥ 5 | 使用「营销话术卡」（限时/限量/从众），对手可「识破检定」（认知 vs. 话术等级） | 从众 XM-11/12 + 过度自信 XM-09/10 |
| **「订阅续费」** | 每回合结算 | 已购订阅自动扣款；取消需主动操作 + 精力 -1；连续 3 回合未用触发「僵尸订阅」惩罚 | 沉没成本 XM-15/16 |
| **「黑贷诱惑」** | 现金流 < 0 / 紧急事件 | 即时到账 vs. 正规贷款二选一；黑贷触发砍头息 / 套路贷判定 | 双曲贴现（已有）+ 过度自信 |
| **「征信修复骗局」** | 信用评分下降时 | 花钱「修复」→ 现金损失 + 信用不恢复；正规异议流程 → 消耗回合但可恢复真实错误 | 确认偏误 XM-13/14 |

### 5.2 营销话术卡 vs. 心魔卡的联动（接入《行为金融与投资心理机制设计》§1 总表）

| 营销话术卡 | 话术内容示例 | 触发的心魔卡 | 识破反制 |
|-----------|------------|------------|---------|
| **「最后 3 件！」** | 制造稀缺 | 损失厌恶 XM-01/02 + 羊群 XM-11/12 | 认知检定通过 → 话术无效，对手精力 -1 |
| **「万人已抢」** | 从众数字 | 羊群 XM-11/12 | 查看真实销量（消耗 1 精力）→ 若造假则对手信用 -1 |
| **「原价 999，今天 199」** | 价格锚定 | 锚定效应 XM-03/04 | 查历史价格（消耗 1 精力）→ 识破「先涨后降」则返还差价 |
| **「家人们冲！」** | 心理契约 | 框架效应 XM-17/18 | 认知检定 → 识别「情感诉求」则免疫 |
| **「0 利息分期」** | 利率幻觉 | 双曲贴现（已有） | 系统强制显示 IRR → 玩家仍可接受但**认知 +1 教育点** |

### 5.3 信用消费规则（接入《规则与经济系统》§8 杠杆与债务系统）

| 规则项 | 建议 |
|-------|------|
| **IRR 强制显示** | 玩家选择分期时，UI 同时展示「月手续费 X 元 / **实际年化 IRR ≈ Y%**」；规则书附录 IRR 速算表（0.5%→≈11%、0.6%→≈13%、0.75%→≈16%） |
| **支付方式维度** | 消费时可选「现金/借记（即时全款，可能流动性危机）」「信用卡分期（IRR 计息）」「花呗/白条（IRR + 信用评分影响）」 |
| **信用评分联动** | 分期金额 / 频率影响信用评分：适度分期且按时还款 → 信用 +；过度分期 / 最低还款 → 信用 -；触发《社交资本与信用体系设计》§6 利率梯度 |
| **司法保护线** | 玩家间借贷利率超过 **4 倍 LPR（≈13.8%）** 的部分不受「法院」保护——可设计「高利贷判定」事件，超限利息自动减免但触发信用惩罚 |

### 5.4 反诈 mini-game（信息甄别，独立于主循环的插入式玩法）

| 项 | 建议 |
|----|------|
| 触发方式 | 进入特定棋盘格 / 每 N 回合强制触发 / 玩家主动参加「反诈挑战」房间 |
| 玩法 | 给出 5–8 条「信息」（短信/电话/链接/投资方案），玩家在 60 秒内标记「真/假/不确定」；每条信息对应公安部十大高发类型之一 |
| 计分 | 正确 +，错误 -，漏判（真诈骗标「真」）双倍 -；总分折算为**现金奖励 / 信用评分奖励 / 认知经验** |
| 难度分级 | 初级（明显诈骗，如「中奖先交税」）→ 中级（半真半假，如「银行升级需点链接」）→ 高级（AI 换脸 / 深度伪造话术） |
| 与心魔卡联动 | 玩家在 mini-game 中「被骗」→ 触发对应心魔卡（如刷单类 → 羊群 XM-11/12；冒充公检法 → 损失厌恶 XM-01/02）；连续 3 次正确识破 → 获得「反诈达人」buff（后续消费陷阱事件卡自动 +2 认知检定） |
| 多人模式 | 6 人一桌（借鉴《收网》形态），各自独立作答 + 可「求助队友」（消耗社交资本），最高分获额外奖励 |

### 5.5 消费预算与支出纪律（接入《规则与经济系统》§5 支出系统）

| 项 | 建议 |
|----|------|
| **支出比例警戒线** | 参照中国居民消费支出结构（食品烟酒约 28%–30%、居住约 24%、交通通信约 13%，数据待核验），玩家某类支出连续 2 回合超过参考比例 1.5 倍 → 触发「消费失衡」事件（精力 -1 / 认知检定） |
| **冲动消费冷却期** | 单笔消费超过月现金流 50% 时，强制进入「冷静期」——下回合才能完成支付，期间可取消（模拟「24 小时冷静期」消费者保护理念） |
| **「想要 vs. 需要」标签** | 消费陷阱事件卡中的商品分「需要（生活必需）/ 想要（享乐）」；购买「想要」类时触发心理账户 XM-05/06 检定——检定通过则正常消费，失败则「意外之财」账户被扣仍不觉痛 |

### 5.6 反诈知识教育与 Agent 教练融合（接入 Agent 教练系统）

| 项 | 建议 |
|----|------|
| **实时干预** | 当玩家连续触发 2 张以上「消费陷阱」且均失败时，Agent 教练弹出**苏格拉底式提问**：「你刚才连续两次在促销时冲动消费，你觉得是什么让你觉得『现在必须买』？」——不直接给答案，引导玩家自我觉察 |
| **阶段复盘** | 每 12 回合（年度结算）时，Agent 教练生成**「消费决策报告」**：冲动消费次数、总损失金额、对应触发的心魔卡、与上一年度对比——把消费行为变成**可量化的进步指标** |
| **个性化难度** | 基于《玩家职业设计》的玩家画像 P01–P18 的决策倾向（保守型 / 激进型 / 焦虑型 / 理性型 / 从众型），Agent 教练调整消费陷阱事件卡的**触发频率**和**强度**——激进型玩家多触发「高回报投资骗局」，焦虑型多触发「冒充公检法」，从众型多触发「直播从众话术」 |
| **反诈知识库** | 把公安部十大高发类型做成 Agent 教练的**知识卡片**——玩家可随时调阅，mini-game 复盘时自动关联对应知识点 |

### 5.7 对《玩家职业设计》职业卡的消费适配（接入职业卡 v1.4）

| 职业画像 | 消费倾向设计 | 典型消费陷阱 |
|---------|------------|------------|
| **新业态从业者**（外卖骑手/网约车/自由职业者，P03/P14） | 收入波动大 → 现金流不稳 → 更依赖信用消费 | 「黑贷诱惑」「发薪日贷款」类事件高频 |
| **新业态管理者**（互联网中层，P04/P16） | 收入高但时间少 → 愿意为「省时」付费 → 订阅制消费多 | 「订阅续费陷阱」「冲动购买大件」 |
| **全职家庭主妇/主夫**（P12） | 家庭消费决策者 → 日用品/教育支出占比高 | 「双十一凑单」「教育焦虑消费」 |
| **个体经营者**（P02） | 经营与个人消费混同 → 心理账户边界模糊 | 「经营贷挪用个人消费」「个人担保经营负债」 |

## 板块 6 · 行为经济学消费侧经典研究速查（设计底稿）

> 以下研究结论可直接转化为游戏机制或 Agent 教练话术，**非**心魔卡重复（心魔卡详见《行为金融与投资心理机制设计》§1 总表），而是消费侧的**补充研究**。

| 研究 | 年份 | 核心结论 | 游戏化映射 |
|------|------|---------|----------|
| **Thaler, Mental Accounting** | 1985 / 1999 | 人们分心理账户，意外之财消费倾向 > 工资；不愿「亏本卖出」——宁可持有贬值资产也不愿实现损失 | 心理账户 XM-05/06 + 处置效应 XM-07/08；意外收入标记标签 |
| **Prelec & Loewenstein, Pain of Paying** | 1998 | 支付疼痛：现金 > 借记卡 > 信用卡 > 扫码 > 先享后付 > 自动续费；疼痛越弱，消费越冲动 | 支付方式维度（见 5.3） |
| **Tversky & Kahneman, Anchoring** | 1974 | 任意数字都能成为锚；**原价标签**是最经典的消费锚 | 锚定效应 XM-03/04；比价 mini-game |
| **Kahneman & Tversky, Prospect Theory** | 1979 | 损失厌恶：损失 100 的痛苦 ≈ 获得 200–250 的快乐；**确定效应**（偏好确定的小收益）；**反射效应**（面对损失偏好冒险） | 损失厌恶 XM-01/02；框架效应 XM-17/18 |
| **Shiller, Irrational Exuberance / Narrative Economics** | 2000 / 2019 | 消费/投资决策受「流行叙事」驱动——「双十一购物节」「直播爆款」本身就是叙事 | 市场周期中的「叙事繁荣期」→ 消费陷阱事件卡密集 |
| **Laibson, Golden Eggs and Hyperbolic Discounting** | 1997 | **双曲贴现**：人们偏好「现在立刻得到小奖励」而非「未来得到大奖励」——这是冲动消费与信用消费的时间根源 | 双曲贴现（已有心魔卡）；「现在买 vs. 下月买」决策 |
| **Ariely & Kreisler, Dollars and Sense** | 2017 | **「免费」是最危险的词**——人们为了「满 99 免邮」「买一送一」会买原本不需要的东西；**社会规范 vs. 市场规范**混淆（「亲，帮我砍一刀」） | 「凑单满减」事件卡；社交消费（砍一刀/拼团） |
| **Sunmola et al., Mobile Money & Consumption (中国)** | 2023–2025 | 多篇中国研究证实：移动支付显著**增加**消费支出、**降低**储蓄意愿；数字红包比现金红包更易花出 | 支付方式维度 + 心理账户联动 |
