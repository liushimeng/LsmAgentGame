## 1. Stockpile：内幕信息与盲拍股票堆

### 1.1 基本信息与定位

| 项目 | 内容 |
|------|------|
| 原名 | Stockpile: An Investor's Game of Insider Trading |
| 设计师 | Brett Sobol / Seth Van Orden |
| 人数 / 时长 | 3–5 人 / 约 45 分钟 |
| 核心标签 | 股票市场 / **不对称信息** / 盲拍 / 市场操纵 |
| 一句话定位 | "快节奏的企业投资、**内幕交易**与市场操纵经济游戏"，玩家扮演私募投资者追求最高净值 |

### 1.2 组件

回合标记 ×1、股票行情轨（Stock Ticker）×6、公司卡 ×6、预测卡（Forecast）×6、
货币卡 ×100（面额 $1K/$5K，开局每人 $20,000 = 三张 $5K + 五张 $1K）、玩家板 ×5、
出价米宝 ×7、首发玩家标记 ×1、股票卡 ×60、**交易费卡** ×12、行动卡 ×8。

六只股票各有行情轨，价格从起始值（深色圆点，多为 5）在 1–10 区间移动，
**超过 10 触发拆股、低于 1 触发破产**。

### 1.3 回合结构：六阶段（本作最值得抄的骨架）

每局回合数随人数固定（记在版图日历上，Turn Marker 倒数），每回合六阶段：

| # | 阶段 | 内容 |
|---|------|------|
| 1 | **Information 信息阶段** | 每人暗领 1 公司卡 + 1 预测卡（配对 = 该股票本回合末的涨跌方向与幅度，±1 至 ±4 或分红）；另翻 **1 组公开**放在版图上；剩余组数暗置版图旁（3 人局 2 组、4 人局 1 组、5 人局 0 组） |
| 2 | **Supply 供给阶段** | 翻 1 张市场牌作每个「股票堆」的底，堆数 = 玩家数；每人领 2 张市场牌（股票/交易费/行动卡），轮流向任意堆各放 **1 张明 + 1 张暗**（可同堆可异堆） |
| 3 | **Demand 需求阶段** | 轮流把出价米宝放到某堆的出价轨数字上（必须比已有出价高；出价上限受现金约束，现金公开）；被超过者收回米宝等所有人首次出价后重出；每轨直到恰好 1 个米宝；锁轨后上限 $25,000；**可以 $0 拿堆** |
| 4 | **Action 行动阶段** | 轮流打掉本回合刚拿到的行动卡：Stock Boom!（自选一只 +2）/ Stock Bust!（自选一只 −2），可能直接触发拆股或破产 |
| 5 | **Selling 卖出阶段** | 轮流任意量卖出：按当前行情价向银行结算；拆股组合（Split Portfolio）里的股票卖出 **2 倍价** |
| 6 | **Movement 移动阶段** | 玩家依次亮出自己手里的公司+预测组合并执行，再执行公开组与暗置组——**所有股票每回合必动** |

### 1.4 四个关键市场机制

**(1) 不对称信息的三层结构**：每人只完整知道「自己那组」的方向，但供给阶段的
明牌与别人往堆里塞的暗牌，构成部分可推断的公共信息池。玩家在**价格移动之前**
就要完成买入（Demand）与卖出（Selling）决策——这正是现实中"预期抢跑"的结构化呈现。

**(2) 拆股（Stock Split）**：价格 > 10 即拆股——持仓者把该股票全部亮出移入
Split Portfolio，**份额翻倍**；若移动恰好落在拆股格，价格回 6 后继续走完剩余涨幅；
拆股后新买的股票进普通仓；已经拆过再拆时，改为每张 Split 仓股票直接补 $10,000 现金。

**(3) 破产（Bankruptcy）**：价格 < 1 立即破产——所有人（含 Split 仓）该股清零弃掉，
价格**回到起始值 5**。配合 ±4 预测卡与 Stock Bust 行动卡，"临近破产的低价股"
是典型的高赔率投机标的——与"低价股幻觉"行为偏差高度同构。

**(4) 分红（Forecast "$$"）**：价格不动，**每股立即派 $2,000**（Split 仓 ×2）。
领取分红必须亮出相应持仓——**可以选择部分不领以隐藏持仓量**（信息隐匿是
真实博弈的一部分）。

### 1.5 交易费卡：藏在堆里的负资产

供给阶段玩家可以把 **交易费卡**（面额 $1K/$2K/$3K）塞进任意股票堆。拿堆者
必须立即付银行该面额；**付不起则亮明保留、下次卖出后必须付**。
这是"资产包里埋雷"的微缩模型：盲拍定价时必须为堆内不可见的交易费留出折扣。

### 1.6 扩展《Corruption》与投资者能力

基础版之外：投资者能力卡（Investor Abilities）给每人一个不对称的专属能力
（如特定公司交易免手续费等）；《Corruption》扩展加入贿赂/做市/内幕升级等更灰色的
机制。两者都强化"规则套利"体验。

### 1.7 策略层与教学价值

- **信息 → 定价 → 执行的完整链条**：知道 ≠ 做到，出价轨上的竞争会把
  已知信息的超额收益压缩到零（信息被 price-in 的直观体验）。
- **流动性管理**：现金全押出去会丧失后续轮出价权；持仓不动则错过 Boom/Bust 窗口。
- 与本作《交易拍卖与企业经营设计》§6 股票价格发现机制直接互补（见 §7）。

## 2. High Society：Knizia 拍卖三部曲的最后一块拼图

> 既有《拍卖议价类桌游深度资料》已覆盖 Ra / For Sale / Medici / Amun-Re，
> 但 Knizia「金钱拍卖三部曲」中的 **High Society** 此前零覆盖，本节补全。

### 2.1 基本信息与定位

| 项目 | 内容 |
|------|------|
| 设计师 | Reiner Knizia |
| 人数 / 时长 | 3–5 人 / 15–30 分钟 |
| 核心标签 | 纯拍卖 / **出价不可撤回** / 声望乘数 / 破产惩罚 |
| 一句话定位 | 用隐藏的金钱卡竞拍炫耀性奢侈品，终局**剩钱最少者直接出局** |

### 2.2 组件与终局结构

- **金钱卡**：每人一套固定面额（如 1/2/3/4/6/8/10/12/15），用一少一张，对手可推断余量。
- **声望牌堆**（Status deck）：奢侈品（Luxury，1–10 分）、声望卡（Prestige ×3，
  终局翻倍）、丑闻卡（Disgrace）、以及 4 张**深绿底**计数牌（3 张 Prestige + 1 张
  Scandale）——**第 4 张深绿牌翻出的瞬间游戏立即结束**，连竞拍都不发生。
  终局时点因此不可精确预测，终局竞价需要为"随时戛然而止"留余量。

### 2.3 出价规则（核心张力）

1. 翻开一张声望牌，起始玩家**出价或弃权**；
2. 出价 = 把金钱卡面朝上打出并报总额；**已打出的卡不能再收回**，只能加码（追加新卡）；
3. 弃权：若本轮已出过价，则**收回自己桌上的金钱卡**回手牌（注意：弃权不损失已出
   的钱，这是与 Ra 太阳代币的关键差异），退出本轮竞价；
4. 全员其余人弃权后，最后留者得牌；**桌上所有人打出的金钱卡全部面朝下弃掉**；
5. 得牌者成为下一轮起始玩家。

可能出现全员弃权 → 最后一人**免费**得牌（罕见但存在）。

### 2.4 丑闻卡：反向拍卖

翻出丑闻卡（Disgrace）时规则反转：**第一个弃权的人必须收下丑闻卡**，其余人
打出的金钱卡照常弃掉。三类丑闻：

| 卡 | 效果 |
|----|------|
| Faux Pas | 立即弃掉自己 1 张奢侈品（没有则记欠账，下次获得时弃） |
| Passe | 终局声望 −5 |
| Scandale | **终局声望减半**（且它是第 4 张深绿计数牌之一） |

"抢着弃权把雷丢给下家"的机制把轮抽式的厌恶损失变成了公开博弈。

### 2.5 终局：Cast Out（最少现金者出局）

第 4 张深绿牌翻出后，所有人亮出**手牌剩余现金总额，最少者（可并列）直接失去
获胜资格**。然后计分：奢侈品求和 → Passe −5 → 每张 Prestige 声望 ×2（两张 ×4，
三张 ×8，乘法叠加）→ Scandale 减半。平局比剩余现金，再比最大单张奢侈品。

### 2.6 教学价值

- **"花钱买资产"与"留钱保命"的两难**：倾囊竞拍 Prestige 乘数的人，往往正是
  被 Cast Out 的人——财富教育里"流动性枯竭"的最快一课。
- 金钱卡面额离散 + 不可撤回，出价即是承诺，逼玩家在"信息不全"时定价。
- 与本作《行为金融与投资心理机制设计》中"稀缺心态 / 炫耀性消费"两条偏差线
  天然同构。

## 3. Lords of Vegas：地产、赌场与控制权斗争

> 既有调研覆盖了 Monopoly（地产）与 Acquire（并购），但没有一款同时模拟
> **地块开发 + 物业经营 + 控制权政变 + 内生赌局**的地产游戏。Lords of Vegas 补此缺。

### 3.1 基本信息与定位

| 项目 | 内容 |
|------|------|
| 设计师 | Mike Selinker / James Ernest |
| 人数 / 时长 | 2–4 人 / 60–90 分钟 |
| 核心标签 | 地产开发 / 骰子影响力 / **控制权斗争** / 赌博内循环 |
| 一句话定位 | 在拉斯维加斯大道旁买地建赌场，做大、兼并、政变，成为分数最高的赌场大亨 |
| 货币口径 | $1 记 $1M（百万美元），开局资金 = 两张地契卡面额之和 |

### 3.2 版图与所有权三层模型

- **Lot 地块**：版图空格，被地产卡指定后放玩家标记 = 私有地（每回合被抽中即付
  持有者 $1 租金）。
- **Casino tile 赌场片**：在自有地块上付费建一片（颜色 5 选 1），并放 1 颗骰子，
  骰面 = 印在地格上的初始值；**同色连续拼成的大赌场不可拆分**。
- **Die 骰子（影响力）**：玩家共 12 颗；某赌场内**最大骰面者 = 该赌场 Boss**
  （老板）。Boss 拿该赌场的**分数**（每片 1 分），所有骰子按骰面拿**钱**
  （每个点 $1）。

地产卡 49 张对应版图 49 格：9 张/色 ×5 色 + 3 张 Pay The Strip；游戏结束卡
垫底插入牌堆第 4 摞顶端，随机化终局。

### 3.3 回合流程（两步）

**Step 1 抽牌**：抽 1 张地产卡 → 接管对应地块（空地放标记；已有片则替换成自己的
骰子保持骰面）→ **所有**持有标记的玩家收 $1/块 → **被抽中颜色的全部赌场**
（全图所有同色）付钱与分：每颗骰子按面收 $1；Boss 每片收 1 分。抽到
Pay The Strip 时改为**所有临街赌场**付款。

**计分道的 break 机制**：分数轨有"跳跃格"（如 8 → 10 → 12），单次付款不足
跨档就卡在前一格并**作废溢出**；同一回合多赌场分数必须**从小到大逐个入账**。
高分区越走越贵——通胀式的分数边际递减。

**Step 2 行动**（可任意次序、除 Gamble 外可重复，且**任何时候可与任意玩家交易**）：

| 动作 | 规则要点 | 现实隐喻 |
|------|---------|---------|
| **Build 建** | 自有地块上付费（地格标价）建 1 片 + 放骰（骰面 = 地格印值） | 一级市场拿地开发 |
| **Sprawl 扩建** | 仅 Boss 可为：付 **2×** 地价，向**相邻无主空地**铺同色片 + 放骰 | 并购相邻地块做大 |
| **Remodel 改造** | 仅 Boss 可为：付 $5/片，整赌场**换颜色**（可与别家赌场连成一体→触发 Boss 重判定） | 资产重组/敌意收购 |
| **Reorganize 改组** | 只要场内有骰即可发起：付 **场内所有骰点合计 ×$1**，**全部骰重掷**（每骰每回合至多 1 次） | 董事会政变 |
| **Gamble 赌** | 每回合至多 1 次：去**别人是 Boss** 的赌场下注 ≤$5/片；掷 2 骰：3/4/9/10/11 赢（Boss 赔）；2/12 赢 **2 倍**；5/6/7/8 输（赔 Boss）。Boss 可在下注后**把一半风险"lay off"转给银行** | 场内资金内循环 + 保险对冲 |

**政变触发器**：任一行动后检查各赌场最大骰面平局 → 平局的骰**免费立即重掷**直到
分出唯一最大值；第三方可能渔翁得利。"Remodel 接入 + 平局重掷"是标准夺权连招。

### 3.4 设计精髓

1. **所有权（地块）≠ 控制权（Boss）≠ 收益权（按骰面分钱）三权分离**——
   这是对公司治理"股权/控制权/现金流权"结构最干净的桌游化。
2. Reorg 的成本 = 场内总骰点 ×$1：**政变成本与对手实力正相关**，且结果随机
   （可能白花钱），对应现实中"代理权之争"的不确定性。
3. Gamble 的 lay off 选项 = 给 Boss 的对冲工具（5.6% 赌场优势下，庄家也可以
   买保险），把"风险转移定价"做成玩家可选动作。
4. 同色连续不可拆 + 颜色稀缺（每种仅 9 片）→ **卡位战略**：用光某颜色即封死
   别人的 Sprawl/Remodel 路线。

## 4. 三款游戏机制对比与拍卖分类学补全

| 维度 | Stockpile | High Society | Lords of Vegas |
|------|-----------|--------------|----------------|
| 拍卖形态 | 多轨明标轮流出价（R1 多物品英式变体） | 单件轮流加价、**不可撤回** | 无拍卖（直接向银行付费 + 玩家自由议价交易） |
| 信息结构 | **人人握有不同内幕**（信息不对称是核心） | 完全信息（金钱卡用量公开可推） | 公开 + 骰运（政变/赌局随机） |
| 价格发现 | 出价轨竞争 price-in 内幕 | 手牌面额离散约束下的喊价 | 无市场，成本由版图固定 |
| 破产/惩罚 | 个股破产清零 | **终局现金最少者出局** | 无个人破产，但骰政变可夺走一切 |
| 现实映射 | 二级市场 + 内幕交易 + 交易费 | 流动性管理 + 炫耀消费 | 地产开发 + 公司控制权市场 |

**拍卖分类学补全**（衔接《拍卖议价与股票市场类桌游资料》拍卖分类学节）：
High Society 补上「**封闭手牌、累进承诺**」这一格——玩家用手牌组合出价且不可
撤回，等价于"预算硬约束下的英式拍卖"；Stockpile 的多轨锁价则是
「**同时多物品、序贯占位**」形态，与 Chinatown 的自由议价、Modern Art 的
五种委托拍卖构成完整光谱。

## 5. 18xx 家族机制综述

> **来源标注**：本节基于 1830（已有专档）公开规则与 18xx 家族通识整理，
> **未逐条联网核验**；数值细节以各作品规则书为准。1830 细节请回看
> 《拍卖议价与股票市场类桌游资料》§2，本节只补"家族全景 + 与 1830 的差异点"。

18xx 是以 **1830: Railways & Robber Barons**（Francis Tresham, 1986）为鼻祖的
铁路股票游戏家族，核心公式 = **股票轮（公司所有权与融资）× 运营轮（铁路建设
与分红决策）× 半强制性的公司交叉持股**。

### 5.1 家族公共骨架

1. **私营公司拍卖**：开局拍卖历史上真实存在的小铁路/桥/隧道（1830 的
   Schuylkill Valley 等），作为玩家启动资本与特殊能力来源；
2. **股票轮**：可开新公司（par 定价）或买卖存量股；**优先股认购权/公司资产
   由股东投入**——公司现金来自 IPO 与后续增发，玩家用现金换股权；
3. **运营轮**：每家公司按董事长（持股最多且 ≥20%/25% 者）意志铺轨、买车、
   跑线，收入**二选一**：分红（股价上移）/ 留存（股价下移）——**分红政策
   直接操纵股价**是家族的灵魂机制；
4. **列车折旧**：列车等级递进（2/3/4/5/6/D），新等级出现使旧车强制报废，
   逼公司周期性资本开支——技术淘汰周期的隐喻；
5. **银行破产与终局**：银行资金耗尽或某玩家破产即终局，按净资产（现金 +
   股票市值，常以 2×/1.5× 市价计）定胜负。

### 5.2 代表作与 1830 的差异点

| 作品 | 与 1830 的关键差异 |
|------|-------------------|
| **1846: The Race for the Midwest** | 美国中西部背景；**开局草稿（draft）**选私企+公司券；公司**预资本化**（开局就有钱），节奏更快；无 1830 式剧烈剥削 |
| **18Chesapeake** | 新手向：地图开放、无恶意浓汤（no float razor），私企温和，是家族公认入门作 |
| **1817** | **银行贷款与做空机制**：公司可抵押发债、可**卖空股票**，玩家破产时资产拍卖清算——金融工程浓度最高 |
| **1889/1861/1867 等** | 日本/俄国背景的区域变体；1861+ 引入国家化接管机制 |
| **18OE/18C2C 等大型** | 多板块地图、跨时段公司合并，时长 6–12 小时 |

### 5.3 与本作的关系

本作《交易拍卖与企业经营设计》的企业经营层（§8–§11）已有"企业生命周期 +
并购"，18xx 补充的设计参照是：**分红政策 ↔ 股价** 的直接联动（本作股票层可
借鉴"企业现金流是否分红，影响次轮估值乘数"）与**列车折旧式的强制资本开支**
（本作企业经营层的"设备迭代/合规升级"事件可参数化为其变体）。

## 6. 创业融资与股权稀释：机制设计素材

> 既有 18 份调研中无"创业融资轮次 / 估值谈判 / 股权稀释"主题（此前缺口）。
> 本节把上面三款游戏的控制权机制与现实 VC 术语映射为本作可用的设计素材。
> 现实术语部分基于创业融资通识（可迭代核验），游戏映射部分为原创设计稿。

### 6.1 现实世界的融资轮次与稀释链条

| 轮次 | 典型出让股权 | 投资人关注 | 创始人风险 |
|------|-------------|-----------|-----------|
| 种子/天使 | 10–20% | 团队、赛道 | 估值过低 → 后续被动 |
| A 轮 | 15–25% | 数据验证、单位经济 | 对赌条款、清算优先权 |
| B/C 轮 | 15–20% | 规模化、护城河 | **多轮累计稀释 < 50% 控制线** |
| IPO/并购 | 20–30% | 公开市场定价 | 锁定期、控制权让渡 |

关键概念：**清算优先权**（Liquidation Preference，退出时投资人先拿回本金倍数）、
**对赌/业绩承诺**（VAM）、**期权池**（ESOP，通常再稀释 10–15%）、
**优先清算权叠加后的"表面增值、实际归零"** 结构。

### 6.2 三款游戏给"股权层"的可复用零件

| 零件 | 来自 | 移植方式（本作草稿） |
|------|------|---------------------|
| 最大骰面 = Boss | Lords of Vegas | 企业卡上放"影响力骰"，融资时投资人放骰；**最大者接管经营决策权** |
| Reorg 重掷政变 | Lords of Vegas | "股东会事件"：付现金 = Σ 影响力 × 系数，全员骰重掷 → 控制权随机重排 |
| Remodel 换色合并 | Lords of Vegas | "资产重组"：两家玩家企业合并时触发 Boss 重判定，弱方股权被摊薄 |
| 内幕信息分层 | Stockpile | 创业事件卡：只有"内部董事"玩家提前 1 回合知道下一轮行业行情 |
| 交易费埋雷 | Stockpile | 融资条款里藏"清算优先权 1.5×"卡：估值高但退出时后拿钱 |
| 不可撤回加价 | High Society | 融资竞价轮：TS（term sheet）一旦打出不可收回，多投资人加价挤兑估值 |

### 6.3 教学目标

让玩家在 2 小时内体验三次经典陷阱：
1. **估值幻觉**：高估值 + 强条款 < 低估值 + 干净条款（用清算优先权卡兑现）；
2. **控制权稀释**：三轮 20% 出让后持股 51.2%（0.8³）——决策权已旁落；
3. **对赌反噬**：业绩未达标时按约定回吐股权/现金。
