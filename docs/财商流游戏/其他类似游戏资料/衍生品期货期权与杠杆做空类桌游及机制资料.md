# 衍生品期货期权与杠杆做空类桌游及机制资料

> **版本**：v1.0（2026-09-11）
> **定位**：补全知识库此前偏弱的"**杠杆 / 做空 / 期货 / 期权 / 逼空 / 保证金交易**"机制谱系。
> 既有《拍卖议价与股票市场类桌游资料》《股票市场与房地产创业类桌游补遗》已覆盖**现货股票的价格发现与拍卖**，
> 但对**带杠杆的衍生品交易**（保证金、逐日盯市、强平、做空、看涨/看跌期权、囤积逼空）着墨不足；
> 本文件集中补齐这一维度，并把真实世界衍生品机制映射回《财商流游戏》的设计。
> **计价货币**：人民币（元）。

---

## 板块 0 · 为什么这一维度必须补

真实世界里，财富剧烈分化与爆仓事故，绝大多数不是发生在"现货买卖"层面，而是发生在**杠杆与衍生品**层面：

- **2015 年中国股灾**：场外配资（杠杆 1:3 ~ 1:10）强制平仓形成多杀多。
- **2021 年 GameStop 逼空**：散户抱团做空机构（Melvin Capital），空头被迫高位回补。
- **2024 年日元套息交易平仓**：利差交易（carry trade）一瞬间逆转，全球风险资产同步暴跌。
- **企业/个人案例**：中航油（陈久霖）、国储铜（刘其兵）、宝钢/中信泰富澳元累计期权——都是衍生品而非现货判断错误。

桌游侧，既有资料偏"温和"的现货买卖（Modern Art 的拍卖定价、18xx 的股票轮、Brass 的股价联动）。
要"真实模拟真实世界经济系统"，就必须让玩家**体验到杠杆的放大快感与爆仓的灭顶之灾**，否则财商教育是残缺的。
本文件即为此而作。

## 板块 1 · 关键桌游逐个拆解

### 1.1 Pit（1904）—— 商品交易所的喊价原型

> Pit(1904) 基础规则（出版背景、8–9种商品每种9张、公开喊价流程、经济系统与财商理念）见《拍卖议价类桌游深度资料》§7。本节仅补其"囤积 corner"机制与真实世界逼空（GameStop 2021）的映射。

- **Corner（囤积居奇）**：当某玩家持有某商品全部 9 张时，即完成 corner，可按任意高价卖给其他必须平仓的玩家——这是 19 世纪商品交易所真实存在的操纵手法（如 1980 年 Hunt 兄弟白银囤积、2021 年 GameStop 散户逼空）。
- **逼空（Short Squeeze）映射**：Pit 中被迫以高价买入平仓的玩家 = 真实世界中被轧空的空头；corner 者 = 多头主力。游戏化还原了"流动性枯竭→价格飙升→空头爆仓"的完整链条。
- **对本作的借鉴**：在自由圈股票/大宗商品交易中，可设计"持仓集中度>70%触发逼空事件"机制，价格在 1 回合内飙升 2–3 倍后回落，训练玩家识别操纵与流动性风险。

### 1.2 Wheat（小麦，1929）——大崩盘同年的商品投机游戏

| 项 | 内容 |
|----|------|
| 年代 | 1929 年出版，恰逢美股大崩盘；是最早把"商品投机 + 崩盘"做成桌游的作品之一 |
| 核心 | 玩家交易"小麦"期货合约，价格随事件牌波动；**保证金（margin）机制**是核心 |
| 机制 | 玩家只需付合约面值的一小部分（保证金）即可"买入"一张小麦合约，价格涨则杠杆获利，跌则要求追加保证金（margin call），无法补足则**爆仓出局** |

**教学点**：
- **保证金杠杆**：以小博大，10% 保证金 = 10 倍杠杆；价格反向波动 10% 即本金归零。
- **追加保证金 / 强制平仓**：margin call 是真实衍生品市场最核心的强制规则。
- **周期与情绪**：价格在"乐观—恐慌"间摆动，1929 年出版本身就是历史注脚。

> **借鉴落点**：《财商流游戏》"投资区"的**期货/合约卡**应内置保证金比例与逐日盯市；
> 反向波动达到阈值即触发"追加保证金"事件，下回合必须补现金或被强平清算。

### 1.3 Roaring 20s（咆哮二十年代，1996，Ed Carmichael）——保证金炒股与大萧条

| 项 | 内容 |
|----|------|
| 主题 | 1920 年代美国牛市→1929 崩盘→大萧条 |
| 人数 | 2–6 |
| 核心机制 | 玩家以**保证金（buying on margin）**购买股票；股市长期上涨时杠杆放大收益；一旦"崩盘牌"翻出，股价断崖下跌，保证金不足者**被强制平仓并破产** |
| 特色 | 分"繁荣期"与"萧条期"两阶段；萧条期失业、破产、救济，模拟人生资产负债表的坍塌 |

**教学点**：
- **借钱炒股（margin buying）在牛市是朋友、在崩盘是杀手**。
- **阶段切换**：繁荣期规则（加杠杆、追涨）与萧条期规则（去杠杆、砍仓）截然不同。
- **破产的传染性**：一家强平压低股价，引发下一家 margin call——多杀多。

> **借鉴落点**：与既有《宏观经济与政策模拟》的"阶段切换"呼应，但本游戏把它落到**个人资产负债表的爆仓**。
> 《财商流游戏》市场周期文档已有"繁荣—衰退"，应补"**杠杆仓位在衰退期的强平连锁**"子机制。

### 1.4 The Stock Market Game（SMG，SIFMA Foundation）——组合模拟教育产品

| 项 | 内容 |
|----|------|
| 运营方 | 美国 SIFMA（证券业与金融市场协会）基金会，全球最大的投资教育模拟平台之一 |
| 形态 | 不是实体桌游，而是**虚拟组合竞赛**：每人初始 10 万美元虚拟现金，在约 10 周内买卖真实股票/基金组合 |
| 评分 | 期末组合收益率排名；允许短线、长线、行业轮动；**不允许裸卖空**（教学版简化） |
| 教学 | 强制写交易日志、提交投资理由；配套课程讲复利、分散化、指数基金、风险收益权衡 |

**教学点**：
- **组合视角而非单押**：分散化、资产配置、再平衡。
- **真实行情驱动**：用真实市价，让学生体验"市场不可预测"。
- **行为对照**：交易日志事后复盘，对照自己当初的理由 vs. 结果，暴露后见之明偏差。

> **借鉴落点**：《财商流游戏》的"复盘/教练"环节可借鉴 SMG——玩家每次大额操作必须在"交易决策卡"上写下理由，终局复盘打分。

## 板块 2 · 真实世界衍生品机制速查（设计底稿）

> 以下机制是把"杠杆/做空/期货/期权"做进桌游时**必须正确建模**的金融事实，
> 数值口径以中国 A 股 / 期货 / 期权市场通行规则为准，供《规则与经济系统》直接引用。

### 2.1 期货（Futures）

- **本质**：标准化合约，约定未来某日以约定价格买入/卖出一定数量标的。
- **保证金交易**：只需缴纳合约价值的一定比例（中国商品期货通常 **5%–15%**，股指期货约 **10%–15%**）即可建仓，自带 **5–20 倍杠杆**。
- **逐日盯市（marking-to-market）**：每日按结算价盈亏划转保证金账户。
- **强平（强制平仓）**：当保证金余额低于**维持保证金**水平，经纪商发出追保，未补足则强行平仓。
- **多头 / 空头**：做多 = 赌涨；做空 = 先卖后买、赌跌。两者对称，但空头有**借券/融券成本**与**逼空风险**。
- **到期**：现金交割或实物交割；多数投机者到期前平仓。

### 2.2 期权（Options）

- **看涨期权 Call**：付出**权利金**，获得"未来以约定价买入"的权利（非义务）。
- **看跌期权 Put**：付出权利金，获得"未来以约定价卖出"的权利。
- **买方最大亏损 = 权利金**；**卖方（写期权）收益有限、亏损可能无限**——这是风险不对称的核心教学点。
- **行权价 / 到期日 / 隐含波动率** 三要素决定权利金价格。
- **保护性看跌（protective put）**：持有现货 + 买入 Put = 给资产买保险。
- **中国**：50ETF/300ETF 期权（欧式）、沪深 300/中证 1000 股指期权、商品期权（豆粕、白糖、铜等）。

### 2.3 融资融券 / 杠杆（中国 A 股口径）

- **融资**：借钱买股（做多杠杆）；**融券**：借股卖出（做空）。
- **保证金比例**：融资买入保证金比例 ≥ **80%（2023 年后多次下调趋松，原 100%）**；融券卖出类似。
- **维持担保比例**：总资产 / 总负债，低于 **130%** 触发追保，低于 **110%/平仓线** 被强平。
- **标的范围**：仅"两融标的股"（约 2000 余只）可融资融券；非标的不能加杠杆。
- **利率**：融资年化利率约 **5%–8%**（券商报价）。

### 2.4 做空与逼空（Short Squeeze / Corner）

- **做空的三个成本**：①借券利息；②分红要补偿给借出方；③**无限上涨风险**（理论上损失无上限）。
- **逼空（short squeeze）**：股价被快速拉高，空头被迫高价回补，进一步推高股价——GameStop 2021、Pit 桌游 corner 的现实版。
- **囤积居奇（corner）**：某人/某资金控制某商品可交割货源，迫使空头高价接货（历史：19 世纪芝加哥小麦、2010 年嘉能可金属逼仓）。

### 2.5 风险对冲与组合

- **对冲（hedging）**：用衍生品抵消现货敞口（如航空股 + 原油看涨期权对冲油价）。
- **分散化 / 再平衡**：SMG 与《行为金融》已覆盖；此处强调**杠杆下分散化的非线性风险**。
- **止损纪律**：预设最大回撤线；行为偏差中"处置效应"（卖盈持亏）会摧毁止损纪律。

## 板块 3 · 桌游化设计：把上述机制映射成《财商流游戏》组件

### 3.1 新增卡牌类型（建议并入《棋盘与道具设计》§6 卡池）

| 卡牌 | 数量 | 作用 |
|------|------|------|
| **期货合约卡** | 每种标的 1 套 | 标注标的、合约面值、保证金比例、到期回合；多头/空头两面 |
| **看涨/看跌期权卡** | 每标的各 6 张 | 标注行权价、权利金、到期；买入即付权利金 |
| **追加保证金卡（margin call）** | 6 张事件卡 | 市场反向波动时翻出，要求限时补保证金 |
| **强平清算卡** | 4 张 | 维持担保比例跌破阈值，强制卖出持仓 |
| **逼空事件卡** | 3 张 | 某小标的被囤积，空头被迫高位回补 |
| **做市商报价卡** | 1 张公共板 | 标注买卖价差，玩家间交易需让利 |

### 3.2 数值设计建议（人民币口径，与《规则与经济系统》对齐）

| 参数 | 建议初值 | 理由（真实世界锚点） |
|------|---------|---------------------|
| 期货保证金比例 | 8%–12% | 国内商品期货 5%–15% 中位 |
| 融资年化成本 | 6%–8% | 券商两融利率 5%–8% |
| 维持担保追保线 | 140% | 现实 130%，游戏略宽松以留教学缓冲 |
| 强平线 | 115% | 现实 110%，游戏略宽 |
| 期权权利金 | 标的市值 3%–10% | 按隐含波动率粗略区间 |
| 逐日盯市频率 | 每个市场回合 | 现实每日 |

### 3.3 回合与流程（接入现有回合结构）

1. **市场回合开始**：翻出"市场周期卡"，确定本回合涨跌与波动率。
2. **盯市阶段**：按最新价重估所有杠杆仓位市值，计算维持担保比例。
3. **追保检查**：低于追保线 → 发"追加保证金卡"，玩家须在下一交易回合前补足现金；否则触发强平。
4. **交易阶段**：现货买卖 + 期货开/平仓 + 期权买入/行权/放弃。
5. **事件阶段**：随机翻出逼空/崩盘/黑天鹅卡。
6. **终局/阶段切换**：市场由繁荣转萧条时，杠杆仓位**优先被强制去化**。

### 3.4 教学目标（与《行为金融》衔接）

| 机制 | 暴露的心理偏差 | 教练话术示例 |
|------|--------------|-------------|
| 杠杆放大收益时的亢奋 | 过度自信、代表性偏差 | "你现在赚的钱里，多少是判断对了，多少只是杠杆放大？" |
| 拒绝补保证金、死扛 | 损失厌恶、沉没成本 | "补保证金是在给错误加杠杆，还是在抄底？" |
| 追涨买入看多期权 | FOMO、羊群效应 | "权利金归零的那一天，你会怪谁？" |
| 做空被逼空 | 低估尾部风险、自负 | "空头的损失为什么是'理论上无上限'？" |
| 用保护性看跌对冲 | 风险感知钝化 | "你给房子买了保险，为什么不给股票仓位买？" |

## 板块 4 · 对本作设计的具体落点清单（10 条）

1. 在《规则与经济系统》"投资"章新增"**杠杆与衍生品**"子节，定义保证金、追保、强平阈值。
2. 在《棋盘与道具设计》§6 卡池新增 6 类衍生品卡（见 §3.1）。
3. 在《交易拍卖与企业经营》"股票价格发现"后补"**期货曲线 / 期权链**"价格表示例。
4. 在《行为金融》"心魔卡"中新增"**杠杆上瘾 / 拒绝止损**"心魔，对应过度自信与损失厌恶。
5. 在《真实世界底座》"八类投资品"中补充"**期货/期权/两融**"真实规则（板块 2 即底稿）。
6. 设计一个"**Pit 式公开喊价小游戏**"作为教学热身（10 分钟），让玩家先体验混乱成交，再进入正式棋盘。
7. 市场周期"衰退"阶段，强制检查所有杠杆仓位，触发去杠杆连锁——强化 Roaring 20s 式阶段切换。
8. 加入"**逼空事件**"：小标的被某玩家囤积后，持有空头的玩家被迫高位回补，教学尾部风险。
9. 终局结算时，**衍生品浮盈浮亏必须并入三表**（资产=市值，负债=应付保证金），不能游离表外。
10. AI 教练在复盘时，专门统计每位玩家"**杠杆使用胜率**"：若长期亏损且靠杠杆，标注为"风险偏好错配"。
