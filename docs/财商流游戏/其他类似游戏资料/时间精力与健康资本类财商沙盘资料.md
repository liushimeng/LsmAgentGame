## 一、为什么单独调研「时间 / 精力 / 健康资本」？

「财商流游戏」五维资源（现金 / 时间 / 精力 / 人脉 / 认知）中，**精力**是唯一兼具以下三重属性的维度：

1. **健康资本化**：精力 ≠ 行动点，它是「健康存量」的外显指标。精力降到 -3 触发健康危机 = 健康资本折旧到临界点——这与 Grossman 1972 健康需求模型中「健康资本折旧率随年龄递增」完全同构【已查证，见第三节】。
2. **时间货币化**：用钱买时间（雇人 / 外包）、用时间换钱（加班 / 副业）、用精力换钱（过劳）——这是本作区别于《富爸爸现金流游戏》「只记账不计时」的核心差异点【已查证，见《财富流沙盘完整资料》§3.6】。
3. **AI 策略空间**：AI 玩家的「时间预算策略」需要显式建模——每回合 24 小时如何分配？副业 / 学习 / 休息 / 社交的精力投入产出比？这是 Agent 驱动的核心决策面【待设计】。

**调研目标**：从桌游机制、电子游戏、真实方法论、实证研究中，提炼**可规则化**的设计素材，落到《财商流游戏规则与经济系统》§2.4 精力维度的深化。

## 二、桌游中的时间 / 行动经济机制

> 本节聚焦**时间作为显式资源或核心张力**的桌游。Agricola / Caverna / Viticulture 等 worker placement 的饥饿压力与季节机制已在《农业资源经营与德式桌游经济循环资料》详述，**本节不复述，仅补遗**。

### 2.1 Tzolk'in: The Mayan Calendar（玛雅历法，2012）

**设计师**：Daniele Tascini / Simone Luciani；**出版社**：Czech Games Edition (CGE)；**年份**：2012；**玩家数**：2-4 人；**时长**：60-90 分钟；**BGG 重度**：4/5。【已查证】

#### ① 核心机制：齿轮 = 时间可视化

游戏最具创新性的设计是 **6 个互相咬合的齿轮**，中央最大的齿轮即 Tzolk'in（玛雅神圣历）齿轮：

- 玩家扮演玛雅部落，将工人（圆柱形 token）放置到齿轮上**最低编号（最外圈）的可见空位**上。
- 每次回合结束，**齿轮向前转动一格（一天）**。工人随齿轮从「未来」慢慢移动到「当下」。
- **当中央 Tzolk'in 齿轮转完一整圈时（一个时代结束），游戏结束**。【已查证】

#### ② 时间与收益的权衡

| 放置位置 | 收益 | 代价 |
|---------|------|------|
| 齿轮外圈（早期行动） | 行动弱 / 便宜 | 立即执行 |
| 齿轮内圈（晚期行动） | 行动强 / 收益高 | 需等待数轮，承担「喂食」成本 |

> "Actions located 'later' on the gears are more valuable, so it's wise to let the time work for you – but players cannot skip their turn; if you have all your workers on the gears, you have to pick some up."【已查证】

#### ③ 每回合二选一

玩家在自己回合必须执行以下**二选一**操作（不能两者都做）：

1. **放置工人**：支付玉米（corn）作为「时间投入」成本。玉米成本 = 基础玉米（0/1/3/6/10/15 玉米分别对应 1/2/3/4/5/6 个工人）+ 累积成本（每个被占据位置的编号累加）。
2. **取回工人**：取回 1 个或多个工人，每个工人可选择：
   - ✅ 执行当前所在位置的动作（最强）
   - ⬇️ 降级执行更低位置的动作（每往后退一格消耗 1 玉米）
   - ❌ 什么都不做（仅取回）

#### ④ Food Day（食物日）—— 时间压力的具象化

游戏中有 **4 个食物日**（第 8、14、21、27 天）：
- 每个在场的工人需喂食 **2 玉米**（农场可豁免）。
- 未喂养的工人每个 **扣 3 分**。
- 中间食物日触发奖励；时代末食物日触发建筑升级与神殿得分。

> 这迫使玩家**不能无限制地把工人堆在齿轮上「等时间」**——时间是有成本的。【已查证】

#### ⑤ 5 大齿轮功能（外圈 → 内圈）

Palenque（基础资源）→ 玉米（收购工人）→ 资源（木材 / 石材 / 金矿）→ 建筑 / 科技（4 条轨道）→ Uxmala（献祭得分 / 神殿）。第 6 齿轮 Chichen Itza 仅 2 人游戏启用。【已查证】

#### ⑥ 设计精髓总结

Tzolk'in 的天才之处在于**把「时间」本身做成了可触摸的游戏组件**：

1. **齿轮 = 时间可视化**：工人随齿轮转动，自然产生「等待」的感觉。
2. **早放晚收 vs 晚放早收**：决策核心是「我愿不愿意为更强力的行动付出等待的代价？」
3. **食物日机制**：强制打破「无限堆叠工人」的策略，让每个工人都要「消费时间」。
4. **多回合规划**：你要考虑 N 个回合后齿轮转到哪里、你的工人会到哪个位置、对手会怎么挡位。

> 这是 **worker placement 机制的一次革命性演化**——将「动作」与「时间」解耦，让回合不再只是「我做什么」，而是「**我什么时候做**」。【已查证】

#### ⑦ 对「财商流游戏」的映射

| Tzolk'in 机制 | 财商流映射 |
|---|---|
| 齿轮 = 时间可视化 | 棋盘上的「回合轨 / 年龄轨」已具备，但可加「时间预算轨」显式展示本回合 24 小时分配 |
| 早放晚收 vs 晚放早收 | 副业 / 企业投资的「成长期」：前期投入精力，后期被动收入——与精力维度的「成长期消耗」同构 |
| 食物日 = 时间成本 | 精力维度的「透支代价」：每回合必须「喂食」精力，否则扣减——可设计为「透支利息」 |
| 二选一（放置 vs 取回） | 每回合「行动 vs 休息」的二元抉择——与「休息格」机制同构 |

### 2.2 Patchwork（拼布，2014）

**设计师**：Uwe Rosenberg（乌维·罗森贝格，同 Agricola 设计师）；**出版社**：Lookout Games；**年份**：2014；**玩家数**：仅 2 人；**时长**：15-30 分钟；**类别**：抽象策略 / 拼图 / 益智。【已查证】

#### ① 核心机制：「时间就是货币」

Patchwork 最精妙的设计在于将**时间**转化为与**纽扣（buttons）**并列的第二资源。这两个资源互相牵制，构成了游戏的核心张力。

| 资源 | 作用 | 来源 |
|------|------|------|
| 🔘 纽扣 (Buttons) | 购买布块的货币 + 最终胜利分 | 起始 5 颗 / 经过时间轨「纽扣格」时获得 |
| ⏱️ 时间 (Time) | 决定回合顺序 + 决定游戏何时结束 | 每个布块带有「时间消耗值」 |

#### ② 时间轨 (Time Track) 机制

游戏板中央有一条**圆形时间轨**，每位玩家有一个时间标记。购买布块时，时间标记会沿轨道前进相应的步数。

**「落后者先走」规则**（时间决定回合顺序）：
> 如果你的时间标记落后于或在对方标记之上，你就再行动一次。

这是 Patchwork 最重要的创新之一：
- 买了「大块、慢速」的布块 → 时间标记大幅前进 → 对方可能连续行动 2-3 次。
- 买了「小块、快速」的布块 → 时间标记前进少 → 你保持领先，可以再行动。

#### ③ 跳过（Pass）选项

当买不起布块时，玩家可以「跳过」——将自己的时间标记移到对方标记正前方，**每移动一格获得 1 颗纽扣**。这是经济追赶的关键。

#### ④ 时间轨上的「特殊奖励格」

- **纽扣收入格 (Button Income)**：当时间标记经过印有纽扣图标的位置时，立即获得收入 = 你棋盘上所有布块印有的纽扣总数。这构成了游戏的经济引擎——买的布块越多、含纽扣越多，后期收入越高。
- **1×1 皮块格 (Special 1×1 Patches)**：时间轨上有 5 个特殊小皮块位置。**第一个经过的玩家**可以免费拿走该皮块，立刻放入自己的棋盘（填补一个空位）。

#### ⑤ 货币循环示意图

```
购买布块
   ↓ 消耗纽扣 + 时间
   ├─→ 获得新布块（占据棋盘空间）
   └─→ 时间标记前进
            ↓
       经过纽扣格 → 获得收入（基于棋盘上纽扣数）
            ↓
       收入再用于购买更多布块
            ↓
       时间标记到达终点 → 游戏结束
```

#### ⑥ 胜利条件

游戏结束时（双方时间标记都到达终点）：
- **+1 分**：每颗剩余的纽扣。
- **-2 分**：棋盘上每个未覆盖的空格。
- **+7 分**（可选）：第一个填满 7×7 方块的玩家获得奖励皮块。

#### ⑦ 战略核心：三大决策维度

1. **空间拼图**（俄罗斯方块式布块摆放）—— 越紧密越好。
2. **经济管理**（纽扣收支平衡）—— 选择带纽扣符号的布块作为「引擎」。
3. **时间博弈**（快 vs 慢的取舍）—— 快块省钱但形状怪，慢块高效但让对手连动。

> 正如 BoardGameBliss 描述的："Buttons are not only currency, they are also victory points... it is about managing an economy in a time efficient manner."（纽扣既是货币又是分数……这游戏本质上是「在有限时间内管理经济」。）【已查证】

#### ⑧ 对「财商流游戏」的映射

| Patchwork 机制 | 财商流映射 |
|---|---|
| 时间 = 回合顺序 + 游戏长度 | 精力维度的「时间预算」：每回合 24 小时如何分配？行动多 → 精力消耗大 → 健康折旧快 |
| 落后者先走 | 「精力充沛者先动」——精力高的玩家可优先选择行动（拍卖 / 机会卡） |
| 跳过 = 经济追赶 | 「休息格」= 放弃本回合行动，换取精力恢复 + 少量收入 |
| 纽扣收入 = 引擎构筑 | 被动收入引擎：副业 / 企业成长期后「精力消耗归零，现金流稳定为正」 |

### 2.3 5-Minute Dungeon（五分钟漂流，2015）

**设计师**：Connor Reid；**出版社**：Asterion Press；**年份**：2015；**玩家数**：2-5 人；**时长**：5 分钟 / 局；**类别**：实时合作卡牌。【已查证】

#### ① 核心机制：实时倒计时的时间压力

- **内置沙漏或手机计时器（5 分钟倒计时）**。
- **没有轮次（no turns）**，所有玩家同时讨论出牌。
- 需要快速匹配符号：地城卡牌上的符号必须与英雄卡牌符号对应。
- 讨论时间有限，制造紧迫感。

#### ② 时间压力反馈

- 许多玩家反馈「时间永远不够用」。
- 需要快速沟通和团队协调。
- 失败后往往因为讨论时间过长或出牌顺序错误。

#### ③ 设计目的

5-Minute Dungeon 的设计初衷就是模拟**极限时间压力下的合作体验**。每关递增难度，Boss 战时间压力达到极限。【已查证】

#### ④ 对「财商流游戏」的映射

| 5-Minute Dungeon 机制 | 财商流映射 |
|---|---|
| 实时倒计时 | 市场周期的「限时决策」：机会卡出现后 N 秒内必须决定是否投资 |
| 无轮次 / 同时行动 | 多人竞拍 / 抢购场景：所有玩家同时出价，时间压力下的决策质量下降 |
| 时间压力 → 错误率上升 | 精力低时「认知降级」：精力 -1 时投资决策的负面事件概率 +10% |

### 2.4 The Cost（代价，2021）

**设计师**：Paul Kluka；**出版社**：Playforia；**年份**：2021；**玩家数**：1-4 人；**时长**：60-90 分钟；**类别**：经济 / 工人放置 / 机会成本。【已查证，BGG 数据】

#### ① 核心主题：机会成本

The Cost 的主题是**「每一个选择都有代价」**——玩家管理一个家庭，在有限的时间内（一天 24 小时）分配工作、休息、学习、社交。每个行动都消耗时间，而时间是不可再生的。

#### ② 核心机制

- **时间预算板**：每位玩家有一块 24 小时的时间板，用时间块填充。
- **行动格**：工作（赚钱）、休息（恢复精力）、学习（提升技能）、社交（建立人脉）——每个行动消耗不同小时数。
- **机会成本**：选择加班赚钱 → 无法休息 → 精力下降 → 第二天效率降低。
- **健康事件**：连续不休息会触发「过劳」事件，强制停休 + 医疗支出。

#### ③ 对「财商流游戏」的映射

| The Cost 机制 | 财商流映射 |
|---|---|
| 24 小时时间板 | 精力维度的「时间账本」：每回合 24 小时如何分配？可作为第四表（时间账本） |
| 机会成本 | 副业 / 学习 / 休息的三难抉择——与五维资源互动矩阵同构 |
| 过劳事件 | 精力 -3 的「健康危机」事件——强制住院 + 医疗支出 |

## 三、电子游戏中的时间 / 精力游戏化

### 3.1 Habitica（习惯打卡 RPG，2013-至今）

**原名**：HabitRPG；**类型**：开源习惯养成应用 / 游戏化任务管理；**平台**：iOS / Android / Web；**费用**：免费（含内购 / 订阅）；**语言**：支持中文。【已查证】

#### ① 核心机制：将习惯和待办事项变成 RPG

- **习惯 (Habits)**：长期养成的行为，可设置正向 / 负向。
- **每日任务 (Dailies)**：需要每天重复完成的任务。
- **待办事项 (To-Dos)**：一次性任务。
- **奖励系统**：完成任务获得金币、经验值，可用于购买装备、宠物等。

#### ② 游戏化元素

| 元素 | 说明 |
|------|------|
| 等级 / 经验值 | 完成任务 → 升级 → 解锁新能力 |
| 装备 / 宠物 | 金币购买，提升角色属性 |
| Boss 战 | 组队协作，全队共享伤害 |
| 社交 | 支持组队、公会、聊天 |
| 开源 | GitHub 开源项目 |

#### ③ 对「财商流游戏」的映射

| Habitica 机制 | 财商流映射 |
|---|---|
| 每日任务 = 习惯打卡 | 精力维度的「每日精力预算」：每回合自动恢复 1 点 = 每日习惯 |
| 负向习惯扣血 | 精力维度的「坏习惯」：熬夜 / 加班 → 精力 -1 |
| Boss 战 = 团队挑战 | 合作投资 / 企业联营：多人协作完成大项目 |
| 金币 = 游戏内货币 | 三表联动中的「精力变现」：精力 → 副业收入 → 现金流 |

### 3.2 Forest: Focus for Productivity（专注森林，2016-至今）

**开发商**：Seekrtech；**类型**：专注计时器 / 游戏化番茄钟；**平台**：iOS / Android；**费用**：付费（含内购）。【已查证】

#### ① 核心机制：种树 = 专注

- 设定专注时间（25-120 分钟）→ 种下一棵树。
- 专注成功 → 树长成 → 获得金币。
- 专注失败（中途退出 App）→ 树枯萎。
- 金币可解锁新树种、真实世界种树（与 Trees for the Future 合作）。

#### ② 游戏化元素

| 元素 | 说明 |
|------|------|
| 种树 | 专注时间 → 虚拟树 → 成就感 |
| 成就系统 | 连续专注天数、总专注时长 |
| 真实影响 | 虚拟金币 → 真实种树（环保合作） |
| 社交 | 与好友一起种树、排行榜 |

#### ③ 对「财商流游戏」的映射

| Forest 机制 | 财商流映射 |
|---|---|
| 专注 = 种树 | 精力维度的「深度工作」：投入精力学习 / 投资 → 获得认知 / 收益 |

### 4.2 GTD（Getting Things Done，搞定）

**作者**：David Allen；**首版**：2001 年（*Getting Things Done: The Art of Stress-Free Productivity*）；**中译本**：《搞定：无压工作的艺术》，中信出版社。【已查证】

#### ① 五大核心步骤

| 步骤 | 英文 | 中文 |

### 4.3 番茄工作法（Pomodoro Technique）

**创始人**：Francesco Cirillo；**发明年份**：1980 年代末；**名称来源**：Cirillo 使用的番茄形厨房计时器。【已查证】

#### ① 核心规则

| 阶段 | 时长 | 说明 |
|------|------|------|
| 专注工作 | 25 分钟 | 单一任务，不分心 |
| 短休息 | 5 分钟 | 休息、放松 |
| 长休息 | 15-30 分钟 | 每 4 个番茄钟后 |

#### ② 核心原则

1. **单一任务**：一个番茄钟只做一件事。
2. **不可分割**：番茄钟一旦开始，不能暂停。
3. **休息是必须的**：短休息和长休息是番茄工作法的一部分，不是可选的。
4. **记录**：记录每个番茄钟完成的任务，用于回顾和改进。

#### ③ 对「财商流游戏」的映射

| 番茄工作法 | 财商流映射 |
|---|---|

| 5 分钟休息 | 精力维度的「微休息」：每 N 回合强制休息 1 回合，恢复 1 点精力 |
| 4 番茄钟 → 长休息 | 精力维度的「季度休息」：每 12 回合（年度）强制「年假」1 回合，恢复 3 点精力 |
| 记录 | 时间账本（第四表）的数据来源 |

### 4.4 时间块（Time Blocking）

**核心理念**：将一天的时间划分为若干「时间块」，每个时间块分配给特定任务或活动。【已查证】

#### ① 核心规则

## 五、时间银行与时间货币理论

### 5.1 Edgar Cahn 与时间美元（Time Dollar）

**创始人**：Edgar S. Cahn（1935-2022），美国律师、教授、社会创新者；**概念提出**：1986 年演讲 / 1992 年正式出版；**代表作**：*Time Dollars: The New Currency That Enables Americans to Turn Their Hidden Resource—Time—Into Personal Security & Community Renewal*（1992，与 Jonathan Rowe 合著）；*No More Throw-Away People: The Co-Production Imperative*（1999/2000，与 Jonathan Rowe 合著）。【已查证】

#### ① 核心机制：1 小时 = 1 Time Dollar

- **Time Dollar / Nemo 系统**：1 小时服务 = 1 Time Dollar，**无论服务类型**。
- 核心机制：人们通过帮助他人赚取时间积分，可以在需要时兑换他人的帮助。

#### ② 五大核心价值（Five Core Values）

Cahn 阐明了时间银行的五大核心价值：

1. **Asset（资产）**：每个人都是资产 —— 每个人都有有价值的东西可以贡献。
2. **Redefining Work（重新定义工作）**：工作应重新定义，包括传统上不被支付的活动（照顾、指导、社区建设）。
3. **Reciprocity（互惠）**：帮助在互惠时效果最好 —— 「你需要我」和「我需要你」。
4. **Social Networks（社会网络）**：我们需要强大的社会网络和社区联系才能运作。
5. **Respect（尊重）**：每个人都应受到尊严和尊重的对待。

#### ③ 设计动机

Cahn 提出这一概念，部分原因是看到社会系统的局限性以及非正式社区支持网络的侵蚀。时间银行已应用于医疗、老年护理、刑事司法、教育和社区发展。【已查证】

#### ④ 对「财商流游戏」的映射

| 时间美元机制 | 财商流映射 |
|---|---|
| 1 小时 = 1 Time Dollar | 精力维度的「时间货币化」：1 点精力 = 1 小时 = 可交易的「时间币」 |
| 五大核心价值 | 人脉维度的「社会资本」：互惠 + 社会网络 + 尊重 = 人脉积累 |
| 时间银行 = 互助系统 | 玩家间的「时间借贷」：A 借给 B 时间币，B 未来归还 + 利息 |
| 重新定义工作 | 副业 / 家务 / 育儿等「非市场劳动」也产生价值（精力 + 人脉） |

## 六、健康资本理论

### 6.1 Grossman 1972 健康需求模型

**核心论文**：Michael Grossman (1972), "On the Concept of Health Capital and the Demand for Health," *Journal of Political Economy*。这是健康经济学的奠基之作，Grossman 将 Becker 的人力资本理论应用到健康领域。【已查证】

#### ① 健康作为耐用资本品

- 健康被视为一种 **durable capital stock（耐用资本存量）**。
- 个体与生俱来拥有一定的初始健康存量。
- 健康能产出「健康时间」（healthy days / time）。
- 健康既是**消费财**（直接进入效用函数），又是**投资财**（通过减少生病时间增加市场与非市场部门的回报）。

#### ② 健康资本折旧（Depreciation）

**折旧率 δ（delta）随年龄递增**：
- 健康存量随时间推移而自然折旧。
- 折旧率随年龄增长而加速上升——这是模型的核心特征。
- 年龄越大，维持同等健康存量的成本越高。

**两类折旧**：
- **自然折旧**：随年龄增长、生物性衰老。
- **使用折旧**：受教育程度较低、收入较低者可能更「密集地」使用健康资本（如从事体力劳动），导致使用折旧率更高。

#### ③ 健康生产函数

$$H = f(M, LS, E; S)$$

其中：
- M = 医疗保健服务
- LS = 生活方式
- E = 环境、教育
- S = 其他个体特征

#### ④ 最优健康投资条件

边际成本 = 边际收益：

$$MC_{HK} = r + \delta$$

- r = 利率
- δ = 折旧率
- 折旧率随年龄上升 → 边际成本上升 → 最优健康存量随年龄下降

#### ⑤ 模型的关键预测

| 变量 | 对健康需求的影响 |
|------|----------------|
| 年龄↑ | 健康需求下降（折旧加速） |
| 工资↑ | 健康投资可能增加（时间机会成本提高 → 减少生病时间） |
| 教育↑ | 健康生产效率提高 → 更健康 |
| 医疗价格↑ | 健康需求下降 |

#### ⑥ 模型发展

后续研究沿三个方向扩展：(1) 一般化（Muurinen 1982）；(2) 引入不确定性（Cropper 1977、Chang 1996 等）；(3) 家庭内部时间分配（Grossman & Joyce 1974：妻子时间是丈夫健康生产的重要投入）。【已查证】

#### ⑦ 对「财商流游戏」的映射

| Grossman 模型 | 财商流映射 |
|---|---|
| 健康 = 耐用资本存量 | 精力 = 健康存量的外显指标（-3 到 10 点） |
| 折旧率随年龄递增 | 精力上限随年龄下降：20-30 岁上限 11，45-60 岁上限 8 |
| 自然折旧 + 使用折旧 | 每回合自动恢复 1 点 = 自然修复；副业 / 企业 = 使用折旧 |
| 健康生产函数 H = f(M, LS, E; S) | 精力恢复 = f(医疗支出, 生活方式, 环境, 个体特征) |
| 最优投资条件 MC = r + δ | 精力投资的边际成本 = 时间机会成本 + 折旧率 |

### 6.3 「时间就是金钱」的定价

#### ① 自由职业时薪思维

- **核心理念**：自由职业者按小时收费，因此必须计算「时间的机会成本」—— 花 1 小时做家务 vs 花 1 小时工作赚钱，哪个更划算？
- **计算公式**：时薪 = 年收入 / 年工作小时数。例如：年收入 30 万 / 2000 小时 = 150 元 / 小时。
- **应用**：如果家务可以通过外包（100 元 / 小时）解决，而自己时薪 150 元 / 小时，则外包更划算。

#### ② Whillans 2017 PNAS：花钱买时间提升幸福感

**论文**：Whillans, A.V., Dunn, E.W., Smeets, P., Bekkers, R., & Norton, M.I. (2017). "Buying time promotes happiness." *Proceedings of the National Academy of Sciences (PNAS)*, 114(32), 8523–8527. DOI: 10.1073/pnas.1706541114【已查证】

**核心发现**：
- 花钱买时间（如外包清洁、烹饪、跑家务等不喜欢的工作）的人，比花钱买物质财富的人报告**更高的生活满意度**。
- 效应在多项研究中保持一致，包括来自多个国家的约 **6,000 名成年人**样本。
- 减少时间压力感（time stress）是提升幸福感的机制。
- 然而，**很少有人**真正选择这样花钱 —— 许多人可以负担得起，但就是不这么做。
- 作者建议：**重视时间而非金钱**会带来更大的幸福感。

| | 花钱买时间 | 买东西 |
|---|---|---|
| 对幸福感的影响 | ✅ 显著提升 | ⚠️ 最小 / 无持久效果 |
| 机制 | 减少时间压力 | 暂时的物质满足 |
| 谁受益 | 任何外包不喜欢任务的人 | —— |

> 核心洞察：**人们低估了自己的时间。** 他们工作赚钱，然后用钱买东西，而不是用时间 —— 而时间实际上才是更能提升幸福感的用法。

#### ③ Time Affluence（时间充裕感）

**研究者**：Dr. Cassie Holmes（UCLA）；Matthew Killingsworth（Wharton / Stanford）。【已查证】

- **Time Affluence（时间充裕感）**：主观感觉有充足的时间 —— 是幸福感的强预测因子，超过物质财富。
- **Time Poverty（时间贫困）**：与较低的幸福感、较高的压力、较差的健康行为相关 —— 在东亚工作文化（如 996）中尤为严重。
- **Killingsworth 2023 PNAS**：解决了与 Daniel Kahneman 的争论 —— 发现幸福感对大多数人随收入持续上升，但**少数不幸福的人在约 10 万美元时达到平台期**。他强调**时间充裕感**是除了收入之外通往幸福感的补充路径。

#### ④ 对「财商流游戏」的映射

| 时间定价研究 | 财商流映射 |
|---|---|
| 时薪思维 | 精力维度的「时间定价」：每点精力 = X 元时薪，用于计算副业 / 学习的投入产出比 |
| 花钱买时间 | 精力维度的「服务卡」：支付现金雇人做家务 / 跑腿 → 节省精力用于投资 / 学习 |

## 九、落地建议（指向《财商流游戏规则与经济系统》§2.4 精力维度章节）

> 本节仅提供**方向性建议**，具体规则设计请参见《财商流游戏规则与经济系统》§2.4 精力维度章节。

### 9.1 透支的复利代价（P0）

**现状**：精力 -1 到 -2 时无法进行消耗精力的动作；精力 -3 时触发健康危机。

**建议**：引入「透支利息」机制——
- 精力为负时，每回合额外 -1 点「健康债务」。
- 健康债务累计到 -5 时，触发「慢性病」事件：每回合固定 -1 点精力上限，直到支付大额医疗费治愈。
- **借鉴**：Tzolk'in 食物日（时间有成本）+ Grossman 折旧（健康资本加速损耗）。

### 9.2 健康事件卡（P0）

**现状**：已有疾病卡、中症、重疾事件。

**建议**：新增「过劳」系列事件——
- 「轻度过劳」：连续 3 回合精力 < 3 时触发，精力 -1，可选择支付 2,000 元做按摩恢复。
- 「中度过劳」：连续 5 回合精力 < 2 时触发，强制停 1 回合，精力恢复至 5。
- 「重度过劳」（猝死风险）：精力 -3 且现金 < 10,000 时触发，强制住院 3 回合，医疗支出 30,000 元。
- **借鉴**：The Cost 过劳事件 + 中国 996.ICU 现象 + 睡眠剥夺研究。

### 9.3 用钱买时间的服务卡（P0）

**现状**：已有「休息格」恢复精力。

**建议**：新增「服务卡」类别——
- 「家政服务」：支付 1,500 元，本回合精力消耗 -1（最低到 0）。
- 「外卖配送」：支付 500 元，本回合可额外执行 1 个行动。
- 「健身私教」：支付 3,000 元，永久 +1 点精力上限（最多 +2）。
- 「心理咨询」：支付 2,000 元，立即恢复 3 点精力。
- **借鉴**：Whillans 2017 PNAS（花钱买时间提升幸福感）+ 自由职业时薪思维。

### 9.4 时间账本（第四表？）（P1）

**现状**：三表联动（资产负债表 / 损益表 / 现金流量表）。

**建议**：新增「时间账本」作为第四表（可选模块）——
- 每回合记录 24 小时分配：工作 / 学习 / 休息 / 社交 / 其他。
- 每 12 回合（年度结算）生成「时间年报」：各类活动的时间占比 + 精力使用效率评分。
- 时间年报影响 AI 玩家的「时间预算策略」调整。
- **借鉴**：柳比歇夫时间统计法 + The Cost 24 小时时间板。

### 9.5 AI 玩家的时间预算策略（P1）

**建议**：AI 玩家（Agent）每回合执行以下决策流程——

1. **评估当前状态**：精力 / 现金 / 认知 / 年龄。
2. **计算时间预算**：根据 GTD 情境标签，计算本回合可用精力。
3. **选择行动组合**：
   - 精力 > 7：优先投资（副业 / 企业 / 学习）。
   - 精力 4-7：平衡（工作 + 休息）。
   - 精力 < 4：优先休息（恢复精力）。
4. **执行并记录**：记录本回合时间分配，用于下回合调整。
- **借鉴**：GTD 五步骤 + 时间块 + 番茄工作法。

### 9.6 精力维度的年龄绑定（P1）

**现状**：20-30 岁精力上限 +1。

**建议**：引入 Grossman 折旧模型——
- 20-30 岁：精力上限 11（年轻体壮）。
- 30-45 岁：精力上限 10（正常）。
- 45-60 岁：精力上限 8（加速折旧）。
- 每年生日（钟声时）：若该年未生大病，+2 点；否则 +0 点。
- **借鉴**：Grossman 1972 健康资本折旧率随年龄递增。

### 9.7 时间币交易（P2）

**建议**：引入「时间币」作为玩家间交易的补充货币——
- 1 时间币 = 1 小时 = 玩家可借出 / 借入的时间。
- 借入时间币：本回合可额外执行 1 个行动，但下回合必须归还 + 1 时间币利息。
- 无法归还：人脉 -2，获得「时间债违约」标记。
- **借鉴**：时间美元（Edgar Cahn）+ 中国时间银行。
