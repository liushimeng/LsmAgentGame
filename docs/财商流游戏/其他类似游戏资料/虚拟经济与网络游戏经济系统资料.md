## 1. 为什么单独调研虚拟经济体

财商流游戏《规则与经济系统》第 3 章（货币系统）、第 6 章（8 类投资品）、第 11 章（玩家经济与 AI 玩家平衡）已经建模了人民币计价的多层市场。但**游戏内货币系统本身就是"小央行"**——几乎所有游戏经济体都在重复发明一套货币发行、回收、销毁与通胀治理机制，且设计比现实更激进（看得见 faucets/sinks、可强制过期、可作恶 RMT 击穿汇率）。把六个案例摸清楚，能给财商流游戏带来三件事：

1. **设计素材**：EVE 的双货币 + 月度经济报告（MER）、WoW 的拍卖行 + Token、动森的强制过期机制、Roblox 的汇率不对称抽成——这四套机制任何一套直接搬到财商流游戏的"游戏内虚拟市场"模块，都能立刻给玩家提供真实感。
2. **风险边界**：RMT（Real Money Trading）/ 打金工作室是网络游戏经济体的**外汇漏洞**——梦幻西游点卡和藏宝阁、Q 币在 2006 年被央行关注、Roblox 的 Premium 转售机制，本质都是"游戏内货币与法币的桥"。玩家如果能在游戏内把金币换回真实人民币，本游戏必须从第一天就设计好这道防火墙。
3. **行为金融教学的素材库**：动森"过周一就变 100 Bell 烂菜"逼玩家在 6 天内做出卖或不卖的决策，恰好就是财商教育最难的"沉没成本 + 持有期判断"组合题——可以原样挪到游戏内。

调研对象选定六款：EVE Online（最像真实经济体的硬核太空 MMO）、魔兽世界（最大 RMT 历史样本 + Token 案例）、动森（最简单的双角色市场 + 强制过期）、Roblox（最大 UGC 创作者经济体）、Second Life（最早的 Linden-美元锚定实验）、梦幻西游 + Q 币（中文社区最深的点卡/藏宝阁实践）。

## 2. 游戏侧：六个虚拟经济体逐一拆解

### 2.1 EVE Online——双货币 + 经济学家治理 + 月度经济报告

**背景**：冰岛 CCP Games 开发的硬核太空沙盒 MMO，世界服"宁静"2003-05-06 上线、中国服"晨曦"2006-07-12 上线、2022-08-23 增开"曙光"服。2006 年至今在中国市场多次更换代理商，**2018-08-01 起由网易游戏代理运营，2023 年成功续约**（百度百科"星战前夜"词条可核实）。

**经济系统结构**（百度百科"星战前夜"词条"物品道具-消耗品"节可核实）：

| 维度 | 设计 |
|---|---|
| 主货币 | 星币 ISK（InterStellar Kredits），通过打怪 / 完成任务 / 变卖道具 / NPC 任务奖金获得 |
| 充值货币 | 伊甸币（Aurum），需玩家充值，主要用于商城购买舰船皮肤、角色外观、服装 |
| 产出 | 采矿、工业制造、科学研究、PvE 赏金、玩家市场交易 |
| 消耗（sinks） | 舰船击毁后爆装、空间站维护费、军团税收、保险费、舰船装备消耗品（弹药/晶体）、蓝图复制 NPC 收费 |
| 市场机制 | 7,000+ 恒星系统内全开放；任何星系任何玩家可挂买单/卖单，由玩家与 NPC 自由报价，类似股票撮合；几乎全部订单为玩家创造 |

**货币治理与 sinks/faucets**：

- **64 个星域 / 7000+ 恒星系统**（百度百科可核实），但 EVE 不分行会服务器，**所有玩家集中在同一服务器**（沙盒理念），所以经济数据可聚合分析。
- CCP 长期聘请**专职经济学家**管理经济体（其中最知名的是 Eyjólfur Guðmundsson，公开署名为 "Dr. EyjoG"，**该姓名已在 EVE 官方 YouTube 频道与 CCP 开发者博客多次出现，但本会话因英文维基百科不可达，原始视频/博客 URL 待核实**），其工作产物即**月度经济报告（Monthly Economic Report, MER）**，按月公布 ISK 总供应量、玩家摧毁舰船回收量、Plex 流转量、活跃挖矿产出、市场税收等核心指标。**MER 是网络游戏界首个由全职经济学家公开审计的内生经济报告**——这一点本文件无法在本会话直接核实 MER 原始 URL（ccp.com 与 developers.eveonline.com 均不可达），但行业广泛报道 CCP 设立此岗并持续运营。
- **PLEX（30 天 Pilot License Extension，飞行员执照）**：玩家可"用真金买 PLEX→ 卖给其他玩家换取 ISK"，这是 EVE 唯一的合法 RMT 通道。买 PLEX 的玩家等于把 ISK "销毁"以换取订阅时长，卖 PLEX 的玩家获得 ISK 注入但失去了订阅权益。**PLEX 既是订阅产品也是 ISK 的隐形回收阀门**——它让 CCP 持续销毁一部分流通中的 ISK，是控制 ISK 通胀最干净的设计之一（本会话无法核实当前 PLEX 牌价与销毁速率，**待核实**）。

**真实世界映射**：

- ISK 销毁 ↔ 央行公开市场操作 + 税收回收流动性。
- PLEX ↔ 外汇管制下的合规兑换通道（指定机构 / 限额 / 反洗钱）。
- 经济学家 + MER ↔ 真实央行的**透明度承诺 + 公开市场操作报告**（美联储 FOMC 声明、人行货币政策执行报告）。
- 64 个星域集中服务器 ↔ 全国统一大市场 vs 联邦制区域市场。

### 2.2 魔兽世界 WoW——金币通胀史 + 拍卖行 + 打金农场 + Token

**背景**：暴雪娱乐 2004-11-23 上线的大型 MMORPG。中国大陆原代理为第九城市，**2009-06-07 变更为网易**，2005-03-21 限量测试 / 2005-06-06 商业化运营；**2023-01-24 0 时网易与暴雪协议到期，国服停运**；**2024-06-27 《巫妖王之怒》怀旧服面向中国大陆重新开放，2024-08-01 正式服重新开放**；**2025-06-25 起登录方式切换为网易账号**（百度百科"魔兽世界"词条可核实）。

**经济系统结构**：

| 维度 | 设计 |
|---|---|
| 主货币 | 金币（Gold，1g = 100s = 10000c） |
| 充值货币 | 月卡（30 天战网通行证）、暴雪战网点、WoW Token |
| 产出 | 任务奖励、PvE/PvP 掉落、采矿/采药/剥皮专业、拍卖行倒卖 |
| 消耗 | 拍卖行抽税、装备维修费、坐骑 / 配方学习费、飞行训练费、物资消耗品（弹药/合剂） |
| 跨服交易 | 拍卖行（中立拍卖行 / 部落拍卖行 / 联盟拍卖行，资料片逐版本合并或分化） |
| 第三方货币 | 时光徽章（间接金币回收器） |

**金币通胀史与治理（**本会话无法核实每一资料片的具体金币发行量，原始数据来自 Blizzard 财报与 Wowpedia，**全部待核实**）：

- **经典旧世（2004-2006）**：金币总量极低，"千金马"是顶级玩家的标志，稀缺度高但消费场景有限。
- **TBC / WotLK（2007-2010）**：日常任务金币大量发放，拍卖行崛起，金币贬值加速。
- **大灾变 / 熊猫人（2011-2014）**：金币与点卡挂钩（RMB 换月卡→ 卖时光徽章→ 换金币），但**金色 ID 玩家**与金币工作室使普通玩家体感通胀。
- **德拉诺 / Legion（2015-2017）**：金币急剧膨胀，**2015-06 暴雪推出 WoW Token**——玩家可用真金买 Token（区域定价，按美/欧/亚等区分），Token 在拍卖行卖出后获得金币。这是暴雪首次正式承认 RMT 通道，目的是把灰色产业链的利润抢回官方。**Token 在拍卖行的成交价即是当时的官方汇率**（美国区长期在 5-10 万金币 / Token 区间波动，**当前精确牌价待核实**）。
- **Shadowlands / Dragonflight（2020-2025）**：金币持续通胀，专业制造原料与战袍涨价；暴雪靠 Token + 拍卖行抽税 + 维修费 + 物资消耗品（药水、合剂）保持 sinks ≥ faucets 的方向。

**RMT / 打金农场**：从 2005 年起，中国 + 东欧 + 拉美的"打金工作室"职业化刷金，再通过淘宝 / 第三方网站 / discord 卖给海外玩家；暴雪长期封号（一次性封禁几万账号）但产业始终存在。WoW Token 本质是把 RMT 利润**内化**到暴雪财报——这套设计后来被 EVE（PLEX）、RuneScape（Bonds）等多家厂商跟进。

**真实世界映射**：

- 资料片金币膨胀 ↔ 货币数量论 MV = PQ：货币量 M 涨 + 流通速度 V 涨 + 商品量 Q 涨不充分 = 通胀 P。
- 拍卖行抽税 ↔ 增值税 / 交易税。
- 装备维修费 ↔ 持有成本（仓储、保险）。
- Token ↔ 外汇管制下的合规兑换通道。
- 打金工作室 ↔ 劳动收入 vs 资本收入、跨境灰色汇款、平台经济合规问题。

### 2.3 集合动物森友会——大头菜市场（强制过期设计 + 散户参与门槛）

**背景**：任天堂 2001 年起系列，**《集合啦！动物森友会》**（Animal Crossing: New Horizons, ACNH）2020-03-20 发售，为任天堂 Switch 第一方支柱作品之一（本节数据来自 Nookipedia 官方 wiki）。

**经济系统结构**：

| 维度 | 设计 |
|---|---|
| 主货币 | 铃钱（Bell）——携带上限逐版本提升（初代 849,999；NH 满扩 4,059,999） |
| 副货币 | NH 起新增 Nook Miles（里程积分），通过每日任务 / 季节活动获得，可兑换机票 / DIY 手册 |
| 储蓄利率 | **零利率**——铃钱存袋里不会自然增长（口袋 / 钱包 / 信件夹三种存储方式，利率都为 0） |
| 玩家余额约束 | 经典"99,999 单袋 × 多袋"上限，迫使玩家**经常花出去**而非囤积 |

**大头菜市场（Stalk Market）**——本游戏最重要的财商教育素材：

**机制要点**（Nookipedia "Stalk Market" + "Turnip" 词条可核实）：

| 维度 | 规则 |
|---|---|
| 买入窗口 | 每周日上午（NH 改为 5 AM 之前），找 Joan（NH 改找 Daisy Mae）买入，买入价 90-110 Bell/颗，**仅可整 10 颗一组** |
| 卖出窗口 | 周一至周六，分"上午 / 下午"两个时段（自 Wild World 起）卖给 Tom Nook / Reese / Nooklings |
| 价格波动模式 | 随机涨价 / 随机跌价 / 随机冲高 / 大幅冲高 / 周末归零——NH 版本有 4 种模式（Decreasing / Small spike / Large spike / Random） |
| NH 峰值区间 | **20-660 Bell/颗**；Large Spike 模式峰值可达购入价 200%-600% |
| 强制过期 | **下一周日 5 AM（NH）/ 6 AM（早期作品）前未售出 → 全部变为 spoiled turnips**；NH 中 spoiled 转售价仅 100 Bell/颗（≈购入价下限，亏损 9-90%） |
| 跨岛套利 | 可带去朋友 / 联机岛出售，价格按本岛时钟 |

**经济意义**：

- **强制过期 = 负利率**——玩家必须在本周内完成"买入 → 等待 → 卖出"决策，否则强制亏损。这是**财商教育最稀缺的一课**："持有期判断 + 沉没成本 + 概率博弈"。
- **零利率储蓄** = 玩家没有"无风险收益"选项，逼玩家进入风险市场。
- **价格区间 90-110（购入）+ 20-660（峰值）** = 玩家实际面对的"高波动资产"，与真实世界散户炒短线 / 期货高度同构。
- **跨岛套利** = 真实世界的**跨市场套利**（A 股 vs H 股、美元 vs 离岸人民币、加密所 vs 法币所）。

**真实世界映射**：

- 大头菜 ↔ 资产价格泡沫与到期强制平仓（散户参与门槛设计）。
- 强制过期 ↔ 期权到期日（实值/虚值判断）/ 短期理财产品的资金占用惩罚。
- 零利率 ↔ 现金为王的隐性成本。

### 2.4 Roblox——Robux 汇率不对称 + 创作者经济（DevEx）

**背景**：美国 Roblox Corporation 2006 年上线的全球最大多人在线游戏创作平台，被中文媒体称为"元宇宙第一股"。**截至 2025-09 日活超 1.118 亿、同时在线峰值突破 4500 万**（百度百科"Roblox"词条可核实）；2025-12 被俄罗斯联邦正式封禁。

**经济系统结构**（百度百科"Roblox"词条"虚拟货币 / 会员资格"节可核实）：

| 维度 | 设计 |
|---|---|
| 主货币 | Robux |
| 副货币（已废弃） | Tix（每日登录获得，可换 Robux，**已移除**） |
| 充值档位 | Premium 三档：**35 元 / 70 元 / 140 元人民币**（月），分别获 450 / 1000 / 2200 Robux |
| 创作者 | 通过开发者中心（DevEx）申请提现（**DevEx 抽成 ≈ 30% 平台留成**为社区广泛报道数值，本会话无法核实 Roblox 官方政策原文，**待核实**） |
| Premium 加赠 | 买 Robux 多得 10%、可转售物品与玩家作品、Premium 间互市 |

**汇率不对称**——Roblox 创作者经济最重要的设计：

- **玩家买入 Robux**（充值 35 元得 450 Robux ≈ **0.078 元/Robux**）。
- **创作者兑换回法币**（DevEx 提现通常 **≈ 0.005-0.01 美元/Robux**，再扣除平台分成），创作者端单价 ≈ 玩家端单价的 1/3 到 1/2（**精确数值本会话不可核实，待核实**）。
- **平台抽成**——开发者卖物品收入 100% 进 Robux 钱包，但提现时平台抽走一定比例。
- 这种**双向汇率不对称**让平台从玩家端（充值）与创作者端（提现）双向获利，是 Roblox 财务模型的核心（Roblox 上市文件 招股书 2021 年公开版本可查，**原始 URL 待核实**）。

**创作者经济的现实映射**：

- 知识付费（公众号/视频号/小红书抽成）。
- 直播打赏（抖音/B 站 50% 抽成）。
- 应用商店（Apple/Google 30% 抽成）。
- 跨境电商平台（亚马逊/Shopee 8-15% 抽成 + FBA 仓储）。

**Roblox 额外约束**（百度百科"Roblox"词条可核实）：

- 2023-07-21 约 4000 名开发者个人信息泄露（姓名/电话/邮箱/出生日期/实际地址）。
- 2024-11 起禁止 13 岁以下儿童在平台上向他人发送消息（除非父母同意）。
- 2025-12 推出 AI 面部年龄估算技术强制年龄验证（误判率超 5%）。
- 2026-03 起印尼将禁止 16 岁以下儿童在高风险平台开账户，首批列入 Roblox。
- 2026-07-29 起 Roblox 与 ChatGPT 在欧盟因月活超 4500 万门槛将进入最严内容监管框架。

**财商流游戏的迁移价值**：平台抽成率（创作者经济）+ 充值档位 + Premium 福利溢价机制，可直接套到"内容创作 / UGC 任务 / 玩家导师"系统里。

### 2.5 Second Life——Linden Dollar 锚定美元 + 虚拟土地拍卖

**背景**：Linden Lab 2003 年上线、2006 年爆发的"3D 元宇宙先驱"——曾因虚拟土地天价拍卖、虚拟物品市场市值超过数百万美元而登上主流财经媒体头条（**精确拍卖数字 Dreamland $100 万美元地块、Ansche Chung 百万美元收入**等具体案例，本会话因 Wikipedia 不可达，全部**待核实**）。

**经济系统结构**：

| 维度 | 设计 |
|---|---|
| 主货币 | Linden Dollar (L$) |
| 锚定 | 长期维持 ≈ 250-300 L$ = 1 USD 的窄幅汇率区间（用户可在 LindeX 内盘挂单交易，本质是 Linden Lab 运营的场内外汇市场） |
| 充值通道 | 通过 PayPal / 信用卡买入 L$，或做任务 / 卖内容挣 L$ 后通过 DevEx（$ 等值门槛）提现 |
| 创作者经济 | 居民自建 3D 内容、皮肤、动画、土地上盖物，可在 LindeX 出售 |
| 土地 | 私有岛屿（Sim）拍卖 / 整岛租赁；2006 年单地块曾报出 100 万美元成交价（**待核实**） |

**治理与争议**：

- **Linden Lab 主动做市**维持 L$/USD 汇率稳定，类似央行的外汇干预（**精确干预手段与历史汇率曲线待核实**）。
- 2006 年 Linden Lab 推出 100% L$ 买地的硬政策，引发"金融化"争议，被彭博、纽约时报等报道。
- **虚拟物品交易所"虚拟产权"的法律地位**——至今仍是各国司法管辖的灰色地带，财商流游戏设计必须考虑虚拟物品的"物权"模型。

**真实世界映射**：

- L$ 锚定 USD ↔ 港币联系汇率制度（7.75-7.85 区间）。
- Linden Lab 做市 ↔ 香港金管局干预港币汇率。
- 虚拟土地拍卖 ↔ 真实世界土地财政 / 房地产泡沫（参考《另类资产收藏品与金融泡沫史资料》"君子兰"案例）。
- 居民自建内容交易 ↔ UGC 平台经济 / 创作者经济。

### 2.6 中文语境：梦幻西游 + Q 币——点卡经济、藏宝阁与未成年人限额

**梦幻西游（NetEase）**：

- **2003-12-18 公测**（百度百科"梦幻西游"词条可核实），是网易迄今运营时间最长、生命力最强的 MMORPG 之一。
- **点卡制度**：2003-2024 长期按点卡收费（4-6 元/小时，具体牌价随时间波动，**精确档位待核实**），玩家付费获取"游戏时间"是典型 sink。
- **金价与游戏内经济**：游戏内金币（"梦幻币"）通过打怪 / 任务产出，**消耗**包括装备打造、子女养育、商城消耗、点卡续费（用游戏内金币代替现金续月卡的"寄售点卡"机制）。
- **藏宝阁**：网易官方 C2C 交易平台，玩家可在藏宝阁挂卖游戏币、装备、召唤兽、角色；其他玩家用法币（人民币）买入后游戏内直接到账。**这是中国大陆首款官方允许的 RMT 通道**——把 RMT 从灰色产业链拉回平台自营。本会话因 baike 主体词条"藏宝阁"为多义词消歧页，**未拿到藏宝阁完整词条**，**精确抽成比例、交易费、封号政策待核实**。
- **经济学外部叙事**：百度百科"梦幻西游"词条收录多篇分析（如外卖小哥靠游戏买房等案例），描述梦幻西游 20 年稳定运营与点卡经济的高度自洽性，**单篇外部分析具体 URL 待核实**。

**Q 币（Tencent）**：

- **2002-05 推出**（百度百科"Q币"词条可核实），官方兑价 **1 Q币 = 1 元人民币**。
- 早期是腾讯生态（QQ 秀 / QQ 会员 / QQ 游戏）的统一充值代币，**Q 币永不过期**。
- 充值限额（**国家新闻出版署强制**，2024-2025 实施）：未满 8 周岁无法充值；8-16 岁单次 50 元/月 200 元；16-18 岁单次 100 元/月 400 元。
- **历史事件**：
  - **2006-11 央行公开关注**——Q 币是否构成虚拟货币、是否违反《人民币管理条例》。腾讯回应"Q 币仅是统计代码、非货币"（**该条已联网核实，但央行原始公告 URL 待核实**）。
  - **2022-05 腾讯大面积取消 97 折充值优惠**——QQ 会员 / 超级会员 Q 币充值优惠同步下调，被视为 Q 币线下实体点卡销售体系式微的标志性事件（界面新闻报道，**URL 待核实**）。
  - **2025 郑州法院案例**——12 岁儿童误充 2000 Q 币案件，法院判决监护人未妥善管理支付密码 50% 责任 + 商家未尽提示义务 50% 责任。
- **Q 币 vs 加密货币**：百度百科明确点名"电子加密货币圈中的 QQCoin 与本 Q 币无关联"——这条澄清对财商流游戏处理"游戏内币 vs 区块链资产"边界很关键。

**财商流游戏的迁移价值**：

- 藏宝阁 = "官方认可的人民币计价 C2C 市场"——财商流游戏如果开放法币入场，必须先建好这道防火墙（防洗钱、防未成年、防 RMT 击穿游戏内经济）。
- Q 币限额政策 = 财商教育天然的"未成年人财商学习"边界。

## 3. RMT 与打金产业

### 3.1 定义与历史

RMT（Real Money Trading，真实金钱交易）指**玩家用真实法币买卖游戏内虚拟物品 / 货币 / 账号**的行为；"打金"是 RMT 中"以劳动换虚拟货币"的子集。

百度百科"打金"词条给出双义项：
1. **传统金银首饰制作工艺**（始于春秋战国，雷州半岛、潮州帮师徒传承制）——与本文件无关。
2. **游戏术语**：在网络游戏中赚取游戏金币或装备，通过互联网卖给时间宝贵的玩家换取真实货币。

### 3.2 劳动经济学侧面

RMT 之所以长期存在，并非单纯"灰色产业 + 玩家偷懒"——它本质是**虚拟经济与真实经济之间存在汇率差**，而这个汇率差由以下三个因素叠加：

1. **时间机会成本不对称**：发达国家玩家 1 小时劳动可买发展中国家玩家 100 小时游戏产出（如 WoW 金币）。
2. **游戏内通胀与官方回收不充分**：金币不断产出会贬值，但官方 sink 不够 → 玩家倾向于把过剩金币换成法币离场。
3. **平台不提供合规兑换通道**：暴雪 2015 年之前不允许官方换金币，所以第三方 RMT 市场长期繁荣。

### 3.3 监管与封号

- **暴雪**：长期封号 + ban wave（一次性封禁几万账号），2015 年 WoW Token 上线后转向"内化 RMT"。
- **腾讯**：通过游戏信用分 + 收益上限 + 同 IP 检测 + 设备指纹等多重风控；网易藏宝阁则是把 RMT 拉到平台内。
- **Roblox**：通过 Premium 转售机制 + DevEx 提现门槛 + KYC，把创作者经济关进合规框架。

### 3.4 中国打金工作室

百度百科"打金"词条与"游戏术语"节确认了"通过互联网将虚拟物品贩卖给时间宝贵的玩家换取真货币"这一定义。**具体规模数字（年产值、从业人数）本会话无法核实权威来源**——2010s 多份学术论文与行业报告估算中国打金产业年产值 10-30 亿美元区间（**具体数字待核实**）。

### 3.5 RMT 与"外挂 / 工作室"边界

RMT 通常与"使用外挂 / 自动化脚本 / 多开农场账号"绑定，因为纯人工打金的边际产能远低于脚本；这也是为什么暴雪 ban wave 几乎从不区分"打金者"与"外挂使用者"——**只要批量登录就触发反外挂系统**。网易藏宝阁的反作弊机制相对更复杂，因为它既要允许 RMT（这是官方合法生意）又要打击外挂（非合规产能）；常见的判别维度是"产出是否经过正常游戏行为链"——比如 NPC 任务、师门任务、副本掉落被视为合规产能，而脚本多开 / 重复走位 / 异常交易时序被视为外挂产能。**财商流游戏如果开放人民币入场，第一道风控就是建立这条"合规产能 vs 非合规产能"的判别线**。

### 3.6 财商映射

- RMT 汇率差 ↔ 国际收支失衡 / 套利资本流动。
- 暴雪封号 ↔ 反洗钱（AML）/ 反恐怖融资（CFT）执法。
- WoW Token ↔ 外汇管制下的合规兑换通道（央行指定机构）。
- 跨境打金 ↔ 服务贸易顺差（中国电竞 / 游戏出海）。
- 网易藏宝阁模型 ↔ 国内合规 C2C 二手平台（闲鱼、转转）的资质审核。

## 6. 对财商流游戏的落地建议

每条建议**标注落地位置**（即写入哪份现有设计文档的哪一节）：

1. **设立"游戏内经济月报"（Game MER）**：把财商流游戏每月公开一次"游戏内币种发行量 / 玩家交易额 / 销毁比例 / 通胀指数"，映射到《财商流游戏规则与经济系统》第 3 章（货币系统）的"透明度承诺"段落。该机制参考 EVE MER。
2. **双货币系统**：人民币（法币入口）+ 游戏内软通货（黄金 / 银票 / 铜钱三类）+ 游戏内硬通货（充值积分）。三层映射到《财商流游戏规则与经济系统》第 3 章。EVE ISK vs Aurum、Roblox Robux 都是双货币参考。
3. **官方兑换 Token**：财商流游戏上线 1 年内推出"游戏内金币 → 限定周边/会员时长"单向兑换通道，参考 WoW Token / EVE PLEX。落地位置：《财商流游戏规则与经济系统》第 11 章（玩家经济）。
4. **强制过期机制**：玩家持有的"特殊投资品"（如大富翁卡 / 限定道具）若 N 周期未参与流通则按 M% 折扣被系统回购。参考动森大头菜机制（最强参考）。落地位置：《财商流游戏规则与经济系统》第 6 章（8 类投资品）。
5. **零利率储蓄 + 携带上限**：玩家钱包有上限、储蓄账户利率为零，强制玩家参与风险市场。落地位置：《财商流游戏规则与经济系统》第 3 章（货币系统）。
6. **未成年人充值限额**：按 Q 币实名限额实施——8 岁以下不可充值、8-16 岁单次 50 元/月 200 元、16-18 岁单次 100 元/月 400 元（已有合规先例）。落地位置：《财商流游戏规则与经济系统》第 11 章（玩家经济与未成年人保护）。
7. **平台抽成模型**：财商流游戏允许玩家自创"课程 / 任务包 / 投资策略"，并通过 DevEx 提现，平台抽成 30%（参考 Roblox 行业惯例）。落地位置：《财商流游戏社交资本与信用体系设计》第 6-7 章（玩家导师 / UGC）。
8. **拍卖行抽税**：拍卖行 / 二手市场按成交额 X%（建议 5-10%）抽税，作为游戏内 sink 的稳定来源。落地位置：《财商流游戏交易拍卖与企业经营设计》第 2 章（拍卖基础规则）。
9. **跨市场套利教学任务**：玩家故意开放"友好岛屿"（动森跨岛套利）或"跨服市场"，让玩家体验套利机会与套利消失过程，作为财商教育案例。落地位置：《财商流游戏行为金融与投资心理机制设计》第 4 章（市场异象）。
10. **RMT 防火墙**：禁止人民币 ↔ 游戏内金币的直接官方兑换通道；玩家可在平台官方"周边商城"用游戏内金币换限定实物（参考梦幻西游藏宝阁但只允许单向兑换实物，不允许反向人民币购游戏币）。落地位置：《财商流游戏规则与经济系统》第 11 章。
11. **货币销毁可视化**：玩家舰船 / 房屋 / 工具被破坏时给出"X 元游戏币从流通中永久销毁"提示，强化货币稀缺感。落地位置：《财商流游戏规则与经济系统》第 3 章。
12. **跨周期投资品衰减曲线**：玩家投资的"古董 / 名酒 / 收藏品"在 N 周期后自动贬值（参考动森大头菜强制过期），但保留"提前套现"接口供主动型玩家退出。落地位置：《财商流游戏规则与经济系统》第 6 章（8 类投资品）。
13. **央行模拟器（高级扩展）**：财商流游戏"教学关"中可设一个**AI 央行**角色，让玩家面对"游戏内经济过热"时选择加息 / 加税 / 公开市场操作 / 强制缩表等政策；玩家在博弈中理解真实货币政策的两难（参考 EVE MER + 现实中央银行货币政策报告）。落地位置：《财商流游戏宏观经济与政策模拟类游戏资料》对应章节（与本系列并列的"宏观经济与政策模拟"线交叉）。
14. **玩家产能审核机制**：当人民币入场通道开启时，必须先建立"合规产能 vs 非合规产能"判别线（参考 §3.5 网易藏宝阁的反外挂与 RMT 审核模型）。落地位置：《财商流游戏规则与经济系统》第 11 章（玩家经济 + 风控）。
