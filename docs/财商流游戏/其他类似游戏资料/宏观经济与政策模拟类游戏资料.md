## 1. 调研范围与本文件定位

### 1.1 知识库的「宏观层」缺口

财商流知识库已有的 7 份资料覆盖了从个人理财到企业经营的多层内容，但**全部集中在「微观层」与「中观层」**：

| 已有资料 | 覆盖层次 | 核心机制 |
|---|---|---|
| 富爸爸现金流 101/202 | 微观·个人 | 工资、被动收入、资产负债表 |
| 财富流沙盘 | 微观·人生 | 顺/逆流事件、关系与金钱观 |
| 时空流沙盘与中文现金流改编 | 微观·改编 | 时间维度、本土化职业 |
| 大富翁 + 人生之旅 + Power Grid + Catan + Acquire | 微观·交易 | 地产垄断、掷骰移动、资源兑换 |
| 拍卖议价与股票市场类 | 微观·市场 | 拍卖、做空、投机、信息不对称 |
| 商业经营与企业模拟类 | 中观·企业 | 供应链、产能、产业链经营 |
| 中文本土财商沙盘 | 微观·本土 | 觉商/幸福/罗盘/ERP 沙盘 |

**缺口（本文件填补）**：玩家扮演「政策制定者」、或游戏内建**完整宏观经济反馈回路**的作品。财商流目前的「市场周期系统」是简化的骰子驱动周期表，缺乏内在因果链。本文件的核心价值即：**把宏观经济的真实因果机制（利率→资产价格→就业→通胀→政策反应）如何被游戏化，提炼成可移植的机制。**

### 1.2 与已有资料的边界

- **不重复**：大富翁的掷骰移动、Catan 的资源交易、FCM 的企业经营、Brass 的借贷链、Container 的货柜投机——这些在对应资料中已详尽，本文件只在「范式谱系」表中作为「微观市场清算型」对照一行。
- **只聚焦**：当一款游戏（如 Victoria 3）既有微观经营又有宏观价格发现时，本文件**只写其宏观层（供需价格发现、产业链通胀传导）**，不写其战斗/外交。
- **重点投入**：Beer Game（系统动力学延迟反馈）与「财商流升级建议」两节写得最细，因为二者对「把骰子周期升级为有因果链的系统」最有直接借鉴价值。

### 1.3 建模范式总览（先行预告）

本文件将所调研对象归入五种建模范式，第 11 节有完整对比表：

| 范式 | 代表 | 一句话特征 |
|---|---|---|
| 目标函数型 | Chair the Fed、£conomia、Fiscal Ship | 给定目标（通胀 2%、债务/GDP），调一个/几个旋钮逼近目标 |
| 政策网络型 | Democracy 3/4 | 一张有向因果图，政策牵一发动全身 |
| 系统动力学型 | Beer Game | 延迟 + 反馈导致的振荡/失真，而非均衡 |
| 市场清算型 | Victoria 3、EU4 | 供需自动出清，价格作为信息载体 |
| 实验博弈型 | 资产泡沫/公共品/最后通牒/公地悲剧 | 观察真实人在规则下的非理性集群行为 |

## 2. Chair the Fed（旧金山联储 · 美联储主席模拟器）

### 2.1 背景与开发方

- **开发方**：美国联邦储备银行旧金山分行（Federal Reserve Bank of San Francisco，简称 SF Fed）的经济教育部门。
- **推出时间**：公开资料普遍记为 **2014 年前后**上线（具体月份公开资料未能验证，标注为推测）。该游戏是一套基于网页的互动模拟器，面向中学生、大学生与公众普及美联储的双重使命（dual mandate）。
- **现状**：截至本次调研（2026-09），SF Fed 官网的 `/education/` 页面已**不再直接挂出 Chair the Fed 链接**（实测 `/education/publications/chair-the-fed/` 返回 404）。游戏很可能已被改版、下线或并入新的教学资源。**因此本节的玩法细节主要依据公众常识与过往报道，未能从官方实时页面核验，标为「权威二手/公众常识」。**

> 来源可信度：公众常识 + 过往媒体报道（具体页面无法实时访问）。下列涉及具体数值处均标「近似/推测」。

### 2.2 核心模型与变量

| 变量 | 角色 | 说明 |
|---|---|---|
| 联邦基金利率（Federal Funds Rate） | **玩家唯一/主要操控旋钮** | 玩家每期设定利率目标 |
| 通胀率（Inflation） | 目标变量 | 美联储双重使命之一，锚定 2% |
| 失业率（Unemployment） | 目标变量 | 双重使命之二，锚定「自然失业率」（NAIRU，游戏内常设为约 5%，近似） |
| 产出缺口（Output Gap） | 状态变量 | 驱动通胀与失业变化 |
| 利率 → 经济 | 传导 | 加息抑制需求→通胀降、失业升（滞后） |

**目标函数（教学化泰勒规则）**：游戏把约翰·泰勒（John Taylor）的泰勒规则直觉简化为「双目标打分」——玩家要在「通胀偏离 2%」与「失业偏离自然率」之间权衡。利率定得太低→通胀失控；定得太高→失业飙升。最优解大致落在泰勒规则给出的中性利率附近。

### 2.3 玩法流程

> ✅ 以下细节已根据 SF Fed 官方教学 PDF（2026-09-10 联网核验）补全。

1. 玩家被任命为「美联储主席」，游戏内决策周期为**季度**，总时长约 **4 年（16 个季度）**。
2. 每季度初面对一组宏观经济读数（通胀率、失业率、GDP 增速），与美联储目标对比。
3. 玩家决定本季度联邦基金利率——**上调、下调或维持不变**。
4. 系统以**滞后若干期**的方式让经济响应（利率不会立刻生效，模拟政策时滞）。官方教学要点：上调利率倾向于推高失业、降低通胀；下调利率反之。
5. 若干季度后游戏以公告画面结束：「Congratulations」表示经济保持在目标附近（通胀接近 2%、失业接近自然率），「Sorry」表示未达标。
6. 提供多种情景（如石油冲击、金融危机）考验稳健性。

> [来源: https://www.frbsf.org/wp-content/uploads/sites/2/CTF_Activity_Introduction.pdf ; https://www.frbsf.org/wp-content/uploads/sites/2/CTF_Activity_EconomyOnTrack.pdf ; https://www.frbsf.org/wp-content/uploads/CTF_Datasheet_EconomyOnTrack.pdf]

### 2.4 反馈回路与因果链

```
玩家加息 ──(+时滞)──> 总需求↓ ──> 通胀↓、失业↑
    ↑                                          │
    └──── 若失业过高则玩家被迫降息 ────────────┘
玩家降息 ──(+时滞)──> 总需求↑ ──> 通胀↑、失业↓
    └──── 若通胀过高则玩家被迫加息
```

要点：**时滞是教学核心**——玩家若等「看到通胀才反应」往往已晚，因为政策要几期才生效，这正是真实货币政策「前瞻指引」难点的游戏化。

### 2.5 教育意图

- 让公众理解美联储「双重使命」的内在冲突。
- 直观展示「政策时滞」为何导致经济波动。
- 用分数机制内化泰勒规则「中性利率」概念。

### 2.6 对财商流的可借鉴点

- **状态机的「政策旋钮」思路**：财商流可由「银行家/Agent 央行」持有一个利率旋钮（对应 LPR），玩家无法私自改利率，只能响应。
- **双重目标打分**：把「资产价格稳定 + 就业/收入增长」设为宏观系统健康度两项指标，避免只用单一通胀。
- **时滞机制可移植**：利率调整后，资产估值变化分 2–3 期逐步体现，正好对应财商流棋盘的「结算延迟」。

## 3. £conomia（英格兰银行 · 货币政策模拟游戏）

### 3.1 背景与开发方

- **开发方**：英格兰银行（Bank of England，英国央行）。
- **推出时间**：公开资料记为 **2014 年**（近似，未能从官方实时页面核验；本次实测 BOE 站点 `/education/£conomia` 已 404，原游戏页似已下架/改版）。
- **形式**：网页互动游戏，玩家扮演英国财政大臣（Chancellor）或货币政策决策者，在通胀目标制框架下做决策。

> 来源可信度：公众常识/过往报道，未能从官方实时页面核验，标「权威二手」。

### 3.2 核心模型与变量

| 变量 | 说明 |
|---|---|
| 通胀率 | 目标 2%（与 BOE 实际法定目标一致，已通过 BOE 官方「Inflation and the 2% target」页核实） |
| 失业率 | 次要目标，越低越好但受政策牵制 |
| 利率（Bank Rate） | 主要政策工具 |
| 公众/媒体/「行长」反馈 | 游戏内置叙事反馈，模拟政策公信力 |

**已核实事实**：英格兰银行确实以 **2% 通胀目标**为法定框架（来源：Bank of England 官方「Inflation and the 2% target」页，本次实测可访问，标注为官方资料）。

### 3.3 玩法流程

1. 玩家设定利率与相关政策。
2. 系统演算通胀与失业走向。
3. 「英格兰银行行长」以剧情化方式对玩家决策给出评价（如「你让通胀失控了」）。
4. 多回合后评估是否守住 2% 目标且经济不衰退。

### 3.4 反馈回路与因果链

与 Chair the Fed 同属「目标函数型」，但 £conomia 增加了**叙事化反馈**（行长/媒体反应），强化了「政策可信度」维度——这比纯分数更接近真实央行面临的沟通约束。

### 3.5 教育意图

- 普及英国通胀目标制。
- 说明「为什么央行不能只盯增长」。
- 用角色扮演降低货币政策的距离感。

### 3.6 对财商流的可借鉴点

- **「银行家/Agent 央行」的叙事外壳**：财商流的 Agent 央行可借鉴 £conomia 的「行长点评」机制，每期用一句话点评宏观状态（如「信贷过热，警惕泡沫」），增强沉浸感。
- **2% 锚定目标**可作为财商流「宏观健康度」的参照模板。

## 4. Fiscal Ship（布鲁金斯学会 + 伍德罗·威尔逊中心 · 财政可持续性模拟）

### 4.1 背景与开发方

- **开发方**：布鲁金斯学会（Brookings Institution）与伍德罗·威尔逊国际学者中心（Woodrow Wilson Center）的「严肃游戏」项目联合开发。
- **推出时间**：公开资料记为 **2016 年**（近似）。
- **官网现状**：`fiscalship.org` 本次实测可访问（返回 200），但页面为 JavaScript 动态渲染（抓取正文仅见「The Fiscal Ship Loading...」），**具体玩法细节未能从源码直接提取**，以下依据公众常识与官网标题推断，标「权威二手」。

> 来源可信度：官网可达（动态页无法静态提取）+ 公众常识。

### 4.2 核心模型与变量

| 变量 | 说明 |
|---|---|
| 债务 / GDP 比（Debt-to-GDP） | **核心可持续目标**，玩家要把它降到可持续轨道 |
| 联邦支出项目 | 国防、社保、医保、教育、基建等 |
| 联邦税收 | 所得税、公司税、消费税等 |
| 利益集团/价值观约束 | 削减某支出会引发特定群体不满（类比 Democracy 的选民） |

### 4.3 玩法流程

> ✅ 以下细节已根据 Fiscal Ship 官网及教学资料（2026-09-10 联网核验）补全。

1. 玩家扮演「舵手」，目标：把美国联邦财政放上可持续轨道。
2. **胜利条件（已核验）**：将 2041 年预测债务/GDP 比从基线的 **126%** 降至 **75%**。
3. 玩家首先从菜单选择若干「执政目标」（如"加强国防""投资教育""减税"等），这些目标构成政治约束——不能削减与目标冲突的项目。
4. 然后在众多政策杠杆（增税、削支、改革）中组合选择，系统演算 debt/GDP 轨迹。
5. 在「财政可持续」与「政治可接受」之间找平衡。提交方案后系统给出达成进度百分比。

> [来源: http://fiscalship.org/about.php ; https://dev3.ngpf.org/blog/policy/interactive-balance-the-uss-budget/ ; http://teach.fiscalship.org/EduLandingPage_FiscalShip_files/classroom_guidelines.pdf]

### 4.4 反馈回路与因果链

```
增税/削支 ──> 短期债务率↓ 但 特定群体支持率↓
    │                                  │
    └──── 政治反弹限制可改革幅度 ──────┘
支出刚性（社保/医保）──> 结构性赤字难消 ──> 债务率长期攀升
```

### 4.5 教育意图

- 揭示「财政可持续性」不是单一开关，而是政策组合。
- 让玩家体会「任何削减都有受益/受损方」的政治现实。
- 解释为何 debt/GDP 比会自我加速（利息滚雪球）。

### 4.6 对财商流的可借鉴点

- **「利益集团约束」可移植为财商流的「监管/民意」维度**：当玩家集体过度投机，触发「监管收紧事件卡」——本质是 Fiscal Ship 政治约束的微观版。
- **债务自我加速机制**可直接用于财商流「信贷松紧」：高杠杆玩家群体推高系统性风险，导致银行收紧信贷（利率被动上行）。

## 5. Budget Hero（美国公共广播 APM · 联邦预算取舍游戏）

### 5.1 背景与开发方

- **开发方**：美国公共媒体（American Public Media，APM），由其「Marketplace」节目团队制作。
- **推出时间**：公开资料记为 **2008 年**（近似，与金融危机时期公众关注预算相吻合）。
- **现状**：`budgethero.org` 与 `marketplace.publicradio.org` 本次实测均**无法访问（000/死域名）**，游戏基于 Flash，已基本下架。**本节全部依据公众常识，标「公众常识/未能验证」。**

### 5.2 核心模型与变量

| 变量 | 说明 |
|---|---|
| 联邦预算天平 | 收入（税）vs 支出（项目） |
| 多目标 | 平衡预算、投资未来、减税、国防等可勾选目标 |
| 时间轴 | 模拟未来数十年预算走向 |

### 5.3 玩法流程

1. 玩家从菜单勾选政策目标（如「平衡预算」「增强国防」）。
2. 调整税收与支出杠杆。
3. 系统即时显示预算等式是否平衡、目标是否达成。
4. 揭示「鱼与熊掌」：想减税又想增支必然失衡。

### 5.4 反馈回路与因果链

相对简单：**线性预算约束**（收入 = 支出 + 赤字），没有 Fiscal Ship 那样的动态债务滚雪球，属于「静态取舍」而非「动态推演」。

### 5.5 教育意图

- 普及「没有免费午餐」的预算常识。
- 让公众直观体验联邦预算的零和取舍。

### 5.6 对财商流的可借鉴点

- **轻量级「目标勾选 + 即时反馈」**适合财商流简化版：玩家设定「本局目标（如 5 年内现金流转正）」，系统即时提示是否可行。
- 作为「简化版」的参照：不做复杂动态，只做即时约束反馈。

## 6. Beer Distribution Game / 啤酒游戏（MIT Sloan · Sterman · 系统动力学）

> **本节为本文件最重要的部分**（用户指定）。所引结构、规则、牛鞭效应机制均来自 `beergame.org` 官方站点（本次实测可访问，提取自其 Structure & Rules / Bullwhip Effect / Typical Results 三页），标注为**官方资料**。

### 6.1 背景与开发方

- **起源**：啤酒游戏（Beer Distribution Game，简称 Beergame）由**麻省理工学院斯隆管理学院（MIT Sloan）**在 1960 年代基于杰伊·福瑞斯特（Jay Wright Forrester）的「工业动力学 / 系统动力学（System Dynamics）」框架开发。
- **教学推广**：约翰·斯特曼（John Sterman，MIT 系统动力学 Group 负责人）在其著作《Business Dynamics》与大量教学中将之普及，成为系统思考（Systems Thinking）的经典教具。
- **站点**：`beergame.org` 由学者 Kai Riemer 维护，提供教学软件与规则材料，明确说明其用于「展示缺乏系统思考与信息共享时供应链典型的协调问题」。本次实测站点可访问，正文已提取。

> 来源：beergame.org 首页、Structure & Rules、Bullwhip Effect、Typical Results 四页（官方资料）。

### 6.2 核心模型与变量

| 要素 | 内容 |
|---|---|
| 供应链结构 | **四个阶段**：零售商（Retailer）→ 批发商（Wholesaler）→ 分销商（Distributor）→ 工厂（Factory） |
| 参与规模 | 每条链 8–12 人，每阶段 1 人（理想 2–3 人）；可并行多条链 |
| 唯一决策 | **每期只决定「向供应商订多少货」**（其余皆由规则决定） |
| 物流方向 | 订单向上游传递，啤酒向下游交付 |
| **关键延迟** | 每段运输/生产有 **2 个回合（rounds，模拟周）的时滞**（shipping delay） |
| 成本 | 库存（inventory）与缺货积压（backlog）均产生成本。**标准 MIT 版本**：库存持有成本 **$0.50/箱/周**，缺货积压成本 **$1.00/箱/周**（缺货成本约为持有成本的 2 倍，反映客户不满与失去收入）。不同教学版本可用不同数值。[来源: https://web.mit.edu/jsterman/www/SDG/beergame.html] |
| 时间尺度 | 典型一局 **40 周（rounds）** |

### 6.3 玩法流程（每回合固定 5 步）

据 beergame.org「Structure & Rules」页原文，每回合玩家依次：

1. **接收 incoming orders**（上游/客户发来的订单）
2. **接收 incoming deliveries**（上游发来的货物）
3. **更新 play sheet**（记录待发货物与库存/积压）
4. **发出 deliveries**（按库存能力向下游发货）
5. **决定本回合 order 数量**（唯一自主决策）

订单必须被满足：能直接发的从库存扣，不能的转为 backlog，后续补发。**库存与 backlog 都计费**——这正是冲突来源：玩家既怕缺货（backlog 成本+客户不满）又怕积压（库存成本）。

### 6.4 反馈回路与因果链（牛鞭效应的诞生）

```
客户在零售端出现一次性需求跃升（如 +4 箱/周）
   │
   ▼（2 周时滞后零售商才察觉）
零售商担心缺货 → 放大订单（如订 8）
   │（再 2 周时滞）
批发商看到订单激增 → 更放大（订 16）
   │
分销商 → 工厂 层层放大
   ▼
工厂疯狂扩产 → 数周后货物涌回 → 全链库存爆仓
   │
   ▼
需求早已回落 → 所有人同时砍单 → 崩溃/停产
```

**牛鞭效应（Bullwhip Effect）定义**（据 beergame.org「Bullwhip Effect」页原文）：需求在零售端的**小幅波动**，沿供应链向上游**被逐级放大**的现象；名称源于 P&G 在婴儿尿布供应链中观察到的「订单剧烈放大」。后果：高安全库存、低客户服务水平、产能利用失衡、预测失真、成本高企、企业间信任下降。

**典型结果**（据「Typical Results」页）：零售端对客户需求跃升有约 2 周时滞反应；随后各阶段订单**逐段放大**形成典型牛鞭；库存曲线显示玩家先陷入 backlog，待过度反应后第 20–30 周库存迅速填满；上游信息随层级衰减（平均订单量逐段递减，但**订单波动逐段递增**）。

### 6.5 教育意图

- **系统动力学核心课**：延迟（delay）+ 局部决策 → 全局振荡。
- 揭示「每个环节都理性，整体却失控」——个体最优 ≠ 系统最优。
- 说明**信息共享与协同**为何能消除牛鞭（beergame.org 软件即支持关闭信息共享以对比）。

### 6.6 对财商流的可借鉴点（**重点**）

这是与财商流「市场周期」升级**最直接相关**的作品，因为：

1. **「唯一决策 + 延迟反馈」的极简架构可照搬**：财商流中每个玩家每期只做一个核心决策（如「本月加/减杠杆、买/卖哪类资产」），但宏观结果要 2–3 期后才显现——完美对应啤酒游戏的 2 周时滞。
2. **牛鞭效应 → 资产价格泡沫的桌游化**：把「零售端小需求」换成「少数玩家买入某资产」，沿「散户→大户→市场情绪→资产定价」向上放大，形成价格泡沫；当信息失真（玩家只看到邻居行为）时必然过冲。
3. **羊群效应建模**：啤酒游戏证明「只看本地订单、看不到终端真实需求」必然导致放大。财商流可让玩家**只能看到自己所在圈层（生存/积累/自由）的局部信息**，从而自然涌现羊群与踩踏。
4. **延迟是泡沫/崩盘的根本原因**：利率下调后资产价格不会立即反应，等玩家「看到涨了再追」往往已是周期尾部——这正是财商流要教会玩家的「宏观时滞」。

## 7. Democracy 系列（Democracy 3/4，Positech）

### 7.1 背景与开发方

- **开发方**：英国独立游戏工作室 **Positech Games**，主创 Cliff Harris（克里斯·哈里斯）。
- **作品线**：Democracy 3（2013，近似）与 Democracy 4（2020 年前后，近似）。本次实测 `positechgames.com` **无法访问（000）**，以下依据公众常识，标「公众常识/权威二手」。

### 7.2 核心模型与变量

| 要素 | 内容 |
|---|---|
| **有向因果图（Directed Graph）** | 数百个变量（经济、犯罪、健康、教育、环境、民意等）互相连接 |
| 政策即「干预节点」 | 每项政策（如「提高燃油税」）向图中注入变化，沿边传导 |
| 选民模型 | 选民按意识形态、收入、年龄分组，对政策有不同敏感度 |
| 选举约束 | 支持率过低则下台，强制玩家在「做对的事」与「连任」间权衡 |

### 7.3 玩法流程

1. 玩家是国家领导人。
2. 每回合从政策菜单选择若干项推行/取消。
3. 系统沿因果图逐期演算：政策 → 中间变量 → 经济/社会指标 → 选民态度。
4. 维持支持率、避免破产、达成个人目标。
5. 多党/危机事件扰动系统。

### 7.4 反馈回路与因果链（政策网络型典范）

```
提高企业税 ──> 政府收入↑ 但 企业投资↓ ──> GDP↓ ──> 就业↓
    │                                              │
    └──── 选民(商人)不满↑ / 选民(劳工)满意↑ ──────┘
         └──── 支持率变化取决于选民结构 ──> 连任概率
```

核心是**牵一发动全身**：没有孤立旋钮，每个政策都同时改变多个下游，且存在二阶、三阶效应（如「减税→赤字→利率→投资」）。

### 7.5 教育意图

- 展示政策系统的「复杂适应性」——简单直觉常错。
- 训练系统思考与对「 unintended consequences（非预期后果）」的敬畏。

### 7.6 对财商流的可借鉴点

- **因果图可作为财商流宏观系统的后台引擎**：把「利率、CPI、失业率、资产价格、信贷」五节点及它们的边，定义成一张小型有向图（见第 12 节）。
- **选民/群体反馈**对应财商流的「玩家集体行为反作用于宏观」：当多数玩家加杠杆，系统变量被群体行为推动，而非仅由央行旋钮决定。

## 8. Victoria 3 / Europa Universalis IV 的经济系统（Paradox）

### 8.1 背景与开发方

- **开发方**：Paradox Development Studio（瑞典）。
- **定位**：大型历史策略游戏，其经济系统是「市场清算型」宏观建模的代表（非教学器，但机制极具参考价值）。本次实测 `paradoxplaza.com/victoria-3/` 返回 404，细节依据公众常识，标「公众常识」。

### 8.2 核心模型与变量（Victoria 3 为重点）

| 要素 | 内容 |
|---|---|
| **Pops（人口）与需求** | 不同阶层人口有各自消费篮子，构成需求侧 |
| **供需价格发现** | 商品在**国家级市场**中由供给与需求自动出清定价 |
| **建筑（Building）产业链** | 农场→小麦、煤矿→煤炭、工厂→工业品；上游产出是下游输入 |
| **生产方法（PM）** | 同一建筑可在「劳动力密集/资本密集」间切换，改变要素需求 |
| **贸易** | 国内供需缺口由国际贸易补足，影响价格与世界市场 |
| **GDP / 生活水平** | 由上述聚合得到 |

EU4 的经济较浅：以「贸易节点」「生产发展度」「关税」为主，缺少 V3 的供需价格发现，本文件**不展开 EU4**（仅作对照：EU4 偏宏观贸易拓扑，V3 偏微观供需出清）。

### 8.3 玩法流程（经济侧）

1. 建设/升级建筑，决定生产方法。
2. 人口消费产生需求，市场即时定价。
3. 价格信号引导资本流向高利润产业。
4. 贸易补足缺口，外部冲击（战争、发现新大陆）改变供需。

### 8.4 反馈回路与因果链（市场清算型）

```
某商品需求↑（如战争导致军需）──> 价格↑ ──> 该产业利润率↑
    │                                      │
    └──── 资本涌入扩产 ──> 供给↑ ──> 价格回落（均衡回归）
需求结构性下降 ──> 价格↓ ──> 产业萎缩 ──> 失业↑ ──> 消费↓
```

要点：**价格是信息载体**，玩家通过价格而非指令感知经济，系统自发达至均衡（或失衡）。

### 8.5 教育意图（非教学器但隐含）

- 展示「产业链依赖」与「价格作为协调信号」。
| 对比项 | 财商流可借鉴 |
|---|---|
| 建筑产业链 | 财商流「8 类投资品」可定义上下游（如房产依赖信贷松紧，信贷依赖利率） |
| 供需定价 | 资产价格由「玩家总买盘 vs 总卖盘」出清，而非固定表价 |

### 8.6 对财商流的可借鉴点

- **资产价格由玩家总供需出清**：财商流当前资产价格多由周期表给定；可改为「该类资产所有玩家买卖单汇总 → 系统定价」，玩家集体行为直接决定价格（与第 12 节「群体反作用」呼应）。
- **产业链依赖**：把 8 类投资品挂到利率/CPI 等宏观变量上，形成 V3 式传导。

## 9. 经济学课堂实验：行为经济学的真实实验室范式

> 本节对象不是「游戏产品」而是**经同行评审的实验室实验范式**。它们证明了「真实人在规则下的系统性非理性」，是财商流设计玩家行为机制的实证根基。细节为经济学常识，标「权威二手（教科书/经典论文）」。

### 9.1 Smith-Suchanek-Williams 资产泡沫实验（1988）

- **论文**：Smith, Suchanek, Williams (1988), *"Bubbles, Crashes, and Endogenous Speculation in Experimental Spot Asset Markets"*, Econometrica（实验经济学奠基性论文之一）。
- **设置**：被试交易一种有**已知分红（fundamental value 随时间线性衰减）**的资产。理性价格应等于预期分红现值。
- **结果**：价格**系统性地远超基本面**后崩盘——即「泡沫」。证明即使基本面透明，人仍会投机追涨。
- **对财商流**：资产可设「内在现金流」，但允许价格脱离基本面形成泡沫，玩家追涨杀跌即重现 SSW 实验。

### 9.2 公共品博弈（Public Goods Game）

- **设置**：N 人每组，每人私有一笔钱，可选择捐入公共池（加倍后平分）或自留。
- **纳什均衡**：所有人都应**不捐**（free-rider），但实验中人初期会捐，随后因看到他人搭便车而**合作崩塌**——揭示「自愿供给不足」。
- **对财商流**：可类比「集体抗风险/互助基金」——个体理性导致系统脆弱。

### 9.3 最后通牒博弈（Ultimatum Game）

- **设置**（Güth, Schmittberger, Schwarze, 1982）： proposer 分一笔钱，responder 接受则生效、拒绝则两人均无。理性均衡是 proposer 给极少、responder 接受。
- **结果**：responder 常**拒绝不公平分配（如 <30%）**，宁可两败俱伤，证明「公平偏好」非自私。
- **对财商流**：玩家间交易/议价可引入「公平阈值」，过低报价被拒，影响二手资产流动性。

### 9.4 共同池资源博弈 / 公地悲剧（Tragedy of the Commons）

- **理论**：Hardin (1968) 提出；Ostrom 通过实验/田野研究证明**制度可缓解**过度攫取。
- **设置**：多人共享一资源池（如渔场），每人独立决定抽取量，过度抽取则池枯竭。
- **结果**：无制度时普遍**过度开采**导致崩溃；引入沟通/规则后可维持。
- **对财商流**：把「信贷总额/市场流动性」视为共同池——玩家集体加杠杆=过度抽取，触发系统性危机；引入「监管共识」可缓解。

### 9.5 行为范式对照表

| 实验 | 核心非理性 | 财商流可映射机制 |
|---|---|---|
| SSW 资产泡沫 | 追涨杀跌、脱离基本面 | 资产价格泡沫/崩盘事件 |
| 公共品博弈 | 搭便车、合作崩塌 | 集体抗风险失灵 |
| 最后通牒 | 公平偏好、拒绝不公 | 玩家议价公平阈值 |
| 公地悲剧 | 过度攫取共有资源 | 信贷/流动性共同池枯竭 |

## 10. 可选补充：城市建造、生活模拟与国际组织教学器

### 10.1 SimCity / Cities: Skylines 的税收与经济模型

### 11.1 范式对比总表

| 范式 | 代表作品 | 玩家角色 | 操控方式 | 核心动态 | 反馈结构 | 教学强项 | 局限 |

### 11.2 五范式对「财商流宏观系统」的映射建议

| 财商流子系统 | 最适配范式 | 理由 |
|---|---|---|
| 央行/Agent 利率决策 | 目标函数型 | 一个 LPR 旋钮 + 双目标（价格稳定/就业） |
| 8 类投资品价格联动 | 市场清算型 | 玩家总买卖单出清定价 |
| 玩家集体加杠杆→泡沫 | 系统动力学型 + 实验博弈型 | 延迟+羊群+公地悲剧共同池 |
| 政策事件卡（限购/印花税） | 政策网络型 | 一项政策牵动多变量 |
| 周期状态机 | 目标函数型（状态化） | 美林时钟四状态转移 |

**结论**：财商流的宏观升级应是**「目标函数型为骨架（状态机+央行旋钮）+ 市场清算型为价格机制 + 系统动力学/实验博弈型为玩家行为涌现」的混合体**，而不应只抄某一款。

## 12. 财商流游戏「市场周期与宏观联动系统」升级建议

> 本节为全文最有价值部分。所有数值为**设计建议值（近似，需线下/线上实测校准）**，非真实经济数据，亦非已核验事实，请按「推测/近似」对待。机制方案分「简化版（线下手算）」与「完整版（线上 Agent 后台计算）」两套。

### 12.1 总体架构：从「骰子周期表」到「状态机 + 内生变量」

当前问题：骰子驱动的周期表是**外生随机**，玩家行为不影响周期，周期也不反作用于玩家决策，缺乏因果。

升级方向：

```
外生骰子  ──X 废除 ──>  改为：
[内生宏观状态机]  ──驱动──>  [五宏观变量]  ──传导──>  [玩家资产/现金流]
      ▲                                            │
      └──────── 玩家集体行为反作用 ────────────────┘
[央行/Agent 旋钮]  ──调节──>  [状态转移条件]
```

### 12.2 宏观状态机：美林时钟四状态 + 转移条件

定义 4 个宏观状态（复苏 / 过热 / 滞胀 / 衰退），每局宏观系统处于其一，按条件转移（每 N 回合评估一次，N 建议=3 期）。

| 状态 | 特征（建议标签） | 资产表现（建议） | 利率 | CPI | 失业 |
|---|---|---|---|---|---|
| **复苏 Recovery** | 低利率、需求回升 | 股票/房产温和上涨 | 低位 | 低位 | 下行 |
| **过热 Overheat** | 需求旺、物价涨 | 商品/房产领涨、股市见顶 | 上行 | >3%（建议阈值） | 低 |
| **滞胀 Stagflation** | 物价高、经济差 | 现金/黄金占优 | 高位僵持 | >4%（建议阈值） | 上行 |
| **衰退 Recession** | 需求萎缩 | 债券/现金占优、资产普跌 | 降息 | 回落 | 快速上行 |

**转移条件（建议，近似）**：

| 转移 | 触发条件（建议） |
|---|---|
| 复苏 → 过热 | CPI 连续 2 期 > 3% **且** 资产价格指数连续 2 期上涨 > 5% |
| 过热 → 滞胀 | 失业率上升 ≥ 1pct **且** CPI 仍 > 4% |
| 滞胀 → 衰退 | 央行被迫降息（利率已近 0 或资产价格单期跌 > 10%） |
| 衰退 → 复苏 | 利率降至低位 **且** 信贷松紧指数回升 **且** 资产价格 2 期企稳 |
| 任意 → 危机（特殊） | 玩家群体杠杆率 > 阈值（见 12.4）触发「系统性危机」事件 |

> 注：阈值数字（3%/4%/5%/10%/1pct）均为**设计起点建议**，须通过试玩调参。

### 12.3 宏观变量清单与传导系数（建议值，近似）

**核心五变量**：
1. **LPR（贷款市场报价利率）**——央行/Agent 旋钮，整数档位（如 3.0% / 3.5% / 4.0%…）
2. **CPI（通胀）**——由需求与货币供给驱动
3. **失业率**——由经济状态与利率驱动
4. **资产价格指数（API）**——房产/股票/黄金等加权
5. **信贷松紧（Credit Tightness, CT）**——由玩家总杠杆与银行风险偏好决定

**传导系数表（建议，近似，需校准）**：

| 因 → 果 | 建议系数 | 说明 |
|---|---|---|
| LPR ↑ 1%（100bp） | → 房产估值 **-8%** | 贴现率+月供压力（用户示例值，采用） |
| LPR ↑ 1% | → 股票估值 **-5%** | 股权风险溢价上升 |
| LPR ↑ 1% | → 企业利润 **-3%** → 失业率 **+0.3pct** | 融资成本高企 |
| CPI ↑ 1% | → 央行加息概率上升（泰勒式：加息≈0.5×(CPI-2%)+0.5×(失业-自然率)，简化） | 倒逼政策 |
| 失业率 ↑ 1pct | → 消费 **-2%** → 资产价格 **-3%** | 收入预期恶化 |
| 信贷松紧(CT) 放松 10%（社融增速+10%） | → 资产价格 **+6%**、CPI **+0.8%** | 流动性推升 |
| 资产价格指数(API) ↑ 20% | → 触发「限购/加息」预警（泡沫阈值） | 监管反应 |
| API 单期 ↓ > 10% | → 触发「衰退/危机」状态评估 | 崩盘反馈 |

**状态对各变量的基线漂移（建议，每期）**：

| 状态 | CPI 漂移 | 失业漂移 | LPR 倾向 | API 漂移 |
|---|---|---|---|---|
| 复苏 | +0.2%/期 | -0.2pct/期 | 维持 | +2%/期 |
| 过热 | +0.5%/期 | -0.1pct/期 | 上行压力 | +4%/期 |
| 滞胀 | +0.3%/期 | +0.3pct/期 | 高位 | -1%/期 |
| 衰退 | -0.2%/期 | +0.4pct/期 | 降息 | -3%/期 |

### 12.4 玩家行为如何反作用于宏观（牛鞭/羊群/公地悲剧的桌游化）

这是让系统「活起来」的关键——宏观不只由央行决定，也由**玩家集体行为**推动。

#### (a) 集体加杠杆 → 资产泡沫 → 破裂（公地悲剧 + 牛鞭）

- 定义 **群体杠杆率 GL** = 所有玩家总负债 / 总资产。
- 当 GL 上升（大家都在借钱买资产）→ CT（信贷松紧）被动**收紧**（银行风险偏好下降，利率上行压力）→ 但短期内资产价格因需求而**继续涨**（正反馈，羊群）。
- 当 GL 超过阈值（建议 **GL > 1.5**，近似）→ 触发「系统性风险」：下一期 CT 骤紧，利率跳升，API 单期 **-10%~-20%**，豪者（高杠杆玩家）最先爆仓。
- 这正是 Beer Game 牛鞭的「宏观版」：每个人的局部理性（借钱买房）汇总成全局泡沫。

#### (b) 羊群效应（SSW 泡沫实验 + 啤酒游戏信息局部性）

- 玩家**只能看到本圈层（生存/积累/自由）的局部交易热度**，看不到全市场真实供需。
- 当某类资产「持有玩家占比 > 60%」（建议阈值，近似）→ 该类资产进入「追涨加速」：每期额外 **+3%** 情绪溢价；但一旦占比回落或利空事件出现，情绪溢价 **-8%/期** 快速回吐。
- 对应 SSW 实验：价格脱离基本面（内在现金流）仍被追高，直至崩盘。

#### (c) 牛鞭在「圈层间」的传递

- 生存圈消费意愿 ↑（玩家普遍加消费）→ 传导至积累圈「投资品订单」↑ → 自由圈资产定价 ↑，且**逐层放大**（2 期时滞，呼应 Beer Game）。
- 设计上让「下游需求」对「上游资产价格」有放大系数（建议 1.5–2 倍，近似），制造周期性过冲。

### 12.5 政策事件卡设计（政策网络型 + 目标函数型结合）

每局设「宏观政策事件卡库」，由银行家/Agent 央行按状态触发或随机抽取，玩家可部分响应：

| 卡名 | 类型 | 效果（建议） | 触发语境 |
|---|---|---|---|
| **LPR 下调** | 货币宽松 | LPR -0.25%~-0.5%，CT 放松，API +3% | 衰退/复苏 |
| **LPR 上调** | 货币收紧 | LPR +0.25%，API -4%，抑制过热 | 过热 |
| **限购令** | 监管 | 单玩家持有某类资产上限，强制部分出售 | API 泡沫预警 |
| **印花税调整** | 交易税 | 买入印花税 +0.1% 抑制投机 / 免征刺激流动性 | 过热/衰退 |
| **降准/货币宽松** | 数量型 | CT 放松 10%，API +4% | 衰退 |
| **财政刺激** | 财政 | 失业 -0.3pct，CPI +0.5%，赤字↑ | 衰退/滞胀 |
| **监管收紧（去杠杆）** | 系统性 | GL 高时触发，CT 骤紧，利率跳升 | 群体杠杆超阈值 |
| **外部冲击**（石油/危机） | 外生 | CPI +1%，API -5%，失业 +0.3pct | 随机事件 |

> 这些卡把 Democracy 的「政策牵一发动全身」浓缩为桌面可读的因果卡，便于线下执行。

### 12.6 两套落地方案

#### 方案 A：简化版（线下桌游，可手算）

- **状态机**：用一枚「宏观状态指示物」在四格（复苏/过热/滞胀/衰退）间移动，每 3 回合按转移条件评估移动。
- **变量追踪**：一张「宏观面板」纸，记录 LPR/CPI/失业/API/CT 五个数，每期按 12.3 的基线漂移 + 政策卡调整**手动加减**。
- **资产定价**：每类资产印一个「基准价」，按 API 百分比整体浮动（如 API +4% → 所有房产估值 +4%），不单独建模供需。
- **玩家反作用**：只保留「群体杠杆率 GL」一个聚合指标——银行家每期统计全场总负债/总资产，超过 1.5 时翻「系统性风险」卡。
- **计算量**：每期约 5 次加法 + 1 次比较，无需计算器，适合线下。

#### 方案 B：完整版（线上 Agent 版，后台计算）

- **引擎**：用 Democracy 式**有向因果图**承载五变量 + 8 类资产的双向边，每 tick 数值积分更新。
- **价格机制**：Victoria 3 式**供需出清**——汇总所有玩家对某类资产的买卖单，按净供需偏移 API 子指数，再经 12.3 系数传导至其他变量。
- **Agent 央行**：独立智能体持有 LPR 旋钮，依泰勒式规则 + 状态机自动调节，并输出「行长点评」叙事（借鉴 £conomia）。
- **行为涌现**：完整实现 12.4 的羊群（局部信息可见性）、公地悲剧（信贷共同池）、牛鞭（圈层放大延迟）。
- **可视化**：实时曲线（CPI/LPR/API/GL）、状态机仪表盘、泡沫预警。
- **计算量**：后台自动，可引入随机冲击与蒙特卡洛情景。

#### 两版对照

| 维度 | 简化版 | 完整版 |
|---|---|---|
| 状态机 | 手动指示物 | 自动状态机 |
| 变量数 | 5 个聚合 | 5 变量 + 8 资产子市场 |
| 价格形成 | 整体浮动 | 供需出清 |
| 玩家反作用 | 仅 GL 聚合 | 羊群+公地+牛鞭全实现 |
| 央行 | 银行家手动 | Agent 自动+叙事 |
| 适用 | 线下教学/首版 | 线上长局/AI 对战 |

### 12.7 与财商流「三层棋盘 + 三张报表」的衔接

- **生存圈**：CPI/失业直接影响「生活费支出」与「工资」，对应 12.3 的失业→消费传导。
- **积累圈**：资产价格指数 API 直接驱动「资产负债表」中投资品估值，对应 LPR→房产 -8% 等系数。
- **自由圈**：利率下行期「被动收入」相对工资的优势放大，呼应美林时钟「复苏/过热持股、衰退持债」。
- **三张报表联动**：宏观变量变化 → 损益表（利息支出、资产收益）→ 资产负债表（估值）→ 现金流量表（再融资能力），形成「宏观→微观报表」的完整因果链，比当前骰子周期表信息含量更高。
