# 儿童青少年财商启蒙桌游资料

> **本文档定位**：为「财商流游戏」青少年版（14-17 岁）裁剪提供实体桌游调研依据。现有知识库已覆盖 App 类财商游戏（Greenlight / GoHenry / Acorns / Banzai 等），但**实体桌游的规则细节完全空白**。本文档聚焦实体桌游的真实规则与数值，并补充儿童金钱认知发展理论，最终给出青少年版裁剪建议。
>
> ⚠️ **免责声明**：本文档仅作游戏设计参考，不构成教育、法律或财务建议。

## 与财商流游戏的映射速查表

| 调研对象 | 核心机制 | 对财商流青少年版的映射价值 |
|---------|---------|------------------------|
| Pay Day（发薪日） | 月度日历棋盘、收支结算、贷款利息 | 最接近"个人现金流桌游"原型，月度结算机制可直接借鉴 |
| The Allowance Game | 家务赚零花钱、储蓄目标 $20 | 劳动→收入→储蓄的闭环，适合低龄段简化参考 |
| CASHFLOW for Kids | 资产vs负债、被动收入跳出老鼠赛跑 | 成人版简化范本，展示如何降低财务报表复杂度 |
| Monopoly Junior | 单一面额纸币、无抵押无拍卖 | 经典IP的低龄化裁剪方法论 |
| Exact Change / Money Bags | 硬币凑数、找零换算 | 货币认知基础训练，可作为迷你游戏嵌入 |
| 中国本土财商教具 | 财富探秘、大宋百商图等 | 本土化叙事与文化适配参考 |
| 儿童金钱认知发展阶段 | 3-6/7-11/12-15/16-18 四阶段 | 确定青少年版认知上限与下限的理论锚点 |
| Jump$tart 国家标准 | K-12 分级金融素养标准 | 14-17 岁应覆盖的能力清单 |

## Pay Day（发薪日，1974/1975）

### ① 完整流程

Pay Day 由 Paul J. Gruen 于 1974 年设计，最初由 Parker Brothers 发行，现由 Winning Moves Games USA 运营。首年销量超越 Monopoly，是历史上最成功的个人现金流模拟桌游之一。

游戏模拟一个或多个"月份"的个人财务管理。开局前玩家协商决定游玩月数（通常 3-6 个月）。每月结束时在"Pay Day"格进行工资发放、利息支付、账单清偿的统一结算。全部月份结束后，净资产最高者获胜。

### ② 详细规则（含具体数值）

**初始设置**：
- 每位玩家起始资金 **$325**
- 纸币面额：$500 / $150 / $20 / $10 / $5
- 棋盘为一个月历，共 **31 个日期格**（从 1 日到 31 日，加 START 和 PAY DAY 格）
- 使用标准六面骰

**月度工资**：
- 到达 PAY DAY 格时领取月薪 **$3,500**（早期版本为 $325，30 周年版调整为 $3,500）
- 最后一个月不发放工资（仅结算）

**贷款系统**：
- 可随时向银行贷款，必须以 **$1,000 为单位**借入
- 每月 PAY DAY 结算时，未还贷款需支付 **10% 月利息**
- 仅在 PAY DAY 格可还款，还款也必须以 $1,000 为单位
- 贷款可在游戏中随时借入，但只能在 PAY DAY 偿还

**邮件系统（Mail）**：
- 棋盘上有 **8 个 Mail 格**
- 落在 Mail 格时抽取指定数量的信件卡
- 信件类型：广告/明信片（无效果）、账单（Bill）、汇款单（Moneygram）
- **账单**：保留到月末 PAY DAY 统一支付；若现金不足必须贷款
- **汇款单**：立即支付指定金额，放入 Jackpot 池

**交易卡（Deal Cards）**：
- 落在 Deal 格时抽取交易卡
- 可选择以标价购买或放弃
- 购买后持有，直到落在 "Found a Buyer" 格时卖出获得收益
- 同一时间只能持有一张交易卡
- 游戏结束时未卖出的交易卡价值归零

**特殊格子**：
- **Sweepstakes（抽奖）**：再掷一次骰子，赢得 $1,000 × 点数
- **Lottery（彩票）**：银行放入 $1,000，每位玩家可选投入 $100 并选 1-6 的数字；落地者掷骰，匹配数字者赢得全部奖金
- **Radio Contest（广播竞赛）**：所有玩家掷骰，最高点数者赢 $1,000
- **Yard Sale（庭院拍卖）**：抽一张交易卡 + 再掷骰，以 $100 × 点数购买该交易卡

**PAY DAY 结算顺序**（严格依次执行）：
1. 领取月薪 $3,500
2. 支付贷款利息（未还本金 × 10%）
3. 可选择偿还部分或全部贷款（$1,000 为单位）
4. 支付本月所有账单；现金不足则必须贷款
5. 棋子回到 START，等待所有玩家完成当月

### ③ 道具卡牌机制

- **Deal Cards（交易卡）**：约 30-40 张，每张标明买入价和潜在卖出价；模拟小额投机机会
- **Mail Cards（邮件卡）**：约 40-50 张，混合正面（汇款）与负面（账单）事件
- **Jackpot 池**：累积的汇款单资金，通过掷 6 赢取

### ④ 棋盘设计

- 环形月历布局，31 个日期格 + START + PAY DAY
- 8 个 Mail 格均匀分布
- 约 6 个 Deal 格
- 4-5 个特殊事件格（Sweepstakes / Lottery / Radio Contest / Yard Sale / Found a Buyer）
- 总有效格数约 **33-35 格**

### ⑤ 经济系统

| 要素 | 数值/规则 |
|------|----------|
| 起始资金 | $325 |
| 月薪 | $3,500 |
| 贷款单位 | $1,000 |
| 月利率 | 10% |
| 胜利条件 | 游戏结束时净资产最高 |
| 通胀/通缩 | 无 |
| 税收 | 无 |

### ⑥ 财商理念与适龄段

- **核心理念**：月度预算意识、贷款成本认知、收支平衡的重要性
- **适龄段**：8 岁以上（官方标注），实际 10+ 更佳
- **教育价值**：让玩家体验"月底没钱→被迫贷款→利息滚雪球"的恶性循环，以及"提前储蓄→从容应对账单"的正向反馈
- **局限**：无投资概念、无税务、无保险、无资产增值；纯粹的消费-借贷模型

### ⑦ 对财商流游戏青少年版的可借鉴点

1. **月度结算节点**：Pay Day 的"月末统一清算"机制非常适合青少年版，可将财商流的年度结算简化为季度/月度结算，降低记忆负担
2. **贷款利息的即时痛感**：10% 月利率虽然夸张，但让青少年直观感受"借钱有代价"；青少年版可用年化 6%-12% 的更真实利率
3. **交易卡的"买了可能卖不掉"**：未卖出归零的设计教会"流动性风险"，可映射到青少年版的"二手物品交易"环节
4. **棋盘格数控制**：31-35 格的月历棋盘是经过验证的最佳规模，青少年版单层环可参考此量级

## The Allowance Game（零花钱游戏，1979 Lakeshore Learning）

### ① 完整流程

The Allowance Game 由 Lakeshore Learning Materials 于 1979 年发行，面向 5-10 岁儿童。玩家绕棋盘行进，通过做家务赚取零花钱，做出消费与储蓄决策。**第一位攒到 $20 的玩家获胜**。

### ② 详细规则（含具体数值）

- 2-4 人，约 30 分钟
- 每位玩家起始 **$0**
- 棋盘约 **40 格**，包含：Chore（家务）、Store（商店）、Bank（银行）、Lose a Turn、Bonus 等
- 落在 Chore 格：抽取家务卡，完成描述后获得 $0.25-$2.00 不等
- 落在 Store 格：可选择购买商品（玩具 $1-$5、零食 $0.50-$1.50）或跳过
- 落在 Bank 格：可选择存入 $1-$5（存款不计息，但安全不会被偷）
- 某些格子强制扣款（丢失钱包 $1、买糖果 $0.50 等）
- 胜利条件：**第一个达到 $20 现金+存款总和的玩家获胜**

### ③ 道具卡牌机制

- **Chore Cards（家务卡）**：约 20 张，描述简单家务（洗碗、扫地、遛狗等），对应报酬 $0.25-$2.00
- **Store Cards（商品卡）**：约 15 张，标明价格
- 使用塑料硬币和纸币教具

### ④ 棋盘设计

- 线性环形路径，约 40 格
- 色彩鲜艳，插图为主，文字极少
- 无分支路径

### ⑤ 经济系统

| 要素 | 数值/规则 |
|------|----------|
| 起始资金 | $0 |
| 收入来源 | 家务劳动报酬 |
| 单次收入范围 | $0.25-$2.00 |
| 胜利阈值 | $20 |
| 储蓄机制 | Bank 格存款（无利息） |
| 消费诱惑 | Store 格商品 |

### ⑥ 财商理念与适龄段

- **核心理念**：劳动换取报酬、延迟满足（存钱 vs 即时消费）、基本计数
- **适龄段**：5-10 岁（官方标注）
- **教育价值**：建立"钱不是凭空来的"这一基础认知；储蓄目标的设定与追踪

### ⑦ 对财商流游戏青少年版的可借鉴点

1. **"劳动→收入"的直接因果链**：青少年版可保留"完成任务获得收入"的核心循环，但将"家务"升级为"兼职/实习/项目"
2. **明确的储蓄目标**：$20 的胜利条件简洁有力；青少年版可设为"攒够第一笔应急基金（如 3 个月生活费）"
3. **30 分钟时长**：证明财商桌游不需要 2 小时也能传递核心价值

## CASHFLOW for Kids（富爸爸儿童版，1999 Rich Dad Company）

### ① 完整流程

CASHFLOW for Kids 是 Robert Kiyosaki 为 6-12 岁儿童设计的简化版现金流游戏。保留了成人版 101 的核心框架（老鼠赛跑圈 + 快车道），但大幅简化了财务报表和投资选项。

### ② 详细规则（含具体数值）

**与成人版 101 的关键差异**：

| 维度 | 成人版 101 | 儿童版 Kids |
|------|-----------|------------|
| 职业卡 | 12+ 种职业，不同收入/支出 | 简化为 4-6 种（教师、医生、工程师等），数值更小 |
| 财务报表 | 完整的损益表+资产负债表 | 简化的"收入-支出=现金流"单表 |
| 小生意卡 | 复杂房产/股票/企业 | 简化为冰淇淋店、柠檬水摊、宠物看护等 |
| 大买卖卡 | $6,000+ 大额投资 | 取消或极度简化 |
| 市场风云卡 | 影响所有玩家的宏观事件 | 简化为"有人想买你的店""股票涨了"等 |
| 额外支出 | 游艇、高尔夫等成人消费 | 电子游戏、自行车、电影票等儿童消费 |
| 婴儿格 | 增加孩子→增加月支出 | 保留但支出增量更小 |
| 慈善格 | 付总收入 10% 换 3 次双骰 | 简化为"帮助邻居"获得额外行动 |
| 起始资金 | 按职业不同 | 统一 $3,000 |
| 胜利条件 | 被动收入 > 总支出 → 进入快车道 → 买梦想或月现金流 $50,000 | 被动收入 > 支出 → 进入快车道 → 买梦想即可 |
| 游戏时长 | 2-3 小时 | 45-60 分钟 |

**儿童版独有简化**：
- 无需填写完整财务报表，银行家代为记录
- 取消了贷款/抵押贷款机制
- 股票只有买入价和卖出价，无期权/做空
- 房产只有"小型出租屋"一种，无公寓楼/商业地产
- 取消了"失业停赛 2 回合"的惩罚

### ③ 道具卡牌机制

- **Opportunity Cards（机会卡）**：分为 Small Deals（小生意）和少量 Big Deals
- **Market Cards（市场卡）**：简化版宏观事件
- **Doodad Cards（额外支出卡）**：儿童消费品
- **Paycheck 格**：经过即领月现金流

### ④ 棋盘设计

- 双圈结构保留：内圈"老鼠赛跑"约 24 格 + 外圈"快车道"约 20 格
- 格子类型：Paycheck / Opportunity / Market / Doodad / Charity / Baby
- 比成人版减少约 30% 的格子总数

### ⑤ 经济系统

| 要素 | 数值/规则 |
|------|----------|
| 起始资金 | $3,000（统一） |
| 月现金流 | 按职业 $200-$800 不等 |
| 小生意投资范围 | $100-$2,000 |
| 被动收入来源 | 小店租金、股息 |
| 胜利条件 | 被动收入 > 支出 → 买梦想 |
| 贷款 | 无 |
| 税收 | 无 |

### ⑥ 财商理念与适龄段

- **核心理念**：资产 vs 负债的区别、被动收入的概念、"让钱为你工作"
- **适龄段**：6-12 岁（官方标注），实际 8+ 体验更佳
- **教育价值**：在简化环境中建立"资产产生收入、负债消耗现金"的核心心智模型
- **局限**：过度简化可能导致"投资很容易"的错觉；缺乏风险管理维度

### ⑦ 对财商流游戏青少年版的可借鉴点

1. **财务报表的分层简化**：成人版三表→青少年版可保留"收入-支出=净现金流"单表 + 简版资产负债（只列大类），取消现金流量表的经营活动/投资活动/筹资活动三分法
2. **投资品的具象化**：冰淇淋店、柠檬水摊比"REIT""可转债"更适合青少年认知；青少年版可用"奶茶店""自媒体账号""二手球鞋转卖"等贴近生活的资产
3. **取消贷款但保留"借钱"概念**：儿童版完全去掉贷款是对的，但青少年版可引入"信用卡透支"作为简化版负债体验
4. **45-60 分钟时长验证**：证明财商教育桌游在 1 小时内可以完成有效学习循环

## Monopoly Junior（大富翁儿童版，Hasbro）

### ① 完整流程

Monopoly Junior 是 Hasbro 面向 5+ 岁儿童的简化版大富翁。最新版本（2023 年起）采用双面棋盘设计：Level 1（4+ 岁）和 Level 2（6+ 岁），实现"随年龄成长"的设计理念。

### ② 相对成人版的核心简化

| 维度 | 成人版 Monopoly | Junior 版 |
|------|----------------|-----------|
| 纸币面额 | $1/$5/$10/$20/$50/$100/$500 | **仅 $1 面额**（Level 1）或 $1/$5（Level 2） |
| 地产购买 | 竞价拍卖或按标价购买 | **直接按标价购买，无拍卖** |
| 抵押 | 可抵押地产获取现金 | **无抵押机制** |
| 房屋/酒店 | 4 栋房屋→1 栋酒店 | 简化为 Ticket Booth（售票亭），无升级层级 |
| 监狱 | 入狱/保释/罚款 | 简化为 "Go to Restroom"（去洗手间），停 1 回合 |
| Chance/Community Chest | 复杂事件卡 | 简化为 Amusement Ride（游乐设施）等主题卡 |
| 破产 | 资不抵债即淘汰 | **无破产淘汰**，资金不足时银行"借钱"（实质是给钱） |
| 交易 | 玩家间自由谈判交易 | **禁止玩家间交易** |
| 棋盘格数 | 40 格 | Level 1: 约 20 格；Level 2: 约 28 格 |
| 游戏时长 | 1-3 小时 | 20-30 分钟 |
| 胜利条件 | 最后未破产者 / 限时 richest | 最先达到指定金额或限时 richest |

### ③ 道具卡牌机制

- Level 1：纯图片匹配，无文字卡牌
- Level 2：简化 Chance 卡 + Amusement 卡

### ④ 棋盘设计

- Level 1：环形约 20 格，主题为游乐场/糖果店/冰淇淋店
- Level 2：环形约 28 格，增加 Boardwalk 概念
- 双面印刷，翻转即用

### ⑤ 经济系统

- 单一面额消除了"找零"认知负担
- 无抵押/无拍卖消除了"估值博弈"
- 无破产消除了"淘汰焦虑"
- 本质上是一个"收集+计数"游戏而非真正的经济模拟

### ⑥ 财商理念与适龄段

- **核心理念**：拥有资产→收取租金→积累财富的基本循环
- **适龄段**：4-8 岁
- **教育价值有限**：更像数学练习而非财商教育；但作为"桌游入门"有价值

### ⑦ 对财商流游戏青少年版的可借鉴点

1. **"随年龄成长"的双面设计**：青少年版可考虑"基础模式/进阶模式"双层规则，14 岁玩基础，16 岁解锁进阶
2. **单一面额的教训**：青少年版**不应**过度简化货币面额，14-17 岁完全能处理多面额；但可限制为 3-4 种（如 ¥10/¥50/¥100/¥500）
3. **无破产的设计取舍**：青少年版可保留"财务困境"但不淘汰，改为"降级生活方式"或"申请助学金"等正向出路

## Exact Change（精确找零）与 Money Bags（钱袋子）

### Exact Change

- **发行方**：PlayMonster（原 Patch Products）
- **适龄段**：6-10 岁
- **核心机制**：卡牌驱动，每张卡显示一个金额（如 $1.37），玩家需用手中的硬币/纸币卡组合出精确金额
- **棋盘**：无传统棋盘，纯卡牌对战
- **经济系统**：无宏观经济模拟，纯粹的计算训练
- **财商价值**：货币面值认知、加减法运算、"精确支付"的习惯养成
- **对青少年版的借鉴**：可作为"收银台迷你游戏"嵌入，但不适合作为核心机制

### Money Bags

- **发行方**：Learning Resources
- **适龄段**：7-12 岁
- **核心机制**：棋盘行进 + 找零挑战；落在特定格需给出正确找零才能继续
- **棋盘**：约 30 格环形路径
- **经济系统**：模拟购物场景的价格与找零
- **财商价值**：实际交易中的计算能力、"给多少钱、找回多少"的日常技能
- **对青少年版的借鉴**：找零机制对 14-17 岁过于简单，但其"交易场景嵌入棋盘"的思路可用于"市场采购"格子

## The Game of Life Junior（人生游戏儿童版，Hasbro）

- **发行方**：Hasbro，2020 年推出 Junior 版
- **适龄段**：5+ 岁
- **核心简化**：
  - 取消了成人版的"职业选择→大学→退休"全生命周期
  - 改为"周末冒险"主题：选择目的地（海滩/动物园/太空站等）
  - 无薪资/退休金/保险概念
  - 保留了转盘（Spinner）代替骰子的标志性机制
  - 棋盘从成人版的约 100+ 格缩减至约 40 格
  - 游戏时长从 1-2 小时压缩至 20-30 分钟
- **财商价值**：极低；Junior 版几乎完全剥离了财务决策，变成了纯粹的冒险故事游戏
- **对青少年版的借鉴**：反面教材——过度简化会丧失财商教育的核心价值；青少年版必须保留"财务决策的后果感"

## 中国本土儿童财商桌游/教具

### 已检索到的真实产品

#### 《财富探秘》（佰特公益 / 汇丰公益基金会）

- **发行方**：佰特公益（Bettr Foundation）开发，汇丰公益基金会资助
- **年份**：2024-2026 年在广东江门等地夏令营中使用
- **适龄段**：8-14 岁
- **核心机制**：原创桌游，模拟微型社会；分队闯关，包含"打工赚第一桶金""规划日常花销""制定存钱目标"等模块
- **教育理念**："正视金钱、尊重劳作、学会储蓄、理智消费"
- **公开资料**：江门市人民政府门户网站 2026-08-27 报道有详细描述，但完整规则未公开
- **⚠️ 规则细节未公开**：无法获取棋盘格数、具体数值、卡牌内容等

#### 《大宋百商图》

- **发行方**：国产原创桌游
- **适龄段**：7+ 岁，2-4 人，45-60 分钟
- **核心机制**：以宋朝商业为背景；目标为建成 8 座店铺并拥有 50 两流动资金
- **涉及概念**：菜单购买、店铺建设、招待客人、成本控制
- **财商价值**：将财商教育融入中国传统文化叙事，降低"西方金融术语"的认知门槛
- **⚠️ 完整规则未获取**：公开评测较少，具体数值待补充

#### 《小小银行家》系列

- **性质**：多家机构推出的同名教具/桌游套装，非单一产品
- **常见形式**：模拟银行柜台、ATM、存折、假钞教具的组合套装
- **适龄段**：5-10 岁
- **财商价值**：认识货币、体验存取款流程；但多为角色扮演教具而非策略桌游
- **⚠️ 无统一标准产品**：市面上有多个同名产品，质量参差不齐

#### 其他提及但未找到完整规则的产品

- **"财商启蒙沙盘"**：多个培训机构自研，无标准化产品
- **"儿童财商桌游"**：电商平台有大量低价仿制品，缺乏教育设计深度
- **中国银河证券《货币精灵》少儿财商课程**：5 课系列（货币变变变/现金流奥秘/管钱小达人/穿越地雷阵/货币与信用），配套桌游但规则未公开

### 检索缺口说明

⚠️ 中国本土儿童财商桌游市场存在明显的**信息断层**：大量产品由培训机构/公益组织自研自用，未在公开渠道发布完整规则。电商平台销售的"儿童财商桌游"多为 Monopoly/CASHFLOW 的低质仿制，缺乏原创教育设计。建议后续通过实地采购或联系佰特公益等机构获取一手资料。

## 教育理论底座

### 儿童金钱认知发展阶段

综合 Furth & Wachs（1975）《Teaching Young Children About Money》、皮亚杰认知发展理论、以及中国经济网/浙商银行理财分析师整理的实操指南，儿童金钱认知可分为四个阶段：

#### 第一阶段：感知期（3-6 岁）

| 年龄 | 认知里程碑 | 对应的游戏体验需求 |
|------|-----------|------------------|
| 3 岁 | 认识纸币、硬币的外形 | 触摸、分类、配对 |
| 4 岁 | 知道钱可以换东西 | 简单的"付钱→得到商品"交换 |
| 5 岁 | 理解钱是劳动换来的 | 完成任务→获得报酬的因果链 |
| 6 岁 | 能数较大数目，开始攒钱 | 储蓄罐、计数、"我的钱"意识 |

**关键特征**：前运算阶段，只能理解具体事物，无法理解抽象概念（利息、投资、保险）。游戏规则必须是"看得见摸得着"的物理操作。

#### 第二阶段：规则期（7-11 岁）

| 年龄 | 认知里程碑 | 对应的游戏体验需求 |
|------|-----------|------------------|
| 7 岁 | 查看价格标签，确认购买力 | 比价、预算约束下的选择 |
| 8 岁 | 理解银行存款概念 | 开户、存钱、看到数字增长 |
| 9 岁 | 制定简单周开销计划 | 短期预算编制与执行 |
| 10 岁 | 懂得节约以备大额支出 | 延迟满足、目标储蓄 |
| 11 岁 | 理解"需要"vs"想要" | 消费优先级排序 |

**关键特征**：具体运算阶段，能进行加减运算和简单推理，但仍难以理解复利、风险概率等抽象概念。可以引入简单的"收入-支出=结余"记账。

#### 第三阶段：策略期（12-15 岁）

| 年龄 | 认知里程碑 | 对应的游戏体验需求 |
|------|-----------|------------------|
| 12 岁 | 理解利息、 basic 投资概念 | 存款生息、简单回报率计算 |
| 13 岁 | 能进行多步骤财务规划 | 月度预算、多目标权衡 |
| 14 岁 | 理解信用/借贷的双刃剑 | 贷款利息、信用记录的影响 |
| 15 岁 | 能评估风险与回报的权衡 | 投资组合、保险的价值 |

**关键特征**：形式运算阶段初期，开始能处理假设性问题和抽象概念。这是财商教育的**黄金窗口期**——可以引入真实的财务决策复杂度，但仍需具象化呈现。

#### 第四阶段：整合期（16-18 岁）

| 年龄 | 认知里程碑 | 对应的游戏体验需求 |
|------|-----------|------------------|
| 16 岁 | 理解税务、社保等制度性安排 | 个税计算、五险一金的意义 |
| 17 岁 | 能进行长期财务规划 | 教育金、创业启动资金规划 |
| 18 岁 | 具备独立财务决策能力 | 完整的个人财务管理 |

**关键特征**：抽象思维趋于成熟，可以处理多变量、长周期的财务模型。这是从"学习财商"到"实践财商"的过渡期。

### Jump$tart Coalition《National Standards in K-12 Personal Finance Education》

Jump$tart Coalition 是美国最具影响力的金融素养教育标准制定机构。其 K-12 标准将个人金融教育分为六大领域，每个领域按年级段（K-4 / 5-8 / 9-12）设定能力目标：

| 领域 | 9-12 年级（对应 14-18 岁）核心能力 |
|------|----------------------------------|
| 收入（Income） | 理解工资、薪水、福利、税收扣除的关系；评估职业选择的终身收入影响 |
| 消费与储蓄（Spending & Saving） | 编制个人预算；区分需要与想要；理解复利对储蓄和债务的影响 |
| 信用与债务（Credit & Debt） | 理解信用评分、贷款利率、信用卡最低还款陷阱；评估借贷决策 |
| 投资（Investing） | 理解风险-回报权衡；了解股票、债券、基金、房地产等基本投资工具 |
| 风险管理（Risk Management） | 理解保险的原理与类型；识别欺诈与身份盗窃风险 |
| 财务责任（Financial Responsibility） | 理解税务义务；了解消费者权益保护法律；做出符合价值观的财务决策 |

### 中国相关政策文件

- **《国务院办公厅关于加强金融消费者权益保护工作的指导意见》（国办发〔2015〕81号）**：首次将"金融知识普及教育"纳入国民教育体系的政策框架
- **中国人民银行《金融知识普及读本》系列**：针对中小学生的分级读物
- **教育部《中小学公共安全教育指导纲要》**：包含"防范金融风险"相关内容
- **各地试点**：上海、浙江、广东等地已将金融素养纳入地方课程或校本课程
- **⚠️ 尚无全国统一的 K-12 金融素养课程标准**：与美国 Jump$tart 相比，中国的体系仍在建设中

## 财商流游戏青少年版裁剪建议

基于以上调研，针对 14-17 岁青少年版提出以下具体、可执行的裁剪方案：

### 一、应关闭的系统

| 系统 | 关闭理由 | 替代方案 |
|------|---------|---------|
| **企业所得税/增值税** | 14-17 岁无企业经营经验，税种计算过于抽象 | 保留个人所得税（工资薪金），作为"到手工资"的直观体验 |
| **杠杆融资/抵押贷款** | 青少年不应被鼓励借贷投资；Pay Day 的教训是"贷款利息痛感"比"杠杆收益"更重要 | 保留信用卡透支（模拟冲动消费后果）+ 助学贷款（模拟教育投资决策） |
| **企业并购/IPO** | 超出青少年认知范围；CASHFLOW for Kids 已验证去除大买卖不影响核心学习 | 保留"小微创业"（奶茶店/自媒体/二手转卖）作为投资体验 |
| **三表联动记账** | 完整三表对高中生过于复杂；CASHFLOW for Kids 用单表即可传递核心价值 | 简化为"收支流水账 + 月末净资产快照"两张表 |
| **遗产税/传承机制** | 青少年版不涉及代际财富转移；且中国现行未开征遗产税 | 完全移除，留到成人版 |
| **保险精算/养老金** |  actuarial 概念超出认知范围 | 简化为"医保卡"（生病时减免医疗费）和"意外险"（一次性赔付）两个具象产品 |

### 二、应简化的系统

| 系统 | 简化方向 | 参考来源 |
|------|---------|---------|
| **市场周期** | 从"繁荣/衰退/萧条/复苏"四周期简化为"好年景/平年/差年景"三态 | Pay Day 的月度波动已足够 |
| **职业系统** | 从 12 职业缩减为 6 个青少年可理解的起点职业（学生兼职/实习生/学徒/自由职业/创业者/全职员工） | CASHFLOW for Kids 的 4-6 职业验证 |
| **投资品种** | 从股票/债券/房产/企业/加密货币缩减为 3 类：定期存款、小微生意、技能投资（考证/培训） | 贴近青少年真实选择 |
| **棋盘格数** | 从 78 格三层同心环缩减为 **单层环 36-42 格** | Pay Day 31-35 格 + Monopoly Junior Level 2 约 28 格的验证区间 |
| **游戏时长** | 从 120-150 分钟压缩至 **60-90 分钟** | CASHFLOW for Kids 45-60 min + Pay Day 60-90 min 的验证 |
| **五维资源** | 从"现金/人脉/知识/健康/声望"五维缩减为 **三维：现金/技能/人脉** | 健康和声望对青少年决策影响较小 |

### 三、应保留的核心系统

| 系统 | 保留理由 |
|------|---------|
| **月度/季度结算节点** | Pay Day 验证了"定期清算"是财商桌游最有效的学习节奏 |
| **资产 vs 负债的区分** | CASHFLOW 系列的核心教育价值，不可删除 |
| **意外事件卡** | 所有成功财商桌游都有随机事件，培养风险意识 |
| **消费决策的即时后果** | Allowance Game 证明了"花掉就没了"的痛感是最佳老师 |
| **储蓄目标的可视化** | 进度条/计数器让延迟满足变得可见 |
| **玩家间的有限互动** | 保留交易/合作机会，但禁止复杂谈判（Monopoly Junior 的教训） |

### 四、棋盘与时长具体建议

```
推荐配置：
├── 棋盘：单层环形 40 格（含 START + 结算格）
│   ├── 收入格 ×8（兼职/实习/奖学金/红包等）
│   ├── 消费格 ×8（餐饮/娱乐/购物/社交等）
│   ├── 投资格 ×6（定存/小店/技能培训/二手转卖等）
│   ├── 事件格 ×6（意外支出/机会/市场变化等）
│   ├── 结算格 ×4（每季度末）
│   ├── 特殊格 ×4（慈善/社交/健康/考试等）
│   └── START ×1 + 终点 ×1 + 缓冲 ×2
├── 时长：60-90 分钟（4 个季度 = 1 个游戏年）
├── 人数：3-5 人
└── 配件：简化记账板（非纸质报表）+ 代币 + 卡牌
```

### 五、认知对齐检查清单

在设计每个机制时，对照以下检查清单：

- [ ] 14 岁学生能否在 30 秒内理解这个规则？
- [ ] 是否需要高中数学知识才能做出最优决策？（如果是→简化）
- [ ] 这个机制在中国青少年的日常生活中有对应物吗？（如果没有→替换为本土化等价物）
- [ ] 失败后果是否"痛但不绝望"？（Pay Day 的贷款螺旋是好例子；Monopoly 的破产淘汰是坏例子）
- [ ] 一局游戏结束后，玩家能否用自己的话复述学到的一个财务概念？
