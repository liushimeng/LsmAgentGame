## 1. 为什么单独调研

**真实世界 90% 的货币不是央行印出来的,而是商业银行通过「放贷」创造出来的。** 但绝大多数财商桌游与教科书把货币来源讲成了「央行印钱→商业银行转手放贷」——这种**「先存后贷」「资金从存款流向贷款」**的教科书模型,与 2014 年英格兰银行（McLeay/Radia/Ryland 论文「Money Creation in the Modern Economy」,BIS Quarterly Review）以来主流货币银行学的实证研究**完全相反**。

财商流游戏要「完全模拟真实世界财富流动」,**银行家 Agent 必须实现真实的信用创造逻辑**——玩家在「银行窗口」存钱不减少银行的「可贷资金」,银行放贷**凭空创造**新存款（M2 增量）,而不是把既有存款「借出去」。这是几乎所有玩家的认知盲点,也是最值得被游戏化的高价值知识点。

**缺口清单**（本文件填补）：
- **信用创造原理** —— 部分准备金、货币乘数、贷款创造存款
- **商业银行资产负债表** —— 资产/负债结构、净息差、资本充足率
- **挤兑与银行危机** —— Diamond-Dybvig 博弈论、SVB 2023、河南村镇银行 2022、海发行 1998
- **存款保险** —— 中国 2015《存款保险条例》50 万上限、覆盖 99%+ 储户
- **数字人民币** —— DCEP 定位 M0 替代、双层运营、试点 17 省（指针：职业卡池 N679 数字人民币推广 BD）
- **教学游戏** —— 银行家游戏、挤兑角色扮演、大富翁银行规则缺陷

**与本作的直接接口**：
- 《规则与经济系统》目前缺少「银行家 Agent」完整行为树,需要按本文件 §3 资产负债表逻辑设计；
- 《社交资本与信用体系设计》§6 已建玩家间借贷,但**未与商业银行的「贷款创造存款」机制挂钩**;
- 《真实世界经济与财商理论底座》§5 已建利率传导,但**未落到商业银行资产负债表的「净息差 → 利润 → 资本充足率」传导链**。

## 2. 信用创造原理与货币层次

### 2.1 部分准备金制度（Fractional Reserve Banking）

**核心思想**：商业银行只保留存款的一小部分作为**准备金（reserve）**应付日常提现,其余**全部用于放贷或购买生息资产**。

| 维度 | 内容 |
|------|------|
| 准备金率（r） | 法定存款准备金 ÷ 各类存款,央行规定下限（中国人民银行按大型/中小金融机构分档） |
| 法定 vs 超额 | **法定准备金（Required Reserve）**央行强制 + **超额准备金（Excess Reserve）**银行自留 |
| 准备金用途 | 央行账户上的存款,**不进入流通**;商业银行也不能放贷 |
| 现实案例 | 中国 2025 年大型存款机构准备金率约 **9%–9.5%** 区间（**训练知识待核验**——央行公告为准）;美国 2020 年疫情后准备金率长期为 0（**待核实**——FED 公开市场为准） |

**教学误区**：很多人以为「存款 = 银行替储户保管的钱,银行拿出去放贷」——**实际是「银行放贷时凭空创造新存款」**,参见 §2.3。

### 2.2 货币乘数：1/r 简化版与现金漏损修正版

**教科书简化版货币乘数公式**：
```
m = 1 / r
```
其中 m = 货币乘数, r = 法定存款准备金率。

**直觉**：央行新增 1 元基础货币（高能货币）→ 银行保留 r 准备金 → 贷出 (1-r) → 借款人再存入 → 银行再贷出 (1-r)² → …… 极限 = 1/r。

| 假设 | 100 元初始存款最终派生 M2 | 实际杠杆倍数 |
|------|--------------------------|--------------|
| r=100%（全额准备金）| 100 元 | 1.0× |
| r=20% | 500 元 | 5.0× |
| r=10% | 1000 元 | 10.0× |
| r=5% | 2000 元 | 20.0× |
| r=9.5%（中国大型机构 2025 假设, **待核实**）| 约 1053 元 | 约 10.5× |

**修正版（含现金漏损 c 与超额准备金 e）**：
```
m = (1 + c) / (r + e + c)
```

| 修正项 | 含义 |
|--------|------|
| c = 现金漏损率 | 公众持有现金占存款的比例,越高则派生能力越弱 |
| e = 超额准备金率 | 银行自留高于法定部分（保守经营 / 流动性压力时上升） |
| 现实 r=10%, c=8%, e=2% 时 | m ≈ (1+0.08) / (0.10+0.02+0.08) = 1.08/0.20 = 5.4× |

**重要修正**：现代货币银行学认为 **货币乘数是被动结果而非主动因**——银行先决定放贷规模,然后**倒推需要多少准备金**,而非央行先投放基础货币、银行被动按 1/r 派生。详见 §2.3。

### 2.3 「贷款创造存款」vs「先存后贷」之争

| 学派 | 主张 | 代表文献 |
|------|------|----------|
| **教科书主流（1950s–1990s）** | 央行先投放基础货币 → 银行吸纳存款 → 按 1/r 派生存款 | 米什金《货币金融学》、国内黄达《金融学》 |
| **现代主流（2014 后）** | 银行**先放贷**创造存款 → 事后**找央行补准备金** | 英格兰银行 2014 McLeay/Radia/Ryland 论文、央行 2017–2019 多篇工作论文（孙国峰等, **待核实具体年份/篇名**）|
| **后凯恩斯 / 货币循环派** | 银行「凭空」创造信用货币,内生货币供给 | 凯恩斯《就业利息和货币通论》Ch.17、明斯基金融不稳定性假说 |

**「贷款创造存款」实操路径**(BIS / 英格兰银行版):(1) 银行评估企业 A 信用 → 同意放贷 100 万;(2) 银行**不需要从其他储户「调」100 万** → 直接在 A 活期账户**记一笔 100 万存款**;(3) A 向 B 支付货款 → 银行 X 内部转账(改个数字);(4) 若 B 在 Y 银行,X 需向 Y **清算**——这时代价才出现:X 需在央行准备金账户**真实扣 100 万**(或同业拆借/债券抵押融资);(5) X 准备金紧 → 找央行**借**(MLF/SLF/逆回购)或**卖债券**。

**关键洞察**:商业银行**不是「放贷需要存款」,而是「放贷→创造存款→需要准备金→找央行融资」**。央行不是源头,是**最后贷款人**。

**对财商流游戏的映射**（**核心玩法创新**）:
- 银行家 Agent **放贷动作**应该直接**增加玩家活期存款（M1）**和**银行资产负债表上的「贷款」**;
- **不需要从「存款池」扣除**——绝大多数玩家会以为「银行的钱就那么多,放完就没了」;
- 触发玩家认知冲突:「明明我没存钱,银行怎么贷给我了?」→ 弹出**「贷款创造存款」科普弹窗**。

### 2.4 M0 / M1 / M2 层次划分与中国口径

| 层次 | 国际(IMF) | 中国 2025 修订前 | 中国 2025 修订后(待核实央行公告) |
|------|-----------|-----------------|----------------------------------|
| **M0** | 流通中现金 | 同左 | 同左 |
| **M1** | M0+活期 | M0+企业活期+机关团体部队+农村+个人信用卡 | **M0+活期(个人活期+企业活期+机关团体部队)**,**新增个人活期+第三方支付机构客户备付金** |
| **M2** | M1+储蓄+小额定期+货基 | M1+城乡储蓄+企业定期+外币+信托+货基+券商保证金 | 同修订前(**待核实是否同步调整**) |

**2025.1 M1 修订重点(待核实)**:(1) **新增个人活期存款**(此前归 M2 储蓄)→ 计入 M1;(2) **新增第三方支付机构客户备付金**(支付宝/微信在央行专户的沉淀资金)→ 计入 M1;(3) **直接动机**:M1 与 M2 长期「剪刀差」(M1 增速远低于 M2) → 资金活化度下降信号失真 → 修订后 M1 与 CPI/PPI 相关性显著提升;(4) **影响**：「M2 - M1 = 准货币」显著缩水,「资金活化」指标需重算。

**教学要点**:**M0** = 现金 + 数字人民币(**待核实**央行口径);**M1** = 立刻能花的钱(活期 + 备付金);**M2** = 准货币(定期/储蓄/货基/理财);**「M1/M2 剪刀差」** 是市场资金活跃度**领先指标**——M1 增速上穿 M2 = 活期化(消费/投资意愿强)= 经济热度上升;M1 增速下穿 M2 = 定期化(避险)= 经济偏冷。

### 2.5 中国 M2 突破 300 万亿与 M2/GDP 之争

**关键事实(全部待核实央行公告)**:2024 年初 M2 余额**突破 300 万亿**;2025.9 约 **330 万亿** 上下;**M2/GDP 比值**约 **2.5×**;对比:美国 0.7–0.9×、欧元区 1.0–1.2×、日本 1.5× → **中国比值显著偏高**。

**M2/GDP 偏高的主流解释**:(1) **「货币深化」论**——经济从计划转市场,偏高正常;(2) **「储蓄率高」论**——中国居民储蓄率长期 35%+(**待核实**),存款形式回流银行推高 M2;(3) **「间接融资为主」论**——企业融资 60%+ 来自银行贷款(**待核实**),不像美国靠直接融资;(4) **「统计口径」论**——2025.1 M1 修订后部分原 M2 划入 M1,但幅度有限。

**对财商流游戏映射**:**M2 = Σ 玩家活期 + Σ 定期 + Σ 货基 + Σ 理财**;玩家定期→活期 → M1↑ 触发「消费活跃」卡;玩家存银行 → M2↑(**但真实世界银行并不「等待存款」才放贷**);**认知冲突**:玩家存钱不增加银行可贷资金——**游戏教学的核心爆点**。

## 3. 商业银行资产负债表与净息差

### 3.1 资产负债表结构（资产端 / 负债端 / 所有者权益）

**核心恒等式**：**资产 = 负债 + 所有者权益**

#### 资产端（Asset, 资金运用）

| 资产类别 | 占比（中国商业银行 2024 估算,**待核实**）| 收益特征 | 风险特征 |
|----------|----------------------------------------|----------|----------|
| **贷款（Loan）** | 约 60% | 利息收入,5%–8% | 信用风险（违约）|
| **债券投资（Securities）** | 约 20%–25% | 票息 + 资本利得,3%–4% | 利率风险 + 信用风险 |
| **现金及存放央行（Reserves）** | 约 8%–10% | 1.5%–2% 准备金利率 | 几乎无风险 |
| **同业资产（Interbank）** | 约 5%–10% | 2%–4% | 交易对手风险 |
| **固定资产 / 其他** | 约 2%–5% | — | — |

#### 负债端（Liability, 资金来源）

| 负债类别 | 占比 | 成本特征 | 备注 |
|----------|------|----------|------|
| **客户存款（Deposits）** | 约 70%–75% | 活期 0.05%–0.35% / 定期 1.5%–3.0%（**待核实 2025 数据**）| 核心负债,粘性高 |
| **同业负债（Interbank）** | 约 10%–15% | 2%–4% 浮动 | 批发性融资 |
| **应付债券（Bonds Issued）** | 约 5%–10% | 3%–5% | 金融债、二级资本债 |
| **向央行借款** | 约 2%–5% | MLF 2.5% / SLF 走廊 | 季节性 |
| **其他** | 约 3%–5% | — | — |

#### 所有者权益（Equity, 资本）

| 项目 | 内容 |
|------|------|
| 股本 | 实收资本（普通股 + 优先股）|
| 资本公积 | 发行溢价等 |
| 盈余公积 + 未分配利润 | 历年留存 |
| **核心一级资本充足率（CET1）** | 中国监管要求 ≥ 8.5%（含 2.5% 储备资本 + 国内系统重要性银行 1% 附加）|
| **一级资本充足率** | ≥ 9.5% |
| **资本充足率** | ≥ 11.5% |

**对财商流游戏的映射**:
- 银行家 Agent 需要维护「**资产负债表三表**」—— 现金/贷款/债券/同业 = 资产,存款/同业借款/发债 = 负债;
- 「资本充足率」低于监管线 → 触发**监管警告事件卡**,限制分红与扩张;
- 玩家看到银行「**现金（库存）很少但存款很多**」会困惑 → 弹出「银行的钱不在金库里,都贷出去了」科普。

### 3.2 净息差 NIM 与「利息收入 / 利息支出」结构

**净息差（NIM, Net Interest Margin）公式**：
```
NIM = (利息收入 − 利息支出) / 生息资产平均余额
```

**中国商业银行 NIM 历史走势(全部训练知识待核验——以银保监会年报为准)**:2015 约 2.5% → 2018 约 2.0% → 2020 约 2.0% → 2022 约 1.9% → 2023 约 1.7% → 2024 **约 1.5%–1.7%(历史低位,待核实)**。

**NIM 压缩原因**:(1) 资产端 LPR 多次下调 → 贷款利率 5%+ 下行至 3.5% 左右(**待核实 2025**);(2) 负债端存款利率市场化滞后 → 定期付息率下调慢 → 剪刀差被压缩;(3) 经济偏弱 → 优质贷款稀缺 → 内卷式低息放贷;(4) 央行多次「减负」让利实体。

**NIM 警戒线**:国际经验 **NIM < 1.5%** 多数银行难覆盖风险成本;中国 2024 多家大行 NIM 已接近 1.4%–1.5% 区间(**待核实**——大行年报),**行业普遍承压**。

**对财商流游戏的映射**:
- 银行家 Agent **核心利润 = NIM × 生息资产规模**;
- 玩家「银行家」决策: **是追规模（多放贷）还是保息差（精选高利率贷款）**?
- 利率事件卡: 「央行降息 25bp」→ 所有贷款利率下降 25bp → NIM 自动压缩 → 银行家利润下降。

### 3.3 中间业务收入、存贷差、资本充足率（巴塞尔 III）

**中间业务收入（非利息收入）**:
- 包括：银行卡手续费、托管费、理财管理费、投行业务费、外汇交易、托管结算、咨询顾问;
- 大行占比 20%–30%,股份行占比 30%–40%,**对 NIM 压缩的对冲手段**;
- **财商流映射**：银行家 Agent 可以选择「做中间业务」（卖理财、托管）增加收入,但需要「客户量」支撑。

**存贷差（Spread 简化口径）**:
- 存贷差 = 贷款利率 − 存款利率;
- 简化: NIM ≈ 存贷差 × (贷款规模 / 生息资产);
- 2025 中国: 1Y 贷款 3.5% / 1Y 存款 1.5% → 存贷差约 2.0%（**待核实**——LPR 与存款利率上限公告为准）。

**资本充足率与巴塞尔 III**:

| 项目 | 国际（Basel III 最终版）| 中国监管要求（2025）|
|------|--------------------------|---------------------|
| 核心一级资本（CET1）| ≥ 4.5% | ≥ 5%（**待核实**）|
| 储备资本（Capital Conservation Buffer）| 2.5% | 2.5% |
| 逆周期资本缓冲 | 0%–2.5% | 0%–2.5% |
| 系统重要性银行附加 | 1%–3.5% | 0.25%–1%（**待核实**——FSB 名单与国内 D-SIB 名单）|
| **CET1 合计** | ≥ 7% | **≥ 8.5%**（含 D-SIB 1%）|
| 一级资本充足率 | ≥ 8.5% | ≥ 9.5% |
| 总资本充足率 | ≥ 10.5% | ≥ 11.5% |

**资本充足率约束的业务意义**:
- 贷款风险权重 100%（一般企业）→ 放 100 元贷款需要 11.5 元资本支持;
- 个人住房按揭风险权重 50%（**待核实**——中国 Basel III 最终版细则）→ 放 100 元按揭只需 5.75 元资本;
- 银行「**资本不够**」→ 限制放贷 → 「资本充足率事件卡」触发 → 银行需要**再融资**（发股票 / 发资本债 / 缩表）。

**对财商流游戏的映射**:
- 银行家 Agent 需要管理 **「资本 vs 风险加权资产」** 的双约束;
- 「发股票 / 发资本债」是高阶操作 → 触发「股权稀释」 / 「资本债利息支出」 事件;
- 资本充足率 < 8.5% → **监管介入事件卡** → 银行家 Agent 强制缩表。

### 3.4 影子银行：信托 / 理财 / 表外

| 类型 | 业务实质 | 监管态度 | 现状 |
|------|----------|----------|------|
| **信托贷款** | 银行通过信托通道放贷（绕开贷款额度/资本充足率）| 严控 | 2018 年后规模大幅压降 |
| **银行理财** | 表外负债 + 资产,刚兑时代实质是「银行担保」| 2018 资管新规要求**净值化转型** | 2022 破净潮（见 §3.5）|
| **同业资管 / 通道业务** | SPV 嵌套,监管套利 | 严控 | 已基本出清 |
| **委托贷款** | 企业间通过银行「走账」 | 严控 | 规模大幅下降 |
| **ABS / ABN** | 资产证券化 | 规范 | 仍正常发展 |

**核心特征**：
- **表内 = 银行资产负债表** → 资本充足率约束;
- **表外 = 银行做「管家」,不在银行资产负债表上** → **不消耗资本**,但**声誉风险仍在**（理财刚兑时代）;
- **财商流映射**：银行家 Agent 可以选择「表内贷款」（耗资本）vs「表外理财」（不耗资本但有声誉风险）。

### 3.5 2022 理财净值化转型破净潮

**背景**：
- 2018.4 央行/银保监会/证监会/外管局联合发布**「资管新规」**,要求银行理财**打破刚兑 + 净值化转型**;
- 过渡期延长至 2021 年底 → 2022.1.1 起,银行理财**全部净值化**（按市值计价,不再保本保息）;
- 2022 年股债双杀 → 大量银行理财**跌破净值**（「破净」）。

**影响（**训练知识待核验——以理财登记中心数据为准**）**:
- 2022 全年理财产品**累计破净产品数超 4000 只**（**待核实**——普益标准 / 理财登记中心数据）;
- 居民赎回 → 部分产品**触发大额赎回上限** → 流动性危机;
- 银行**自购**（用自有资金买自家理财）维稳 → 但效果有限;
- 事件后监管层**指导银行估值方法**（用摊余成本法等做「平滑」）→ 2023–2024 破净减少。

**教学要点**:
- **「刚兑时代」** = 银行隐含担保 → 投资者无风险意识;
- **「净值化时代」** = 真实价格波动 → 投资者教育;
- **财商流映射**：玩家「买银行理财」→ 真实浮动收益 → 教学「保本理财已不存在」。

## 4. 挤兑与银行危机案例库

### 4.1 Diamond-Dybvig 1983 模型与 2022 诺奖

**模型核心**（Diamond & Dybvig, 1983, American Economic Review,「Bank Runs, Deposit Insurance, and Liquidity」,**待核实具体期刊号**）:
- **假设**：(1) 银行吸收短期存款 + 投资长期资产（如 3 年期贷款）;(2) 存款人分两类：「耐心储户」（长期不动）vs「不耐心储户」（随时要取）;(3) 银行**无法事前区分**两类储户。
- **最优合约**：银行提供「活期存款」合约,允许不耐心者随时取现,银行用长期资产的高收益补偿。
- **多重均衡**：
  - **好均衡**：所有储户都「耐心」,不取现 → 银行投资长期 → 收益高 → 储户获益;
  - **坏均衡**：听说「有人取钱了」→ 大家都去取 → 银行被迫「贱卖」长期资产 → 损失 → 兑现减少 → 更多人来取 → **挤兑崩盘**。
- **关键洞察**：**挤兑是「自我实现预言」** —— 即使银行资产充足,只要足够多储户**预期**别人会来取,他们就会**真的来取**,最终导致银行破产。
- **政策含义**：**存款保险** + **最后贷款人**（央行）可以**消除坏均衡的预期**,避免挤兑。

**2022 诺贝尔经济学奖**：
- 授予 **Ben Bernanke**（美联储前主席,银行危机与金融加速器）+ **Douglas Diamond** + **Philip Dybvig**（**待核实**——瑞典皇家科学院公告原文为准）;
- Diamond-Dybvig 的银行挤兑理论是核心贡献之一;
- Bernanke 贡献：**信贷渠道**在大萧条中的作用。

**对财商流游戏的映射**:
- 教学关卡「**挤兑模拟**」:随机抽签,部分玩家「听说银行要倒」,触发集中取款 → 银行破产 → 全员存款部分损失;
- 教学弹窗:Diamond-Dybvig 模型 + 2022 诺奖介绍。

### 4.2 硅谷银行 SVB 2023.3（48 小时倒闭）

**核心时间线（**训练知识待核验——以美国 FDIC/SEC 报告、Reuters 财经为准,所有具体数字标「待核实」**）**:

| 日期 | 事件 |
|------|------|
| 2023.3.8 周三 | SVB 宣布出售 210 亿美元 AFS,亏损 18 亿;同时发行 22.5 亿普通股 + 5 亿优先股融资 |
| 2023.3.9 周四 | 股价暴跌 60%;储户集中挤兑(手机银行 1 天 420 亿提款请求);FDIC 介入 |
| 2023.3.10 周五 | 加州监管机构关闭 SVB,FDIC 接管;**48 小时**从正常到倒闭 |
| 2023.3.12 周日 | 财政部 / 美联储 / FDIC 全额兜底所有存款;推出「银行定期融资计划(BTFP)」 |

**倒闭机制(教科书级)**:(1) **久期错配** —— 资产端 10 年期+ 国债/MBS,负债端活期存款;(2) **利率上行** → 资产端市值暴跌 20%+;(3) **科技创投储户集中度高** → 风投建议被投企业提款 → 触发**信息级联**;(4) **手机银行加速** —— 1 天内集中转账 420 亿,远超现金储备;(5) **无保险存款占比 93%** → 保险不覆盖 → 恐慌。

**教学点**:久期错配 = 商业银行期限错配的固有风险;储户集中度 = 单一行业占比过高的脆弱性;手机银行 = 挤兑速度比 1907/1933 年快 100 倍;信息级联 = Diamond-Dybvig 模型的现实演绎。

### 4.3 First Republic / Signature / 瑞士信贷 AT1 减记

| 机构 | 倒闭 / 处置 | 时间 | 关键细节 |
|------|--------------|------|----------|
| **Silvergate** | 自愿清算 | 2023.3 | 加密货币友好银行,挤兑后主动清算 |
| **Signature Bank** | FDIC 接管 | 2023.3.12 | 加密友好 + 商业地产,**与 SVB 同一天关闭** |
| **First Republic** | FDIC 接管 → 摩根大通收购 | 2023.5.1 | 资产规模约 **2290 亿美元**（**待核实**——FDIC 公告）;存款大量流失;5.1 被 FDIC 接管,**同日**摩根大通以**特许经营价值**收购（**待核实**具体对价）|
| **Credit Suisse** | 瑞银（UBS）收购 | 2023.3.19 | 167 年历史;AT1 债**全额减记 170 亿瑞郎**（**待核实**）|
| **AT1 减记争议** | Credit Suisse AT1 减记 0 | 2023.3.19 | 股东血本无归 + AT1 债权人血本无归,**违反市场预期**（传统上股东应先 AT1 后损失）;**欧洲银行股 AT1 暴跌**;瑞士央行 / FinMA 解释为「完全合法」(COC 条款)|

**AT1（Additional Tier 1）减记含义**:
- AT1 = 商业银行发行的**应急可转债**（Contingent Convertible Bond）;
- **触发条件**：银行 CET1 跌破某一阈值 → 债券自动减记 / 转股;
- **Credit Suisse 案例**:CET1 跌穿 7% 触发线 → AT1 170 亿瑞郎**全部归零**（**待核实**——瑞士 FINMA 公告）;
- **市场反应**:全球 AT1 债暴跌 10%–30%;**引发监管反思**（欧洲央行紧急声明「普通股应先于 AT1 损失」）。

**对财商流游戏的映射**:
- 银行家 Agent 可以发行「**资本债**」（AT1 类）→ 平时付息 **6%–8%**（高息）→ 危机时**减记为 0**;
- 玩家买「银行资本债」 → 平时收益高 → 危机时**血本无归**;
- **教学要点**:股权与债权的损失顺序——**普通股 > AT1 > 二级资本债 > 普通债 > 存款**。

### 4.4 中国案例：包商银行 2019 / 河南村镇银行 2022 / 海发行 1998

**4.4.1 包商银行(2019.5 被接管)**:2019.5.24 央行 / 银保监会联合公告接管,1 年期限(**待核实**);**首家被接管的全国性股份制商业银行**(**措辞待核实**);原因:明天系控股,严重资不抵债(**待核实**);处置:2020.4 蒙商银行承接内蒙古区域 + 徽商银行承接区外,个人存款全额保障 + 机构大额债权打折(**待核实**)。**教学点**:**大额机构存款不保本** vs 个人存款 50 万保本。

**4.4.2 河南村镇银行(2022.4–7 事件)**:2022.4 起储户取款难 → 6 月部分储户**被赋「红码」**(**待核实**);涉事:河南 4 家 + 安徽 2 家村镇银行(**待核实**);涉案约 **400 亿元**(**待核实**);性质:河南新财富集团内外勾结,通过第三方平台+互联网揽储,资金被转移;**线上异地储户**为主;处置:2022.7 央行 / 银保监会公告垫付 5 万以下,后扩大至 10/15/25/50 万,最终 50 万内全额垫付(**待核实**)。**教学点**:互联网存款的跨区域风险;小银行不必然被存款保险兜底(操作/犯罪风险);红码事件警示技术权力滥用。

**4.4.3 海发行(海南发展银行, 1998.6.21 关闭)**:1998.6.21 央行公告关闭;**新中国唯一被关闭清算的商业银行**(**措辞待核实**);背景:1990s 海南房地产泡沫破灭 → 海发不良积压;1992–1997 海南 34 家信用社并入海发,把信用社窟窿也背了(**待核实**);处置:央行指定工行托管,个人存款全额兑付(**待核实**),机构债权打折,海发进入清算至今未完结(**待核实**)。**教学点**:银行危机 = 泡沫破灭 + 不良资产 + 兼并包袱三重叠加;存款保险实施前(2015.5.1 前)央行兜底但程序混乱;**行政托管 vs 市场化收购**。

### 4.5 《It's a Wonderful Life》(1946) 乔治·贝利的挤兑教学场景

**影片背景**:
- 1946 年 Frank Capra 导演,Jimmy Stewart 主演,**圣诞经典电影**;
- 主角乔治·贝利经营**贝利兄弟建筑贷款公司**（Bailey Building & Loan）—— 一家社区互助型储蓄贷款社;
- **核心挤兑场景**:**反派 Potter 银行**（*Bedford Falls* 镇上的大银行）引发储户对贝利公司的挤兑（**等待储户排长队,贝利用尽家财应对**）;
- **结局**:社区居民**自愿撤回存款请求** → 互助战胜资本 → 「It's a Wonderful Life」主题升华。

**教学价值**:
- **影视化教学**远比文字直观:挤兑的视觉冲击 → 财商流游戏可做**「电影片段 + 复盘选择题」**教学关卡;

- **角色扮演**:让玩家扮演「贝利」应对挤兑 → 教学「**最后贷款人**」「**存款保险**」政策价值。

## 7. 教学游戏与课堂实验

### 7.1 「银行家游戏」课堂信用创造实验

**经典货币银行学 Demo**:
- **角色**:学生分组扮演「**央行 / 商业银行 / 储户 / 企业**」;
- **道具**:筹码(代表货币) + 账本(代表资产负债表);
- **流程**:
  1. **央行**给「商业银行 A」发 **100 元初始基础货币**(作为超额准备金);
  2. **储户**在 A 存 0 元(银行只能自己);
  3. **企业**来 A 申请贷款 90 元 → A 发放贷款 → **A 资产负债表**: 资产 +90 元「贷款」/ 负债 +90 元「企业存款」 → **新创造了 90 元 M1!**
  4. 企业用 90 元向「储户张三」支付货款 → 90 元从「企业存款」转到「张三存款」 → 银行 A 内部转账;
  5. 张三存 50 元定期 → A 留 10 元准备金(假设 20% 准备金率,**待核实**) + 50 元可贷;
  6. A 再贷出 40 元 → …… 多轮派生;
- **教学价值**:**亲眼看到「贷款创造存款」**—— 这是反直觉的,**但学生亲手操作后终生难忘**。

**财商流游戏改造**:
- 设置「**银行家**」特殊角色 → 每轮可放贷给企业;
- 其他玩家扮演**储户 / 借款企业**;
- 「放贷」动作直接增加**玩家活期存款** + 银行资产负债表**贷款**;
- **认知冲突点**:**没有玩家把钱存进来,银行怎么有钱放贷?** → 弹出「贷款创造存款」弹窗。

### 7.2 挤兑角色扮演（Diamond-Dybvig 课堂版）

**Diamond-Dybvig 课堂实验**:
- **角色**:学生 = 储户;教师 = 银行;
- **机制**:
  1. 银行给每名学生发「**活期存款账户**」100 元;
  2. 银行用所有存款**投资长期项目**(老师拿走 80% 投入「长期项目」,只留 20% 现金);
  3. **抽签决定**「坏消息」:教师悄悄告诉 1–2 名学生「**银行要倒了**」;
  4. 知道「坏消息」的学生**先去取款** → 拿到现金;
  5. 其他学生看到 → 怀疑 → 也去取 → **挤兑**;
  6. 银行现金不足 → **变卖长期项目**(打折) → 资产缩水 → 储户拿到的更少;
- **结论**:**挤兑是「自我实现预言」** —— 即使银行健康,挤兑也能使其破产。

**财商流游戏改造**:
- 触发条件:**银行家 Agent NIM 连续 3 季 < 1% + 出现 1 张「负面新闻」卡** → 触发「挤兑事件」;
- **挤兑事件**:所有玩家**当回合**可选择「提取全部存款」;
- 若提取比例 > 30% → **银行破产** → 启动存款保险(50 万内保本);
- **教学弹窗**:Diamond-Dybvig 1983 + 2022 诺奖介绍。

### 7.3 《大富翁》里银行规则的缺陷与改编教学点

**原版规则缺陷**:
- 银行**有无限钱**——永远拿得出玩家抵押的「释放地产」钱;
- **不存在银行破产**——银行存款绝对安全;
- **玩家间无信用风险**——买地产的钱都是「自己的」。

**改编为「真实银行」版**:
- 银行发**总钱数有限**——1000 张「钞票」;
- 玩家**存钱** → 银行资产(贷款)扩张 → 但银行可贷余额受**存款 × (1-准备金率)**约束;
- **挤兑事件**触发 → 银行流动性枯竭 → 央行介入(印发新钞救援);
- **核心改造**:**让银行有「破产」机制**——但加存款保险避免玩家全部崩盘。

### 7.5 负利率实验（欧元区 2014–2022 / 日本 YCC 2016–2024）

**对财商流游戏的映射**:
- 每个危机可设计成「**教学关卡**」,让玩家扮演相关角色(储户 / 银行家 / 监管);
- **危机教学点** 提炼为「**风险卡片**」,玩家在游戏中遇到对应条件时触发。
