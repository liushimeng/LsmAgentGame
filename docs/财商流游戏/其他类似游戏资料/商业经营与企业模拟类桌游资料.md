## 1. Food Chain Magnate（快餐连锁大亨）

### 1.1 背景与设计理念

- **设计师**：Jeroen Doumen、Joris Wiersinga（荷兰 Splotter Spellen 工作室创始人）
- **出版年**：2015；豪华版 / Special Edition 由 Lucky Duck Games 于 2025 年众筹重制
- **玩家人数**：2–5 人 | **时长**：120–240 分钟 | **适龄**：14+
- **复杂度评级**：BGG Weight ≈ 4.2/5（极重度策略）
- **设计初衷**：模拟 20 世纪 50 年代美国快餐业从零到连锁帝国的全过程。零运气成分——没有骰子、没有抽牌、所有信息完全公开，胜负纯粹取决于商业决策质量。被硬核桌游社区公认为"最接近真实商业经营的桌游"。

### 1.2 完整游戏流程

1. **开局准备**：每位玩家获得一块起始餐厅板块（4 格）、$10 启动资金、一套员工卡储备。地图由 3×4 或 4×4 城市板块拼接，含住宅区、道路、机场等。
2. **回合结构**（每轮 = 一个"营业日"）：
   - **招聘/培训阶段**：从个人储备中打出员工卡到餐厅面板上。员工分 7 级：跑腿伙计→服务员→厨师→经理→培训讲师→总经理助理→CEO。高级员工需先培训低级员工才能上岗。
   - **营销阶段**：按编号升序结算营销板块。广告牌/广播/报纸等营销手段在特定住宅区产生"需求标记"（汉堡/披萨/饮料/沙拉等）。未被满足的需求会累积。
   - **晚餐阶段**：按住宅区编号升序结算。每个有需求的住宅区，距离最近且价格最低的餐厅获得订单。若多家餐厅同价同距，则平分或按规则排序。
   - **收入结算**：售出菜品获得收入 = 售价 × 数量。未售出的食材浪费。
   - **薪资支付**：所有在岗员工需支付工资（入门模式可跳过）。
   - **里程碑检查**：达成条件者立即获得奖励（如"首家开设 3 家餐厅""首位雇佣 CEO"等）。
3. **结束条件**：预设轮数结束或银行资金耗尽。**现金最多者获胜**。

### 1.3 详细规则

- **定价战**：每道菜品的售价由玩家自行设定（整数美元）。低价抢客但利润薄；高价利厚但可能零订单。这是全游戏最核心的博弈点。
- **员工培训链**：厨师只能做已培训的菜品；经理增加服务容量；培训讲师解锁新菜品/新员工类型。培训需要"工时"——每轮有限行动槽位。
- **营销竞争**：营销板块按固定顺序结算，先到先得。同一住宅区被多次营销时，需求叠加。
- **里程碑**：全局仅 3 个名额，先到先得。提供永久收益加成（如"每轮额外 $5""免费培训一次"等）。
- **破产**：无法支付工资时被迫裁员；连续亏损导致现金归零即淘汰。

### 1.4 道具/卡牌系统

| 类型 | 数量 | 关键字段 | 说明 |
|------|------|---------|------|
| 员工卡 | 每人约 30 张 | 职位、薪资、能力、培训前置 | 构成"人力资源树" |
| 营销板块 | 地图内置 ~20 个 | 编号、需求类型、触发条件 | 按编号升序结算 |
| 餐厅板块 | 每人起始 1 + 可扩展 | 座位数、厨房类型 | 决定产能上限 |
| 里程碑卡 | 全局 3–5 张 | 达成条件、奖励效果 | 先到先得 |
| 需求标记 | 无限供应 | 食物类型、数量 | 放在住宅区上 |

### 1.5 棋盘设计

模块化城市地图，由正方形板块拼接。每个板块含若干住宅格（带编号）、道路格、特殊地标格。餐厅占据 4 格，入口必须邻接道路。地图布局每局不同，直接影响选址策略。

### 1.6 棋牌设计

- **员工卡**：标准扑克尺寸，正面印职位图标+薪资+能力描述，背面为统一花色。
- **纸币**：$1/$5/$10/$20/$50/$100 面额，美式复古风格。
- **玩家面板**：双层凹槽板，放置在职员工卡，显示当前菜单与定价。
- **需求标记**：木质小方块，颜色区分食物类型。

### 1.7 经济系统（真实世界模拟机制）

**本篇重点**：FCM 是桌游界对"企业经营"模拟最硬核的作品。

- **成本核算**：每道菜品有隐含成本（员工薪资 + 食材机会成本）。售价低于总成本 = 亏本卖。玩家必须心算每道菜的边际利润。
- **供需与价格形成**：需求由营销外生创造，但供给端（谁能接单）完全由玩家的选址、产能、定价内生决定。这是一个**玩家驱动的局部垄断竞争市场**。
- **货币流动路径**：银行 → 玩家（初始资金）→ 员工工资（回流银行）→ 销售收入（玩家间零和转移，因为客户需求总量有限）。
- **信贷与杠杆**：**无贷款机制**。纯靠经营现金流滚动发展，这迫使玩家极度关注短期盈亏平衡。
- **破产与清算**：现金归零即淘汰，资产不拍卖、不转让。对应现实中"小企业现金流断裂即死"。
- **对应真实概念**：边际成本定价、规模经济、人力资本投资回报期、市场进入壁垒（选址）、价格战的囚徒困境、里程碑 = 先发优势。

### 1.8 角色/玩家差异

所有玩家起始完全对称（相同资金、相同员工储备、相同餐厅）。差异化完全来自游戏中的决策分歧。这是"纯策略零运气"设计的极致体现。

### 1.9 财商理念与核心策略

- **核心理念**：企业经营的核心不是"赚更多"而是"不亏"。现金流管理 > 利润最大化。
- **高手策略**：前期低价抢市场份额 → 中期通过培训提升产能降低成本 → 后期提价收割利润。里程碑是关键加速器。
- **新手常见错误**：过早扩张（开新店但没钱付工资）、忽视营销（有产能没客户）、定价拍脑袋（不算边际成本）。

### 1.10 对「财商流游戏」的可借鉴点

1. **生存圈副业的轻量化经营循环**：FCM 的"招聘→生产→销售→发薪"四步循环可直接简化为财商流副业的经营模板。建议副业每回合仅需 1 次决策（选产品+定价格），AI Agent 自动结算细节。
2. **定价博弈作为社交互动点**：财商流的企业投资品可引入"同行竞价"机制——同一行业的企业/副业在同一回合内暗中出价，低价者获客但利润薄，模拟 FCM 的价格战精髓。
3. **里程碑 = 阶段性成就奖励**：财商流的三圈层可各设 3–5 个里程碑（如"首家年收入破百万""首次成功出售企业"），先到先得，提供永久被动收益或资源加成。
4. **Agent 经营的企业作为 NPC 竞争对手**：FCM 的零运气特性使其天然适合 AI 接管。财商流中 Agent 可经营同行业企业，与人类玩家在同一市场中竞争，Agent 的定价/营销策略由 LLM 驱动，提供动态竞争压力。
5. **⚠️ 简化警示**：FCM 原版 4 小时+、心算量极大。财商流必须将经营环节压缩到每回合 ≤ 2 分钟决策时间，复杂计算交给 Agent 自动结算。

## 2. Brass: Lancashire（工业革命：兰开夏）

### 2.1 背景与设计理念

- **设计师**：Martin Wallace（英国 Treefrog Games 创始人）
- **出版年**：2007（原版）；Roxley 豪华版 2018
- **玩家人数**：2–4 人 | **时长**：90–150 分钟 | **适龄**：14+
- **复杂度评级**：BGG Weight ≈ 3.9/5
- **设计初衷**：模拟 18 世纪末至 19 世纪中叶英国兰开夏郡工业革命。玩家扮演工业企业家，通过建厂、修运河/铁路、获取贷款、参与煤炭与棉花市场来积累胜利点数。
- **分工注明**：Brass: Birmingham（伯明翰）由另一位同事负责，本文仅覆盖 Lancashire。两版共享核心 Brass 系统但地图、产业、时代划分不同。

### 2.2 完整游戏流程

1. **开局准备**：版图展示兰开夏郡地图，含煤矿、棉纺厂、港口、城市节点。每位玩家获得手牌（地点卡+产业卡）、收入轨道标记、VP 标记。
2. **双半场结构**：游戏分为**运河时代**（Canal Phase）和**铁路时代**（Rail Phase），各含若干轮。
3. **回合结构**（每轮）：
   - 每位玩家执行 **2 个行动**（弃 1 张手牌/行动）。可选行动：建造（Build）、开发（Develop）、出售棉花（Sell Cotton）、贷款（Loan）、修运河/铁路（Canal/Rail Link）、通行（Pass）。
   - 建造需匹配手牌中的产业卡+地点卡，并支付费用。
4. **计分阶段**：每个时代结束时，翻转所有已建产业板块，按连接度与产出计算 VP。
5. **结束条件**：铁路时代最后一轮结束后终局计分。**VP 最高者获胜**。

### 2.3 详细规则

- **建造约束**：工厂必须建在对应资源节点旁；运河/铁路连接两个相邻城市；港口需临海。
- **贷款机制**：任何时候可借 £10，但收入轨道下降 1 级。贷款无利息但降低每轮基础收入。
- **煤炭市场**：煤矿产出的煤必须先运到城市才能被其他玩家的工厂使用。煤炭是"公共基础设施型资源"。
- **棉花市场**：棉纺厂产出的棉花可通过港口出售换取 VP + 收入。外部市场需求随时代变化。
- **翻转计分**：产业板块正面朝下表示"建设中"，翻面后表示"运营中"。只有运营中的产业才计 VP。

### 2.4 道具/卡牌系统

| 类型 | 数量 | 关键字段 | 说明 |
|------|------|---------|------|
| 地点卡 | 每人 ~8 张 | 城市名 | 指定建造地点 |
| 产业卡 | 每人 ~8 张 | 产业类型（矿/厂/港/运河/铁路） | 指定建造类型 |
| 产业板块 | ~60 个 | 类型、VP、收入、煤炭/棉花需求 | 双面（建设/运营） |
| 运河/铁路标记 | 有限 | 连接关系 | 物理放置在版图上 |
| 收入轨道 | 每人 1 条 | 当前收入等级 | 贷款会降低 |

### 2.5 棋盘设计

固定地理地图，展示兰开夏郡真实地形。城市节点以圆圈标注，资源节点（煤矿/棉花）以图标区分。运河/铁路线路以预印虚线标示可修建路径。整体色调为工业灰褐色。

### 2.6 棋牌设计

- **产业板块**：厚纸板双面印刷，正面（运营面）印 VP + 收入值，背面（建设面）纯色。
- **手牌**：标准尺寸，简洁图标+文字。
- **收入轨道**：长条形纸板，滑块标记当前位置。
- **VP 标记**：木质方块。

### 2.7 经济系统（真实世界模拟机制）

- **成本与利润**：建造费用 = 固定成本 + 资源消耗（煤炭/棉花）。运营收入 = 基础收入 + 连接加成。利润 = 收入 - 贷款导致的收入惩罚。
- **供需与价格**：煤炭和棉花的"价格"不以货币表示，而是以**可用性**表示——煤矿必须先运输到城市才能被工厂使用，形成物流瓶颈。这是一种**实物供需模型**而非货币定价模型。
- **信贷与杠杆**：贷款是唯一融资手段，代价是永久性降低收入等级。这模拟了早期工业企业的"债务融资 vs 股权融资"权衡。
- **网络效应**：运河/铁路连接越多，沿线产业价值越高。模拟基础设施的正外部性。
- **对应真实概念**：工业革命产业链、基础设施投资回报、债务融资成本、产业集群效应、物流瓶颈。

### 2.8 角色/玩家差异

所有玩家起始对称。差异化来自手牌抽取顺序与建造时序选择。

### 2.9 财商理念与核心策略

- **核心理念**：基础设施先行。没有运河/铁路，工厂产出无法变现。
- **高手策略**：早期贷款建煤矿+运河 → 中期利用煤炭优势建棉纺厂 → 后期铁路时代收割高 VP 产业。
- **新手常见错误**：过度贷款导致收入崩塌、忽视煤炭运输链、在铁路时代仍投资运河。

### 2.10 对「财商流游戏」的可借鉴点

1. **积累圈企业创办的"基础设施依赖"**：财商流的企业投资品可设计要求玩家先投入"人脉/认知"资源打通供应链，再开始盈利。模拟 Brass 中"先修路再建厂"的逻辑。
2. **贷款的双刃剑设计**：财商流的银行贷款可增加"精力/人脉惩罚"——借钱容易但消耗人生资源，迫使玩家在"借钱加速"与"自有资金稳健发展"间权衡。
3. **时代切换 = 市场周期**：Brass 的运河→铁路切换可直接映射为财商流的四阶段市场周期（复苏/繁荣/衰退/萧条）。每个周期改变可用投资品类型与收益率。
4. **⚠️ 简化警示**：Brass 的物流链计算较复杂。财商流应将供应链抽象为"前置条件检查"而非逐格追踪物流。

## 3. Terraforming Mars（殖民火星 / 重塑火星）

### 3.1 背景与设计理念

- **设计师**：Jacob Fryxelius（瑞典 FryxGames）
- **出版年**：2016 | **出版社**：FryxGames / Stronghold Games
- **玩家人数**：1–5 人 | **时长**：90–120 分钟 | **适龄**：12+
- **复杂度评级**：BGG Weight ≈ 3.3/5
- **设计初衷**：受 Kim Stanley Robinson《火星三部曲》启发。玩家扮演竞争性企业集团，通过项目卡将火星改造为宜居星球。核心是将"地球化改造"这一宏大目标拆解为企业级的资源管理与引擎构筑。

### 3.2 完整游戏流程

1. **开局准备**：选择/随机分配企业卡（不对称起始能力+资源）。设置三大行星参数轨道：温度（-30°C → +8°C）、氧气（0% → 14%）、海洋（0 → 9 块）。
2. **回合结构**（每"代"Generation）：
   - **研究阶段**：抽 4 张项目卡，支付 3 M€/张保留任意数量。
   - **行动阶段**：轮流执行 1–2 个行动。可选：打出项目卡、执行标准项目、宣称里程碑、资助奖励、使用蓝色卡行动、转化植物/热量。
   - **生产阶段**：按 TR 获得 M€ 收入 + 各资源产量自动产出。
3. **结束条件**：三大行星参数全部达标 → 触发终局计分。**TR + 里程碑/奖励 + 卡牌 VP + 地图元素 VP 总和最高者获胜**。

### 3.3 详细规则

- **TR（Terraform Rating）**：每提升一步行星参数，TR +1。TR = 每代基础 M€ 收入 + 终局基础 VP。
- **标准项目**：固定价格的"兜底行动"（发电厂 11 M€、小行星 14 M€、含水层 18 M€、绿化 23 M€、城市 25 M€）。
- **钢铁/钛金替代**：打建筑卡时钢铁可抵 2 M€、太空卡时钛金可抵 3 M€。
- **里程碑**：全局仅 3 个，每个 8 M€，要求达到特定条件（如"拥有 3 个建筑标签""能量产量 ≥ 6"等）。
- **奖励**：全局仅 3 个，每个 14 M€，终局时按排名发放 VP（第 1 名 5 VP、第 2 名 2 VP）。

### 3.4 道具/卡牌系统

| 类型 | 数量 | 关键字段 | 说明 |
|------|------|---------|------|
| 项目卡 | 200+ 张（基础） | 费用、标签、效果、VP | 红/绿/蓝三色分类 |
| 企业卡 | 15+ 张 | 起始资源、独特能力 | 不对称起点 |
| 里程碑/奖励标记 | 各 5 选 3 | 条件、VP | 全局竞争 |
| 资源方块 | 大量 | M€/钢/钛/植物/能量/热 | 六色区分 |
| 地图板块 | 海洋/绿化/城市/特殊 | 放置奖励 | 六角格地图 |

### 3.5 棋盘设计

六角格火星地图，预印地形奖励（抽卡/资源/温度等）。三条行星参数轨道位于版图边缘。中央为公共区域放置里程碑/奖励标记。

### 3.6 棋牌设计

- **项目卡**：标准尺寸，左上角费用、中部效果图标、底部标签+VP。红牌（事件，一次性）、绿牌（持续效果）、蓝牌（主动行动）。
- **玩家面板**：双层凹槽，追踪六种资源产量与存量。
- **资源方块**：木质/塑料立方体。

### 3.7 经济系统（真实世界模拟机制）

- **企业化长期投资**：TR 机制本质是"对社会贡献越大，自身基础收入越高"。这模拟了企业通过承担社会责任（ESG）获得政策红利与市场信任。
- **资源转化为收入**：六种资源形成转换链：能量→热量→温度→TR→M€。植物→绿化→氧气→TR。这是一条**多跳价值链**。
- **里程碑与奖励 = 市场竞争中的先发优势与行业标准**：里程碑是"谁先到谁拿"，奖励是"谁做得最好谁拿更多"。两者共同构成多维竞争。
- **项目卡组合 = 投资组合构建**：每张卡代表一个投资项目，标签代表行业属性。玩家需要构建协同效应（如多个"科学"标签解锁高 VP 里程碑）。
- **对应真实概念**：ESG 投资、产业链价值传导、先发优势、行业标准制定、投资组合多元化、沉没成本（已打出的事件卡不可回收）。

### 3.8 角色/玩家差异

企业卡提供显著不对称性：Tharsis Republic 起始多 1 个绿化+城市放置奖励；Ecoline 起始多植物产量；Helion 可用热量替代 M€ 等。这模拟了不同企业的禀赋差异。

### 3.9 财商理念与核心策略

- **核心理念**：引擎构筑 > 即时收益。前期投资于产能提升，后期享受复利效应。
- **高手策略**：早期冲 TR（快速提升基础收入）→ 中期构建标签组合瞄准里程碑 → 后期刷 VP 卡。
- **新手常见错误**：只买便宜卡不看标签协同、忽视标准项目的兜底价值、过晚宣称里程碑被别人抢先。

### 3.10 对「财商流游戏」的可借鉴点

1. **TR 机制 → 财商流的"社会贡献值"**：玩家在积累圈/自由圈的投资行为可同时提升个人资产与社会贡献值。社会贡献值影响贷款利率、保险费率、NPC 雇主好感度等。
2. **里程碑/奖励 → 财商流的多维度结局计分**：财商流终局不应只看金钱总量，应设"最佳创业者""最佳投资人""最佳社会贡献者"等多维奖项，鼓励多元策略。
3. **项目卡组合 → 企业投资品的"资产配置"**：每个企业投资品可带 2–3 个标签（科技/消费/制造/服务等），标签组合触发额外收益或解锁特殊事件。
4. **企业卡不对称 → 职业差异化**：12 个中国化职业可各有独特的"创业天赋"（如程序员创业科技企业成本 -20%、外卖骑手创业餐饮副业起步更快）。

## 4. Concordia（康考迪亚）

### 4.1 背景与设计理念

- **设计师**：Mac Gerdts（德国 PD-Games）
- **出版年**：2013 | **出版社**：PD-Games / Rio Grande Games
- **玩家人数**：2–5 人（最佳 4 人）| **时长**：60–100 分钟 | **适龄**：12+
- **复杂度评级**：BGG Weight ≈ 3.0/5
- **设计初衷**：以古罗马帝国经济发展为背景，强调贸易路线规划与多维终局计分。零运气、纯策略，BGG 总榜长期 Top 20。

### 4.2 完整游戏流程

1. **开局准备**：每位玩家获得相同的起始手牌（7 张人物卡）、2 个殖民者、若干资源（砖/食物/工具/酒/布）、起始资金。
2. **回合结构**：每回合打出 1 张手牌，执行其效果。可选行动包括：移动殖民者、建造房屋、生产货物、收集金币、买卖货物、购买新人物卡、复制他人弃牌效果、收回所有弃牌并获得金币。
3. **结束条件**：任一玩家建成 15 栋房屋 OR 市场最后一张人物卡被买走 → 触发终局。**触发者获康考迪娅卡（+7 VP），其余玩家各再走一回合**。

### 4.3 详细规则

- **卡牌双重功能**：每张人物卡既是行动指令，又是终局计分依据。例如"朱庇特"卡在行动时让你建造非砖城房屋，终局时每栋非砖城房屋 × 持有朱庇特卡数量 = VP。
- **乘法计分**：同一神明卡持有多张时，得分相乘。2 张朱庇特 + 8 栋非砖城房屋 = 16 VP。这创造了"专注 vs 多元"的核心张力。
- **贸易路线**：殖民者在道路上移动，经过的城市触发货物生产。完成贸易路线时，沿线有房屋的玩家各得 1 VP。
- **商品定价**：买卖货物的价格由市场轨道决定，供过于求时价格下跌。

### 4.4 道具/卡牌系统

| 类型 | 数量 | 关键字段 | 说明 |
|------|------|---------|------|
| 人物卡 | 市场 ~30 张 + 每人起始 7 张 | 神明标识、行动效果、计分规则 | 核心组件 |
| 资源标记 | 五种 | 砖/食物/工具/酒/布 | 建造与交易媒介 |
| 殖民者 | 每人若干 | 陆/海两种 | 在版图上移动 |
| 房屋 | 每人 15 个 | 颜色标识 | 建在城市旁 |
| 金币 | 大量 | Sesterii | 通用货币 |

### 4.5 棋盘设计

双面地图（罗马帝国 / 意大利行省），划分为若干省份，每省含多个城市。城市标注产出资源类型。道路/海路连接城市。扩展包提供不列颠/高卢/埃及等新地图。

### 4.6 棋牌设计

- **人物卡**：标准尺寸，顶部神明图标、中部行动描述、底部计分规则。
- **资源标记**：木质小方块/圆柱，五色区分。
- **房屋**：微型立体建筑模型。

### 4.7 经济系统（真实世界模拟机制）

- **贸易路线 = 供应链网络**：殖民者移动路径即贸易路线，沿线城市产出货物。这模拟了古代地中海贸易网络的物流逻辑。
- **商品定价 = 市场均衡**：买卖价格随供需波动，但不是玩家直接定价，而是由市场轨道机械调节。比 FCM 更抽象但更易操作。
- **乘法计分 = 专业化投资的复利效应**：专注某一神明（行业）可获得指数级回报，但风险集中。这完美模拟了"把所有鸡蛋放在一个篮子里"的投资哲学。
- **卡牌购买 = 人才/技术投资**：购买新人物卡既扩展行动选项，又增加终局计分维度。每一笔"投资"都有双重回报。
- **对应真实概念**：贸易网络效应、专业化 vs 多元化投资、市场均衡价格、人力资本投资、复利效应。

### 4.8 角色/玩家差异

所有玩家起始完全对称。差异化来自卡牌购买顺序与版图扩张方向。

### 4.9 财商理念与核心策略

- **核心理念**：行动效率 = 卡牌组合优化。每张卡既要考虑当下行动价值，又要考虑终局计分潜力。
- **高手策略**：早期购买高分神明卡 → 中期围绕该神明构建版图布局 → 后期用"外交官"卡复制对手好牌加速。
- **新手常见错误**：只看行动效果忽略计分规则、盲目多元导致每种神明都只有 1 张（乘法失效）、忘记"收回弃牌"行动的金币收益。

### 4.10 对「财商流游戏」的可借鉴点

1. **乘法计分 → 财商流的"多维度结局"**：终局计分可设为"金钱 × 人脉系数 × 认知系数 × 社会贡献系数"，鼓励玩家全面发展而非只攒钱。
2. **卡牌双重功能 → 投资品的"过程收益+终局价值"**：每个企业/副业投资品既提供每回合现金流（过程收益），又在终局时按特定条件计分（终局价值）。
3. **贸易路线 → 人脉网络的可视化**：财商流的"人脉"资源可设计为版图上的连接关系，人脉网络越广，可触达的投资机会越多。
4. **⚠️ 简化警示**：Concordia 的乘法计分在心算时可接受（整数小数字），但财商流若引入过多维度会导致终局计算繁琐。建议控制在 3 个乘法维度以内，或由 Agent 自动计算。

## 5. Hotel Tycoon（酒店大亨）

### 5.1 背景与设计理念

- **设计师**：⚠️ 公开资料不足，未查证具体设计师姓名
- **出版年**：2013（Asmodee 版）；原版 Hotels 更早
- **出版社**：Asmodee / MB Giochi
- **玩家人数**：2–4 人 | **时长**：60–90 分钟 | **适龄**：8+
- **复杂度评级**：BGG Weight ≈ 1.5/5（轻度）
- **设计初衷**：以大富翁式的掷骰移动为基础框架，叠加酒店建设与地租收取机制。定位为家庭级商业启蒙游戏，规则简单但包含地产开发、贷款、破产等核心商业概念。

### 5.2 完整游戏流程

1. **开局准备**：每人选择颜色车辆棋子置于起点。起始资金：2–3 人 ¥16,000 / 4 人 ¥12,000。银行和国会厅放置在版图指定位置。
2. **回合结构**：掷骰子顺时针移动。停在钞票图标格可购买相邻无主地契（每回合限 1 块）。停在建筑图标格可掷特制骰子决定是否允许建造。经过银行格领取 ¥2,000。
3. **建造规则**：掷建造骰子——绿色=原价建造、红色=双倍造价、黄色=免费建造。建筑分 5 星级，星级越高地租越贵。
4. **地租收取**：对手停在你的酒店所在格时，按星级支付住宿费。
5. **结束条件**：最后一名未破产者获胜。或预设轮数结束后资产最多者获胜。

### 5.3 详细规则

- **强制买入**：购地后未及时建造，他人停在同格可按半价强制收购。这防止囤地不建。
- **休闲设施**：可在酒店旁加建游泳池/网球场等，提升地租。
- **飞机旅行**：特定格子可乘飞机跳转到远处，加速版图循环。
- **国会厅/教堂**：特殊格子，停留时触发随机事件（罚款/奖励/免税等）。

### 5.4 道具/卡牌系统

| 类型 | 数量 | 关键字段 | 说明 |
|------|------|---------|------|
| 地契 | 8 张 | 地段、地价、强制买入价 | 对应 8 个酒店地块 |
| 建筑模型 | 28 个 | 星级、颜色 | 物理放置在版图上 |
| 休闲设施 | 8 个 | 类型、加成 | 附属建筑 |
| 纸币 | 多面额 | ¥500–¥5000 | 交易媒介 |
| 建造骰子 | 1 个 | 绿/红/黄三面 | 决定建造成本 |

### 5.5 棋盘设计

环形赛道式版图（类似大富翁），内含 8 个酒店地块、银行、国会厅、机场等特殊格。每个酒店地块旁有建筑放置区和休闲设施区。

### 5.6 棋牌设计

- **地契**：硬卡纸，正面印地段信息+价格，背面统一花色。
- **建筑模型**：塑料立体酒店，按星级分层叠放。
- **车辆棋子**：塑料小汽车，四色区分。

### 5.7 经济系统（真实世界模拟机制）

- **地产开发循环**：购地 → 建造 → 收租 → 升级。这是最经典的房地产投资模型。
- **建设贷款**：⚠️ 公开资料对贷款具体规则描述不一致，部分版本含银行贷款机制，部分版本不含。已查证版本中，资金不足时可通过抵押地契获取半价现金。
- **地租定价**：由星级决定，星级越高租金呈指数增长。模拟现实中酒店星级与房价的关系。
- **破产流程**：无法支付住宿费/罚款时，先出售建筑（半价）→ 再抵押地契（半价）→ 仍不足则破产。破产者资产归债权人或银行拍卖。
- **对应真实概念**：房地产开发周期、资产抵押融资、租金回报率、破产清算顺序。

### 5.8 角色/玩家差异

所有玩家完全对称。差异化仅来自骰子运气与购地时机。

### 5.9 财商理念与核心策略

- **核心理念**：地产投资的核心是"位置+时机"。好地段早买早受益。
- **高手策略**：优先购买高频经过的地段 → 尽快升到 3 星以上 → 用高租金逼迫对手现金流紧张。
- **新手常见错误**：分散购地不集中升级、忽视建造骰子的风险（红色=双倍造价）、现金全投地产不留应急资金。

### 5.10 对「财商流游戏」的可借鉴点

1. **生存圈副业的"轻量地产"模型**：酒店大亨的"购地→建造→收租"三步循环可作为财商流生存圈副业的基础模板。简化为：投入启动资金 → 每回合产出被动收入 → 可追加投资升级。
2. **破产隔离设计参考**：酒店大亨的破产是"个人破产"——所有资产清零。财商流应区分"企业破产"（有限责任，仅损失投入资本）与"个人破产"（无限连带，波及个人资产）。这是重要的财商教育点。
3. **⚠️ 局限性**：酒店大亨本质是大富翁换皮，经营深度不足。财商流的企业经营应远超此水平，本节主要借鉴其"简化程度"作为下限参考。

## 6. Manager / Менеджер（苏联/俄罗斯经典财商教具）

### 6.1 背景与设计理念

- **起源**：苏联晚期（1980s 末–1990s 初），Monopoly 在苏联被禁后的替代品
- **出版年**：约 1988–1992 年间多个版本流通
- **出版社**：⚠️ 公开资料不足，未查证具体出版社。已知至少有列宁格勒、莫斯科两地独立生产的版本
- **玩家人数**：2–6 人 | **时长**：60–120 分钟 | **适龄**：10+
- **复杂度评级**：⚠️ 公开资料不足，估计 BGG Weight ≈ 1.5–2.0/5
- **设计初衷**：在计划经济体制下向青少年普及市场经济基本概念。据学术研究（HSE University, Abramov 2020），Manager 是苏联晚期"DIY Monopoly"现象的代表作，最初以"科学与理性"自居，承诺教会玩家"企业管理"，实际玩法仍以掷骰买地为主。

### 6.2 完整游戏流程

⚠️ 公开资料不足，以下基于 BGG 条目与学术论文交叉推断：

1. 类似 Monopoly 的环形赛道，但主题从"地产垄断"改为"企业管理"。
2. 玩家扮演企业经理，通过购买"生产单位"（而非地产）来获取收入。
3. 包含"计划指标""物资调配"等苏联特色元素，但具体规则因版本差异极大。

### 6.3 详细规则

⚠️ 公开资料不足，未查证完整规则。已知要素：
- 保留了 Monopoly 的掷骰移动+购买资产+收取费用的核心循环。
- 将"地产"替换为"工厂/商店/合作社"等社会主义经济单位。

### 6.4 道具/卡牌系统

### 6.5 棋盘设计

环形赛道，视觉风格为苏联宣传画风格。格子内容从"街道名"改为"工厂名/合作社名"。

### 6.6 棋牌设计

⚠️ 公开资料不足。已知为简易印刷纸板+纸质货币，制作质量参差不齐（多为地下作坊生产）。

### 6.7 经济系统（真实世界模拟机制）

- **历史意义 > 机制深度**：Manager 的价值不在于游戏设计本身，而在于它是"计划经济向市场经济转型期的文化 artifact"。它反映了苏联民众对"什么是资本主义经营"的朴素想象。

- **对应真实概念**：市场经济启蒙教育、计划经济与市场经济的概念碰撞、企业文化载体。

### 6.8 角色/玩家差异

⚠️ 公开资料不足。推测为完全对称。

### 6.9 财商理念与核心策略

- **核心理念**：作为教育工具，Manager 试图传达"企业经营需要管理能力"的理念，但实际游戏性不足以支撑深度学习。
- **历史教训**：好的财商教育游戏不能只是"换个皮的 Monopoly"。必须有真正的经营决策空间，而非纯粹的资产积累竞速。

### 6.10 对「财商流游戏」的可借鉴点

1. **反面教材**：Manager 证明了"换皮 Monopoly ≠ 财商教育"。财商流的企业经营必须有独立的决策机制，不能退化为"买地收租"。
2. **文化适配的重要性**：Manager 的成功在于它将西方商业概念翻译成了苏联语境下的"企业管理"。财商流的中国化同样需要将商业概念翻译为中国语境（如"编制内创业""个体工商户""合伙企业"等）。
3. **⚠️ 资料局限**：本节内容大量标注"未查证"，仅供历史文化参考，不建议直接借鉴具体机制。

### 7.1 背景与设计理念

#### Capitalism Lab

### 7.2 完整游戏流程

#### Capitalism Lab

1. **创建公司**：设定公司名称、初始资本、所在城市。可选择零售/制造/农业/房地产/传媒等行业起步。

#### 《大富翁》系列

1. **掷骰移动**：经典强手棋循环。
2. **资产购买**：土地、股票、公司股权。
3. **卡片/神明**：使用功能卡干扰对手或增益自身。

### 7.6 棋牌设计

#### Capitalism Lab

纯数字化界面。财务报表采用与现实会计准则一致的格式：

**资产负债表（Balance Sheet）**：
- 资产侧：现金及等价物、应收账款、存货、固定资产（厂房/设备/土地）、无形资产（专利/品牌）
- 负债侧：应付账款、短期借款、长期借款、应付债券
- 所有者权益：股本、资本公积、留存收益

**利润表（Income Statement）**：
- 营业收入 → 营业成本 → 毛利润 → 销售费用 → 管理费用 → 研发费用 → 营业利润 → 利息支出 → 税前利润 → 所得税 → 净利润

**十项财务绩效指标**：
1. 毛利率（Gross Profit Margin）
2. 净利率（Net Profit Margin）
3. 资产回报率 ROA（Return on Assets）
4. 股东权益回报率 ROE（Return on Equity）
5. 总资产周转率（Total Asset Turnover）
6. 应收账款周转率（Accounts Receivable Turnover）
7. 存货周转率（Inventory Turnover）
8. 资产负债率（Debt-to-Assets Ratio）
9. 权益资产比率（Equity-to-Assets Ratio）
10. 利息保障倍数（Interest Coverage Ratio）

#### 《大富翁》系列

数字化界面，含股票行情看板、卡片图鉴、角色立绘。

### 7.7 经济系统（真实世界模拟机制）

#### Capitalism Lab —— 三表联动详解

**这是对财商流"三表联动"设计最具参考价值的系统。**

- **损益表 ↔ 资产负债表**：净利润流入留存收益（资产负债表所有者权益增加）。折旧费用减少固定资产净值同时减少利润。利息支出减少利润同时减少负债对应的现金。
- **资产负债表 ↔ 现金流量表**：现金变动 = 经营活动现金流 + 投资活动现金流 + 筹资活动现金流。购建固定资产（投资活动）减少现金但增加固定资产。发行债券（筹资活动）增加现金同时增加负债。
- **损益表 ↔ 现金流量表**：净利润 ≠ 经营现金流（需调整折旧、应收/应付变动、存货变动等非现金项目）。
- **股市模型**：股价 = f(每股收益 EPS, 市盈率 PE, 市场情绪, 行业前景)。PE 受宏观经济（利率/GDP 增速）与行业竞争格局影响。玩家可通过回购提升 EPS、通过并购扩大规模、通过分红吸引价值投资者。
- **AI 竞争对手**：最多 20 家 AI 公司，各有独立的经营策略（激进扩张/稳健经营/专注细分）。AI 会根据市场供需调整定价、产能、研发投入。AI 也会参与股市交易与并购。

#### 《大富翁》系列

- **股票系统**：简化版股市，股价波动主要受玩家买卖行为与随机事件驱动。缺乏基本面分析维度。
- **房地产**：经典"购地→建房→收租"循环，与大富翁桌游一致。
- **公司经营**：部分代数（如大富翁 4）允许投资公司获取分红，但经营过程高度抽象。

### 7.8 角色/玩家差异

#### Capitalism Lab

- 起始条件可自定义（初始资本、城市、行业）。
- AI 竞争对手有不同性格参数（激进度、多元化倾向、研发投入偏好）。
- 高管聘用带来能力差异化。

#### 《大富翁》系列

- 每个角色有独特技能/属性（如钱夫人擅长炒股、阿土伯擅长地产）。
- 神明附身提供临时能力差异。

### 7.9 财商理念与核心策略

#### Capitalism Lab

- **核心理念**：企业经营是系统工程。任何单一维度的优化（如只追求营收增长）都会在其他维度暴露风险（如现金流断裂、负债过高）。
- **高手策略**：早期聚焦单一品类建立品牌 → 中期纵向整合供应链降低成本 → 后期横向并购扩大市场份额 → 全程关注财务健康指标（资产负债率 < 60%、流动比率 > 1.5）。
- **新手常见错误**：盲目多元化、忽视现金流只看利润、不设止损线在股市中被套牢、不聘高管事事亲力亲为导致决策瓶颈。

#### 《大富翁》系列

- **核心理念**：资产管理 + 风险管理。股票与地产的组合配置、卡片的使用时机都是风险管理的体现。
- **高手策略**：早期囤地 → 中期炒股套利 → 后期用卡片封锁对手关键地块。

### 7.10 对「财商流游戏」的可借鉴点

1. **三表联动的简化实现**：Capitalism Lab 的完整三表对桌游来说过于复杂。建议财商流采用"简化三表"：
   - **损益表**：收入 - 成本 - 折旧 - 利息 = 净利润（5 行以内）
   - **资产负债表**：现金 + 固定资产 + 投资 = 负债 + 净资产（6 行以内）
   - **现金流量表**：经营/投资/筹资三类现金流净额（3 行）
   - Agent 自动维护三表勾稽关系，玩家只需看摘要仪表盘。
2. **AI 竞争对手的参数化设计**：Capitalism Lab 的 AI 性格参数（激进度/多元化/研发偏好）可直接用于财商流的 Agent NPC 企业。每个 Agent 经营的企业有独立的经营风格，由 LLM 根据参数生成决策。
3. **高管聘用 → Agent 自动结算分工**：财商流中玩家经营企业时，可"聘用"Agent 担任 COO/CMO 等角色，Agent 自动处理日常经营（采购/定价/招聘），玩家只做战略决策（扩产/并购/退出）。这既降低了操作负担，又体现了"委托-代理"的真实商业关系。
4. **企业集团架构 → 自由圈资本运作**：财商流自由圈的"资本运作与并购"可借鉴 Capitalism Lab 的母子公司架构。玩家可设立控股公司，通过注资/分红/IPO 等操作实现资本增值。
5. **《大富翁》的卡片系统 → 财商流的"事件卡"**：大富翁的功能卡（涨价/降价/查封等）可改造为财商流的"市场事件卡"，由 Agent 或玩家触发，影响特定行业/企业的经营环境。

## 财商流游戏「企业与副业投资品」借鉴综合建议

### ① 生存圈副业的轻量化经营循环设计

借鉴 Hotel Tycoon 的三步循环 + FCM 的四步循环，简化为：

```
每回合副业决策（≤ 1 分钟）：
  选择产品/服务类型 → 设定价格档位（低/中/高三档） → 确认
Agent 自动结算：
  市场需求检定 → 竞争比价 → 计算收入 → 扣除成本 → 更新损益
```

- 副业不需要"招聘/培训"等重操作，启动门槛低（投入少量金钱+精力）。
- 价格档位代替精确数字定价，降低心算负担。
- Agent 负责计算细节，玩家只做"做什么+卖多少钱"的战略决策。

### ② 积累圈企业创办→运营→分红→出售的完整生命周期规则建议

借鉴 Brass 的"基础设施依赖" + TM 的"引擎构筑" + FCM 的"定价竞争"：

```
创办阶段（1–2 回合）：
  投入启动资金 + 人脉资源 → 选择行业 → 完成前置条件（供应链/资质）
运营阶段（每回合）：
  战略决策（扩产/研发/营销/定价）→ Agent 自动结算经营结果 → 更新三表
分红阶段（每 N 回合或触发条件）：
  净利润 × 分红比例 = 股东分红 → 可选择再投资或提取
出售阶段（任意回合）：
  估值 = 净资产 × 行业倍数 + 品牌溢价 → 挂牌出售 → 竞价/议价 → 交割
```

- 企业生命周期与人生时间轴绑定（20–60 岁），不同年龄段适合不同行业。
- 出售企业是积累圈→自由圈的关键跃迁节点。

### ③ 自由圈并购与资本运作

借鉴 Capitalism Lab 的母子公司架构 + Concordia 的乘法计分：

- 玩家可设立控股公司，收购积累圈中经营良好的企业。
- 并购方式：现金收购 / 换股合并 / 杠杆收购（LBO）。
- 资本运作工具：IPO、增发、回购、分拆、资产重组。
- 终局计分中，"成功并购并整合的企业数量"作为独立计分维度。

### ④ 企业经营的三表记账规则

借鉴 Capitalism Lab 的完整三表，简化为桌游可操作的版本：

**简化损益表（每回合更新）**：
```
营业收入（销售额）
- 营业成本（原材料 + 人工 + 租金）
- 折旧（固定资产 / 使用年限）
- 利息支出（贷款余额 × 利率）
= 净利润
```

**简化资产负债表（每回合更新）**：
```
资产：现金 | 固定资产净值 | 投资
负债：银行贷款 | 应付账款
净资产 = 资产 - 负债
```

**简化现金流量表（每回合更新）**：
```
经营现金流 = 净利润 + 折旧 - 应收变动 - 存货变动
投资现金流 = -购建固定资产 + 出售资产
筹资现金流 = +新增贷款 - 偿还贷款 - 分红
现金净变动 = 三项之和
```

- Agent 自动维护三表勾稽关系。
- 玩家看到的是"仪表盘摘要"（净利润趋势、资产负债率、现金流健康度），而非原始报表。
- 仅在"审计事件"或"年度总结"时展示完整三表。

### ⑤ 企业失败与个人破产的隔离设计

借鉴 Hotel Tycoon 的破产流程 + Capitalism Lab 的公司独立性：

- **有限责任公司**：企业破产时，玩家仅损失已投入的股本。个人资产（现金、房产、其他投资）不受影响。这是默认模式。
- **无限连带责任**：若玩家选择了"个人担保贷款"（利率更低但风险更高），企业破产时个人资产需偿还剩余债务。这是高风险高回报选项。
- **个人破产**：当个人净资产 < 0 且无法通过变卖资产清偿时，触发个人破产。进入"重整期"（3–5 回合），期间无法创办新企业、无法获得贷款，但可继续工作赚取工资。
- **教育意义**：通过游戏体验让玩家理解"有限责任"与"无限连带"的区别，这是现实创业中最关键的法律概念之一。

### ⑥ 经营环节的节奏控制与 Agent 自动结算分工

借鉴 Capitalism Lab 的高管聘用 + FCM 的零运气特性：

- **节奏控制**：每回合企业经营决策时间上限 2 分钟。超时则由 Agent 按"保守策略"自动决策。
- **Agent 角色分工**：
  - **银行家 Agent**：审批贷款、评估信用、执行清算。
  - **教练 Agent**：在玩家首次经营企业时提供引导提示。
  - **NPC 雇主 Agent**：经营同行业竞争企业，提供动态市场压力。
  - **AI 玩家 Agent**：作为完整玩家参与游戏，经营自己的企业组合。
- **自动结算范围**：Agent 负责所有数值计算（成本/收入/折旧/税费/三表更新），玩家只负责战略选择（做什么/不做什么/何时退出）。
- **透明度**：Agent 的每一步结算都可展开查看详细过程（类似狼人杀的 BotTranscripts），确保玩家信任系统公平性。
