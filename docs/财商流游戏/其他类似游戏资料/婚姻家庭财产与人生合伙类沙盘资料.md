## 1. 为什么单独调研婚姻家庭财产

财商流游戏现有《规则与经济系统》第 11 章已定义结婚/生子/离婚三张事件卡，配偶工资与支出参数已写入 §10.3。但从真实世界看，婚姻远不止"加一张配偶卡"——它涉及**财产制的法律默认规则**（婚后收入自动共有）、**彩礼这一中国特色的大额一次性债务/资产**、**离婚时房产分割的复杂计算**、**家务劳动补偿**、**共同债务认定**，以及**家庭财务冲突对离婚的预测力**。

本档的核心价值：**把婚姻从"事件卡加一张配偶参数卡"升级为"可计算的合伙财产制度模拟层"**，让玩家在游戏桌前真实体验——

- 婚前存款与婚后存款的法律边界；
- 彩礼是"资产流入"还是"债务预付"；
- 加名到底意味着什么；
- 离婚时 50% 分割 + 家务补偿的计算逻辑；
- 一方的投资亏损是否牵连配偶（共同债务认定）。

## 2. 婚姻的本质：人生合伙制公司

### 2.1 法理隐喻：婚姻 = 法定合伙

《民法典》虽然没有直接定义婚姻为"合伙"，但其财产制结构高度类比**默示合伙（partnership by default）**：

| 合伙制特征 | 婚姻对应规则 |
|-----------|------------|
| 合伙人按约定出资 | 婚前财产 = 个人财产（第 1063 条）；婚后所得 = 共同财产（第 1062 条） |
| 合伙收益按约定分配 | 婚后工资/投资收益自动共有（无需约定） |
| 合伙人退伙时结算 | 离婚时财产分割（第 1087 条） |
| 合伙债务连带 | 夫妻共同债务连带清偿（第 1064 条） |
| 退伙需清算 | 离婚登记 / 诉讼离婚 |
| 劳务出资可计量 | 家务劳动补偿（第 1088 条）——把"劳务出资"货币化 |

> **游戏化启示**：财商流游戏可把"结婚事件"设计为**签订一份默认合伙协议**——玩家可以选择"法定共同财产制"（默认）或"约定分别财产制"（需主动选择），后者将解锁不同的事件触发概率。

### 2.2 婚姻的三个经济阶段

| 阶段 | 典型时长 | 财务特征 | 游戏对应 |
|------|---------|---------|---------|
| **婚前** | 恋爱期 | 各自财产独立；可能产生彩礼/嫁妆/购房出资 | 结婚前事件：彩礼支付、房产加名 |
| **婚姻存续期** | 1–50+ 年 | 收入自动共有；共同债务连带；子女养育支出叠加 | 配偶工资持续计入；共同债务事件卡 |
| **离婚/丧偶** | 一次性事件 | 财产清算分割；家务补偿；抚养费支付 | 离婚事件卡；财产分割计算；抚养费支出 |

## 3.《民法典》婚姻家庭编核心规则（财产制·债务·补偿·分割）

> 以下条文自 2021 年 1 月 1 日起施行，取代原《婚姻法》及相关司法解释。

### 3.1 第 1062 条：夫妻共同财产范围

婚姻关系存续期间所得的下列财产为**夫妻共同财产**：

1. 工资、奖金、劳务报酬
2. 生产、经营的收益
3. 投资的收益
4. 知识产权的收益
5. 继承或受赠的财产（但遗嘱/赠与合同中确定只归一方的除外）
6. 其他应当归共同所有的财产

> **核心原则**：**婚后取得的收入自动共有，无需登记、无需约定。** 这是中国法定财产制的默认规则。

**配套解释**（《婚姻家庭编解释（一）》第 25 条）——"其他应当归共同所有的财产"包括：
- 一方以个人财产投资取得的收益；
- 男女双方实际取得或应当取得的住房补贴、住房公积金；
- 男女双方实际取得或应当取得的基本养老金、破产安置补偿费。

### 3.2 第 1063 条：夫妻一方的个人财产

下列财产为**个人财产**：

1. 一方的**婚前财产**
2. 一方因受到人身损害获得的赔偿或者补偿
3. 遗嘱或者赠与合同中确定只归一方的财产
4. 一方专用的生活用品
5. 其他应当归一方的财产

> **关键推论**：婚前存款、婚前房产、婚前投资——无论婚姻持续多久，本金部分仍归个人（除非混同或赠与）。

### 3.3 婚后收益的"三分类"（《婚姻家庭编解释（一）》第 26 条）

夫妻一方个人财产在婚后产生的收益，按以下规则认定：

| 收益类型 | 认定 | 举例 |
|---------|------|------|
| **孳息** | 个人财产 | 婚前存款的利息、婚前房产的租金 |
| **自然增值** | 个人财产 | 婚前房产因市场上涨的增值 |
| **其他收益（主动经营/投资）** | **夫妻共同财产** | 婚前股权在婚后增值、婚前基金在婚后卖出收益 |

> **游戏化要点**：这一区分非常值得在游戏里体现。如果玩家婚前持有 50 万存款，婚后存款利息仍归个人；但婚前持有的 50 万基金若在婚后卖出获利，收益部分要计入共同财产。

### 3.4 第 1064 条：夫妻共同债务认定

本条是 2021 年《民法典》吸收 2018 年最高人民法院司法解释的立法成果，**彻底推翻**了 2003 年《婚姻法司法解释（二）》第 24 条"推定共同债务"原则。

**第一款（属于夫妻共同债务）**：
1. 夫妻**双方共同签名**或夫妻一方**事后追认**等共同意思表示所负的债务（"共债共签"）
2. 夫妻一方以个人名义为**家庭日常生活需要**所负的债务（"共需共债"）

**第二款（不属于 + 例外）**：
- 夫妻一方以个人名义**超出家庭日常生活需要**所负的债务 → **不属于**夫妻共同债务
- **例外**：债权人能够证明该债务用于夫妻共同生活、共同生产经营或基于夫妻双方共同意思表示

| 债务类型 | 俗称 | 认定规则 |
|---------|------|---------|
| 共同签字/追认 | "共债共签" | 直接认定 |
| 日常家庭生活需要 | "共需共债" | 推定共同债务 |
| 超日常需要 | "共用共债" | 债权人举证，否则非共同 |

> **举证责任分配**：超出日常需要的债务由**债权人**承担举证责任——这保护了不知情的配偶方。

### 3.5 第 1088 条：家务劳动补偿

> 夫妻一方因抚育子女、照料老年人、协助另一方工作等**负担较多义务**的，离婚时有权向另一方请求补偿，另一方应当给予补偿。具体办法由双方协议；协议不成的，由人民法院判决。

**立法突破**：旧《婚姻法》第 40 条要求家务补偿必须以"夫妻书面约定分别财产制"为前提，由于中国仅约 3%–5% 的家庭实行分别财产制，该条款长期休眠。**《民法典》第 1088 条取消了这一前置条件**。

#### 2021 年北京首案（全国首例）

| 项目 | 内容 |
|------|------|
| 法院 | 北京市房山区人民法院 |
| 当事人 | 陈先生（男方）诉王女士（女方） |
| 时间 | 2021 年 2 月一审判决；2021 年 3 月 25 日二审维持 |
| 背景 | 2015 年结婚，育有一子；2018 年 7 月分居；孩子随王女士生活 |
| 家务补偿判决 | **陈先生给付王女士家务补偿款 5 万元** |
| 考量因素 | 双方婚后共同生活时间 + 女方家务付出具体情况 + 男方经济收入 + 当地生活水平 |
| 社会反响 | 冲上微博热搜；"北京找个保姆一年都不止 5 万"成热议焦点 |

> **游戏化要点**：财商流游戏可把"家务补偿"做成离婚事件卡的隐藏分支——若婚姻存续 > 5 年且有子女，离婚时非抚养方可主张一次性补偿（按当地月均工资 × 月数，上限待定）。

### 3.6 第 1087 条：离婚财产分割原则

离婚时夫妻共同财产由双方协议处理；协议不成的，法院根据财产具体情况，**按照照顾子女、女方和无过错方权益**的原则判决。

- **一般原则**：共同财产均等分割（50%：50%）
- **倾斜情形**：照顾子女抚养方、照顾女方、照顾无过错方（如家暴/出轨）
- **《规则与经济系统》现状**：当前§11.2.3 离婚事件卡的"50% 判给配偶" + "过错方比例可调整"与法条一致，**无需修改**

## 4. 彩礼制度与 2024 最高法司法解释

彩礼是中国婚姻财务最具特色的模块，也是玩家最容易产生强烈情绪反应的切入点。

### 4.1 2024 年《涉彩礼纠纷司法解释》核心内容

| 项目 | 内容 |
|------|------|
| 名称 | 《最高人民法院关于审理涉彩礼纠纷案件适用法律若干问题的规定》 |
| 文号 | 法释〔2024〕1 号 |
| 通过 | 2023 年 11 月 13 日（最高法审委会第 1905 次会议） |
| 公布 | 2024 年 1 月 17 日 |
| 施行 | **2024 年 2 月 1 日** |
| 全文 | 共 7 条 |

#### 核心条款摘要

| 条款 | 要点 |
|------|------|
| **第 1 条** | 适用范围：以婚姻为目的依据习俗给付彩礼后要求返还的纠纷 |
| **⭐ 第 2 条** | **禁止借婚姻索取财物**。一方以彩礼为名借婚姻索取财物，另一方要求返还的，法院应予支持 |
| **第 3 条** | **彩礼认定范围**：综合当地习俗、给付时间方式、财物价值、给付接收人等认定。**以下不属于彩礼**：①节日/生日等特殊时点给付的价值不大的礼物礼金；②为表达/增进感情的日常消费性支出；③其他价值不大的财物 |
| **第 4 条** | 诉讼主体：婚约财产纠纷中，婚约一方及其**实际给付彩礼的父母**可作为共同原告；接收方及其**父母**可作为共同被告 |
| **⭐ 第 5 条** | **已办结婚登记 + 共同生活**：离婚时请求返还彩礼一般**不予支持**。**例外**：共同生活时间**较短**且彩礼数额**过高**——可酌情返还（综合彩礼数额、共同生活及孕育情况、双方过错、当地习俗） |
| **⭐ 第 6 条** | **未办登记但已共同生活**：根据彩礼实际使用及嫁妆情况，综合共同生活及孕育情况、双方过错、当地习俗，确定是否返还及返还比例 |
| **第 7 条** | 2024 年 2 月 1 日起施行；施行后尚未审结的一审、二审案件适用 |

> **核心信号**：司法解释保护女性孕育付出——将妊娠、分娩、抚育子女作为"酌情减少甚至不予返还"的考量因素。

### 4.3 彩礼的游戏化映射

| 真实规则 | 财商流游戏映射建议 |
|---------|------------------|
| 彩礼是男方家庭向女方家庭的大额转移 | 结婚事件触发时，从男方玩家现金中一次性扣除（按地区档位的随机值） |
| 女方可能带"嫁妆"（等价或超额回赠） | 根据配偶画像类型，嫁妆概率/比例不同（如"专业人士"配偶高嫁妆概率） |
| 共同生活短 + 彩礼高 → 离婚时可主张返还 | 离婚事件卡加分支：婚姻存续 < 1 年 → 彩礼按比例返还 |
| 借婚姻索取财物 = 违法 | 设计"彩礼诈骗"事件卡：若玩家抽到此卡，彩礼支出且不触发配偶工资（= 人财两空） |

## 5. 离婚房产分割与"加名"规则

房产是中国家庭最大单项资产（央行 2019 调查：住房占总资产 59.1%），离婚房产分割是游戏中最应该复杂化的模块。

### 5.1 婚前按揭房 + 婚后共同还贷（《婚姻家庭编解释（一）》第 78 条）

**规则**：
> 夫妻一方婚前签订不动产买卖合同，以个人财产支付首付款并在银行贷款，婚后用夫妻共同财产还贷，不动产登记于首付款支付方名下的，离婚时该不动产由双方协议处理。不能达成协议的，法院可以判决该不动产归登记一方，尚未归还的贷款为登记一方的**个人债务**。双方婚后共同还贷支付的款项及其相对应财产增值部分，离婚时由登记一方对另一方进行**补偿**。

**常用补偿公式**：

```
补偿额 = 共同还贷本息总额 ÷ 房屋总成本（购房总价 + 已还利息 + 其他费用）× 离婚时房屋现值 × 50%
```

**数值示例**（司法考试常用模型）：

| 参数 | 数值 |
|------|------|
| 购房总价 | 100 万元 |
| 首付 | 30 万元（婚前，男方） |
| 贷款 | 70 万元 |
| 婚后共同还贷 | 40 万元（本金 20 万 + 利息 20 万） |
| 离婚时房屋现值 | 200 万元 |
| **补偿额** | 40 万 ÷ (100 万 + 20 万) × 200 万 × 50% = **约 33.3 万元** |

> **游戏化要点**：玩家婚前购房+婚后共同还贷的，离婚时房产归原所有人，但需向配偶一次性支付"共同还贷 + 增值补偿"——这一笔现金流冲击应该体现在离婚事件卡中。

### 5.2 "加名"的法律效果

| 情形 | 法律认定 |
|------|---------|
| **婚前加名**（婚前房产加配偶名） | 通常视为**赠与**，房产变为夫妻共同财产（按份共有或共同共有视登记） |
| **婚后加名** | 一般认定为共同财产，但分割时不一定均等——法院仍考虑出资贡献、婚龄、过错等 |
| **加名 ≠ 均分** | 即使加名，法院可酌定分割比例（如出资方 70% : 30%） |

> **游戏化要点**：加名是一张**高风险决策卡**——婚后主动加名将房产变为共同财产，离婚时面临分割；不加名则房产归个人，但需支付"共同还贷补偿"。玩家需权衡。

### 5.3 父母出资购房（《婚姻家庭编解释（一）》第 29 条）

| 出资时间 | 出资对象 | 认定 |
|---------|---------|------|
| **婚前** | 对自己子女的赠与 | 视为个人财产（除非明确赠与双方） |
| **婚后** | 无约定 | 按夫妻共同财产处理 |

## 6. 全职主妇/主夫的经济风险与保障

### 6.1 经济弱势的三大来源

全职主妇（或主夫）在离婚时面临三重经济风险：

| 风险 | 说明 |
|------|------|
| **1. 收入中断** | 离婚后从"零工资"重返职场，存在职业断层与再就业困难 |
| **2. 社保断缴** | 灵活就业者需自行缴纳养老/医疗，公积金断缴影响房贷 |
| **3. 财产积累不足** | 婚姻存续期间的工资积累多以房产/存款形式存在，被"共同财产"覆盖；离婚分割后可能只拿到少量现金 |

### 6.2 法律保护机制

| 保护机制 | 内容 | 局限 |
|---------|------|------|
| **家务补偿**（第 1088 条） | 一次性补偿，2021 年北京首案 5 万 | 数额普遍偏低，各地裁判尺度差异大 |
| **经济帮助**（第 1090 条） | 离婚时一方生活困难，有负担能力的另一方应给予适当帮助 | "生活困难"门槛较高 |
| **抚养费** | 不直接抚养子女一方每月支付 2,000–5,000（视地区） | 覆盖基本生活，难以保障原生活水平 |
| **婚内财产协议** | 可约定分别财产制（第 1065 条） | 社会接受度低，"谈钱伤感情" |

### 6.3 保险方案（游戏可借鉴）

| 工具 | 作用 |
|------|------|
| **百万医疗险** | 覆盖大额医疗支出，防"因病致贫" |
| **定期寿险** | 覆盖家庭支柱身故后的配偶/子女生活保障 |
| **年金险/增额终身寿** | 以个人财产投保 + 指定受益人，可实现"个人财产"隔离 |
| **婚前财产公证** | 对婚前房产/存款进行公证，防混同 |

> **游戏化要点**：财商流游戏中，全职主妇/主夫角色的"保险配置率"可影响离婚后的生存回合数——未配置保险者离婚后更可能触发"破产清算"。

### 7.2 离婚登记对数走势

| 年份 | 离婚登记对数（万对） | 备注 |
|------|---------------------|------|
| **2019** | 470.1 | 高点 |
| **2020** | 433.9 | 离婚冷静期尚未施行 |
| **2021** | 283.9 | 冷静期施行第一年，大幅下降 |
| **2022** | 287.9 | 小幅回升 |
| **2023** | 310+（待核实） | 继续小幅回升 |

> **离婚冷静期制度**（《民法典》第 1077 条）：2021 年 1 月 1 日起施行。提交离婚申请后有 **30 天冷静期**，任何一方可撤回；冷静期届满后 **30 天内双方需共同到场申请领证**，否则视为撤回。

**冷静期效果**：
- 2021 年离婚登记较 2020 年下降约 **140 万对**（降幅约 32%）；
- 但诉讼离婚（法院判决/调解）有所上升，说明部分需求从"协议离婚"转入"诉讼离婚"；
- 冷静期主要抑制的是"冲动型离婚"，对家暴/感情破裂型离婚影响有限。

### 7.3 宏观趋势的游戏化映射

| 宏观趋势 | 游戏对应 |
|---------|---------|
| 结婚率持续下降 | 结婚事件卡的触发概率可随游戏"年份"推进递减 |
| 离婚冷静期 | 离婚事件卡增加"冷静期"机制——触发后需等待 1–3 回合才能正式执行分割 |
| 诉讼离婚上升 | 玩家可选择"协议离婚"（均分）或"诉讼离婚"（由法官/骰子裁决，结果波动大） |

## 8. 家庭财务行为研究：金钱冲突·权力结构·隐性账户

> 以下研究结论来自婚姻家庭心理学与行为经济学领域，为婚姻事件卡的"冲突设计"提供实证支撑。

### 8.1 金钱冲突是离婚的首要预测因子之一

| 研究 | 发现 |
|------|------|
| **家庭财务冲突研究（多国学者的元分析）** | 夫妻间金钱争吵的频率与离婚风险呈显著正相关；其预测力甚至超过性格不合、性生活不和谐等其他冲突类型 |
| **深层原因** | 金钱冲突不仅是"钱不够"问题，更反映夫妻间的**权力不对等**和**价值观差异**（消费观、储蓄观、对"安全感"的定义） |

> **游戏化要点**：游戏中夫妻双方若"财务决策倾向"不一致（如一方激进投资、一方保守储蓄），可累计"婚姻满意度"衰减值 → 衰减到阈值触发离婚事件。

### 8.2 家庭财务权力结构

| 模式 | 特征 | 与婚姻质量的关系 |
|------|------|----------------|
| **一方主导型** | 一人掌控全部财务决策 | 主导方满意度高，从属方隐性不满累积，长期风险高 |
| **共同管理型** | 双方共同决策，账户共用 | 通常婚姻满意度较高，但决策效率低 |
| **各自独立型（AA 制）** | 各管各的，按比例分摊家庭支出 | 灵活度高，但"算太清"可能削弱亲密感 |

### 8.3 隐性账户（私房钱）

| 研究结论 | 说明 |
|---------|------|
| **普遍性** | 隐性账户在婚姻中普遍存在，金额通常为主收入的 5%–15% |
| **短期效果** | 避免冲突、获得财务自主感 |
| **长期风险** | 一旦被发现，会**严重破坏夫妻信任**，修复难度极大 |
| **离婚预测** | 涉及隐藏财务行为的婚姻，离婚风险显著高于无隐藏行为者 |

> **游戏化要点**：财商流游戏可设计"私房钱"机制——玩家可在家庭共同账户之外持有私人小金库。效果：（1）平时不影响共同财产分割计算；（2）但若被"查账"事件卡发现 → 婚姻满意度骤降 + 触发离婚概率上升。

## 9. AA 制、共同账户与家庭财务制度实践

### 9.1 中国家庭的财产制度光谱

| 制度 | 占婚姻比例（估计） | 游戏映射 |
|------|-------------------|---------|
| **法定共同财产制**（默认） | 约 90%+ | 结婚后双方工资自动汇入共同账户 |
| **约定分别财产制** | 约 3%–5% | 玩家主动选择"婚前协议"后启用——各管各的 |
| **部分 AA 制**（混合） | 估计 15%–25%（城市双职工） | 双方按比例出资家庭共同账户，各自保留私房钱 |
| **一方全交型** | 传统模式，比例下降中 | 一方工资全额上交，按月领"零花钱" |

> **注意**：以上比例为非官方估计值（来自社会学田野调查与媒体报道），财商流游戏引用时应标注"社会学田野估计值"。

### 9.2 实践中的家庭财务模式

| 模式 | 适用人群 | 优势 | 风险 |
|------|---------|------|------|
| **完全共用** | 传统双职工、单收入家庭 | 透明、信任感高 | 一方可能失去财务自主 |
| **按比例分摊** | 城市双职工 | 公平、各自保留自主 | "算太清"可能伤感情 |
| **大账户 + 私房钱** | 多数中国家庭的实际做法 | 兼顾透明与弹性 | 私房钱被发现时信任崩塌 |
| **完全 AA** | 年轻情侣/丁克 | 极度独立 | 重大支出（育儿/购房）分摊困难 |

> **游戏化要点**：在结婚事件卡中，让玩家选择"家庭财务制度"——选择影响后续的现金流合并规则、私房钱上限、离婚分割计算方式。

## 10. 婚姻/家庭财务类沙盘、桌游与课程原型

### 10.1 Game of Life（人生游戏）——指针引用

> Game of Life（Hasbro 发行）是婚姻/家庭事件机制的经典桌游原型。

| 机制 | 设计概要（不展开数值） |
|------|---------------------|
| **结婚格** | 停在结婚格时加入配偶 peg，获得婚礼礼金，配偶工资计入月薪 |
| **配偶工资** | 结婚后月薪增加，离婚后移除 |
| **离婚** | 移除配偶 peg，支付一次性损失，失去配偶工资 |
| **Life Tiles（2021 版）** | "结婚 OR 领 5 万美元"二选一——婚姻作为**可选决策**而非强制 |
| **生子** | 加 baby peg，支出增加，可能获得保险理赔/遗产 |

> 💡 **对财商流游戏的启示**：Game of Life 把婚姻做成**可选决策**（结婚 or 领钱二选一）的设计，与《规则与经济系统》的"结婚格"强制触发形成差异。财商流可保留"强制触发 + 选择配偶类型"模式，但增加"延迟结婚/不结婚"选项（有代价）。

### 10.2 中国本土"婚姻家庭理财沙盘"课程

> 以下为市场调研综合条目（非单一来源课程）。"婚姻家庭理财沙盘"在中国尚无统一课程标准，多为培训机构/理财规划师/社区学堂的定制课程。

#### 10.2.1 常见课程形态

| 课程类型 | 主办方 | 内容 |
|---------|--------|------|
| **家庭资产配置沙盘** | 理财培训机构（如天元学堂、信涌书院等） | 使用"标准普尔家庭资产四象限"教具，让夫妻模拟家庭资产分配 |
| **婚前财产公证体验课** | 公证处 + 社区/律所 | 模拟婚前财产公证流程，讲解"什么算婚前/婚后财产" |
| **婚姻财务规划工作坊** | 理财规划师（CFP/AFP） | 夫妻共同完成家庭资产负债表，制定共同理财目标 |
| **离婚财产分割模拟法庭** | 法学院/律所/社区 | 用真实案例模拟离婚分割诉讼 |

#### 10.2.2 标准普尔家庭资产四象限——批判性评估

| 项目 | 内容 |
|------|------|
| **内容** | 把家庭资产分为四象限：① 要命的钱（10%，日常开销）；② 保命的钱（20%，保险）；③ 生钱的钱（30%，投资）；④ 保本的钱（40%，稳健资产） |
| **出处考证** | **学术上无权威出处**。Standard & Poor's 官方从未发布此"标准普尔家庭资产象限图"。该图最早出现于 2000 年代中文理财培训界，被冠以"标准普尔"名义推广，但标普官方对此无记录。学术界多将其视为"培训营销产物"而非严谨金融模型 |
| **批判意见** | （1）刚性比例（10/20/30/40）不考虑收入阶段、地区差异、家庭结构；（2）与标普官方发布的家庭理财指引无关；（3）误导性使用"世界四大评级机构"背书 |
| **游戏化建议** | 财商流游戏**不建议**直接使用该象限作为核心机制，但可将其作为"理财培训卡"的道具出现——玩家使用后可小幅提升财商认知，但有概率触发"过度简化认知" debuff（即现实中该象限的误导性） |

### 10.3 玩家职业设计中的配偶联动

## 12. 对财商流游戏的落地建议

### 12.1 婚姻事件卡深化（按优先级排序）

#### P0 — 与现有规则直接衔接

| 事件卡 | 规则建议 | 对应法条 |
|--------|---------|---------|
| **彩礼支付卡**（结婚触发） | 结婚时从男方玩家现金中扣除随机彩礼（按地区档位：农村档 15–35 万；城市档 0–10 万）。可触发"嫁妆回礼"（根据配偶画像类型概率性返还）。离婚时若婚姻存续 < 1 年，彩礼按比例返还 | 2024 彩礼司法解释第 5/6 条 |
| **房产加名卡**（婚后决策） | 玩家可主动选择将婚前房产"加名"为共同财产——离婚时配偶可分割，但加名后降低离婚触发阈值（配偶有动机离婚） | 加名 = 赠与（实务认定） |
| **离婚分割计算**（离婚触发） | 强化现有"50% 判给配偶"：① 区分婚前/婚后财产（婚前存款不分割）；② 婚前房产婚后共同还贷 → 支付补偿（共同还贷 × 增值比例 × 50%）；③ 家务补偿分支（婚龄 > 5 年 + 有子女 → 额外一次性补偿） | 第 1087/1088/78 条 |
| **共同债务事件卡** | 玩家投资/借款时，若超出日常需要且未经配偶签字 → 债务为个人债务（不由配偶承担）；若用于家庭 → 共同债务（配偶需连带）。可设计"被负债"负面事件：债权人起诉配偶 → 若无法举证"非共同债务"则配偶资产被冻结 | 第 1064 条 |

#### P1 — 增强真实感

| 事件卡 | 规则建议 |
|--------|---------|
| **家务补偿卡** | 离婚时由骰子/配偶画像决定家务补偿额（基准：当地月均工资 × 婚龄年数 × 系数 0.5–1.5） |
| **离婚冷静期** | 离婚事件卡触发后进入"冷静期"状态（1–3 回合），期间任何一方可撤回；冷静期结束后正式分割 |
| **私房钱发现事件** | 每隔若干回合投骰：若一方持有私房钱 → 概率触发"发现事件"→ 婚姻满意度骤降 + 离婚概率上升 |
| **婚姻财务制度选择**（结婚时） | 选择"完全共用 / 按比例分摊 / AA 制"——影响后续现金流合并与离婚分割计算 |
| **诉讼离婚 vs 协议离婚** | 协议离婚：均分；诉讼离婚：骰子裁决（波动大，可能 30:70 甚至极端比例） |

### 12.2 配偶资源联动（衔接 04 档案）

| 配偶画像类型 | 建议新增游戏机制 |
|-------------|----------------|
| **全职太太/主夫** | 本人工资 = 0；家庭支出 -30%（精打细算）；但"家务补偿"权重 ×1.5；保险配置率影响离婚后生存回合 |
| **普通职员** | 稳定工资 + 零花钱支出；离婚触发概率低（本分性格） |
| **专业人士** | 高工资 + 高支出；双职工家庭 → 房产加名概率高；时间稀缺 → 投资决策"快速拍板"（高波动） |
| **创业者** | 收入波动大（可能某月 0，也可能某月 5 万）；共同债务风险高（经营债务可转嫁家庭） |
| **自由职业** | 中等收入 + 社保自理（影响公积金贷款）；"私房钱"概率最高（收入不固定） |

### 12.3 家庭现金流合并规则建议

> 现有《规则与经济系统》§10.3 的配偶工资/支出机制为基础，建议新增以下规则：

```
结婚后家庭现金流 = 主玩家月现金流 + 配偶月工资 - 配偶月支出 - 家庭共享支出
```

| 新增参数 | 建议规则 |
|---------|---------|
| **家庭共享支出** | 结婚后额外 +5,000–15,000 元/月（住房/餐饮/社交合并） |
| **私房钱池** | 玩家可将月收入的 5%–15% 转入私人池（不计入共同财产分割基数），但"发现风险"累积 |
| **共同账户 vs 私人账户** | 根据婚姻财务制度选择——完全共用时私房钱池 = 0；AA 制时私房钱池自动为月收入的 50% |
