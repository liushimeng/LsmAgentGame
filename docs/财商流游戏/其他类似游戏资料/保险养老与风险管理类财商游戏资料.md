### 1.2 本文要补齐的三条核心线

1. **风险的真实结构**：低频高损 vs 高频低损，对应「保险 / 自留 / 预防 / 规避」四象限。
2. **保险的定价与转移逻辑**：保费如何对应风险概率、保额如何对应损失、为何「买定投余（buy term and invest the rest）」成立。
3. **退休资金的可持续性数学**：蒙特卡洛、4% 法则、序列收益风险、长寿风险，如何被游戏化。

### 1.3 对《财商流》三层棋盘的映射（一句话）

- **生存圈**：高频低损（医疗小额、失业、意外）→ 自留 + 小额医疗/意外险。
- **积累圈**：低频高损（重疾、身故、伤残）→ 定期寿险/重疾/长护险转移。
- **自由圈**：长寿 + 序列收益 → 年金 + 提款率纪律。

## 2. 保险主题沙盘与教具

### 2.1 保险公司 / 银行的客户教育沙盘

**背景**：保险机构与银行零售条线长期用「演示工具」做客户教育，而非严格意义的公开桌游。典型形式是「生命周期规划沙盘」：一张纸面时间轴，标注人生阶段（单身→家庭形成→子女教育→退休）与对应风险缺口。

**核心机制**：
- 用一条「收入曲线」与「支出曲线」叠加，凸显「责任最重、收入最高」的中段风险暴露最大。
- 通过「如果现在倒下，家庭缺口 = 负债 + 子女教育 + 父母赡养 − 现有资产」的减法，导出保额需求。

**真实世界依据**：此类工具属行业内部培训/销售辅助材料，**白名单域名无法抓取其原始模板**（中国保险行业协会、各险企内训资料不在白名单）→ 标注「公开资料未能验证」其统一标准版式。其底层逻辑（收入能力折现）与公开文献一致，属「训练知识待核验」。

**教育意图**：让玩家把「保险」从「花钱买心安」重构为「买断未来某笔确定负债的不确定性」。

**对财商流的可借鉴点**：可用「责任缺口 = 现存资产缺口」的减法算式，作为自由圈前「保障体检」环节。

### 2.2 保险行销的「草帽图 / 生命周期保障缺口」演示

**背景**：中文保险从业者培训中常见的两幅图——
- **草帽图（人生收支曲线图）**：用「支出线」（一生平滑）与「收入线」（工作期才有）之间的「草帽形状」缺口，说明「退休后无收入但仍要支出」。
- **保障缺口图（乒乓板/爬坡图）**：把人生分为「成长期（被保护）— 责任期（需自保）— 退休期（消耗）」。

**核心机制**：草帽图的「帽檐」= 退休后支出，「帽顶」= 工作期结余，直观表达「用工作期结余覆盖退休后缺口」的储蓄本质。

**真实世界依据**：属行业通用话术工具，无官方统一口径，白名单不可达 → **「训练知识待核验」**。图样本身非监管文件，不涉合规争议，仅作教育演示。

**教育意图**：把「养老储蓄」与「保障缺口」在一条时间轴上可视化。

**对财商流的可借鉴点**：草帽图可直接作为「自由圈入场前」的视觉教具，对应「长寿风险」章节。

### 2.3 保险规划桌游（公开可查品类）

**背景**：海外有面向青少年的「保险主题桌游 / 卡牌」，多把「风险事件卡」与「保单卡」配对；国内公开出版的少儿财商桌游中，保险多为一个「可选模块」。具体已出版桌游清单因 WebSearch 不可用**未能逐一核验**，仅作品类提示 → 「公开资料未能验证」具体书名与厂商。

**核心机制（典型）**：每位玩家持有一叠「人生事件」，可花费金币购买「保单」抵御对应事件；出险时由「保险公司 / 银行家」角色赔付。

**教育意图**：体验「小钱换大保障」的杠杆感，以及「没出事 = 钱白花」的心理摩擦（这是保险教育最难的一点，见 §7.2）。

**对财商流的可借鉴点**：直接复刻「银行家角色发保单、收保费、赔保额」的机制——与《财商流》已有「LLM Agent 当银行家」设定天然契合。

### 2.4 中国保险需求分析两大公开方法

| 方法 | 思路 | 公式骨架 | 可信度 |
| --- | --- | --- | --- |
| **遗属需求法（Needs Approach）** | 站在「被扶养人」视角，算「如果经济支柱倒下，家庭还差多少钱」 | 保额 = 负债 + 子女教育 + 父母赡养 + 家庭 N 年生活费 − 现有金融资产 | 训练知识待核验（行业通用，非监管强制） |

## 3. 养老金与退休模拟器

### 3.1 蒙特卡洛退休模拟的原理

**背景**：传统「我 60 岁有 200 万，每年花 10 万，能花 20 年」是确定性的、错误的——它假设每年正好 5% 回报、零波动。

**核心机制**：
- 对「未来年化收益率」「通胀」「寿命」做随机抽样（数千到数万次），每次得到一条退休路径。
- 统计「资产在身故前归零」的次数占比 → **破产概率**；其反面即**成功率（Probability of Success）**。
- 通常目标成功率 80%–90%（越高越保守，需更多本金或更省）。

**真实世界依据**：蒙特卡洛方法数学原理成熟（训练知识）。具体「退休规划器用几万次模拟、目标成功率取何值」属各家产品设定 → 「训练知识待核验」各家阈值。

**教育意图**：让玩家接受「退休不是算术题，是概率题」。

**对财商流的可借鉴点**：自由圈每次「年终结算」由 Agent 掷「市场骰子」并跑一次轻量蒙特卡洛，给出「你的钱撑过 90 岁的概率」。

### 3.2 Trinity Study 与 4% 法则

> 🔒 4% 法则 / Trinity Study 权威定义见《财商流游戏真实世界经济与财商理论底座》板块7；本节聚焦蒙特卡洛模拟的游戏化实现与退休计算器设计。

**背景**：1998 年 Trinity University 三位教授（Bengen 1994 补充）研究「退休首年提取组合 4%、 thereafter 随通胀上调，30 年不破产的历史胜率」。

**核心机制 / 结论（公开文献口径）**：
- 「4% 初始提取率 + 每年按通胀调整」在美股债历史回测中 30 年存活率很高（常被转述为「约 95%+」，**该精确数字本环境未抓原始论文 → 训练知识待核验**）。
- 适用前提：30 年退休期、美股+债券组合、历史回报可代表未来。

**适用边界与批评**：

| 批评点 | 说明 | 可信度 |
| --- | --- | --- |
| **序列收益风险（Sequence-of-Returns Risk）** | 退休初期遇到熊市，本金被低价变卖，后期无法恢复——同样的年均回报，顺序不同结果天差地别 | 训练知识（学界共识） |
| 退休期拉长 | 现代人活到 95+，30 年不够，需更低提取率（如 3.3%–3.5%） | 训练知识待核验（具体数值） |
| 低利率环境 | 债券收益率低于历史，安全提取率下移 | 训练知识待核验 |
| 费用与税收 | 未计管理费、税，实际可用更低 | 常识 |
| 单一历史样本 | 仅美国历史，非「未来保证」 | 文献自陈局限 |

**真实世界依据**：Trinity/Bengen 为公开学术文献，本环境 WebSearch 不可用、白名单无学术库 → **未能抓取原始论文，具体胜率数字一律标注「训练知识待核验」**。

**教育意图**：理解「4% 不是铁律，是历史经验值」，且对「退休头几年市场」极度敏感。

**对财商流的可借鉴点**：自由圈用「4% 初始提取率」作默认线，但若玩家退休头 3 年遇到熊市（市场周期卡），强制演示「序列收益风险」如何击穿提款。

### 3.5 4% 法则计算示例（教学用）

> 示例数值，用于演示机制，非投资建议。

| 变量 | 值 | 说明 |
| --- | --- | --- |
| 退休时资产 A | 1,000,000（虚拟币） | — |
| 初始提取率 | 4% | Trinity 默认线 |
| 首年提取 | 40,000 | A × 4% |
| 通胀调整 | 每年 +3% | 提取额随通胀上调 |
| 组合年化回报 | 假设 6%（设计值） | — |
| 30 年是否耗尽 | 取决于序列 | 演示点 |

**关键演示**：把「年化 6%、通胀 3%」拆成两种顺序——
- 路径甲：前 5 年 +12%/+10%/+9%…（早涨）→ 30 年末资产仍正。
- 路径乙：前 5 年 −20%/−15%/−10%…（早跌）→ 同平均回报却**第 18 年耗尽**。
两路径「平均回报相同」，结局不同——这就是序列收益风险。

## 4. 风险管理教育游戏

### 4.1 灾害 / 应急管理模拟：Stop Disasters（品类提示）

**背景**：联合国减灾署（UNDRR）曾推出「Stop Disasters!」在线游戏，让玩家在限定预算内给社区布防（堤坝、预警、建筑加固），抵御地震/洪水/野火等。

**核心机制**：预算有限 → 必须在「预防投入」与「灾后损失」间权衡；不同灾害有不同「低频高损」特征。

**真实世界依据**：Stop Disasters 为公开教育游戏，**本环境白名单不可达其站点（不在实测可达域名）** → 标注「公开资料未能验证」其当前可玩性与具体数值。机制描述属「训练知识待核验」。

**教育意图**：预防（mitigation）也是一种「保险」，且常比灾后理赔更划算。

**对财商流的可借鉴点**：生存圈/积累圈可设「防灾投入」选项——花小钱降损失概率（对应第四象限「预防」）。

### 4.2 健康与医疗支出冲击主题

**背景**：医疗支出是家庭财务的「低频高损 + 长尾」风险。中国基本医保覆盖广，但「自付 + 自费」部分仍可能击穿家庭资产负债表。

**真实世界依据（实测抓取核实）**：`https://www.nhsa.gov.cn/`（国家医保局，HTTP 200，正文实测）。
- 抓取确认：国家医保局设「**医保数智库**」，2026 年已发布多期数据专刊，包括「2026 年第一期：1998 年–2025 年全国经济人口卫生医保相关数据」「第二期：2012 年–2025 年医保待遇享受相关数据」「第三期：2000 年–2025 年国家基本医保药品目录相关数据」「第四期：2023 年–2025 年医保结算住院人次 TOP10 疾病费用结构分析」。
- 第四期明确「基于**国家医保信息平台结算数据**」，并指出 2023–2025 年 TOP10 疾病药品费用占比「逐年下降」，归因于「集采、支付方式改革」——此为**实测抓取核实**表述。
- 抓取确认：国家医保局推进「**按病种付费 3.0 版分组方案**」（DRG/DIP 支付改革）与「**长期护理保险制度**」（新疆等地已发实施方案）。

**具体自付比例数字**：本环境未能从 nhsa 数据专刊抽取到「居民/职工具体自付比例 %」的原文表格（文章为图表形式、文本未含数字）→ 标注「公开资料未能验证」精确自付率。仅能确认「存在自付/自费段、集采降低药占比」方向性事实。

**对财商流的可借鉴点**：用「基本医保报销后剩余自付」作为医疗险的「免赔 + 共保」设计依据。

### 4.3 寿命不确定性游戏化：长寿风险（Longevity Risk）

**背景**：人无法预知自己活多久。活得比钱久 = 长寿风险；活得短 = 资产闲置（另一类「风险」）。

**核心机制**：把「寿命」设为随机变量（可用生命表抽样），玩家退休时不知道终局年龄。

**真实世界依据**：中国人身保险业经验生命表（CL 2010–2013 / 第三套等）为公开精算基准，本环境白名单不可达精算师协会原文 → 具体预期寿命数字「训练知识待核验」。方向性事实：城镇人口预期寿命随年代上升（国家统计局可达 `https://www.stats.gov.cn/`，HTTP 200，仅确认站点）。

**教育意图**：让「活太久」成为可被建模的真实威胁，而非背景设定。

**对财商流的可借鉴点**：自由圈终局判定用「隐藏寿命卡」，玩家直到抽中「身故/领取完毕」才知终局。

### 5.2 大病支出对家庭的冲击

**机制**：大病冲击 = ①直接医疗费用（自付段） + ②收入中断（患者及陪护均可能停工） + ③资产被动变现（贱卖）。三类叠加才可能击穿家庭资产负债表。

**真实世界依据**：该「三重复合冲击」逻辑为风险管理常识（训练知识）。中国「因病致贫/返贫」曾是扶贫攻坚重点议题，具体发生率数字白名单不可达 → 「公开资料未能验证」精确率。

**对财商流的可借鉴点**：一次「重疾事件」应同时触发「医疗报表支出 + 收入报表中断 + 资产负债表变现」，而非只扣现金。

### 5.3 失业与收入中断

| 项 | 说明 | 可信度 |
| --- | --- | --- |
| 失业频率 | 劳动者一生可能经历多次失业，单次持续数月到逾年 | 训练知识 |
| 收入中断传导 | 失业 → 现金流断裂 → 房贷/保单断供 → 资产被处置 | 逻辑常识 |
| 具体失业率/再就业时长 | 国家统计局（stats.gov.cn，HTTP 200 可达）发布城镇调查失业率，但本文未抽取具体数值 | 站点可达、具体数字待核验 |

**对财商流的可借鉴点**：生存圈设「失业卡」——不仅停工资，还触发「必须有 3–6 个月应急储备金否则断供」的规则。

### 5.4 伤残与身故概率（生命表概念）

**背景**：生命表（mortality table）给出分年龄的死亡/生存概率；伤残率（morbidity / disability）另有经验表。保险定价本质是「用大数定律把个人不确定变成群体可测」。

**真实世界依据**：生命表为精算公开基础工具（训练知识）。中国人身保险业经验生命表由精算师协会发布，白名单不可达 → **具体分年龄死亡率数字「训练知识待核验」，绝不编造**。

**量级（仅作设计锚，非真实）**：游戏内「30 岁男性当年身故概率」建议取设计值约 0.1% 量级、「当年重疾发生率」约 0.1%–0.3% 量级——**明确标注为设计建议值，非精算数据**（见 §7 参数表）。

**对财商流的可借鉴点**：用生命表思路让「定期寿险」保费 = 群体死亡概率 × 保额 + 费用，玩家能看到「年轻买便宜、年老买贵」的曲率。

## 6. 保险产品的真实机制

> 以下为产品形态的客观描述（公开合规要求层面），**不构成任何投保或投资建议**。具体条款以监管规定与保险合同为准。

### 6.1 六类核心产品的区别

| 产品 | 保什么（标的） | 给付方式 | 期限特征 | 在财商流中的「可购买道具」定位 |
| --- | --- | --- | --- | --- |
| **定期寿险** | 身故/全残（责任期） | 定额给付 | 保到 60/70 岁，到期无返还 | 责任期「收入能力」对冲（遗属需求法） |
| **终身寿险** | 身故（必赔） | 定额/增额给付 | 终身，含现金价值 | 传承 + 强制储蓄（与「储蓄」格联动） |
| **重疾险** | 约定重疾（确诊给付） | 定额给付（保额） | 定期/终身 | 对冲「收入中断 + 自费」双冲击 |
| **医疗险** | 医疗费用（报销） | 实报实销、有免赔/限额 | 一年期为主 | 对冲「高频中损」自付段 |
| **意外险** | 意外身故/伤残/医疗 | 给付+报销 | 一年期 | 便宜高杠杆，生存圈标配 |
| **年金险** | 生存（活着领钱） | 按期给付 | 终身/定期 | 对冲长寿风险（与自由圈绑定） |

### 6.2 现金价值与「保险 + 理财」混合产品的争议

**背景**：带储蓄属性的保单（终身寿、年金、两全）有「现金价值」——退保时能拿回的钱，前期低、后期累积。

**争议核心（buy term and invest the rest）**：
- 一派认为：定期消费型保险便宜，省下的保费自行投资，长期收益常优于「保险+理财」混合品。
- 另一派认为：混合品提供「强制储蓄 + 保障二合一」，对缺乏投资纪律者更稳妥。

**真实世界依据**：该争论为公开理财讨论（训练知识）。混合产品涉及「费用率、演示利率 ≠ 保证利率」等披露要求，由监管规范（如产品说明书、利益演示规则）→ 仅客观描述存在争议，**不做倾向性结论，不给建议**。

**对财商流的可借鉴点**：让玩家对比「纯消费保障 + 自行投资」vs「混合保单」两条路径的终值，理解「现金价值曲线」前期为何「不划算」。

### 6.3 关键条款如何影响真实赔付体验

| 条款 | 含义 | 对玩家体验的设计含义 |
| --- | --- | --- |
| **免赔额** | 自付段以下不赔 | 医疗险只赔「大额自付」，小额自留 |
| **共保 / 赔付比例** | 超出免赔后按比报销（如 80%） | 体现「保险不替你全扛」 |
| **等待期** | 投保后 N 天内出险不赔 | 防「带病投保」，游戏里「刚买就出事不赔」制造真实摩擦 |
| **健康告知** | 投保前如实申报 | 游戏可设「隐瞒 → 理赔纠纷卡」 |
| **两年不可抗辩** | 投保满两年后保险人不得解除合同（法定，见《保险法》） | 游戏里「满两年带病也赔」简化呈现；属公开合规条款，具体以法律为准 |
| **犹豫期 / 现金价值** | 退保规则 | 「中途退保亏多少」可视化 |

> 注：「两年不可抗辩条款」指向《中华人民共和国保险法》相关条文（训练知识：第 16 条相关），具体以现行法律文本为准；本环境未抓取法条原文，标注「训练知识待核验」精确表述。

### 6.6 横向对比：风险的四象限与对应工具

> 横轴 = 发生频率（高/低），纵轴 = 损失额度（大/小）。这是风险管理教科书经典框架（训练知识）。

| 象限 | 频率 × 损失 | 真实例子 | 最优应对 | 游戏化手法 | 财商流落点 |
| --- | --- | --- | --- | --- | --- |
| **① 高频低损** | 高 × 小 | 小病门诊、车险剐蹭、日常维修 | **自留（Self-insure）** + 预防 | 用「应急储备金」格子自动扣，玩家不心疼 | 生存圈「日常支出池」 |
| **② 高频高损** | 高 × 大 | 慢病长期用药、经营连续亏损 | **预防 + 控制**（根源治理） | 「防灾投入」降频率；降不下来则强制退出 | 积累圈「经营诊断」 |
| **③ 低频高损** | 低 × 大 | 重疾、身故、伤残、大火、长熊 | **保险转移（Transfer）** | 买保单，付保费换保额；银行家角色理赔 | 积累圈「保障系统」核心 |
| **④ 低频低损** | 低 × 小 | 小概率丢物、零星罚款 | **自留 / 忽略** | 不建模或极轻量事件卡 | 可忽略或合并进① |

**关键教育点**：很多人用「自留」处理③（裸奔），用「保险」处理①（过度投保门诊）——本游戏要让玩家**把工具放对象限**。

## 7. 财商流游戏「风险与保障系统」升级建议

> 本章为全文最有价值部分。所有「建议值」均标注为**设计建议值（非真实精算数据）**；所有「实测」项已在文末来源清单标注。

### 7.1 把「意外卡扣钱」升级为「风险池模型」

**现状问题**：原设计「意外事件卡 = 直接扣一笔钱」把风险当随机事件，玩家无对策、无杠杆感。

**升级方案**：建立**年度风险池**，把每个风险事件拆成「发生概率 × 损失分布」，由银行家（Agent）在每回合从池中抽样。玩家可在年初「投保」来对冲部分事件。

**建议的年度发生概率与损失分布（设计建议值，非真实精算）**：

| 风险事件 | 建议年发生概率 | 损失分布（设计值） | 主冲击报表 | 默认对冲工具 |
| --- | --- | --- | --- | --- |
| 小额医疗（门诊/药） | 60%–80% | 固定 0.1–0.5 月支出 | 现金流 | 自留（①象限） |
| 意外伤残（轻） | 3%–5% | 0.5–2 月支出 + 1 月收入中断 | 现金流+收入 | 意外险 |
| 失业 | 4%–8% | 3–12 月收入中断 | 收入 | 应急储备金 |
| 重疾 | 0.5%–1.5% | 5–30 月支出 + 6–24 月收入中断 | 三张表 | 重疾险+医疗险 |
| 身故（经济支柱） | 0.1%–0.3% | 家庭缺口 = 负债+抚养−资产 | 资产负债表 | 定期寿险 |
| 长熊（自由圈） | 市场周期驱动 | 组合 −20% 至 −40% | 资产 | 提款纪律+年金 |
| 长寿（自由圈） | 抽样至 80–100 岁 | 终局未知 | 资产 | 年金 |

> 上表概率/损失为**游戏平衡设计值**，量级参考第 5 章「训练知识」方向，但**非任何真实精算表**。实测仅确认「医保结算/生命表概念/长护险存在」方向，未获具体数字。

### 7.2 六类保险作为「可购买道具」的设计

每类保险在游戏内是一张「保单卡」，含字段：保费（年缴）、保额、免赔、等待期、赔付触发。

| 保险道具 | 建议年保费（设计值，占月支出%） | 建议保额（设计值） | 免赔 | 等待期 | 「买了没出事」的心理体验如何呈现 |
| --- | --- | --- | --- | --- | --- |
| 意外险 | 0.3%–0.8% | 50–200 月支出 | 0 | 0 | 保费极低，玩家几乎无感——最好教的「杠杆」 |
| 医疗险 | 1%–3% | 报销自付段（封顶 20–50 月支出） | 1 月支出 | 30 天 | 平时「看不见」，出事一次性回血，制造「幸好买了」 |
| 重疾险 | 3%–8% | 30–100 月支出（定额） | 0（确诊即付） | 90 天 | 最易「白花钱」焦虑——用「保障天数计数」可视化 |
| 定期寿险 | 0.5%–2%（年轻极低） | = 家庭缺口（遗属需求法） | 0 | 0 | 责任期专属；用「若今天倒下家庭缺口」持续显示 |
| 年金险 | 转为「趸交换终身领」 | 月领 = 保额×系数 | — | 领取期起 | 自由圈入场券；把「不确定寿命」变「确定月领」 |
| 长护险 | 1%–3% | 护理月费×N 月 | 0 | 90 天 | 对应「失能」低频高损，实测 nhsa 已推长护险 |

**保险教育最难的一点——「买了没出事」**：
- **手法 A（储蓄可视）**：把已缴保费累计显示为「风险对冲成本」，并对比「若出事省下的钱」，让玩家用期望值理解。
- **手法 B（遗憾/庆幸双结局）**：游戏结束翻「平行宇宙卡」——展示「如果当年没买、且出事了」的破产结局，制造「花钱买的是确定性」的体感。
- **手法 C（保障天数）**：保单卡显示「本已为你守护 N 天」，把抽象保费变成具象时间。

### 7.3 序列收益风险如何在自由圈体现

**机制**：
1. 玩家进入自由圈，资产组合价值 = A，采用「4% 初始提取率」首年提取，之后随通胀上调（默认线）。
2. 退休头 3 个回合若抽到「熊市卡」（组合 −20%~−40%），Agent 做轻量蒙特卡洛：在「先跌后涨」与「先涨后跌」两种顺序下跑同一平均回报，**演示成功率差距**。
3. 规则具象：若头 3 年累计回撤超阈值，触发「被迫低价变卖资产」标记，终值显著低于「同样平均回报但晚跌」的路径。

**教育点**：让玩家亲历「平均回报一样，顺序不同，结局不同」——这是 4% 法则最大的隐性前提。

### 7.4 长寿风险与「活太久钱不够」的终局判定

**机制**：
- 每位玩家入场自由圈时抽一张**隐藏寿命卡**（抽样区间建议 80–100 岁，设计值，参考寿命上升趋势但非真实表）。
- 每年提取，资产归零但寿命未到的玩家 → 判「长寿破产（longevity ruin）」，游戏失败（或降级结局）。
- 资产耗尽前已身故 → 剩余资产作遗产（对应「遗产规划 / 终身寿」）。
- 年金持有者：即使资产归零，仍按「月领」活到寿命卡终局 → 对冲长寿风险成功。

**教育点**：把「我能不能活到领回本」的直觉，替换为「我能不能活过资产耗尽点」的正确问题。

### 7.5 医疗 / 失业 / 伤残三类冲击对三张报表的传导路径

| 冲击 | 现金流量表 | 利润表（收支结余） | 资产负债表 | 连锁风险（参考啤酒游戏延迟放大） |
| --- | --- | --- | --- | --- |
| **医疗（重疾/意外伤）** | 自付医疗费现金流出；若有医疗险则部分回流 | 当期结余转负 | 无直接（报销型）；重疾定额给付可补资产 | 大额自费 → 变现投资 → 错过反弹 |
| **失业** | 工资流入中断 3–12 月 | 固定支出不变 → 结余转负 | 动用储蓄/应急金；断供 → 资产被处置 | 失业 → 断供 → 贱卖 → 财富永久损失（牛鞭式放大） |
| **伤残** | 收入中断 + 康复支出 | 双重挤压 | 重疾/意外伤残给付补位；否则消耗资产 | 长期中断 → 保障缺口暴露 |

**设计落点**：三类冲击都应是「三表联动事件」，而非只在现金表扣一笔——呼应《财商流》三张报表联动的核心设定。

### 7.6 两套落地方案

**简化版（线下手算，适合面对面沙盘）**：
- 风险池用「预先洗好的事件卡堆」代替随机抽样（每年发 1–2 张）。
- 保险用「保单卡 + 查表」：保费/保额印在卡上，理赔由银行家按卡面规则口算。
- 退休用「固定 4% 线 + 手动掷 1 个市场骰子（涨/平/跌）」近似序列风险。
- 蒙特卡洛省略，直接用「悲观/中性/乐观」三档路径卡。
- 长寿用「抽一张寿命卡」即可。

**完整版（线上 Agent 计算，适合《财商流》数字化）**：
- 风险池：Agent 按 §7.1 概率分布做年度抽样，支持相关性与事件叠加。
- 保险：Agent 维护每位玩家保单组合，自动算「保障缺口 = 家庭责任 − 现有保障」，建议加保。
- 退休：Agent 跑轻量蒙特卡洛（数千次），实时显示「撑过寿命卡的成功率」，并展示序列收益敏感带。
- 长寿：Agent 用隐藏寿命采样 + 年金精算近似，给「还需多少本金」反馈。
- 三表传导：Agent 在事件触发时自动改写三张报表并给出「连锁预警」。

### 7.8 银行家（Agent）理赔流程设计

> 《财商流》已有「LLM Agent 可当银行家」设定，理赔是银行家最自然的新职责。

| 环节 | 银行家动作 | 玩家动作 | 透明性 |
| --- | --- | --- | --- |
| 投保 | 按费率卡收保费，登记保单 | 出示现金/资产支付 | 费率卡公示 |
| 出险 | 抽事件卡，比对保单触发条件 | 提交「理赔申请卡」 | 规则前置 |
| 核赔 | 检查等待期/健康告知（如设） | 配合「诚实声明」 | 可复核 |
| 给付 | 按保额/报销规则拨付 | 入账现金流量表 | 三表联动 |
| 拒赔 | 说明条款依据 | 可申诉（争议卡） | 留痕 |

**心理体验自动化**：银行家每回合向玩家推送「保障日历」——「本月为你守护的风险：重疾✓ 身故✓ 意外✓，累计已缴保费 X」，把抽象的「白花钱」变成可见的「在保状态」。

### 7.9 与三层棋盘的具体接入点

| 棋盘 | 接入的风险/保障模块 | 触发机制 |
| --- | --- | --- |
| 生存圈 | 意外险 + 医疗险 + 应急储备金 | 高频低损事件卡 → 自留或小额报销 |
| 积累圈 | 定期寿险 + 重疾险 + 长护险 + 个人养老金 | 低频高损事件卡 → 大额理赔或缺口暴露 |
| 自由圈 | 年金 + 提款率纪律 + 长寿抽样 | 退休结算 → 蒙特卡洛成功率 + 寿命终局 |

**接入原则**：保障系统不是独立模块，而是「每张事件卡都先查保单再决定由谁承担」——银行家在事件结算前做一道「保单抵扣」。

### 7.10 一局完整脚本示例（教学演示）

> 以下为示意流程，展示系统如何运转。

1. **生存圈第 3 年**：抽到「意外伤残（轻）」卡。银行家查玩家保单 → 有意外险 → 赔付 1 月支出，现金表仅小幅波动。*（无险玩家则直接扣 1–2 月支出。）*
2. **积累圈第 8 年**：抽到「重疾」卡。银行家查 → 有重疾险（保额 60 月支出）+ 医疗险（报销自付段）。重疾定额给付补收入中断，医疗险报自费；三表联动但家庭不破产。*（裸奔玩家：变现投资 + 收入中断 → 净资产大降，触发「连锁预警」。）*
3. **积累圈第 12 年**：玩家用「遗属需求法」算出家庭缺口 340 月支出，加保定期寿险至该额。
4. **自由圈入场**：资产 = 25× 年支出（达 4% 线），但隐藏寿命卡抽中 96 岁。首年提取 4%，第 2 年遇「熊市卡 −30%」→ Agent 跑蒙特卡洛，成功率从 90% 降到 70%，提示「考虑降提取或购年金」。
5. **终局**：玩家此前购入年金 → 即使资产在第 22 年耗尽，仍按月领活到 96 岁，判「长寿风险对冲成功」。

### 7.11 平衡性调参与防滥用建议

| 风险 | 可能失衡 | 调参建议 |
| --- | --- | --- |
| 玩家全不投保 | 频繁破产劝退 | 生存圈保留「基础医保兜底」（低保额）让裸奔不至于瞬死 |
| 玩家全买保险 | 保费吃掉现金流，无积累 | 保费占支出设上限（如 ≤15%），超额不可投 |
| 事件卡太频繁 | 运气主导、策略无用 | 低频高损年概率压到 ≤2%，靠规划而非赌 |
| 蒙特卡洛太吓人 | 提前弃局 | 用「成功率区间」而非单次破产吓人 |
| 年金太强 | 自由圈无敌 | 年金领取系数设低，需搭配资产 |

| 指标 | 观测方式 | 达标信号 |

## 8. 风险与保障教育的常见误区（防误导）

> 本节用于校准《财商流》教学设计，避免把保险教育做成「恐吓营销」或「万能解药」。

| 误区 | 错误表述 | 正确认知（游戏应传递） |
| --- | --- | --- |
| 误区 1：保险=理财 | 「买这份险能跑赢通胀」 | 保障与增值是不同功能，混合品有费用与演示利率≠保证利率 |
| 误区 2：越全越好 | 「什么都保才安心」 | ③象限才需保险，①象限自留更优，过度投保挤占积累 |
| 误区 3：年轻不用保 | 「我还健康，以后再说」 | 定期寿险年轻最便宜，正是责任最重时 |
| 误区 4：4% 是铁律 | 「按 4% 提款稳了」 | 4% 是历史经验值，受序列风险与寿命影响 |
| 误区 5：政府全包 | 「有社保不用自己管」 | 第一支柱保基本，替代率有限，需二三支柱补充 |
| 误区 6：赌一把 | 「不买险，省下的钱投资更赚」 | buy term 成立但有纪律前提，裸奔遇③象限即破产 |
| 误区 7：长寿是福 | 「活得久领得多」 | 无规划时长寿=长寿破产，需用年金对冲 |

**防误导原则**：游戏中所有保险/养老机制仅作「风险转移工具」演示，不暗示任何产品优劣、不引导现实投保，结尾附免责声明（见 §D）。
