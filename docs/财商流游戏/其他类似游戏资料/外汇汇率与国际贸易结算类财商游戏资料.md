## 板块 0 · 为什么这一维度必须补

真实世界里，财富的跨境流动与汇率波动是**最被普通中国玩家低估的风险源**：

- **2015 年"811 汇改"**：人民币兑美元中间价一次性贬值约 1.86%，三天累计贬值约 4.6%，新兴市场货币连锁承压——持外币资产/外债的玩家若未对冲，资产端直接缩水。
- **2022 年日元贬值**：USD/JPY 从约 115 贬破 150，日本财务省罕见口头/实际干预，套息交易（carry trade）平仓引发全球风险资产同步暴跌。
- **2024 年日元套息交易二次平仓**：利差交易逆转，日经单日暴跌——这正是《衍生品资料》已覆盖"套息"但未落到"汇率机制与外币资产定价"层面的缺口。
- **中国个人每年 5 万美元便利化换汇额度**：真实的制度天花板，游戏内可做成**配额资源**，训练玩家"额度管理"意识。
- **跨境结算（信用证 L/C、电汇 TT）**：真实国贸的核心履约链条，SimTrade/POCIB 等高校实训平台已跑通 6 步 L/C 流程，可抽象为桌游结算机制。

桌游侧，《Alhambra》的四货币兑换市场、《Hamburgum》的供需定价、《Container》的集装箱出口贸易经济——都是**把汇率/跨境交易做成核心机制**的成熟范本。

要"真实模拟真实世界经济系统"，就必须让玩家**体验到汇率浮动的换汇损益、跨境结算的履约风险、外币资产的敞口管理**，否则财商教育在"全球化资产"维度是残缺的。本文件即为此而作。

## 板块 1 · 桌游/教具逐个拆解

### 1.1 Alhambra（阿尔罕布拉宫，2003，Dirk Henn）——四货币兑换市场原型

| 项 | 内容 |
|----|------|
| 出版年 | 2003 |
| 设计师 | Dirk Henn |
| 人数 | 2–6 |
| 获奖 | 2003 年 Spiel des Jahres（德国年度游戏） |
| 主题 | 在格拉纳达修建阿尔罕布拉宫，购买四种风格的建筑 tile |
| 核心机制 | **四货币兑换市场 + 手牌构建 + 计分竞拍** |

**货币/兑换系统**：
- 游戏包含**四种货币**（通常以 4 种颜色区分，面值不同，对应不同"强势度"），代表不同购买力。
- 玩家每回合在**货币市场（currency market）**用手中货币**以市场汇率购买建筑 tile**。
- **关键规则**：每种货币购买建筑时，必须**按 tile 标价的面值支付，但可以用"较弱"货币超额支付，不找零**——这天然制造"持有弱势货币就吃亏"的激励，驱动玩家抢强势货币。
- 建筑 tile 抽出时按 4 个"建筑风格"分类，计分时要求**每种风格数量领先**才得分——迫使玩家分散持仓（类似资产配置分散化）。

**经济系统**：
- 货币牌库固定（有限供给），强势货币（低面值但购买力高）数量少于弱势货币——**稀缺性决定汇率**。
- 货币市场牌每回合翻出，汇率由**牌序随机决定**，玩家无法精确预测——模拟浮动汇率的不确定性。

**财商理念**：
- **"持有弱势货币就亏"**：映射真实世界"持有高通胀/贬值货币的购买力损失"。
- **"分散风格才高分"**：映射资产配置分散化，押单一风格风险极高。
- **"强势货币稀缺"**：映射强势货币（美元/瑞郎）在危机时的供不应求。

**真实世界映射**：
- 四货币 ≈ 真实世界的 USD/EUR/JPY/CNY 等一篮子货币。
- "不找零的超额支付" ≈ 真实换汇的**点差与隐性成本**（你用弱势货币换强势货币时，损失点差）。
- 货币稀缺性 ≈ 美元在危机时的"美元荒"（2020 年 3 月美元流动性危机）。

> **借鉴落点**：《财商流游戏》可在季度交易窗口 T2 增设"**外币兑换子窗口**"：玩家按当期汇率把人民币换成 USD/JPY/EUR 等外币，汇率由事件卡/周期阶段决定；持有外币资产期间，每季度按**新汇率重估**并计入资产负债表汇兑损益。详见板块 4。

### 1.2 Hamburgum（汉堡，2007，Mac Gerdts）——汉萨贸易与供需定价

| 项 | 内容 |
|----|------|
| 出版年 | 2007 |
| 设计师 | Mac Gerdts（以"rondel 轮盘机制"著称） |
| 人数 | 2–5 |
| 发行商 | Rio Grande Games / Catan GmbH |
| 主题 | 中世纪汉堡汉萨同盟贸易，建造教堂与市政厅 |
| 核心机制 | **Rondel 轮盘行动选择 + 商品供需定价 + 教堂建设** |

**贸易/定价系统**：
- 商品（布匹、谷物、啤酒等）有**浮动市场价格**，由供需板决定：当某商品被大量卖出，价格下跌；大量买入，价格上涨——**纯粹的供需定价**。
- 玩家用 rondel 选择"贸易/生产/建设"等行动，在最优时机卖出商品获利。
- **教堂建设**是胜利条件（先建 6 座教堂+市政厅者胜），需要**特定商品组合 + 货币捐献**——把"消费"（建教堂不产生现金流）与"投资"（贸易获利）对立起来。

**货币/经济系统**：
- 货币用于捐献建教堂和交易结算，单一货币（无多币种），但**商品价格浮动**构成了"商品货币"式的汇率效应：1 单位布匹今天值 5 元、明天值 3 元——玩家必须判断何时卖出。
- 没有多币种，但**商品↔货币的相对价格**本质上就是"商品货币汇率"。

**财商理念**：
- **"供需决定价格"**：最纯粹的市场定价教学——供给过剩 → 跌价。
- **"消费 vs 投资的抉择"**：建教堂（消费/得分）vs 滚利贸易（复利增长），映射"花钱买房 vs 再投资"。
- **"rondel 的不可逆行动"**：行动有代价（跳过得付成本），映射真实交易的摩擦成本。

**真实世界映射**：
- 供需定价板 ≈ 真实大宗商品市场的供需曲线。
- 商品货币效应 ≈ 原油/黄金以 USD 计价时，商品↔USD 的相对价格就是"商品汇率"。
- 汉萨同盟 ≈ 中世纪版 WTO——区域贸易联盟降低交易成本。

> **借鉴落点**：《财商流游戏》§6.6"贵金属与大宗商品"的价格驱动机制可参照 Hamburgum 的**供需板**设计：原油/黄金价格由"本期买入总人数 vs 卖出总人数"决定浮动区间，而非纯随机事件，让玩家体验"追涨杀跌如何反噬"。

### 1.3 Container（集装箱，2007，Valery Chvatil）——出口贸易经济闭环

| 项 | 内容 |
|----|------|
| 出版年 | 2007 |
| 设计师 | Valery Chvatil |
| 人数 | 3–5 |
| 主题 | 集装箱出口贸易，工厂→港口→航运→海外销售 |
| 核心机制 | **生产-运输-销售闭环 + 供需拍卖 + 秘密估值** |

**贸易/结算系统**：
- 玩家扮演**工厂主**：在本地生产集装箱（需买原料、雇运力），装上自己的船，运到海外市场销售。
- **关键机制**：海外市场价格由**总供给量**决定——所有人把集装箱运到海外后，市场按"供给越多、单价越低"定价。**你的利润取决于别人运多少**——典型的"公地悲剧"。
- **秘密估值**：每个集装箱对每个玩家有**私有估值**（不同颜色/类型对不同玩家价值不同），交易时你不知道对方底价——训练**信息不对称下的议价**。
- 结算使用**单一货币**，但"工厂→海外销售"的链条模拟了**出口贸易的全流程**（生产、运输、跨境、销售）。

**经济系统**：
- 无多币种，但**海外销售价格 vs 本地生产成本**的价差就是"贸易利润"。
- 船舶容量有限 → 必须选择运什么 → **机会成本决策**。
- 工厂产能可投资扩张 → **资本支出 vs 当期利润**的权衡。

**财商理念**：
- **"供给过剩压价"**：映射真实出口贸易的"一窝蜂出口→价格战"（中国光伏/纺织业历史）。
- **"秘密估值"**：映射真实并购/议价的私有信息。
- **"产能投资 vs 当期分红"**：映射企业留存 vs 分红的抉择（与本作 §7.3 企业经营分红机制直接呼应）。

**真实世界映射**：
- 集装箱出口 ≈ 中国制造业出口的真实链条。
- 海外供需定价 ≈ 出口目的国市场的价格接受者模型（小国出口理论）。
- 船舶容量 ≈ 运力约束（2021 年集装箱海运价格暴涨的真实案例）。

> **借鉴落点**：《财商流游戏》季度交易窗口 T2 可增设"**出口订单卡**"：玩家企业可接海外订单（价格由本期总接单量决定），训练"不要一窝蜂"的反周期思维；同时与 §7.3 企业经营"扩产/研发/营销"战略决策联动。

### 1.4 Monopoly Here and Now: World Edition（大富翁：此时此地·世界版，2008/2015 重印）——多货币兑换板

| 项 | 内容 |
|----|------|
| 出版年 | 2008（初版）/ 2015（重印） |
| 发行商 | Hasbro / Winning Moves |
| 人数 | 2–6 |
| 主题 | 经典大富翁换皮，地产换为全球地标（巴黎/伦敦/纽约/悉尼等） |
| 核心机制 | **多货币 + 兑换板 + 经典大富翁买卖/收租** |

**货币/兑换系统**：
- 游戏包含**多种颜色的货币**（代表 USD/EUR/JPY/GBP 等不同货币），每种颜色面值不同。
- **兑换板（currency exchange board）**：玩家可在自己回合按**固定汇率**把一种货币换成另一种（汇率印在板上，简化版固定汇率制）。
- 购买地产时必须用**该地产所在国货币**支付——持有美元的玩家想买巴黎地产，必须先换欧元。
- 收租时收取的是**地产所在国货币**——玩家自然积累多币种头寸。

**经济系统**：
- 汇率**固定**（非浮动），简化了真实外汇市场的波动性，但保留了"换汇成本"和"多币种资产管理"的核心体验。
- 兑换板汇率通常**非 1:1**（如 1 USD = 0.8 EUR = 110 JPY），制造换汇损益。

**财商理念**：
- **"持有错误货币就亏换汇成本"**：映射真实旅行/跨境投资的换汇摩擦。
- **"多币种资产组合"**：玩家自然学会分散持有多种货币。
- **"固定汇率的幻觉"**：汇率固定看似安全，但一旦改版为浮动（house rule），立刻暴露敞口风险——可做成教学转折点。

**真实世界映射**：
- 固定汇率 ≈ 香港的联系汇率制（USD/HKD 7.8）、沙特里亚尔盯住美元。
- 多币种地产 ≈ 真实跨境房产投资（中国买家买日本/澳洲房产需换汇）。
- 兑换板 ≈ 银行外汇牌价的买入/卖出价差。

> **借鉴落点**：《财商流游戏》可把 Monopoly World Edition 的"兑换板"抽象为**季度汇率表**：每季度交易窗口 T1 公布当期汇率（由周期阶段+事件卡决定），玩家按表换汇；汇率表可做成"固定→浮动"的进阶规则（初级房固定汇率，高级房浮动汇率）。

### 1.5 Foreign Exchange（外汇，1979，3M）——纯货币投机原型

| 项 | 内容 |
|----|------|
| 出版年 | 1979（待核实：3M 公司"bookshelf game"系列之一） |
| 发行商 | 3M（Minnesota Mining and Manufacturing） |
| 人数 | 2–4（待核实） |
| 主题 | 外汇市场货币投机 |
| 核心机制 | **货币对交易 + 事件驱动汇率波动** |

**货币/交易系统**（待核实细节，据 BGG 条目与二手规则书整理）：
- 玩家持有初始一篮子货币，通过**货币对交易**（如 USD/DEM、JPY/USD）投机。
- 每回合翻出**事件卡**（政治/经济事件）驱动汇率波动——类似本作"机会卡"驱动市场。
- 目标：在若干回合后**持有最多高价值货币**的玩家获胜。

**经济系统**：
- 无商品/资产，**纯货币投机**——是桌游中少见的"外汇即主题"作品。
- 事件卡模拟真实世界的央行决议、政治危机、贸易数据发布。

**财商理念**：
- **"货币相对价值"**：没有"绝对好货币"，只有"相对升贬值"——训练相对思维。
- **"事件驱动波动"**：映射真实外汇市场的新闻交易（news trading）。

**真实世界映射**：
- 事件卡 ≈ 非农就业数据、央行利率决议、GDP 发布等外汇市场催化剂。
- 货币对 ≈ 真实外汇交易的货币对（EUR/USD、USD/JPY）。

> **借鉴落点**：《财商流游戏》可设计"**汇率事件卡**"子类型：在季度交易窗口 T1 翻出，直接扰动下期汇率（如"美联储加息 25bp → USD 升值 2%"），让玩家提前调整外币敞口。

### 1.6 The Exchange（交易所，2024，待核实设计师）——股票/商品交易所竞价

| 项 | 内容 |
|----|------|
| 出版年 | 2024（待核实：BGG 2024 年条目，Kickstarter 或 Gen Con 新品） |
| 人数 | 2–4（待核实） |
| 主题 | 股票/商品交易所内的公开喊价交易 |
| 核心机制 | **公开喊价（open outcry）+ 做市商 + 价格发现** |

**交易系统**（据 BGG 条目摘要，待核实完整规则）：
- 玩家扮演交易所内的**交易员/做市商**，通过公开喊价买卖股票或商品合约。
- 价格由**买卖盘撮合**决定——买方喊高价、卖方喊低价，撮合成交。
- 做市商角色有**报价义务**（必须同时报买价和卖价），赚取买卖价差。

**经济系统**：
- 单一货币（无多币种），但**价格发现机制**与外汇市场的电子撮合高度相似。
- 做市商价差 ≈ 真实外汇交易的 bid-ask spread。

**财商理念**：
- **"做市商赚价差"**：映射真实外汇做市商（银行）的盈利模式。
- **"公开喊价的心理压力"**：训练快速决策与情绪控制。

**真实世界映射**：
- 公开喊价 ≈ 芝加哥交易所（CME）的传统交易池（现已电子化）。
- 做市商 ≈ 真实外汇 ECN 市场的流动性提供者。

> **借鉴落点**：《财商流游戏》季度交易窗口 T2 的"撮合阶段"可借鉴 The Exchange 的**公开喊价**机制：大宗资产（≥100 手股票、商业地产）走英式拍卖时，让玩家真实喊价（而非密封），训练议价心理。

### 1.7 Exchange（交易所，2018，Games by Bicycle）——股票轮交易

| 项 | 内容 |
|----|------|
| 出版年 | 2018 |
| 发行商 | Games by Bicycle |
| 人数 | 2–6 |
| 主题 | 股票交易策略与时机 |
| 核心机制 | **5 轮股票选择/买卖/市场阶段** |

**交易系统**：
- 游戏分 **5 轮**，每轮含"股票选择→买卖→市场"三阶段。
- 玩家每轮选择要交易的股票，按市场阶段的价格波动结算。
- 无多币种，但**时机选择**（何时买/卖）是核心——与外汇交易的"择时"同理。

**财商理念**：
- **"低买高卖的时机"**：最基础的投机教学。
- **"5 轮的有限视野"**：映射真实交易的有限信息集。

> **借鉴落点**：Exchange 的"5 轮有限视野"结构可借鉴为《财商流游戏》季度交易窗口的**回合限制**：T2 撮合阶段限时 90 秒，超时自动按底价成交——训练"犹豫就亏"的决策纪律。

## 板块 2 · 中国本土实训平台与模拟交易

### 2.1 POCIB（国际贸易从业技能综合实训）

| 项 | 内容 |
|----|------|
| 开发方 | 中国国际贸易学会 + 《国际贸易》杂志社 + 世格软件（Desunsoft） |
| 定位 | 互联网培训证书课程，对接外销员/跟单员考试 |
| 核心模块 | 英文函电磋商（询盘/发盘/还盘/接受）+ 贸易术语 + 结算方式 |

**结算机制**：
- 覆盖**信用证（L/C）、电汇（T/T）、付款交单（D/P）、承兑交单（D/A）**四种结算方式。
- 信用证流程归纳为**六步**：开证 → 审证 → 备货 → 制单发货 → 交单议付 → 付款赎单。
- 与职业资格证书挂钩，支持在校生与社会学员弹性学习。

**游戏化机制**：
- 平台设计了**突发事件机制**（模拟货物运输意外等风险）和**异常状况处理机制**（信用证项下进口商业务问题）。
- 评分基于**履约完整度 + 单证准确率 + 利润**——类似桌游的计分系统。

> **借鉴落点**：《财商流游戏》可把 POCIB 的"六步 L/C"抽象为**跨境结算事件链**：玩家企业接海外订单时，掷骰/翻卡决定哪一步出问题（如"单证不符→拒付"），训练"履约风险"意识。

### 2.2 SimTrade（外贸实习平台，世格软件）

| 项 | 内容 |
|----|------|
| 开发方 | 世格软件（Desunsoft） |
| 定位 | 高校国际贸易专业实训软件 |
| 角色 | 出口商 / 进口商 / 工厂 / 出口地银行 / 进口地银行 / 指导老师 / 系统管理员 |

**核心机制**：
- 模拟**真实国际贸易全流程**：从建立实习计划、英文函电磋商、合同签订、信用证结算到单证中心操作。

- **突发事件机制**：模拟货物运输意外等风险；**异常状况处理机制**：处理信用证项下异常。

### 2.3 ERP 沙盘 / 国际贸易沙盘（高校教具）

| 项 | 内容 |
|----|------|
| 代表产品 | 用友 ERP 沙盘、金蝶 ERP 沙盘、ITMC 国际贸易沙盘 |
| 定位 | 高校经管类实训教具 |
| 核心模块 | 企业经营 + 国际贸易（报关/报检/结算） |

**国贸模块机制**：
- **报关报检模拟**：玩家需填写报关单、报检单，通过海关/检验检疫审核才能出口。
- **结算方式**：L/C、T/T、D/P、D/A 全覆盖。
- **汇率风险**：部分沙盘引入**汇率浮动**，出口收入按结算日汇率折算本币——直接训练汇率敞口意识。
- **关税/退税**：出口退税机制（按退税率计算退税收入）是真实中国出口企业的核心利润来源之一。

**财商理念**：
- **"退税是利润"**：真实中国出口企业的利润很大程度来自退税——玩家必须理解政策红利。
- **"报关单证合规"**：单证不符 → 无法退税/无法结汇——训练合规意识。

> **借鉴落点**：《财商流游戏》可把"出口退税"做成**政策红利事件卡**：在特定周期阶段（如"出口退税上调"事件），出口企业获得额外现金流奖励，训练玩家关注政策窗口。

### 2.4 银行/券商外汇模拟交易大赛

| 项 | 内容 |
|----|------|
| 代表赛事 | 工商银行"首届网上外汇模拟交易大赛"（2009）、同花顺杯外汇模拟交易大赛（第 17 届，2025–2026）、AFX 平台月度模拟赛 |

- 基于**真实行情**的模拟盘（非实时滑点，但价格走势贴近真实）。
- 按**收益率排名**——纯投机导向，无结算/履约维度。

**财商理念**：

### 2.5 外汇保证金模拟盘教育（风险教育导向）

| 项 | 内容 |
|----|------|
| 背景 | 中国境内非法外汇保证金交易屡禁不止，监管/高校以"风险教育"为导向推出模拟盘 |
| 代表 | 各银行"外汇宝"模拟、高校金融实验室 MT4/MT5 模拟 |
| 核心 | 杠杆交易 + 爆仓机制 + 风险揭示 |

**机制**：
- 基于 MT4/MT5 平台的模拟环境，**1:100 或 1:200 杠杆**。
- 强制**止损/止盈**设置教学。

**财商理念**：
- **"杠杆放大亏损"**：1% 反向波动 × 100 倍杠杆 = 本金归零。

## 板块 3 · 真实世界外汇/国贸机制速查（供游戏化）

### 3.1 汇率制度：固定 vs 浮动

| 制度 | 定义 | 真实案例 | 游戏化方式 |
|------|------|---------|-----------|
| **固定汇率** | 央行承诺本币兑某一货币（或一篮子）维持固定比价 | 香港联系汇率（USD/HKD 7.8）、沙特里亚尔盯住美元 | 初级房汇率固定，换汇无风险但额度受限 |
| **浮动汇率** | 汇率由市场供求决定，央行不承诺任何价位 | USD/EUR、USD/JPY、GBP/USD | 高级房汇率浮动，每季度按事件卡/周期调整 |
| **有管理的浮动** | 日常浮动，但央行在极端波动时干预 | 人民币（"收盘价+一篮子"中间价机制） | 本作默认制度：汇率浮动，但"央行干预卡"可临时锁定 |
| **货币局** | 法律强制 100% 外汇储备背书本币 | 香港（联系汇率是货币局的一种）、保加利亚列弗 | 可做成"货币局事件"：某外币临时锚定人民币 |

### 3.2 汇率决定理论（简化游戏化）

| 理论 | 核心逻辑 | 游戏化映射 |
|------|---------|-----------|
| **购买力平价（PPP）** | 长期汇率由两国物价水平决定（"一篮子商品"价格相等） | 若某国"通胀事件卡"频发，其货币每季度自动贬值 1–2% |
| **利率平价（IRP）** | 高利率货币远期贴水、低利率货币远期升水（无套利约束） | 若某国"加息事件"，其货币即期升值但远期贬值 |
| **国际收支** | 贸易顺差国货币升值压力，逆差国贬值压力 | 若某玩家/AI 大量出口，本币面临升值压力（出口利润被汇率吃掉） |
| **套息交易（Carry Trade）** | 借低利率货币（JPY）、投高利率货币（USD/BRL），赚利差 | 玩家可"借 JPY 投 USD"赚利差，但 JPY 突然升值时利差被汇兑损失吞没 |

### 3.3 中国个人换汇制度

| 项 | 内容 | 来源 |
|----|------|------|
| **便利化额度** | 每人每年等值 **5 万美元**（经常项目） | 国家外汇管理局《个人外汇管理办法实施细则》 |
| **用途限制** | 不得用于境外买房、证券投资、购买人寿保险等资本项目 | 同上 |
| **超额审核** | 超过 5 万需提供真实性证明材料（留学学费/就医等） | 同上 |
| **分拆购汇** | 5 个以上个人同日/连续多日向同一境外账户汇款 = "分拆"，列入关注名单 | 同上 |

> **游戏化映射**：玩家每年有 **5 单位外币额度**（1 单位 = 1 万美元等价），用完即止；超额换汇需"审核事件"（掷骰/翻卡，通过率与信用评级挂钩）。训练"额度管理"意识。

### 3.4 跨境结算方式

| 方式 | 英文缩写 | 流程 | 风险特征 | 游戏化 |
|------|---------|------|---------|--------|
| **信用证** | L/C | 开证→审证→备货→制单发货→交单议付→付款赎单（6 步） | 单证不符→拒付；开证行信用风险 | 翻"单证卡"，不符则拒付 |
| **电汇** | T/T | 汇款行→中间行→收款行（1–3 天） | 商业信用风险（预付则买方赊销则卖方） | 简单直接，但"欺诈卡"可触发 |
| **付款交单** | D/P | 买方付款后才能拿到提单提货 | 买方不付款→卖方货物滞留 | 中等风险 |
| **承兑交单** | D/A | 买方承兑汇票即可拿单，到期付款 | 买方到期不付→卖方钱货两空 | 高风险 |

### 3.5 汇率风险对冲工具

| 工具 | 定义 | 适用场景 | 游戏化 |
|------|------|---------|--------|
| **远期结售汇** | 锁定未来某日的汇率 | 出口企业 3 个月后收美元，锁定汇率防贬值 | 玩家可买"远期合约卡"，锁定下期汇率 |
| **外汇掉期（FX Swap）** | 即期+远期组合，调整资金期限 | 企业短期外币流动性管理 | 高级玩家可"掉期"调整现金流期限 |
| **外汇期权** | 付权利金获得"按约定汇率买卖"的权利（非义务） | 不确定性大的跨境并购 | "期权卡"：付少量现金，获得下期按有利汇率换汇的权利 |
| **自然对冲** | 收入与支出用同一货币，自动抵消 | 进出口双向企业 | 同时有本币收入+外币支出的玩家自动降低敞口 |

### 3.6 历史案例库（供事件卡设计）

| 案例 | 时间 | 核心事件 | 游戏化事件卡 |
|------|------|---------|-------------|
| **1997 亚洲金融危机** | 1997.07 | 泰国放弃固定汇率，泰铢 1 年贬值超 50%；印尼/韩国/马来西亚连锁危机；IMF 救助 | "泰铢脱钩"：所有盯住 USD 的货币 1 回合贬值 30%，持有该货币的玩家资产缩水 |
| **2015 人民币"811 汇改"** | 2015.08.11 | 央行完善中间价机制，3 天累计贬值约 4.6%，新兴市场货币连锁承压 | "811 汇改"：CNY 一次性贬值 3%，持有 CNY 资产的玩家按新汇率重估 |
| **2022 日元贬值** | 2022.09–10 | USD/JPY 从 ~115 贬破 150，日本财务省罕见干预，套息交易平仓 | "日元急贬"：JPY 单季度贬值 10%，借 JPY 套息的玩家汇兑损失吞没利差 |

## 板块 5 · 对本作设计的具体落点清单（12 条）

> 以下落点明确指向《财商流游戏》既有设计文档的具体章节，避免"悬空建议"。

1. **在《规则与经济系统》§6"投资系统"新增"**外币资产**"子节（§6.9 或 §6.10）**：定义 USD/JPY/EUR 三类外币现金资产，每季度按当期汇率重估，汇兑损益计入利润表"财务费用-汇兑损益"科目。与既有 8 类投资品并列，作为第 9 类（或归入 §6.6 贵金属/大宗商品下的"外币现金"子类）。

2. **在《交易拍卖与企业经营设计》§2.2 季度交易窗口 T1 增设"汇率公告"步骤**：每季度 T1 挂牌阶段开始时，翻出"汇率事件卡"公布下期汇率（USD/CNY、JPY/CNY、EUR/CNY），汇率由**周期阶段基准 + 事件卡扰动**决定（如繁荣期 USD 贬值 2% + "美联储加息"事件 USD 升值 3% = 净升值 1%）。

3. **在《交易拍卖与企业经营设计》§2.2 T2 增设"外币兑换子窗口"**：玩家可按当期汇率把人民币换成外币（受年度 5 单位额度限制），或把外币换回人民币。换汇**不找零**（借鉴 Alhambra），制造换汇摩擦。

4. **在《棋盘与道具设计》卡池新增"汇率事件卡"子类型**（约 12 张）：含"811 汇改""日元急贬""美元荒""泰铢脱钩""英镑危机"等历史案例卡，每张标注汇率扰动幅度与持续回合。与《宏观经济与政策模拟类游戏资料》的"政策卡"联动。

5. **在《规则与经济系统》§7 市场周期系统"周期对各类资产的影响表"中新增"外币资产"行**：USD/CNY 在繁荣期贬值（资金外流）、在萧条期升值（避险）；JPY/CNY 在危机时升值（避险货币）、在复苏时贬值（套息平仓）。与既有黄金/债券的避险属性形成差异化。

6. **在《交易拍卖与企业经营设计》§5.4"玩家间借贷"中新增"外币借贷"**：玩家可借外币（如借 JPY 投 USD 套息），但需在季度窗口按**新汇率**还本付息——汇兑损失可能吞没利差，训练套息交易风险。

7. **在《规则与经济系统》§6.3 企业经营中新增"出口订单"收入类型**：企业可接海外订单（价格由本期总接单量决定，借鉴 Container），收入以外币计价，结算时按当期汇率折算——训练"出口企业的汇率敞口"意识。

8. **在《行为金融与投资心理机制设计》"心魔卡"中新增"**汇率幻觉 / 锚定旧汇率**"心魔**：持有外币资产的玩家若拒绝按新汇率重估（心理锚定在买入价），标注为"损失厌恶+锚定偏差"，与既有心魔系统联动。

9. **在《真实世界经济与财商理论底座》中新增"**外汇与跨境结算**"板块**：整理固定/浮动汇率、PPP/IRP/套息交易、L/C 六步流程、远期/掉期/期权对冲、5 万美元额度等真实规则，作为事件卡/机制设计的底稿（本文件板块 3 即底稿）。

10. **设计一个"**外汇模拟盘热身小游戏**"（10 分钟）**：玩家用虚拟 1 万美元在 5 个"行情回合"内交易 USD/CNY，体验杠杆与止损，再进入正式棋盘。借鉴银行模拟交易大赛机制，但**无杠杆**（本作财商教育定位）。

11. **在《财商流游戏规则与经济系统》§3 三表联动中明确"外币资产/负债的汇兑损益"科目**：资产负债表"外币现金/外币借款"按期末汇率重估，差额进利润表"汇兑损益"，确保外币敞口**不游离表外**（与《衍生品资料》第 10 条"衍生品浮盈浮并入三表"原则一致）。

12. **在《财商流游戏交易拍卖与企业经营设计》§7 企业经营"经营危机判定"中新增"汇率冲击"触发条件**：若企业有净外币负债（外币借款 > 外币现金），且本币单季度贬值 ≥ 5%，触发"汇兑损失危机"——强制计提损失或追加担保。训练"外币错配"风险意识。
