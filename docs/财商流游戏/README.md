## 阅读路径建议

### 路径 A：新成员入门（4 小时）

1. 《总体设计》（必读，30 分钟）——理解游戏定位
2. 《玩家职业设计》总索引 + [`玩家职业设计/`](玩家职业设计/) 选读 3 个画像（30 分钟）——理解人物差异

4. 《行为金融》§1 + §5（45 分钟）——理解心魔系统
5. 实玩一局（90 分钟）——其余规则边玩边查

1. 路径 A 全部内容（4 小时）

3. 《交易拍卖与企业经营》全部（1.5 小时）——理解市场深度
4. 《棋盘与道具设计》§6 全部（1.5 小时）——理解卡牌设计
5. 《社交资本与信用体系》全部（45 分钟）
6. 全部 25 份调研资料按需深读（每份 30 分钟 × 选 5 份）

### 路径 C：教育研究者（1 天）

1. 《总体设计》§1 + §3 + §7（30 分钟）
2. 《真实世界底座》板块 7 + 板块 9（45 分钟）

## 维护规约

### 命名规约

- **核心设计文档**：`财商流游戏<主题>设计.md`，放置在 `docs/财商流游戏/` 根目录。
- **职业画像档案**：总索引为 [`玩家职业设计/00-职业画像框架与索引.md`](玩家职业设计/00-职业画像框架与索引.md)；详细档案按主题放置在 `玩家职业设计/*.md`。
- **同类游戏资料**：`<filename>资料.md`，放置在 `docs/财商流游戏/其他类似游戏资料/` 子目录。
- **本索引文件**：`docs/财商流游戏/README.md`，唯一入口。

### 版本规约

- 文档头部包含 `> **版本**：v<x.y> <类型>` 标识。
- 每次修订追加 `> **v<x.y+1> 修订（YYYY-MM-DD）**：变更摘要` 行。
- 文档末尾保留 `## 更新日志` 章节，详细列出每次修订内容。

### 引用规约

- 跨文档引用使用「《<文档简称>》§<章节号>」格式，例如「《规则与经济系统》§10」。
- 跨文档数据校验使用「依据《<文档简称>》<定位>」格式，例如「依据《底座》板块 3」。
- 所有财务数据必须可追溯到《真实世界底座》或本文档 §10。

### 同步规约

- 修改任意一份文档，必须同步检查本文档的「文档交叉引用关系图」是否需要更新。
- 修改《规则与经济系统》§10 职业数据，必须同步通知《玩家职业设计》§10.2 数据来源章节。
- 修改《玩家职业设计》§4 决策倾向矩阵，必须同步通知《行为金融》§1 总表。

### 行数上限

- 单份文档不超过 §4 单文件 ≤ 1800 行硬上限（CLAUDE.md §4）。
- 当前最大单文档：《交易拍卖与企业经营设计》1245 行（未触顶）；《行为金融与投资心理机制设计》1250 行（未触顶）。
