## 1. 测试总纲：为什么需要 Playtest 数据

### 1.1 现状诊断

《知识库审计与去重报告_20260912》第四节将 G3 列为明确缺口：

> "9 份核心文档全是设计稿，无任何一局测试时长、胜率分布、卡池抽到率、经济通胀实测记录；《棋盘与道具》有时长预算但无实测回填。"

后果：《规则手册》v1.1 自称"依据《真实世界底座》完成参数校准"，但那是**文献校准**（锚定统计局/LPR/CPI），不是**对局校准**（玩家真实行为）。文献校准保证"数值不像假的"，对局校准保证"游戏真的好玩且平衡"。本文档补的是后者。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| **先测机制，再调数值** | α 阶段只问"规则玩不玩得下去"，不问"数字对不对"；数值问题留到 β。 |
| **一切结论可复算** | 每条平衡结论必须能追溯到采集表的一局记录或蒙特卡洛的一次模拟，禁止"我觉得"。 |
| **教育目标与可玩性双轨验收** | 一局既要看"好不好玩"（留存/满意度），也要看"教没教到"（知识点测后测对比）。 |
| **AI 局与真人局分开统计** | 单人/AI 局的平衡框架见《财商流游戏单人模式与 AI 玩家平衡设计》（G4 文件），本文档以真人局为主，AI 局仅作压测数据源。 |

## 2. 测试目标与七维测量指标

### 2.1 总目标

一局 **2–6 人真人局**，**目标时长 100–140 分钟**（对齐《总体设计》§1.1 的"2 小时"定位，允许 ±20 分钟弹性），让玩家走完 20→60 岁人生轴（1 回合 = 1 游戏月，见《规则手册》§1.2），结束时：

- 至少 **60% 的玩家**形成了 ≥2 类资产的资产配置；
- **无单一投资品收益率长期跑赢其他品类 1.5 倍以上**；
- 玩家在局后问卷中"我学到了一条以前不知道的财商道理"勾选率 ≥ 70%。

### 2.2 七维指标定义表

| # | 维度 | 指标定义 | 设计目标值 | 测量方式 |
|---|------|---------|-----------|---------|
| D1 | **一局时长** | 从 S1 开局到终局结算的墙钟时间 | **100–140 分钟**（中位数） | 采集表 T_total |
| D2 | **经济通胀率** | 终局全桌总资产 ÷ 开局全桌总现金（即"钱被印多快"） | **3.0–5.5 倍/局** | 终值汇总计算 |
| D3 | **胜率/结局分布** | 财务自由 / 人生圆满 / 平庸度日 / 破产出局 四结局占比 | 自由+圆满 ≥45%，破产 15–30% | 终局分类计数 |
| D4 | **卡池抽到率** | 每张事件卡/心魔卡/行业卡的实际出现频次 vs 设计频次 | 偏差 ≤ ±25% | 卡池日志统计 |
| D5 | **破产率** | 触发《规则手册》§12 破产出局规则的玩家占比 | **15–30%**（单局）；≥40% 触红线 | 破产回合记录 |
| D6 | **投资品收益率分布** | 8 类投资品各自的局化年化收益率（=局收益/投入×12/经过月数） | 任意品类持续 >30%/局 或 <3%/局 触红线 | 逐资产结算 |
| D7 | **玩家满意度** | 局后 5 分制问卷：时长感受/难度/公平感/学到东西/想再玩 | 均分 ≥ 3.8；"想再玩"≥60% | 问卷 |

### 2.3 为什么是这七维（设计意图）

- D1 直接对应"2 小时"承诺；超时长是桌游体验第一杀手。
- D2 衡量经济系统是否"印钞过度"或"紧缩死局"：通胀过高=随便买都赢（失去决策意义），过低=有钱没处投（市场死寂）。
- D3 验证《总体设计》§7 多结局不是摆设：若 90% 都破产或 90% 都自由，结局系统失效。
- D4 保证 315 张卡牌（《棋盘与道具》§6）没有"死卡"或"霸屏卡"。
- D5/D6 是数值平衡的两只手：D5 管"别把人逼死"，D6 管"别让某类资产成神"。
- D7 是主观维度，用于校验客观指标没把游戏调成"正确但无聊"。

## 3. 三阶段测试设计：α → β → 公测

### 3.1 阶段总览

| 阶段 | 代号 | 核心问题 | 样本量 | 参与者画像 | 通过标准（Go/No-Go） |
|------|------|---------|--------|-----------|---------------------|
| **α 机制验证** | α | 规则玩得下去吗？流程卡死吗？三表勾稽算得对吗？ | **≥ 15 局**（≥90 人次） | 设计师+核心测试组（懂规则的内部玩家） | ①一局能在 180 分钟内打完；②三表勾稽零错账（Agent 校验通过率 100%）；③无规则歧义导致的停表争论 ≥2 次/局 |
| **β 数值平衡** | β | 数字平衡吗？某类资产过强吗？破产率正常吗？ | **≥ 60 局**（≥360 人次） | 分层抽样：入门/进阶/高净值各 1/3（对齐《总体设计》§1.2） | ①D1 中位数落入 100–140 分；②D5 破产率 15–30%；③D6 无品类持续 >30%；④D7 均分 ≥3.6 |
| **公测压力** | γ | 线上扛得住吗？随机/卡牌组合出 bug 吗？ | **≥ 300 局**（线上数据，含 AI 局） | 公开报名，含 30% 纯新手、20% 青少年教育场景 | ①崩溃率 <1%；②D2 通胀率落入 3.0–5.5；③前 3 回合无人交易的局占比 <20%；④D7 均分 ≥3.8 |

### 3.2 α 阶段（机制验证）细则

- **样本量下限 15 局**：桌游 α 测试需覆盖至少 3/4/5/6 人四种人数配置（建议 4+4+4+3 局），因为人数直接改变交易窗口 T1–T4（《交易经营》§2）的流动性。
- **参与者画像**：全部为"能替别人读规则"的内部测试员，目的是找**流程漏洞**而非数值快感。
- **关键动作**：每局指定 1 名"流程记录员"，记录 S1–S7 七阶段（《规则手册》§1.1）每个阶段的**实际停表时长**与**争论点**。
- **No-Go 情形**：若任一局出现"必须发明一条新规则才能继续"，则不进入 β，先补规则澄清 FAQ。

### 3.3 β 阶段（数值平衡）细则

- **样本量下限 60 局**：按桌游 playtest 统计惯例，60 局足以让单类投资品收益率分布的均值标准误 <2 个百分点（见 §6.2 统计功效估算）。
- **分层要求**：入门（18–25）/进阶（26–40）/高净值（40+）各 ≥20 局，避免"只被年轻人测过"导致数值偏向激进型玩家。
- **双盲埋点**：β 起，所有数据由线上版 Agent 自动埋点（见 §4），不依赖人工事后回忆。
- **A/B 切换规则**：同一周内对同一测试群轮换"旧数值 vs 新数值"（蒙住玩家版本号），用 §6.3 的 A/B 方法判断改动是否真的改善了 D3/D5/D6。

### 3.4 公测 γ 阶段（压力测试）细则

- **样本量 300 局**：其中 ≥30% 为纯新手（第一次接触规则），≥20% 为青少年财商课/企业团建场景，验证《行为金融》§6 的青少年适配与教育目标矩阵（《总体设计》§9）。
- **压测重点**：①线上 Agent 银行家（发薪/结算/拍卖主持）在高并发下的延迟与错算；②卡牌 1000+ 组合（职业 18 人 × 投资品 8 类 × 市场周期 4 阶段）下是否出现 D4 的"死卡/霸屏卡"；③单人/AI 局的通关率（交 G4 文档验收）。

### 4.4 胜负原因分类枚举（固定 8 类，用于归因）

| 代码 | 类别 | 判定依据 |
|------|------|---------|

| WIN-4 | 合伙/股权分红 | 被动收入主要来自合伙分红 |
| LOSE-1 | 高杠杆爆仓 | 破产主因是贷款月供>D5 |

## 5. 平衡阈值与红线清单

> **红线 = 触发即冻结当前数值版本、必须回炉调参的硬指标。** 下表阈值为设计初始建议值，经 α 阶段实测后在 §7 回填为正式值。

### 5.1 时长红线

| 规则 | 阈值 | 触发后的动作 |
|------|------|-------------|
| R-T1 | **单局墙钟 > 180 分钟** | 立即停赛复盘，定位是某圈耗时过长（看 §4.1 三段耗时）→ 压缩该圈格子事件结算量 |
| R-T2 | 生存圈耗时 >45 分钟（占比 >35%） | 生存圈是"新手教学段"，过长说明 S3 格子事件说明负担过重 → 把重复事件做快查卡 |
| R-T3 | 自由圈耗时 <15 分钟 | 自由圈是财富收割段，过快说明大额结算缺乏仪式感/决策深度 → 增加并购/传承选择 |
| R-T4 | **前 3 回合无人发起任何交易** | 说明 S1/T1 交易窗口太冷（《交易经营》§2）→ 优化开局交易引导（赠送 1 次撮合、降低首次议价心理门槛） |

### 5.2 经济与投资品红线

| 规则 | 阈值 | 触发后的动作 |
|------|------|-------------|
| R-E1 | **某投资品局化收益率持续 >30%**（连续 10 局以上均值） | 该品过强，**削弱**：下调其景气期收益率一档或提高入手门槛 |
| R-E2 | 某投资品局化收益率 <3%（连续 10 局） | 该品是"死资产"，**增强**：增加它的非货币效用（如人脉/认知补偿）或降低入手价 |
| R-E3 | **单桌经济通胀率 D2 >7 倍** | 印钞过快：发薪/分红总和 > 系统回收（税/支出/损失），调高税率或生活成本增速 |
| R-E4 | 单桌通胀率 <2 倍 | 市场死局：投资无利可图，降低优质资产入手门槛或缩短萧条期 |
| R-E5 | **破产率 D5 > 40%** | 初始资源/容错过低，**上调初始现金或延长新手保护期**（v2.58 P2-09 已有前 3 回合禁复杂衍生品） |
| R-E6 | 破产率 <8% | 破产线形同虚设，风险教育失效 → 收紧信用评分/缩短宽限期 |

### 5.3 分布与公平性红线

| 规则 | 阈值 | 触发后的动作 |
|------|------|-------------|
| R-B1 | 先手机会（第 1 位玩家）胜率 > 其他位次均值 +15pp | 先手优势过大，给后手"补偿性初始资源"或把开局格设为中性 |
| R-B2 | 某职业卡（P01–P18）胜率偏离全体均值 ±20pp | 该职业收入/风险画像失衡，回填《规则手册》§10 |
| R-B3 | 拍卖参与率中位数 <30% | 拍卖机制没人用（《交易经营》§4），改为强制触发或降低参与成本 |
| R-B4 | 某张卡抽到率 D4 偏差 >±50% | 死卡（<50% 设计频次）或霸屏卡（>150%），调整卡池权重/放入/移出 |
| R-B5 | 心魔卡触发后玩家"事后仍认为自己是对的"比例 >60% | 心魔教育失效（《行为金融》§1），复盘话术未击中，调整 §5 话术 |

### 5.4 阈值使用示例（决策树）

```
若 D5 破产率 = 45%（>40% 红线 R-E5）
  ├─ 先分解破产原因（§4.4）：LOSE-1 高杠杆爆仓占主导？
  │     ├─ 是 → 调《规则手册》§8 贷款降收入等级梯度，而非加钱
  │     └─ 否（LOSE-4 流动性枯竭为主）→ 加长 T1–T4 交易窗口频次
  └─ 用 §6.3 A/B 验证新数值：20 局新 vs 20 局旧，D5 是否回到 15–30%
```

## 6. 数值校准方法：蒙特卡洛 / 敏感度 / A-B 测试

### 6.1 蒙特卡洛模拟（Monte Carlo）参数

用于在**不烧真人局**的前提下粗筛数值。线上版 Agent 引擎天然可跑模拟局。

| 参数 | 取值 | 说明 |
|------|------|------|
| 单次模拟局数 | **1,000 局/配置** | 对齐 v2.58 P1-09"1000 局蒙特卡洛复盘" |
| 玩家决策模型 | 5 种原型（《总体设计》§10.2 保守/激进/社交/学习/谨慎）按真实人群比例投放 | 30%/17%/17%/22%/14%（对齐《行为金融》v1.3 画像分布） |
| 随机种子 | 固定种子 + 重复 10 次 | 保证可复现 |
| 输出 | D1–D6 六维指标的分布（中位数/P25/P75） | 输入《规则手册》§7.4 周期参数扫描 |
| 用途 | **在 β 之前**筛掉明显失衡的数值配置，真人局只测模拟通过的 2–3 个候选 |

> v2.58 已在行为金融侧用 1000 局复盘玩家个人策略；本节把它升级为**设计期数值扫描工具**，两者共用同一模拟引擎。

### 6.2 敏感度分析（Sensitivity Analysis）

一次只动一个参数，观察 D3/D5/D6 的响应，找出"杠杆点"。

| 被调参数 | 扫描范围 | 观察指标 | 预期敏感度方向 |
|---------|---------|---------|---------------|
| 股票景气期收益率（现 +10%，见《总体设计》§8.3） | 5% / 10% / 15% / 20% | D6 股票收益率、D3 胜率 | 越敏则股票越易成神 |
| 初始现金 | ±20% | D5 破产率 | 直接对应 R-E5 |
| 萧条期持续回合数（现 2–4 年） | 1/2/4/6 年 | D2 通胀率、D6 | 越长则积累圈越苦 |
| 个税起征档距（现 7 级累进） | 档距 ±20% | D7 公平感、高净值结局占比 | 高净值线敏感 |
| 心魔卡触发阈值（如连赢 3 次） | 2/3/4/5 次 | 心魔触发次数、LOSE-3 占比 | 阈值越低触发越密 |

**方法**：每个参数取 4 档 × 1000 局 = 4000 次模拟，画"参数—指标"曲线；曲线最陡的参数即"杠杆参数"，是 playtest 时人工重点盯防项。

### 6.3 A/B 测试设计

真人局阶段用 A/B 确认改动方向：

| 要素 | 规定 |
|------|------|
| 分组 | 同一测试周内，同一测试群，双周轮换 A/B（交叉设计，抵消"周次"偏差） |
| 最小样本 | 每组 **≥20 局**（使破产率差的统计检验功效 ≥0.8，α=0.05） |
| 主指标 | 先看 D5 破产率与 D6 收益率差；D7 满意度作护栏（不得因调数值把满意度打下来） |
| 显著性判定 | 两比例用卡方检验；收益率均值用 t 检验；p<0.05 才认定改动有效 |
| 护栏 | A/B 任何一边出现 R-T1（>180 分）或 D2 越界，立即中止该组 |

## 8. 数据治理与复盘流程

### 8.1 一局一闭环（每局结束后 24 小时内）

1. 局级 + 玩家级采集表由 Agent 自动生成（线上版）或流程记录员录入（线下版）。
2. 主持人对照 §4.4 给每位玩家打胜负原因分类。
3. 若该局触碰任一 §5 红线，自动生成"红线警报工单"，48 小时内召开设计评审。

### 8.2 阶段一汇报（每 20 局一次）

- 出一张**仪表盘**：D1–D7 当前均值 vs 目标区间 + 最近 5 条红线事件。
- 决策：Go（进下一阶段）/ Iterate（回炉调参）/ Hold（数据不足，继续测）。

### 8.3 防数据自欺

- **避免幸存者偏差**：未完成局（中途走人）也必须记录其局内数据，不能只统计打完的局。
- **避免霍桑效应**：β 起玩家知道"被测试"会超常理性，需在 γ 引入"匿名公开局"对照。
- **数值不可回改**：一经回填《规则手册》，旧值只入变更日志，不在文档正文覆盖。
