# 中国军棋（Junqi）游戏币策划方案

> 版本：v1.0　|　作者：game-designer　|　最后更新：2026-07-02　|　适用：LsmAgentGame MVP

---

## 1. 概述

### 1.1 产品定位
中国军棋是平台第三款棋类（2 人 1v1），核心特征是 **信息不对称 · 暗棋试探 · 子力碰撞**。相比象棋"全盘可见"，军棋对局中的**决策密度更高、心理博弈更深**，单局平均时长 **20–45 分钟**，在所有游戏中属于中长篇。

### 1.2 金币定位
军棋金币（封闭资金池）在 junqi 中的定位，不是"运气博弈"（斗地主/德州），而是**策略深度对赌**——玩家用金币对赌**情报分析能力**与**子力调配决策**。底注应介于德州扑克（高博弈）与象棋（低博弈）之间，鼓励**技术型玩家**长期留存。

### 1.3 设计原则
| 维度 | 原则 |
|------|------|
| 公平性 | 暗棋模式信息不对称属于合法博弈，不得作为刷分工具 |
| 流动性 | 单局金币周转占余额比例 ≤ 20%，防止波动过大 |
| 活跃度 | 每日登录 + 胜场 + 连胜三重激励，覆盖休闲与硬核玩家 |
| 段位分层 | 4 档底注匹配玩家资产量级，避免"贫富悬殊对局" |

## 2. 金币获取途径

### 2.1 注册奖励（一次性）
| 项目 | 数值 |
|------|------|
| 新账户注册 | **+1,000 金币** |
| 发放时机 | 注册成功后立即发放（落 `t_lsm_game_wallet_log`，source=`register`） |
| 备注 | 与现有 5 款游戏统一标准 |

### 2.2 每日登录奖励（日活核心）
| 项目 | 数值 |
|------|------|
| 每日登录 | **+2,000 金币 / UTC+8 自然日** |
| 发放时机 | 用户任意一次登录触发发放，后同日内不重复 |
| 防重复 | `t_lsm_game_daily_reward(user_id, reward_date)` 唯一键 |
| 补领 | **不补领**（过期作废，控制通胀） |
| 备注 | 与德州/斗地主同档，军棋单局时长更长、日活上限更低，故不加大奖励 |

### 2.3 胜场奖励（核心PVP激励）
采用 **"底注比例 × 对手等级加成"** 公式：

```
胜场奖励 = floor( 房间底注 ante × 奖励系数 α × 对手等级因子 β )
```

**参数定义：**
| 参数 | 值 | 说明 |
|------|----|----|
| α（基础奖励系数） | **1.8** | 赢家扣除 10% 平台手续费后净赚约 0.8×ante（两家通吃） |
| β（对手等级因子） | 1.0 / 1.1 / 1.2 / 1.3 | 按对手近 30 天胜场数分档（<10 场=1.0，10–30=1.1，30–100=1.2，>100=1.3） |

**举例：**
- ante=100，打β=1.0 对手 → 胜者得 180，负者 -100
- ante=500，打β=1.3 对手 → 胜者得 1,170，负者 -500

**MVP 处理**：β 简化为 1.0（不区分对手等级），后续版本动态计算。

### 2.4 连胜奖励（streak加成）
| 连胜场次 | 额外倍率 | 说明 |
|---------|---------|------|
| 3 连胜 | ×1.2 | 触发门槛低，鼓励持续对局 |
| 5 连胜 | ×1.5 | 中高段位玩家目标 |
| 10 连胜 | ×2.0 | 巅峰奖励，系统公告 |

- **重置条件**：任意一局为负（投降/被将死/超时）→ 连胜归零
- **和局处理**：连胜保留但不递增（防止和局刷 streak）

### 2.5 邀请好友奖励（reusal referral）
利用现有 `referral_count` / `referrer_user_id` 字段：

| 条件 | 奖励 |
|------|------|
| 被邀请好友完成注册 | 邀请人 +500 金币 / 人 |
| 被邀请好友完成 10 场军棋 | 邀请人 +500 金币 / 人（额外） |
| 月度邀请上限 | 20 人 / 自然月（防羊毛） |

备注：邀请奖励 **不触发递归**（仅一层邀请链路）。

### 2.6 其他（MVP 不实施，列作路线图）
| 类型 | 说明 |
|------|------|
| 成就系统 | 首胜 / 百场 / 千场里程碑 → 固定金币 |
| 活动奖励 | 节日活动、赛季通行证（延期） |
| 任务系统 | 每日"完成 3 局军棋"→ 300 金币（延期） |
| 段位奖励 | 达到特定段位发放一次性段位奖金（延期） |

## 3. 金币消耗途径

### 3.1 带注房间入场（ante）—— 主消耗通道
详见 §4 房间带注规则。

### 3.2 投降惩罚（reduce loss）
| 情况 | 扣减 |
|------|------|
| 主动投降（resign） | 扣除底注的 **100%**（按全输处理） |
| 超时判负（120s未落子） | 扣除底注的 **100%** |
| 断线超时（15s 被踢） | 扣除底注的 **100%**，对方获胜计分 |

说明：不存在"投降减半"—— 军棋战局劣势时认输是正常决策，全额扣减维持博弈完整性。

### 3.3 商城（MVP 不实施，方向预留）
| 品类 | 建议定价 |
|------|---------|
| 头像框（赛季限定） | 1,000 – 5,000 |
| 棋盘皮肤（木质/金属/夜景） | 2,000 – 8,000 |
| 棋子皮肤（卡通/写实/像素） | 3,000 – 10,000 |
| 表情/动作特效 | 500 – 2,000 |

## 4. 房间带注规则

### 4.1 底注档位（ante）
提供 **4 档标准底注** + 自定义（后续版本开放）：

| 档位 | ante（金币/桌） | 适合玩家 | 备注 |
|------|----------------|---------|------|
| 新手桌 | **50** | 注册 ≤ 7 天 或 余额 < 500 | 低保门槛 |
| 标准桌 | **100** | 主要流量池 | MVP 默认选中 |
| 进阶桌 | **500** | 中高级玩家 | 余额 ≥ 2500 解锁 |
| 高手桌 | **1,000** | 硬核玩家 | 余额 ≥ 5000 解锁 |

**解锁条件**（创建房间时校验）：
- `balance ≥ ante × 5`：单局最大可能损失（含连胜倍率）= ante × 1.0（单局扣 ante），5 倍缓冲保障玩家不致一蹶不振
- 不满足解锁条件 → 前端底注选项灰化，hover 显示"余额不足"

### 4.2 奖金分配规则
采用 **"赢家通吃"**：

- **胜者**：获得 `2 × ante - 平台手续费`
- **负者**：损失 `ante`
- **平台手续费**：10%，即 0.2×ante 进入系统回收池

**举例**（ante=100）：
- 玩家 A 投入 100，玩家 B 投入 100，总池 200
- 手续费 20，奖励池 180
- 胜者 A 净收益 = +80（收到 180，其中 100 是本金）
- 败者 B 净收益 = -100

### 4.3 和局处理
军棋和棋（双方同意 / 三次重复局面 / 60 步无吃子）：

| 结果 | 处理 |
|------|------|
| 首次和局 | **双方退还 ante，不扣手续费** |
| 连续同房间和局（≤ 3 次） | 第 3 次起扣除 10% 手续费 |
| 恶意和局检测 | 触发异常检测机制（见 §5） |

### 4.4 破产保护
| 机制 | 规则 |
|------|------|
| 最低余额下限 | **0** 金币（可归零） |
| 余额 < 最低底注（50）时 | 只能加入 ante=50 的新手桌（如仍不足则禁止创建带注房间） |
| 零余额救济 | 连续 3 天未登录的归零账户，触发"救济金"登录一次性 +500（防流失） |
| 最大单局损失 | ≤ 1,000（ant=1,000 全输），避免小额玩家一次爆仓 |

## 5. 风控与防作弊

### 5.1 刷分检测
| 风险场景 | 检测规则 | 处置 |
|---------|---------|------|
| 同 IP 多账号 | 单 IP 同日内 ≥ 3 账号进行军棋对局 | 标记审计，对局结果暂不发放金币 |
| 同设备指纹 | 浏览器指纹 24h 内换账号对局 | 触发人机验证 |
| 反复对局 | 同 pair（A vs B）24h 内 ≥ 5 局 | 从第 6 局起金币收益递减 50% |
| 投降刷分 | 一方连续 3 局在 60s 内 resign | 触发人工审核 |

### 5.2 异常胜率监控
| 指标 | 阈值 | 动作 |
|------|------|------|
| 单账号 7 日胜率 | > 90% 且 样本 ≥ 30 局 | 标记"异常高胜率"，进入审计队列 |
| 单账号 7 日胜率 | < 10% 且 样本 ≥ 30 局 | 标记"可疑送分局"，关联对手一并审计 |
| 金币转移方差 | 核心玩家群金币流入/流出比 > 3σ | 触发反洗钱审计 |

### 5.3 流水审计要求
每笔金币变动必须落 `t_lsm_game_wallet_log` 双簿记流水：
- **主账户**：金币余额（balance）
- **流水表**：每笔 `user_id, amount, type, ref_id, created_at, before_balance, after_balance`
- 流水保留 **365 天**，支持按 user_id / ref_id / type 查询

### 5.4 军棋特殊风险
| 风险 | 影响 | 对策 |
|------|------|------|
| 暗棋信息不对称 | 可用"藏子"规则掩护刷分（故意输子） | 监控异常"早期大量送子"模式 |
| 司令阵亡亮旗 | 可利用亮旗规则判断对手子力分配，合法利用但需防机器人 | 机器人行为检测（AI 挑战） |
| 心理博弈刷分 | 利用"对手子力误判"故意制造有优势后投降 | 监控连胜后立即投降的模式 |

## 6. 数值平衡建议

### 6.1 通胀/通控
| 指标 | 目标 |
|------|------|
| 每日金币新增 / 每日金币消耗 | ≈ 1:1.2（微通缩，维持金币价值） |
| 注册玩家前 30 天金币持有 | 3,000 – 15,000 |
| 中高活跃玩家（日均 2 局）持有 | 10,000 – 50,000 |
| 高活跃玩家（日均 ≥ 5 局）持有 | 30,000 – 200,000 |
| 平台整体金币流通速率 | ≈ 每日总量 1%（调控手续费率） |

**调控手段**：
- 手续费率浮动（当前 10%，可按通胀指标在 5%–15% 之间调整）
- 活动奖励窗口控制（节假日加大回收力度）
- 商城金消费（后续版本引入高价位皮肤）

### 6.2 底注段位分层
| 玩家资产量级 | 推荐底注 | 风险比（单局损失 / 总资产） |
|-------------|---------|--------------------------|
| 1 千 – 3 千 | 50 | ≤ 5% |
| 3 千 – 1 万 | 100 | ≤ 3% |
| 1 万 – 5 万 | 500 | ≤ 3% |
| > 5 万 | 1,000 | ≤ 2% |

目标：让活跃玩家**长期停留在风险比 2%–5%**，避免一场对局摧毁心态。

## 8. 与其他游戏的差异化

| 维度 | 中国象棋 | 国际象棋 | **中国军棋** | 斗地主 | 德州扑克 |
|------|---------|---------|------------|-------|---------|
| 平均对局时长 | 15–30 min | 20–40 min | **20–45 min** | 5–15 min | 10–25 min |
| 决策密度 | 中 | 中 | **高** | 低 | 中 |
| 信息不对称 | 无 | 无 | **暗棋模式** | 暗牌 | 暗牌 |
| 底注档位 | 50/100/200 | 50/100/200 | **50/100/500/1000** | 50/100/200/500 | 100/500/1000/5000 |
| 奖励系数 | 1.5 | 1.5 | **1.8** | 2.0 | 2.5 (pot-based) |
| 单局金币周转率 | 中 | 中 | **中高** | 低 | 高 |

**差异化理由**：
1. 军棋对局时长最长 → 单局价值应更高（奖励系数 1.8 vs 象棋 1.5）
2. 军棋心理博弈最深 → 硬核玩家基数小 → 底注跨度更大（支持 1000 档）
3. 军棋暗棋模式 ≠ 真人德州（机会因素可通过策略对冲）→ 奖励系数居中

## 9. 军棋特殊考量

### 9.1 明棋 vs 暗棋模式金币规则
| 模式 | 是否支持带注 | 金币规则 |
|------|------------|---------|
| **暗棋模式**（默认，信息不对称） | ✅ | 适用全部金币规则 |
| **明棋模式**（双方可见） | ✅ (MVP 内) | 奖励系数下调至 **1.3**（消除信息壁垒的纯策略博弈） |
| **自定义开局** | ❌ | 不涉及金币 |

MVP 版本：先上线**暗棋带注**，明棋模式作为"练习/无注"保留，带注明棋后续版本评估是否放开。

### 9.2 司令阵亡亮旗规则与金币
- 当前规则：司令（军长）阵亡后，对手可看到其位置
- 与金币挂钩：**不直接挂钩**——亮旗是战局信息，不是资源
- 风控关联：监控"快速送司令"的异常模式（可能故意制造局面刷分）
- 建议：加入**异常行为检测**（近 5 局有 3 局司令首 5 步被吃 → 触发审计）

### 9.3 其他特殊规则影响
| 规则 | 金币影响 | 处理 |
|------|---------|------|
| 地雷只能被工兵挖 | 影响对局时长 | 不直接影响金币，但长对局消耗时间 → 间接影响活跃度 |
| 炸弹与任何子同归于尽 | 增加对局变数 | 认定为影响对局的"高风险高回报"要素，奖励系数不变 |
| 军旗被扛 = 输 | 终结对局关键 | 与金币结算直接挂钩（扛旗直接触发胜负结算） |

> **结束语**：军棋在 LsmAgentGame 5 款游戏中是**策略深度最高、对局时长最长、单局金币价值最高**的产品。策划核心是 **"让技术型玩家长期驻留、让新人不再被一场对局劝退"**。上述数值和机制正是在这一目标上的第一次平衡尝试，上线后需根据实际留存率、金币流转率、段位分布持续迭代。
