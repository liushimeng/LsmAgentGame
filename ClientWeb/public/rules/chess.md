## 1. 游戏性质与目标

### 1.1 基本定义

国际象棋是两名棋手在正方形棋盘上**交替移动棋子**的对弈游戏。执浅色棋子（**白方**）的一方**先行**，执深色棋子（**黑方**）的一方后行，双方轮流走棋。

### 1.2 游戏目标

每位棋手的目标是**攻击对方的王**，使对方王没有任何合法着法可以躲避攻击。达成此目标称为「**将死**」（Checkmate），将死对方者获胜。

### 1.3 核心原则

- **不允许**将自己的王置于被攻击的位置。
- **不允许**让自己的王处于被攻击状态而不走开。
- **绝对不允许**吃掉对方的王。

## 2. 棋盘与棋子

### 2.1 棋盘结构

- 棋盘为正方形，由 **8×8 = 64 个** 大小相同的方格组成，深浅颜色交替排列。
- 深色方格称为「**黑格**」，浅色方格称为「**白格**」。
- 棋盘置于两位棋手之间，**每位棋手的右下角必须是白格**。

### 2.2 坐标系统

棋盘采用**代数记谱法**标识：

- **横线（行）**：从白方视角由近到远编号为 **1 至 8**。
- **竖线（列）**：从白方视角由左到右标记为 **a 至 h**。
- **格子命名**：列字母 + 行数字，例如 `a1`、`e4`、`h8`。

### 2.3 棋子种类与数量

每方各有 **16 枚** 棋子，共 **6 种**：

| 棋子 | 数量  | 英文名称 |
| ---- | ----- | -------- |
| 王   | 1 枚  | King     |
| 后   | 1 枚  | Queen    |
| 车   | 2 枚  | Rook     |
| 象   | 2 枚  | Bishop   |
| 马   | 2 枚  | Knight   |
| 兵   | 8 枚  | Pawn     |

### 2.4 初始位置

**白方棋子初始位置**（第 1、2 横排）：

- 第 1 排（从 a 到 h）：**车、马、象、后、王、象、马、车**。
- 第 2 排：8 个兵。

**黑方棋子初始位置**（第 8、7 横排）：

- 第 8 排（从 a 到 h）：**车、马、象、后、王、象、马、车**。
- 第 7 排：8 个兵。

> 注意：白后位于白格（d1），黑后位于黑格（d8），即「**后占己色**」。王位于后的另一侧（白王 e1，黑王 e8）。

## 3. 棋子基本走法

### 3.1 王（King）

- 每次可向任意方向（横、竖、斜）移动**一格**。
- 不能移动到被对方棋子攻击的格子。
- 不能移动到与对方王相邻的格子。
- 王是对局核心，被将死即输掉对局。

### 3.2 后（Queen）

- 可沿横、竖、斜任意方向移动**任意格数**。
- 不能越过其他棋子。
- 是棋盘上威力最大的棋子。

### 3.3 车（Rook）

- 可沿横、竖方向移动任意格数。
- 不能越过其他棋子。
- 参与王车易位特殊走法。

### 3.4 象（Bishop）

- 可沿斜线方向移动任意格数。
- 不能越过其他棋子。
- 每只象始终只能在同色格子上移动（白格象或黑格象）。

### 3.5 马（Knight）

- 走「**日**」字形：先横走两格再竖走一格，或先竖走两格再横走一格。
- **唯一可以越过其他棋子的棋子**（跳跃移动）。
- 落点格有己方棋子时不能走过去。
- 马从白格出发必落黑格，从黑格出发必落白格。

### 3.6 兵（Pawn）

- **前进**：每次向前走一格；从未移动过的兵第一步可选择走一格或两格。
- **吃子**：斜向前方一格吃子（**不能直走吃子，也不能斜走空步**）。
- **后退**：兵永远不能后退。
- 兵是**唯一走法与吃子方式不同的棋子**。

### 3.7 吃子通用规则

- 除马外，棋子**不能越过其他棋子**。
- 对方棋子占据目标格时可以吃掉它，将其从棋盘上移除。
- 己方棋子占据目标格时不能移动过去。
- 吃子时，移动方棋子占据被吃棋子的格子。

## 4. 特殊走法规则

### 4.1 王车易位（Castling）

王车易位是一步棋内**同时移动王和一辆车**的特殊走法，每方每局仅有一次机会。

#### 4.1.1 操作方式

- 王朝车的方向移动两格。
- 该车越过王，放置在王另一侧紧邻的格子上。

#### 4.1.2 两种易位

| 易位方式     | 王移动路径     | 车落点 |
| ------------ | -------------- | ------ |
| 短易位（王翼） | 王向 h 线方向移动两格（白王到 g1，黑王到 g8） | f 线   |
| 长易位（后翼） | 王向 a 线方向移动两格（白王到 c1，黑王到 c8） | d 线   |

#### 4.1.3 必备条件（必须全部满足）

- 王在此局中尚未移动过。
- 参与易位的车在此局中尚未移动过。
- 王与该车之间没有任何棋子阻隔。
- 王当前不处于将军状态。
- 王经过的格子不被对方棋子攻击。
- 王最终落点的格子不被对方棋子攻击。

> 注意：易位时**车经过的格子**是否被攻击不影响易位合法性，只有王经过和落点的格子受此限制。

### 4.2 吃过路兵（En Passant）

#### 4.2.1 触发条件

- 对方一个兵从初始位置一步前进两格。
- 该兵落地后与己方兵横向相邻（并排）。
- 己方兵原本可以斜吃该兵只走一格后的位置。

#### 4.2.2 吃子方式

己方兵斜向前走一格，落到对方兵「经过」的那个格子上，对方兵被吃掉并移除。

#### 4.2.3 时效规则

- 吃过路兵必须在对方兵走两格后的**紧接着一回合内**执行。
- 若当回合不吃，则**永久失去**吃过路兵的权利。

### 4.3 兵的升变（Promotion）

#### 4.3.1 升变条件

当兵到达对方底线（白兵到第 8 横排，黑兵到第 1 横排）时，**必须升变**。

#### 4.3.2 升变选择

- 兵可升变为**后、车、象、马**中的任意一种。
- **不能升变为王**。
- 升变棋子颜色与己方相同。
- 升变不要求该棋子已被吃掉，理论上可拥有多个后（最多 9 个后）。

#### 4.3.3 升变完成

当棋手将新棋子放到升变格并松开手时，升变完成，该步棋结束。升变后的棋子立即具备全部走法能力。

## 5. 行棋行为规范

### 5.1 轮流行棋

- 白方先行，之后黑白双方交替走棋。
- 走完一步棋并按停己方棋钟后，轮到对方行棋。

### 5.2 摸子走子规则

- 若棋手**故意触摸己方棋子**，则必须移动该棋子（若有合法着法）。
- 若棋手**故意触摸对方棋子**，则必须吃掉该棋子（若能合法吃掉）。
- 若触摸多个棋子，必须移动或吃掉第一个触摸的可走/可吃棋子。
- 如需摆正棋子位置，应事先声明「**摆正**」（J'adoube）。

### 5.3 落子无悔

- 棋子移动到某格后，棋手松手即完成该步棋，不得更改。
- 若棋子未松手，可以改走其他格子。
- 吃子时，松开被吃棋子即完成吃子。

### 5.4 非法着法

- 走出不符合棋子走法的棋。
- 走棋后己方王仍处于或进入被攻击状态。
- 违反王车易位、吃过路兵等特殊规则的着法。
- 非法着法应予以撤回，重走合法着法，并根据规则判罚。

## 6. 将军与将死

### 6.1 将军（Check）

当王处于对方棋子的攻击范围内时，称为「**被将军**」。

### 6.2 解将的三种方式

被将军时必须立即应将，且只能通过以下三种方式之一：

| 方式 | 操作                                                         |
| ---- | ------------------------------------------------------------ |
| 移王 | 将王移动到不被攻击的格子                                     |
| 吃子 | 吃掉进行将军的对方棋子                                       |
| 垫将 | 用己方棋子挡住将军路线（**仅适用于远射程棋子将军，马将军无法垫将**） |

### 6.3 将死（Checkmate）

- 王处于将军状态。
- 该方没有任何合法着法可以解除将军。
- 将死立即结束对局，**将军方获胜**。

## 7. 对局胜负判定

### 7.1 获胜情况

| 胜负条件       | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| 将死对方       | 将死对方王的一方获胜，对局立即结束                           |
| 对方认输       | 一方口头认输或推倒自己的王，对方获胜                         |
| 对方超时       | 对方棋钟时间耗尽且己方有足够子力将死                         |
| 对方严重违例   | 对方因严重违反规则被判负                                     |

### 7.2 认输规则

- 认输可以口头声明或推倒己方王表示。
- 认输一旦作出**不可撤回**。
- 若局面为理论和棋（对方无法将死），即使认输也判和。

## 8. 和棋规则

### 8.1 逼和（Stalemate）

- 轮到行棋的一方王**未被将军**。
- 该方**没有任何合法着法**可走。
- 符合以上两条即为逼和，对局判和。

> 注意：**逼和 ≠ 将死**。将死是王在将军中无路可走（负），逼和是王不在将军中但无路可走（和）。

### 8.2 协议和棋

- 一方可以提议和棋，对方同意则和棋成立。
- 和棋提议**只能在自己刚走完一步棋后**提出。
- 对方可以口头接受，也可以走一步棋表示拒绝。
- 和棋提议一旦提出，在对方答复前不可撤回。

### 8.3 子力不足和棋（理论和棋）

当双方子力都不足以将死对方时，对局判和。典型情况：

- 单王对单王
- 王 + 单象对单王
- 王 + 单马对单王
- 王 + 单象对王 + 单象，且双方象在同色格上

> 核心判断标准：无论双方如何走棋，都不可能出现将死局面，则为死局，直接判和。

### 8.4 三次重复局面和棋

- 同一局面在棋盘上出现三次。
- 每次都是同一方行棋。
- 每次双方拥有的权利完全相同（包括王车易位权、吃过路兵权）。
- 由棋手向裁判提出申诉后判和，**非自动判和**。
- 局面重复不必连续。

### 8.5 五十回合规则

- 连续 50 个回合（双方各走 50 步，共 100 个半步）。
- 期间没有任何棋子被吃掉。
- 期间没有任何兵移动过。
- 由棋手向裁判提出申诉后判和。

> 补充：七十五回合规则——若连续 75 回合无吃子无兵动，裁判**可直接判和**，无需棋手申诉。

### 8.6 长将和棋

一方通过连续不断的将军使对方无法摆脱，且形成三次重复局面时，可按三次重复规则判和。长将本身不是独立的和棋规则，本质上属于三次重复局面。

## 9. 棋钟与计时规则

### 9.1 棋钟使用

- 每方各有一个计时器，累计各自思考时间。
- 棋手走完一步棋后按停自己的钟，同时启动对方的钟。
- 棋钟必须用走棋的那只手按。

### 9.2 超时判罚

- 一方棋钟时间耗尽称为「**旗落**」。
- 旗落后对方发现并指出，则超时方判负。
- 若对方子力不足以将死，则**超时判和**。

### 9.3 常见时限类型

| 赛制 | 时限                          |
| ---- | ----------------------------- |
| 快棋 | 每方总时间少于 10 分钟        |
| 快棋（标准） | 每方 10~60 分钟        |
| 慢棋 | 每方 60 分钟以上              |
| 加秒制 | 每走一步增加若干秒（如每步加 30 秒） |

### 9.4 超时与未完成着法

如果旗落时棋手的手尚未离开棋子，则该步棋**不算完成**。

## 10. 对局记录

### 10.1 记录义务

正式比赛中，双方棋手必须在对局记录纸上**逐着记录**双方走法，使用代数记谱法。

### 10.2 代数记谱法

| 符号      | 含义                                       |
| --------- | ------------------------------------------ |
| 棋子缩写  | 王 K、后 Q、车 R、象 B、马 N，兵不写字母   |
| 记录格式  | 棋子字母 + 目标格子                        |
| `x`       | 吃子标记，如 `Bxf7` 表示象吃 f7            |
| 兵吃子    | 记出发列，如 `exd5` 表示 e 线兵吃 d5      |
| 短易位    | `O-O`                                      |
| 长易位    | `O-O-O`                                    |
| `+`       | 将军                                       |
| `#` 或 `++` | 将死                                     |

### 10.3 记录豁免

当一方剩余时间不足 **5 分钟**且无每步加秒时，可暂停记录。旗落后必须补全记录。

### 10.4 记录纸

对局结束后，双方在记录纸上签字确认结果。记录纸归赛事主办方所有。

## 11. 违例与判罚

### 11.1 非法着法处罚

- 慢棋中**首次**出现非法着法：警告，加给对方 2 分钟时间。
- **同一方第二次**出现：判负。

### 11.2 严重违例

- 使用外部帮助（电子设备、书籍等）。
- 故意干扰对手。
- 拒绝遵守裁判指令。
- 严重违反体育道德行为。

> 以上行为可直接判负或取消比赛资格。

### 11.3 申诉

棋手对裁判裁决不服，可按赛事规定程序申诉。**申诉期间对局继续进行**。

## 12. 裁判员职责

### 12.1 裁判职责

- 确保规则得到遵守。
- 维护比赛秩序与环境。
- 裁决争议与申诉。
- 执行计时与判罚。
- 监督对局记录与结果确认。

### 12.2 裁判权力

- 警告、罚时、判负。
- 调整棋钟时间。
- 中断或延期对局。
- 取消棋手比赛资格。

## 13. 附录：常见术语表

| 术语     | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| 先手     | 白方先行的优势                                             |
| 后手     | 黑方后行的劣势                                             |
| 兑子     | 交换价值相当的棋子                                         |
| 弃子     | 主动送吃棋子以换取局面优势                                 |
| 闪击     | 一子走开后露出后方远射程子力攻击                           |
| 双将     | 两个棋子同时将军，只能移王解将                             |
| 牵制     | 棋子因保护王或重要子力而不能移动                           |
| 串击     | 沿一条线攻击两个目标                                       |
| 击双     | 一步棋同时攻击两个目标                                     |
| 升变格   | 兵到达底线进行升变的格子                                   |
| 底线杀   | 利用对方王被己方兵阻挡在底线将死                           |
| 肩冲     | 用王从侧面限制对方王的活动                                 |
