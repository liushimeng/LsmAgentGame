# 中国军棋（陆战棋）规则

> 军棋又名陆战棋，是中国流行的双人或四人策略棋类游戏。本规则以**暗棋**模式为主，附加明棋、翻翻棋、四国军棋等变体说明。平台实现以服务端权威为准，引擎位于 `ServerGo/game/junqi/`，前端 UI 位于 `ClientWeb/src/components/junqi/`。

## 1. 游戏概述

军旗又名陆战棋，是中国流行的**双人**或**四人**策略棋类游戏。游戏核心目标是通过棋子的移动与战斗，**夺取对方军旗**或**消灭对方所有可移动棋子**以获得胜利。军旗游戏兼具策略性与趣味性，暗棋模式下还包含信息博弈的元素。

## 2. 棋盘结构

军旗棋盘由**公路线**、**铁路线**、**兵站**、**行营**、**大本营**和**山界**组成。

### 2.1 线路系统

- **公路线**：棋盘上较细的单线。任何棋子在公路线上每回合只能沿连线方向移动一格。
- **铁路线**：棋盘上较粗的双线。铁路线是棋子的快速移动通道，在无棋子阻挡时，**普通棋子可沿直线移动任意步数**；**工兵**可沿铁路线转弯移动。
- **弧形铁路线**：棋盘四角的弧形铁路属于铁路线的一部分，普通棋子可沿弧形线转弯，但**不能转直角弯**。

### 2.2 点位类型

| 点位     | 数量 / 方 | 说明                                                         |
| -------- | --------- | ------------------------------------------------------------ |
| 兵站     | 23        | 棋子的常规摆放与落点位置。棋子在兵站上可以移动、攻击或被攻击 |
| 行营     | 5         | 圆形标记。进入行营的棋子受到保护，敌方棋子不能攻击行营内的棋子，但行营内的棋子可以主动出击攻击外部棋子。行营内的棋子每次只能移动一步 |
| 大本营   | 2         | 位于棋盘最底线。**军旗必须放置在其中一个大本营内**。进入任何大本营的棋子均不能再移动 |
| 山界     | 1         | 棋盘中央的分隔区域，棋子不能停留在山界上，仅可通过铁路线跨越 |

## 3. 棋子构成

每方共有 **25 枚** 棋子，按军衔与功能分类如下：

| 棋子名称 | 数量 | 军衔等级        | 特殊功能                                       |
| -------- | ---- | --------------- | ---------------------------------------------- |
| 军旗     | 1    | —               | 不可移动，被吃掉则直接判负                     |
| 司令     | 1    | 9 级（最高）    | 阵亡后己方军旗位置暴露                         |
| 军长     | 1    | 8 级            | —                                              |
| 师长     | 2    | 7 级            | —                                              |
| 旅长     | 2    | 6 级            | —                                              |
| 团长     | 2    | 5 级            | —                                              |
| 营长     | 2    | 4 级            | —                                              |
| 连长     | 3    | 3 级            | —                                              |
| 排长     | 3    | 2 级            | —                                              |
| 工兵     | 3    | 1 级（最低）    | 可排除地雷；铁路线上可转弯                     |
| 炸弹     | 2    | —               | 与任何棋子相遇同归于尽                         |
| 地雷     | 3    | —               | 不可移动；消灭除工兵外的所有来犯棋子           |

## 4. 布局规则

游戏开始前，双方需将己方棋子**秘密布置**在己方区域内。

### 4.1 通用布局限制

- **军旗**：必须放置在两个大本营中的任意一个，放置后**不可移动**。
- **地雷**：只能放置在最后两排（底线与倒数第二排）的兵站和大本营中，**不可移动**。
- **炸弹**：不能放置在第一排（最前线）。
- **行营**：布局阶段不能在任何行营摆放棋子。
- 其余棋子可自由摆放在己方区域的兵站与大本营内。

### 4.2 布局模式

| 模式       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 暗棋模式   | 棋子字面朝向自己，对方不可见，需第三方裁判或电子系统判定战斗结果 |
| 明棋模式   | 棋子正面朝上，双方棋子大小均可见                             |
| 翻棋模式   | 所有棋子背面朝上打乱，随机布满棋盘，通过翻子确定阵容         |

## 5. 行棋规则

### 5.1 基本行棋

- 双方**轮流走棋**，每回合只能移动一枚棋子。
- 棋子只能沿有连线的方向移动，**不能跨越棋盘上没有线路连接的点位**。
- 棋子不能跨越其他棋子的位置，铁路线上若有棋子阻挡，只能走到阻挡棋子前一格。

### 5.2 公路线移动

所有棋子在公路线上每回合只能**移动一格**，即从一个交点走到相邻的另一个交点。

### 5.3 铁路线移动

| 棋子类型 | 铁路行走规则                                                 |
| -------- | ------------------------------------------------------------ |
| 普通棋子 | 在铁路线上无阻挡时，可沿直线方向移动任意步数，也可沿弧形铁路线转弯，但不能转直角弯 |
| 工兵     | 在铁路线上无阻挡时，可以**任意转弯**，抵达铁路线上的任何可达位置，俗称「**工兵飞铁路**」 |
| 阻挡处理 | 铁路线上若有任何棋子（无论敌我）阻挡，移动路径在阻挡处截止   |

### 5.4 行营移动

- 行营内的棋子每次只能移动一格（无论公路或铁路）。
- 棋子可以自由进出己方或对方的行营，**进入后即获得保护**。

### 5.5 不可移动棋子

**军旗、地雷**以及进入大本营后的**所有棋子**均不能移动。

## 6. 吃子规则

### 6.1 常规战斗判定

当两枚棋子相遇发生战斗时，遵循以下规则：

- **军衔高者吃掉军衔低者**：司令 > 军长 > 师长 > 旅长 > 团长 > 营长 > 连长 > 排长 > 工兵。
- **同级相遇**：两枚军衔相同的棋子相遇，双方**同归于尽**，同时移出棋盘。

### 6.2 特殊棋子战斗规则

#### 炸弹

- 炸弹与**任何棋子**（包括对方炸弹、军旗、地雷）相遇时，双方**同归于尽**，同时移出棋盘。
- 炸弹可以主动冲击任何敌方棋子。

#### 地雷

- 地雷**不能移动**，只能被动防御。
- 除工兵外，任何棋子主动攻击地雷时，**攻击方被消灭**，地雷保留。
- 工兵攻击地雷时，地雷被消灭（**工兵排雷**），工兵保留。
- 炸弹攻击地雷时，**双方同归于尽**。

> 注：部分地区规则变体中，**任何棋子撞地雷均同归于尽**，对局前需双方约定。

#### 工兵

- 常规战斗中军衔**最低**，会被所有军官棋子吃掉。
- **唯一可以排除地雷**的常规兵种。
- 铁路线上拥有**转弯特权**，机动性最强。

## 7. 特殊规则

### 7.1 司令阵亡亮旗规则

暗棋模式下，当一方司令被消灭时（被炸弹炸掉、与对方司令同归于尽或误触地雷），该方**必须亮出自己军旗所在的大本营位置**，通常以翻明军旗或标记提示的方式呈现。

### 7.2 大本营规则

- 军旗必须置于大本营内，**不可移动**。
- 另一个大本营可放置任意棋子，棋子进入后同样不能移动。
- 敌方棋子可以进入空的大本营，但进入后也**不能再移动**。
- 大本营内的棋子**不受行营保护规则影响**，可以被攻击。

### 7.3 行营保护规则

- 行营内的棋子**绝对安全**，敌方任何棋子都不能攻击行营中的棋子。
- 行营内的棋子可以主动移动出去攻击营外棋子。
- 双方棋子均可占据对方的行营并获得保护。

## 8. 胜负判定

### 8.1 获胜条件

满足以下任一条件即获得胜利：

| 获胜方式     | 说明                                       |
| ------------ | ------------------------------------------ |
| 扛旗获胜     | 己方任意可移动棋子吃掉（占据）对方军旗     |
| 灭子获胜     | 消灭对方所有可以移动的棋子                 |
| 困毙获胜     | 对方在回合内无任何棋子可以移动（无棋可走） |

### 8.2 失败条件

- 军旗被对方吃掉。
- 所有可移动棋子被消灭。
- 轮到自己行棋时，无任何棋子可以移动。
- 超时违规（线上游戏中，累计超时达到规定次数判负）。

## 9. 和棋规则

出现以下情况可判定为和棋：

- 双方均同意求和。
- 连续 **70 回合**（不同平台略有差异）双方均没有损失任何棋子，自动判定和棋。
- 双方同时无棋可走，轮到走棋的一方判负，**非同时情况下不构成和棋**。

## 10. 主要玩法模式

### 10.1 双人对战模式

#### 暗棋（立棋）

- 最主流玩法。双方各自秘密布局，棋子互相不可见。
- 需要裁判或电子系统判定战斗结果，玩家只能通过战斗结果推断对方棋子大小。
- 包含**司令阵亡亮军旗**规则。

#### 明棋

- 双方棋子正面朝上，所有信息公开。
- 纯策略博弈，考验布阵与行棋计算。

### 10.2 四国军棋模式

四人分坐四方，相对两人为一组联盟对抗另外两人。

| 变体       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 四国暗棋（四暗） | 四家棋子均不可见，只能看见己方棋子。逆时针顺序轮流走棋。友军之间也互不可见棋子大小，完全靠配合默契 |
| 四国双明   | 友军之间可以互相看见对方棋子，敌军棋子不可见。配合度更高，战术更丰富 |
| 四国明棋   | 所有棋子全部可见，纯策略对抗                                 |

### 10.3 翻翻棋模式

- 所有棋子背面朝上打乱，随机布满整个棋盘的兵站。
- 双方轮流翻子，首先翻出的棋子颜色决定玩家阵营。
- 翻子与行子可交替进行，每回合只能选择翻一个子或走一步棋。
- 需先消灭对方**三颗地雷**后才能吃军旗；若工兵与炸弹全部阵亡且仍有地雷未除，则只能通过困毙对方获胜。
- 翻棋模式中，**大本营内的非军旗、非地雷棋子可以移动**。

## 11. 常见规则变体说明

| 变体         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 地雷规则差异 | 主流规则为地雷胜工兵外所有棋子；部分地区规则为任何棋子撞地雷均同归于尽。对局前需约定 |
| 铁路步数限制 | 部分民间规则规定非工兵棋子在铁路上最多走 3 格，但可拐弯。正式比赛与线上平台多采用**无限步数**规则 |
| 大本营可动   | 翻棋模式中大本营普通棋子可移动；暗棋/明棋模式中大本营棋子**不可移动** |
| 和棋步数     | 不同平台对无吃子和棋的步数规定不同，常见为 **50 步、60 步或 70 步** |

## 12. 游戏礼仪与注意事项

- 暗棋模式下，不得故意询问或试探对方棋子身份。
- 行棋落子无悔，棋子放下后不得更改。
- 四国军棋中，盟友间不得通过语言或手势传递棋子信息。
- 尊重裁判判定，有异议可在对局结束后提出。
