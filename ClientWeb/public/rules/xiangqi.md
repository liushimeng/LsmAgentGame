## 1. 游戏概述

中国象棋是起源于中国的**二人对弈策略棋类**，使用方形格状棋盘与圆形棋子，红黑双方各 16 枚棋子，在棋盘交叉点上交替行棋，以**将死对方将/帅**为核心获胜目标。中国象棋是国家正式体育竞赛项目，也是世界智力运动会正式比赛项目。

## 2. 棋盘与棋子

### 2.1 棋盘构造

- 棋盘由 **9 条竖直线** 与 **10 条水平线** 垂直相交构成，共形成 **90 个交叉点**，棋子摆放与移动均在交叉点上进行。
- 棋盘中部第 5 条与第 6 条横线之间为空白分界区域，称为 **楚河汉界**（简称河界），是双方阵营的分界线。
- 双方底线正中各有一个由两条斜线交叉构成的「米」字形区域，称为 **九宫**，范围为 3×3 个交叉点，是将/帅与士/仕的专属活动区域。
- 棋盘两侧第 4、6 两条竖线称为 **肋道**，是攻防要道；中间第 5 条竖线称为 **中路**。

### 2.2 棋子配置

棋子总计 **32 枚**，分为红、黑两组，每组 **16 枚**，包含 7 个兵种：

| 红方棋子 | 黑方棋子 | 每方数量 | 初始位置（己方视角从右至左） |
| -------- | -------- | -------- | ----------------------------- |
| 帅       | 将       | 1        | 底线正中第 5 路               |
| 仕       | 士       | 2        | 帅/将两侧第 4、6 路           |
| 相       | 象       | 2        | 仕/士外侧第 3、7 路           |
| 马       | 马       | 2        | 相/象外侧第 2、8 路           |
| 车       | 车       | 2        | 最两端第 1、9 路              |
| 炮       | 炮       | 2        | 己方第 2 条横线第 2、8 路     |
| 兵       | 卒       | 5        | 己方第 4 条横线第 1、3、5、7、9 路 |

## 3. 行棋基本规则

- **先后手**：对局开始由**红方先行**，之后黑方走一步、红方走一步，双方交替行棋，直至对局结束。
- **一着定义**：将己方一枚棋子从一个交叉点移动到另一个交叉点，**无论是否吃子**，均算作一着。双方各走一着，称为一个**回合**。
- **落子规则**：棋子落下并松手后，**不得再更改位置或挪动其他棋子**。
- **摸子规则**：
  - 触摸己方棋子则必须走该棋子；
  - 触摸对方棋子则必须吃掉该棋子，除非该棋子完全无法走动或无法被吃。
- **摆正棋子**：如需调整棋子位置，须提前向对方声明「摆正」，否则按摸子论处。

## 4. 各棋子走法详解

### 4.1 帅 / 将

- **活动范围**：仅限己方九宫之内，不得走出九宫。
- **行棋方式**：每着只能沿直线（上下左右）走一格，可进可退可平移。
- **特殊限制**：**红帅与黑将不得在同一条竖直线上无遮挡直接相对**，俗称「将帅不能对面」，主动造成该局面的一方判负。

### 4.2 仕 / 士

- **活动范围**：仅限己方九宫之内。
- **行棋方式**：每着沿九宫格内的斜线走一格，可进可退。
- 仕/士始终只能在九宫的 **5 个固定交叉点** 上活动。

### 4.3 相 / 象

- **活动范围**：不得越过河界，仅能在己方阵营内活动。
- **行棋方式**：每着沿对角线斜走两格，俗称「**象走田**」。
- **塞象眼**：若「田」字中心交叉点有任意一方棋子占据，则相/象无法向该方向移动。

### 4.4 马

- **行棋方式**：每着走一直一横一斜，即先沿直线或横线走一格，再斜走一格，整体走成「日」字形，俗称「**马走日**」。
- **蹩马腿**：若马行进方向的第一步格点上有任意一方棋子阻挡，则马无法向该方向跳跃。
- 马在棋盘开阔位置最多可向 **8 个方向** 移动。

### 4.5 车

- **行棋方式**：可沿竖线或横线任意方向行走，**步数不限**，不得斜走。
- 只要前方无棋子阻挡，车可一步到达同一直线上任意空位，是棋盘上威力最强的棋子。

### 4.6 炮

- **普通移动**（不吃子）：走法与车完全一致，沿直线横线任意行走，步数不限。
- **吃子移动**：必须跳过**恰好一枚棋子**（己方或对方棋子均可）作为「炮架」，才能吃掉对方棋子，俗称「**炮打隔子**」。

### 4.7 兵 / 卒

- **未过河**：每着只能**向前直走一格**，不得后退，也不得横向移动。
- **过河之后**：越过河界后，每着可**向前走一格**，也可**向左或向右横走一格**，但始终不得后退。

## 5. 吃子规则

- **普通吃子**：己方棋子移动到对方棋子所在的交叉点时，即可将对方棋子移出棋盘，由己方棋子占据该位置，算作一着。
- **炮的吃子**：炮必须隔着一枚棋子（炮架）才能吃掉对方棋子，**无法直接贴近吃子**。
- **吃子优先级**：除将帅特殊规则外，所有棋子均可互相吃子，**无棋子大小等级之分**。
- **禁着限制**：走子后导致己方将帅处于被攻击状态（送将/自将），属于**非法着法**，禁止走出。

## 6. 将军与应将

### 6.1 将军

当一方棋子攻击对方将帅，且下一着可以吃掉对方将帅时，称为**将军**（简称「将」）。将军无需口头声明，被将军方**必须**应将。

### 6.2 应将方式

被将军的一方必须立即化解将军状态，共有三种合法应将手段：

| 方式 | 操作                          |
| ---- | ----------------------------- |
| 避将 | 将己方将帅移动到不受攻击的安全位置 |
| 垫将 | 用己方棋子移动到将帅与攻击棋子之间，阻挡攻击线路 |
| 消将 | 用己方棋子吃掉对方发动将军的棋子 |

### 6.3 将死

被将军后，己方**无法通过上述三种方式化解**将军状态，即为**将死**，对局结束，被将死一方判负。

## 7. 胜负判定规则

出现以下任意一种情况，对局结束，一方获胜：

| 胜负条件     | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 将死对方     | 对方将帅被将军且无法应将                                     |
| 困毙对方     | 轮到对方行棋时，其将帅虽未被将军，但所有棋子均无合法着法可走 |
| 对方认输     | 一方主动口头或书面承认失败                                   |
| 对方超时     | 比赛规定用时耗尽，超时方判负                                 |
| 对方违规判负 | 严重违反竞赛规则（如走出禁着且拒不变着、三次犯规、将帅主动对面等） |
| 对方缺席     | 比赛开始后规定时间内未到场                                   |

## 8. 和棋判定规则

出现以下任意一种情况，对局判为和棋：

| 和棋类型       | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| 理论和棋       | 双方剩余子力均不具备将死对方的能力（如双方只剩将帅、一方帅加单士/单相等） |
| 协议和棋       | 一方提出和棋提议，另一方明确表示同意                         |
| 不变作和       | 棋局出现循环反复局面，双方均为允许着法，且都不愿变着，可判和棋 |
| 六十回合规则   | 连续 60 个回合内，双方均未吃掉任何棋子，也未移动兵/卒，一方提出后可判和 |
| 自然限着       | 正式比赛中，符合规定回合数内无吃子、无兵卒移动，裁判可直接判和 |

## 9. 禁止着法与允许着法

### 9.1 禁止着法（单方长走必须变着，不变判负）

| 名称     | 说明                                       |
| -------- | ------------------------------------------ |
| 长将     | 单方面持续重复将军                         |
| 长杀     | 单方面持续威胁下一步将死对方               |
| 长捉     | 单方面持续追捉对方无保护的棋子             |
| 一将一杀 | 一步将军、一步叫杀循环往复                 |
| 一将一捉 | 一步将军、一步捉子循环往复                 |
| 一将一抽 | 一步将军、一步准备抽吃对方棋子循环往复     |

### 9.2 允许着法（循环往复不变可判和）

| 名称         | 说明                                                     |
| ------------ | -------------------------------------------------------- |
| 长兑         | 持续邀兑对方价值相当的棋子                               |
| 长献         | 持续主动送子给对方吃                                     |
| 长拦         | 持续阻挡对方棋子行进路线，不构成捉子                     |
| 长跟         | 持续跟随对方棋子，不构成攻击或捉子                       |
| 将帅长捉     | 将帅本身可以持续捉对方棋子                               |
| 兵卒长捉     | 过河兵卒可以持续捉对方棋子（不含将帅）                   |

## 10. 竞赛行棋规范

- **计时规则**：正式比赛采用限时制，常见赛制为每方基本用时 60 分钟、45 分钟或 30 分钟，走棋后按动棋钟切换对方计时，超时判负。
- **记录规则**：正式比赛中双方须完整记录每一步棋谱，漏记需在自己用时内补全。
- **犯规判定**：摸子不走、落子悔棋、摆正棋子不声明、干扰对方等行为计一次犯规，三次犯规判负。
- **行棋礼仪**：对局前双方握手致意；对局中不得随意离席、交谈；对局结束后双方共同复盘、整理棋子。

## 11. 棋谱记录方法

### 11.1 坐标体系

- **红方**：使用汉字数字一至九，从己方视角从右到左标记 9 条竖线。
- **黑方**：使用阿拉伯数字 1 至 9，从己方视角从右到左标记 9 条竖线。

### 11.2 动作术语

- **进**：棋子向对方阵营方向纵向移动。
- **退**：棋子向己方阵营方向纵向移动。
- **平**：棋子沿横线横向移动。

### 11.3 记录格式

**棋子名称 + 原位置路数 + 动作 + 目标位置路数**

| 棋谱        | 含义                                   |
| ----------- | -------------------------------------- |
| 炮二平五    | 红方二路炮横向移动到五路               |
| 马 8 进 7   | 黑方 8 路马向前跳跃到 7 路             |
| 车九进一    | 红方九路车向前走一格                   |
| 象 3 退 5   | 黑方 3 路象向后退回到 5 路             |

## 12. 常用术语释义

| 术语       | 释义                                                       |
| ---------- | ---------------------------------------------------------- |
| 先手       | 开局先走的一方，也指局面中占据主动、掌控节奏的一方         |
| 后手       | 后走的一方，也指局面中处于防守、被动的一方                 |
| 开局       | 对局前 10-15 回合，双方部署子力、展开阵型的阶段             |
| 中局       | 开局结束后至残局前的阶段，是子力交锋最激烈的阶段           |
| 残局       | 双方子力大量消耗后，接近对局终局的阶段                     |
| 有根       | 棋子有己方其他棋子保护，被吃后可以反吃回来                 |
| 无根       | 棋子无己方棋子保护，被吃后无法立即反击                     |
| 兑子       | 双方互相交换价值相近的棋子                                 |
| 弃子       | 主动舍弃己方棋子，以换取攻势、位置或局面优势               |
| 卧槽马     | 马跳到对方九宫侧下方位置将军，是经典杀法                   |
| 挂角马     | 马跳到对方九宫上角位置将军                                 |
| 马后炮     | 马在前将军、炮在后叠加攻击，形成无解杀局                   |
| 重炮       | 两枚炮在同一直线上叠加攻击，前方炮充当后方炮的炮架         |
| 铁门栓     | 用车在中路或肋道锁住对方将帅，配合炮或兵形成杀局           |
| 空头炮     | 炮在中路直接对准对方将帅，中间无棋子遮挡                   |
| 海底捞月   | 残局阶段用车炮从底线攻击对方将帅的经典杀法                 |
| 担子炮     | 两枚炮互相作为炮架，形成稳固的防守阵型                     |
| 连环马     | 两马互相保护、互为根的防守阵型                             |
| 对面笑     | 利用将帅不能直接对面的规则，用车或其他子力逼对方将帅无法躲避而取胜 |
