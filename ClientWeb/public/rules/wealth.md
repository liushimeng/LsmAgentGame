# 虚拟城市规则

> 虚拟城市是一款 **实时月度节拍的人生财商沙盘**：25 岁入场，60 岁结算。3–8 名玩家（人类 + AI Agent 混编）共享同一条时间轴，在 35 年 = 420 个游戏月里打工、投资、加杠杆、过日子，追求「财务自由 + 人生幸福 + 社会贡献」三重最高分。平台实现以服务端权威为准，引擎位于 `ServerGo/game/wealth/`，前端 UI 位于 `ClientWeb/src/components/wealth/`。

## 1. 游戏形态与节奏

- **不是回合制**：全房间共享一条时间轴。每个月份分两段：
  - **行动窗口（acting）**：默认 8 秒（建房可选 3–30 秒）。人类随时提交动作（每月限 3 次），AI Agent 由大模型决策（同样 ≤3 动作 + ≤1 次发言），全员点「结束本月」可提前进入结算。
  - **月结（settling）**：服务端结算 <500ms，随后广播新月快照。
- **时间轴**：开局 25 岁（统一主时钟）；12 个月 = 1 年；每 5 年（60 个月）= 一次「钟声」（人生事件 + 市场周期重掷）；**60 岁强制终局**。
- **单局时长**：420 月 × 8s ≈ 56 分钟（加月结开销约 60–70 分钟）。
- **开局条件**：满 8 座自动开局；已占座 ≥3 时房主可「提前开始」。
- **中途加入**：允许，新座位从下月开始参与结算。

## 2. 五维资源与核心公式

| 资源 | 范围 | 说明 |
|------|------|------|
| 现金 C | 可短暂透支为负 | **连续 3 个月 < 0 触发破产清算** |
| 年龄 T | 25–60 | 主时钟，60 岁终局 |
| 精力 E | 0–10（透支到 -3 触发健康危机） | 加班 / 副业 / 迁区都会消耗 |
| 人脉 N | 0–10 | 社交、捐赠可提升 |
| 认知 K | 0–10 | 学习可提升；解锁高阶副业 |

**核心公式**：

```
FI Index = 月被动收入 ÷ 月总支出   （支出为 0 时记 2.0 封顶）
终局总分 = 财务自由度 50% + 人生满意度 30% + 社会贡献 20%
```

三张报表（损益 / 资产负债 / 现金流）由服务端「双式流水账（Ledger）」推导，前端财务面板实时展示。

## 3. 城市地图与八大城区

世界 = 一座 40×40 的城市，8 个城区各有基准房价与 β（波动放大系数）：

| 城区 | 基准房价 | β | 特点 |
|------|---------|-----|------|
| 金融CBD | 800 万 | 1.30 | 最贵、波动最大 |
| 科技园 | 500 万 | 1.15 | 程序员聚集 |
| 工业区 | 200 万 | 0.85 | 便宜 |
| 老城区 | 180 万 | 0.80 | 最便宜、稳定 |
| 商业中心 | 400 万 | 1.10 | 骑手 / 销售 |
| 居住区 | 300 万 | 1.00 | 教师 / 医生 |
| 郊区 | 120 万 | 0.70 | 低 β 避险 |
| 滨河新区 | 450 万 | 1.25 | 高成长新区 |

- 房价公式：`当前房价 = 基准价 × β × 房价指数`（指数初始 1.0，随周期漂移）。
- 住宅月租 ≈ 房价 × 0.16%；商铺月租 ≈ 房价 × 0.35%。
- 地图上**楼群高度随房价指数变化**：繁荣期楼变高、萧条期变矮 —— 周期可视化。
- 「迁区」搬家费 3000 元 + 精力 1；若目标区有自住房自动转为自住。

## 4. 市场周期与四阶段

| 阶段 | LPR | CPI | 股票年化 | 房产年化 | 黄金年化 | 就业基线 |
|------|-----|-----|---------|---------|---------|---------|
| 复苏期 | 3.5% | 2% | +15% | +5% | -5% | 95% |
| 繁荣期 | 4.5% | 3.5% | +30% | +15% | -10% | 95% |
| 衰退期 | 5.8% | 2% | -25% | -5% | +10% | 80% |
| 萧条期 | 2.8% | 0% | -40% | -15% | +25% | 65% |

- 每阶段持续 24–48 个月，到期按转移矩阵重掷；**每 60 个月钟声额外强制重掷一次**。
- 每月还有小幅随机漂移（各区按 β 加权）。
- 顶部周期徽章四色实时提示当前阶段；切换时全屏公告。

## 5. 投资品与贷款

**投资品**（按市价整份成交）：

| 品种 | 初始价 | 费用 |
|------|--------|------|
| 指数基金 | 3.50 元/份 | 佣金 0.025%（min 5 元） |
| 债券 | 锁定当期票面利率（约 2.7%–4.2%） | 无 |
| 黄金 | 750 元/克 | 卖出费 0.5% |
| 住宅 / 商铺 | 按各区房价 | 卖出增值税 5% + 中介 2%（满 5 年唯一免） |
| 副业 | — | 月入 2000–6000 元，月耗精力 2 |

**贷款**：

| 种类 | 额度 | 利率 | 门槛 |
|------|------|------|------|
| 房贷（买房自动生成） | 房价 ×（1−首付） | LPR + 0.5% + 信用上浮，30 年等额本息 | 首付 ≥30%，信用分 ≥600 |
| 消费贷 | ≤ min(月收入×12, 20 万) | 10% 年化，3 年 | — |
| 信用贷 | 5 万 / 10 万 / 20 万 三档 | 高息 + **Brass 档副作用**（压低未来工资增长与副业收入） | 信用分门槛 |
| 经营贷 | ≤ 20 万 | — | 需运行中副业 |

- 还款：提前还本 ≥1 万或结清；先扣当期利息再还本。
- **持有上限**：住宅 4 套 / 商铺 4 间。

## 6. 17 个动作与费用

每月最多执行 **3 个动作**（`submit_month` 不耗预算）。人类按钮与 AI Agent 工具走同一套引擎校验，完全公平：

| 动作 | 参数 | 费用 / 效果 |
|------|------|------------|
| 买资产 `buy_asset` | 资产 + 金额（≥1000） | 按市价买入 |
| 卖资产 `sell_asset` | 资产 + 份额 | 按市价卖出（房产整售） |
| 买房 `buy_house` | 城区 + 首付比例（0.3–1.0） | 首付现金 + 30 年房贷 |
| 贷款 `take_loan` | 种类 + 金额 | 款项入现金 |
| 还款 `repay_loan` | 贷款 id + 金额（≥1 万） | 减少本金、重算月供 |
| 开副业 `start_side_business` | 配送 / 内容 / 家教 / 自由职业 | 月入 2000–6000；认知门槛 0/2/4/3 |
| 停副业 `stop_side_business` | — | 停止，无残值 |
| 学习 `study` | — | 2000 元 / 精力-1 / **认知+1** |
| 社交 `socialize` | — | 1000 元 / **人脉+1** |
| 休息 `rest` | — | **精力+2** |
| 加班 `work_overtime` | — | 精力-2 / 当月工资 ×0.3 奖金 |
| 迁区 `move_district` | 目标城区 | 3000 元 / 精力-1 |
| 消费 `consume` | 金额 + 备注 | 纯记事，无机制效果 |
| 捐赠 `donate` | 金额（≥1000） | 每万元 1 社会贡献分；人脉+1（累计前 3 次） |
| 发言 `speak` | 文本（≤100 字） | 仅 AI Agent；人类走聊天面板 |
| 查状态 `check_state` | — | 仅 AI Agent |
| 结束本月 `submit_month` | — | 标记完成；全员提交提前月结 |

## 7. 月度结算顺序

每月结算严格按以下顺序入账（双式流水）：

```
工资（+配偶收入+副业） → 被动收入（房租/债息/养老金入账）
→ 固定支出 → 税 + 社保 → 生活支出 → 债务月供
→ 市场波动 → 人生事件 → 失业判定
```

结算后广播全座位月度汇总（现金变动 / 净资产 / FI / 备注）与新月快照。

## 8. 税 / 社保 / 养老金

- **个税**：7 级累进，起征点 5000 元/月。
- **社保**：工资的 10.5%，其中 8% 进入个人养老金账户（**60 岁才能领**）。
- 养老金账户余额在财务面板可见，是终局被动收入的重要组成。

## 9. 破产与出局

1. **现金连续 3 个月 < 0** → 全屏公告「⚖️ X 号位触发破产清算」。
2. 清算：流动资产按市价、房产按 70% 强制变现 → 消费贷本金减 50% 分 36 期免息 → 信用分清零 → 停赛 3 个月（token 灰色 + ⛔）。
3. 重组后月现金流仍为负 → **出局**（token 移出地图，`alive=false`）。
4. 进行中离席的人类座位由 AI 托管接管（无可用模型则座位冻结，可回来夺回）。

## 10. 终局评分与六种结局

60 岁全房停止，按三维度打分：

```
总分（0–100） = 财务自由度（FI 相关）×50% + 人生满意度（家庭/健康/精力）×30% + 社会贡献（捐赠）×20%
```

| 总分 | 结局 |
|------|------|
| ≥85 | 🏆 财务自由 · 人生赢家 |
| 70–84 | 🥈 富足安稳 · 中产典范 |
| 50–69 | 🌤 平淡度日 · 普通一生 |
| 30–49 | 😰 债务缠身 · 挣扎求生 |
| <30 | ⚖️ 破产出局 |
| 特殊 | FI ≥ 1.5 且人生满意度 < 40 → 💰 孤独富翁 |

终局弹窗展示：三维评分条 + 净资产曲线（25→60 岁）+ 人生报告 + 全场结算榜。房间停留 60 秒后自动解散。

## 11. 人生事件

不可控事件随机发生（事件流 + 座位 token 闪烁提示）：

- 💒 结婚（配偶收入入账）、🍼 生育（支出增加）
- 🏥 住院 / 疾病（医疗支出 + 精力损失）
- 📉 失业（按周期就业基线判定：复苏/繁荣 95% 就业，衰退 80%，萧条 65%）
- 🔔 每 5 年钟声：大概率触发大事件 + 市场周期重掷

**应急建议**：始终保留 3–6 个月支出的现金缓冲。

## 12. 观战与断线

- 任何登录用户可 `/wealth/spectate/:roomId` 观战：**不消耗座位**，可见全部公开数据与 Agent 思维，动作帧被服务端硬拒（错误码 30011）。
- 公开信息博弈：所有玩家的净资产 / 收入档 / 资源 / 位置 / 职业全公开；私有信息仅本人 `my.*`（持仓 / 贷款 / 现金 / 信用分）。
- 断线 / 刷新：自动重连并重放全量快照（8 秒兜底轮询）。
- 房主可暂停 / 恢复（月结完成后生效）。
