## 1. 游戏概述

德州扑克（Texas Hold'em）是世界上最流行的**公共牌扑克游戏**。每名玩家持有**两张底牌**，与桌面上的**五张公共牌**组合，选出五张组成最大牌型参与比牌。游戏通过多轮下注，以**赢取其他玩家的筹码**为目标。

## 2. 基本用具

- **扑克牌**：标准 52 张牌，**无大小王**。
- **筹码**：代表游戏中的资金，不同颜色对应不同面值。
- **庄家按钮（Dealer Button）**：标记本局庄家位置，每局顺时针移动。
- **牌桌**：通常可容纳 2-10 名玩家。

## 3. 牌型大小

### 3.1 牌型排序（从大到小）

| 牌型         | 说明                       | 示例                          |
| ------------ | -------------------------- | ----------------------------- |
| 皇家同花顺   | 同花色的 10、J、Q、K、A    | ♠10 ♠J ♠Q ♠K ♠A              |
| 同花顺       | 五张同花色且点数连续的牌   | ♥5 ♥6 ♥7 ♥8 ♥9               |
| 四条         | 四张点数相同的牌           | ♠K ♥K ♦K ♣K ♠9                |
| 葫芦（满堂红） | 三张同点数 + 一对         | ♠Q ♥Q ♦Q ♣7 ♥7                |
| 同花         | 五张同花色但点数不连续     | ♠2 ♠5 ♠7 ♠J ♠K                |
| 顺子         | 五张点数连续但花色不同     | ♠4 ♥5 ♦6 ♣7 ♠8                |
| 三条         | 三张点数相同的牌           | ♠10 ♥10 ♦10 ♣K ♠5             |
| 两对         | 两组对子 + 一张单牌        | ♠A ♥A ♦9 ♣9 ♠K                |
| 一对         | 两张点数相同的牌           | ♠J ♥J ♦K ♣7 ♠3                |
| 高牌         | 以上都不满足，按最大单牌比大小 | ♠A ♥K ♦9 ♣5 ♠2            |

### 3.2 牌型补充说明

- A 可作为最大牌（`10-J-Q-K-A`），也可作为最小牌（`A-2-3-4-5`），**但不能同时作为首尾**（`Q-K-A-2-3` 不算顺子）。
- 同花大顺（皇家同花顺）是同花顺的特例，为**最大牌型**。
- 牌型相同时，按点数大小比较；点数完全相同时**平分底池**。

## 4. 游戏位置

玩家按顺时针围坐，位置名称如下（以庄家按钮为基准）：

| 位置             | 缩写 | 说明                                               |
| ---------------- | ---- | -------------------------------------------------- |
| 庄家             | BTN  | 最后行动，位置最有利                               |
| 小盲注           | SB   | 庄家左侧第一位，强制下小盲                         |
| 大盲注           | BB   | 小盲左侧，强制下大盲（通常为小盲两倍）             |
| 枪口位           | UTG  | 大盲左侧，翻牌前第一个行动                         |
| 中间位置         | MP   | 枪口位与庄家之间的位置                             |
| Cutoff（CO）     | CO   | 庄家右侧第一位                                     |

## 5. 完整游戏流程

### 第 1 步：强制盲注

- 每局开始前，**小盲位** 和 **大盲位** 玩家必须强制下注。
- 小盲注 = 大盲注的一半（如 `$1/$2` 级别，小盲 `$1`，大盲 `$2`）。
- 盲注是底池的初始资金，不参与行动选择。

### 第 2 步：发底牌

- 荷官从庄家左侧开始，**顺时针**给每位玩家发两张面朝下的牌，即**底牌（Hole Cards）**。
- 底牌只有玩家自己可见，全程不公开。

### 第 3 轮：翻牌前下注（Pre-flop）

- **行动顺序**：从大盲左侧第一位（枪口位）开始，顺时针依次行动。
- **行动选项**：

| 选项     | 说明                                                |
| -------- | --------------------------------------------------- |
| 弃牌（Fold）  | 放弃手牌，不参与后续底池争夺                        |
| 跟注（Call）  | 投入与当前最大下注额相等的筹码                      |
| 加注（Raise） | 增加下注额，加注额至少等于上一次加注的额度          |
| 全押（All-in）| 将所有筹码一次性全部投入                            |

- 当所有玩家下注额相等或全部弃牌时，本轮结束。

### 第 4 步：翻牌（Flop）

- 荷官先烧掉一张牌（**Burn Card**），然后发出**三张公共牌**面朝上放在桌面中央。
- 公共牌**所有玩家共享**。

### 第 5 轮：翻牌后下注

- **行动顺序**：从小盲位开始，顺时针依次行动。
- **行动选项**：

| 选项     | 说明                                                |
| -------- | --------------------------------------------------- |
| 过牌（Check） | 不下注，将行动权传给下一位玩家（**仅当前无下注时可选**） |
| 下注（Bet）   | 率先投入筹码，开启本轮下注                          |
| 跟注（Call）  | 跟上已有的下注额                                    |
| 加注（Raise） | 提高下注额                                          |
| 弃牌（Fold）  | 放弃手牌                                            |

- 所有玩家行动一致后，本轮结束。

### 第 6 步：转牌（Turn）

荷官再烧掉一张牌，发出**第四张**公共牌。

### 第 7 轮：转牌后下注

行动顺序与规则同翻牌后下注。

### 第 8 步：河牌（River）

荷官再烧掉一张牌，发出**第五张**也是**最后一张**公共牌。

### 第 9 轮：河牌后下注

行动顺序与规则同翻牌后下注。

### 第 10 步：摊牌与胜负判定

- 若最后一轮下注后仍有两名及以上玩家未弃牌，则进入**摊牌**阶段。
- **摊牌顺序**：最后一轮下注中**最后一个下注或加注**的玩家先亮牌；若本轮无人下注，则从小盲位开始顺时针亮牌。
- **组牌规则**：每名玩家从自己的 **2 张底牌 + 5 张公共牌共 7 张牌**中，选出**最佳的 5 张**组合成牌型。
- **比牌规则**：牌型最大者赢得底池；牌型完全相同时平分底池。

## 6. 下注规则详解

### 6.1 加注规则

- **最小加注额**：加注额至少等于上一次加注的额度。
  - 例：大盲 `$2`，首次加注至少加到 `$4`（加注额 `$2`），下次加注至少加到 `$6`（再加注额 `$2`）。
- **不足加注**：若玩家全押但筹码不足以构成完整加注，**视为跟注 + 额外筹码，不重新开启下注轮**。

### 6.2 全押与边池规则

- 当玩家筹码少于当前下注额时，可选择全押（All-in）。
- 全押玩家仅对自己投入的筹码部分享有分配权，超出部分形成**边池**。
- **边池分配原则**：

| 概念     | 规则                                                         |
| -------- | ------------------------------------------------------------ |
| 主池     | 所有玩家都参与的底池部分                                     |
| 边池     | 筹码更多的玩家之间额外形成的底池                             |
| 比牌顺序 | 先比主池，再依次比各边池                                     |
| 参与限制 | 全押玩家**只能赢取自己参与的底池部分**                       |

### 6.3 下注限额类型

| 类型         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 无限注（No Limit）  | 下注额无上限，可随时全押                                     |
| 有限注（Limit）     | 每轮下注和加注有固定额度，翻牌前/翻牌轮为小注额，转牌/河牌轮为大注额（通常等于大盲的两倍） |
| 底池限注（Pot Limit）| 最大下注额等于当前底池总额                                  |

## 7. 特殊规则

### 7.1 烧牌规则

- 每轮发公共牌前**必须烧掉一张牌**，防止作弊。
- 烧掉的牌不参与游戏，正面朝下弃置。

### 7.2 平分底池（Split Pot）

- 当两名或多名玩家牌型完全相同时，**底池平均分配**。
- 若底池无法均分，多余的筹码归位置靠前的玩家（或庄家最近的玩家，依规则而定）。

### 7.3 死牌规则

- 玩家主动弃牌后，手牌即作废，**不得再参与游戏**。
- 若荷官发牌错误，按具体规则判定是否重发。

### 7.4 短筹码规则

玩家筹码不足大盲注时，仍可入座参与，全押后按边池规则处理。

### 7.5 按钮移动

- 每局结束后，**庄家按钮顺时针移动一位**。
- 新的小盲和大盲由新位置的玩家担任。

## 8. 玩家行为规范

- 按顺序行动，不得抢注或拖延。
- 不得向其他玩家展示底牌或暗示牌力。
- 下注时应**一次性推出筹码**，避免分次下注（串注）。
- 弃牌应将牌面朝下推向荷官。
- 禁止与其他玩家串通作弊。

## 9. 常见变体

| 变体           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| 奥马哈扑克（Omaha） | 每名玩家发**四张底牌**，必须使用其中**两张 + 三张公共牌**组成牌型 |
| 短牌德州（Short Deck） | 使用 **36 张牌**（去掉 2-5），牌型排序有变化（**同花大于葫芦**） |
| 无限注单挑（Heads Up） | 仅两名玩家对战，庄家同时担任小盲，大盲位先行动             |
