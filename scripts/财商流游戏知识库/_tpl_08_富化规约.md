# 财商流游戏 · 人物卡富化规约（richness: skeleton → rich）

> 本规约定义「黄金样本」批次的富化作业标准。
> 对象：经机械映射生成的 `richness: skeleton` 人物卡。
> 目标：在**不违背任何既有 `explicit` 字段**的前提下，补齐叙事性内容。

---

## 1. 什么可以改，什么不能改

### ✅ 允许修改

| 位置 | 动作 |
|---|---|
| frontmatter `richness` | `skeleton` → `rich` |
| frontmatter `psych.personality` 等**已登记字段** | 填入内容（见 §3） |
| frontmatter `emotion_satisfaction` | 若已存在则填；不存在则不新增 |
| `## 6. 情感与人格` 正文 | 把 `【待富化】` 替换为正文 |
| `## 8. 开局钩子` 正文 | 把 `【待富化】` 替换为**一个具体开局事件** |
| `## 7. 人生目标与机会` | 在原模板目标下**追加** 1–2 条与该人物职业/处境强相关的具体目标 |
| 新增 `_rich` 元数据块 | 见 §4 |

### ❌ 严禁修改

1. **任何 `explicit` 字段** —— `name` `age` `gender` `income_monthly`
   `health_conditions` `occupation` `marital` `children_count` `city`
   `housing_detail` `stress_sources` `_legacy_ids` `_raw` 等。
2. **`id`、文件名、所在目录** —— 富化只改文件内容，**不移动、不重命名**。
3. **正文 9 个小节的标题与顺序**。
4. **与既有数据矛盾的表述** —— 见 §2 一致性硬约束。

---

## 2. 一致性硬约束（违反即整卡作废）

富化内容必须与以下字段**逐项自洽**：

| 约束 | 说明 |
|---|---|
| 城市 | 提到的地名必须与 `housing_city` 同级或更小（不得写人物在北京而 `housing_city` 是成都） |
| 年龄 | 出生年份、工作年限、子女年龄、父母年龄必须与 `age` / `birth_year` 自洽 |
| 收入 | 提到的金额量级必须与 `income_monthly` 同档；**不得**声称远高于或远低于该收入的生活方式 |
| 健康 | 不得声称患有与 `health_conditions` 冲突的疾病；可补充同向的亚健康描述 |
| 家庭 | 提及的家人数量必须与 `children_count` / `elders_dependent` / `marital` 一致 |
| 职业 | 不得改行；不得声称拥有 `certs` 之外的执业资格 |
| 负债 | 不得虚构房贷以外的大额负债（`mortgage_left` / `debts` 已载明） |
| 教育 | 不得声称高于 `education` 的学历 |

> **判据**：读者拿本卡与 `## 9. 数据溯源` 的 `_raw` 原档行对照，**不应发现任何矛盾**。

## 3. 富化内容规格

### 3.1 `## 6. 情感与人格`（必填）

替换为 **2 段**：

```
- **人格特征**：大五人格 O:<0-100> C:<0-100> E:<0-100> A:<0-100> N:<0-100>
  —— <一句话概括，20–40 字>
- **风险偏好**：<保守 / 中低 / 中性 / 中高 / 激进>（<依据：与该人物收入结构、健康档、家庭负担的关系>）
- **时间偏好**：<现期偏向 / 中性 / 远期偏向>（<依据>）
- **金钱脚本**：<一句话 —— 这个人与钱的关系是什么>
- **情感张力**：<一到两句，与 `emotion_status`、`household_type` 自洽>
```

大五人格五个分值必须**互补自洽**：高 C（尽责）与低收入月光并存时要给出解释；
高 N（神经质）应与 `stress_level: 高` 或 `stress_sources` 条数多相呼应。

### 3.2 `## 8. 开局钩子`（必填）

**一个**具体场景，150–350 字，格式：

```
**「<场景首句，引号包住，含时间与地点>」**
<3–5 句展开：触发事件 → 该人物的两难 → 一个必须在本回合内做出的财务决定>
```

要求：
- 必须包含**一个数字**（金额、期限或比例），且该数字与该人物财务快照自洽；
- 必须体现 `psych.biases` 中的**至少一个**行为金融偏差如何影响其判断；
- 必须是《财商流游戏》可落地的**回合内事件**（不是人生总结）。

### 3.3 `## 7. 人生目标与机会`（追加）

保留原有模板目标，**追加** 1–2 条带金额/期限的具体目标：

```
- **<期限>**：<具体目标>（约 <金额> 元，<资金来源设想>）
```

## 6. 诚实性要求

富化内容是**生成的叙事**，不是调研事实。因此：

- `_rich.basis` 必须列明所依据的真实字段；
- 正文中不得出现「据调研」「数据显示」等**伪引用**；
- 数字可以合理构建，但必须**与既有数据同档**，不得凭空放大或缩小人生处境。
