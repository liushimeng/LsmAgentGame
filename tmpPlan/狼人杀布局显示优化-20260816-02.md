## 1. 现状问题清单（基于截图实测）

通过 1920×1080 视口截图,狼人杀 13 人局主界面实测出 7 类布局缺陷：

### 1.1 中栏底部「折叠态面板」仍占据过多垂直空间
- **症状**：截图显示 `私下通道` 与 `阵营赌注` 折叠后,两个面板 header 行依然占用 **约 90~110px**(×2 ≈ 180~220px)
- **根因**：panel header `padding: 12px + gap: 12px`(werewolf-20260812-03.css:8-12),折叠时把整个 panel 容器一起撑高,没有专门的「collapsed compact header」样式
- **影响**：13 人局座位卡 4 行 × 3 列 ≈ 占用 940~960px 高度,中栏总高度 ≈ 1100px,**屏幕底部内容溢出可见,必须滚动才能看到两个 panel**

### 1.2 顶部三色 chip 信息冗余
- **症状**：截图顶部 chip 行 `⏰ 剩余 610s` `👤 真人混合房间` `Xiaomi-model fallback_initial` 三色 chip 横排,即使在 ≤1280 视口下也会挤兑 6 个 token / 调用 chip
- **根因**：`GameStatusHeader` 把「游戏状态」「AI 模型」「调用统计」三组语义完全不同的信息全部用同样的 chip 样式拼成一行,视觉权重失衡
- **影响**：用户难以一眼区分"这是游戏规则信息"vs"这是统计信息"

### 1.3 中栏座位卡 3 列布局在宽屏浪费水平空间
- **症状**：截图 1920px 视口下中栏座位卡为 3 列(13÷3 ≈ 4~5 行),**每张卡宽度 ≈ 360px,但内部有大量留白**
- **根因**：`calcColsForViewport`(WerewolfTable.tsx:168)只在 `>1100px` 落 4 列,但截图实际中栏 container 宽约 1020px(< 1100px 阈值),所以走 3 列
- **影响**：3 列下每张卡内部信息密度可压缩,卡片高度 ≈ 280px,4 行就吃掉 1120px,留给下方 panel 的空间极少

### 1.4 左侧房间信息面板内容密度低
- **症状**：截图左栏 `房间信息` 面板上半部分 `首夜强制发言阶段` + `阵营` + `状态` 三块之间有大量留白(`gap: 16px`),每个块本身高度紧凑但块间距过大
- **根因**：`GameInfoPanel` 内 section 之间 `margin-bottom: 16px`,无紧凑化
- **影响**：13 人局 4 行座位 + 中栏 panel 占满屏后,左栏空白更加刺眼

### 1.5 右侧聊天面板「没有更早的消息了」占独立行
- **症状**：截图右栏 `房间聊天` 顶部有一条「没有更早的消息了」**单独成行**(24px 高),信息量少却占据独立行
- **根因**：chat 空状态渲染独立区块(`.chat-empty`)
- **影响**：聊天面板顶部视觉割裂

### 1.6 座位卡内「响应中 22 秒…」徽章跨列溢出
- **症状**：截图第 2 号座位卡的 `🌊 深度响应中 22 秒…` 徽章因内容过长,文字溢出 card 边界,触发横向滚动
- **根因**：BotPhaseIndicator 默认 badge 文本不截断,deep thinking / streaming 状态文案过长
- **影响**：破坏座位卡网格对齐,相邻卡视觉错位

### 1.7 13 人局第 8~10 号座位卡在折叠态下完全隐藏
- **症状**：截图视口(1080p)只能看到第 2~7 + 第 8~10 部分座位,**第 11~13 完全在 fold 下方**
- **根因**：座位卡 grid + 中栏两个 panel 叠加后高度超过视口,无折叠 / 滚动优化
- **影响**：用户必须手动滚动才能看到完整座位分布

## 2. 设计目标

| # | 目标 | 量化指标 |
|---|---|---|
| G1 | 中栏 1920 视口下座位卡 1 屏可见 | 13 张座位卡 全部进入 1080p 视口(滚动 ≤ 1 次) |
| G2 | 折叠态 panel 高度 ≤ 64px(2 个合计 ≤ 128px) | 比当前节省 ≥ 100px |
| G3 | 顶部 chip 信息分层清晰 | 「游戏状态」与「调用统计」分组独立区域 |
| G4 | 座位卡无横向溢出 | deep/streaming 徽章截断 / 文本 wrap |
| G5 | 1920 视口座位网格自动 4 列 | `cols >= 4` 时 4 列生效(原 1100px 阈值下调到 900px) |
| G6 | 左栏 / 右栏信息密度提升 | 块间距 ≤ 8px,空状态文案折叠 |

## 3. 设计方案

### 3.1 中栏底部 Panel — 极致紧凑模式(Ultra-Compact)

**触发条件**：未开启(`windowOpen=false`)且无未读项 → 自动降级到「单行摘要」。

**新样式** `.ww-panel-collapsed-strip`：
```
┌─────────────────────────────────────────────────────┐
│ ✉️ 私下通道 · 仅白天发言阶段开启          📋 0  ▲   │
│ 💰 阵营赌注 · 仅白天发言阶段开启        🎯 0  ▲   │
└─────────────────────────────────────────────────────┘
```

- 单行高度 **28px**(原 90px)
- padding 4px 12px,无 flex gap
- 右侧三件套:`未读数` `余额 / 统计` `▲/▼ toggle`
- 折叠状态持久化到 `localStorage` key `ww_panel_strip_<letter|bet>`

**开启态展开**：点击 header 切换到原 compose form,展开态高 **≤ 220px**。

**JSX 改造**：在 `SecretLetterPanel.tsx` 与 `FactionBetPanel.tsx` 引入 `forceStrip` prop,内部 state `stripCollapsed`,渲染条件：
- `!windowOpen && (noUnread || !autoOpenOnUnread)` → strip 模式
- 否则 → 原 form 模式

### 3.2 座位网格 4 列阈值下调(U1)

`calcColsForViewport`(WerewolfTable.tsx:168) 当前 `>1100 → 4`,改：

```
≤360   → 1
≤700   → 2
≤900   → 3     (原 ≤1100 → 3,下调 200px)
>900   → 4     (原 >1100 → 4)
```

**原理**：1920 视口下 board-container 实测宽约 1020px,3 列下每张卡 ≈ 340px,4 列仅 ≈ 250px;但内部 5 行结构(情绪/延迟/调用/token/模型)必须紧凑 + 头像缩小到 48px,4 列就成立。13 人局 ÷ 4 列 = 4 行,**比 3 列少 1 行 ≈ 节省 250px**。

### 3.3 顶部 chip 分组分桶(U2)

`GameStatusHeader.tsx` 拆分两组 chip：

```
┌─ 游戏状态 ────────────────┐ ┌─ 实时统计 ────────────────┐
│ ⏰ 剩余 587s · 👥 13/13   │ │ 🔄 9 成功 · 0 失败        │
│ ⚖️ 法官 Xiaomi · 🌙 夜    │ │ 💰 86.9K/7.2K·94.1K 总    │
└───────────────────────────┘ └───────────────────────────┘
```

- 容器 `display: grid; grid-template-columns: 1fr auto; gap: 12px`
- 每组内部 `flex-wrap: wrap; gap: 4px`
- 标题前缀色:游戏状态 = 蓝紫,统计 = 绿
- ≤1280 视口自动 stack 上下两行

### 3.4 座位卡 Streaming 徽章文本截断(U3)

`BotPhaseIndicator.tsx` 长文本 CSS：
- `.phase-badge.is-deep-thinking` 与 `.is-streaming` 加 `max-width: 110px; text-overflow: ellipsis; overflow: hidden; white-space: nowrap;`
- title 属性保留完整文案(悬停可见)
- 文案本身:超过 8 字用「🌊 响应中…」替代「🌊 深度响应中 22 秒…」

### 3.5 左侧房间信息 panel 块间距收紧(U4)

`werewolf-room-info-panel.css`(或对应文件)：
- section `margin-bottom: 8px`(原 16px)
- 内部 `.room-info-panel__row` `gap: 4px`(原 8px)
- 状态行图标 + 文字 `display: inline-flex; gap: 4px; align-items: center`

### 3.6 右侧聊天空状态折叠(U5)

`GameChatPanel.tsx` 空历史提示：
- 「没有更早的消息了」改为 `padding: 4px 12px; font-size: 11px; opacity: 0.6;` 嵌入滚动区顶部
- 不再独立一行,而是 sticky 在 scroll-top

### 3.7 4 列下座位卡紧凑化(U6 — 配套 3.2)

`werewolf-v2.css` 加 `--ww-seat-avatar-size: 48px`(4 列下),默认 56px:
- `.werewolf-game .board-container.cols-4 { --ww-seat-avatar-size: 48px; --ww-seat-info-row-h: 18px; }`
- SeatCell 头像区 + meta 行高度同步缩小

## 5. 验收标准

1. **截图比对**:1920×1080 视口下 13 张座位卡全部可见(无 fold 遮挡)
2. **高度测量**:中栏底部两个 panel 折叠态合计高度 ≤ 128px(原 ~200px)
3. **无溢出**:座位卡无 `overflow-x: auto` 横向滚动条
4. **类型检查**:`tsc --noEmit` 通过
5. **构建**:`npm run build` 通过
6. **运行**:`./rebuild_restart_app.sh` 启动后,服务正常

## 6. 风险与回滚

- **风险 1**:4 列下座位卡宽度 250px 可能挤压长模型名(如 "DeepSeek-V4")—— 解决:`text-overflow: ellipsis` + title 全名
- **风险 2**:Panel 折叠后用户找不到原表单入口 —— 解决:Header 加 hover tooltip「点击展开」+ ▲ 图标高亮
- **风险 3**:折叠状态 localStorage 在多端不同步 —— 接受(用户偏好是本地语义)
- **回滚**:所有 CSS 改动独立 class 命名(`.ww-panel-collapsed-strip` / `.cols-4` / `.chip-group`),删除类即可

## 7. 教训沉淀

1. **「折叠态」≠「小一号的全 panel」** —— 真折叠需要独立设计摘要条样式,不是简单的 height: 64px
2. **网格列数阈值必须实测容器宽度,不能假设视口宽度** —— 同一视口下侧栏展开/折叠会让 container 缩 200~300px,阈值要保守
3. **长文本徽章必须有 max-width + title 全名兜底** —— streaming/thinking 文案动辄 10+ 字
4. **顶部状态栏分组比堆叠更易扫读** —— 把语义不同的 chip 强行拼一行,用户视觉扫过时会"信息丢失"
