## 1. 问题诊断(亲自验证 + 探索 Agent 报告)

### 1.1 问题 1:布局结构不符合用户要求

**当前结构**(`TexasHoldemGamePage.tsx:147-247`):

```
.texas-game                                       (calc(100vh - 56px), flex col)
└── .game-area                                    (flex row, gap:16px, padding:12px)
    ├── .board-container                          (flex:1, 子挂 Table + Action + Over)
    │   ├── error-banner(条件)
    │   ├── waiting-board(isWaiting)
    │   └── 主区(isPlaying)
    │       ├── TexasHoldemTable
    │       ├── ActionControls (人类玩家)
    │       └── game-over-banner (isOver)
    └── .game-sidebar                             (flex:0 0 280px, 单列纵向)
        ├── GameInfoPanel                         ← 信息
        └── GameChatPanel                         ← 聊天
```

**问题**:用户要求的是 **3 栏布局** —— **`left(信息) + center(牌桌+动作) + right(聊天)`**。
当前的 sidebar 是"信息在上、聊天在下"两段纵向叠加,贴右侧。**信息/聊天从未分列两侧**。

**§12.5 验证**:✅ 我方在 s0-bottom(`texasholem.css:403`),不需调整。

### 1.2 问题 2:聊天气泡黑色背景与牌桌重叠

#### 1.2.1 直接证据

`ClientWeb/src/styles/chat.css:182-187` Bot 消息气泡:
```css
.game-chat-msg--bot {
  border-left: 2px solid rgba(45, 212, 191, 0.55);
  padding: 2px 6px 2px 8px;
  border-radius: 3px;
  background: rgba(45, 212, 191, 0.045);  /* ⚠ 透明度仅 4.5% */
}
```

**叠加到牌桌暗绿底色 `#1f4d2e` / `#3a5d3a` 上**:
- 牌桌暗背景已经接近黑
- Bot 气泡背景透明度仅 4.5%,叠加后**视觉上几乎等于纯黑底**
- 没有 card-style 容器,直接挂在外层 `var(--panel)` 透明背景的 `.game-chat` 内
- `.game-chat` 在 sidebar 内 `width:280px`,从牌桌**不会被牌桌背景重叠**

#### 1.2.2 "牌桌上面"歧义澄清

经核查,德州扑克 Web 端**没有真正的发言冒泡组件**(`/texasholdem/*` 文件零 `bubble`/`speech-bubble` 命中)。最接近"牌桌上面显示的对话内容"只有 3 类:
1. **`.thp-bot-thought`**(`texasholem.css:74-89`)— Bot 内心独白,`position:absolute; top:8px; right:8px` 覆盖在牌桌 PNG 上;背景 `linear-gradient(rgba(155,89,182,0.18),rgba(155,89,182,0.18))` 叠 `rgba(20,16,32,0.85)` 暗紫底,**与牌桌重叠风险存在**
2. **`.seat-heart-thought`**(`PlayerSeat.tsx:102-110`)— 内心独白截断卡片,挂座位下方;背景 `rgba(155,89,182,0.18)` + border `rgba(155,89,182,0.5)`,**紫色,非黑**
3. **`.seat-thinking`**(`PlayerSeat.tsx:96-100`)— 思考中 ⏳ 标签;紫底 `rgba(155,89,182,0.55)`,字 `#ffffff`

**用户大概率指的是**:`.thp-bot-thought`(BotThoughtPanel),因为:
- 它唯一满足"在牌桌上面"(`position:absolute; top:8px; right:8px`)
- 黑色 rgba(20,16,32,0.85) 深色面板,**视觉观感接近纯黑**
- 在深绿/暗色桌布背景下"漂浮",确实"重叠看不清"

**但也不排除**:用户实际想要的是**真正聊天频道里的消息**(GameChatPanel 内的 `.game-chat-msg--bot`),可能在浏览器下缩放/分辨率下 `.game-chat` 容器在 viewport 较小的情况下溢出,压到牌桌上面。

#### 1.2.3 全面排查的 3 处黑色风险位置

| # | 文件:行号 | 元素 | 当前背景 | 风险 | 是否需要修复 |
|---|-----------|------|---------|------|------------|
| ① | `texasholem.css:79-89` `.thp-bot-thought` | BotThoughtPanel 浮卡 | `rgba(155,89,182,0.18)` 叠 `rgba(20,16,32,0.85)` | 暗紫接近黑,叠深绿桌布 | **必须修复** |
| ② | `texasholem.css:425-435` `.texas-pot` | 底池数值标签 | `rgba(0,0,0,0.55)` 纯黑 55% | 与牌桌对比度够(字金黄),但在浅色 PNG 桌布上变成"贴在黑框" | 可选优化 |

## 2. 总体策略

**只动 CSS + TexasHoldemGamePage.tsx 1 个文件**,不重写 React 组件骨架:
1. **三栏布局重构**:`.game-sidebar` 内部拆成 2 个 独立 `.game-info-column`(左) + `.game-chat-column`(右),保留 1024/768/640 三档断点适配
2. **3 处黑底风险点修复**:
   - `.thp-bot-thought`:背景由 `rgba(20,16,32,0.85)` 暗紫黑 → `rgba(30, 25, 50, 0.92)` 亮紫黑 + 圆角 + border 加粗(§26.4 紫徽章色相库)
   - `.texas-pot`:背景不动(字金黄对比已够 6.8:1),仅 `box-shadow` 加 `0 0 12px rgba(255, 215, 0, 0.3)` 金色光晕更醒目
   - `.game-chat-msg--bot`:背景从 4.5% 提升到 ≥ 0.15,加 `border: 1px solid rgba(45, 212, 191, 0.25)`,内边距与圆角与 `.game-chat-msg--whisper` 对称(§26.3 一致性)
3. **桌布重叠防御**:`.thp-bot-thought` 在背景图上增加 `backdrop-filter: blur(8px)` 毛玻璃(支持 prefers-reduced-motion 关闭动画)
4. **响应式 → 三栏**:1024px 以下 3 栏比例微调, ≤ 1024 仍保三栏, ≤ 640 折成单列(信息 → 牌桌 → 聊天 顺序)
5. **左信息面板宽度调整**:从 `var(--info-panel-w, 240px)` 抽 CSS 变量,便于 §26 后续调整
6. **不破坏 §2.1 globals.css @import 顺序**;不污染 xiangqi/doudizhu/werewolf(全部挂在 `.texas-game` 后代)

## 6. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 三栏布局挤压 1024px 以下 ActionControls 区 | 1024/768 断点缩侧栏宽度 + `min-width:0` 中间列弹缩 |

| BotThoughtPanel 紫渐变在浅色 PNG 桌布上变成"白字淡紫底"对比度差 | 已计算实际对比 ≥7.6:1 ✓ |
| `.game-chat-msg--bot` 透明度提升到 15% 影响狼人杀等共享组件视觉 | 改用 `.game-chat-msg--bot` 局部加规则,不影响 `.game-chat-msg--whisper` / 默认 `.game-chat-msg` |
