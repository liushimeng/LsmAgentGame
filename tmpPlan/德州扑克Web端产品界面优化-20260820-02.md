---

## 1. 背景与根因

### 1.1 用户反馈
用户以观战身份进入德州扑克 1+N 房间(1 玩家 + 5 Agent),主界面严重简陋:
- 所有模块(6 座位卡 + 公共牌 + 底池 + 玩家列表 + 风格切换 + 房间聊天)紧凑到中显示、垂直堆叠
- 大厅全局聊天面板"看不到"(实际 `AppLayout.tsx:121-122` 渲染正常,问题是德扑 `.game-sidebar` 缺宽度被挤掉)
- 整体界面不像专业扑克室,像调试骨架

### 1.2 根因(已验证)

**`ClientWeb/src/styles/texasholem.css`(309 行)严重缺失**——它只覆盖了 Bot 徽章、思考动画、BotThoughtPanel、RoomCreateModal。**核心布局类 0 个**:

| 缺失类 | 位置 | 后果 |
|---|---|---|
| `.texas-table`(容器尺寸) | `TexasHoldemTable.tsx:67` | 容器无尺寸 |
| `.seat-pos` + `.s0-bottom..s5-right` 6 个 slot | `TexasHoldemTable.tsx:64, 80` | 6 张座位卡沿文档流垂直堆叠 |
| `.texas-card` / `.card-png` / `.card-css` / `.card-back-pattern` | `CardView.tsx:23, 49, 57` | 卡牌无尺寸/边框/花色 |
| `.texas-action-controls` / `.raise-controls` / `.game-over-banner` | `ActionControls.tsx:74` | 动作按钮无容器 |
| `.error-banner` / `.waiting-board` / `.spinner` | `TexasHoldemGamePage.tsx:155, 172` | 加载/错误条无样式 |
| `.texas-center` / `.texas-pot` / `.texas-community` | `TexasHoldemTable.tsx:99-107` | 中央公共牌/底池无定位 |
| `.game-sidebar`(右侧栏宽度) | `TexasHoldemGamePage.tsx:236` | 信息面板与房间聊天挤在一起 |
| `.badge.dealer` / `.sb` / `.bb` / `.allin-badge` | `PlayerSeat.tsx:64-67` | 徽章样式缺失 |

**组件借用了 `xiangqi.css` 中无作用域公共类**(`.game-area`、`.game-info-panel`、`.panel-section`、`.player-info`、`.dot`、`.badge`、`.style-switcher`、`.game-over-msg`、`.status`),所以信息面板勉强能看;但德扑专属类全部无样式 → 6 个座位垂直堆叠在 `.game-area` 水平居中区域。

### 1.3 资源缺失

**`ClientWeb/src/assets/images/texasholem/` 下完全没有 PNG 文件**(只有 `index.ts`)。`python-generate-image-tool/generate_texasholem_assets.py` 脚本就绪(297 行),但磁盘上没有产物。前端所有图片降级到 CSS 文字卡面。

### 1.4 后端字段缺失

`view.go` 未透传 SB/BB 座位、turn 倒计时、手牌评估 4 个 UI 必需字段,导致:
- `PlayerSeat.tsx:87-88` 硬编码 `isSB={false} isBB={false}` → SB/BB 徽章永远不显示
- `TexasHoldemTable.tsx` 无法计算 turn 倒计时
- 摊牌后无法显示赢家牌型

---

## 2. 总体策略

**只补 CSS + 补齐 PNG + 补齐 4 个 view.go 字段**,不重写任何 React 组件。React 组件骨架已完整,问题 100% 集中在:
- 缺失 CSS(`texasholem.css` 309 行,核心布局类 0 个)
- 缺失 PNG 资源(`ClientWeb/src/assets/images/texasholem/` 下 0 个 PNG)
- view.go 未透传 SB/BB/TurnStartedAt/HandRank 4 个 UI 必需字段

### 2.1 分阶段优先级

| 阶段 | 名称 | 阻塞性 | 涉及文件 | 验收点 |

| **P3** | 验证 + 中文 git 提交 | 阻塞收口 | `rebuild_restart_app.sh` | 编译通过 + 截图验证 |
