> **任务**: 修复 `狼人杀 13 人标准竞技局` 主界面座位卡的「头像列下方留白」与「Agent 信息过于紧凑」双重缺陷。

> **版本**: §20260817-05
> **前置**: §20260817-04（Agent 紧凑指标块 + 气泡 hover 全文 + 私聊格式）· §20260817-03 · §20260816-02
> **工作面**: 仅 `ClientWeb/`（纯前端布局重构，零后端改动、零协议改动）

## 1. 问题陈述

### 1.1 用户反馈（2026-08-17 报告）

> 狼人杀 13 人局游戏主界面，每个「游戏玩家」显示主模块的**角色头像**显示主模块所在列的
> **下面空间有留白的区域**；「游戏玩家」显示主模块**其他区域显示 Agent 信息过于紧凑**。

### 1.2 实机截图佐证（ProjectPic/werewolf-2026-01-opening-full-room.png，2026-08-17 深夜局）

5 列网格下每张座位卡 ~190px 宽、min-height 200px：

- **缺陷 A — 头像列死区**：左列 `avatar(64×88) + margin-top:6px ≈ 94px`，卡高 ≥200px，
  头像正下方残留 **~90–100px 垂直空白带**（截图中 #1/#2/#5/#9/#10/#11 等 idle 座位尤其明显：
  头像悬在左上角，下方整片空黑，Agent 指标被 `margin-top:auto` 压到右列底部，
  形成「左上头像 / 左下空白 / 右下挤满」的失衡三角）。
- **缺陷 B — Agent 信息过挤**：决策摘要 / 延迟调用 / Token 模型三行指标全部挤在右列
  ~100px 宽的信息列内（190px 卡宽 − 20px padding − 64px 头像 − 8px gap），
  10px 字号 + 2px 间距 + chips 被迫 `flex-wrap` 折行（如 `Xiaomi mimo-v2.5-pro`
  模型名折行、`🐇 µ × 📊` 四枚 chip 折成两行），视觉密度过高。

**根因**：§20260817-04 U1 把三行指标打包进 `.werewolf-seat__agent-block` 并用
`margin-top:auto` 贴底——但它贴的是**右列（info 列）的底**，不是**整张卡的底**。
左列头像区域没有任何元素向下延伸，死区就此产生；同时指标仍被囚禁在 ~100px 窄列里。

## 3. 设计方案（产品 / 美工 / 界面三视角）

### 3.1 设计原则

1. **消灭死区，而非填充死区** —— 不往头像下塞装饰，而是让布局结构上不存在死列。
2. **信息带宽归还给数据** —— Agent 指标是数据密度最高的区块，应获得整卡宽度。
3. **零协议/零状态改动** —— 纯 DOM 重排 + CSS，所有数据字段、testid、popover、
   徽章逻辑原样保留，e2e 测试零影响。
4. **断点零回归** —— cols-1~5 / compact / 三个媒体查询断点全部自然适配，
   不新增断点特例。

### 3.2 目标布局：卡内「上段横排 + 底部通栏」两段式

```
┌─────────────────────────────────────┐
│ ┌──────┐  #3 (我) ★ 🃏 ⭐72          │  ← .werewolf-seat__main (flex row)
│ │      │  预言家                    │     上段:头像 + 铭牌/角色/发言
│ │avatar│  ┌──────────────────────┐ │
│ │64×88 │  │ 💬 发言气泡 2 行钳位  │ │
│ └──────┘  └──────────────────────┘ │
│────────────────────────────────────│  ← border-top 虚线分隔(既有)
│ 📤 决策摘要(24 字放宽)              │  ← .werewolf-seat__agent-block
│ 🐇2.3s  µ3.1s  ×12  📊5            │     通栏:整卡宽度, chips 单行排下
│ 🔤in:3.2k out:1.1k ⚡ 🤖Kimi 2.7 🕐│
│ ▸ 响应中 · 已运行 4s                │  ← BotPhaseIndicator 并入通栏末行
└─────────────────────────────────────┘
```

**为什么这样分配**：

- **上段（头像 + 身份 + 发言）=「这个玩家是谁、刚说了什么」** —— 博弈信息，
  人眼扫视座位阵列时的第一优先级。头像右侧放 header/role/气泡，三者在有发言时
  高度 ≈ 22+18+50+gap ≈ 94px，与头像 94px **恰好齐平**，左列死区从结构上消失。
- **底部通栏 =「这个 Agent 跑得怎么样」** —— 观测指标，从 ~98px 窄列解放到
  ~170px 全卡内宽（+73%），四枚 metrics chip 单行容纳，模型名不再折行。
- BotPhaseIndicator 本质是 Agent 运行状态，逻辑上属于指标区，移入通栏末尾。

### 3.3 各缺陷的对应修复

| 缺陷 | 修复 |
|---|---|
| A 头像列下方留白 | 卡容器改 `flex-direction:column`；新增 `.werewolf-seat__main` 横排 wrapper 包住 avatar+info；agent-block 提升为卡的直接子节点通栏。头像下方紧贴通栏分隔线，死区消除 |
| B Agent 信息过挤 | agent-block 通栏后：chips 由 wrap 改回 nowrap 单行；字号 10→11px；块内 gap 2→4px、chips padding 1px 4px→2px 6px；决策摘要截断 18→24 字；模型名 `max-width:70%` 限制放宽 |

### 3.4 无发言 / 真人 / 空座位退化形态

- **无发言 Agent**：上段右列仅 header+role(~44px) < 头像 94px，右列内自然留白
  属「铭牌区」正常呼吸位；头像下方是通栏分隔线，无孤立死区。
- **真人玩家**：无 botCtx → agent-block 仅剩决策摘要行（有则显示），通栏高度收缩，
  卡片由 min-height 保持阵列整齐。
- **空座位**：保持现状（虚线框 + 灰化），结构重排不影响 `.is-empty` 规则。

### 3.5 断点与模式适配

| 场景 | 适配 |
|---|---|
| cols-4（container ≤940px） | 既有 `avatar 48×48 / min-height:170px` 覆盖继续生效，无需新增 |
| ≤1280 / ≤1024 / ≤768 | 既有 min-height 225/200/180 与 avatar 缩放继续生效 |
| compact（container ≤480px） | 既有 3 行折叠逻辑不动（AgentCallTimeBadge 仍按 `!compact` 隐藏） |
| 夜晚滤镜 `.is-night` | 不改任何颜色/透明度，brightness 衰减行为不变（§26 无关） |
| popover / reveal-badge / guess-badge | 均为 absolute 定位挂在 `.werewolf-seat` 或 `.speech` 上，DOM 重排不影响 |

### 3.6 明确不做（防范围蔓延）

- ❌ 不调 min-height 200px 基准（涉及 4 处断点覆盖，风险大于收益；通栏化后
  中间余量以横向整带形式存在，观感远好于左列死区）。
- ❌ 不改头像尺寸 64×88（EmotionAvatar 特效溢出、caption 定位均按此调校）。
- ❌ 不动发言气泡的 2 行钳位与 hover popover（§20260817-04 U2 刚落地）。
- ❌ 不新增/删除任何数据字段、testid、i18n 键。

### 4.2 新增 `ClientWeb/src/styles/werewolf-20260817-05.css`

（§4 行数上限约束：不回写 werewolf-v2.css；`globals.css` 在


  `nowrap`，但保留 `max-width:100%; overflow:hidden` 防极端溢出。
- 紧凑断点（cols-4 / ≤1280 / ≤1024 / ≤768）下的既有覆盖规则逐条核对仍适用。

## 5. 风险与回滚

- **风险 1：上段右列在无发言时高度 < 头像，右列内出现新留白。**
  缓解：属铭牌区自然呼吸位，且位于右上而非左下孤立带；实测截图确认可接受。
- **风险 2：`metrics-row` 改回 nowrap 后在 cols-4 窄卡(~140px 内宽)溢出。**
  缓解：cols-4 下卡内宽 ≈ 140−16=124px，四 chip ~110px 勉强容纳；保留
  `overflow:hidden` + title 全文兜底；若实机溢出则对 cols-4 单独保留 wrap。
- **回滚**：纯前端两文件改动（1 JSX + 1 新 CSS + 1 行 @import），
  `git revert` 单提交即可完全回滚。

## 6. 实施追加(2026-08-18 实机联调后补记)

初版方案落地后经 CDP 实机 getComputedStyle 联调,追加三项修正并已随本批落地:

### U3 修正 — cols-5/cols-4 min-height 重算(两轮)

1. **第一轮(170/178px)**:两段式结构在窄卡下总高 ~168-176px,超过 §20260817-01 的
   158/168px,model-row 折行第二行被 overflow:hidden 裁切(实测 clip 17px)。
   同时发现 §20260817-01 的紧凑字号只覆盖旧类名 `.__metrics`,新类名
   `.__metrics-row` 漏覆盖 → cols-5 误吃 11px 基础字号。
2. **第二轮(192/200px)**:LLM 5 态指示器行(`.ww-bot-phase`,21px)仅 LLM 活跃时
   渲染,静态预算必须容纳,否则「响应中」高亮卡(用户视线焦点)整行被裁。
   选择静态容纳而非 `.is-llm-calling` 动态加高,避免 13 卡网格 layout thrash。
3. **实测依据**:网格行轨 = min-height(卡片被 grid stretch 到行轨),溢出即裁。

### U4 — 座位号 #N 与身份「未知」合并为一行(用户第 5 项)

- JSX:`.werewolf-seat__role` 从 `__info` 独立行移入 `__header`,紧跟 `__num`;
  div→span,class 与 `is-revealed-truth` 条件类原样保留(死亡变色等 4 处既有
  CSS 规则全部是类选择器,DOM 层级无关)。
- CSS:header `flex-wrap:nowrap + align-items:baseline`;role `text-align:left`。
- 释放 ~18px 纵向空间,主段高度改由 avatar 主导。

### U5 — 发言气泡撑满剩余高度(用户第 6 项)

- `.werewolf-seat__speech { flex:1 1 auto; display:flex; flex-direction:column }`:
  气泡吃掉 info 列剩余高度,底部与 avatar 底部齐平。
- 解除 §20260817-01 的 max-height 钳位(42px/30px → none),文本边界由
  `-webkit-line-clamp`(base 2 行 / cols-5 1 行)继续承担 —— 钳位从盒高度转移到
  文本行数,§20260817-01 U2 的高度可预测性不变。
- `.werewolf-seat__speech-meta { margin-top:auto }`:相对时间/kind 贴气泡底,
  与头像底边同线。
