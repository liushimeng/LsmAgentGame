## 1. 现状诊断

### 1.1 高度现状（无统一标尺，各组件各自为政）

| 对象 | 当前世界单位 | 问题 |
|---|---|---|
| 地面 | 40×40 | 无米制锚定 |
| 建筑 | `(1+prosperity*4) * factor(0.6~1.0)` → 0.6~5.0 | 8 个城区同一公式，金融 CBD 与郊区别墅一样高 |
| 行人 Pedestrian | 0.36（平面 0.18×0.36） | 若建筑 5.0≈50m，行人 = 3.6m 巨人 |
| 玩家标记 AgentToken | 圆柱高 0.7 / 半径 0.35 | 7m 高柱子，远超人高 |
| 路灯 StreetLight | 总高 ~1.45（杆 1.3） | 主/次干道不分档 |
| 树 Tree | scale 0.7~1.1，总高 ~0.9~1.3 | 缺米制依据 |
| 车辆 Vehicle | 0.3×0.12×0.18 | 偏小偏扁 |
| 路牌 Sign | 杆 0.8，总高 ~1.0 | 10m 高的"路牌"，失真 |
| 屋顶杂物 RooftopAcc | yOffset 硬编码 2.8~4.2 | 与新区高体系脱钩，郊区楼 0.9 高时杂物悬空 |

### 1.2 贴图渲染根因（确认）

`BuildingMesh.tsx` 5 个面材质全部为：

```tsx
<meshStandardMaterial map={facade} color={def.color} emissive={def.color} ... />
```

three.js 中 **最终颜色 = map × color + emissive × emissiveIntensity**。
`def.color` 是城区饱和主色（`#1d4ed8` 蓝 / `#b91c1c` 红 / `#15803d` 绿…），
直接把 facade/roof 贴图乘成单色——这就是"单一颜色覆盖了贴图"的根因。
emissive 再叠一层主色，雪上加霜。

对照组（已正确的写法）：`WealthCityMap.tsx` Ground、`Road.tsx` 均为
`color={tex ? '#ffffff' : 回退色}` —— BuildingMesh 是唯一漏网之鱼。

## 2. 高度系统设计

### 2.1 世界标尺（硬约定）

**1 世界单位 = 10 米**。地图 40×40 = 400m×400m 城区（合理的小型城市尺度）。

新建 **`ClientWeb/src/components/wealth/cityScale.ts`**（游戏私有，放 `wealth/` 内合规）：

```ts
/** 世界标尺：1 单位 = 10 米（虚拟城市 3D 高度系统唯一事实来源）。 */
export const METERS_PER_UNIT = 10;
/** 米 → 世界单位。 */
export const u = (meters: number): number => meters / METERS_PER_UNIT;
```

### 2.2 各对象真实高度标准

| 对象 | 真实高度 | 世界单位 | 说明 |
|---|---|---|---|
| 行人 | 1.7 m | **0.17** | 成年人均身高 |
| 玩家标记 AgentToken | ~2.5 m | **0.25** | 游戏标记物（非真人），整体按比例 ~0.36× 缩放，含光环/Billboard/Html 标签联动 |
| 路灯·主干道 | 11 m | **1.10** | 城市快速路/主干道标准 10~12m |
| 路灯·次干道 | 7 m | **0.70** | 支路/小区道路 6~8m；`StreetLight` 新增 `kind: 'main'\|'side'` |
| 行道树 | 5~10 m | 0.5~1.0 | scale 范围收紧到 0.5~1.0（默认 0.7） |
| 轿车 | 高 1.5 / 长 4.5 / 宽 1.8 m | 0.15 / 0.45 / 0.18 | bus/truck 可 ×1.5 高 |
| 路牌 | 杆 2.2 m + 牌 0.6 m | 0.22 + 0.06 | 总高 ~0.28 |
| 屋顶水箱 | 3 m | 0.30 | 现状 0.36 → 0.30 |
| 屋顶空调外机 | 0.8 m | 0.08 | 现状 0.18 → 0.08 |
| 屋顶天线 | 3 m | 0.30 | 现状 0.36 → 0.30 |

### 2.3 建筑分城区楼层剖面（核心改动）

层高 **3 m/层（0.3 单位）**。每城区给 `[最低楼层, 最高楼层]` 区间，
楼高 = `u(3) × lerp(minF, maxF, prosperity) × jitter`，jitter 由现有
`spec.factor(0.6~1.0)` 映射为 `0.85 + factor × 0.15`（保留确定性伪随机，
避免 0.6 倍把楼压扁）。

`cityScale.ts` 追加：

```ts
import type { WealthDistrictId } from '@/types/wealth';

/** 各城区楼层区间 [minF, maxF]（真实城市形态：CBD 摩天 / 郊区别墅）。 */
export const DISTRICT_FLOORS: Record<WealthDistrictId, [number, number]> = {
  finance:     [8, 20],   // 金融CBD   24~60 m
  tech:        [6, 15],   // 科技园    18~45 m
  industry:    [2, 6],    // 工业区     6~18 m（厂房高顶棚）
  oldtown:     [2, 7],    // 老城区     6~21 m（多层老公房）
  commerce:    [4, 12],   // 商业中心  12~36 m
  residential: [6, 18],   // 居住区    18~54 m（高层住宅）
  suburb:      [1, 3],    // 郊区       3~9 m（别墅/排屋）
  riverside:   [8, 20],   // 滨河新区  24~60 m
};

/** 楼层数 → 世界单位楼高。 */
export const buildingHeight = (floors: number): number => u(3) * floors;
```

`BuildingMesh.tsx` 高度公式改为：

```ts
const [minF, maxF] = DISTRICT_FLOORS[def.id];
const h = buildingHeight(minF + (maxF - minF) * prosperity) * (0.85 + spec.factor * 0.15);
```

`DistrictBlock.tsx` 的 `heightBase`（hover 卡定位用）改用
`buildingHeight(DISTRICT_FLOORS[def.id][1])`，卡片偏移 +1.0 即可。

`StreetPropsLayer.tsx` 楼顶杂物 `yOffset` 改为按城区取中位楼高：
`buildingHeight((minF + maxF) / 2) × 0.9`（去掉硬编码 2.8+rnd×1.4），
杂物不再悬空/埋楼。

### 2.4 相机/雾/灯光

相机 `minDistance: 8 / maxDistance: 40`、fog `[28, 60]` 在新体系下
（最高楼 6.0）仍然匹配，**不动**。

## 3. 贴图渲染修复（BuildingMesh.tsx）

5 个面的材质统一改为"有贴图纯白、无贴图回退主色"：

```tsx
const map = facadeBase ?? facadeMid ?? undefined;
<meshStandardMaterial
  map={map}
  color={map ? '#ffffff' : def.color}   // 贴图不再被主色乘掉
  emissive={map ? '#ffcf99' : def.color} // 繁荣暖光改中性色，不再叠城区主色
  emissiveIntensity={emissive}           // prosperity × 0.25 不变
  roughness={0.7}
  metalness={0.1}
  side={THREE.DoubleSide}
/>
```

顶面同理（emissiveIntensity × 0.6 保留）。

**验收基准**：与 `Ground` / `Road` 的既有正确模式逐字段对齐。
