# 德州扑克 Web 端产品界面优化方案

> **日期**: 2026-08-22  
> **版本**: §20260822-01  
> **问题来源**: 用户反馈 — 游戏棋牌桌面主界面，每个用户的显示信息在显示层级上被桌面背景、页面背景挡住，导致显示不全。

---

## 1. 问题分析

### 1.1 现象描述

德州扑克牌桌界面中，玩家座位卡（PlayerSeat）的信息显示存在以下问题：
- 座位卡的部分内容被牌桌背景图遮挡
- 下注筹码条（seat-committed）被牌桌边缘裁切
- 座位卡在深色背景上对比度不足，信息可读性差

### 1.2 根因分析

通过代码审查，定位到以下 CSS 层级和样式问题：

| 问题编号 | 问题描述 | 影响范围 | 严重度 |
|---------|---------|---------|--------|
| **P1** | `.texas-table` 设置了 `overflow: hidden`，导致椭圆桌边缘的座位卡及其下注筹码条被裁切 | 所有座位 | 高 |
| **P2** | `.texas-table` 的 `box-shadow: inset 0 0 60px rgba(0,0,0,0.6)` 产生深色晕影，遮挡边缘座位信息 | 边缘座位 | 高 |
| **P3** | `.texas-seat` 背景 `rgba(20,25,35,0.92)` 透明度过高，在浅色桌布上与背景融合 | 所有座位 | 中 |
| **P4** | `.seat-committed` 的 `z-index: 1` 低于座位卡 `z-index: 2`，可能被同级元素遮挡 | 下注信息 | 中 |
| **P5** | 座位卡宽度 128px，在小屏幕上内容拥挤，名字/徽章/筹码信息换行 | 小屏幕 | 低 |

### 1.3 当前 z-index 层级结构

```
.texas-table (position: relative)
├── .seat-pos (z-index: 2) ─── 座位定位容器
│   └── .texas-seat ─── 座位卡
│       ├── .seat-name-row ─── 名字行
│       ├── .seat-badges ─── 徽章行
│       ├── .seat-stack ─── 筹码
│       ├── .seat-committed (z-index: 1) ─── 下注筹码条(absolute, bottom: -14px)
│       └── .seat-holes ─── 手牌区
├── .texas-center (z-index: 3) ─── 公共牌 + 底池
└── .thp-bot-thought (z-index: 5) ─── Bot 独白面板
```

**问题链**: `overflow: hidden` → 座位卡底部内容被裁切 → 下注信息不可见

---

## 2. 解决方案

### 2.1 修改清单

| 修改项 | 文件 | 修改内容 | 预期效果 |
|--------|------|---------|---------|
| **M1** | `texasholdem.css` | 移除 `.texas-table` 的 `overflow: hidden`，改用 `overflow: visible` | 下注筹码条不再被裁切 |
| **M2** | `texasholdem.css` | 减弱 `.texas-table` 的 inset shadow，从 60px 减到 30px，透明度从 0.6 降到 0.3 | 减少晕影遮挡 |
| **M3** | `texasholdem.css` | 提升 `.texas-seat` 背景不透明度，从 0.92 提升到 0.96 | 增强座位卡与背景的对比 |
| **M4** | `texasholdem.css` | 调整 `.seat-committed` 的 z-index 从 1 提升到 3，确保在座位卡最上层 | 下注信息始终可见 |
| **M5** | `texasholdem.css` | 为 `.texas-seat` 添加更明显的边框和阴影，增强视觉边界 | 提升座位卡辨识度 |
| **M6** | `texasholdem.css` | 优化椭圆桌的 border-radius，从 `50% / 35%` 调整为 `50% / 40%` | 增加垂直空间，减少边缘裁切 |

### 2.2 z-index 层级优化方案

**优化后层级结构**:

```
.texas-table (position: relative, overflow: visible)
├── .seat-pos (z-index: 2) ─── 座位定位容器
│   └── .texas-seat (z-index: auto) ─── 座位卡
│       ├── .seat-name-row ─── 名字行
│       ├── .seat-badges ─── 徽章行
│       ├── .seat-stack ─── 筹码
│       ├── .seat-committed (z-index: 3) ─── 下注筹码条(提升层级)
│       └── .seat-holes ─── 手牌区
├── .texas-center (z-index: 3) ─── 公共牌 + 底池(保持不变)
└── .thp-bot-thought (z-index: 5) ─── Bot 独白面板(保持不变)
```

### 2.3 视觉增强方案

| 元素 | 当前样式 | 优化后样式 | 目的 |
|------|---------|-----------|------|
| 座位卡背景 | `rgba(20,25,35,0.92)` | `rgba(15,20,30,0.96)` | 增强不透明度 |
| 座位卡边框 | `2px solid transparent` | `2px solid rgba(255,255,255,0.12)` | 添加可见边框 |
| 座位卡阴影 | `0 4px 12px rgba(0,0,0,0.4)` | `0 4px 16px rgba(0,0,0,0.5), 0 0 0 1px rgba(255,255,255,0.05)` | 增强立体感 |
| 牌桌晕影 | `inset 0 0 60px rgba(0,0,0,0.6)` | `inset 0 0 30px rgba(0,0,0,0.3)` | 减少遮挡 |
| 椭圆桌比例 | `border-radius: 50% / 35%` | `border-radius: 50% / 40%` | 增加垂直空间 |

## 3. 实施步骤

### 3.1 第一阶段：CSS 层级修复

1. 修改 `ClientWeb/src/styles/texasholdem.css`
   - 移除 `.texas-table` 的 `overflow: hidden`
   - 调整 inset shadow 参数
   - 提升 `.seat-committed` 的 z-index

### 3.2 第二阶段：视觉增强

1. 优化座位卡背景和边框样式
2. 调整椭圆桌比例
3. 增强下注筹码条的视觉效果

### 3.3 第三阶段：响应式适配

1. 检查各断点下的显示效果
2. 确保移动端布局不受影响

---

## 4. 验证标准

| 验证项 | 验证方法 | 预期结果 |
|--------|---------|---------|
| 下注信息可见性 | 观察所有座位的下注筹码条 | 所有下注信息完整显示，不被裁切 |
| 座位卡辨识度 | 在不同背景桌布下观察 | 座位卡边界清晰，信息可读 |
| 公共牌显示 | 确认公共牌区域不被遮挡 | 公共牌始终在最上层 |
| Bot 独白面板 | 确认独白面板显示正常 | 面板在牌桌右上角，不被遮挡 |
| 响应式布局 | 测试 1280px/1024px/768px/640px 断点 | 各断点布局正常 |

---

## 5. 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 移除 overflow: hidden 可能导致椭圆桌边缘内容溢出 | 低 — 座位卡使用绝对定位，不会溢出 | 保持 border-radius 裁切效果 |
| 修改 z-index 可能影响其他游戏组件 | 低 — 使用 .texas- 前缀隔离 | 确认选择器特异性 |
