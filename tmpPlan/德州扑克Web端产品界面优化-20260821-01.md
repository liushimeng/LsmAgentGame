## 1. 问题诊断

### 1.1 Step 6:文件缺失检查

### 1.2 Step 7:黑边/伪影问题(`chroma-key` 残留)

用 PIL + ffprobe 抽样检测(见 §7 验证脚本),**实际是 chroma-key 不彻底 + 模型阴影残留**:

| 图像 | 四角 alpha | 半透明边缘像素数 | 伪影颜色 (R/G/B/α avg) |
|------|------|------|------|
| `ace_club.png` | 0,0,0,0 ✓ | **130** | 8/16/16/68 |
| `ace_diamond.png` | 0,0,0,0 ✓ | 130 | (类似深灰) |
| `ace_spade.png` | 0,0,0,0 ✓ | 130 | — |
| `ace_heart.png` | 0,0,0,0 ✓ | 130 | — |
| `two_spade.png` | 0,0,0,0 ✓ | 约 100-130 | — |
| `back.png` | 255,255,255,255 ✓(实心) | 0 ✓ | — |

**根因**:
1. 模型生成牌面时,在牌的四周渲染了**阴影**(让牌立体感),但 chroma-key 只抠绿幕底,阴影(深灰)+ 边缘反 alpha 渐变保留了
2. 当牌 PNG 放在**深色桌布**上时,半透明黑色伪影变成"黑边"
3. 当牌 PNG 放在**浅色容器**上时,半透明伪影变成"灰色环"
4. 用户描述的"蓝色背景的黑边"——实际是低饱和度深色 alpha,在不同背景下感知不同

**结论:是模型生成瑕疵 + chroma-key 阈值过高,不是故意设计。**

### 1.3 Step 8:Web 端显示评估

读 `CardView.tsx` + `texasholem.css`:

- ✅ `<img className="card-png">` 正确加载 PNG
- ✅ `onError={() => setImgFailed(true)}` 自动降级到 CSS 文字卡面
- ✅ `.texas-card` 容器有 `width:56px height:78px` 固定尺寸
- ✅ `.card-png` `width:100% height:100% object-fit:cover` 撑满
- ⚠️ `.texas-card` `border: 1px solid rgba(0,0,0,0.4)` 深色边框**会加重伪影黑边观感**
- ⚠️ `.texas-card` 无 `background:transparent`,PNG 透明区域会透出 `cardStyle.backgroundColor = colors.cardBg`(`#f8f5e9` 米白),导致 PNG 透明区域**被填成米白色**,反而把伪影边缘对比拉强
- ⚠️ `.texas-card.small` `width:42px height:58px`,但 PNG 原生 140×200,缩放比例一致(0.3x),尺寸统一 ✓
- ⚠️ board_bg 2560×1440 缩到椭圆桌布 ~1100px,cover 会裁剪,但不会变形

**整体观感问题汇总**:
1. **黑边/灰边**:PNG 伪影 + CSS 深色边框 + 米白背景叠加
2. **牌与牌之间缝隙**:sX-bottom 等 absolute 定位 + transform: translate(-50%,-50%)居中,扑克牌并排会有视觉重叠或间隙
3. **board_bg 大图未应用**:CSS `.texas-table` 已有 `background-color:#1f4d2e` 与 `background-image:url(${bgSrc})` 双层支持,但**桌布背景图在浅色背景下看不太出来**(深绿桌布 + 浅绿 PNG 都偏暗)
4. **筹码/庄家按钮** PNG 是单图,UI 没用到(`index.ts` 有 `chipImg` / `dealerButtonImg` 但组件未引用)

## 3. PNG 后处理方案(`postprocess_texasholem_assets.py`)

### 3.1 思路

对每张 PNG(140×200 牌面):
1. 加载 RGBA
2. 把所有**alpha < 255 且 RGB 都偏暗(< 80)** 的像素强制 alpha=0(伪影检测)
3. 用**形态学腐蚀**(MORPH_ERODE)把边缘 1-2 px 残余清除
4. 保存为优化 PNG(pillow optimize=True)

### 3.2 关键代码(伪代码)

```python
from PIL import Image, ImageFilter, ImageChops
import numpy as np
from pathlib import Path

def clean_card_artifact(path: Path):
    img = Image.open(path).convert("RGBA")
    arr = np.array(img)
    r, g, b, a = arr[..., 0], arr[..., 1], arr[..., 2], arr[..., 3]
    # 规则 1:暗色像素 + 半透明 = 伪影 → 直接透明
    is_dark = (r < 80) & (g < 80) & (b < 80)
    is_semi = (a > 0) & (a < 200)
    artifact_mask = is_dark & is_semi
    arr[..., 3][artifact_mask] = 0
    # 规则 2:半透明像素做 alpha 阈值清理(alpha < 30 完全透明,> 200 完全不透明)
    alpha_thresh = np.where(a < 30, 0, np.where(a > 200, 255, a))
    arr[..., 3] = alpha_thresh
    # 形态学腐蚀 1px 清理
    out = Image.fromarray(arr, mode="RGBA")
    alpha = out.split()[3]
    alpha = alpha.filter(ImageFilter.MinFilter(3))  # 3×3 最小滤波 = 腐蚀
    out.putalpha(alpha)
    out.save(path, "PNG", optimize=True)
```
