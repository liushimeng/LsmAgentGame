# 声音音效功能播放删除 — 解决方案

> 日期：2026-08-17 · 编号：20260817-01
> 需求来源：狼人杀 13 人局标题栏最右侧 `🔊` 播放器按钮 + 圆点（音量滑块拖动柄）设计突兀，
> 用户决策：**整体删除音效功能**，不保留该设计。

## 1. 背景与现状分析

### 1.1 功能是什么

§20260812-02 U4 引入的纯前端音效系统（零后端依赖）：

- **`ClientWeb/src/hooks/useSoundEffects.ts`**（约 160 行）—— Web Audio API（OscillatorNode + GainNode）
  合成 7 类音效：`night`(天黑) / `dawn`(天亮) / `vote`(投票) / `death`(死亡) / `prop`(道具) /
  `chat`(聊天气泡) / `reveal`(翻牌)；开关与音量持久化到 localStorage
  （`lsm_sound_enabled` / `lsm_sound_volume`）；检测 `prefers-reduced-motion` 自动禁用。
- **`ClientWeb/src/components/common/SoundToggle.tsx`** —— 标题栏右侧的 🔊/🔇 开关 + 音量控制
  （本轮会话中刚从「常驻滑块」重构为「popover 面板」，未提交，随本次删除一并废弃）。
- **`ClientWeb/src/pages/WerewolfGamePage.tsx`** —— 唯一使用方：
  - L55-56：`import { useSoundEffects }` / `import { SoundToggle }`
  - L93：`const sound = useSoundEffects();`
  - L470-495：监听 `gameState.phase` 变化触发 night/dawn/vote/reveal 音效
  - L497-505：监听 `all_dead_list_verbose` 长度变化触发 death 音效
  - L528-529：`<SoundToggle sound={sound} />` 挂在 `werewolf-top-bar` 最右侧

### 1.2 为什么要删

1. 🔊 按钮 + 常驻滑块（视觉上只剩一颗孤立蓝圆点）在顶栏突兀，与 `ww-header-btn` chip 风格不统一；
2. 用户明确不需要该设计 —— 删除优于继续迭代；
3. 合成音效信息价值低（Day/Night 已有 `DayNightOverlay` CSS 视觉特效覆盖同一场景）。

### 1.3 影响面盘点（grep 全仓确认，仅 7 个文件）

| 文件 | 涉及内容 | 处置 |
|------|---------|------|
| `ClientWeb/src/components/common/SoundToggle.tsx` | 整个组件 | **删除文件** |
| `ClientWeb/src/hooks/useSoundEffects.ts` | 整个 hook | **删除文件** |
| `ClientWeb/src/pages/WerewolfGamePage.tsx` | 2 import + 1 hook 调用 + 2 useEffect + 1 JSX 挂点 + 注释 | 移除相关行 |
| `ClientWeb/src/styles/common.css` | `.sound-toggle*` 全部规则（约 L872-1004） | 整段删除（保留上方 `@keyframes radar-spin`） |
| `ClientWeb/src/i18n/types.ts` | `common.sound.{title,enable,disable,volume}` 4 键（L1004-1007） | 删除 |

| `ClientWeb/src/styles/werewolf.css` | L1327 `.werewolf-top-bar` 注释提及「音效开关」 | 更新注释（结构保留，见 §3） |

**无其他引用**：`grep -rn "useSoundEffects|SoundToggle|sound\.play|sound-toggle"` 全 `ClientWeb/src`
仅命中上表文件；其他 5 款游戏从未接入音效。`ServerGo/` 零涉及。

## 2. 方案决策

| 决策点 | 结论 | 理由 |
|--------|------|------|
| 删除范围 | 组件 + hook + 样式 + i18n + 页面接线 **全部删除** | 用户明确「相关的功能都要删除」；留半截死代码违反 §130 教训 |
| `.werewolf-top-bar` flex 容器 | **保留**，仅更新过时注释 | 只剩 GameStatusHeader 一个子元素后 flex 仍等价于块级布局，零视觉回归；删容器反而引入布局风险 |
| localStorage 残留键 | 不清理 | `lsm_sound_enabled`/`lsm_sound_volume` 残留无害，清理代码本身反而是新复杂度 |
| 音效触发点（phase/死亡监听） | 整段 useEffect 删除 | 无音效后监听无意义；`prevPhaseRef`/`prevDeadLenRef` 一并删除 |
| `useT` import | 若 WerewolfGamePage 未因本次删除产生未使用 import 则不动 | tsc 会兜底未使用变量报错 |

## 3. 实施步骤（frontend-dev SubAgent 执行）

1. `git rm`/删除 `SoundToggle.tsx` 与 `useSoundEffects.ts` 两个文件。
2. `WerewolfGamePage.tsx`：
   - 删 L55-56 两行 import；
   - 删 L93 `const sound = useSoundEffects();`；
   - 删 L470-505 两个音效 useEffect（含 `prevPhaseRef`/`prevDeadLenRef` ref 声明）；
   - 删 L528-529 `<SoundToggle>` JSX 及其注释；
   - 自查：`useRef`/`useEffect` 若仍被页面其他逻辑使用则保留 import。
3. `common.css`：删除 `.sound-toggle` 起至 `.sound-toggle__slider:focus-visible` 止的整段
   （§20260812-02 U4 注释行一并删），保留其前的 `@keyframes radar-spin` 与其后内容。
4. `i18n/types.ts` + 三语 locales：删除 `common.sound.*` 4 键。
5. `werewolf.css` L1327 注释由「顶部栏(GamStatusHeader + 音效开关同行)」改为「顶部栏(GameStatusHeader)」。
