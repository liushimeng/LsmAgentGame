## 1. 背景与目标

### 1.1 定位转变声明（本方案的核心）

「虚拟城市」**不再是一款游戏**。它是一个**由人类 Agent（居民 Agent）组成的真实城市模拟器**：

- 每位居民 Agent 由一张全息人生档案（75,115 张人物卡，Schema v1.1，65 字段）赋予身份；
- 居民在城市中**真实地生活**——就业、消费、储蓄、投资、创业、社交、借贷、成家、购房、养老；
- 城市层面的经济周期、市场价格、利率通胀、社会信用、公共财政与治理，由全体居民行为与制度规则**交互涌现**；
- 以真实中国经济为底座（真实税制、社保、居民收支、LPR/CPI、市场参数），高保真复现人类真实生活；
- **没有胜负与竞技目标**，只有人生的时间推进与多维度人生结局评定——它是模拟系统，不是竞技游戏。

> 「虚拟城市」是一个由大模型驱动的**全 Agent 真实城市模拟器**：每位居民 Agent 依据一张全息人生档案

> 没有胜负，只有以真实中国经济底座高保真复现的人类真实生活。
