# 德州扑克 Web 端产品界面优化方案

> **日期**: 2026-08-22
> **版本**: §20260822-02
> **问题来源**: 用户反馈 — 创建德州扑克房间弹窗的「选择盲注级别」使用 List 下拉菜单选择，目的是减少显示空间，减少房间名称下面的大面积留白区域。

---

## 1. 问题分析

### 1.1 用户反馈原话

> 创建房间弹出式界面 `创建德州扑克房间` 的 `选择盲注级别` 使用 List 下拉菜单选择，这样的目录是减少显示空间，减少房间名称下面的大面积留白区域。

### 1.2 现象描述

#### 现象 1（P0 — 视觉样式完全缺失）

`BlindSelector` 和 `BuyinSlider` 两个 React 组件都使用了语义化的 BEM 类名（`.blind-selector__grid`、`.blind-card`、`.blind-card__bb`、`.buyin-slider__presets` 等），但在 `ClientWeb/src/styles/` 全目录搜索这些类名时**零命中**：

```bash
$ grep -rln "blind-selector\|blind-card\|buyin-slider" ClientWeb/src/styles/
（无输出 — 没有任何 CSS 文件定义这些类的样式）
```

这意味着用户在前端看到的是浏览器默认 `<button>` 渲染：5 个盲注档位按钮（10/50/200/1000/5000 BB）以裸 button 形式挤成一团，每行显示 BB/SB/Ante/BuyIn范围/默认买入 4 行文字（来自 `BlindSelector.tsx:93-102`），实际效果是「信息密集 + 无视觉层次 + 大量空白」。

#### 现象 2（P1 — 弹窗两列布局挤压）

`texasholdem.css:199-204` 的 `.thp-create-modal__row` 是两列网格布局：

```css
.thp-create-modal__row {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 12px;
  margin-bottom: 12px;
}
```

把 `BlindSelector` 和 `BuyinSlider` 都塞入单行 → 弹窗宽度 480px → 每列 ~220px → 盲注选择器的 5 个卡片挤在 ~220px 窄列里、卡片内容换行严重。下方剩余垂直空间因 `max-height: 80vh` 和 `overflow-y: auto` 而出现明显空白条。

#### 现象 3（P2 — 棋类共用 selector 已存在但样式缺失）

`AnteSelector.tsx`（中国象棋 / 中国军棋共用）使用 `.ante-selector`、`.ante-tier` 等类名，同样在样式目录中无任何定义。这是同类问题的另一表现，但不在本任务范围内（仅记录）。

### 1.3 根因清单

| 编号 | 根因 | 触发条件 | 严重度 |
|------|------|---------|--------|
| **R1** | `BlindSelector` 的所有 BEM 类无 CSS 规则 | 任何时候打开创建房间弹窗 | **P0** |
| **R2** | `BuyinSlider` 的所有 BEM 类无 CSS 规则 | 同上 | **P0** |
| **R3** | 弹窗 row 强制 2 列布局，盲注选择器与买入选择器挤在一行 | 同上 | **P1** |
| **R4** | 盲注选择器使用 5 档卡片网格（每档 4 行信息），占空间大 | 用户反馈 | **P1** |
| **R5** | `BlindSelector` 余额提示放在标题右侧，弹窗窄列里会换行 | 余额 < min buy-in 时 | **P2** |
| **R6** | `BuyinSlider` 当前买入 + 风险提示在窄列里换行 | 余额不足 / 风险 ≥25% | **P2** |
| **R7** | 弹窗 footer 与 body 间距不可见，整体留白感重 | 同上 | **P2** |

### 1.4 期望与现状对比

| 维度 | 用户期望 | 现状 | 差距 |
|------|---------|------|------|
| 盲注选择方式 | 单行下拉列表（List），点开后展示档位 + 简要信息 | 5 张卡片密集堆叠，无样式 | **完全不一致** |
| 空间占用 | 占 1 行约 30-40px 高度 | 占 5 行以上 ~200px 高度（理论） | **5-7 倍** |
| 房间名称下留白 | 不应出现大面积留白 | 盲注选择器挤压后下方出现空白条 | **明显留白** |
| 信息可读性 | 各档位信息清晰可读 | 类名无样式，文字拥挤 | **不可读** |
| 弹窗整体高度 | 紧凑，约 480-560px | 当前样式溢出 + 80vh 限制触发滚动 | **整体松散** |

---

## 2. 解决方案

### 2.1 总体思路

1. **重写 BlindSelector**：将 5 档卡片网格改为 `<select>` 下拉列表，每行展示一个档位（含 BB/SB/Ante/BuyIn/默认买入的紧凑信息）。
2. **修复 BuyinSlider**：补齐缺失的 CSS 样式，让 min/default/max 快捷按钮 + 滑块 + 风险提示正常显示。
3. **调整弹窗布局**：把 `.thp-create-modal__row` 从「两列」改为「单列堆叠」，每个选择器独占一行，给下拉列表足够宽度。
4. **样式集中**：把两个选择器的 CSS 添加到 `texasholdem.css`（与组件所在游戏一致 — CLAUDE.md §2.1）。

### 2.2 修改清单

| 修改项 | 文件 | 修改内容 | 预期效果 |
|--------|------|---------|---------|
| **M1** | `BlindSelector.tsx` | 重写为 `<select>` 下拉列表 + 选中档位的紧凑信息条（BB/SB/Ante/BuyIn range/default） | 占用 1 行 ~36px，可折叠 |
| **M2** | `BuyinSlider.tsx` | 保留结构（min/default/max 三按钮 + 滑块 + 风险提示），但 className 保持不变（向后兼容） | 视觉样式生效 |
| **M3** | `texasholdem.css` | 新增 `.blind-selector`、`.blind-select`、`.blind-info-row` 等样式 | 下拉选择器视觉 |
| **M4** | `texasholdem.css` | 新增 `.buyin-slider`、`.buyin-slider__presets`、`.buyin-slider__range` 等样式 | 买入选择器视觉 |
| **M5** | `texasholdem.css` | `.thp-create-modal__row` 改为单列布局（`grid-template-columns: 1fr`），让每个 field 独占一行 | 弹窗整体紧凑，无横向挤压 |

## 3. 实施步骤

### 3.1 第一阶段：BlindSelector 重写（核心需求）

1. 重写 `ClientWeb/src/components/ui/BlindSelector.tsx`：
   - 移除 `.blind-selector__grid` + 5 个 `.blind-card` 按钮
   - 替换为 `<select>` 下拉列表，5 个 `<option>` 各含 BB + BuyIn range
   - 选中后下方渲染 `.blind-selector__info-row` 显示该档位的详细 4 列信息（BB/SB+Ante/BuyIn range/默认买入）
   - 余额不足的档位置灰（`disabled` 属性）
   - 保留余额显示、tooltip（option 的 title 属性）

### 3.2 第二阶段：BuyinSlider 样式补齐

1. 在 `texasholdem.css` 添加 §2.6.2 的所有 `.buyin-slider*` 规则
2. BuyinSlider 组件本身无需改动

### 3.3 第三阶段：BlindSelector 样式补齐

1. 在 `texasholdem.css` 添加 §2.6.1 的所有 `.blind-selector*` 规则
2. 弹窗布局调整（`.thp-create-modal__row` 改单列 + `.thp-create-modal__card` 改 440px）

### 3.4 第四阶段：i18n 同步

1. 在 `zh-CN.ts` / `en.ts` / `ja.ts` 添加 3 个新键
2. 验证类型签名匹配（TKey）

### 3.5 第五阶段：编译验证

1. `cd ClientWeb && tsc --noEmit` 类型检查通过
2. `cd ClientWeb && npm run build` 构建成功
3. `cd ServerGo && go build -o LsmAgentGame main.go` 后端编译通过（无相关改动但需兜底）

## 5. 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| BlindSelector 重写后丢失 BuyIn 信息 | 用户看不到档位的 BuyIn 范围 | 在选中档位下方加信息条展示 4 列详细数据 |
| 余额提示遮挡 | 弹窗窄列里余额文字过长 | 余额数字右对齐，超出 ellipsis |
| 选项 disabled 后 select 整体灰化 | 部分浏览器会让 select 不可用 | 仅 option disabled，不给 select 加 disabled |
| BuyinSlider 现有 className 与新样式冲突 | 已有用户组件 className 复用 | 检查 common.css / appmodal.css / werewolf.css，无冲突 |
| 现有 dist/index-*.js 缓存 | 部署后用户需刷新 | rebuild_restart_app.sh 重新构建 |
