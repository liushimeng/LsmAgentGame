# 雷达图显示优化方案 (§20260816-04)

> 分析日期: 2026-08-16 | 状态: 待实施

## 1. 问题诊断

### 1.1 现象

在 `🤖 LLM 模型管理` 页面点击 `📊 能力雷达图` / `📊 隐藏雷达图` 按钮，按钮文本**正常切换**（说明 `showRadar` state 正确 toggle），但页面**无任何视觉变化**——雷达图始终不显示。

### 1.2 根因分析

读取源码后发现 **3 层原因叠加**：

| # | 层 | 文件:行 | 问题 |
|---|---|---|---|
| P1 | **数据守卫过严** | `ModelAdminPage.tsx:563` | `{showRadar && radarData && Object.keys(radarData).length > 0 && (` 要求 `radarData` 非 null **且** 非空对象。若 API 返回 `{}`（DB 无 game_log 记录）或 `null`（API 静默失败），整个 section 被跳过，用户只看到按钮变色但无任何反馈。|
| P2 | **静默错误吞噬** | `ModelAdminPage.tsx:211` | `.catch(() => { /* best-effort */ })` 将所有 API 错误吞掉，`radarData` 永远停留在 `null`，且无任何错误提示或重试入口。|
| P3 | **无加载态** | `ModelAdminPage.tsx:206-212` | `getRadarStats()` 是异步调用，但没有 loading state，用户无法知道数据正在加载还是已经失败。|
| P4 | **缺少空态说明** | `ModelRadarChart.tsx` | 当 `radarData` 存在但所有模型 `games === 0` 时，`models` 数组为空，SVG 渲染出空壳（只有网格线无数据），用户无法理解为什么没有彩色多边形。|

### 1.3 后端 API 验证

后端 `GET /api/llm/radar` (ServerGo/api/llm_api.go:70) 实现正确：
- `ModelLogService.RadarStats()` 执行 `GROUP BY provider_id` 聚合查询
- 返回 `map[provider_id]*ModelRadarStats`，5 维度归一化到 0..100
- 无 game_log 时返回空 map `{}`，有数据时返回正常

**结论：后端无问题，纯粹是前端交互缺陷。**

## 2. 优化方案

### 2.1 修复 P1+P2+P3：数据加载三态 + 错误反馈 + 重试

**改动文件**: `ClientWeb/src/pages/ModelAdminPage.tsx`

```ts
// 替换现有 radarData/showRadar 两个 state 为三态：
const [radarState, setRadarState] = useState<
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'ready'; data: Record<string, ModelRadarStats> }
  | { status: 'error'; message: string }
>({ status: 'idle' });
const [showRadar, setShowRadar] = useState(false);
```

**加载逻辑**：
- 点击按钮时，如果 `radarState.status === 'idle' || 'error'`，先触发加载再 toggle
- 加载中显示 spinner
- 加载失败显示错误信息 + 重试按钮
- 加载成功但数据为空显示友好提示「暂无对局数据，模型完成 ≥1 局后自动显示」

### 2.2 修复 P4：空态 UI

**改动文件**: `ClientWeb/src/components/common/ModelRadarChart.tsx`

- 当 `models` 数组为空时，显示占位图 + 引导文案而非空白 SVG
- 增加 `loading` / `error` 两个可选 props

### 2.3 视觉增强

- **展开/收起动画**: `max-height` + `overflow: hidden` 过渡
- **暗色主题增强**: 网格线 `0.12` → `0.18` 透明度，轴标签 `0.7` → `0.85`
- **数据点 tooltip**: hover 时显示具体数值

### 2.4 i18n 补全

新增 3 语种 key：
- `modelAdmin.radar.loading` / `.empty` / `.error` / `.retry`
