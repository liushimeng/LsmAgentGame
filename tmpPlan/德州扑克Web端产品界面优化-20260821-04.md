# 德州扑克 Web 端产品界面优化方案 (§20260821-04)

> 日期：2026-08-21　|　范围：`ClientWeb/` 德州扑克对局页三栏布局
> 排查工具：`go-web-debug-tool`（`ListChromePages` / `LookChromePageInfo screenshot` / `ControlChromePage eval_js` 只读 DOM 测量）
> 证据截图：`tmpPlan/screenshots-20260821-04/before_fix.png`、`after_fix.png`

## 1. 问题现象（用户反馈）

1. 「游戏棋牌桌面」显示在**左侧**且被**缩小**，完全不可用、看不清楚。
2. 期望布局：「游戏菜单和信息界面」（对手回合 / 底池 / 第 N 手 / 风格切换 / 观战中 / 离开观战 / 规则说明）**最左侧**；「游戏棋牌桌面」**居中**；「房间聊天」**最右侧**。

## 2. 排查过程

1. `git log` 定位：§20260821-02（`9b82d35`）引入三栏 Grid，但只改了 CSS、未核对 JSX DOM 顺序。
2. `go-web-debug-tool` 对线上页截图（`before_fix.png`）：牌桌 spinner 被挤进左窄列、信息面板居中 —— 与反馈一致。
3. `eval_js` 只读测量 `getBoundingClientRect` + `getComputedStyle`，逐层量化出 3 个叠加缺陷（见 §3）。
4. 对照狼人杀同款机制：`werewolf.css` 早已用 `.content:has(.werewolf-game)` 覆写全局 `.content` 限宽，德州扑克漏了这一步。

## 3. 问题诊断（3 层叠加缺陷）

### P0 — DOM 顺序与 Grid 列定义错位（牌桌进 240px 窄列）

`.texas-game .game-area` 声明 `grid-template-columns: 240px minmax(0,1fr) 300px`（信息/牌桌/聊天），
Grid **auto-placement 按 DOM 顺序**填列，而 `TexasHoldemGamePage.tsx` 旧 DOM 顺序为
`board-container → game-info-column → game-chat-column`：

| DOM 序 | 元素 | 落入列 | 结果 |
|---|---|---|---|
| 1 | board-container（牌桌） | 240px 信息列 | **牌桌缩到左侧 240px，不可用** |
| 2 | game-info-column（信息） | 1fr 中列 | 信息面板居中 |
| 3 | game-chat-column（聊天） | 300px 右列 | 正常 |

### P1 — 全局 `.content` 限宽 1280px（大屏中栏只剩 ~644px）

`base.css:311` 的 `main.content { max-width: 1280px; padding: 24px; margin: 0 auto }`。
实测 1920×941 视口：`.texas-game` 宽仅 **1232px**，中列 `1fr` 解析为 **644px**，
牌桌（max-width 1100px）无法展开，整体偏离视口真中心。
狼人杀有 `.content:has(.werewolf-game)` 覆写（`werewolf.css:72`），德州扑克缺失。

### P1 — 继承 xiangqi.css 基类 `.game-area` 的 flex 语义（三栏高度参差）

`xiangqi.css:7` 基类 `.game-area { align-items: flex-start; justify-content: center }` 被 Grid 继承：
实测三列高度 **245 / 765 / 194** 互不相等（聊天列不撑满、信息列悬空）。
另 `.board-container` 残留旧 Flex 布局 `flex: 1 1 auto`（Grid 子项无效属性）。

### P2 — 溢出裁切风险 + 移动端顺序依赖 DOM

- `.board-container` 的 `justify-content: center` + `overflow: auto`：矮视口内容溢出时
  顶部被裁切到滚动不可达区域（经典 Flex 陷阱）。
- 640px 单列折叠顺序隐式依赖 DOM 顺序；产品上移动端应「牌桌优先」。

## 4. 修改方案

### 4.1 `ClientWeb/src/pages/TexasHoldemGamePage.tsx`

- 交换 `.game-area` 三个子 div 的 DOM 顺序为 `game-info-column → board-container → game-chat-column`。
- 注释更新：列位现由命名网格区域决定，与 DOM 顺序解耦。

### 4.2 `ClientWeb/src/styles/texasholdem.css`

| # | 规则 | 修改 | 针对 |
|---|---|---|---|
| a | `.content:has(.texas-game)` | 新增：`padding:0; max-width:none; height/max-height: calc(100dvh - var(--header-h,56px)); overflow:hidden`（机制同 werewolf） | P1 限宽 |
| b | `.texas-game .game-area` | 新增 `grid-template-areas: "info board chat"`；`align-items: stretch; justify-content: normal` 覆写基类继承 | P0 根除 + P1 高度 |
| c | 三列 | 各加 `grid-area: info / board / chat` —— **列位不再依赖 DOM 顺序**，根除本类回归 | P0 根除 |
| d | `.board-container` | 删 `flex: 1 1 auto`；加 `min-height: 0`；`justify-content: safe center`（溢出退回 start，不裁切顶部） | P1/P2 |
| e | `@media (max-width: 640px)` | `grid-template-areas: "board" "info" "chat"`（移动端牌桌优先，显式声明） | P2 |
| f | `.texas-game .game-info-panel` | 覆写 xiangqi.css 硬编码 `width: 240px`（+20px padding 溢出 240px 列） | 配套 |

### 4.3 不改动的部分

游戏逻辑、WS 协议、`GameInfoPanel` / `ActionControls` / `GameChatPanel` 组件逻辑零改动；
4 档桌面断点（1280/1024/768）仅列宽数值，随命名区域自动适配。

## 7. 回归风险

- `:has()` 需 2024+ 浏览器 —— 与狼人杀同机制同基线，可接受。
- 命名网格区域使列位与 DOM 顺序解耦：后续无论怎么调 JSX 顺序都不会复现 P0。
- 其他游戏不受影响：所有新规则均带 `.texas-game` / `:has(.texas-game)` 前缀。
