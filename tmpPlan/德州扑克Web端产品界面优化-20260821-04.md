# 德州扑克 Web 端界面布局优化方案 (2026-08-21)

## 1. 问题诊断

### 核心 Bug: DOM 顺序与 CSS Grid 列定义不匹配

CSS 中 `.texas-game .game-area` 已正确声明了三栏 Grid 布局:
```css
grid-template-columns: 240px minmax(0, 1fr) 300px;
/*                     信息(左)  牌桌(中)   聊天(右) */
```

但 `TexasHoldemGamePage.tsx` 的 JSX DOM 顺序为:
1. `div.board-container` (牌桌) -- **占据 Grid 第 1 列 = 240px (信息列宽度)**
2. `div.game-info-column` (信息) -- **占据 Grid 第 2 列 = 自适应**
3. `div.game-chat-column` (聊天) -- **占据 Grid 第 3 列 = 300px**

**结果**: 牌桌被挤入 240px 窄列 → 显示在左侧且缩小，完全不可用。

### 次要问题: flex 残留属性

`.board-container` 仍保留 `flex: 1 1 auto`，这是旧 Flex 布局的残留。
在 Grid 容器中，子元素用 `grid-column` 控制尺寸，flex 属性无效且可能干扰布局。

---

## 2. 修改方案

### 2.1 修改 `TexasHoldemGamePage.tsx` (JSX)

**操作**: 交换 `.game-area` 内三个子元素的 DOM 顺序。

修改前 (当前):
```jsx
<div className="game-area">
  <div className="board-container">...        {/* 1st → grid col 1 (240px, 错误) */}
  <div className="game-info-column">...        {/* 2nd → grid col 2 (1fr, 错误) */}
  <div className="game-chat-column">...        {/* 3rd → grid col 3 (300px, OK) */}
</div>
```

修改后 (目标):
```jsx
<div className="game-area">
  <div className="game-info-column">...        {/* 1st → grid col 1 (240px, 正确) */}
  <div className="board-container">...          {/* 2nd → grid col 2 (1fr, 正确) */}
  <div className="game-chat-column">...        {/* 3rd → grid col 3 (300px, 正确) */}
</div>
```

### 2.2 修改 `texasholdem.css`

**操作 A**: 清理 `.board-container` 的 flex 残留属性 (保留 Grid 兼容的必要属性)。

修改前:
```css
.texas-game .board-container {
  flex: 1 1 auto;
  min-width: 0;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  gap: 12px;
  overflow: auto;
}
```

修改后:
```css
.texas-game .board-container {
  min-width: 0;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  gap: 12px;
  overflow: auto;
}
```

## 3. 预期效果

- **信息面板(左)**: 240px 固定宽，展示座位列表、牌局信息、风格切换、操作按钮
- **牌桌(中)**: 自适应宽 (`1fr`)，椭圆桌布 + 6 座位 + 公共牌居中展示
- **聊天(右)**: 300px 固定宽，实时聊天面板
- **响应式**: 640px 以下单列堆叠，顺序为 信息 → 牌桌 → 聊天
- **所有现有功能保持不变**: ActionControls、BotThoughtPanel、GameChatPanel 均无逻辑修改
