# 私下通道 & 阵营赌注 模块布局紧凑化优化

> 2026-08-16 §20260816-01
> 关联: §20260812-03 U2/U3(原始落地) · §126「组件存在但未被 import 等于不存在」

## 1. 问题

两个模块在 `WerewolfGamePage` 中栏(`board-container`)纵向堆叠，占用大量垂直空间：

| 状态 | 当前占用 | 问题 |
|------|---------|------|
| 窗口关闭(非 speak 阶段) | header(28px) + 关闭提示(20px) + 空列表占位(≈40px) ≈ **90px/模块** | 13 人局 4 行座位本就拥挤，中栏每像素都宝贵 |
| 窗口开启(speak 阶段) | header + 表单(select+textarea+meta+btn ≈ 160px) + 列表 ≈ **200px+** | 与 NightActionPanel/DayControlPanel/PropPanel 抢空间 |

两个模块**同时存在**，合计吃掉中栏 300-500px，直接压缩了游戏角色(座位卡)的显示区域。

## 2. 设计方案

### 2.1 折叠式面板(Collapsible Panel)

核心思路：**默认折叠为一行摘要条，点击展开**。

- 新增 `collapsed` state(默认 `true`)，点击 header 切换。
- `collapsed` 状态持久化到 `localStorage`(key: `ww_panel_collapsed_<letter|bet>`)，避免每次进房都展开。
- Header 右侧加 `▼/▲` 指示箭头。

### 2.2 窗口关闭时 — 极简单行

```
✉️ 私下通道 · 仅白天发言阶段开启                          ▲
💰 阵营赌注   · 仅白天发言阶段开启                        ▲
```

- 单行，高度 ≤ 32px。
- 不渲染空列表、不渲染 compose 表单。
- 保留历史信件/下注记录的查看能力(展开后可见)。

### 2.3 窗口开启时 — 紧凑内联表单

**私下通道**：
- select + textarea 改为 `display: grid; grid-template-columns: 120px 1fr` 内联。
- textarea `rows={2}`(原 3)。
- 发送按钮与字数计数同行。
- 列表 `max-height: 200px`(原 320px)。

**阵营赌注**：
- 目标 select + 金额 slider 同行(grid 2 列)。
- 阵营按钮(狼/好)与提交按钮同行。
- 整体两行搞定表单。

### 2.4 CSS 改动

在 `werewolf-20260812-03.css` 中追加折叠态规则(不修改既有规则，保持向后兼容)。

新增类:
- `.ww-panel-collapsed` — 折叠根态(`max-height: 32px; overflow: hidden`)
- `.ww-panel__header` — 可点击 header(加 `cursor: pointer` + 箭头)
- `.ww-panel__arrow` — 箭头旋转动画
- `.ww-panel__body` — 折叠时 `display: none`

### 2.5 改动文件清单

| 文件 | 改动 |
|------|------|
| `ClientWeb/src/components/werewolf/SecretLetterPanel.tsx` | 加折叠 state + header 点击 + 折叠态渲染 |
| `ClientWeb/src/components/werewolf/FactionBetPanel.tsx` | 同上 |
| `ClientWeb/src/styles/werewolf-20260812-03.css` | 追加折叠态 CSS |
| `ClientWeb/src/i18n/locales/{zh-CN,en,ja}.ts` | 新增 `werewolf.panel.expand` / `collapse` 键 |

## 3. 验收

- [ ] 非 speak 阶段:两个模块各仅显示单行摘要条(≤32px)，中栏座位区明显增大
- [ ] speak 阶段:展开后表单紧凑(两模块合计 ≤ 300px)
- [ ] 点击 header 可折叠/展开，箭头旋转
- [ ] localStorage 持久化:刷新后保持折叠状态
- [ ] `tsc --noEmit` 通过
- [ ] 历史信件/下注记录展开后仍可查看

## 4. 教训

(1) **辅助功能模块不应抢占主游戏区域** — 私下通道/阵营赌注是「锦上添花」，默认折叠是对主游戏(座位卡)的尊重;
(2) **空状态也要占空间 = 设计失误** — 「暂无私下信件」的占位 padding 46px 是典型的空间浪费，空状态应收缩到最小;
(3) **折叠状态要持久化** — 不持久化的折叠等于每次强迫用户手动折叠，体验更差。
