## 2. 详细问题分析与修复方案

### 2.1 P0：公共牌区与座位卡层级颠倒

**现象**：中央公共牌区 `.texas-center` 的 `z-index: 1`，而座位卡 `.seat-pos` 的 `z-index: 2`。
座位卡（特别是侧面的 s1-left / s5-right）的底部可能延伸到公共牌区域，遮挡公共牌。

**根因**（`texasholdem.css:514-526`）：
```css
.texas-center {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
  z-index: 1;   /* ← 低于座位的 z-index:2 */
}
```

**修复方案**：
- 将 `.texas-center` 的 `z-index` 提升到 3（高于座位的 2）
- 但座位卡的手牌（`seat-holes`）应该在公共牌上方吗？—— 不，座位卡在椭圆边缘，
  公共牌在正中心，正常情况下不会重叠。但当视口变窄、牌桌高度变小时，
  顶部座位（y: 8%）的底部和底部座位（y: 92%）的顶部可能向中心延伸。
- 更合理的方案：保持座位 z-index:2，将公共牌 z-index 提到 3，
  因为公共牌是「桌面中央」的，视觉上应该在最上层（符合真实赌场牌桌的层次）。

**修改文件**：`ClientWeb/src/styles/texasholdem.css`
- 第 523 行：`z-index: 1` → `z-index: 3`

### 2.2 P0：底部座位下注筹码条被 ActionControls 遮挡

**现象**：`seat-committed` 绝对定位在座位卡底部外 `bottom: -16px`，
但底部座位（s0-bottom, `--seat-y: 92%`）的下注筹码条向下延伸出座位卡，
可能与下方的 ActionControls 面板重叠时被遮挡。

**根因**（`texasholdem.css:642-655`）：
```css
.texas-seat .seat-committed {
  position: absolute;
  bottom: -16px;
  left: 50%;
  transform: translateX(-50%);
  /* 无 z-index，继承父元素的堆叠上下文 */
}
```

**修复方案**：
1. 给 `.seat-committed` 显式设置 `z-index: 1`（在座位卡内层级高于其他内容）
2. 调整底部座位坐标：`s0-bottom` 的 `--seat-y` 从 92% 调整为 88%，
   为下注筹码条和 ActionControls 留出空间
3. 同步调整顶部座位坐标对称：`s3-top` 从 8% 调整为 12%

**修改文件**：`ClientWeb/src/styles/texasholdem.css`
- `.seat-committed` 增加 `z-index: 1`
- `.s0-bottom` 的 `--seat-y: 92%` → `88%`
- `.s3-top` 的 `--seat-y: 8%` → `12%`
- `.s2-top-left` 的 `--seat-y: 14%` → `18%`
- `.s4-top-right` 的 `--seat-y: 14%` → `18%`

### 2.3 P1：Bot 座位高度不一致，布局松散

**现象**：Bot 座位比普通座位多 2 行内容（思考中指示器 + 内心独白），
当 6 个座位中有 5 个是 Bot 时，座位卡高度差导致椭圆布局视觉上不均衡、松散。

**根因**（`PlayerSeat.tsx` + `texasholdem.css`）：
- 普通座位：名字行 + 筹码 + 手牌 = 约 110px
- Bot 座位：名字行 + 筹码 + 思考中 + 内心独白 + 手牌 = 约 150px
- 高度差约 40px，在椭圆布局中造成视觉错位

**修复方案**（三层优化）：

#### 2.3.1 座位卡内容紧凑化
- 将「思考中」与「内心独白」合并为一行（思考时只显示思考中，不思考时显示独白）
- 「内心独白」默认只显示 icon，hover 或点击时展开文字

#### 2.3.2 Bot 徽章精简
- 当前 Bot 徽章显示 "🤖 模型名"，模型名较长（如 "DeepSeek-model"）占空间
- 改为只显示 "🤖" 图标 + title 属性悬浮显示完整模型名

#### 2.3.3 座位卡内间距优化
- `.texas-seat` 的 `gap: 4px` → `3px`
- `.seat-info` 的 `min-height: 18px` → `16px`
- 内边距 `padding: 8px 6px 6px` → `6px 6px 4px`

**修改文件**：
- `ClientWeb/src/components/texasholdem/PlayerSeat.tsx`
  - Bot 徽章文字精简（只保留 🤖 图标，模型名放 title）
  - 思考中 + 内心独白条件优化：思考时隐藏独白，不思考且有独白时显示
- `ClientWeb/src/styles/texasholdem.css`
  - `.texas-seat` gap / padding 调小
  - `.badge.bot-badge` 宽度精简

### 2.4 P1：三栏布局在大屏下留白过多

**现象**：1920px 屏幕上，左列 240px + 右列 300px = 540px，
中间列 = 1920 - 540 - 36(gap/padding) = 1344px，
而牌桌 `max-width: 1100px`，两侧各留 122px 空白。

**修复方案**：
1. 牌桌 `max-width` 从 1100px 提升到 **1200px**（利用更多中间空间）
2. 左列宽度优化：从 240px → 220px（信息面板内容不多，220px 足够）
3. 右列保持 300px（聊天需要一定宽度）

**修改文件**：`ClientWeb/src/styles/texasholdem.css`
- `.texas-game .game-area` 的 `grid-template-columns: 240px minmax(0, 1fr) 300px`
  → `220px minmax(0, 1fr) 300px`
- `.texas-table` 的 `max-width: 1100px` → `1200px`
- 同步调整 1280px / 1024px 断点

### 2.5 P1：顶部座位间距过大，上半区空旷

**现象**：顶部三个座位（s2/s3/s4）水平分布 18%/50%/82%，
在 1200px 宽的牌桌上，座位间距约 384px，而座位卡宽 132px，
每个座位之间有 252px 空隙，上半区显得空旷。

**修复方案**：
- 调整顶部座位的水平坐标，让它们稍微向中心靠拢
- `s2-top-left`: `--seat-x: 18%` → `22%`
- `s4-top-right`: `--seat-x: 82%` → `78%`
- 侧面座位也微调：
  - `s1-left`: `--seat-x: 6%` → `8%`
  - `s5-right`: `--seat-x: 94%` → `92%`

这样整体座位布局更紧凑，更符合真实椭圆牌桌的座位分布。

**修改文件**：`ClientWeb/src/styles/texasholdem.css`
- 调整 6 个座位的坐标

### 2.6 P2：内心独白 hover 弹层被裁切

**现象**：顶部座位的内心独白 hover 弹层向上弹出时，
由于 `.texas-table` 设置了 `overflow: hidden`，弹层可能被裁切。

**根因**（`texasholdem.css:684-704` + 第 488 行）：
```css
.texas-table {
  overflow: hidden;  /* ← 裁切牌桌外的内容 */
}
.seat-heart-thought::after {
  z-index: 100;
  bottom: calc(100% + 4px);  /* 从座位顶部向上弹出 */
}
```

**修复方案**：
- 将 `overflow: hidden` 改为 `overflow: visible`
- 但这会破坏牌桌的椭圆裁剪（背景图的椭圆形状）
- 替代方案：弹层改为「向下弹出」（top: 100%），对于顶部座位更合理
- 或者：只在有空间的方向弹出，用 JS 检测位置

**选择方案**：由于这是 P2 低优先级，且实际触发频率低（需要 hover 顶部座位），
本轮先不修改，记录为后续优化项。

### 2.7 P2：seat-info 行高不稳定

**现象**：`.seat-info` 使用 `flex-wrap: wrap`，当徽章较多时
（如 Bot 座位同时有 D + SB/BB + ALL IN + 🤖），信息行可能变成 2 行，
导致座位卡高度不稳定。

**修复方案**：
- 将 `flex-wrap: wrap` 改为 `flex-wrap: nowrap` + `overflow: hidden`
- 徽章过多时压缩显示，而不是换行
- 或者：将徽章组移到第二行，名字独占第一行

**选择方案**：名字行保持单行，徽章行另起一行且固定高度，
这样即使徽章数量变化，座位卡总高度也稳定。

**修改文件**：
- `PlayerSeat.tsx`：调整 JSX 结构，将名字和徽章分为两行
- `texasholdem.css`：新增 `.seat-badges` 样式

### 2.8 P2：CSS 重复定义

**现象**：`.texas-table { position: relative }` 在 CSS 文件中定义了两次：
- 第 70-72 行（BotThoughtPanel 注释附近）
- 第 482 行（椭圆赌桌节）

**修复方案**：删除第 70-72 行的重复定义，保留第 482 行的完整定义。

**修改文件**：`ClientWeb/src/styles/texasholdem.css`

### 2.9 P2：牌桌最大宽度偏小

**现象**：1920px 屏幕下牌桌 max-width:1100px，而中间列有约 1344px 空间。

**修复方案**（已包含在 2.4 中）：max-width 提升到 1200px。
